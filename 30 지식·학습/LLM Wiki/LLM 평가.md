# LLM 평가

LLM 평가는 모델 단독 점수가 아니라 실제 애플리케이션의 품질, 안전, 비용, 지연시간을 측정하는 과정이다.

## 평가 차원

| 차원 | 질문 | 예시 지표 |
|---|---|---|
| 정확성 | 요구한 답이 맞는가? | 정답률, 사실 오류율 |
| 근거성 | 제공된 근거에 기반하는가? | 인용 정확성, 환각률 |
| 완결성 | 필요한 항목을 빠뜨리지 않았는가? | 필수 항목 충족률 |
| 안전성 | 금지된 정보나 행동을 피하는가? | 정책 위반률 |
| 형식 | 시스템이 파싱할 수 있는가? | Schema 통과율 |
| 성능 | 사용자 요구 시간 안에 답하는가? | p50·p95 지연시간 |
| 비용 | 목표 품질을 적절한 비용으로 달성하는가? | 요청당 비용 |

## 평가셋 구성

- 정상 사례
- 경계 사례
- 입력 누락과 모순
- 공격성 프롬프트와 권한 밖 요청
- 최신 정보와 오래된 정보의 충돌
- 실제 운영 장애에서 수집한 회귀 사례

## 운영 기준

1. 프롬프트·모델·검색 설정 변경 전후를 같은 평가셋으로 비교한다.
2. LLM 심사 결과는 표본 인간 평가로 교정한다.
3. 평균값뿐 아니라 최악 사례와 실패 유형을 본다.
4. 품질 상승과 비용·지연시간 증가를 함께 판단한다.
