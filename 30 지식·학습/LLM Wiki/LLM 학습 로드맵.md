# LLM 학습 로드맵

## 1단계. 기반 개념

- 토큰과 토크나이저
- 벡터와 임베딩
- Transformer와 Attention
- 사전학습, 지시 튜닝, 선호도 정렬
- 컨텍스트 윈도와 생성 파라미터

**완료 기준:** [[LLM 핵심 용어]]의 주요 개념을 자신의 말로 설명할 수 있다.

## 2단계. 모델 활용

- System·User·Tool 메시지의 역할
- 프롬프트 구조와 구조화 출력
- 모델 선택: 품질, 비용, 지연시간, 보안
- 로컬 모델과 API 모델의 차이
- Ollama 기반 모델 실행

**완료 기준:** 동일 과제를 2개 이상의 모델로 평가하고 선택 근거를 기록한다.

## 3단계. RAG

- 수집, 정제, 분할, 임베딩, 검색, 재랭킹
- 벡터 검색과 키워드 검색
- 메타데이터 필터와 접근 권한
- 답변 인용과 근거 검증
- 검색 평가와 생성 평가

**완료 기준:** 작은 문서 집합으로 [[RAG]] PoC를 만들고 정답률·근거성을 측정한다.

## 4단계. Agent와 MCP

- Tool calling과 구조화 입력
- 상태, 메모리, 계획, 재시도
- MCP 서버와 클라이언트
- Human-in-the-loop
- 권한과 실행 경계

**완료 기준:** 읽기 전용 도구부터 시작해 [[AI Agent]]가 3단계 이상의 작업을 안전하게 수행한다.

## 5단계. 평가와 운영

- 오프라인 평가셋과 회귀 테스트
- 정확성, 근거성, 안전성, 비용, 지연시간
- 프롬프트·모델·데이터 버전 관리
- 로그, 추적, 알림, 장애 대응
- 레드팀과 보안 검증

**완료 기준:** [[LLM 평가]] 결과로 배포 여부를 판단하고 [[LLMOps]] 운영 절차를 갖춘다.

## 6단계. 기업 적용

- 내부망과 데이터 등급
- 개인정보와 회사 기밀 처리
- 권한 기반 검색
- PoC → 파일럿 → 제한 운영 → 확산
- ROI, 사용자 채택, 운영 책임

**완료 기준:** 기술 데모가 아니라 책임자·SLA·폐기 기준이 있는 서비스 계획을 작성한다.
