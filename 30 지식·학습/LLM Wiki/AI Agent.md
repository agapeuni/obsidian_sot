# AI Agent

AI Agent는 목표를 달성하기 위해 LLM이 상태를 해석하고, 도구를 선택하며, 여러 단계를 실행하는 시스템이다.

## 핵심 구성

- **목표**: 완료 조건과 허용 범위
- **상태**: 현재 입력, 중간 결과, 남은 작업
- **도구**: 검색, 파일, API, 메시지, 코드 실행
- **정책**: 허용·금지 행동과 승인 경계
- **메모리**: 단기 상태와 장기 지식
- **관측**: 실행 로그, 비용, 지연시간, 오류

## 권장 실행 패턴

```text
요청 이해 → 계획 → 읽기 전용 조사 → 실행 후보 검증
→ 필요 시 사용자 승인 → 실행 → 결과 검증 → 보고
```

## Agent가 필요하지 않은 경우

- 실행 순서가 고정되어 일반 워크플로가 더 예측 가능한 경우
- 단일 API 호출로 해결되는 경우
- 실패 비용이 큰데 승인과 롤백이 없는 경우
- 도구 권한을 최소화할 수 없는 경우

## 안전 기준

- 읽기와 쓰기 도구를 분리한다.
- 삭제·배포·외부 전송·비용 발생은 승인 경계를 둔다.
- 도구 결과를 성공으로 가정하지 않고 후속 검증한다.
- 반복 횟수, 시간, 토큰, 비용 한도를 둔다.
