# LLM Wiki

LLM의 원리, 모델, 애플리케이션 아키텍처, RAG, Agent, 평가, 보안과 운영을 연결하는 실무 지식 위키다.

> [!summary] 목표
> 단편적인 도구 사용법을 모으는 데 그치지 않고, **개념 → 설계 → 구현 → 평가 → 운영 → 콘텐츠 재사용**으로 이어지는 지식 체계를 만든다.

## 빠른 시작

1. [[LLM 학습 로드맵]]에서 현재 수준과 다음 학습 주제를 확인한다.
2. [[LLM 핵심 용어]]에서 개념을 빠르게 찾는다.
3. [[LLM 애플리케이션 아키텍처]]에서 전체 시스템 구조를 이해한다.
4. 프로젝트 목적에 따라 [[RAG]], [[AI Agent]], [[LLM 평가]], [[LLMOps]]로 이동한다.
5. 새 지식은 [[LLM Wiki 작성 규칙]]과 템플릿에 따라 기록한다.

## 지식 지도

```text
LLM 원리
  ├─ 토큰·임베딩·Transformer·Attention
  ├─ 사전학습·미세조정·정렬·추론
  └─ 컨텍스트·프롬프트·구조화 출력

애플리케이션
  ├─ RAG ─ 검색·재랭킹·인용·평가
  ├─ Agent ─ 도구·메모리·계획·MCP
  └─ 멀티모달 ─ 텍스트·이미지·음성·영상

운영
  ├─ 평가 ─ 품질·안전·비용·지연시간
  ├─ LLMOps ─ 배포·관측·버전·장애 대응
  └─ 보안 ─ 데이터 경계·프롬프트 공격·권한
```
