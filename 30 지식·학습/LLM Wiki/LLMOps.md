# LLMOps

LLMOps는 LLM 애플리케이션을 반복 가능하게 개발·배포·관측·평가·개선하는 운영 체계다.

## 관리 대상

- 모델과 모델 파라미터
- System prompt와 템플릿
- RAG 원본, 분할 규칙, 임베딩, 색인
- 도구와 MCP 서버 버전
- 평가셋과 평가 결과
- 비용, 지연시간, 실패율, 안전 이벤트

## 배포 게이트

- [ ] 핵심 평가셋이 기준 점수를 통과했다.
- [ ] 프롬프트와 데이터 버전이 기록되어 있다.
- [ ] 민감정보 마스킹과 접근 권한을 검증했다.
- [ ] 시간·토큰·비용 한도가 설정되어 있다.
- [ ] 오류 알림과 수동 복구 절차가 있다.
- [ ] 이전 버전으로 롤백할 수 있다.

## 핵심 운영 지표

- 요청 성공률과 도구 호출 성공률
- p50·p95 응답 시간
- 요청당 토큰과 비용
- 근거 없는 응답 비율
- 사용자 재질문·수정 비율
- 안전 정책 차단과 오탐 비율
