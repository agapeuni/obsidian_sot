# LLMOps

LLMOps는 LLM 애플리케이션을 반복 가능하게 개발·배포·관측·평가·개선하는 운영 체계다.

## 관리 대상

- 모델과 모델 파라미터
- System prompt와 템플릿
- RAG 원본, 분할 규칙, 임베딩, 색인
- 도구와 MCP 서버 버전
- 평가셋과 평가 결과
- 비용, 지연시간, 실패율, 안전 이벤트

## 배포 게이트

- [ ] 핵심 평가셋이 기준 점수를 통과했다.
- [ ] 프롬프트와 데이터 버전이 기록되어 있다.
- [ ] 민감정보 마스킹과 접근 권한을 검증했다.
- [ ] 시간·토큰·비용 한도가 설정되어 있다.
- [ ] 오류 알림과 수동 복구 절차가 있다.
- [ ] 이전 버전으로 롤백할 수 있다.

## 핵심 운영 지표

- 요청 성공률과 도구 호출 성공률
- p50·p95 응답 시간
- 요청당 토큰과 비용
- 근거 없는 응답 비율
- 사용자 재질문·수정 비율
- 안전 정책 차단과 오탐 비율

## 버전 단위

- 애플리케이션 코드와 배포 환경
- System prompt·도구 설명·출력 Schema
- 모델 공급자·모델 ID·추론 파라미터
- RAG 원본 스냅샷·분할기·임베딩·색인
- 평가셋·평가 코드·판정 임계값

## 장애 대응

1. 요청·검색·모델·도구 호출을 하나의 추적 ID로 연결한다.
2. 영향 범위와 데이터 노출 여부를 먼저 판단한다.
3. 도구 쓰기 권한이나 문제 버전을 차단한다.
4. 이전 검증 버전으로 롤백한다.
5. 장애 입력을 회귀 평가셋에 추가한다.

## 실패 패턴

- 모델 이름만 기록하고 실제 공급자 버전과 파라미터를 남기지 않는다.
- 평균 지연시간만 보고 p95·p99와 타임아웃을 놓친다.
- 프롬프트 로그에 개인정보와 기밀 원문을 그대로 저장한다.
- 평가 통과 없이 모델·프롬프트·색인을 독립 배포한다.
