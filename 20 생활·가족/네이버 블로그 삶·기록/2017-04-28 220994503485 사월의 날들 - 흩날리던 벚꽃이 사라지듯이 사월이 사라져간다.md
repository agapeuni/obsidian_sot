# 2017-04-28 220994503485 사월의 날들 - 흩날리던 벚꽃이 사라지듯이 사월이 사라져간다

이제 길가에 떨어진 꽃잎이 바람에 날려 눈앞에 사라지듯이 사월의 날들이 지나가고 가슴까지 따스한 오월이 조금씩 다가온다. 주어진 하루하루가 소중한 만큼 이렇게 지나가는 시간이 너무 아깝게 생각된다. 아침저녁으로 일교차가 커서 그런지 때아닌 코감기가 걸려버렸다. 당분간 몸조리를 잘 하자.

​

3개월간의 사물인터넷 수험서를 집필을 마치고서 잠시 쉬면서 새로운 프로젝트를 준비하고 있다. 한동안 인생과 성장과 발전을 위한 독서에 열중하다 보니 본업인 프로그래머의 감각이 많이 무디어졌다. 그래서 요즘은 다시 기술서적을 중심으로 단계별로 학습을 진행하고 있다.

​

기술서적의 책 읽기 순서는 다음과 같다. 모든 분야가 웹 프로그래밍을 위해 알고 있어야 하는 기술들은 아니고 개인적으로 관심있는 내용도 포함되어 있다. 먼저 화면 기술(프론트앤드)을 시작으로 그다음은 서버 기술(백앤드)을 익힌다. 그리고 프레임워크와 데이터 관련 기술을 확인한다. 마지막으로 오픈소스 하드웨어를 학습하면서 사물인터넷에 대해 자세히 공부할 계획이다.

  * HTML, CSS (완료)
  * JavaScript (완료)
  * Ajax (완료) 
  * jQuery (완료)
  * jQuery Mobile (완료)
  * JSP/Servlet (완료)
  * Java (진행)
  * Design Patterns 
  * Spring
  * Struts 

| 

  * iBatis
  * Eclipse 
  * Database 
  * XML
  * Linux
  * Raspberry Pi 
  * Arduino 
  * Windows

  * Etc

필요에 의해서 기술서적을 읽고 있는데 일반 서적과 달리 삶의 모습이나 이야기가 없으니 딱딱한 느낌이 든다. 새로운 것을 배우는 기쁨보다는 의무감에서 해야 하는 책 읽기라 어떻게든 빨리 읽어야겠다는 생각뿐이다. 독서한 내용이 머리에 얼마나 저장되고 있을지가 좀 염려스럽다.

​

**[ 시편 23편 1절 ~ 5절 말씀 ]**

**여호와는 나의 목자시니 내게 부족함이 없으리로다**

**그가 나를 푸른 풀밭에 누이시며 쉴 만한 물 가로 인도하시는도다**

**내 영혼을 소생시키시고 자기 이름을 위하여 의의 길로 인도하시는도다**

**​**

**내가 사망의 음침한 골짜기로 다닐지라도 해를 두려워하지 않을 것은**

**주께서 나와 함께 하심이라 주의 지팡이와 막대기가 나를 안위하시나이다**

**​**

**주께서 내 원수의 목전에서 내게 상을 차려 주시고 기름을 내 머리에 부으셨으니 내 잔이 넘치나이다**

**내 평생에 선하심과 인자하심이 반드시 나를 따르리니 내가 여호와의 집에 영원히 살리로다**

**​**

막내가 시편 23편 말씀을 암송한다고 해서 본인이 알아듣게 이야기로 설명해 달라고 해서 하나씩 풀어서 설명해 주었다. 그렇게 설명하던 중에 마음에 잔잔한 감동이 와서 여기에 남겨본다. 여호와께서 그 양들을 위해 푸른 풀밭과 쉴 만한 물 가로 이끌어 주시고 자기의 이름을 위해서 의의 길로 인도해 주신다는 부분이 마음에 와닿는다.
