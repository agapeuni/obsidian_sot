# 2015-03-23 220308982171 요리와 간식 - 순식간에 사라지는 닭 날개 오븐구이

## 본문

![](https://postfiles.pstatic.net/MjAyNDA1MDZfODEg/MDAxNzE0OTMxMzMxNDEz.KmNSY9wwB-PFbPAMLZLnuwS2BEcTRKWJdiIWVct5srYg.eNhFxVA3I9Ixlzmj_K9nY-6qTBneNtpLazBDAxAcr34g.PNG/%EC%9A%94%EB%A6%AC_%EA%B0%84%EC%8B%9D-001.png?type=w80_blur)

​

주말에 아이들을 위해 **닭 날개 오****븐****구이** 에 도전해 보았습니다.

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

재료는 아래와 같습니다.

  * 닭 날개 20개 정도

  * 매콤 소스 : 고추장, 고춧가루, 아카시아 꿀.

  * 짭짤 소스 : 토마토 케첩, 머스터드, 돈가스 소스.

​

마트에서 닭 날개를 사서 깨끗이 물로 씻고 나서 칼집을 내어줍니다.

![](https://postfiles.pstatic.net/20150323_115/agapeuni_1427113898597sroUl_JPEG/20150317_212718.jpg?type=w80_blur)

​

**매콤 소스**

고추장, 고춧가루, 아카시아 꿀을 적당한 양으로 섞어서 **매콤 소스** 를 만들어 둡니다.

![](https://postfiles.pstatic.net/20150323_127/agapeuni_1427113898464H39KM_JPEG/20150317_212527.jpg?type=w80_blur)

​

깨끗이 씻은 닭 날개에 **매콤 소스** 를 골고루 발라줍니다.

![](https://postfiles.pstatic.net/20150323_96/agapeuni_1427113898806N6nD8_JPEG/20150317_212943.jpg?type=w80_blur)

​

**매콤 소스** 가 잘 발라진 닭 날개를 알루미늄 호일 위에 적당한 간격으로 잘 놓아둡니다.

![](https://postfiles.pstatic.net/20150323_78/agapeuni_1427113899024fe766_JPEG/20150317_212948.jpg?type=w80_blur)

​

**짭짤 소스**

토마토 케첩, 머스터드, 돈가스 소스를 적당한 양으로 섞어서 **짭짤 소스** 를 만들어 둡니다. 

![](https://postfiles.pstatic.net/20150323_174/agapeuni_1427113898262a8NnS_JPEG/20150317_212509.jpg?type=w80_blur)

​

깨끗이 씻은 닭 날개에 **짭짤 소스** 를 골고루 발라줍니다. 

![](https://postfiles.pstatic.net/20150323_77/agapeuni_1427113899206OAdo3_JPEG/20150317_213221.jpg?type=w80_blur)

​

닭 날개 전체에 **짭짤 소스** 를 골고루 발라줍니다. 

![](https://postfiles.pstatic.net/20150323_107/agapeuni_1427113899355sk5Id_JPEG/20150317_213257.jpg?type=w80_blur)

소스가 잘 발라진 닭 날개를 알루미늄 호일 위에 적당한 간격으로 잘 놓아둡니다.

붉은색으로 보이는 것은 **매콤 소스** 를 발라둔 닭 날개입니다. 

![](https://postfiles.pstatic.net/20150323_91/agapeuni_1427113899494pHKiE_JPEG/20150317_213559.jpg?type=w80_blur)

​

소스가 잘 발라진 닭 날개를 알루미늄 호일 위에 적당한 간격으로 잘 놓아둡니다.

누런색으로 보이는 것은 **짭짤 소스** 를 발라둔 닭 날개입니다. 

![](https://postfiles.pstatic.net/20150323_191/agapeuni_1427113899647SaQIz_JPEG/20150317_213603.jpg?type=w80_blur)

​

이제 골고루 잘 익을 때까지 오븐에 닭 날개를 굽습니다. 

다 익으면 아이들을 불러서 즐겁고 맛나게 먹습니다.
