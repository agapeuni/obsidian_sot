# Home

Vault 전체의 진입점이다. 각 영역 MOC를 거쳐 문서로 이동한다.
구조와 운영 규칙은 [[README - Vault 구조]]에 있다.

운영 자동화는 [[OpenClaw Obsidian 변경 정책]], 분류 기준은 [[Vault 태그 사전]]을 따른다.

## 수집과 보존

| 영역 | 용도 |
|---|---|
| [[00 Inbox]] | 분류 전 메모, 외부 수집 자료, AI Agent 임시 작성물 |
| [[99 Archive]] | 완료·중단·비활성 자료의 장기 보존 |

## 처리 흐름

1. 새 자료는 분류가 확실하지 않으면 `00 Inbox`에 저장한다.
2. 검토 후 해당 영역으로 옮기고 관련 문서와 링크한다.
3. 완료·비활성 자료는 `status: archived`로 바꾸고 `99 Archive`로 옮긴다.
