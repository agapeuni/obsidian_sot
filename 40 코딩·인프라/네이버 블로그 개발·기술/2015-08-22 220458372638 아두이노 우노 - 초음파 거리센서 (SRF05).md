이번 실험의 준비물은 다음과 같습니다.

보드에는 SRF05라고 표시되어 있고 왼쪽 5개의 핀은 아래의 같이 정의되어 있습니다. 

​

1번 핀 : 5V

2번 핀 : Echo

3번 핀 : Trigger

4번 핀 : Mode

5번 핀 : GND

초음파 센서의 1번 핀에 Vcc를 연결하고 5번 핀에는 GND와 연결합니다. 

![](https://postfiles.pstatic.net/20160506_169/agapeuni_1462523060174b8HFh_JPEG/20150819_233555.jpg?type=w80_blur)

움직이는 것을 바로 촬영하기 위해 서보모터는 간이로 만든 고정대에 놓아두었습니다. 

![](https://postfiles.pstatic.net/20160506_124/agapeuni_1462523062761uj9HE_JPEG/20150819_234927.jpg?type=w80_blur)

**▣ 소스코드 : SRF05_02_servo.ino**

#include <Servo.h> #define ECHO_PIN 2 #define TRIG_PIN 3 #define SERV_PIN 4 Servo servo; void setup() { servo.attach(SERV_PIN); pinMode(ECHO_PIN, INPUT); pinMode(TRIG_PIN, OUTPUT); } void loop() { digitalWrite(TRIG_PIN, LOW); delayMicroseconds(2); digitalWrite(TRIG_PIN, HIGH); delayMicroseconds(10); digitalWrite(TRIG_PIN, LOW); int distance = pulseIn(ECHO_PIN, HIGH); distance = distance / 58; servo.write(map(distance, 10, 50, 179, 0)); delay(50); } 

​

초음파 센서를 구매했는데 센서 하나에 33,000이나 해서 이번 실험은 가격에 부담이 좀 있었습니다. 

구매하고 나서 나중에 네이버에 해당 상품을 검색을 해보니 다양한 가격의 제품들이 있습니다. 

​

성능은 어떨지 모르겠지만 가격은 1,800원인 상품도 있습니다. ㅠㅠ

그래서 가격이 저렴한 센서를 구매해 보았습니다.
