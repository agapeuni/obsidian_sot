**1\. 개요**

Vue.js는 웹 페이지를 개발하기 위한 프런트앤드 프레임워크이다. HTML, CSS, JavaScript를 알고 있는 웹 개발자라면 약간의 학습으로 바로 사용할 수 있다. 최근에 진행하는 웹 프로젝트에서 Vue.js 사용이 점점 늘어나고 있고 대기업에서도 웹 프로젝트를 진행하는데 있어 표준으로 정할만큼 가볍고 빠르다. 다른 프런트앤드 프레임워크처럼 Vue.js도 컴포넌트 기반의 개발을 지원한다. Vue.js는 Angular의 데이터 바인딩과 React의 가상 돔의 장점을 모두 갖고 있다.

​

​

**2\. 설치**

1) Vue CLI를 설치

다음의 명령어로 Vue CLI를 설치한다. -global 옵션을 주어 시스템 레벨로 설치한다.​

> npm install -g @vue/cli

**3\. 예제**

1) Hello Vue.js

message 에 "Hello Vue.js"를 리턴하여 표시한다.

<script> export default { data() { return { message: 'Hello Vue.js' } } } </script> <template> <h1>{{ message }}</h1> </template>

2) 간단한 컴포넌트

항목을 표시하기 위한 Item.vue 컴포넌트를 만들고 사용하는 예제이다.

<script> export default { props: { item: Object } } </script> <template> <li>{{ item.text }}</li> </template>

<script> import Item from './Item.vue' export default { components: { Item }, data() { return { itemList: [ { id: 0, text: '밀가루' }, { id: 1, text: '감자' }, { id: 2, text: '오이' }, ] } } } </script> <template> <ol> <Item v-for="item in itemList" :item="item" :key="item.id" ></Item> </ol> </template>
