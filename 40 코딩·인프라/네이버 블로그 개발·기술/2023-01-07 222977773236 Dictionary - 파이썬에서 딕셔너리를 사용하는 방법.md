1\. 딕셔너리 개요

딕셔너리(Dictionary)는 리스트(List)와 함께 파이썬에서 많이 사용하는 자료형이다. 기본적으로 제공되는 데이터 구조로 순차 데이터를 저장하는 데 사용한다. 연관 배열(Associative Array)처럼 사용하는데 Key와 Value로 이루어진다. 딕셔너리를 생성하는 방법은 중괄호(**{ }**)를 사용하고 중괄호 안에 <키>:<값> 형태로 쉼표(,)로 구분해 주면 된다.

dic = {'이름': '주한길', '회사': '내담씨앤씨', '직급': '부장'} print(dic)

{'이름': '주한길', '회사': '내담씨앤씨', '직급': '부장'}

​

2\. 원소 개수

len 함수를 사용하여 딕셔너리 자료형의 원소 개수를 구할 수 있다.

print(len(dic))

실행 결과

3

​

3\. 데이터 추가

딕셔너리 자료형에 데이터를 추가하려면 인덱싱에 값을 대입하면 된다.

dic["국적"] = "한국" print(dic)

실행 결과

{'이름': '주한길', '회사': '내담씨앤씨', '직급': '부장', '국적': '한국'}

​

4\. 데이터 수정

새로운 키값에 값을 대입하면 데이터가 추가되는데 기존에 존재하는 키값에 값을 대입하면 값이 수정된다.

dic["국적"] = "대한민국" print(dic)

실행 결과

{'이름': '주한길', '회사': '내담씨앤씨', '직급': '부장', '국적': '대한민국'}

​

5\. 데이터 삭제

데이터를 삭제하려면 del 함수를 사용하여 삭제하려는 키를 지정한다.

del dic["국적"] print(dic)

실행 결과

{'이름': '주한길', '회사': '내담씨앤씨', '직급': '부장'}

​

6\. 값 반환

딕셔너리 자료형에 키를 사용하면 값을 얻을 수 있다.

print(dic["이름"])

실행 결과 

주한길

​

7\. 키 확인

in 명령을 사용하면 딕셔너리에 특정한 키가 있는지 없는지 알 수 있다.

print("이름" in dic) print("성별" in dic)

실행 결과

True False

​

8\. 키를 반복

key() 메서드는 딕셔너리의 키를 dict_keys라는 객체로 반환한다.

print(dic.keys()) for k in dic.keys(): print(k)

실행 결과

dict_keys(['이름', '회사', '직급']) 이름 회사 직급

​

9\. 값을 반복

value() 메서드는 딕셔너리의 키를 dict_values라는 객체로 반환한다.

print(dic.values()) for v in dic.values(): print(v)

실행 결과

dict_values(['주한길', '내담씨앤씨', '부장']) 주한길 내담씨앤씨 부장

​

10\. 키와 값을 반복

items() 메서드를 사용하면 딕셔너리의 키와 값을 쌍으로 dict_items 객체로 반환한다.

print(dic.items()) for k, v in dic.items(): print("key[%s] => value[%s]" % (k, v)) 

실행 결과

dict_items([('이름', '주한길'), ('회사', '내담씨앤씨'), ('직급', '부장')]) key[이름] => value[주한길] key[회사] => value[내담씨앤씨] key[직급] => value[부장]

​
