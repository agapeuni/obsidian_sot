## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfNDEg/MDAxNzQ0ODEzNzY4Mjk5.o00egHjTXWD6T243_MpeW0LJG-IcJtMM3lqHRVD8c5gg.uUv-VCR2MmdqLs6Cc6eCPX1jZ8muGYoqXuOqZdcHzfsg.PNG/Java-001_\(6\).png?type=w80_blur)

​

1998년 컴퓨터과학과를 졸업한 이후 현재까지 약 25년간 프로그래밍 업무를 수행해오고 있다. 초기에는 어셈블리와 C 언어를 활용하여 개발을 시작하였으며, 이후 닷컴 시대가 도래함에 따라 웹 기술을 습득하게 되었다. 이 시기에는 ASP와 MS-SQL을 약 2년간 사용하며 실무 경험을 쌓았다.

​

2002년경부터 Java 언어가 시장에서 점차 대중화되기 시작하였고, 이를 계기로 본격적인 Java 개발자의 길을 걷게 되었다. 그렇게 시작한 Java는 20년이 지난 현재까지도 주요 개발 언어로 사용하고 있으며, 다양한 프로젝트에서 지속적으로 활용해오고 있다.

​

한편, Java 언어는 썬마이크로시스템즈(Sun Microsystems)에서 오라클(Oracle)로 소유권이 이전된 이후, 공식 다운로드 페이지의 구조가 자주 변경되었다. 과거에는 원하는 버전을 비교적 쉽게 찾을 수 있었으나, 최근에는 다운로드 링크를 따라가다 보면 다시 JDK 소개 페이지로 되돌아가는 경우가 많아 사용에 불편함이 발생하고 있다.

​

이에 따라, 각 Java SE 버전별로 쉽게 접근할 수 있도록 다운로드 링크를 정리하게 되었다. 참고로, Java SE 18과 17 버전은 별도의 로그인 없이 클릭만으로 바로 다운로드가 가능하나, Java SE 16 이하 버전은 URL에 "otn"이 포함되어 있어 오라클 계정으로 로그인해야 다운로드를 받을 수 있다.
