5\. csr_matrix() 함수

압축 희소 행 행렬 함수인 csr_matrix()를 사용하면 Numpy 배열에서 0이 아닌 데이터의 위치와 값을 쉽게 찾아준다.

import numpy as np from scipy.sparse import csr_matrix print(csr_matrix(np.array([0, 0, 0, 0, 0, 1, 1, 0, 2])))

실행결과

(0, 5) 1 (0, 6) 1 (0, 8) 2

6\. Delaunay 삼각분할

Delaunay 삼각분할이란 평면위의 점들을 삼각형으로 연결하여 공간을 분할한다. 임의의 좌표에 맞게 Delaunay 삼각분할을 사용하여 출력한다.

import numpy as np from scipy.spatial import Delaunay import matplotlib.pyplot as plt points = np.array([ [2, 2], [2, 7], [3, 4], [3.5, 6], [4, 1], [4, 5], [5, 3], [5, 6] ]) simplices = Delaunay(points).simplices plt.triplot(points[:, 0], points[:, 1], simplices) plt.scatter(points[:, 0], points[:, 1], color='r') plt.show()

7\. 통계(stats)

두 개의 독립적인 점수 표본의 평균에 대한 T-검정을 계산한다. 계산된 t-통계량과 양쪽 꼬리 p-값을 구할 수 있다.

import numpy as np from scipy.stats import ttest_ind a = (56, 128.6, 12, 123.8, 64.34, 78, 763.3) b = (1.1, 2.9, 4.2) print(ttest_ind(a, b, trim=.2)) print() v1 = np.random.normal(size=100) v2 = np.random.normal(size=100) print(v1) print(v2) print() res1 = ttest_ind(v1, v2).statistic res2 = ttest_ind(v1, v2).pvalue print('statistic =', res1) print('pvalue =:', res2)
