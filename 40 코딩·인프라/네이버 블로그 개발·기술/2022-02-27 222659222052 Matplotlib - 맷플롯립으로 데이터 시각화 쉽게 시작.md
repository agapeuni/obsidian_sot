1\. Matplotlib 개요

Matplotlib(맷플롯립)은 파이썬에서 데이터 시각화를 위한 가장 널리 사용되는 라이브러리다. Matplotlib은 다양한 유형의 그래프, 플롯, 차트 등을 생성하고 데이터를 시각적으로 표현하는 기능을 제공한다. Matplotlib은 과학적인 그래픽 작업부터 비즈니스 데이터 시각화까지 다양한 분야에서 사용된다. Matplotlib을 사용하면 데이터를 분석하고 이해하기 쉽게 표현할 수 있으며, 인사이트를 얻고 결과를 시각화할 수 있다.

​

Matplotlib은 파이썬의 기본적인 그래픽 기능을 보완하고, 다양한 스타일 및 옵션을 제공하여 그래프를 보다 정교하게 커스터마이즈 할 수 있다. 사용자는 그래프의 축, 레이블, 제목, 색상, 선 스타일 등을 조작하여 그래프를 원하는 대로 디자인할 수 있다. Matplotlib은 NumPy와 함께 사용되는 경우가 많으며, NumPy 배열을 기반으로 데이터를 시각화하는 데 사용된다. 또한, Pandas, SciPy 등 다른 데이터 분석 및 과학적인 계산 도구와 함께 사용하여 데이터 시각화 및 분석 작업을 효과적으로 수행할 수 있다.

​

2\. 선 그래프

plot() 함수로 xy 좌표를 정한하고 데이터를 입력하면 된다. x 좌표는 x = 1, 2, 3, 4, 5이고 y 좌표는 y = 5, 9, 7, 6, 8로 임의로 입력한다. 실제로 사용할 때는 x, y 값에 관한 데이터를 정의하면 된다. 그래프의 범의를 지정하는데 x축은 0에서 6까지 y 축은 4에서 10까지 정한다. 타이틀을 입력하고 x축 라벨, y 축 라벨에 이름을 준다. show() 함수를 사용하면 그래프가 표시되는데 이때 grid() 함수를 사용하면 그래프에 그리드가 표시된다.

​

소스 코드 : matplotlib_1.py​

import matplotlib.pyplot as plt plt.plot([1, 2, 3, 4, 5], [5, 9, 7, 6, 8]) plt.axis([0, 6, 4, 10]) plt.title('간단한 예제') plt.xlabel('x축') plt.ylabel('y축') plt.grid() plt.show()

4\. 사인, 코사인 그래프

Numpy를 사용하여 범위 값을 설정한다. Numpy 라이브러리의 sin() 함수, cos() 함수를 사용하여 y1과 y2의 값을 구한다.

​

소스 코드 : matplotlib_4.py​

import matplotlib.pyplot as plt import numpy as np plt.rc('font', family='gulim') x = np.arange(0, 10, 0.2) y1 = np.sin(x) y2 = np.cos(x) plt.title('사인, 코사인 그래프') plt.xlabel('x축') plt.ylabel('y축') plt.legend() plt.plot(x, y1, label="사인") plt.plot(x, y2, label="코사인") plt.legend() plt.show()

7\. 화면에 구역 나누기

한 화면에 구역을 나누어 N 개의 그래프를 그릴 수 있다. fiqure(1)에 subplot()으로 두 개의 plot을 그리고 figure(2)에 하나의 plot을 그린다.

​

소스 코드 : matplotlib_7.py​

import numpy as np import matplotlib.pyplot as plt x1 = np.arange(0.0, 2 * np.pi, 0.1) x2 = np.arange(0.0, 2 * np.pi, 0.1) plt.figure(1) plt.subplot(1, 2, 1) # 1행 2열, 첫번째 plt.plot(x1, np.sin(x1), 'r--', x2, np.sin(x2), 'k') plt.subplot(2, 2, 2) # 2행 2열, 두번째 plt.plot(x2, np.sin(2 * np.pi * x2), 'g--') plt.figure(2) plt.subplot(2, 2, 2) # 2행 2열, 2번째 plt.plot(x1, np.sin(x1), 'b--') plt.subplot(2, 2, 3) # 2행 2열, 3번째 plt.plot(x2, np.cos(x2), 'r--') plt.show()

10\. 3차원 그래프

다음은 홈페이지에 있는 예제인데 간단한 코드로 3차원의 그래프를 손쉽게 그린다.

​

소스 코드 : matplotlib_10.py​

from mpl_toolkits.mplot3d import Axes3D import matplotlib.pyplot as plt import numpy as np n = 150 xmin, xmax, ymin, ymax, zmin, zmax = 0, 30, 0, 40, 0, 50 cmin, cmax = 0, 3 color = np.array([(cmax - cmin) * np.random.random_sample() + cmin for i in range(n)]) xs = np.array([(xmax - xmin) * np.random.random_sample() + xmin for i in range(n)]) ys = np.array([(ymax - ymin) * np.random.random_sample() + ymin for i in range(n)]) zs = np.array([(zmax - zmin) * np.random.random_sample() + zmin for i in range(n)]) plt.rcParams["figure.figsize"] = (6, 6) fig = plt.figure() ax = fig.add_subplot(111, projection='3d') ax.scatter(xs, ys, zs, c=color, marker='o', s=20, cmap='Greens') plt.show()
