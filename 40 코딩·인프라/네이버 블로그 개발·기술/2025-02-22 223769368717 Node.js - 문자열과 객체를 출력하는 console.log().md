개요

console.log() 메서드는 문자열, 숫자, 객체 등의 값을 출력하는 데 사용된다. 개발 과정에서 코드의 정상적인 흐름을 추적하기 위해 간단히 콘솔에 출력하는 용도로 활용된다. 하지만 실무 환경에서는 console.log()보다 전문적인 로깅 라이브러리를 사용하는 것이 좋다. 이를 통해 로그 레벨 관리, 파일 저장, 로그 분석 및 모니터링이 가능해진다.

​

​문자열이나 숫자를 출력할 때는 어떤 값인지 확인하기 위해 아래와 같이 변수명과 함께 출력하는 경우가 많다.

console.log("n = " + n); console.log("s = " + s);

​

그러나 JSON이나 객체를 출력할 때 아래와 같이 하면,

console.log("obj = " + obj);

​

자바스크립트는 + 연산자를 사용하여 문자열과 객체를 연결하려고 시도하고, 결과적으로 toString() 메서드가 호출되면서 "[object Object]" 형태로 표시된다.

따라서 객체의 내용을 제대로 확인하려면 console.log()에 순수한 객체 참조 변수만 인자로 전달해야 한다.​

console.log(obj); // 객체의 실제 내용 출력

​

또한, JSON 형태로 보기 쉽게 출력하려면 JSON.stringify()를 활용하면 된다.

console.log(JSON.stringify(obj, null, 2)); // JSON 포맷으로 보기 좋게 출력

​

예제 1

문자열이나 숫자를 출력하고 Object를 출력하는 예제이다.

var n = 10; console.log("n = " + n); var s = "Hello Node.js"; console.log("s = " + s); var obj = { name : "Node.js", version : "v0.12.2", sayHello : function() { console.log("Hello Node.js"); } }; console.log("obj = " + obj); console.log(obj); obj.sayHello();

실행 결과

n = 10 s = Hello Node.js obj = [object Object] { name: 'Node.js', version: 'v0.12.2', sayHello: [Function] } Hello Node.js

​

예제 2

Node.js 스트림에 사용할 수 있는 console 객체의 메소드는 log(), info(), warn(), error() 가 있다. console 객체에는 dir(), count(), time(), timeEnd() 메소드로 있다.

console.log('hello world'); console.info('hello %s', 'world'); const name = 'John'; console.warn(`Hello ${name}!`); console.error(new Error('Whoops, error happened'));

실행 결과

예제 3

console.time()과 console.timeEnd()로 소요된 시간을 측정할 수 있다. 시간을 측정하기 위한 시작부분에 console.time() 메소드에 "Time1"을 인자로 기술한다. 그리고 소요된 시간을 측정하길 원하는 지점에 "Time1"을 인자로 하여 console.timeEnd() 메소들를 사용하면 된다.

​

참고로 아래의 for 순환문에서 아무런 의미 없이 반복하여 연산시간을 증가시키기 위한 코드이다.

console.log("Time1 Start!"); console.time("Time1"); var result = 0; for (var i = 0; i < 999999; ++i) { // 단순히 연산시간을 증가시키는 무의미한 코드 result = result + i - i + i - i + i - i + i - i + i - i + i - i; } console.log("Time1 End!"); console.timeEnd("Time1"); console.log("Time2 Start2!"); console.time("Time2"); for (var i = 0; i < 999999; ++i) { // 단순히 연산시간을 증가시키는 무의미한 코드 result = result + i - i + i - i + i - i + i - i + i - i + i - i; } console.log("Time2 End!"); console.timeEnd("Time2");

실행 결과

Time1 Start! Time1 End! Time1: 10.728ms Time2 Start2! Time2 End! Time2: 8.36ms
