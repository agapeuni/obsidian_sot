1\. 개요

입력화면이나 수정화면에서 페이지 인쇄를 하면 입력항목과 선택항목... 등이 그대로 인쇄되는 경우가 있어 보기에 좀 불편하다. 이때 인쇄를 위한 페이지를 별도로 만들지 않고 jQuery를 사용하여 입력화면이나 수정화면을 바로 조회전용 화면으로 전환할 수 있다.

​

**1) 입력 필드 변환**

input[type="text"], select, textarea와 같은 입력 요소를 <span> 태그로 대체하여 텍스트만 남도록 한다. 이를 통해 입력 가능한 항목이 텍스트 형태로 출력되어 인쇄에 적합한 형태로 변환된다.

**​**

**2) 버튼 숨기기**

인쇄 시 필요 없는 버튼은 숨겨 화면을 깔끔하게 유지한다.

​

​

2\. 예제

입력화면을 수정화면으로 변경할 때 select와 text, textarea 항목은 span으로 변경하고 값을 넣어주면 된다. 

화면에 있는 버튼은 인쇄를 위해 잠시 숨긴다.

​

예제 소스 : viewMode.html

<!DOCTYPE html> <head> <title>New Document</title> <script src="http://code.jquery.com/jquery-latest.js"></script> <script language="javascript"> jQuery(document).ready(function() { jQuery.noConflict(); jQuery("select").each(function(i) { jQuery(this).replaceWith("<span>" + jQuery(this).val() + "</span>"); }); jQuery("[type=text]").each(function(i) { var $text = this; jQuery($text).replaceWith("<span>" + jQuery($text).val() + "</span>"); }); jQuery("textarea").each(function(i) { var $textarea = this; jQuery($textarea).replaceWith("<span>" + jQuery($textarea).val() + "</span>"); }); jQuery("[type=button]").hide(); }); </script> </head> <body> <form method="post" action=""> <table border="1"> <tr> <td>input</td> <td><input type="text" name="logo" value="프로그래머 한길"></td> </tr> <tr> <td>input</td> <td><input type="text" name="name" value="Programmer OneWay"></td> </tr> <tr> <td>select</td> <td><select name="sex"> <option value="Female">Female <option value="Man" selected>Man </select> </td> </tr> <tr> <td>textarea</td> <td><textarea name="info" rows="12" cols="20">프로그래밍 정보를 정리하고 공유하는 블로그입니다.</textarea> </td> </tr> <tr> <td colspan="2" align="center""> <input type="button" value="OK"> <input type="button" value="Cancel"> </td> </tr> </table> </form> </body> </html>
