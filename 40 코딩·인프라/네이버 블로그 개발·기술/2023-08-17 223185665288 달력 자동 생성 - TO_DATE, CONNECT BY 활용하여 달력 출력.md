# 2023-08-17 223185665288 달력 자동 생성 - TO_DATE, CONNECT BY 활용하여 달력 출력

​

이 쿼리는 년월(YYYYMM)을 입력하면 해당하는 달의 달력을 출력하는 쿼리이다. 사용자가 입력한 연월(예: 202306)을 기준으로 그 달의 달력을 행(row) 단위로 출력하는 SQL 문이다. Oracle의 날짜 함수와 계층적 쿼리(Connect by)를 활용해 1일부터 말일까지 날짜를 생성하고, 각 날짜를 요일(DAY)에 따라 정렬해 주 단위로 그룹핑하여 달력 형태로 변환한다.

​

**SELECT**

MIN(DECODE(TO_CHAR(dates, 'D'), 1, TO_CHAR(dates, 'DD'))) D1

, MIN(DECODE(TO_CHAR(dates, 'D'), 2, TO_CHAR(dates, 'DD'))) D2

, MIN(DECODE(TO_CHAR(dates, 'D'), 3, TO_CHAR(dates, 'DD'))) D3

, MIN(DECODE(TO_CHAR(dates, 'D'), 4, TO_CHAR(dates, 'DD'))) D4

, MIN(DECODE(TO_CHAR(dates, 'D'), 5, TO_CHAR(dates, 'DD'))) D5

, MIN(DECODE(TO_CHAR(dates, 'D'), 6, TO_CHAR(dates, 'DD'))) D6

, MIN(DECODE(TO_CHAR(dates, 'D'), 7, TO_CHAR(dates, 'DD'))) D7

**FROM**

(**SELECT** (MAKE_DATES + LEVEL -1) DATES

**FROM**

(**SELECT** TO_DATE('202306', 'YYYYMM') MAKE_DATES

**FROM** DUAL

) CONNECT **BY** (MAKE_DATES + LEVEL -1) <= LAST_DAY(MAKE_DATES)

)

**GROUP** **BY** DECODE(TO_CHAR(DATES, 'D'), 1, TO_CHAR(DATES, 'IW') + 1, TO_CHAR(DATES, 'IW'))

**ORDER** **BY** DECODE(TO_CHAR(DATES, 'D'), 1, TO_CHAR(DATES, 'IW') + 1, TO_CHAR(DATES, 'IW'));

**쿼리 설명**

  * TO_DATE('202306', 'YYYYMM') : 기준이 되는 달의 첫 날을 생성합니다.

  * CONNECT BY ... <= LAST_DAY(...) : 해당 달의 마지막 날까지 반복적으로 날짜를 생성합니다.

  * TO_CHAR(dates, 'D') : 각 날짜의 요일(1: 일요일, 7: 토요일)을 숫자로 반환합니다.

  * TO_CHAR(dates, 'DD') : 날짜를 '일(day)' 형식으로 출력합니다.

  * DECODE() 함수 : 요일에 해당하는 열에 날짜 값을 넣기 위한 조건문 역할을 합니다.

  * GROUP BY 와 MIN() : 한 주씩 묶어서, 각 요일에 해당하는 날짜를 정렬하여 행으로 구성합니다.
