1\. Apache와 Tomcat 개요

아파치(Apache)는 정적인 웹페이지를 서비스하는 웹서버이다. 톰캣(Tomcat)은 동적인 웹을 구현하는 웹 애플리케이션 서버(WAS)이다. 아파치 톰캣(Apache Tomcat)은 톰캣이 아파치 웹서버의 기능을 제공하면서 WAS까지 처리하는 형태를 말한다. 톰캣에 내장된 웹서버를 이용하여 구성이 가능하지만 대규모의 웹 시스템에서는 권장하지 않는다. 정적인 페이지를 처리하는 아파치 웹서버를 두고 톰캣과 연동하는 것이 서비스의 부하를 분산시킬 수 있어서 보다 빠르게 응답할 수 있다. 

​

4\. 아파치와 연동하기

HTML, CSS, 이미지와 같은 정적인 페이지를 처리하는 것은 아파치 웹서버가 응답속도가 좋다. 아파치 웹서버를 앞에 두고 서블릿에 대한 요청은 AJP 통신을 통해 톰캣과 연동하여 서비스한다. 그렇게 로드를 분산시켜 WAS인 톰캣은 동적인 페이지 서비스와 데이터베이스 처리 등을 집중할 수 있게 된다.

​

아파치와 톰캣을 연동하는 방법 중 가장 일반적인 방법은 "mod_jk" 모듈을 사용하는 것이다. "mod_jk" 모듈은 아파치 웹 서버와 톰캣 간의 통신을 담당하며, 아파치의 요청을 톰캣으로 전달하고 톰캣이 생성한 동적인 콘텐츠를 다시 아파치로 전달한다.

​

아래는 아파치와 톰캣을 연동하는 단계이다.

​

1) 톰캣 설치

톰캣을 다운로드하고 설치한다. 설치 후에는 톰캣이 정상적으로 실행되는지 확인한다.

​

2) 아파치 설치

아파치를 다운로드하고 설치한다. 설치 후에는 아파치 웹 서버가 정상적으로 실행되는지 확인한다.

​

3) mod_jk 설치

mod_jk 모듈을 다운로드하고 아파치의 모듈 디렉터리에 설치한다.

일반적으로 "mod_jk.so"와 같은 이름을 가지며, 해당 파일을 아파치 모듈 디렉터리에 복사한다.

​

4) 아파치 설정

아파치의 설정 파일(httpd.conf)을 열고, mod_jk 모듈을 로드하도록 설정한다.

LoadModule jk_module modules/mod_jk.so

5) mod_jk 구성

mod_jk의 구성 파일(worker.properties 혹은 mod_jk.conf)을 생성하고, 톰캣과의 연결 정보를 설정한다.

톰캣이 localhost의 8009 포트에서 AJP 연결을 기다리고 있다고 가정한다.

worker.list=worker1 worker.worker1.type=ajp13 worker.worker1.host=localhost worker.worker1.port=8009

6) 가상 호스트 구성

아파치의 가상 호스트(Virtual Host) 설정에서 톰캣과의 연결을 지정한다.

example.com 도메인으로 들어오는 요청을 worker1로 지정하고, 톰캣과 연동한다.

<VirtualHost *:80> ServerName example.com DocumentRoot /var/www/html JkMount /* worker1 </VirtualHost>

​

7) 아파치 재시작

모든 설정이 완료되면 아파치를 재시작하여 변경 사항을 적용한다.

​

​

8) 톰캣 설정

톰캣의 설정 파일 server.xml에서 AJP 포트 설정이 주석으로 되어 있는데 주석을 제거한다.

​

D:\app\apache-tomcat-10.1.19\conf\server.xml

<!-- Define an AJP 1.3 Connector on port 8009 --> <!-- <Connector protocol="AJP/1.3" address="::1" port="8009" redirectPort="8443" /> \-->

그리고 톰캣에서 서비스하고 있는 8080 커넥트는 주석 처리한다.

<!-- A "Connector" represents an endpoint by which requests are received and responses are returned. Documentation at : HTTP Connector: /docs/config/http.html AJP Connector: /docs/config/ajp.html Define a non-SSL/TLS HTTP/1.1 Connector on port 8080 \--> <Connector port="8080" protocol="HTTP/1.1" connectionTimeout="20000" redirectPort="8443" />

이제 아파치와 톰캣이 연동되었다. 아파치는 정적인 콘텐츠를 처리하고, 동적인 요청은 톰캣으로 전달하여 실행한다. 이를 통해 아파치와 톰캣의 협력으로 웹 서버와 웹 애플리케이션 서버를 함께 사용할 수 있다.

​

5\. AJP(Apache JServ Protocol)

AJP(Apache JServ Protocol)는 아파치 웹 서버와 웹 애플리케이션 서버(WAS) 간의 통신을 위한 프로토콜이다. AJP는 아파치 웹 서버와 AJP를 지원하는 웹 애플리케이션 서버(톰캣) 사이에서 효율적이고 빠른 데이터 전송을 위해 설계되었다. AJP는 HTTP와 유사한 방식으로 동작하지만, 일반적으로 더 가볍고 최적화되어 있어 웹 애플리케이션의 성능을 향상시킬 수 있다.

​

AJP는 HTTP와 달리 바이너리 형식으로 데이터를 전송하기 때문에 더 효율적이고 처리 속도가 빠르다. AJP는 아파치 웹 서버와 웹 애플리케이션 서버 사이에서 특정 기능과 통계 정보를 교환하는 데에도 사용될 수 있다. 아파치와 톰캣을 연동할 때 주로 AJP로 통신한다.
