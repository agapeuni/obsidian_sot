1\. 인코딩 확인

JSP에서 현재 페이지의 인코딩(Encoding)을 확인하는 테스트 코드는 다음과 같이 작성할 수 있다. 코드에서는 JSP 페이지의 <%@ page %> 디렉티브를 통해 페이지의 기본 인코딩을 UTF-8로 설정하고 <meta charset="UTF-8"> 태그도 추가로 설정한다.

​

페이지의 <body> 내에서 <% %> 태그를 사용하여 현재 페이지의 인코딩을 확인하고 출력한다. request.getCharacterEncoding() 메서드를 사용하여 현재 요청의 인코딩을 가져와 out.println()을 사용하여 해당 정보를 출력한다.

​

페이지를 실행하면 Current Encoding: UTF-8"이라는 메시지가 표시된다. 

이를 통해 페이지의 인코딩이 UTF-8로 설정되었음을 확인할 수 있다.

<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8" %> <!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>Encoding Test</title> </head> <body> <h1>Encoding Test</h1> <%-- 현재 페이지의 인코딩 확인 --%> <% String encoding = request.getCharacterEncoding(); out.println("Current Encoding: " + encoding); %> </body> </html>

​
