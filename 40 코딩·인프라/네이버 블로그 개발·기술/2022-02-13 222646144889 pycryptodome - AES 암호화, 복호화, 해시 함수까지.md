1\. pycryptodome 개요

PyCryptodomes는 암호화/복호화 처리를 지원하는 pycrypto를 개선한 라이브러리이다. Python 2에서는 PyCrypto를 사용하였는데 Python 3버전에서는 PyCryptodomes를 사용한다. pycrpto를 대처하기 위해 만들어져서 기존의 코드와 호환된다.

​

**CCM**

메시지 인증 코드인 CCM 모드는 데이터 전송시 인증과 기밀성을 모두 제공하도록 설계된 인증 암호화 알고리즘이다. CCM 모드란 Counter 모드+ CBC 모드를 의미한다. Key, AAD, Nonce가 필요하며 모두 MAC 계산에 사용된다. Key는 암호화나 MAC 계산에 쓰이는 데이터를 의미하고, AAD는 추가 인증 데이터를 의미하며, Nonce는 Key나 AAD에 할당되는 유일한 값을 의미한다.

​

**AES**

AES는 암호화/복호화 알고리즘의 하나이고 CCM 모드를 사용한다. DES가 더 이상 안전하지 않아 NIST가 주최한 공모전에서 Rijndael 알고리즘이 선정되었다. SPN 구조를 사용하며 중간에 키를 XOR 해가며 여러 라운드에 걸쳐 사용하면 공격하기가 어려운 구조로 만들어진다. 현재까지도 Full Round에 대해서는 전수조사보다 4배 정도 빠른 방법만이 밝혀졌을 뿐 효과적인 공격이 없기 때문에 안전하다.

3\. 암호화

암호화/복호화 하는 측에서 Key, ADD, Nonce에 관한 정보는 서로 알고 있다고 가정한다.

# ImportError: No module named 'Crypto' 오류로 인한 import import sys import crypto sys.modules['Crypto'] = crypto from Crypto.Cipher import AES # Key는 암호화나 MAC 계산에 쓰이는 데이터를 의미한다. key = bytes([ 0x00, 0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77, 0x88, 0x99, 0xAA, 0xBB, 0xCC, 0xDD, 0xEE, 0xFF ]) # AAD는 추가 인증 데이터를 의미한다. aad = bytes([ 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08, 0x09, 0x0A, 0x0B, 0x0C, 0x0D, 0x0E ]) # Nonce는 Key나 AAD에 할당되는 유일한 값을 의미한다. nonce = bytes( [0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77, 0x88, 0x99, 0xAA, 0xBB] ) # 원본 데이터 plain_data = bytes([0x41, 0x42, 0x43, 0x45, 0x47, 0x48, 0x49, 0x4A, 0x4B, 0x4C, 0x4D, 0x4E]) # 암호화 라이브러리 생성 cipher = AES.new(key, AES.MODE_CCM, nonce) # AAD 추가 cipher.update(aad) # 암호화 cipher_data = cipher.encrypt(plain_data) mac = cipher.digest() # 결과 출력 print("plain =", plain_data) print("cipher_data =", cipher_data) print("mac =", mac)

4\. 복호화

암호화/복호화 하는 측에서 Key, ADD, Nonce에 관한 정보는 서로 알고 있다고 가정한다.

# ImportError: No module named 'Crypto' 오류로 인한 import import sys import crypto sys.modules['Crypto'] = crypto from Crypto.Cipher import AES # Key는 암호화나 MAC 계산에 쓰이는 데이터를 의미한다. key = bytes([ 0x00, 0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77, 0x88, 0x99, 0xAA, 0xBB, 0xCC, 0xDD, 0xEE, 0xFF ]) # AAD는 추가 인증 데이터를 의미한다. aad = bytes([ 0x01, 0x02, 0x03, 0x04, 0x05, 0x06, 0x07, 0x08, 0x09, 0x0A, 0x0B, 0x0C, 0x0D, 0x0E ]) # Nonce는 Key나 AAD에 할당되는 유일한 값을 의미한다. nonce = bytes( [0x11, 0x22, 0x33, 0x44, 0x55, 0x66, 0x77, 0x88, 0x99, 0xAA, 0xBB] ) # 원본 데이터 plain_data = bytes([0x41, 0x42, 0x43, 0x45, 0x47, 0x48, 0x49, 0x4A, 0x4B, 0x4C, 0x4D, 0x4E]) # 암호화 라이브러리 생성 cipher = AES.new(key, AES.MODE_CCM, nonce) # AAD 추가 cipher.update(aad) # 암호화 cipher_data = cipher.encrypt(plain_data) mac = cipher.digest() # 복호화 라이브러리 생성 및 AAD 추가 cipher = AES.new(key, AES.MODE_CCM, nonce) cipher.update(aad) # 복호화 데이터 decrpyt_data = cipher.decrypt_and_verify(cipher_data, mac) print("cipher_data =", cipher_data) print("mac =", mac) print("decrpyt_data =", decrpyt_data)

5\. 해시 함수 암호화

hashlib에는 SHA1, SHA224, SHA384, SHA512, MD5 등의 알고리즘이 들어있다. 단방향 함수인 해시 함수로 암호화할 수 있다. 하지만 암호화된 결과를 다시 복호화 하기는 어렵다. 

import hashlib secret = "password1234" secret_enc = secret.encode() print(secret_enc) sha = hashlib.sha512() sha.update(secret_enc) result = sha.digest() print(result)
