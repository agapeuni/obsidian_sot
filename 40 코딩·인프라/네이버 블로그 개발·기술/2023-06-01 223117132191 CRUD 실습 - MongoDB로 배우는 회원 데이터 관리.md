참고로 CRUD는 Create(생성), Read(읽기), Update(갱신), Delete(삭제)를 말한다.

  * C : Create

  * R : Read

  * U : Update

  * D : Delete​

**3.****C****RUD**

아래와 같이 3건의 데이터를 입력한다. 

member 컬렉션에는 이름과 나이와 보유기술을 입력한다.

db.member.insertOne({name : "Kim", age : 43, skill : [ "Java", "Oracle" ]}) db.member.insertOne({name : "Lee", age : 40, skill : [ "Node.js", "Express" ]}) db.member.insertOne({name : "Park", age : 37, skill : [ "MongoDb", "AngularJs" ]})

생성할 데이터를 먼저 선언하고서 선언된 변수명을 매개변수로 해서 생성할 수도 있다.

1) 먼저 아래와 같이 데이터를 선언한다.

var mems = [ { name: "Son", age: 41, skill: { major: "Reader", minor: "Book" } }, { name: "Jung", age: 39, skill: { major: "Sale", minor: "Comedy" }, option: [ { car: "Santafe", toy: "Lego" } ] } ];

​

2) 선언된 변수명을 매개변수로 해서 생성한다. 결과에 보면 2건이 생성되었다고 표시된다.

> db.member.insertMany( mems );

![](https://postfiles.pstatic.net/MjAyMzA2MDJfOTAg/MDAxNjg1NjMyNDM3NTQ3.jsgsX97XnHlVesfnivSji2VKnGIQIZyj8KfvaQJ5RPwg.w8QgbCE3hjyXW8K2IsA7smEmGj_ZBSP9O8hHgAdS3Zsg.PNG.agapeuni/image.png?type=w80_blur)

배치처리처럼 여러 개의 생성문을 한 번에 실행해 본다.

​

1) 먼저 bult 변수를 선언한다.

> var bulk = db.member.initializeUnorderedBulkOp();

​

2) 선언한 bulk에 데이터 생성을 기록해둔다.

> bulk.insert({ name : "Chio", age: 18, grade : "High School"

​

3) execute() 문으로 한 번에 생성을 한다.

> bulk.execute();

﻿var bulk = db.member.initializeUnorderedBulkOp();﻿ bulk.insert({ name : "Chio", age: 18, grade : "High School" }); bulk.insert({ name : "Chio", age: 21, jobtype : "College" }); bulk.insert({ name : "Chio", age: 24, jobtype : "University" }); bulk.execute();

**5\. C****R****UD (2)**

이름이 "Choi"이고 나이가 20 초과인 사람을 검색하려면

> db.member.find( { name: "Chio", age: { $gt: 20} } )

![](https://postfiles.pstatic.net/MjAyMzA2MDJfMTUg/MDAxNjg1NjMyOTg0NDUy.ou5_nf-BySaTRXe63UXk_vu6NxSUJiKaCW3UT4d8w-0g.zebOe4NfsadM2cCqKkKfdGF5N_R7yPfoOvp0Q_ylWAMg.PNG.agapeuni/image.png?type=w80_blur)

> db.member.find( { $or: [ { name : "Son" }, { age: { $gt: 40} } ] })

![](https://postfiles.pstatic.net/MjAyMzA2MDJfMTgx/MDAxNjg1NjMzMDQ5ODUy.jPu9Wu389F2ahrHrjEnSnSunQTbOikc-geUmSYA6fecg.oGLBzSJn2185CpkLVKDwgRqR5MJS9Ag81n70iAMn3Uwg.PNG.agapeuni/image.png?type=w80_blur)
