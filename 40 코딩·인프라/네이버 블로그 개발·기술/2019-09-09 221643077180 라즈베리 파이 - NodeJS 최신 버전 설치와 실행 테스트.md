​

라즈베리 파이에 NodeJS를 설치하려고 합니다.

​

아래와 같이 node와 npm의 버전을 확인해 봅니다. 

라즈비안 설치 후 톰캣만 설치했는데 NodeJS가 기본적으로 설치되어 있나 봅니다.

​

**$ node -v**

**$ npm -v**

​

참고로 아래의 라즈비안을 설치하였습니다.

​

**raspbian-buster-full.img**(Raspbian Buster with desktop and recommended software)

Version:July 2019

Release date:2019-07-10

Kernel version:4.19

Size:1945 MB

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMTk2/MDAxNTY3OTY0MzAzNjE0.N7lITjp86ps1askj1IikGKipqLa0XcKkmILlKY8VzGIg.MZTjxE_JCDpfpN7RVa2O-eifrVTDksN-W8c-25K7ueUg.PNG.agapeuni/20190909_015449.png?type=w80_blur)

먼저 최신의 NodeJS를 설치하기 전에 아래의 명령어로 기존에 설치되어 있는 nodejs를 제거합니다.

**$ sudo apt remove nodejs**

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMjIz/MDAxNTY3OTY0MzA0NTQz.qXf0I_OdbMmkU9uxokta6xEWKqpeEoCA1h5rHOaaD3kg.5cNwWB1_bNDzpBHYKvS8Y2Fck8NOxjf9M_jxN7-29_Ag.PNG.agapeuni/20190909_015539.png?type=w80_blur)

NodeJS 사이트에 가서 10.16.3 LTS 아래에 있는 "Other Downloads"를 클릭합니다. 

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMjc5/MDAxNTY3OTY0NzY1OTE0.sMZxw-3hypvMqdh-y3C_PjZjyoLkMDn1-n_7poGCSogg.BiazCqOpgSO9M5c0SGCSaKiWdwRbHm1AgGBRNEohU_4g.JPEG.agapeuni/20190909_014915.png?type=w80_blur)

​

Linux Binaries(ARM)에서 ARMv7에서 오른쪽 마우스 클릭으로 "링크주소 복사"를 선택합니다.

복사된 URL: [**https://nodejs.org/dist/v10.16.3/node-v10.16.3-linux-armv7l.tar.xz**](https://nodejs.org/dist/v10.16.3/node-v10.16.3-linux-armv7l.tar.xz)

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMTIz/MDAxNTY3OTY0MzA3Njgw.gebGcLiao_-Oyyfp4cBODSTRvF4jb3FnZE9r5Um2xe0g.jsjXl1FfkDxHcEgL5VpkV8oUSHMaFwIGyNlDchLoIQkg.PNG.agapeuni/20190909_014927.png?type=w80_blur)

​

그리고 다시 터미널 창으로 돌아와 wget 명령어로 복사된 URL을 입력해 설치할 파일을 다운로드합니다.

**$ wget**[**https://nodejs.org/dist/v10.16.3/node-v10.16.3-linux-armv7l.tar.xz**](https://nodejs.org/dist/v10.16.3/node-v10.16.3-linux-armv7l.tar.xz)

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMjU4/MDAxNTY3OTY0MzA0OTE5.IA4ptUtjiUcXmZMJm07pgXZn8SHd3_B9DFeVrBYsABkg.w0jo0EDy87b9c-szozxgSgV5TKkjFCnr82ir3LKlR7Qg.PNG.agapeuni/20190909_015713.png?type=w80_blur)

​

tar.xz 압축파일을 tar 명령어를 사용하여 압축 해제합니다. node-v10.16.3-linux-armv7l 디렉터리에 압축파일이 풀어집니다.

**$ tar -xvf node-v10.16.3-linux-armv7l.tar.xz**

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMTA1/MDAxNTY3OTY0MzA1MzAy.lFQMxqDoLm6xaZVtHyS9qUCl8jW4jp0ldYTWr0Y57WIg.-vOlDKhLwXer3kP0Fr26OkrZMJiQDDyON_tJPc4WpIsg.PNG.agapeuni/20190909_015721.png?type=w80_blur)

​

압축 해제가 완료되면 node-v10.16.3-linux-armv7l 디렉터리에서 /opt/nodejs 디렉터리로 옮깁니다.

**$ sudo mv node-v10.16.3-linux-armv7l /opt/nodejs**

​

그리고 다음과 같이 심볼릭 링크를 걸어줍니다.

**$ sudo ln -s /opt/nodejs/bin/node /usr/bin/node**

**$ sudo ln -s /opt/nodejs/bin/npm /usr/bin/npm**

**$ sudo ln -s /opt/nodejs/bin/npx /usr/bin/npx**

​

아래와 같이 입력하면 새롭게 설치된 node와 npm의 버전을 확인할 수 있습니다.

**$ node -v**

**$ npm -v**
