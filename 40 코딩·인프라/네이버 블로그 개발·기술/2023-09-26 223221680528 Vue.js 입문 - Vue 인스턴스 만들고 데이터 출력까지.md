**​**

**1\. 개요**

Vue.js를 사용하여 화면에 데이터를 표시하기 위해 Vue 인스턴스를 만들고 여러 가지 옵션을 사용한다. 

Vue.js에서 데이터를 표시하는 다양한 방법에 대해서 간단히 알아보자. 

​

​

**2\. 데이터 표시**

Vue.js를 사용하여 데이터를 표시하기 위해 먼저 Vue 인스턴스를 만든다.

new Vue({ ... }) or var vue1 = new Vue({ ... })

​

Vue 인스턴스를 만들고 el 옵션을 사용하여 연결할 HTML 요소를 지정하고 data 옵션을 사용하여 사용할 데이터를 지정한다. data 옵션에 정의한 프로퍼티를 이중 중괄호로 감싸면 프로퍼티의 값이 바로 표시된다. { { 프로퍼티 이름 } }

<div id="app"> <p> {{count}}</p> </div> <script> new Vue({ el: "#app", data: { count: 0 } }) </script>

​

v-text 디렉티브를 사용하여 HTML 요소에 데이터를 표시할 수도 있다.

<div id="app"> <p v-text="hello"></p> </div> <script> new Vue({ el: "#app", data: { hello: "Hello, Vue.js" } }) </script>

​

v-html 디렉티브를 사용하여 HTML 요소에 데이터를 표시할 수도 있다.

<div id="app"> <p v-html="hello"></p> </div> <script> new Vue({ el: "#app", data: { hello: "<h1>Hello, Vue.js</h1>" } }) </script> ​

​

**3\. 오브젝트 데이터 표시**

이번에는 오브젝트 형태의 데이터를 사용하여 화면에 표시해 보자.

<!DOCTYPE html> <html> <head> <meta charset="UTF-8" /> <title>Vue.js</title> <script src="https://cdn.jsdelivr.net/npm/vue@2.5.17/dist/vue.js"></script> </head> <body> <div id="app"> <p>이름 : {{ book.name }}</p> <p>가격 : {{ book.price }}원</p> <br> <p>{{ book }}</p> </div> <script> new Vue({ el: "#app", data: { book: { name: "Vue.js", price: 16000 }, }, }); </script> </body> </html>

**4\. 데이터를 확인**

data로 정의한 전체 구조를 쉽게 확인하는 코드이다. Vue 인스턴스에서 정의한 데이터가 $data에 담겨있다. 

<li v-for="(item, key) in $data">{{ key }} : {{ item }}</li>

<!DOCTYPE html> <html> <head> <meta charset="UTF-8" /> <title>Vue.js</title> <script src="https://cdn.jsdelivr.net/npm/vue@2.5.17/dist/vue.js"></script> </head> <body> <div id="app"> <li v-for="(item, key) in $data">{{ key }} : {{ item }}</li> </div> <script> new Vue({ el: "#app", data: { title: "Vue.js Data", price: 20000, array: [10, 20, 30], isFront: true, isBack: false, }, }); </script> </body> </html>
