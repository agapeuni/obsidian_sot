1\. spaCy 개요

spaCy는 파이썬에서 사용할 수 있는 자연어 처리(Natural Language Processing, NLP) 라이브러리다. spaCy는 최신 연구를 기반으로 제작되었으며 실제 제품에 사용되도록 처음부터 설계되었다. spaCy는 효율적이고 고성능의 자연어 처리 기능을 제공하며, 텍스트 처리 작업을 간단하게 수행할 수 있도록 도와준다. 설치가 쉽고 API가 간단하여 생산성이 좋다. 대규모 정보 추출 작업에 탁월하며 상당히 빠른시간에 처리할 수 있다. 

​

spaCy는 토큰화(Tokenization), 형태소 분석(Morphological analysis), 구문 분석(Syntactic parsing), 개체명 인식(Named Entity Recognition, NER) 등 다양한 자연어 처리 기능을 제공한다. 또한, 품사 태깅(Part-of-speech tagging), 의존성 분석(Dependency parsing), 개체간 관계 추출(Relation extraction) 등의 작업도 지원한다.

​

spaCy는 오픈 소스로 제공되고 있으며, 문서화가 잘 되어 있어 사용하기 쉽다. TensorFlow, PyTorch, scikit-learn 및 나머지 Python의 멋진 AI 생태계와 원활하게 상호 운용된다. spaCy를 사용하면 다양한 자연어 처리 문제에 대해 정교한 통계 모델을 쉽게 구성 할 수 있다. 딥러닝 모델을 준비하는데 가장 좋은 방법이다.

​

5\. 코드 실행 - 영어

"인생은 짧고 예술은 길다"를 영어로 실행해 봅니다. (en_core_web_sm)

import spacy from spacy import displacy nlp = spacy.load('en_core_web_sm') doc = nlp(u'Life is short and art is long') for token in doc: print(token.text, token.pos_) displacy.serve(doc, style="dep")

실행 결과

Life NOUN is AUX short ADJ and CCONJ art NOUN is AUX long ADJ

6\. 코드 실행 - 일본어

"인생은 짧고 예술은 길다"를 일본어로 실행해 봅니다. (ja_core_news_sm)

import spacy from spacy import displacy nlp = spacy.load("ja_core_news_sm") doc = nlp("人生は短く、芸術は長い。") for token in doc: print(token.text, token.pos_) displacy.serve(doc, style="dep")
