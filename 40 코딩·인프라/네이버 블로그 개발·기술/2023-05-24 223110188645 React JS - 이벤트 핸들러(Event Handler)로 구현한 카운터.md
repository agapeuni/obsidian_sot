**1\. 개요**

페이지에 버튼을 표시하고 클릭 이벤트에 따라 값이 변하는 예제를 구현해 본다.

​

​

**2\. 책 정보 예제**

Book 클래스를 하나 만들어 초기에는 제목을 "Vue 가이드", 가격을 20000원으로 표시한다.

제목 변경 버튼을 클릭하면 changeTitle() 함수가 호출되고 가격 변경 버튼을 클릭하면 changePrice() 함수가 호출된다.

​

파일 : event_book.html

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>React</title> <script src="https://unpkg.com/react@18/umd/react.development.js" crossorigin></script> <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js" crossorigin></script> <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script> </head> <body> <div id="container"></div> <script type="text/babel"> class Book extends React.Component { constructor(props) { super(props); this.state = {title: "Vue 가이드", price: props.price}; } changeTitle = () => { this.setState({title: "React 마스터"}); } changePrice = (n) => { this.setState({price: n}); } render(props) { return ( <div> <h2>{this.state.title} - {this.state.price}원</h2> <button onClick={this.changeTitle}>제목 변경</button> <br /><br /> <button onClick={() => this.changePrice("25000")}>가격 변경</button> </div> ); } } const container = document.getElementById('container'); const root = ReactDOM.createRoot(container); root.render(<Book price="20000" />) </script> </body> </html>

**3\. 카운터 예제**

리액트를 학습하는 중에 책의 예제를 참고로 '+' 버튼 기능과 '-' 버튼 기능을 구현해 보았다. Counter 클래스는 부모로부터 전달받은 display를 표시한다. CounterParent 클래스에는 Counter를 표시하고 '+' 버튼과 '-' 버튼을 표시한다. 생성자에서 count 값을 0으로 초기화하고 increase와 decrease 함수에서 count 값을 증가/감소를 한다.

​

파일 : counter.html 

<!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>React</title> <script src="https://unpkg.com/react@18/umd/react.development.js" crossorigin></script> <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js" crossorigin></script> <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script> <style> #container { padding: 50px; background-color: #FFF; } </style> </head> <body> <div id="container"></div> <script type="text/babel"> class Counter extends React.Component { render() { var textStyle = { fontSize : 80, fontFamily : "sans-serif", color : "#377", fontWeight : "bold" }; return ( <div style={textStyle}> {this.props.display} </div> ); } } class CounterParent extends React.Component { constructor(props) { super(props); this.state = { count : 0 }; this.increase = this.increase.bind(this); this.decrease = this.decrease.bind(this); } increase(e) { var curCount = this.state.count; if(e.shiftKey) { curCount += 5; } else { curCount += 1; } this.setState({ count : curCount }); } decrease(e) { var curCount = this.state.count; if(e.shiftKey) { curCount -= 5; } else { curCount -= 1; } this.setState({ count : curCount }); } render() { var backgroundStyle = { padding: 20, backgroundColor: "#FFC53A", width: 150, height: 150, borderRadius : 10, textAlign: "center" }; var buttonStyle = { fontSize: "1.5em", width: 30, height: 30, fontFamily : "sans-serif", color: "#F33", fontWeight: "bold", lineHeight: "3px" }; return ( <div style={backgroundStyle}> <Counter display={this.state.count} /> <button onClick={this.increase} style={buttonStyle}>+</button>&nbsp; <button onClick={this.decrease} style={buttonStyle}>-</button> </div> ) } } const container = document.getElementById('container'); const root = ReactDOM.createRoot(container); root.render(<div><CounterParent /></div>) </script> </body> </html>
