## 본문

_​_

파이썬은 버전 릴리즈 주기가 빠른 언어로, 프로젝트마다 서로 다른 버전을 요구하는 경우가 잦다. 예컨대 어떤 프로젝트는 Python 3.8에서만 정상적으로 작동하는 반면, 다른 프로젝트는 3.12를 요구할 수 있다. 이때 시스템에 설치된 기본 파이썬만을 이용하면 충돌이 발생하거나 개발 환경이 혼란스러워지기 쉽다.

​

이 문제를 해결하기 위해 파이썬 가상환경을 사용하는데, 효과적으로 관리할 수 있는 pyenv를 알아보자. Node.js의 nvm과 유사한 개념으로, pyenv는 여러 버전의 파이썬을 간단히 설치하고 프로젝트별로 적용할 수 있도록 돕는다.

​

1\. pyenv란 무엇인가?

  * 다양한 버전의 파이썬을 손쉽게 설치하고 전환할 수 있는 도구

  * 프로젝트별로 독립적인 실행 환경 구성 가능

  * 프로젝트별로 다른 파이썬 버전을 지정할 수 있어 버전 충돌을 방지

  * pyenv-virtualenv를 함께 사용하면 더욱 강력한 가상환경 관리 가능

​

pyenv를 이용하면 "이 프로젝트는 Python 3.10, 저 프로젝트는 Python 3.12"와 같이 환경을 분리할 수 있다.

​

2\. pyenv 설치 방법

(1) Ubuntu 및 Debian 계열

먼저 필요한 빌드 종속성을 설치해야 한다.

sudo apt update sudo apt install -y make build-essential libssl-dev zlib1g-dev \ libbz2-dev libreadline-dev libsqlite3-dev wget curl llvm \ libncurses5-dev libncursesw5-dev xz-utils tk-dev \ libffi-dev liblzma-dev python-openssl git 

이후 아래 명령어로 설치를 진행한다.

curl https://pyenv.run | bash

(2) Windows

Windows 환경에서는 pyenv-win을 사용해야 한다.

git clone https://github.com/pyenv-win/pyenv-win.git $HOME/.pyenv

환경 변수 설정 후 정상 설치 여부를 확인한다.

pyenv --version

​

3\. 설치 후 환경 설정

설치가 완료되면 셸 설정 파일(~/.bashrc, ~/.zshrc)에 다음 내용을 추가한다.

export PYENV_ROOT="$HOME/.pyenv" export PATH="$PYENV_ROOT/bin:$PATH" eval "$(pyenv init --path)" 

적용은 다음과 같이 한다.

source ~/.bashrc # Bash

​

4\. Python 버전 설치 및 관리

(1) 설치 가능한 버전 확인

pyenv install --list

sgkim@3d:~$ pyenv install --list ... (생략) ... 3.10.15 3.10.16 ... (생략) ... 3.11.10 3.11.11 ... (생략) ... 3.12.7 3.12.8 ... (생략) ... 3.13.0 3.13.1 ... (생략) ... 3.14.0a3 3.14.0a3t 3.14-dev 3.14t-dev

​

(2) 특정 버전 설치

pyenv install 3.11.11

sgkim@3d:~/book$ pyenv install 3.11.11 Installing Python-3.11.11... Installed Python-3.11.11 to /home/sgkim/.pyenv/versions/3.11.11

​

(3) 설치된 버전 확인

pyenv versions

sgkim@3d:~/book$ pyenv versions system * 3.11.11 (set by /home/sgkim/.pyenv/version) 

​

(4) 버전 적용

  * 시스템 전역:

pyenv global 3.11.11

  * 특정 프로젝트:

pyenv local 3.11.11

  * 현재 세션에서만:

pyenv shell 3.11.11

​

5\. pyenv-virtualenv로 가상환경 관리

(1) 설치

git clone https://github.com/pyenv/pyenv-virtualenv.git "$(pyenv root)/plugins/pyenv-virtualenv" echo 'eval "$(pyenv virtualenv-init -)"' >> ~/.bashrc source ~/.bashrc 

(2) 가상환경 생성 및 사용

pyenv virtualenv 3.11.11 myprj # 생성 pyenv activate myprj # 활성화 pyenv deactivate # 비활성화

특정 프로젝트에서만 자동 활성화하려면

pyenv local myenv 

​

6\. 자주 발생하는 문제 해결

  * 명령어 인식 불가

    * PATH 설정 확인 후 재적용

  * Python 빌드 오류

    * 종속성 패키지 누락 여부 확인

  * pyenv-virtualenv 작동 불가

    * eval "$(pyenv virtualenv-init -)" 구문이 셸 설정 파일에 포함되었는지 확인

​

7\. 정리 및 결론

pyenv는 파이썬 개발 환경을 체계적으로 관리할 수 있게 해 주는 필수 도구라 할 수 있다. 개발 환경의 혼란을 줄이고, 프로젝트에 집중할 수 있게 해주는 도구다. 이제 pyenv를 활용하여 안정적이고 효율적인 파이썬 개발 환경을 구축해 보자.
