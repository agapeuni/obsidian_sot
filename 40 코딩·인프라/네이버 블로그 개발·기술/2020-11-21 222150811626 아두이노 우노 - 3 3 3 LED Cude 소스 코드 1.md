​

먼저 시각적 효과를 위해 delay를 3가지 유형으로 나누었다.

핀은 2번부터 13번까지 모두 출력으로 사용한다. 2번부터 10번까지 바닥 9개 연결, 11번부터 13번까지 각 층 연결

int delay1 = 600; int delay2 = 400; int delay3 = 100; void setup() { for (int i = 2; i <= 13; i++) { pinMode(i, OUTPUT); } }

​

반복적으로 사용하는 코드를 함수로 구분하였다. 코드가 조금 무식하다.

2, 3, 4번 핀의 On/Off

5, 6, 7번 핀의 On/Off

8, 9, 10번 핀의 On/Off

void setHigh234() { digitalWrite(2, HIGH); digitalWrite(3, HIGH); digitalWrite(4, HIGH); } void setHigh567() { digitalWrite(5, HIGH); digitalWrite(6, HIGH); digitalWrite(7, HIGH); } void setHigh8910() { digitalWrite(8, HIGH); digitalWrite(9, HIGH); digitalWrite(10, HIGH); } void setLow234() { digitalWrite(2, LOW); digitalWrite(3, LOW); digitalWrite(4, LOW); } void setLow567() { digitalWrite(5, LOW); digitalWrite(6, LOW); digitalWrite(7, LOW); } void setLow8910() { digitalWrite(8, LOW); digitalWrite(9, LOW); digitalWrite(10, LOW); }

​

처음에는 각층을 위에서부터 아래로 전체 On을 하면서 이동하는 코드이다. 

층을 연결한 핀을 제어하면 된다. 1층 : 11번 핀, 2층 : 12번 핀, 3층 : 13번 핀

void showAllLayer() { for (int i = 0; i < 3; i++) { digitalWrite(13, HIGH); delay(delay1); digitalWrite(13, LOW); digitalWrite(12, HIGH); delay(delay1); digitalWrite(12, LOW); digitalWrite(11, HIGH); delay(delay1); digitalWrite(11, LOW); } }

​

이번에는 아래에서 위로 하나의 열을 교차로 Off 하면서 이동하는 코드이다. 

(2, 3, 4) 열 --> (5, 6, 7) 열 --> (8, 9, 10) 열

void showPartLayer() { for (int i = 0; i < 3; i++) { // 2,3,4열 digitalWrite(11, HIGH); setHigh234(); delay(delay2); setLow234(); digitalWrite(11, LOW); digitalWrite(12, HIGH); setHigh234(); delay(delay2); setLow234(); digitalWrite(12, LOW); digitalWrite(13, HIGH); setHigh234(); delay(delay2); setLow234(); digitalWrite(13, LOW); // 5,6,7열 digitalWrite(11, HIGH); setHigh567(); delay(delay2); setLow567(); digitalWrite(11, LOW); digitalWrite(12, HIGH); setHigh567(); delay(delay2); setLow567(); digitalWrite(12, LOW); digitalWrite(13, HIGH); setHigh567(); delay(delay2); setLow567(); digitalWrite(13, LOW); // 8,9,10열 digitalWrite(11, HIGH); setHigh8910(); delay(delay2); setLow8910(); digitalWrite(11, LOW); digitalWrite(12, HIGH); setHigh8910(); delay(delay2); setLow8910(); digitalWrite(12, LOW); digitalWrite(13, HIGH); setHigh8910(); delay(delay2); setLow8910(); digitalWrite(13, LOW); } }

​

이번에는 세로로 Off 가 움직이는 코드이다.

void showMoveSero() { for (int i = 0; i < 3; i++) { digitalWrite(13, HIGH); digitalWrite(12, HIGH); digitalWrite(11, HIGH); setHigh234(); setHigh567(); setLow8910(); delay(delay1); setHigh8910(); setLow567(); delay(delay1); setHigh567(); setLow234(); delay(delay1); setHigh234(); digitalWrite(13, LOW); digitalWrite(12, LOW); digitalWrite(11, LOW); } }

​

마지막은 각 층마다 하나의 LED가 순차적으로 Off 이동하면서 반복하는 코드이다.

void showMoveOne() { for (int j = 11; j <= 13; j++) { digitalWrite(j, HIGH); for (int i = 2; i <= 10; i++) { digitalWrite(i, HIGH); delay(delay3); digitalWrite(i, LOW); } digitalWrite(j, LOW); } }
