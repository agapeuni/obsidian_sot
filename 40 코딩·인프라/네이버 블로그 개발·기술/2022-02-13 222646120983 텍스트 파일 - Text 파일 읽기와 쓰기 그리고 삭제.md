1\. 텍스트 파일(Text File)

텍스트 파일(Text File)은 컴퓨터에서 자료를 저장하는 파일의 일종이다. 텍스트 파일은 사람이 알아볼 수 있는 문자열로 구성되며 확장자가 txt로 되어 있다. 프로그래밍 언어마다 텍스트 파일을 처리하는 함수들이 존재한다. 텍스트 파일의 처리에 있어서 함수 이름이나 사용법 등이 많이 유사하다. 파이썬은 그보다 텍스트 파일 처리가 상당히 간단하고 쉽다. 

​

파이썬에서 파일을 다룰 때 open 함수를 사용하여 파일을 모드별로 연다.

r : 읽기모드 (기본값) - 파일이 없으면 오류가 발생 w : 쓰기모드 - 파일이 없으면 생성 a : 추가모드 - 파일이 없으면 생성 x : 만들기모드 - 파일을 만들고 파일이 있으면 오류를 반환 t : 텍스트 모드 (Text) b : 바이너리 모드 (Binary)

​

읽기 모드가 기본값이라 파일을 열 때는 파일 이름만 open 함수에 넣어주면 된다. 파일에 쓰기 위해서는 "w" 모드를 지정해 준다.

open("sample.txt") open("sample.txt", "w")

​

2\. 파일 쓰기

파이썬으로 간단한 내용을 텍스트 파일에 쓰는 코드를 작성해보자.

for 루프를 사용해서 file.write() 함수로 여러 번 문장을 기록했다.

​

소스코드 : file_write.py

import os # 폴더가 없으면 폴더생성 if not os.path.exists("data"): os.mkdir("data") # 파일쓰기 모드로 열기 with open("data/sample.txt", "w") as f: for i in range(1, 11): line = "line %d. " % i f.write(line + "This is sample file\n") 

실행결과

line 1. This is sample file line 2. This is sample file line 3. This is sample file line 4. This is sample file line 5. This is sample file line 6. This is sample file line 7. This is sample file line 8. This is sample file line 9. This is sample file line 10. This is sample file

​

​

3\. 파일 읽기

이번에는 파일 쓰기로 생성한 텍스트 파일을 readlines() 함수를 사용하여 읽어오는 코드를 작성해 본다.

​

소스코드 : file_read.py

import os file_path = "data/sample.txt" # 파일이 존재하면 파일읽기 if os.path.exists(file_path): # 파일읽기 모드로 열기 with open(file_path, "r") as f: lines = f.readlines() # 개행문자(\n)를 처리 lines = list(map(lambda s: s.strip(), lines)) for line in lines: print(line)

실행결과

line 1. This is sample file line 2. This is sample file line 3. This is sample file line 4. This is sample file line 5. This is sample file line 6. This is sample file line 7. This is sample file line 8. This is sample file line 9. This is sample file line 10. This is sample file

​

3\. 파일 삭제

파일 삭제는 os 모듈의 remove 함수에 파일 경로 값을 입력하면 된다. 파일이 존재하는지 확인한 후에 삭제하는 것이 안전하다.

​

소스코드 : file_remove.py

import os file_path = "data/sample.txt" # 파일이 존재하면 파일삭제 if os.path.exists(file_path): os.remove(file_path) 

​

파일을 다룰 때는 with open(...) as file: 구문을 사용하면 자동으로 파일이 닫혀서 안전하다.

**기능** |  **코드**  
---|---  
파일 쓰기 (w) |  open("파일명", "w").write("내용")  
파일 추가 (a) |  open("파일명", "a").write("내용")  
파일 읽기 (r) |  open("파일명", "r").read()  
한 줄씩 읽기 |  open("파일명", "r").readline()  
여러 줄 읽기 |  open("파일명", "r").readlines()  
파일 삭제 |  os.remove("파일명")
