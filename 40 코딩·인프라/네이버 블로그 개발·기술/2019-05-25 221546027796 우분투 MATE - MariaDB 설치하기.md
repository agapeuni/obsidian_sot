우분투(Ubuntu)를 설치한 라즈베리 파이에 자바(Java)와 톰켓(Tomcat)을 설치해 보았습니다. 

데이터베이스로 MariaDB를 설치해 보겠습니다.

​

MariaDB를 설치하기 위해 다음의 명령어를 수행합니다. 

설치를 계속 진행하려면 "Y"를 입력하고 엔터(Enter)키를 누르면 됩니다.

**​**

**$ sudo apt-get install mariadb-server******

​

설치가 완료되면 아래와 같이 입력을 대기하고 있는 프롬프트 상태로 돌아옵니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjVfMjQg/MDAxNTU4NzE4MjY1NzM4.GPTFSaC-VpBOrEu_PAVSnn3Hzn8ZfAdrjzgit2SThGIg.uuJ5d3_CVDnf1m6FcEzDwWtBAKbgxKjxXM8NxCnab8Qg.PNG.agapeuni/20190525_003708.png?type=w80_blur)

​

MariaDB가 잘 설치되어 실행되고 있는지 아래의 명령어로 확인해 봅니다. MariaDB는 MySQL이 오라클에 인수되면서 오픈소스로 만들어진 데이터베이스입니다. 드라이버 설정이나 서비스 이름은 MySQL과 동일하여 프로세스도 mysql로 표시됩니다. 

​

**$ ps -ef | grep mysql**

​

서비스가 잘 실행된거 같은데 mysql -u root 명령어를 입력하니 ERROR가 표시되네요.

**Access denied for user 'root'@'localhost'**

**​**

그래서 다음과 같이 root권한으로 접속하니 MariaDB에 접속이 잘 되었습니다 .

**$ sudo mysql -u root**

![](https://postfiles.pstatic.net/MjAxOTA1MjVfMTUz/MDAxNTU4NzE4MjY2NTM3.Vqjb5RqRTx6wNkEPUERxazNgxzQ9j3sL1sc_KJ24qD8g.lS5-cRHeJqsiRvCbhVq5RSUUfi5pWzYUo2F35c3hEKkg.PNG.agapeuni/20190525_004252.png?type=w80_blur)

​

접속하고 나서 다음의 명령어를 순서대로 입력하여 MariaDB의 root 사용자 암호를 1234로 설정하였습니다. 

그리고 'root'@'%'의 레코드를 추가로 생성합니다.

**> use mysql **

**> update user set password = password('1234') where user = 'root';**

**> grant all privileges on *.* to 'root'@'localhost' identified by '1234';**

**> grant all privileges on *.* to 'root'@'127.0.0.1' identified by '1234';**

**> grant all privileges on *.* to 'root'@'%' identified by '1234';**

**> flush privileges;**

![](https://postfiles.pstatic.net/MjAxOTA1MjVfNDYg/MDAxNTU4NzE4MjY3MTY0.wiFN81aBDrNy49c6SeEXjwrt46Qi3zhgPyW-Zq9haXEg.mdp88JfZbZiXtDBpuNL9LTmALvOtXcc56DXxDHAmSpYg.PNG.agapeuni/20190525_005244.png?type=w80_blur)

​

구글에 검색하니 기본적인 보안을 설정할 수 있는 mysql_secure_installation 이라는 명령어가 있습니다. 

root 계정의 패스워드 변경과 보안과 접속에 대한 설정을 Y/N 으로 입력으로 설정하고 있습니다. 

![](https://postfiles.pstatic.net/MjAxOTA1MjVfNzQg/MDAxNTU4NzE4MjY3ODY3.cOFT0iWWB4DWphLCxNBwfI1zJm8nUFiYg-z2BWkkmMAg.vmYnlKf7RzxqfCJKGxwl8Blevig8VHELelQ5zxwfr10g.PNG.agapeuni/20190525_005854.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAxOTA1MjVfMTQ2/MDAxNTU4NzE4MjY4NTI5.FcH_WD9kiz7pU141L12pkeDkq5s98AgqC3NuojqvHukg.sWLSegf_5Pv0C24ib7l2NpjUqEg-vgUSsDnV1QbcUVcg.PNG.agapeuni/20190525_005934.png?type=w80_blur)

​

아래의 명령어를 실행하여 로컬에서 뿐만 아니라 외부에서도 접속할 수 있게 하였습니다.

**grant all privileges on *.* to 'root'@'localhost' identified by '1234';**

**grant all privileges on *.* to 'root'@'127.0.0.1' identified by '1234';**

**grant all privileges on *.* to 'root'@'%' identified by '1234';**

​

정보가 잘 저장되었는지 mysql 데이터베이스에서 user 테이블의 내용으로 확인할 수 있습니다.

**select host, user, password from user;**

![](https://postfiles.pstatic.net/MjAxOTA1MjVfMjU0/MDAxNTU4NzE5NTMzNTM4.3yfxA974_plxsuNGOOlw6d9FYXadu3_6Hmy7OHSx3bYg.KGWrNXMh8equkOs7va2nfHqY2OumZHlQpHrrFWY7lLIg.PNG.agapeuni/20190525_023805.png?type=w80_blur)

​

설정을 잘 마치고 나니 아래의 명령어로 root 계정으로 접속할 수 있게 되었네요.

**> mysql -u root -p1234**

![](https://postfiles.pstatic.net/MjAxOTA1MjVfMTY1/MDAxNTU4NzE4MjY5OTcw.qUC_Tk0Hi9mM-IYdVdJF09XM8wY0epgyf03NUizwI2Ig.yIy0J2xLdyI0oAFaxuaA67M-YaC7TwGR96YCn7XaS-wg.PNG.agapeuni/20190525_011840.png?type=w80_blur)
