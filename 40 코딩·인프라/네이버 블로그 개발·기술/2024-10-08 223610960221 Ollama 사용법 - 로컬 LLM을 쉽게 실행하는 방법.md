**Ollama 개요**

Ollama는 AI 모델과 관련된 도구 및 서비스를 제공하는 플랫폼으로, 대형 언어 모델(LLM, Large Language Model)의 배포 및 활용에 중점을 둔다. Ollama는 기업이나 개발자들이 AI 모델을 더 쉽게 배포하고 사용할 수 있도록 다양한 기능을 제공한다.

​

대형 언어 모델(LLM)인 ChatGPT와 GPT-4는 주목받고 있지만, 보통 클라우드 API를 통해 접근해야 하고 비용이 많이 든다. Ollama는 이러한 문제를 해결하는 오픈소스 프로젝트로, 무료로 LLM을 실행할 수 있도록 해준다. Ollama는 Linux, Winmdows, macOS 환경에서 비용 부담 없이 LLM을 돌릴 수 있다.

​

대규모 언어 모델(LLM)을 로컬에서 실행하는 것은 매우 유용하지만, 환경 설정과 실행 과정은 복잡할 수 있다. 이러한 번거로움을 해결하기 위해 Ollama라는 플랫폼이 있다. Ollama는 오픈 소스 대규모 언어 모델을 로컬에서 쉽게 실행할 수 있게 해 주며, 필요한 모든 것(모델 가중치 및 구성 파일)을 단일 Modelfile로 패키지 한다. Ollama는 마치 LLM을 위한 Docker처럼 동작하여, 복잡한 설정 없이 로컬에서 LLM을 실행할 수 있다.

​

​

**Ollama 기능**

**1) 모델 배포 및 관리**

Ollama는 대형 언어 모델을 빠르고 효율적으로 배포할 수 있는 플랫폼을 제공한다. 이를 통해 개발자들은 복잡한 설정 없이 모델을 손쉽게 운영할 수 있다.

​

**2) AI 모델 통합**

Ollama는 다양한 AI 모델을 API 형태로 쉽게 통합할 수 있게 하여, 애플리케이션 내에 자연어 처리, 번역, 생성형 AI 등 기능을 추가하는 것이 간단하다.

​

**3) 고성능 및 확장성**

Ollama는 고성능 환경에서 대규모 모델을 운영할 수 있으며, 필요에 따라 확장이 가능하다. 이를 통해 사용자 요구에 맞게 성능을 조정할 수 있다.

​

**4) 모델 커스터마이징**

Ollama는 사용자가 자신의 필요에 맞게 모델을 맞춤화할 수 있는 기능을 제공한다. 이는 도메인 특화된 AI 모델을 구현하는 데 유리하다.

​

**5) 보안 및 데이터 프라이버시**

Ollama는 데이터를 안전하게 보호하기 위한 다양한 보안 기능을 제공하여, 기업이나 연구 기관에서의 데이터 프라이버시를 보장한다.

​

​

**Ollama 특징****​**

Ollama의 특징들은 AI 모델의 배포 및 관리를 단순화하고, 사용자가 AI 기술을 더 쉽게 사용할 수 있도록 돕는다.

  * 간편한 설정: 모든 필요한 요소가 단일 파일로 패키지 되어 있어 복잡한 환경 구성이 필요 없다.

  * 로컬 실행: 클라우드에 의존하지 않고 로컬 컴퓨터에서 직접 대규모 언어 모델을 실행할 수 있다.

  * 모델 최적화: 하드웨어 리소스를 최적화하여 AI 모델의 성능을 극대화할 수 있다.

  * 멀티 모델 지원: 다양한 언어 모델과 AI 모델을 지원하며, 이러한 모델을 간단하게 전환하거나 통합할 수 있는 기능을 제공한다.

  * 사용자 친화적인 API: 직관적이고 사용하기 쉬운 API를 제공하여, 개발자들이 빠르게 모델을 통합하고 활용할 수 있다.

  * 쉽고 빠른 배포: Ollama는 클라우드 환경에서 AI 모델을 손쉽게 배포할 수 있는 도구를 제공하여, 복잡한 인프라 관리를 간소화한다.

**Ollama 설치**

**1) Ollama 설치**

Ollama는 Linux, Windows, macOS 운영 체제를 지원한다. AI 모델을 실행하기 위해서는 충분한 CPU 또는 GPU 리소스가 필요할 수 있으며, LLM(대규모 언어 모델)은 고성능 GPU가 필요할 수 있다.

​

본 문서에서는 Ubuntu 배포판에서 아래의 명령어를 실행한다. Ollama는 CLI(명령줄 인터페이스)를 통해 설치한다. 설치 과정은 일반적으로 몇 분 정도 소요되며, 설치 중 NVIDIA/AMD GPU가 자동으로 감지된다. CPU 모드에서도 잘 작동하지만, GPU 모드에 비해 훨씬 느릴 수 있다.

**2) 모델 다운로드**

Ollama는 다양한 AI 모델을 지원하므로, 사용하려는 모델을 다운로드해야 한다. Ollama에서 지원되는 모델 패밀리를 확인하려면 모델 라이브러리를 방문할 수 있으며, 여기서 각 모델의 크기, 양자화 등의 정보를 확인할 수 있다. 모델을 실행하려면 태그 목록을 검색하여 원하는 모델을 선택한다. 각 모델 패밀리에는 다양한 크기의 모델이 존재한다.

Ollama는 누구나 무료로 LLM을 실행할 수 있도록 도와주는 플랫폼이다. 설치와 사용법이 간단하며, 다양한 모델을 지원한다. 사용자 정의 프롬프트로 커스터마이징할 수 있어 활용 범위가 넓다. 웹, 모바일, 데이터베이스 등 다양한 플랫폼과 연동할 수 있으며 코딩, 글쓰기, 질의응답 등 다양한 분야에 활용할 수 있는 AI 어시스턴트를 직접 만들 수 있다.

​

양자화(Quantization)는 딥러닝 모델의 가중치(Weights)와 활성화 값(Activations)을 낮은 비트수로 변환하여 모델 크기를 줄이고, 연산 속도를 높이는 기법이다. LLM의 경량화 및 온디바이스 실행을 위해 널리 사용된다. 양자화 모델을 사용하면 보다 적당한 하드웨어에서 모델을 실행할 수 있지만 모델을 양자화하면 모델을 더 빠르게 실행할 수 있고 메모리 소모는 적지만 정확도는 떨어진다. 

​

Ollama는 명령어에 플래그를 사용하여 FP16 및 FP32 기반 모델을 다른 양자화 레벨로 양자화할 수 있다 

-q/--quantize

​

ollama create 명령어와 함께 양자화된 모델을 만들 수 있다.

$ ollama create --quantize q4_K_M mymodel transferring model data quantizing F16 model to Q4_K_M creating new layer sha256:735e246cc1abfd06e9cdcf95504d6789a6cd1ad7577108a70d9902fef503c1bd creating new layer sha256:0853f0ad24e5865173bbf9ffcc7b0f5d56b66fd690ab1009867e45e7d2c4db0f writing manifest success

**지원되는 양자화**

GPTQ 또는 LLAMA 모델에서 사용하는 정규 양자화 방식

LLM의 가중치를 양자화하여 메모리 사용을 줄이고, 추론 속도를 높이는 데 사용된다.

​

  * q4_0: 4비트 양자화 (가장 기본적인 4비트 방식)

  * q4_1: 4비트 양자화 + 보정 (정확도를 조금 높인 방식)

  * q5_0: 5비트 양자화

  * q5_1: 5비트 양자화 + 보정

  * q8_0: 8비트 양자화 (일반적으로 4비트보다 정확도가 높지만, 저장 공간은 더 많이 차지함)

**​**

**K-means 양자화**

K-means는 가중치를 양자화할 때 단순 정규화 대신, 클러스터링(K-means 알고리즘)을 활용하는 방식이다.

일반적인 q4_0, q5_0 등의 정형화된 방식보다 K-means 기반 방식이 더 최적화된 양자화 방식일 가능성이 높다.

일반적인 정형화된 양자화보다 더 높은 압축률을 유지하면서도, 정확도를 더 보장하는 방식으로 연구되고 있다.

​

  * q3_K_S: 3비트 K-means 양자화 (S: Small)

  * q3_K_M: 3비트 K-means 양자화 (M: Medium)

  * q3_K_L: 3비트 K-means 양자화 (L: Large)

  * q4_K_S: 4비트 K-means 양자화 (Small)

  * q4_K_M: 4비트 K-means 양자화 (Medium)

  * q5_K_S: 5비트 K-means 양자화 (Small)

  * q5_K_M: 5비트 K-means 양자화 (Medium)

  * q6_K: 6비트 K-means 양자화 (단일 옵션)
