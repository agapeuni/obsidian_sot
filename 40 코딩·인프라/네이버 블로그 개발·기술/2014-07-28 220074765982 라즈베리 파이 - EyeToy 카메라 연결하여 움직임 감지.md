# 2014-07-28 220074765982 라즈베리 파이 - EyeToy 카메라 연결하여 움직임 감지

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220074765982&categoryNo=982
- 게시일: 2014. 7. 28. 23:31

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTkz/MDAxNzU4NDM3OTMyODk2.DccUje8bxcrUxxowHxUMSFAbC-IkDGRkfRxfHPmXi1og.7ZEZl-XvyCrkrYj7zb14Id7N8MCnww2R45Y-2jMYZQwg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(11\).png?type=w80_blur)

​

예전에 플레이스테이션2를 할 때 사용했던 EyeToy로 **라즈베리 파이**(Raspberry Pi) 카메라로 장착해 보고 화면에 표시되는 영상의 움직임을 감지하기 위한 motion 패키지를 설치해 봅니다. Play Station 2에서 사용했던 EyeToy입니다. 별다른 준비물은 없습니다. 게임으로 사용했던 EyeToy가 이렇게 다시 쓰일 줄은 몰랐네요. ^^ 

![](https://postfiles.pstatic.net/20150605_30/agapeuni_1433464025344hnLGq_JPEG/20140728_224224.jpg?type=w80_blur)

​

USB가 2개 있습니다. 모델 B+는 USB 포트가 4개라고 합니다. 

키보드 마우스를 직접 연결하지 않고 PC에서 원격으로 연결해야 USB 포트를 다른 용도로 사용할 수 있습니다. 

![](https://postfiles.pstatic.net/20150605_227/agapeuni_1433464034335KiCjy_JPEG/20140728_224534.jpg?type=w80_blur)

EyeToy를 **라즈베리 파이**(Raspberry Pi) USB 포트에 꼽아둡니다. 

![](https://postfiles.pstatic.net/20150605_176/agapeuni_1433464043368bjUQI_JPEG/20140728_224612.jpg?type=w80_blur)

SSH로 파이에 연결합니다. 그리고 date 명령어로 날짜를 확인합니다. 

요녀석은 오랜만에 꺼내서 인지 마지막 로그인이 6월 26일이네요.

![](https://postfiles.pstatic.net/20150605_274/agapeuni_1433464051783fPsvO_PNG/20140728_225040.png?type=w80_blur)

motion 패키지를 설치하기 위해서 먼저 update를 실행합니다. 

**sudo apt-get update**

​

![](https://postfiles.pstatic.net/20150605_145/agapeuni_14334640607111gBX2_PNG/20140728_225247.png?type=w966)

그리고 오랜만에 접속도 했으니 최신 패키지로 업그레이드 해줍니다.

**sudo apt-get upgrade**

​

![](https://postfiles.pstatic.net/20150605_110/agapeuni_1433464071413s7zxI_PNG/20140728_225532.png?type=w966)

화면으로 뭐가 많이 지나갑니다.

​

![](https://postfiles.pstatic.net/20150605_172/agapeuni_14334640796503ALV6_PNG/20140728_225647.png?type=w966)

쉘 프롬프트가 보이는 걸 보내 업그레이드가 다 되었나 봅니다.

​

![](https://postfiles.pstatic.net/20150605_89/agapeuni_1433464092248fbcS2_PNG/20140728_225929.png?type=w966)

USB에 연결한 EyeToy를 찾아봅니다. 004에 Sony Corp. 가 표시됩니다.

**lsusb**

**lsusb -s1:4 -v**

![](https://postfiles.pstatic.net/20150605_178/agapeuni_1433464102179dFHMk_JPEG/20140728_230027.jpg?type=w80_blur)

그리고 v4l-utils을 설치합니다. 참고로 v4l은 Video for Linux입니다.

**sudo apt-get install v4l-utils**

​

![](https://postfiles.pstatic.net/20150605_40/agapeuni_14334641104004AgFG_PNG/20140728_230221.png?type=w966)

Video4Linux를 설치하고서 video 디바이스를 조회해 보면 /dev/video0 장치가 표시됩니다.

**ls -al /dev/video***

​

![](https://postfiles.pstatic.net/20150605_141/agapeuni_1433464118142AJ104_JPEG/20140728_230251.jpg?type=w966)

udevadm 명령어로 /dev/video0 장치의 정보를 조회해 보자.

**udevadm info -q all -n /dev/video0**

![](https://postfiles.pstatic.net/20150605_300/agapeuni_1433464127201lbPrr_PNG/20140827_233759.png?type=w966)

이제 motion 패키지를 설치합니다.

**sudo apt-get install motion**

​

![](https://postfiles.pstatic.net/20150605_253/agapeuni_14334641362572jERL_PNG/20140728_230311.png?type=w966)

화면 위로 뭔가 막 지나갑니다.

​

![](https://postfiles.pstatic.net/20150605_294/agapeuni_1433464213863e8ITz_PNG/20140728_230330.png?type=w966)

반가운 쉘 프롬프트가 나왔습니다.

​

![](https://postfiles.pstatic.net/20150605_210/agapeuni_1433464234231R0gFR_PNG/20140728_230459.png?type=w966)

/etc/motion/motion.conf 설정 파일을 수정합니다. 전체 라인이 600 넘어서 해당 라인을 찾기 어렵습니다. 

나노 에디터에서 제공하고 있는 검색 기능, Ctrl-W (Where is)로 검색어를 조회해서 찾으면 됩니다.

​

**sudo nano /etc/motion/motion.conf**

​

먼저 daemon은 on으로 수정합니다.

daemon off -> on

​

![](https://postfiles.pstatic.net/20150605_300/agapeuni_1433464243834sHfMl_PNG/20140728_230627.png?type=w966)

먼저 webcam_localhost는 off로 수정합니다.

webcam_localhost on -> off

​

![](https://postfiles.pstatic.net/20150605_127/agapeuni_14334642530551sVuE_PNG/20140728_230711.png?type=w966)

locate는 on으로 수정합니다.

locate off -> on

​

![](https://postfiles.pstatic.net/20150605_222/agapeuni_14334642621340OqSB_PNG/20140728_230754.png?type=w966)

참고 정보

width 320 -> 640

height 240 -> 480

framerate 2 -> 100

​

/etc/motion/motion.conf 파일 수정을 마치고서 /etc/default/motion 파일도 수정합니다. 

​

**$ sudo nano /etc/default/motion**

​

start_motion_daemon를 yes로 변경합니다.

start_motion_daemon no -> yes

​

![](https://postfiles.pstatic.net/20150605_96/agapeuni_1433464270299quDyO_PNG/20140728_230900.png?type=w966)

드디어 설정을 마쳤습니다. mothon 서비스를 시작합니다.

**sudo service motion start**

​

아래는 참고

**sudo service motion restart**

**sudo service motion stop**

​

![](https://postfiles.pstatic.net/20150605_251/agapeuni_1433464279119HQRLo_PNG/20140728_230920.png?type=w966)

브라우저에서 <http://192.168.0.5:8081> 주소로 접속합니다. 

IE에서는 잘 표시되지 않는데 파이어폭스에서는 아주 잘 표시됩니다.

​

![](https://postfiles.pstatic.net/20150605_286/agapeuni_1433464288809BfcGQ_PNG/20140728_231826.png?type=w966)

아래는 캠에 반응하는 motion 을 잡아줍니다. 

화면에서 무언가 움직이면 그 움직임만큼 사각형 영역으로 잡아줍니다.

​

![](https://postfiles.pstatic.net/MjAyNjA2MTNfMzIg/MDAxNzgxMzU2NjAzODc1.fAX_0tIPR1-GAHtWczM5yTlyghR6x3M7qQ-QhqShT7og.NPR-4df8XxBWfzrlqWcI4XaUxjj8ethbDK0VV3XOeKMg.PNG/%EC%A3%BC%ED%95%9C%EA%B8%B8.png?type=w966)
