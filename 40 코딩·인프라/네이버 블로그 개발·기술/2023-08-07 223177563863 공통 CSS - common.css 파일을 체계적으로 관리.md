웹 프로젝트를 진행하게 되면 CSS 파일의 내용이 점점 증가한다. CSS 파일을 기능 및 모듈에 따라 분리하면 유지 보수 및 재사용성을 높일 수 있다. 유사한 스타일을 동일한 클래스로 모듈화하여 재사용할 수 있도록 한다. 그리고 레이아웃과 스타일을 분리하여 각각의 역할을 분명하게 한다. 레이아웃을 담당하는 CSS 파일은 구조와 위치에 관한 스타일을 포함하고, 스타일 파일은 디자인과 관련된 스타일을 포함한다.

​

CSS 파일 안에서 모듈의 순서를 정의하여 우선순위를 부여합니다. 주로 기본 스타일, 레이아웃, 모듈 스타일, 미디어 쿼리 등 순서로 정리하는 것이 일반적이다. 불필요한 선택자 사용을 피하고, CSS 속성 중복을 최소화하며, 불필요한 중첩을 피하여 CSS 파일의 용량과 렌더링 성능을 개선한다.

이렇게 CSS 파일을 기능 또는 요소에 따라 분류하면 코드를 구조적으로 관리할 수 있고, 향후 유지 보수나 스타일 추가 시에도 보다 편리하게 작업할 수 있다. 또한 주석을 추가하여 각 섹션의 역할을 설명하는 것도 도움이 될 수 있다.

/* 1. BLOCK Elements */ .container { } .header { } .section { } /* 2. TABLE Elements */ .table { } .tr { } .td { } /* 3. INLINE Elements */ .link { } .text { } /* 4. LIST Elements */ ul { } ol { } li { } /* 5. FORM Elements */ .form { } .input { } .button { } /* 6. ETC */ /* ... */
