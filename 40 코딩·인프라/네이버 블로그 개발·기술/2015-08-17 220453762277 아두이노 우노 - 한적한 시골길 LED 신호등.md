# 2015-08-17 220453762277 아두이노 우노 - 한적한 시골길 LED 신호등

- 게시일: 2015. 8. 17. 22:00

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMjg1/MDAxNzU4NDMwNDI2OTE3.ASKVbw6-hxy9I8WRbCHs-vsC2z4C7Tsa9jW1vE-f_jcg.GvTUaRCZDwxUBBfnbGf-mtHEU_b-DkTkg2OnjMFk2Tog.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(2\).png?type=w80_blur)

​

이번에는 한적한 시골길을 가상으로 하여 LED 임시 신호등을 만들어 보겠습니다. 인도에서 사람이 건너기 위해 버튼을 누르면 지정한 시간 뒤에 신호가 녹색에서 노란색(주황대신) 점멸로 바뀌게 됩니다. 그리고 빨강이 되어 사람이 지나가기 위한 시간이 지나고 나서 다시 녹색 신호로 바뀌게 되는 실험입니다.

​

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다. 

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 빨, 노, 초 LED 각각 1개

  * 220 옴 저항 3개 

  * 버튼 1개 

  * 10K 옴 저항 1개

  * 점퍼선 4개

  * 연결 전선 1개 ​

![](https://postfiles.pstatic.net/20160506_292/agapeuni_1462521906559QbX2M_JPEG/20150817_211247.jpg?type=w80_blur)

​

브레드보드에 빨, 노, 초 LED와 버튼을 적당한 간격으로 꼽아둡니다. 

![](https://postfiles.pstatic.net/20160506_281/agapeuni_1462521906286Ua9rs_JPEG/20150817_211152.jpg?type=w80_blur)

LED에는 220 옴 저항과 GND 접지를 연결합니다. 

버튼의 한쪽에는 10K 저항을 GND 접지와 연결하고 다른 쪽에는 연결 전선으로 Vcc 전원과 연결합니다. 

![](https://postfiles.pstatic.net/20160506_31/agapeuni_1462521906034GCnzc_JPEG/20150817_211126.jpg?type=w966)

​

**아두이노 우노**(Arduino UNO)의 2번과 4,5,6번 핀에 점퍼선을 연결합니다. 

![](https://postfiles.pstatic.net/20160506_152/agapeuni_1462521905440fzjIH_JPEG/20150817_211035.jpg?type=w80_blur)

**아두이노 우노**(Arduino UNO)의 2번에 연결한 점퍼선을 버튼의 10K 옴 저항의 위쪽에 연결합니다. 

![](https://postfiles.pstatic.net/20160506_82/agapeuni_1462521905777gAtg5_JPEG/20150817_211120.jpg?type=w80_blur)

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/1.png)

**아두이노 우노**(Arduino UNO)의 4,5,6번 핀에 연결한 점퍼선을 각각의 LED의 애노드(+)에 연결합니다.

![](https://postfiles.pstatic.net/20160506_219/agapeuni_14625219049510IyTQ_JPEG/20150817_211000.jpg?type=w80_blur)

**▣ 소스코드 : button_led_traffic.ino**

delayGreen을 20초로 설정하는 것이 적당한데 실험을 위해서 5초로 설정하였습니다. ​

int LED_RED = 6; int LED_YELLOW = 5; int LED_GREEN = 4; int BUTTON = 2; int btnState = 0; int prevState = 0; int delayBlink = 500; int delayGreen = 5000; void setup() { pinMode(LED_RED, OUTPUT); pinMode(LED_YELLOW, OUTPUT); pinMode(LED_GREEN, OUTPUT); pinMode(BUTTON, INPUT); } void loop() { setLights(LOW, LOW, HIGH); btnState = digitalRead(BUTTON); if (btnState != prevState) { if (btnState == HIGH) { delay(delayGreen); for (int i = 0; i < 4; i++) { setLights(LOW, HIGH, LOW); delay(delayBlink); setLights(LOW, LOW, LOW); delay(delayBlink); } setLights(HIGH, LOW, LOW); delay(delayGreen); } prevState = btnState; } delay(50); } void setLights(int red, int yellow, int green) { digitalWrite(LED_RED, red); digitalWrite(LED_YELLOW, yellow); digitalWrite(LED_GREEN, green); }
