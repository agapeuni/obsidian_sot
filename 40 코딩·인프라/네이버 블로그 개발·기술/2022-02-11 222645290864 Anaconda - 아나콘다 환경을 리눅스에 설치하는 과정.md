![](https://postfiles.pstatic.net/MjAyNTA0MTJfMjc3/MDAxNzQ0NDQ1OTI0NDQ2.M-JpWQu45E7znDWKkm2PphpxcQN_nf_xOkg2qCkmBw0g.AByuOZOQLqezbxRXyEGQr5riKfpA5UsO0YrLSTIvKUog.PNG/%EC%95%84%EB%82%98%EC%BD%98%EB%8B%A4-001_\(1\).png?type=w80_blur)

​

현재 진행하고 있는 프로젝트에서 아나콘다를 사용하고 있다. 집에서도 동일한 환경을 구축하기 위해 리눅스를 설치하고 그 위에 아나콘다를 설치하려고 한다. 윈도에 비해서 뭔가 설정해야 하는 것들이 있어 몇가지 정리해 본다.

​

1\. yum update

리눅스를 기동하고 터미널에서 yum update를 하려고 하는데 superuser 권한이 필요하다고 메시지가 나온다.

Error: This command has to be run with superuser privileges (under the root user on most systems).

​

그래서 sudo yum update를 입력했는데 sudoers 파일에 pi 계정이 없다고 한다.

pi is not in the sudoers file. This incident will be reported.​

​

2\. sudo 명령

sudo 명령을 입력할 수 있도록 아래와 같이 변경을 한다.

**$ nano /etc/sudoers**

![](https://postfiles.pstatic.net/MjAyMjAyMTFfMjcy/MDAxNjQ0NTg5MzQwMTg5.AVdwuHQeYMWm4urzhyKpGV2VRiPhhMbGjCF2_vMdW8Ag.z8dC2dSnWrPhXA22n8JE9isxzhElM7_lmrfHqENiKlwg.PNG.agapeuni/1.png?type=w80_blur)

​

sodoers 파일을 수정하고 나서 명령을 실행하니 정상적으로 수행된다.

**$ sudo yum update**

![](https://postfiles.pstatic.net/MjAyMjAyMTFfNzUg/MDAxNjQ0NTg5MzQ4NTcx.j6qZ_tCfFc-XWmv6DkpdzoEVrezyQZ3GIorgPkfgOLMg.D-r-sAZ8Od8-PTLNICV4H0FdZPzwHFNFneqgfdH3cr4g.PNG.agapeuni/2.png?type=w80_blur)

4\. 아나콘다 다운로드

리눅스 터미널에서 아나콘다 설치파일을 받기 위해 다음의 주소에 접속한다.

<https://repo.anaconda.com/archive/>

​

아래의 그림처럼 설치하고자 하는 "Anaconda3-2020.11-Linux-x86_64.sh" 링크 위에서 마우스 우클릭으로 링크 주소를 복사한다.

![](https://postfiles.pstatic.net/MjAyMjAyMTFfMTc0/MDAxNjQ0NTg5MzYwOTg5.mnVx78AiIxMg87tHe1n6HaONZkJR6mtX0deR2jgKjSkg.XFhXv0d_-iGjOEL8hSz508Sj80YGZBpsfU2f0VksDwog.PNG.agapeuni/4.png?type=w80_blur)

​

설치 파일을 받기위에 wget 명령어 뒤에 복사한 링크 주소를 붙여넣고 실행한다. 그러면 리눅스용 아나콘다 인스톨러를 다운받는다.

**$ wget**[**https://repo.anaconda.com/archive/Anaconda3-2020.11-Linux-x86_64.sh**](https://repo.anaconda.com/archive/Anaconda3-2020.11-Linux-x86_64.sh)

![](https://postfiles.pstatic.net/MjAyMjAyMTFfNTIg/MDAxNjQ0NTg5MzcwNzM5.wuxDoOsdqOdFzkf7n50kKJqbK13Xc8R3UA1VMNFggfIg.qoFUkuKdMILyIb8R5p0dHLkgh-b8YJ0rCfBFOAFCOXwg.PNG.agapeuni/5.png?type=w80_blur)

​

5\. 아나콘다 설치

다음의 명령으로 아나콘다 인스톨러를 실행하고 아래의 화면이 표시되면 "ENTER"를 입력한다.

$ sh Anaconda3-2020.11-Linux-x86_64.sh

![](https://postfiles.pstatic.net/MjAyMjAyMTFfMjI5/MDAxNjQ0NTg5Mzc3MTQy.zOpHSE8Ncy2qMsRgO2vO6Vkt2vej_qYihcMrxPHs-Z0g.DXyxTpGphFl2u3vl--ULzYD87M7EHaMkS4W5RPxhSIwg.PNG.agapeuni/6.png?type=w80_blur)

​

라이센스가 표시되면 마지막 페이지까지 모두 읽고 "yes"를 입력한다.

![](https://postfiles.pstatic.net/MjAyMjAyMTFfMTAz/MDAxNjQ0NTg5MzgwNjI5.9zeZJ0cqOA4AJZZhDGP0Cl9lCsb6Switp54ULbGHpu4g.gbfur3CZb99CNqpHi9k_S6LPVXoZinR6aDvEGktDeqgg.PNG.agapeuni/7.png?type=w80_blur)

​

설치경로는 표시되는 기본값으로 하려면 "ENTER"를 입력하고 다른 위치에 설치하고자 하면 전체 경로를 입력한다.

/home/pi/anaconda3

![](https://postfiles.pstatic.net/MjAyMjAyMTFfMjE2/MDAxNjQ0NTg5Mzg1OTM3.k_hyvYXq_zt9HPVq5FENwTIvHB-Zp97X-9ek8EPWBWUg.08Zw5m4jsDybdZ2-zySgd8OdVP7z1LMjTl1ScvBNb2Ag.PNG.agapeuni/8.png?type=w80_blur)

​

설치가 완료되면 Anaconda 초기설정을 물어보는데 터미널 실행시 conda 환경으로 시작하려면 "yes"를 입력한다.

![](https://postfiles.pstatic.net/MjAyMjAyMTFfMTI4/MDAxNjQ0NTg5Mzg5OTAx.Y5fIvag9exbJKr7saFwF9ws2xxQ1pViBUn3-4gulhcQg.AUxX3fvlsY3_im4Rfi97PKWcEWA-wN4NdOVHZvmDWbwg.PNG.agapeuni/9.png?type=w80_blur)

​

리눅스에 아나콘다 설치를 완료하고 다시 터미널을 실행하니 (base) 가상환경으로 conda가 실행되었다.

**$ conda -V**

**$ conda info**
