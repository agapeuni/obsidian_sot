2\. Tab (jQuery UI)

Tab은 페이지 공간을 절약하여 화면에 많은 정보를 표시할 수 있다. Tab은 표시하려는 정보와 화면 기능을 논리적으로 구분할 수 있다.

​

파일 : jquery_tab.html

3\. UI Layout (jQuery Plugin)

"extJS border-layout" 에서 영감을 얻어 구현한 jQuery 플러그인이다. 웹 애플리케이션을 구현할 때 원하는 UI 레이아웃을 쉽게 구현할 수 있다. north(상단), west(좌측), center(중앙), east(우측), south(하단) 영역으로 구분한다.

​

파일 : jquery_layout.html

<!DOCTYPE html> <html> <head> <title>Layout Example</title> <script type="text/javascript" src="http://layout.jquery-dev.com/lib/js/jquery-latest.js"></script> <script type="text/javascript" src="http://layout.jquery-dev.com/lib/js/jquery.layout-latest.js"></script> <script type="text/javascript"> $(document).ready(function () { $('body').layout({ applyDemoStyles: true }); }); </script> </head> <body> <div class="ui-layout-center">중앙</div> <div class="ui-layout-north">상단</div> <div class="ui-layout-south">하단</div> <div class="ui-layout-east">좌측</div> <div class="ui-layout-west">우측</div> </body> </html>
