웹페이지를 만들다 보면 좌측 서브메뉴를 동적으로 펼치고 접는 기능이 필요할 때가 많다. 메뉴 항목이 여러 개로 나뉘는 페이지에서는 모든 내용을 한 번에 보여 주기보다, 사용자가 필요한 항목을 선택했을 때만 하위 메뉴가 열리도록 구성하는 방식이 더 효율적이다. 화면은 깔끔해지고, 원하는 메뉴를 찾기도 쉬워진다.

![](https://postfiles.pstatic.net/MjAyNjA2MTNfMjg3/MDAxNzgxMzU3MjU1Mjgy.y-56e6IUOSfZQCKhhWL5Hcv1dbtsAtYSf88A3erKZy8g.wvEbkSmw2KBs5YjacJuI2IlOcm32V1RW1hKLUVT32Isg.PNG/image.png?type=w80_blur)

​

서브메뉴 기능은 단순한 장식이 아니라 페이지 구조를 정리하는 기본적인 웹페이지 메뉴 구현 방법이다. 관리자 화면이나 게시판 관리 화면처럼 좌측에 여러 메뉴가 배치되는 경우, 하위 항목을 모두 펼쳐 두면 화면이 복잡해 보일 수 있다. 반대로 필요한 메뉴만 열리게 하면 전체 구조를 한눈에 파악하기 쉽다.

![](https://postfiles.pstatic.net/MjAyNjA2MTNfMjU1/MDAxNzgxMzU3MjY2Mjcw.JEQajtkFRCY6BmaLfzDZbmadJAtKymYrJZoF_YJ_7GEg.LudI-eX8X24TCead8D57xeuvly5jZSP9Z8HZcAcrMx0g.PNG/image.png?type=w80_blur)

​

동적 서브메뉴의 핵심은 펼침과 접힘이다. 사용자가 상위 메뉴를 클릭하면 숨겨져 있던 하위 메뉴가 나타나고, 다시 클릭하면 접힌다. 이때 중요한 것은 메뉴의 현재 상태를 확인한 뒤 화면 표시 여부를 바꾸는 것이다. 이런 방식으로 정적인 HTML 페이지에도 간단한 상호작용을 추가할 수 있다.

![](https://postfiles.pstatic.net/MjAyNjA2MTNfNTQg/MDAxNzgxMzU3MjczMTM3.Z4lYeEjjxDZTQ37K9kNrUyiEJ8ZlkPo5QKa9ZgneNbkg.qXfnYhg98kA2WKMMoO17T6ZcNol1jyKyyKA72x_hQHEg.PNG/image.png?type=w80_blur)

​

좌측 서브메뉴를 만들 때는 메뉴의 계층 구조도 중요하다. 상위 메뉴는 기준점이 되고, 하위 메뉴는 실제 이동할 페이지나 세부 기능으로 연결된다. 이 구조가 명확해야 사용자는 어떤 메뉴를 열었는지 쉽게 이해할 수 있다.
