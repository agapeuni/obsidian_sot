**1\. 개요**

iBATIS에서 SQL로깅은 한 줄로 표현되기 때문에 디버깅이 불편하다. 이를 해결하고자 몇 가지 알아봤지만 소스를 직접 수정하는 수밖에 없었다. 그래서 소스코드를 받아 수정하여 SQL 로그 출력을 보기 편하게 수정한다. 참고로 com.ibatis.common.jdbc.logging.* 패키지에 JDBC 관련 로깅 java들이 있다.

![](https://postfiles.pstatic.net/MjAyNDAxMjBfNDQg/MDAxNzA1NzIwMzA5Mjk4.sUIdV8WbAQooXmCaVOdUNQvR77M-OgmDhrNWmzA85aEg.sa8B2C-wC5yelVF77TL44V34Ci37J4HuVPSH8niYub4g.PNG.agapeuni/img1.daumcdn.png?type=w80_blur)

​

**2\. 소스 수정 리스트**

  * com.ibatis.common.jdbc.logging.ConnectionLogProxy.java

  * com.ibatis.common.jdbc.logging.PreparedStatementLogProxy.java

  * com.ibatis.common.jdbc.logging.StatementLogProxy.java

  * com.ibatis.sqlmap.engine.mapping.sql.SqlText.java

  * com.ibatis.sqlmap.engine.mapping.sql.stat.StaticSql.java

​

1) com.ibatis.common.jdbc.logging.ConnectionLogProxy.java

주석 처리 후 removeBreakingWhitespace 함수를 제거한다. removeBreakingWhitespace 함수가 '\n'를 ' '로 변환한다. 

// log.debug("{conn-" + id + "} Preparing Statement: " + removeBreakingWhitespace((String) params[0])); log.debug("{conn-" + id + "} Preparing Statement: " + ((String) params[0])); ... // log.debug("{conn-" + id + "} Preparing Call: " + removeBreakingWhitespace((String) params[0])); log.debug("{conn-" + id + "} Preparing Call: " + ((String) params[0]));

​

2) com.ibatis.common.jdbc.logging.PreparedStatementLogProxy.java

마찬가지로 removeBreakingWhitespace 함수를 제거한다. 

// log.debug("{pstm-" + id + "} Executing Statement: " + removeBreakingWhitespace(sql)); log.debug("{pstm-" + id + "} Executing Statement: " + (sql));

​

3) com.ibatis.common.jdbc.logging.StatementLogProxy.java

removeBreakingWhitespace 함수를 제거한다.

// log.debug("{stmt-" + id + "} Statement: " + removeBreakingWhitespace((String) params[0])); log.debug("{stmt-" + id + "} Statement: " + ((String) params[0]));

4) com.ibatis.sqlmap.engine.mapping.sql.SqlText.java 

replace 하는 부분을 주석 처리해 놓고 this.text = text;를 추가한다.

public void setText(String text) { // this.text = text.replace('\r', ' ').replace('\n', ' '); this.text = text; this.isWhiteSpace = text.trim().length() == 0; } 

​

5) com.ibatis.sqlmap.engine.mapping.sql.stat.StaticSql.java

마찬가지로 replace 하는 부분을 주석 처리하고 this.sqlStatement = sqlStatement;를 추가시킨다.

public StaticSql(String sqlStatement) { //this.sqlStatement = sqlStatement.replace('\r', ' ').replace('\n', ' '); this.sqlStatement = sqlStatement; }

​

**3\. 수동으로 컴파일 후 jar 압축하기**

1\. 다운로드한 ibatis-2.3.0.677을 압축을 푼다.

2\. C:\ibatis-2.3.0.677\src\ibatis-src.zip의 압축을 푼다.

3\. C:\ibatis-2.3.0.677\src\ 아래에서 소스 수정 리스트에 있는 코드를 찾아 수정한다.

4\. C:\ibatis-2.3.0.677\src\의 수정된 5개의 자바 소스를 C:\ibatis-2.3.0.677\lib\로 복사한다.

5\. C:\ibatis-2.3.0.677\lib\ibatis-2.3.0.677.jar 압축을 푼다.

6\. cmd 창을 열어 C:\ibatis-2.3.0.677\ 이동 후 컴파일한다.

> javac -classpath "." -d ./ *.java

7\. jar 압축한다.

> jar cvf ibatis-2.3.0.677.jar ./
