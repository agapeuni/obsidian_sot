터미널을 하나 실행하고서 필요한 패키지를 설치합니다. 

**$ sudo apt-get install python-opencv**

**$ sudo apt-get install python-scipy**

**$ sudo apt-get install python-numpy**

**$ sudo apt-get install python-pip**

![](https://postfiles.pstatic.net/20150605_127/agapeuni_1433465659354aKthT_PNG/20150601_021642.png?type=w80_blur)

​

패키지가 모두 성공적으로 설치가 되었습니다.

![](https://postfiles.pstatic.net/20150605_191/agapeuni_14334656685851TqU3_PNG/20150601_022704.png?type=w80_blur)

​

아래의 명령으로 SimpleCV 패키지를 설치합니다. 

원격 데스크톱에서 실행하여도 되는데 키가 잘 입력이 안되고 명령어가 길어서 타이핑하기도 번거로워 SSH로 접속하였습니다.

**$ sudo pip install**[**https://github.com/ingenuitas/SimpleCV/zipball/master**](https://github.com/ingenuitas/SimpleCV/zipball/master)

![](https://postfiles.pstatic.net/20150605_293/agapeuni_1433465676858iNL1C_PNG/20150601_022504.png?type=w80_blur)

**​**

**1\. 소스코드 (image.py)**

SimpleCV 패키지로부터 Image와 Display를 import 합니다.

새로운 Display 객체를 하나 만들고 "rpi.jpg" 이름의 이미지 객체로 메모리에 로드합니다.

그러고 나서 이미지를 Display에 표시합니다.

![](https://postfiles.pstatic.net/20150605_87/agapeuni_1433465684763U1Pmd_PNG/20150601_031908.png?type=w80_blur)

​

파일을 저장하고 실행하면 아래와 같이 이미지가 새 창에 표시가 됩니다.

![](https://postfiles.pstatic.net/20150605_157/agapeuni_1433465692962lO658_PNG/20150601_032042.png?type=w80_blur)

**​**

**2\. 소스코드 (imagetext.py)**

SimpleCV 패키지로부터 Image와 Display, DrawingLayer, Color를 import 합니다. 새로운 Display 객체를 하나 만들고 "rpi.jpg" 이름의 이미지 객체로 메모리에 로드합니다. 이미지와 같은 크기로 DrawingLayer를 생성합니다. (50, 20) ~ (450, 80) 크기의 직사각형을 하나 만듭니다. 텍스트가 잘 보이기 위한 직사각형의 배경입니다. 폰트 사이즈를 100으로 설정하고 "Raspberry PI"라는 문자열을 (50, 20)의 위치에서 빨간색으로 표시합니다. 이제 DrawingLayer 객체를 이미지에 추가하고서 추가된 레이어를 합칩니다.

![](https://postfiles.pstatic.net/20150605_300/agapeuni_1433465701072vG6tv_PNG/20150601_032316.png?type=w80_blur)

​

파일을 저장하고 실행하면 아래와 같이 이미지와 텍스트가 새 창에 표시가 됩니다.
