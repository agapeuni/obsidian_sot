SPI (Serial Peripheral Interface) 인터페이스에 사용되는 핀으로 

10번핀은 CS/SHDN, 11번핀은 D IN, 12번핀은 D OUT, 13번핀은 CLK이다.

10번핀은 CE0에 연결, 11번핀은 MOSI에 연결, 12번핀은 MISO에 연결, 13번핀은 CLK에 연결한다.

![](https://postfiles.pstatic.net/MjAyMDExMjZfMjM1/MDAxNjA2MzIxNTA0NjQ1.w06UvJMqAvnXs9eUHppv3LF_zM789jeB_keQsdf-Y8cg.2Y7JuvX1tHKTTDK2AOuCKYVq73DAOImcpcX3Vv4LQR8g.JPEG.agapeuni/SE-dd5e2984-64d9-4274-b6ae-63550f5dcd9a.jpg?type=w80_blur)

**소스 코드 :****MCP3208_TMP_LED3.py (작성중)**

import spidev import time spi = spidev.SpiDev() spi.open(0, 0) def ReadAdc(channel): if channel > 7 or channel < 0: return -1 adc = spi.xfer2([1, (8 + channel) << 4, 0]) data = ((adc[1] & 3) << 8) + adc[2] return data def ConvertVolt(data, places): volt = (data * 3.3) / float(1023) volt = round(volt, places) return volt def ConvertTMP36(data, places): temp = ((data * 330) / float(1023)) - 50 temp = round(temp, places) return temp temp_channel = 0 while True: temp_level = ReadAdc(temp_channel) temp_volt = ConvertVolt(temp_level, 2) temp = ConvertTMP36(temp_level, 2) print("TMP36 : Data {} ({}V) {} C".format(temp_level, temp_volt, temp)) time.sleep(1)
