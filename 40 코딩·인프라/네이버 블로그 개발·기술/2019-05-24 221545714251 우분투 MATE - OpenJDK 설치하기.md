# 2019-05-24 221545714251 우분투 MATE - OpenJDK 설치하기

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221545714251&categoryNo=982
- 게시일: 2019. 5. 24. 17:28

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MDdfMTk3/MDAxNzQ0MDI4OTYyMzcy.TdTJYj0DGohU1Ez4p8PTzqbZNCzf9_GTZVq8aWjopjUg.pN8BR32YyRTsFAXcd1KgXV5ECe2YSJP3rcBpPWnKXWkg.PNG/Pi-Software-001_\(13\).png?type=w80_blur)

​

라즈베리 파이에 운영체제로 우분투 MATE를 설치하였고 여기에 자바 웹 프로젝트를 생성하기 위해 Java를 설치해 보려고 합니다.

라즈베리 파이에 XRDP를 설치하여 윈도우에서 "원격 데스크톱 연결"로 접속하였습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTkx/MDAxNTU4Njg1NDIzNzQw.aDIWX7sXjef1Op1e4BexIBcYXN032w9t5Npwnfsi6Tgg.5YU64muGOTTfvXV3PCSrzdpbP1T8PhNZX5iHWZFrIbgg.PNG.agapeuni/20190524_144225.png?type=w80_blur)

​

다음의 명령을 사용하여 디스크 용량을 확인해 보려고 합니다. 그냥 습관적으로 입력해 보는 명령어입니다.

**$ df - h**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTA1/MDAxNTU4Njg1NDI0NzQ2.GnzpcO3_Sk6FVB3g9gVvDD56MamVTB2ZzJ7cJW5e6Vcg.l2mEhpu5rlhfjnHQVMOisd9EmE19OQjcIO1x-5IHAfgg.PNG.agapeuni/20190524_152505.png?type=w80_blur)

다음의 명령어로 소프트웨어 업그레이드를 수행합니다.

**$ sudo apt-get update**

**$ sudo apt-get upgrade**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjI5/MDAxNTU4Njg1NDI1NzEx.R7H3-03F8mSxZxUVYvnT5z19dy5f5jE9SeAzLBziP80g.-DEyKTpfPdsGNK93exk-AEb_-FchSRC8ByoHqxsXFqAg.PNG.agapeuni/20190524_152838.png?type=w80_blur)

​

자바를 설치하기 위해 다음의 명령어를 수행합니다. 설치를 하려면 "Y"를 입력하고 엔터(Enter)키를 누르면 계속 진행됩니다.

**$ sudo apt-get install openjdk-8-jdk**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjcy/MDAxNTU4Njg1NDI2NDAx.QrgSx2yb1fDLro-BQMfQckI1MpEOKLsoWQK1pYOEw7Ug.lMa-T79DAdXALUvX8HCI1YnCo19wrJU1YLAjmZ6hEpgg.PNG.agapeuni/20190524_154748.png?type=w80_blur)

​

아래의 화면처럼 설치가 진행되고.... 잠시 티타임을 하고 나면 설치가 완료되어 있습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjI4/MDAxNTU4Njg1NDI3MjQ0.1RBCgTwqEooc-Cf-e1iOt0a4DhvinfwLegqYfMGe1ysg.mKNi2B512o5XKmWn-zmtc7OnPHaTXWHCEjK_xbGdjm8g.PNG.agapeuni/20190524_154959.png?type=w80_blur)

​

Java 환경설정을 위해 아래의 명령어로 프로파일을 편집합니다.

**$ sudo nano /etc/profile**

​

그림 nano 에디터에 설정정보가 로드되는데 파일의 맨 아래로 가서 다음의 설정정보를 입력합니다.

**export JAVA_HOME=/usr/lib/jvm/java-8-openjdk-amd64**

**export PATH=$JAVA_HOME/bin:$PATH**

**export CLASS_PATH=$JAVA_HOME/lib:$CLASS_PATH**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTE1/MDAxNTU4Njg1NDI3OTY0.iMq0xnRr8XH_rFACrOC268_eUPqEH03zk-klrjeFTqIg.DOPnJRiig-q9zL2Xpg54PMcdwQP4JvzTwM3tFHo8B70g.PNG.agapeuni/20190524_155753.png?type=w80_blur)

​

java --version을 입력하면 설치된 Java 버전을 확인할 수 있습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTU5/MDAxNTU4Njg1NDI4NjY3.vSG6STHSLN03ORI6Wv-y6Vos2vAYJZZnOIKPxpHxZEQg.OwyP2yu93GAldYya8WJB_Zc2pXBhBO9_WLtq52kiR0wg.PNG.agapeuni/20190524_155757.png?type=w80_blur)
