이번에는 랜덤 LED 주사위를 구현해 보는 실험입니다. 버튼을 클릭하면 주사위가 무작위로 표시되는데 처음에는 빠르게 표시되다가 점점 느리게 표시되다가 멈추게 됩니다. 랜덤으로 표시되다가 멈추는 것 같지만 사실 미리 수를 담아두고 있다가 나중에 멈추게 되는 시점에 그 수를 표시합니다. 참고로 아래의 포스터는 예전에 구현한 LED 주사위입니다. 클릭하면 1에서 6까지 주사위 모양을 표시하는 실험입니다.

**▣ 소스코드 : led_dice2.ino**

delayGreen을 20초로 설정하는 것이 적당한데 실험을 위해서 5초로 설정하였습니다.

int buttonPin = 2; int dicePins[7] = { 3, 4, 5, 6, 7, 8, 9 }; int hintPins[3] = { 12, 11, 10 }; int hint = 0; int buttonState = 0; int prevState = 0; int diceNums[7][7] = { { 0, 0, 0, 1, 0, 0, 0 }, // 1 { 0, 1, 0, 0, 0, 1, 0 }, // 2 { 0, 0, 1, 1, 1, 0, 0 }, // 3 { 1, 0, 1, 0, 1, 0, 1 }, // 4 { 1, 0, 1, 1, 1, 0, 1 }, // 5 { 1, 1, 1, 0, 1, 1, 1 }, // 6 { 0, 0, 0, 0, 0, 0, 0 } // 0 }; int hintNums[7][3] = { { 0, 0, 1 }, // 1 { 0, 1, 0 }, // 2 { 0, 1, 1 }, // 3 { 1, 0, 0 }, // 4 { 1, 0, 1 }, // 5 { 1, 1, 0 }, // 6 { 0, 0, 0 } // 0 }; void setup() { randomSeed(analogRead(0)); pinMode(buttonPin, INPUT); for (int i = 0; i < 7; i++) { pinMode(dicePins[i], OUTPUT); digitalWrite(dicePins[i], LOW); } for (int i = 0; i < 3; i++) { pinMode(hintPins[i], OUTPUT); } } void loop() { buttonState = digitalRead(buttonPin); if (buttonState != prevState && buttonState == HIGH) { hint = random(1, 7); showHint(hint); for (int i = 0; i < 20; i++) { showDice(random(1, 7)); delay(20 * i); clearDice(); } showDice(hint); delay(100); } prevState = buttonState; } ​ void clearDice() { for (int i = 0; i < 7; i++) { digitalWrite(dicePins[i], diceNums[6][i]); } } void showDice(int dice) { for (int i = 0; i < 7; i++) { digitalWrite(dicePins[i], diceNums[dice][i]); } } void showHint(int hint) { for (int i = 0; i < 3; i++) { digitalWrite(hintPins[i], hintNums[hint][i]); } }

아래는 위의 코드로 실행한 동영상입니다. 주사위가 보기 편하게 보드를 세로로 놓고 찍었습니다.

처음에는 주사위가 2가 나오고 그다음에는 5가 나오고 그리고 꽝이 한번 나오고 마지막으로 4가 나옵니다.
