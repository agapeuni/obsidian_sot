# 2025-05-03 223854481253 PL SQL - 중첩 테이블(Nested Table)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223854481253&categoryNo=982
- 게시일: 2025. 5. 3. 21:30

## 본문

![](https://postfiles.pstatic.net/MjAyNTA1MDNfMjkg/MDAxNzQ2MjY0NzkwOTUx.fzcGohHlzQTQC_AbJmaiR0tBeJ8lOEJ2TLeGGaUNQDAg.IG2WVizkxOW3dERiVd4hzhzSu9nzZqpZUVrO4JOoX2sg.PNG/PL_SQL-001_\(12\).png?type=w80_blur)

​

Oracle PL/SQL에서는 여러 데이터를 하나의 집합으로 다루기 위한 다양한 컬렉션(Collection) 유형을 제공하고 있으며, 그 중 하나가 중첩 테이블(Nested Table)이다. 중첩 테이블은 테이블처럼 유연하게 크기를 조정할 수 있는 컬렉션 형태로, 특히 정렬되지 않은 항목들을 유동적으로 저장하고 처리하는 데 유용하게 사용된다.

​

중첩 테이블은 PL/SQL에서 유연하고 확장 가능한 데이터 저장 구조로, 메모리 기반의 배열을 넘어서 **SQL과의 연동성까지 갖춘 컬렉션 타입** 이다. 다른 컬렉션과 달리 인덱스를 연속적으로 유지할 필요가 없고, 동적으로 요소를 추가·삭제할 수 있어 복잡한 데이터 로직 처리에 유리하다.

​

특히 업무 로직 내에서 테이블 데이터를 임시로 처리하거나, 반복 계산, 조건 분기 등의 목적에 사용할 경우 코드의 효율성과 가독성을 크게 향상시킬 수 있다. EXTEND, DELETE, TRIM, COUNT, EXISTS와 같은 컬렉션 메소드들을 적절히 조합하여 더욱 유연한 로직을 구성해보기를 권장한다.

​

중첩 테이블의 개념, 선언 방법, 초기화 및 확장, 삭제 메소드에 이르기까지 실제 활용 중심으로 알아보자.

**​**

**1\. 중첩 테이블이란?**

중첩 테이블(Nested Table)은 PL/SQL 컬렉션 중 하나로, **요소가 정렬되어 있지 않으며 인덱스가 불연속적일 수 있는** 점이 특징이다. 이는 일반적인 배열(Index-by Table)과는 다르게 동작한다.

​

주요 특성은 다음과 같다.

  * **요소는 순서대로 정렬되지 않는다.**

  * **특정 데이터형을 제한하지 않으며** , 스칼라형, 레코드형, 객체형 등 다양한 유형으로 선언할 수 있다.

  * **인덱스 범위는 -2,147,483,647 ~ 2,147,483,647** 로 매우 넓다.

  * **INDEX BY 절이 존재하지 않으면 중첩 테이블로 간주된다.**

  * 데이터를 추가하기 위해서는 반드시 **생성자(Constructor)**를 사용하여 초기화해야 한다.

**​**

**​**

**2\. 중첩 테이블의 선언 및 초기화**

중첩 테이블은 사용자 정의 TYPE을 통해 먼저 선언한 후, 해당 타입을 변수로 지정하여 사용한다.

**선언 예시**

TYPE dept_table IS TABLE OF department%ROWTYPE; depts dept_table; -- 중첩 테이블 변수 선언 

이 예제에서는 department 테이블의 레코드 구조를 기반으로 중첩 테이블 타입을 정의하고, 이를 통해 depts라는 변수를 선언하였다.

**​**

초기화는 생성자 함수를 통해 수행한다.

depts := dept_table(); -- 생성자 함수 호출 (빈 테이블 생성) 

※ dept_table(dept1, dept2) 형태로 항목을 넣으면 해당 값으로 초기화된 테이블을 생성할 수 있다.

**​**

**​**

**3\. 중첩 테이블에 요소 추가하기 – EXTEND 메소드**

중첩 테이블은 EXTEND 메소드를 사용하여 배열에 요소를 추가할 수 있다. 메모리는 자동으로 동적으로 할당되며, 기존 값을 복사하여 추가하는 방식도 제공된다.

​

**기본 사용**

depts.EXTEND; -- 항목 하나 추가

**복사 확장**

depts.EXTEND(5,1); -- 첫 번째 항목을 5번째 항목까지 복사 

이처럼 EXTEND(n, m)은 m번째 항목을 기준으로 n개를 복사하여 배열에 추가하는 방식으로 활용된다.

**​**

**​**

**4\. 중첩 테이블의 항목 삭제 – DELETE, TRIM 메소드**

**특정 인덱스 삭제**

depts.DELETE(10); -- 10번째 항목 삭제 

**마지막 항목부터 제거**

depts.TRIM(2); -- 마지막 2개 항목 제거 

DELETE는 지정한 항목만 제거하지만, TRIM은 뒤에서부터 순차적으로 제거하는 방식으로 동작한다.

**​**

**​**

**5\. 실용 예제: 중첩 테이블을 이용한 부서 정보 처리**

DECLARE CURSOR dept_cursor IS SELECT * FROM department ORDER BY dept_name; TYPE dept_table IS TABLE OF department%ROWTYPE; depts dept_table; idx PLS_INTEGER := 0; BEGIN depts := dept_table(); -- 빈 테이블로 초기화 FOR dept_rec IN dept_cursor LOOP idx := idx + 1; depts.EXTEND; depts(idx) := dept_rec; END LOOP; \-- 부서 목록 출력 FOR i IN 1 .. depts.COUNT LOOP IF depts.EXISTS(i) THEN DBMS_OUTPUT.PUT_LINE('부서명: ' || depts(i).dept_name); END IF; END LOOP; END; / 

이 예제는 실제 테이블에서 데이터를 읽어 중첩 테이블에 저장하고 출력하는 방식이다. 중첩 테이블은 SQL에서도 사용이 가능하므로, 이와 같이 **대용량 데이터를 처리하거나 반복적으로 가공하는 상황에서 매우 유용** 하게 사용된다.
