**1\. 개요**

사용자가 클릭하는 이벤트를 사용하여 Vue 메소드(이벤트 핸들러)를 호출해 보는 예제이다.

​

​

**2\. 이벤트 핸들러 정의**

v-on 디렉티브를 사용하여 메소드 이름을 입력한다. methods : { } 에서 메소드 이름에 해당하는 이벤트 핸들러를 정의한다.

<button v-on:click="메소드 이름">+1</button> <script> new Vue({ ...(생략)... methods: { 메소드 이름: function () { 실행 코드 }, }, }); </script>

​

**3\. 이벤트 핸들러 예제**

아래는 4개의 버튼을 만들로 클릭할 때 마다 count 값을 변경하는 코드이다.

<!DOCTYPE html> <html> <head> <meta charset="UTF-8" /> <title>Vue.js sample</title> <script src="https://cdn.jsdelivr.net/npm/vue@2.6.12/dist/vue.js"></script> </head> <body> <div id="app"> <h1>{{ count }}</h1> <button v-on:click="countDown(-10)">-10</button> <button v-on:click="countDown(-1)">-1</button> <button v-on:click="countUp(1)">+1</button> <button v-on:click="countUp(10)">+10</button> </div> <script> new Vue({ el: "#app", data: { count: 0, }, methods: { countDown: function (val) { this.count += val; }, countUp: function (val) { this.count += val; }, }, }); </script> </body> </html>

**실행 결과**

버튼을 누르면 메소드가 실행되고 count 값이 변경되어 화면에 표시된다.
