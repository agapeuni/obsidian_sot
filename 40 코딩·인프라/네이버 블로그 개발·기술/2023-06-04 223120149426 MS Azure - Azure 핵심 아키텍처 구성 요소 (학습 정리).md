​

Microsoft Azure란 무엇인가요?

Microsoft Azure는 Microsoft가 제공하는 클라우드 컴퓨팅 플랫폼 및 서비스다. Azure는 비즈니스 과제를 해결하도록 돕는 지속적으로 확장 중인 일련의 클라우드 서비스다. Azure를 통해 애플리케이션을 자유롭게 빌드, 관리 및 배포할 수 있다. Azure는 다양한 운영 체제, 프로그래밍 언어, 도구 및 프레임워크를 지원하며, 기업용 및 개인용으로 사용될 수 있다. 또한, Azure는 보안, 데이터 백업 및 복원, 비상 복구, 실시간 모니터링 등의 기능을 제공하여 안정성과 신뢰성을 강화한다.

​

Azure는 전 세계에 분산된 데이터 센터 네트워크를 기반으로 하는 인프라스트럭처 서비스 (IaaS), 플랫폼 서비스 (PaaS) 및 소프트웨어 서비스 (SaaS)를 제공한다. Azure를 사용하면 조직은 인터넷을 통해 서버, 스토리지, 데이터베이스, 네트워크, 분석, 인공지능, 머신러닝, 사물인터넷 (IoT) 등 다양한 기능과 서비스에 대한 액세스를 얻을 수 있다. 

​

Azure는 어떤 기능을 제공합니까?

  * 다양한 옵션으로 원하는 방식으로 원하는 위치에 빌드하고 배포

  * 온-프레미스, 클라우드, 에지 등 원하는 위치에서 원활한 하이브리드 운영

  * 신뢰할 수 있는 클라우드로 철저한 보안성을 확보

​

Azure로 무엇을 할 수 있나요?

Azure는 100여 개의 서비스를 제공한다.

Azure는 AI(인공 지능) 및 ML(기계 학습) 서비스를 제공한다.

Azure에서 실행되는 VM(가상 머신)으로 기존 앱을 마이그레이션 할 수 있다.

Azure는 동적으로 확장되는 스토리지 솔루션을 제공하여 대량의 데이터를 수용한다.

​

Azure 계정 시작

Azure 서비스를 만들고 사용하려면 Azure 구독이 필요하다.

Azure 구독을 만든 후에는 Azure 리소스를 만들 수 있다.

Azure 계정을 만든 후에는 추가 구독을 무료로 만들 수 있다. 

단일 Azure 계정을 사용하고 부서별 구독을 사용할 수 있다.

​

Azure 계정 만들기

1) Azure 체험 계정 : 12개월간 Azure 제품에 대한 무료 액세스. 무료로 제공되는 25개 이상의 제품에 대한 액세스.

2) Azure 체험 학생 계정 : 12개월 동안 특정 Azure 서비스에 비용 없이 액세스. 특정 소프트웨어 개발자 도구에 비용 없이 액세스.

​

Learn 샌드박스란 무엇인가요?

Azure 계정에 임시 구독을 만드는 샌드박스라는 기술을 사용한다.

Learn 샌드박스는 무료로 Azure 리소스를 만들고 테스트할 수 있다.

​

Azure 물리적 인프라

Azure의 물리적 인프라는 데이터 센터에서 시작한다. 

Azure는 전 세계에 데이터 센터를 보유하고 있습니다. 

데이터 센터는 전원 및 네트워킹 인프라를 갖춘 시설이다.

​

지역

지역이란 데이터 센터를 하나 이상 포함하고 있는 지리적 영역을 의미한다.

Azure는 각 지역의 리소스를 제어하여 워크로드의 적절한 균형을 유지한다.

​

가용성 영역

가용성 영역은 Azure 지역 내에서 물리적으로 분리된 하나 이상의 데이터 센터로 구성된다.

가용성 영역은 격리 경계로 설정되어 한 영역이 다운되어도 다른 영역은 계속 작동한다.

​

앱에서 가용성 영역 사용

Azure는 가용성 영역을 통해 앱의 가용성을 높일 수 있다.

인프라를 호스트 할 때 중복된 하드웨어 환경을 구축해야 한다.

​

가용성 영역을 사용하여 애플리케이션을 실행할 수 있다.

가용성 영역 간에 데이터를 전송하는 비용이 발생할 수 있다.

가용성 영역은 주로 VM, 디스크, 데이터베이스에 주로 사용됩니다. 

​

지역 쌍

대부분의 Azure 지역은 동일한 지리적 위치 내의 다른 Azure 지역과 쌍을 이룬다.

지리적 위치에서 리소스를 복제할 수 있어 서비스가 중단될 가능성을 줄일 수 있다.

​

Azure 서비스의 복구 및 복제는 고객이 구성해야 한다.

Azure 지역 쌍은 Azure 지역 규모의 재해를 피할 수 있도록 충분히 멀리 떨어져 있다.

​

소버린 지역

Azure에는 일반 지역 외에도 소버린 지역이 있다. 

소버린 지역은 Azure의 주 인스턴스에서 격리된 Azure의 인스턴스다.

​

Azure 리소스 및 리소스 그룹

리소스는 Azure의 기본 구성 요소이다.

사용자가 만들고, 프로비저닝하고, 배포하는 모든 것은 리소스다. 

​

리소스 그룹은 리소스의 그룹이다.

리소스를 만들면 리소스 그룹에 두어야 한다.

리소스 그룹을 삭제하면 모든 리소스가 삭제된다.

​

Azure 구독

Azure를 사용하려면 Azure 구독이 필요하다.

구독은 Azure 서비스에 대해 인증이 되고 권한이 부여된 액세스를 제공한다.

​

Azure에서 구독은 관리 및 청구의 단위다. 

구독은 리소스 그룹을 논리적으로 구성하고 청구를 쉽게 한다.

​

구독 유형은 청구 경계와 액세스 제어 경계가 있다.

환경, 조직 구조, 청구에 따라 추가적인 Azure 구독을 만들 수 있다.

​

Azure 관리 그룹

리소스는 리소스 그룹으로 모이고 리소스 그룹은 구독으로 모입니다. 

구독이 많다면 효율적으로 관리하는 방법이 필요할 수 있다.

Azure 관리 그룹은 구독 상위 수준의 범위를 제공한다.

관리 그룹 트리에서 지원할 수 있는 최대 깊이 수준은 6이다.
