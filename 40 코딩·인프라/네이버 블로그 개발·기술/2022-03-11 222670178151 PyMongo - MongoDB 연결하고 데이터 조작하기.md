1\. PyMongo 개요

PyMongo는 MongoDB에서 제공하는 Python 라이브러리로 MongoDB 데이터베이스와 상호 작용하기 위한 기능이 포함되어 있다. Python에서 MongoDB를 사용할 때 이 라이브러리를 권장한다. MongoDB의 Database는 Collection의 집합으로 구성되고 Collection은 Document의 집합으로 구성된다. Document는 JSON 기반의 데이터로 관리된다.

3\. 사용법

MongoDB와의 연결은 pymongo.MongoClient 함수를 사용한다.

# 방법 1 : 호스트와 포트 conn = pymongo.MongoClient("localhost", 27017) # 방법 2 : URL 문자열 conn = pymongo.MongoClient("mongodb://localhost:27017/") # 방법 3 : URL 문자열 (계정포함) username = 'test' password = '1234' conn = pymongo.MongoClient('mongodb://%s:%s@localhost' % (username, password))

MongoDB 데이터베이스 접근은 pymongo.MongoClient 함수에서 리턴한 연결객체를 사용한다. 데이터베이스가 없으면 생성이 된다.

# 방법 1 : 딕셔너리 mongo_db = conn["example"] # 방법 2 : 속성정보 mongo_db = conn.example

MongoDB 컬렉션 접근은 데이터베이스 참조변수를 사용한다. 컬렉션이 없으면 생성이 된다.

# 방법 1 : 딕셔너리 mongo_col = mongo_db["books"] # 방법 2 : 속성정보 mongo_col = mongo_db.books

Collection에 Document를 추가는 insert_one 함수와 insert_many 함수를 사용하고 한다. Document 수정은 update_one 함수와 update_many 함수를 사용한다. Document 삭제는 delete_one 함수와 delete_many 함수를 사용한다. Document 조회는 find_one 함수와 find 함수를 사용한다.

​

위의 내용을 정리하면 다음과 같다.

Document 조회 : fine_one(), find() Document 추가 : insert_one(), insert_many() Document 수정 : update_one(), update_many() Document 삭제 : delete_one(), delete_many()

​

4\. 예제

books 컬렉션에 서적의 정보를 추가하고 수정하고 삭제하는 예제입니다.

import pymongo # MongoDB 연결 conn = pymongo.MongoClient("localhost", 27017) # Database 생성 mongo_db = conn["example"] # Collections 생성 mongo_col = mongo_db["books"] print("Collections 삭제") mongo_col.delete_many({}) print("Collections 추가 1") data = {"name": "Python", "price": 25000} x = mongo_col.insert_one(data) print("record inserted, ID:", x.inserted_id) print() print("Collections 추가 2") data_dic = [ { "name": "MongoDB", "price": 30000 }, { "name": "Flask", "price": 20000, } ] x = mongo_col.insert_many(data_dic) print("record inserted, IDs:", x.inserted_ids) print() print("Collections 수정") mongo_col.update_one({"name": "MongoDB"}, {"$set": {"price": 27000}}) print("Collections 조회") rows = mongo_col.find() for row in rows: print(row) print() print("Collections 조회 : price > 25000") my_query = {"price": {"$gt": 25000}} rows = mongo_col.find(my_query) for row in rows: print(row) print() print("Collections 삭제 : price < 26000") mongo_col.delete_many({"price": {"$lt": 26000}}) print("Collections 조회") rows = mongo_col.find() for row in rows: print(row) print()
