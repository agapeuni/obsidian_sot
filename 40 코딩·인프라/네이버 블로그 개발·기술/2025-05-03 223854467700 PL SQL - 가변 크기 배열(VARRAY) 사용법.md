# 2025-05-03 223854467700 PL SQL - 가변 크기 배열(VARRAY) 사용법

## 본문

![](https://postfiles.pstatic.net/MjAyNTA1MDNfMTMg/MDAxNzQ2MjY0MzU0MDI5.PdSR1WGA1ncPKDfErCotVuhKWvyp2hPe2aAJwrn6ZXsg.40eJomDloWiZJiq45a9kT8lo6umwFnmXsg9noM9taNYg.PNG/PL_SQL-001_\(11\).png?type=w80_blur)

​

Oracle PL/SQL에서는 다양한 형태의 컬렉션을 지원하며, 그 중 하나가 바로 **VARRAY** 이다. 가변 크기 배열은 요소의 순서를 유지하면서도 한정된 개수의 데이터를 다루는 데 적합한 자료구조로, 중첩 테이블(Nested Table)과 유사한 형태를 갖추고 있으나 고유한 특징들도 함께 지닌다.

​

VARRAY의 개념부터 선언 및 초기화 방법, 요소 추가 방식에 이르기까지 PL/SQL에서의 실무 활용법을 중심으로 알아보자.

**​**

**​**

**1\. VARRAY란 무엇인가?**

**VARRAY** 는 Variable-Size Array의 약어로, 이름 그대로 가변적 요소를 가지는 배열이다. 그러나 일반적인 배열과 달리, **생성 시점에 최대 크기를 명시해야 한다** 는 제약이 있으며, 이로 인해 아래와 같은 특성을 가진다.

  * 최대 크기가 고정되므로, 배열 요소 수는 사전에 결정되어야 한다.

  * 한 번 추가된 항목은 삭제할 수 없다.

  * 요소들은 **정해진 순서대로 유지** 된다.

  * SQL에서도 컬럼 타입으로 사용 가능하다.

  * 일반적으로 **순서가 중요한 데이터 처리** 에 적합하다.

**​**

**​**

**2\. VARRAY의 선언 및 초기화 방법**

VARRAY를 사용하기 위해서는 먼저 TYPE(자료형)을 정의해야 하며, 이후 해당 TYPE을 기반으로 변수를 선언하여 배열을 사용할 수 있다.

​

**형식**

TYPE 타입명 IS VARRAY(최대크기) OF 데이터형 [NOT NULL]; 

**예제**

DECLARE TYPE dept_array IS VARRAY(100) OF VARCHAR2(30); depts dept_array; inx1 PLS_INTEGER; BEGIN depts := dept_array('Dept One', 'Dept Two'); -- 생성자 호출 FOR inx1 IN 1..2 LOOP DBMS_OUTPUT.PUT_LINE(depts(inx1)); END LOOP; END; / 

위 예제는 dept_array라는 VARRAY 타입을 정의한 후, 배열을 초기화하면서 두 개의 부서명을 추가하는 과정이다. 나머지 요소는 비어 있으며, 배열의 최대 용량은 100개로 제한되어 있다.

**​**

**​**

**3\. 배열 요소의 동적 추가: EXTEND 메소드**

VARRAY는 EXTEND 메소드를 이용하여 배열에 새로운 요소를 추가할 수 있다. 단, 배열이 이미 최대 크기에 도달한 경우에는 추가가 불가능하다.

​

다음은 실제 테이블(department)로부터 데이터를 읽어 배열에 순차적으로 저장하는 예제이다.

**예제**

DECLARE CURSOR all_depts IS SELECT * FROM department ORDER BY dept_name; TYPE dept_array IS VARRAY(100) OF department%ROWTYPE; depts dept_array; inx1 PLS_INTEGER; BEGIN inx1 := 0; depts := dept_array(); -- 빈 배열로 초기화 FOR dept IN all_depts LOOP inx1 := inx1 + 1; depts.EXTEND(); -- 요소 추가 depts(inx1).dept_id := dept.dept_id; depts(inx1).dept_name := dept.dept_name; END LOOP; \-- 결과 출력 FOR i IN 1 .. inx1 LOOP DBMS_OUTPUT.PUT_LINE('부서 ID: ' || depts(i).dept_id || ', 부서명: ' || depts(i).dept_name); END LOOP; END; / 

이 예제는 커서를 통해 부서 정보를 순차적으로 읽고, VARRAY 타입의 배열에 저장한 뒤 출력하는 구조로 되어 있다. 이처럼 VARRAY는 **정렬된 데이터 목록** 을 유지하면서 반복 처리할 때 매우 유용하다.

**​**

**​**

**4\. VARRAY와 다른 컬렉션과의 비교**

**항목** |  **VARRAY** |  **중첩 테이블** |  **연관 배열**  
---|---|---|---  
요소 순서 유지 여부 |  유지됨 |  보장되지 않음 |  보장되지 않음  
크기 제한 여부 |  있음 (고정 크기 선언 필요) |  없음 |  없음  
SQL 사용 가능 여부 |  가능 |  가능 |  불가능  
삭제 가능 여부 |  직접 삭제 불가 |  가능 |  가능  
주 용도 |  순서가 중요한 데이터 처리 |  대용량 리스트 관리 |  메모리 내 임시 데이터 저장  
  
**​**

Oracle PL/SQL의 VARRAY는 **정렬된 고정 크기 배열** 을 다룰 수 있도록 지원하는 컬렉션 유형으로, 정해진 범위 내에서의 반복 처리, 순차 출력, 목록 보관 등의 작업에 매우 적합하다. VARRAY는 SQL 컬럼으로도 사용할 수 있어, 테이블과 연계된 구조적 데이터 모델링에도 활용될 수 있다.

​

이 컬렉션은 중첩 테이블이나 연관 배열과는 다른 제한을 갖지만, 사용 목적에 맞게 적절히 활용한다면 코드의 가독성과 실행 효율을 크게 향상시킬 수 있다. 추가적으로 TRIM, LIMIT 등의 VARRAY 관련 메소드를 함께 활용하면 더 유연한 컬렉션 처리가 가능하다.
