**1\. 개요**

최근 웹 애플리케이션의 사용자 경험을 개선하기 위한 기술로 실시간 데이터 송수신 기능이 중요하게 여겨지고 있다. 이러한 기능을 구현하기 위해 대표적으로 사용되는 기술 중 하나가 **WebSocket** 이며, JavaScript 런타임인 **Node.js** 환경에서는 socket.io 모듈을 통해 쉽게 이를 구현할 수 있다.

​

socket.io는 Node.js 기반의 실시간 통신 라이브러리로, WebSocket을 기본으로 하되 상황에 따라 자동으로 폴백(fallback) 방식도 제공한다. 포스팅에서는 socket.io를 활용하여 브라우저 간 실시간 메시지 통신을 구현하는 간단한 예제를 소개하고자 한다. 개 이상의 브라우저 클라이언트가 하나의 서버를 통해 메시지를 주고받는 예제이다. 이 예제를 통해 서버와 클라이언트 간의 양방향 통신 흐름을 이해하고, 기본적인 이벤트 처리 방식을 학습할 수 있다.

**​**

**2\. 서버 코드 구성**

서버는 기본적으로 80번 포트를 사용하며, 이는 HTTP의 기본 포트이기 때문에 URL에서 포트 번호를 생략할 수 있는 장점이 있다. 서버 초기화는 다음과 같이 이루어진다. 클라이언트와의 연결이 성사되면 connection 이벤트가 발생하고, 해당 소켓 객체를 통해 이후의 이벤트 처리가 이루어진다. 

var io = require('socket.io').listen(80); io.sockets.on('connection', function(socket) {

본 예제에서는 두 가지 이벤트를 정의하였다.

  * msg_from_client1 : 메시지를 수신하면 카운터를 1 증가시킨 뒤, 1.5초 후 모든 클라이언트에게 msg_from_server1 이벤트로 메시지를 전송함

  * msg_from_client2 : 카운터를 2 증가시킨 후, 동일하게 모든 클라이언트에게 msg_from_server2 이벤트로 메시지를 전송함

전체 서버 코드는 아래와 같다.

var count = 0; var io = require('socket.io').listen(80); io.sockets.on('connection', function(socket) { socket.on('msg_from_client1', function(data) { count++; console.log(data); setTimeout(function() { io.sockets.emit('msg_from_server1', '[from Server] Message [' + count + '] : ' + data); }, 1500); }); socket.on('msg_from_client2', function(data) { count++; count++; console.log(data); setTimeout(function() { io.sockets.emit('msg_from_server2', '[from Server] Message [' + count + '] : ' + data); }, 1500); }); });

​

서버가 구동되면, 각 클라이언트가 접속할 때마다 핸드셰이크 로그가 출력되며, 클라이언트의 구분 값이 출력된다.

**3\. 클라이언트 코드 구성**

클라이언트 측은 HTML 파일로 구성되며, socket.io.js 라이브러리를 <script> 태그로 로드한 후, 서버와 연결을 시도한다.

<script src="http://localhost/socket.io/socket.io.js"></script>​

페이지가 로드되면 msg_from_server1과 msg_from_server2 이벤트를 수신할 준비를 하고, 각각의 메시지는 다음과 같이 처리된다.

  * msg_from_server1 : 알림창(alert)으로 메시지를 표시

  * msg_from_server2 : 페이지 내 div 태그를 이용하여 메시지를 출력

socket.on('msg_from_server1', function(data) { alert(data); }); socket.on('msg_from_server2', function(data) { var div = document.getElementById("display"); div.innerHTML = data; });

화면에는 이름과 메시지 입력항목이 있고 서버를 통해 메시지를 전달하는 버튼 2개가 있다. 2개의 버튼을 각각 클릭하면, 버튼 클릭 이벤트에 따라 클라이언트는 서버로 메시지를 전송하며, 서버는 해당 메시지를 모든 클라이언트에게 브로드캐스팅하게 된다.

<html> <head> <script src="http://localhost/socket.io/socket.io.js"></script> <script> var socket; window.onload = function() { socket = io.connect('http://localhost'); socket.on('msg_from_server1', function(data) { alert(data); }); socket.on('msg_from_server2', function(data) { var div = document.getElementById("display"); div.innerHTML = data; }); } var sendMessage1 = function() { var name = document.getElementById("name").value; var msg = document.getElementById("msg").value; socket.emit('msg_from_client1', name + "," + msg); } var sendMessage2 = function() { var div = document.getElementById("display"); div.innerHTML = ""; var name = document.getElementById("name").value; var msg = document.getElementById("msg").value; socket.emit('msg_from_client2', name + "," + msg); } </script> </head> <body> <table> <tr> <td>name: <input type="text" name="name" id="name" value="name"> </td> </tr> <tr> <td>msg: <input type="text" name="msg" id="msg" value="msg"> </td> </tr> <tr> <td> <button onclick="sendMessage1();">sendMessage1</button> <button onclick="sendMessage2();">sendMessage2</button> </td> </tr> </table> <div id="display"></div> <hr> </body> </html>
