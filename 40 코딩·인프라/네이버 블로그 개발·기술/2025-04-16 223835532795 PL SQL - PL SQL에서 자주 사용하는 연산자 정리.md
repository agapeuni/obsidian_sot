# 2025-04-16 223835532795 PL SQL - PL SQL에서 자주 사용하는 연산자 정리

## 본문

​

Oracle 데이터베이스를 활용한 프로그래밍 시, PL/SQL 내에서 다양한 연산자를 활용해 효율적인 데이터 처리가 가능하다. 본 포스팅에서는 PL/SQL에서 사용되는 연산자의 종류와 특징, 그리고 실습 예제를 중심으로 정리하였다.

**​**

**​**

**연산자의 종류**

**대입 연산자**

PL/SQL에서 변수에 값을 할당할 때는 := 연산자를 사용한다.

예) 변수명 := 값;

​

**산술 연산자**

기본적인 산술 계산에 사용되는 연산자는 다음과 같다.

  * ** : 지수 연산자 (예: 10**3 → 1000)

  * +, -, *, / : 덧셈, 뺄셈, 곱셈, 나눗셈

​

**비교 연산자**

값을 비교할 때 사용하는 연산자로, 결과값은 TRUE 또는 FALSE다.

  * = : 동일 여부 확인

  * <>, !=, ~= : 같지 않음을 의미

  * <, >, <=, >= : 크기 비교

  * LIKE : 패턴 일치 여부 확인

  * 예) LIKE 'log%' → log로 시작하는 문자열

  * LIKE 'log___' → log로 시작하고 뒤에 3글자가 더 있는 경우

  * BETWEEN A AND B : A 이상 B 이하의 범위 확인

  * IN (값1, 값2, ...) : 특정 값이 목록 내에 존재하는지 확인

  * IS NULL : 값이 NULL인지 여부 확인

**​**

**​**

**실습 예제 – LIKE 연산자 활용 함수**

다음은 휴대폰 번호를 입력 받아 통신사를 판별하는 함수 예제다.

CREATE OR REPLACE FUNCTION mobile_phone (phone_number IN VARCHAR2) RETURN VARCHAR2 AS BEGIN IF phone_number LIKE '___-%-____' THEN IF SUBSTR(phone_number,1,3) = '011' THEN RETURN 'SK Telecom 011'; ELSIF SUBSTR(phone_number,1,3) = '016' THEN RETURN 'KTF 016'; ELSE RETURN 'ETC...'; END IF; END IF; END; / 

​

실행 예

SQL> select mobile_phone('016-0000-0000') MAKER from dual;

​

결과

MAKER \-------------------- KTF 016 

​

**논리 연산자**

  * AND, OR, NOT : 조건을 조합할 때 사용된다.

**​**

**문자열 연결 연산자**

  * || : 문자열을 연결할 때 사용한다.

  * 예) 'Kang' || ' ' || 'Yong Woon' → 'Kang Yong Woon'

**​**

**​**

**연산자 우선순위**

복잡한 식을 작성할 때는 연산자 우선순위를 숙지하고 괄호를 적절히 사용하는 것이 중요하다.

**우선순위** |  **연산자**  
---|---  
① |  **, NOT  
② |  단항 +, -  
③ |  *, /  
④ |  이항 +, -, `  
⑤ |  비교 연산자 (=, <>, LIKE, IN, 등)  
⑥ |  AND  
⑦ |  OR  
  
**​**

**NULL 관련 주의사항**

  * NULL 값을 비교할 때는 반드시 IS NULL 또는 IS NOT NULL을 사용해야 합니다.

  * 예) IF a IS NULL

  * 기본값을 설정하고 싶을 경우 NVL 함수를 사용할 수 있습니다.

  * 예) NVL(변수, '기본값')

**​**

**형 변환 함수**

PL/SQL에서는 자동 형변환이 가능하지만, 코드의 안정성과 가독성을 위해 명시적으로 변환하는 것이 좋습니다.

**함수** |  **기능**  
---|---  
TO_DATE(문자) |  문자 → 날짜  
TO_NUMBER(문자) |  문자 → 숫자  
TO_CHAR(숫자 또는 날짜) |  숫자 또는 날짜 → 문자  
  
위 내용을 잘 숙지해두면 PL/SQL을 활용한 프로그래밍 시 보다 유연하고 오류 없는 코드를 작성할 수 있다. 다음 포스팅에서는 조건문과 반복문에 대한 내용을 다루도록 하겠다.
