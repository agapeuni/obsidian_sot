**1\. MongoDB 개요**

**M** EAN Stack의 **M** 에 해당하는 MongoDB를 설치하고 정상적으로 동작하는지 Java 테스트 코드를 만들어 실행해 보자.

​

MongoDB는 NoSQL 데이터베이스 시스템의 하나로, Document-Oriented 데이터베이스이다. MongoDB는 오픈소스이며 뛰어난 확장성과 성능을 바탕으로 NoSQL을 대표한다. 2009년에 10gen이라는 회사에 의해 개발되었으며, 현재는 MongoDB Inc.라는 회사가 관리하고 있다.

​

MongoDB는 다양한 언어를 지원하며, 개발자들이 쉽게 접근할 수 있는 다양한 클라이언트 라이브러리와 드라이버가 제공된다. 또한, MongoDB는 유연한 쿼리 언어와 인덱싱 기능을 제공하여 데이터의 검색과 분석을 효율적으로 수행할 수 있다. MongoDB의 주요한 사용 사례로는 대량의 비정형 데이터를 처리해야 하는 경우나, 실시간 데이터 분석, 로그 분석, 사용자 프로파일링, 소셜 미디어 애플리케이션 등이 있다.

다음 코드는 MongoDB 데이터베이스의 컬렉션을 조회하는 Java 코드이다.

파일 : MongoDbScan.java

import org.bson.Document; import com.mongodb.client.FindIterable; import com.mongodb.client.MongoClient; import com.mongodb.client.MongoClients; import com.mongodb.client.MongoCollection; import com.mongodb.client.MongoDatabase; import com.mongodb.client.MongoIterable; public class MongoDbScan { public static void main(String[] args) { // 연결 문자열 String uri = "mongodb://localhost:27017"; // MongoClient 생성 try (MongoClient mongoClient = MongoClients.create(uri)) { // 데이터베이스 이름 목록 MongoIterable<String> databaseNames = mongoClient.listDatabaseNames(); for (String databaseName : databaseNames) { // 데이터베이스 System.out.println("database = " + databaseName); MongoDatabase database = mongoClient.getDatabase(databaseName); // 컬렉션 목록 MongoIterable<String> collectionNames = database.listCollectionNames(); for (String collectionName : collectionNames) { // 컬렉션 System.out.println("collection = " + collectionName); MongoCollection<Document> collection = database.getCollection(collectionName); FindIterable<Document> docs = collection.find(); for (Document doc : docs) { System.out.println(doc.toJson()); } } System.out.println(); } } } }
