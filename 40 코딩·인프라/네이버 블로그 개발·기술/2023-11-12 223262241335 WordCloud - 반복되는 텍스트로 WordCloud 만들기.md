1\. 개요

WordCloud(워드 클라우드)는 텍스트 데이터에서 가장 빈번하게 나타나는 단어를 시각적으로 표현하는 도구이다. 주로 자연어 처리 및 텍스트 마이닝에서 텍스트 데이터의 특징을 빠르게 시각화하고 이해하는 데 사용된다. 보통은 텍스트 데이터를 처리하고, 단어의 빈도를 계산한 후, 이 정보를 바탕으로 워드 클라우드를 생성한다. WordCloud 라이브러리는 이러한 작업을 쉽게 할 수 있다.

​

3\. 기본 예제

WordCloud 라이브러리와 Matplotlib을 사용하여 간단한 텍스트 데이터로부터 워드 클라우드를 생성하고 시각화하는 예제다. 

​

WordCloud 클래스의 인스턴스를 생성하고, generate 메서드를 사용하여 텍스트 데이터에서 워드 클라우드를 생성한다. 텍스트는 링컨의 게티즈버그 연설 원문을 텍스트 파일로 두고 파일로 읽어서 사용했다.

# 라이브러리 가져오기 from wordcloud import WordCloud import matplotlib.pyplot as plt # 텍스트 데이터 text_data = open('./Gettysburg.txt', encoding='utf-8').read() # 워드 클라우드 생성 # background_color 매개변수로 배경을 흰색으로 지정 wordcloud = WordCloud(background_color='white').generate(text_data) # 생성된 워드 클라우드를 matplotlib을 사용하여 표시 plt.figure(figsize=(8, 8)) plt.imshow(wordcloud, interpolation='bilinear') # x 및 y 축을 표시하지 않도록 설정 plt.axis("off") plt.show()

4\. 이미지 마스킹

WordCloud 라이브러리와 Matplotlib을 사용하여 이미지 마스크를 활용하여 텍스트 데이터로부터 워드 클라우드를 생성하고 시각화하는 예제이다. 주어진 이미지 마스크를 기반으로 텍스트 데이터로부터 워드 클라우드를 생성하여 시각화한다. 결과물은 주어진 이미지의 형상을 따르는 워드 클라우드로 나타난다.

​

1) 라이브러리 가져오기

코드의 첫 부분에서는 WordCloud와 Matplotlib을 비롯하여 이미지 처리를 위한 PIL(Pillow) 및 NumPy 라이브러리를 가져온다.

from wordcloud import WordCloud, STOPWORDS import matplotlib.pyplot as plt from PIL import Image import numpy as np

​

2) 텍스트 데이터 설정

usa.txt 파일에서 텍스트 데이터를 읽어와 `text_data` 변수에 할당한다. 이 파일에는 워드 클라우드를 생성할 텍스트 데이터가 들어있다.

text_data = open('./usa.txt', encoding='utf-8').read()

​

3) 이미지 마스크 설정

usa.png 파일을 열어 이미지를 NumPy 배열로 변환한 후 usa_map 변수에 저장한다. 이 이미지는 워드 클라우드의 모양을 결정하는 마스크로 사용된다. 마스크 이미지의 모양에 따라 워드 클라우드의 배치가 결정된다.

image_path = "./usa.png" usa_map = np.array(Image.open(image_path))

​

4) 워드 클라우드 생성

WordCloud 클래스의 인스턴스를 생성하고, background_color 매개변수로 배경 색상을 지정하고, stopwords 매개변수로 불용어(무시할 단어)를 설정하며, mask 매개변수로 앞서 로드한 이미지 마스크를 설정하여 워드 클라우드를 생성한다.

wordcloud = WordCloud(background_color='white', stopwords=STOPWORDS, mask=usa_map).generate(text_data)

​

5) Matplotlib을 사용한 시각화

그림의 크기를 설정하고(plt.figure(figsize=(10, 10))), imshow 함수를 사용하여 생성된 워드 클라우드를 Matplotlib을 통해 시각화한다. axis("off")는 x 및 y 축을 표시하지 않도록 설정한다. 마지막으로 show()를 호출하여 그림을 화면에 표시한다.

plt.figure(figsize=(10, 10)) plt.imshow(wordcloud, interpolation='bilinear') plt.axis("off") plt.show()

​

6) 전체 코드

from wordcloud import WordCloud, STOPWORDS import matplotlib.pyplot as plt from PIL import Image import numpy as np # 텍스트 데이터 예제 text_data = open('./usa.txt', encoding='utf-8').read() image_path = "./usa.png" usa_map = np.array(Image.open(image_path)) # 워드 클라우드 생성 wordcloud = WordCloud(background_color='white', stopwords=STOPWORDS, mask=usa_map).generate(text_data) # 생성된 워드 클라우드를 matplotlib을 사용하여 표시 plt.figure(figsize=(10, 10)) plt.imshow(wordcloud, interpolation='bilinear') plt.axis("off") plt.show()
