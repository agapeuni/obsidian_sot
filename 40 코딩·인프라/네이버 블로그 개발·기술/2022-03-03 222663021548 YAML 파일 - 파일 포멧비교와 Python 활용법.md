1\. YAML 파일

![](https://postfiles.pstatic.net/MjAyMzAzMTVfMjU0/MDAxNjc4ODg0Njc3ODIy.3NuBeIKeupXn0xAA3UAXZSn1xvn1VInrMBOG_RGBswUg.KouRQwuwjenv3uGO0124EyL0ousyLqpvGP59LJYA7ukg.PNG.agapeuni/SE-a1555eab-23b7-4768-8a79-b3efeca008cf.png?type=w80_blur)

최근에는 프로젝트를 수행 시 YAML 파일도 종종 접하게 된다. YAML은 사람이 쉽게 읽을 수 있는 데이터 직렬화 양식이다. YAML은 앵커 (`)를 사용하여 관계형 데이터를 허용한다. 시스템 환경설정 파일이나 패키징 정보를 관리할 때 XML과 JSON을 많이 사용하는데 같은 정보를 표현할 때 XML보다 JSON과 YAML이 더 가볍다. 사람이 읽히는 구조화 형식으로 본다면 YAML 파일이 JSON보다 심플하고 가독성이 좋다. 

​

동일한 데이터를 대상으로 파일 포맷별로 크기를 비교해 보면 구분자만으로 데이터를 구성하고 있는 CSV가 가장 가볍고 데이터를 열린태그과 닫힌 태그로 감싸야 하는 XML이 가장 무겁다. JSON과 YAML은 CSV와 XML의 중간 정도 크기이다.

파일 포맷 |  파일 크기(10,000 레코드) |  파일 크기(100,000 개 레코드)  
---|---|---  
CSV |  0.41 |  4.2  
JSON |  0.81 |  8.2  
YAML |  0.80 |  8.1  
XML |  1.50 |  15  
  
​

​

2.설치 및 비교

pyyaml 패키지를 설치하면 YAML 파일을 읽어 구분을 분석할 수 있다.

pip install pyyaml 

동일한 정보를 XML, JSON, CSV, YAML로 표현하면 다음과 같다. 한 때 데이터 처리에 뜨거운 감자였던 XML은 데이터를 표현하기 위한 태그정보들이 오버헤드이다. 순수 데이터양은 생각보다 적다. JSON은 XML보다 가볍지만 메타정보가 반복적으로 추가된다. 순수 데이터만을 표현하기에는 CSV 가 제일 좋다. YAML은 메타 정보를 담고 있지만 JSON과 거의 비슷하다.

​

XML

<users> <user> <name> 홍길동 </name> <age> 30 </age> <hobby> Swimming </hobby> </user> <user> <name> 김서방 </name> <age> 40 </age> <hobby> Dancing </hobby> </user> </users>

​

JSON

{ "users": [ { "name": "홍길동", "age": 30, "hobby": "Swimming" }, { "name": "김서방", "age": 40, "hobby": "Dancing" } ] }

​

YAML

users: \- name: "홍길동" age: 30 hobby: "Swimming" \- name: "김서방" age: 40 hobby: "Dancing"

​

CSV

name, age, hobby 홍길동, 30, Swimming 김서방, 40, Dancing

​

3\. YAML 파일 쓰기

파이썬에서 yaml_data를 구성한다. 쓰기 모드로 파일을 열고 yaml.dump 함수를 사용하여 파일을 저장한다.

​

소스코드 : file_yaml_write.py

import yaml yaml_data = [ { "Code": "A1", "Name": "item1", "Date": "2020-09-19" }, { "Code": "B2", "Name": "item2", "Date": "2020-09-20", "Memo": {"Hobby1": "Music", "Hobby2": "Movie"} }, { "Code": "C3", "Name": "item3", "Date": "2020-09-20" }, {"Code": "D4", "Name": "item4"} ] with open("data/sample.yml", "w") as f: yaml.dump(yaml_data, f)

​

실행 결과 : sample.yaml

\- Code: A1 Date: '2020-09-19' Name: item1 \- Code: B2 Date: '2020-09-20' Memo: Hobby1: Music Hobby2: Movie Name: item2 \- Code: C3 Date: '2020-09-20' Name: item3 \- Code: D4 Name: item4

​

4\. YAML 파일 읽기

파일을 열고 yaml.load() 함수를 사용하여 yaml 파일을 읽는다.

​

소스코드 : file_yaml_read.py

import yaml with open('data/sample.yml') as f: yaml_data = yaml.load(f, Loader=yaml.FullLoader) for item in yaml_data: print(item)

실행 결과 : 터미널 창

{'Code': 'A1', 'Date': '2020-09-19', 'Name': 'item1'} {'Code': 'B2', 'Date': '2020-09-20', 'Memo': {'Hobby1': 'Music', 'Hobby2': 'Movie'}, 'Name': 'item2'} {'Code': 'C3', 'Date': '2020-09-20', 'Name': 'item3'} {'Code': 'D4', 'Name': 'item4'}
