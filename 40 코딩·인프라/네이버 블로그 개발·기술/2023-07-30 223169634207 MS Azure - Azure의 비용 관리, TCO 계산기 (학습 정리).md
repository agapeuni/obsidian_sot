​

Azure에서 비용을 예측, 추적 및 관리하는 방법을 살펴본다.

​

Azure의 비용에 영향을 줄 수 있는 요인 

Azure는 인프라 및 시설을 구축하고 유지 관리하는 데 드는 **CapEx(자본 비용)** 에서 

컴퓨팅, 스토리지, 네트워킹 등과 같이 필요에 따라 인프라를 임대하는 **OpEx(운영 비용)** 로 개발 비용을 전환한다.

​

리소스 유형

리소스의 유형, 리소스에 대한 설정 및 Azure 지역은 모두 리소스 비용에 영향을 준다.

Azure 리소스를 프로비저닝하면 Azure에서 해당 리소스에 대한 측정 인스턴스를 만든다.

​

소비(Consumption)

Azure는 미리 정해진 양의 클라우드 리소스를 사용할 것을 약정하고, “예약된” 해당 리소스에 대해 할인을 받을 수 있는 기능도 제공한다.

데이터베이스, 컴퓨팅 및 스토리지를 비롯한 다양한 서비스는 모두 사용량 수준을 약정하여 할인을 받을 수 있는 옵션을 제공한다.

​

유지 관리

클라우드의 유연성을 수요에 따라 리소스를 신속하게 조정할 수 있다. 

리소스 그룹을 사용하면 모든 리소스를 체계적으로 유지하는 데 도움이 된다. 

​

지리(Geography)

Azure에서 대부분의 리소스를 프로비저닝하는 경우 리소스가 배포되는 지역을 정의해야 한다. 

Azure 인프라는 전 세계에 배포되므로 서비스를 중앙이나 고객이 사용하는 위치와 가까운 곳에 배치할 수 있다. 

전력 비용, 인건비, 세금 및 요금은 지역에 따라 달라지게 되어 글로벌 가격 책정 차이가 발생한다. 

​

네트워크 트래픽

대역폭이란 Azure 데이터 센터로 들어오고 나가는 데이터를 말한다. 

일부 인바운드 데이터 전송(Azure 데이터 센터로 들어오는 데이터)은 무료다. 

아웃바운드 데이터 전송(Azure 데이터 센터에서 나가는 데이터)의 경우 영역에 따라 데이터 전송 가격이 책정된다.

​

Azure Marketplace

Azure Marketplace에서는 타사 공급업체의 Azure 기반 솔루션과 서비스를 구입할 수 있다.

Azure Marketplace에서 제공되는 모든 솔루션은 인증을 받았고 Azure 정책 및 표준을 준수한다.

제품을 구매할 때 사용 중인 Azure 서비스뿐만 아니라 타사 공급업체의 서비스 대해서도 비용을 지불할 수 있다.

​

가격 계산기

가격 계산기는 Azure에서 리소스를 프로비저닝하기 위한 예상 비용을 제공하도록 설계되었다. 

개별 리소스에 대한 예상가를 얻거나, 솔루션을 빌드 하거나, 시나리오를 사용하여 Azure 지출의 추정치를 볼 수 있다. 

가격 계산기를 사용하면 컴퓨팅, 스토리지 및 관련 네트워크 비용을 포함하여 프로비저닝된 리소스의 비용을 예측할 수 있다.

TCO 계산기

TCO 계산기는 온-프레미스 인프라를 실행하는 비용을 Azure 클라우드 인프라와 비교하는 데 도움이 되도록 설계되었다. 

TCO 계산기를 사용하면 현재 데이터 센터 또는 Azure에서 동일한 환경을 실행하기 위한 비용의 예측된 차이 값이 제공된다.

Azure Cost Management 도구

Microsoft Azure는 글로벌 클라우드 공급자이므로 전 세계 어디서나 리소스를 프로비저닝할 수 있다. 

갑작스러운 수요를 충족하거나 새 기능을 테스트하거나, 또는 실수로 신속하게 리소스를 프로비저닝할 수 있습니다. 실수로 새 리소스를 프로비저닝하는 경우 청구서를 받을 때까지 상황을 인식하지 못할 수 있습니다. Cost Management는 이러한 상황을 방지하는 데 도움이 되는 Azure 서비스입니다.

​

비용 관리(Cost Management)는 무엇입니까?

Azure 리소스 비용을 신속하게 확인하고, 리소스 지출에 따라 경고를 만들고, 리소스 관리를 자동화하는 예산을 만드는 기능을 제공한다.

비용 분석을 사용하면 청구 주기, 지역, 리소스 기준을 포함한 다양한 방법으로 총 비용을 빠르게 볼 수 있다.

시간에 따라 누적된 비용을 확인하여 예산을 기준으로 월 단위, 분기 단위 또는 연 단위 비용 추세를 평가할 수 있다.

​

비용 경고

Cost Management 서비스에 신속하게 확인할 수 있는 다양한 경고 유형을 제공한다.

​

**예산 경고**

사용량 또는 비용을 기준으로 지출이 예산의 경고 조건에 정의된 금액에 도달하거나 초과할 때 알린다.

Cost Management 예산은 Azure Portal 또는 Azure Consumption API를 사용하여 만들어진다.

​

**크레딧 경고**

크레딧 경고는 Azure 크레딧 현금 약정 금액이 사용될 때 사용자에게 알린다.

크레딧 경고는 Azure 크레딧 잔액의 90% 및 100%로 자동 생성됩니다. 

​

**부서 지출 할당량 경고**

부서 지출 할당량 경고는 부서가 할당량의 고정 임계값에 도달할 때 사용자에게 알린다.

임계값이 충족될 때마다 부서 소유자를 위한 메일이 생성되고 비용 경고에 표시된다.

​

예산

예산은 Azure에 대한 지출 한도를 설정하는 곳이다. 예산을 설정하면 예산 경고도 설정된다.

구독, 리소스 그룹, 서비스 유형 또는 기타 기준에 따라 예산을 설정할 수 있다.

​

태그 용도

클라우드 사용이 늘어남에 따라 구성된 상태를 유지하는 것이 더 중요해지고 있다. 

리소스 그룹을 사용하여 관련 리소스를 관리할 수도 있다. 

관련 리소스를 구성하는 한 가지 방법은 자체 구독에 포함하는 것이다.

​

리소스 ‘태그’는 리소스를 구성하는 또 다른 방법이다.

태그는 리소스에 관한 추가 정보 또는 메타데이터를 제공한다.

​

리소스 태그는 어떻게 관리하나요?

PowerShell, Azure CLI, Azure Resource Manager 템플릿, Azure Portal 을 통해 리소스 태그를 추가, 수정 또는 삭제할 수 있다.

​

Azure Policy를 사용하여 태그 지정 규칙을 적용할 수 있다.

리소스는 구독 및 리소스 그룹에서 태그를 상속하지 않는다.

태그가 지정되지 않은 모든 리소스는 중요 업무용으로 간주하지 않는다.
