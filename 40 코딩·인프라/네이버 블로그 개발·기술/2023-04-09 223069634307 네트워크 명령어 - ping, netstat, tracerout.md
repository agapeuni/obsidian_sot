1\. ping

ping은 ICMP echo 메시지를 전송하여 목적지 시스템으로 부터 ICMP echo 메시지를 응답 받는데 걸린 시간을 측정하여 네트워크 연결을 검사한다.

﻿ping -c 7 www.google.co.kr﻿

실행예시

[fedora@localhost ~]$ ping -c 7 www.google.co.kr PING www.google.co.kr (74.125.128.94) 56(84) bytes of data. 64 bytes from hg-in-f94.1e100.net (74.125.128.94): icmp_seq=1 ttl=128 time=62.9 ms 64 bytes from hg-in-f94.1e100.net (74.125.128.94): icmp_seq=2 ttl=128 time=63.2 ms 64 bytes from hg-in-f94.1e100.net (74.125.128.94): icmp_seq=3 ttl=128 time=62.9 ms 64 bytes from hg-in-f94.1e100.net (74.125.128.94): icmp_seq=4 ttl=128 time=63.2 ms 64 bytes from hg-in-f94.1e100.net (74.125.128.94): icmp_seq=5 ttl=128 time=63.5 ms 64 bytes from hg-in-f94.1e100.net (74.125.128.94): icmp_seq=6 ttl=128 time=62.8 ms 64 bytes from 74.125.128.94: icmp_seq=7 ttl=128 time=81.5 ms \--- www.google.co.kr ping statistics --- 7 packets transmitted, 7 received, 0% packet loss, time 12404ms rtt min/avg/max/mdev = 62.891/65.782/81.549/6.447 ms ​ [fedora@localhost ~]$

﻿traceroute www.google.co.kr

3\. netstat

netstat(Network Statistics)는 전송 제어 프로토콜, 라우팅 테이블, 네트워크 인터페이스의 통계를 보여주는 명령어이다. 

﻿netstat -ant | grep LISTEN﻿

실행예시

[fedora@localhost ~]$ netstat -ant | grep LISTEN tcp 0 0 0.0.0.0:111 0.0.0.0:* LISTEN tcp 0 0 0.0.0.0:56629 0.0.0.0:* LISTEN tcp 0 0 0.0.0.0:22 0.0.0.0:* LISTEN tcp 0 0 127.0.0.1:631 0.0.0.0:* LISTEN tcp6 0 0 :::111 :::* LISTEN tcp6 0 0 :::22 :::* LISTEN tcp6 0 0 ::1:631 :::* LISTEN tcp6 0 0 :::53180 :::* LISTEN

4\. 네트워크 명령어 

system-config-network : 네트워크 관련설정

service network restart : 네트워크 설정후에 변경된 내용을 시스템에 적용시키는 명령어

ifup <장치이름> : 해당하는 장치를 작동시켜 주는 명령어

ifconfig <장치이름> : 장치의 IP주소정보를 출력

nslookup : DNS 서버의 작동을 테스트

ping -c # <IP주소 or URL> : 네트워크 응답을 테스트

5\. 네트워크 설정 주요파일

/etc/sysconfig/network : 네트워크 기본정보가 설정

/etc/resolv.conf : DNS 서버의 정보 및 호스트 이름

/etc/hosts : 현 컴퓨터의 호스트 이름 및 FQDN
