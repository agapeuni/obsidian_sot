Azure Blueprints의 목적

Azure Blueprints의 목적은 클라우드 리소스를 표준화하고 반복 가능하게 배포하여 보안과 규정 준수를 강화하고, 클라우드 아키텍처를 쉽게 이행하며 시간을 절약하고, 협업과 관리를 용이하게 하는 것이다.

​

Azure Blueprints는 Azure 환경 내에서 표준화된, 반복 가능한, 규정 준수 가능한 솔루션을 생성하는 데 사용되는 서비스다. 새 구독마다 Azure Policy와 같은 기능을 구성하는 대신 반복 가능한 설정 및 정책을 정의하여 적용할 수 있다. Azure Blueprints를 사용하면 클라우드 구독 또는 환경 배포를 표준화할 수 있다. Azure Blueprints를 사용하면 보안 및 규정 준수 설정이 이미 구성된 새 테스트/개발 환경을 배포할 수 있다.

​

아티팩트(Artifacts)란?

Azure Blueprints에서 "아티팩트"란 블루프린트에 포함되는 리소스 구성 요소를 의미한다. Azure Blueprints는 연결된 아티팩트에서 모든 요구 사항, 설정 및 구성에 따라 새 환경을 배포한다. 정의된 블루프린트를 적용하면, 일관된 가상 머신 구성을 쉽게 배포하고, 여러 환경 간에 표준화된 리소스를 구성할 수 있다.

​

Azure Blueprints는 배포를 모니터링하는 데 어떻게 도움이 되나?

Azure Blueprints는 버전 관리가 가능하다.

버전 관리를 사용하면 업데이트를 수행하고 어떤 구성 집합이 어떤 배포를 사용하는지 추적할 수 있다.

Azure Blueprints를 사용하는 경우에는 청사진 정의와 청사진 할당 간의 관계가 유지된다. 이 연결로 배포를 추적이 가능하다.

​

Azure Policy의 목적

Azure Policy의 목적은 클라우드 리소스의 보안과 규정 준수를 강화하고, 일관성 유지를 도와주며, 자동화와 오류 방지를 통해 클라우드 리소스 관리를 지원하는 것이다. 이러한 정책은 해당 구성이 표준을 준수하는 상태를 유지하도록 다양한 규칙을 적용한다.

​

Azure Policy는 정책을 어떻게 정의하나요?

Azure Policy는 JSON(JavaScript Object Notation) 형식으로 정책을 정의한다. JSON 파일을 사용하여 리소스에 적용할 규칙을 정의하고 이를 Azure Portal, Azure PowerShell, Azure CLI 등을 통해 생성하고 관리한다.

​

Azure Policy에는 Storage, 네트워킹, 컴퓨팅, Security Center, 모니터링에 대한 기본 제공 정책 및 이니셔티브 정의가 함께 제공된다.

Azure Policy를 사용하면 개별 정책 및 관련 정책 그룹을 둘 다 정의할 수 있다. Azure Policy는 리소스를 평가하고 사용자가 만든 정책을 준수하지 않는 리소스를 강조한다. Azure Policy는 정책 미준수 리소스가 생성되지 않게 할 수도 있다.

​

Azure Policy 이니셔티브란?

Azure Policy 이니셔티브는 관련 정책을 함께 그룹화하는 방법이다. Azure Policy 이니셔티브(Initiative)는 여러 개의 Azure Policy 정책을 하나로 묶어서 관리하고, 한 번에 적용하거나 할당할 수 있는 기능이다. 이니셔티브를 사용하면 조직의 보안 요구 사항과 규정 준수를 효과적으로 적용하고, 정책을 일관성 있게 관리할 수 있다. 이니셔티브를 적용하면 정책의 집합을 간단하게 배포하고 관리할 수 있으며, 정책의 효과를 쉽게 모니터링할 수 있다.

​

리소스 잠금의 목적

리소스 잠금을 통해 리소스를 실수로 삭제하거나 변경하는 것을 방지한다.

​

Azure RBAC(역할 기반 액세스 제어) 정책을 적용한 경우에도 여전히 적절한 수준의 액세스 권한이 있는 사용자가 중요한 클라우드 리소스를 삭제할 수 있는 위험이 있다. 리소스 잠금은 잠금 유형에 따라 리소스가 삭제되거나 수정되지 않도록 한다. 리소스 잠금은 개별 리소스, 리소스 그룹 또는 전체 구독에 적용할 수 있다.

​

리소스 잠금 유형

리소스 잠금에는 두 가지 유형이 있습니다. 사용자가 리소스를 삭제할 수 없도록 하는 유형과 사용자가 리소스를 변경하거나 삭제하지 못하도록 하는 유형입니다.

​

리소스 잠금을 관리하려면 어떻게 할까요?

Azure Portal, PowerShell, Azure CLI 또는 Azure Resource Manager 템플릿에서 리소스 잠금을 관리할 수 있다.

Azure Portal에서 잠금을 보거나 추가하거나 삭제하려면 Azure Portal에서 리소스 설정 창의 설정 섹션으로 이동한다.

​

잠긴 리소스를 삭제하거나 변경하려면 어떻게 할까?

잠긴 리소스를 수정하려면 먼저 잠금을 제거해야 한다. 리소스 잠금은 RBAC 권한에 관계 없이 적용됩니다. 리소스 소유자라 할지라도 차단된 활동을 수행하려면 먼저 잠금을 제거해야 한다.

​

​

Service Trust Portal의 목적

Microsoft Service Trust Portal은 Microsoft Azure 클라우드 플랫폼과 관련된 보안 및 규정 준수에 대한 정보를 제공하는 것이다. 이 포털은 사용자에게 Azure의 보안 및 규정 준수 인증서, 감사 보고서, 규정 준수 문서 등의 자료를 제공하여 클라우드 리소스의 신뢰성과 안전성을 보장하고 조직의 요구 사항을 충족시킬 수 있도록 도와준다.
