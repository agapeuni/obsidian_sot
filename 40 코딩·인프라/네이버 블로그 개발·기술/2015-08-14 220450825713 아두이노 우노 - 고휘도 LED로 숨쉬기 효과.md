이번에는 White LED로 밝기를 조절하여 숨 쉬는 효과를 보여주는 간단한 실험입니다.

​

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다.

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 고휘도 White LED 2개

  * 270 옴 저항 2개 

  * 점퍼선 2개

![](https://postfiles.pstatic.net/20160506_98/agapeuni_1462521795950f1qUD_JPEG/20150814_080635.jpg?type=w80_blur)

​

브레드보드에 고휘도 LED를 적당한 간격으로 꼽아둡니다. 

![](https://postfiles.pstatic.net/20160506_225/agapeuni_1462521796231GHnOQ_JPEG/20150814_080857.jpg?type=w80_blur)

고휘도 LED의 아래쪽 캐소드(-)에 270옴 저항을 GND 접지와 연결합니다.

![](https://postfiles.pstatic.net/20160506_198/agapeuni_1462521796738zXwLg_JPEG/20150814_080951.jpg?type=w966)

**아두이노 우노**(Arduino UNO)의 3번과 5번 핀에 점퍼선을 연결합니다. 

아날로그 출력을 위해 물결무늬가 있는 핀에 연결해야 합니다.

![](https://postfiles.pstatic.net/20160506_279/agapeuni_1462521796926O05eo_JPEG/20150814_081020.jpg?type=w80_blur)

**아두이노 우노**(Arduino UNO)에 연결한 점퍼선을 고휘도 LED 위쪽 다리 애노드(+)에 연결합니다.

**▣ 소스코드 : led_breathe.ino**

숨쉬기를 표현하기 위해 breatheLights 배열을 선언하였습니다. fadeInOut(), breathe() 함수가 숨쉬기 효과를 표현하고 있습니다.

int LED_WHITE1 = 3; int LED_WHITE2 = 5; int fadeDelayTime = 5; ​ int breatheRepeat = 5; int breatheDelayTime = 40; int breatheLights[] = { 100, 90, 80, 70, 60, 50, 40, 30, 30, 30, 40, 50, 600, 70, 80, 90, 100, 110, 110, 110, 110 }; int breatheLightsAdd = 10; void setup() { pinMode(LED_WHITE1, OUTPUT); pinMode(LED_WHITE2, OUTPUT); } void loop() { fadeInOut(); breathe(); } void fadeInOut() { for (int pwm = 0; pwm < 256; pwm++) { analogWrite(LED_WHITE1, pwm); delay(fadeDelayTime); } for (int pwm = 255; pwm >= 0; pwm--) { analogWrite(LED_WHITE1, pwm); delay(fadeDelayTime); } } void breathe() { for (int i = 0; i < breatheRepeat; i++) { for (int j = 0; j < 20; j++) { analogWrite(LED_WHITE2, breatheLights[j] + breatheLightsAdd); delay(breatheDelayTime); } } analogWrite(LED_WHITE2, 0); }

숨쉬기 효과를 표현하고 있는 동영상입니다.
