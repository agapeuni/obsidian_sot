라즈베리 파이 프로토콜

라즈베리 파이(Raspberry Pi)는 다양한 프로토콜을 사용하여 통신하고 다른 기기와 상호 작용할 수 있습니다. 주요한 프로토콜은 다음과 같습니다.

​

1\. SSH (Secure Shell): SSH는 원격으로 라즈베리 파이에 접속하여 명령을 실행하고 파일을 전송하는 데 사용되는 프로토콜입니다. SSH는 암호화된 연결을 제공하여 보안적으로 통신할 수 있습니다.

​

2\. HTTP (Hypertext Transfer Protocol): HTTP는 웹 브라우저와 웹 서버 사이에서 정보를 전송하는 데 사용되는 프로토콜입니다. 라즈베리 파이는 Apache와 같은 웹 서버를 호스팅하여 웹 페이지나 웹 애플리케이션을 제공할 수 있습니다.

​

3\. FTP (File Transfer Protocol): FTP는 파일을 서버와 클라이언트 간에 전송하는 데 사용되는 프로토콜입니다. 라즈베리 파이에서 FTP 서버를 설정하면 파일 공유와 전송을 쉽게 할 수 있습니다.

​

4\. VNC (Virtual Network Computing): VNC는 원격 데스크톱 접속을 위한 프로토콜입니다. 라즈베리 파이에서 VNC 서버를 실행하면 다른 기기에서 라즈베리 파이의 데스크톱 화면에 접속하여 원격으로 제어할 수 있습니다.

​

5\. MQTT (Message Queuing Telemetry Transport): MQTT는 인터넷 연결된 장치들 간에 경량 메시지를 교환하기 위한 프로토콜입니다. 라즈베리 파이는 MQTT 프로토콜을 사용하여 센서 데이터의 수집 및 제어, IoT 프로젝트와의 통신 등에 활용할 수 있습니다.

​

6\. Bluetooth: 라즈베리 파이는 Bluetooth 프로토콜을 사용하여 다른 Bluetooth 장치와 통신할 수 있습니다. 이를 통해 블루투스 스피커, 키보드, 마우스 등과 연결하여 상호 작용할 수 있습니다.

* * *

이번에는 라즈베리 파이와 아두이노에서 사용하는 통신 프로토콜인 SPI, I2C, UART에 대해서 알아보겠습니다.

​

**SPI (Serial Peripheral Interface)**

직렬 주변기기 인터페이스 (Serial Peripheral Interfaces) 또는 SPI는 전이중 통신 모드로 그러니까 양방향으로 동작하는 동기식 직렬 데이터 연결 표준입니다. 장치들은 마스터와 슬레이브 모드로 통신하며 슬레이브 장치들은 개별 슬레이브 셀렉트 라인과 함께 동작할 수 있습니다.

![](https://postfiles.pstatic.net/20150801_108/agapeuni_1438416820205MK6WK_PNG/20150801_165351.png?type=w80_blur)

SCLK : 클럭. CLOCK (Clock Rising Edge, Clock Falling Edge)

MOSI : 마스터 출력 슬레이브 입력. Master Out Slave In (SDI)

MISO : 마스터 입력 슬레이브 출력. Master In Slave Out (SDO)

SS : 슬레이브 선택. Chip Select (CS)

​

​

*** SPI 통신 순서**

  1. 통신할 SPI 장치의 SS 핀 상태를 LOW 설정

  2. CLOCK 회선을 HIGH, LOW로 전환

  3. 매 CLOCK 주기에 MOSI에는 1비트 전송, MISO에는 1비트 수신

  4. 송수신이 완료될 때까지 계속 CLOCK 신호 보냄

  5. 송수신이 완료되면 CLOCK 회선의 HIGH, LOW 전환을 중지

  6. SPI 장치의 SS 핀 상태를 HIGH로 전환

​

**I2C (Inter-Integrated Circuit Interface)**

I²C(Inter-Integrated Circuit)는 1980년대 필립스가 개발하였고 Two-wire 프로토콜이라 불립니다. 직렬 컴퓨터 버스이며 여러 저속의 주변 기기를 연결하기 위해 사용됩니다. SPI와 같이 동기식 직렬 데이터 연결이다. I²C는 여러 개의 마스터와 슬레이브도 쉽게 지원이 가능합니다.

![](https://postfiles.pstatic.net/20150801_223/agapeuni_14384168204578ipkq_PNG/20150801_165401.png?type=w80_blur)

SCL : 클럭. CLOCK

SDA : 데이터. DATA

​

​

*** I2C 통신 순서**

  1. 마스터 시작비트 전송

  2. 슬레이브 7비트 주소 전송

  3. 읽기(1) / 쓰기(0) 명령 전송

  4. 슬레이브 ACK 비트 응답

  5. 1바이트 명령을 전송

  6. 1바이트 정보 수신

  7. 마스터 STOP 비트 전송

​

​

**UART (Universal Asynchronous Receiver Transmitter)**

UART는 비동기식이기 때문에 클럭이 필요하지 않고 병렬 데이터의 형태를 직렬 방식으로 전환하여 데이터를 전송합니다.

UART의 자료 형태나 전송 속도를 직접 구성할 수 있습니다. 

![](https://postfiles.pstatic.net/20150801_134/agapeuni_1438416820624KWfs6_PNG/20150801_165410.png?type=w80_blur)

TXD : Transmit

RXD : Receive
