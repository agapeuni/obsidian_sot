**1\. 개요**

ejs 뷰엔진은 확장자가 ejs인 파일을 사용한다. 이클립스에서 ejs 파일을 열게 되면 모두 검은색으로 표시되어 시인성이 떨어진다.

![](https://postfiles.pstatic.net/MjAyMzA5MDFfNzcg/MDAxNjkzNTM3MTA0NDY5.0T3iaWRV3mWGVfDsUMNgVAAN7FkdAGCZdrHPV5s8Jm8g.POGBJLieRIDNN4Q44291d0ROxV0BDv7c9fymJ5pJxlsg.PNG.agapeuni/img.png?type=w80_blur)

​

html 파일로 열게 되면 태그와 속성 그리고 텍스트 구분이 되어 코드를 보기 편하다.

![](https://postfiles.pstatic.net/MjAyMzA5MDFfMTYw/MDAxNjkzNTM3MTA5MzU1.eLgoMViKPgG8YkmcfzwDtiA6vHArLt_sANAax-QGGC0g.LRPDi9y3Ohfn_yhLFdQJ-ehUBAr8Oqpj-DVZXL9mBrIg.PNG.agapeuni/img.png?type=w80_blur)

​

​

**2\. 설치**

express 제너레이터가 생성한 app.js 코드에 다음과 같이 view engine setup 이 되어 있다.

view 폴더를 설정하고 view engine의 값을 ejs를 수정해 html로 변경한다. 그리고 엔진에 ejs.renderFile을 적용한다. 

​

(변경 전)

// view engine setup app.set('views', path.join(__dirname, 'views')); app.set('view engine', 'ejs');

_​_

(변경 후)

var ejs = require('ejs'); // view engine setup app.set('views', path.join(__dirname, 'views')); app.set('view engine', 'html'); app.engine('html', ejs.renderFile);

​

​

**3\. 예제**

잘 적용되는지 확인하기 위한 index.html 파일이다.
