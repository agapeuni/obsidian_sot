# 2014-07-15 220061532261 라즈베리 파이 - 파이 Model B+ 출시

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220061532261&categoryNo=982
- 게시일: 2014. 7. 15. 23:48

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMjg4/MDAxNzU4NDM3NDk1Mzkx.1gO4-xHooLENp74LHWyyCPsn00siBjgWEHBzjTuluJAg.bRtsxXxo5gpfMHZLHaHhgoKWmuvLemNsbjkEnKbly3Qg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(7\).png?type=w80_blur)

​

폭발적인 인기를 힘입어 2년 만에 라즈베리 파이의 새로운 제품이 출시되었습니다. 가격은 $35 그대로 유지하고서 BCM2835 프로세서에 RAM은 512MB은 동일한데 GPIO 핀은 40개로 늘리고 USB 포트도 4 개로 늘어났네요. 보드에 장착된 칩을 보면 SAMSUNG 마크가 선명히 눈에 들어옵니다.

![](https://postfiles.pstatic.net/20140715_213/agapeuni_1405435287059X13Wi_JPEG/rsz_b-.jpg?type=w80_blur)

[이미지출처] <http://www.raspberrypi.org/blog/>

​

​

모델 B의 26 핀에 대해 동일한 핀 아웃을 유지하면서 GPIO 헤더는 40 핀으로 늘렸고 USB 포트도 모델 B 기준으로 2개에서 4개로 늘어나서 키보드, 마우스에 다른 거 2개더 장착 가능하네요. SD 카드 소켓도 향상되었고 보다 전력 소비를 보다 낮게 줄였네요.

![](https://postfiles.pstatic.net/20140716_250/agapeuni_1405514048771yTs0J_JPEG/201407150003.jpg?type=w80_blur)

[이미지출처] <http://www.raspberrypi.org/blog/>

​

​

국내에도 판매가 되고 있습니다. 가격은 모델 B와 크게 다르지 않네요. 모델 B를 하나 구매하고 너무 마음에 들어서 바로 모델 B를 하나 더 구해했었는데... 이럴 줄 알았으면 조금 더 기다렸다가 요녀석을 구매할걸... 두 대로 서로 연동하는 실험을 해보려고 하나 더 구매했었는데 두고두고 아쉬움이 남네요.​
