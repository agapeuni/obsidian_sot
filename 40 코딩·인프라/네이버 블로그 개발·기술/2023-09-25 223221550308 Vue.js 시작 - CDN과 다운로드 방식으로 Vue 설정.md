**​**

**1\. 개요**

Vue.js를 손쉽게 설치하는 방법에는 CDN을 사용하는 방법과 파일을 다운로드하는 방법이 있다.

​

​

**2\. CDN 설치**

CDN(Content Delivery Network) 설치는 네트워크에 공유하고 있는 파일을 사용하는 방법이다.

​

학습이 목적인 경우는 아래의 코드로 최신 vue.js를 사용한다.

﻿<script src="https://cdn.jsdelivr.net/npm/vue/dist/vue.js"></script>﻿

​

운영 환경인 경우는 예상치 못하는 오류를 방지하기 위해 특정 버전을 명시하여 사용한다.

﻿<script src="https://cdn.jsdelivr.net/npm/vue@2.6.0"></script>﻿

​

**3\. Download 설치**

vue.js 사이트에서 다운로드 받아 <script> 태그에 추가하여 사용한다.

개발 중에는 vue.js를 사용하고 사이트 배포 시에는 vue.min.js를 사용한다.

​

vue.js (개발 버전) : 오류 메시지 및 디버그 모드가 가능하다.
