몽고디비 설치

라즈베리 파이에 몽고디비를 설치해 본다. 소스를 기반으로 설치를 진행하여서 완료하기까지 상당한 시간이 소요된다. 중간에 기다리지 말고 다른 일을 하거나 커피타임을 하면서 보내는 것이 정신건강에 좋다.

![](https://postfiles.pstatic.net/MjAyMzA2MDJfMTY5/MDAxNjg1NjQyNTcxMTE2.IhnsfxTQoeuxL-VjGXjh2duO_quej2dPNwVYys-m07Ig.1Q2cFFYVXSOGZMQ8pktqBHBxNnoIK2w7qMc3OsTiGbYg.PNG.agapeuni/img.png?type=w80_blur)

​

라즈베리 파이에 몽고디비를 설치하는 과정에서 입력한 명령어를 순서대로 정리해본다.

​

1\. 패키지를 업데이트하고 업그레이드

sudo apt-get update

sudo apt-get upgrade

​

2\. 라이브러리 설치

sudo apt-get install build-essential libboost-filesystem-dev libboost-program-options-dev libboost-system-dev libboost-thread-dev scons libboost-all-dev python-pymongo git

​

3\. 디폴트 폴더로 이동

cd ~

​

4\. 깃허브 저장소에서 다운로드

git clone <https://github.com/skrabban/mongo-nonx86>

​

5\. mongo 설치폴더로 경로이동

cd mongo-nonx86

​

6\. 경로에서 파이썬으로 작성된 구성 프로그램 실행

sudo scons

​

7\. 설치코드 실행

sudo scons --prefix=/opt/mongo install

​

8\. 사용자 및 그룹에 대한 사용 권한

sudo adduser --firstuid 100 --ingroup nogroup --shell /etc/false --disabled-password --gecos "" --no-create-home mongodb

​

9\. 로그 폴더 생성

sudo mkdir /var/log/mongodb/

​

10\. 로그 폴더 사용 권한

sudo chown mongodb:nogroup /var/log/mongodb/

​

11\. 상태 데이터 폴더 생성

sudo mkdir /var/lib/mongodb

​

12\. 폴더 사용 권한

sudo chown mongodb:nogroup /var/lib/mongodb

​

13\. init.d 스크립트 복사

sudo cp debian/init.d /etc/init.d/mongod

​

14\. config 파일 복사

sudo cp debian/mongodb.conf /etc/

​

15\. 링크생성

sudo ln -s /opt/mongo/bin/mongod /usr/bin/mongod

sudo ln -s /opt/mongo/bin/mongo /usr/bin/mongo

​

16\. 실행권한 부여

sudo chmod u+x /etc/init.d/mongod

sudo update-rc.d mongod defaults

​

17\. MongoDB 시작

sudo /etc/init.d/mongod start

​

18\. MongoDB Shell 시작

mongo

​

19\. init.d 스크립트 편집

sudo nano /etc/init.d/mongod

DAEMONUSER=${DAEMONUSER:-mongodb}

DAEMON_OPTS=${DAEMON_OPTS:-"--dbpath $DATA --logpath $LOGFILE run"}

DAEMON_OPTS="$DAEMON_OPTS --config $CONF --rest"

​

20\. MongoDb 재시작

sudo /etc/init.d/mongod restart
