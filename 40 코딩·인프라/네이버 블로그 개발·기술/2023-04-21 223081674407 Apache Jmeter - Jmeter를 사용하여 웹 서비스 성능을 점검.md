1\. Jmeter 개요

Apache JMeter는 자바로 개발된 100% 오픈 소스로 무료로 사용할 수 있다. 웹 애플리케이션 테스트용으로 설계되었지만 다른 테스트를 수행할 수 있도록 기능이 확장되었다. 준비된 Sampler를 통해 다양한 테스트를 수행할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMjc2/MDAxNjgyMDgyOTUxMDUy.-18FMZ4Rn0IPARGOwPrEsr52wCNFfp_dNrP4pIL7cwog.VbRSOEYzvABpU9E0RII9sPN7zcBKgINvuMoTyf0vt98g.PNG.agapeuni/img.png?type=w80_blur)

​

2\. Jmeter 설치

서비스 성능을 테스트해 보기 위해서 Apache Jmeter를 사용해 보자. 먼저 아래의 URL에서 JMeter를 다운로드한다.

<https://jmeter.apache.org/>

3\. Jmeter 사용

JMeter의 첫 화면은 다음과 같다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMTY3/MDAxNjgyMDgyOTg0NTQ2.MIIQd8LvxQbv_1Hh6vQWyRwJdDDT_KqvfPjGUjEWEUUg.x0LelnEnMkvkCoJvXatXEkYMnk92We1gPLtIMrZCVN8g.PNG.agapeuni/img.png?type=w80_blur)

​

**User Defined Variables**

공통으로 사용할 사용자 정의 변수를 정의할 수 있다. 테스트 서버의 이름과 포트 정보 등을 정의해 둔다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMjU0/MDAxNjgyMDgyOTg4ODI3.t72mTFkatBk_LvSR1n9_P3XA-qATRCQwWq5Uf0lGWsIg.2Qx3XDbFM1FrTuXn3f3jlKgVsONrZZpvSbhBqnvt5IMg.PNG.agapeuni/img.png?type=w80_blur)

​

**Thread Group**

테스트를 수행하기 위한 Thread Group을 생성한다. 테스트를 하기 위해 최소한 하나 이상의 스레드 그룹이 필요하다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMTQg/MDAxNjgyMDgyOTkzNTY0.vNcVVoAm-hMddrtQvNSVlok0uiK1Q8AqItLTluyNip8g.SY3-1OxNkSQ8ge3yYQ80l5n8SjMD2UtP16_HfvdPPcIg.PNG.agapeuni/img.png?type=w80_blur)

​

Thread Group의 기본 화면이다.. Number os Threads (users)는 스레드 수를 나타내며 로드테스트를 수행하는 사용자로 간주할 수 있다. Ramp-Up Period (in seconds)는 스레드 간의 수행 시간 간격이고 Loop Count는 반복 횟수이다. Infinite가 체크되면 무효화된다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMTI5/MDAxNjgyMDgyOTk3Mjg1.LQGuQOoq2XowbrRxdv_wTh6QRiMU0S5I1RvkfWPRQYYg.JDxc-K9jynHyrWR5tj-DPZ5dgTwwYZG0V1-179D8oVIg.PNG.agapeuni/img.png?type=w80_blur)

​

**Number of Threads (users)**

동시 접속자 수를 나타내는 "Number of Threads (users)"의 값을 20으로 하였고 Loop Count는 정의한 변수를 사용했다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMTg2/MDAxNjgyMDgzMDAwNTg4.3xZJbey7cl3kBAJyki55mo0DWOEkZIn0YrlewUfdhzYg._FaiGvYiWlnKhq4uUFMBhQU9b2FtTJIsq1g9l_2QjVog.PNG.agapeuni/img.png?type=w80_blur)

​

**HTTP Request**

다음의 화면과 같이 Sampler에서 HTTP Request를 생성한다. Sampler는 아래의 화면과 같이 테스트 서버에 요청하는 방식을 다양하게 선택할 수 있다. 주로 HTTP 요청을 많이 사용한다.

​

다운로드된 ZIP 파일을 특정 폴더에 압축 해제를 하고서 bin 폴더에 있는 jmeter.bat를 실행하면 JMeter가 기동 된다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMjgy/MDAxNjgyMDgzMDA0OTk3._KaYOHHnapWKiMq-0l_sqDg-lkuCAHsIOXpTpkboBeIg.kiXAxVzR9xtpjmBNVNmo5euh85EwcfSlEg4mvvT_PAIg.PNG.agapeuni/img.png?type=w80_blur)

​

User 목록을 테스트하기 위한 HTTP Request로 미리 정의한 Server Name을 입력하고 Path에 "/com/userList"를 입력한다. 요청 방식에 따라 GET과 POST를 선택할 수 있다. 참고로 테스트를 수행한 주소는 <http://localhost/com/userList> 이다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMjAg/MDAxNjgyMDgzMDA5NjAx.Qt914KXE_lfxLuyIP47KyMbT-5RtNrnUy5rpwY3gXk0g.wxDsgEwj4Y2I7PZujpWzIGrg_YqKLNy8-wAN2iI0VR8g.PNG.agapeuni/img.png?type=w80_blur)

​

Code 목록을 테스트하기 위한 HTTP Request로 정의한 Server Name을 입력하고 Path에 "/com/codeList"를 입력한다.

테스트 주소 : <http://localhost/com/codeList>

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMjMy/MDAxNjgyMDgzMDE2NTc2.4FuD-9SucRR1nk3rRzQRs6KWnLa_c93cKoQ3WKh__k0g.fV00WlwowFh81SPk0NZOYT9zxcrJrgMIFoOA-hemQgkg.PNG.agapeuni/img.png?type=w80_blur)

**Summary Report**

자주 사용하는 3개(Graph Results, View Results in Table, Summery Report)를 등록하였다. 

Summary Report는 다양한 결괏값을 그리드 형태로 표시해 준다.

​

# Sample : 서버 요청 횟수

Average : 평균 응답시간 (ms)

Min : 최소 응답시간 (ms)

Max : 최대 응답시간 (ms)

Sts. Dev. : 표준편차

Error % : 에러율

Throughput : 처리량

KB/sec : 초당 처리 KB

Avg. Bytes : 평균 Bytes

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMTU4/MDAxNjgyMDgzMDI1MjIw.qWixu_66mHfj2sSoPI_FkW7FagZLmRl7AkYvF9n-1ecg.VxtWhB2OgeJYVRv90M58TCN2oIEnxsU3aR2uXFqztxMg.PNG.agapeuni/img.png?type=w80_blur)

​

툴박스에 보이는 Start 버튼을 클릭하면 서버로 설정한 정보에 따라 요청을 보낸다. 

Console 화면을 보면 보면 무수히 많은 로그가 출력된다.

![](https://postfiles.pstatic.net/MjAyMzA0MjFfMTY1/MDAxNjgyMDgzMDU0MzQ4.S0__9hCQhT0xxzJN05o4BxharerPmpn9P9MNj1w7M4Ig.W4vmMYU4MQ7k5PQC8u_c5CDaEFq6mYBr8JxkFhKQNEIg.PNG.agapeuni/img.png?type=w80_blur)
