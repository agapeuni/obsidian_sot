라즈베리 파이에 설치되어 있는 Python 2.7을 삭제하고 3.9를 설치한다.

​

python 2.7을 삭제하려고 아래의 명령어를 입력했는데 관련된 패키지가 상당히 많은지 지우는데 시간이 좀 걸린다.

> sudo apt autoremove python2.7

![](https://postfiles.pstatic.net/MjAyMDExMDVfMjk5/MDAxNjA0NTA3NjA3ODI1.7ygBQWXczxdsmAkh-bM-D8rhVzzwD7lCosk414Pq-S0g.zwboYtK5I6DLtuqjH3d5oDITa_o-9rmpEvwz1gRS5c4g.PNG.agapeuni/image.png?type=w80_blur)

​

그리고 나서 아래의 명령어로 python3도 삭제하고 재부팅을 한번 한다.

> sudo apt autoremove python3

> sudo reboot

![](https://postfiles.pstatic.net/MjAyMDExMDVfMjM4/MDAxNjA0NTA3ODAzMzk5.uBCIm2M46pGkRwfaB6wc-wQ27iLrDBPr2b6XGXhoRkcg.OMOLVFKlzjQ_Zcv-7mKESixoXY7JpbC69_UKeo0g4tAg.PNG.agapeuni/image.png?type=w80_blur)

​

아래의 명령어로 Python 3.9 설치파일을 다운로드 받아 압축을 해제한다.

> wget <https://www.python.org/ftp/python/3.9.0/Python-3.9.0.tgz>

> sudo tar zxf Python-3.9.0.tgz

![](https://postfiles.pstatic.net/MjAyMDExMDVfMTM2/MDAxNjA0NTA4NzA1MDE0.WmoKAghDTbGPqlAjqNhGmsXJ694BwfuveCjHBSuJVF4g.wnhaKLwlbURgY7VNywB18lJ3nCptXYhDyCaTdW9SfJ0g.PNG.agapeuni/SE-d1186acf-d544-40bd-afd4-0e63a07c5980.png?type=w80_blur)

​

> cd Python-3.9.0/

> sudo ./configure --enable-optimizations

![](https://postfiles.pstatic.net/MjAyMDExMDVfMTk4/MDAxNjA0NTA4NjY1OTc5.Rc22m7HOWFKglNVyB3OR72txBtOQjeugg91dUNjpH2Ag.BoFYPc0JxqrPkwERfHks7qPsdBPiVHL0A-GkZxA9IGQg.PNG.agapeuni/image.png?type=w80_blur)

​

컴파일과 설치를 진행합니다.

> sudo make -j 4

> sudo make altinstall

![](https://postfiles.pstatic.net/MjAyMDExMDVfOTgg/MDAxNjA0NTA4OTE1NDc5.ulsURyt0ajszmCjVEwia4Inie78AUa0G5EKmBLclxJkg.YMcmlEqphax1l0cc1QFzHW86PNbxtk5qVJtI1HgqdLMg.PNG.agapeuni/image.png?type=w80_blur)

​

Python 3.9가 잘 설치 되었습니다.

![](https://postfiles.pstatic.net/MjAyMDExMDVfMjM3/MDAxNjA0NTExNTMzMzU1.Ay_FCSTIdGdx4hcgquMuvmjuYh8w7fQyWVnGXWv7qGgg.dLXXZlu3NXtGG7XQ4CuNCQTtWEPGMqpRYiBECNCb6OEg.PNG.agapeuni/image.png?type=w80_blur)

​

사용자 홈 디렉토리에 위치한 .bashrc 파일의 끝에 다음의 설정을 입력한다.

**$ sudo nano .bashrc**

alias python=/usr/local/bin/python3.9
