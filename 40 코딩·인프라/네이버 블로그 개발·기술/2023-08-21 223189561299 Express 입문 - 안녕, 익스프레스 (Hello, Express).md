# 2023-08-21 223189561299 Express 입문 - 안녕, 익스프레스 (Hello, Express)

- 게시일: 2023. 8. 21. 19:00

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTJfMjcg/MDAxNzQ0NDY1NDAyODM4.sSKOV2Qvn2HTBwJzecJ3w71e6PwoObaD53dHu1IK7Psg.JPxoxbFy9CeTIsoYI8V6ePckDHHrk38KfO1B9qZgIlwg.PNG/Express-001.png?type=w80_blur)

​

M**E** AN Stack에서 **E** 에 해당하는 Express를 시작해 본다. Express는 Node.js를 위한 웹 프레임워크로 빠르고 개방적이다. Express로 웹 애플리케이션을 만들게 되면, 프로젝트를 좀 더 발전시켜 다양한 기능을 추가할 수 있다. Express에서 제공하는 미들웨어 기능을 사용해 요청 처리 흐름을 확장할 수 있다.

​

미들웨어는 요청과 응답 사이에서 동작하는 함수로, 요청 객체(req), 응답 객체(res), 그리고 다음 미들웨어 함수를 호출할 수 있는 next() 함수를 인자로 받는다. 미들웨어는 특정 경로에만 적용하거나, 모든 경로에 적용할 수 있다.

​

​

Node.js Express Project를 생성한다.

​

프로젝트 폴더 HelloExpress에 app.js 파일을 작성한다. 

포트를 3000으로 하고 "/" 요청이 오면 "Hello World!"를 출력하는 코드이다.

const express = require('express') const app = express() const port = 3000 app.get('/', (req, res) => { res.send('Hello World!') }) app.listen(port, () => { console.log(`Example app listening on port ${port}`) })

​

미들웨어는 다양한 역할을 할 수 있으며, Express 애플리케이션의 유연성을 높여준다. 

​

주로 다음과 같은 용도로 사용된다.

  * **로그 기록** : 서버로 들어오는 요청에 대한 로그를 남긴다.

  * **인증 및 권한 부여** : 사용자의 요청이 적절한 권한을 가지고 있는지 확인한다.

  * **오류 처리** : 요청 처리 중 발생한 오류를 처리하여 클라이언트에 적절한 응답을 보낸다.

  * **요청 데이터 처리** : 클라이언트로부터 전송된 데이터를 파싱하거나 검증하는 작업을 한다.
