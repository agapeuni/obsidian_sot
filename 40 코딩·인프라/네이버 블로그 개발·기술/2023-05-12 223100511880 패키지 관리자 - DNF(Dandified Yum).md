1\. DNF(Dandified Yum) 개요

DNF(Dandified Yum)는 Fedora, CentOS 8 이후 버전에서 사용되는 RPM 기반 리눅스 패키지 관리 도구이다. Fedora 18에 처음 도입되었고 Fedora 22 이후에는 YUM을 대신하여 기본 패키지 관리자가 되었다. YUM 패키지 관리자와 비교해 보면 DNF는 최적화된 메모리 집약적 작업, 패키지 의존성 기술을 적용하여 자동으로 해결하였다. 기존의 Yum 패키지 관리자보다 빠르고 안정성이 높으며, 명령어 사용이 더욱 직관적이다.

﻿DNF 패키지 관리자는 다음과 같은 명령어를 사용한다. \- 패키지 검색 : `dnf search [검색어]` : 패키지 검색 \- 패키지 정보 : `dnf info [패키지명]` : 패키지 정보 확인 \- 패키지 설치 : `dnf install [패키지명]` : 패키지 설치 \- 패키지 업데이트 : `dnf update [패키지명]` : 패키지 업데이트 \- 패키지 삭제 : `dnf remove [패키지명]` : 패키지 삭제 \- 패키지 의존성 검사 : `dnf check [패키지명]` : 패키지 의존성 검사
