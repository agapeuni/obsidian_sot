# 2014-11-29 220195844338 라즈베리 파이 - 명령어로 시스템정보 확인

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTA4/MDAxNzU4NDM4MDc2MzYw.FBQlqfQ8j78YAIQ6nX8BD3BTjMKXcxdFlx8yd5WcnIEg.VhoXhfGPfZAa-0TLiFXHUpblbnwsEs3ITZ2M1tbArKEg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001.png?type=w80_blur)

**​**

이번에는 간단한 리눅스 명령어를 사용하여 라즈베리 파이 시스템정보를 확인해 보겠습니다. 새로운 프로젝트 진행 및 자격시험 준비로 인해 한동안**라즈베리 파이(Raspberry Pi)** 를 손놓고 있다가 구석에 있던 파이 하나 꺼내서 워밍업으로 여러가지 리눅스 명령어를 연습해 보려고 합니다.

먼저 아래의 명령어로 Upgrade 설치 패키지를 확인해 봅시다. 

설치할 패키지가 존재하면 y 를 입력하고 엔터를 누르면 됩니다.

**$ sudo apt-get update**

**$ sudo apt-get upgrade**

![](https://postfiles.pstatic.net/20150605_251/agapeuni_1433464791958Ykfzr_PNG/20141129_223216.png?type=w966)

**cat /proc/cpuinfo** 와 **cat /proc/version** 로 CPU 정보와 리눅스 버전을 알 수 있습니다. 

**uname -a** 명령어를 사용해도 Linux Version 을 확인할 수 있습니다. 

**​**

**$ cat /proc/cpuinfo**

**$ cat /proc/version**

**​**

CPU는 ARMv6 rev 7으로 표시됩니다. 그리고 Linux Version은 3.12.28이네요.

![](https://postfiles.pstatic.net/20150605_245/agapeuni_1433464801086l5VKJ_PNG/20141129_224632.png?type=w966)

**free -h** 명령어로 메모리 정보를 확인하고 **df -h** 명령어로 메모리 정보를 확인합니다. 

메모리는 전체 373M 에서 120M 사용중이고 253M 여유가 있고 512M 메모리에서 128M 는 GPU에 할당하였습니다. 

디스크는 15G 에서 2.5G 사용중이고 12G 여유가 있어서 디스크 공간은 충분해 보입니다.

**​**

**$ free -h**

​

![](https://postfiles.pstatic.net/20150605_136/agapeuni_1433464809334eJfQ2_PNG/20141129_224126.png?type=w966)

메모리에 대해서 보다 자세한 정보를 보려면 **cat /proc/meminfo** 를 입력하면 됩니다. 

**$ cat /proc/meminfo**

​

![](https://postfiles.pstatic.net/20150605_233/agapeuni_1433464817757rf7ea_PNG/20141129_225303.png?type=w966)

​

실행중인 프로세스를 확인할 때는 **pstree** 명령어를 입력합니다. 실행 중인 프로세스를 트리로 표시해줍니다. 

**$ pstree**
