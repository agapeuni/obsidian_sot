1\. Jakarta Project 개요

아파치 자카르타 프로젝트(Apache Jakarta Project)는 아파치 프로젝트 중 자바 기반의 오픈소스 솔루션을 만들고 유지 배포하는 프로젝트다. 잘 알고 있는 톰캣이나 스트러츠 같은 것들이 자카르타 프로젝트 제품들이다. 아파치 자카르타 프로젝트는 자바를 이용한 기업용 애플리케이션을 구축하기 위한 강력하고 신뢰성 있는 소프트웨어 솔루션을 제공하기 위한 오픈 소스 프로젝트이다. 이 프로젝트는 원래 아파치 소프트웨어 재단의 톰캣 프로젝트의 하위 프로젝트로 시작되었으며 Tomcat 5로 불리기도 했다. 이 프로젝트는 Java Servlet 2.4 및 JavaServer Pages (JSP) 2.0 사양의 참조 구현을 제공하는 것을 목표로 했다.

​

자카르타 프로젝트는 Jakarta EE Working Group이 관리하며, 이 그룹은 Jakarta EE 및 관련 기술의 개발과 진화에 헌신하는 커뮤니티 기반 개발 그룹이다. 이 프로젝트는 개방성, 협력 및 커뮤니티 참여에 중점을 둔 강력한 포커스를 가지고 있으며, 전 세계 개발자로부터 기여를 환영한다.

​

2\. Jakarta Project 기술

자카르타 프로젝트는 시간이 지남에 따라 진화하면서 다음과 같은 기업용 애플리케이션 구축을 위한 다양한 기술을 포함하게 되었다.

\- Jakarta EE는 자바에서 기업용 애플리케이션을 구축하기 위한 사양 세트.

\- Jakarta Persistence는 자바에서 객체-관계 매핑을 위한 사양.

\- Jakarta RESTful Web Services는 자바에서 RESTful 웹 서비스를 구축하기 위한 사양.

\- Jakarta Messaging(이전에는 Java Message Service 또는 JMS로 알려졌음)는 자바에서 애플리케이션 간 메시징을 위한 사양.

\- Jakarta Security는 자바에서 보안 애플리케이션을 구축하기 위한 일련의 API를 제공.

​

3\. Jakarta 제품 분류

Jakarta 제품은 일반적으로 3개의 분류로 나뉘어 있다.

1) 라이브러리, 도구, API

2) 프레임워크과 엔진

3) 서버 어플리케이션

**1) 라이브러리, 도구, API**  
---  
[BCEL](http://jakarta.apache-korea.org/bcel/index.html) |  The Byte Code Engineering 라이브러리는 (바이너리) 자바 클래스 파일들(확장자가 .class인)을 분석하고,만들고,조작하기 편리하게 하기 위해서 만들어졌다.  
[BSF](http://jakarta.apache-korea.org/bsf/index.html) |  빈 스크립팅 프레임워크(BSF)는 자바 어플리케이션 내에서 스크립팅 언어 지원과, 스크립팅 언어로부터 자바 객체와 메소드를 접근할 수 있도록 하는 자바 클래스 모음이다.  
[Commons](http://jakarta.apache-korea.org/commons/index.html) |  많은 자카르타 부속 프로젝트들에서 유용한 작은 크기의, 재사용가능한, 코드 컴퍼넌트들의 저장소이다.  
[ECS](http://jakarta.apache-korea.org/ecs/index.html) |  The Element Construction Set은 다양한 마크업 언어들을 위한 요소들을 생성하기 위한 자바API이며 HTML 4.0과 XML을 기본 지원한다.  
[JMeter](http://jakarta.apache-korea.org/jmeter/index.html) |  테스트 기능을 수행하고 성능을 측정하기위해 디자인된 순수 자바 데스크탑 애플리케이션이다.  
[ORO](http://jakarta.apache-korea.org/oro/index.html) |  파일이름의 치환, 분할, 필터링 등을 수행하기 위한 Perl5 호환 정규식, AWK와 같은 정규식, glob 표현, 그리고 유틸리티 클래스들을 제공하는 텍스트 처리 자바 클래스들의 집합.  
[POI](http://jakarta.apache-korea.org/poi/index.html) |  자바만을 이용하여(native api의 도움을 받지 않고) OLE 2 Compound 문서 양식에 기반을 둔 파일을 생성하고, 읽고, 쓰기 위한 API의 집합. 현재는 OLE 2 Compound 문서 양식과 마이크로소프트 엑셀(XLS) 파일 형식만 제공된다.  
[Regexp](http://jakarta.apache-korea.org/regexp/index.html) |  100% 순수 자바 정규식 패키지.  
[Taglibs](http://jakarta.apache-korea.org/taglibs/index.html) |  웹 어플리케이션들을 만드는 데 유용한 JSP용 사용자정의 태그 라이브러리들의 모음이다  
[Watchdog](http://jakarta.apache-korea.org/watchdog/index.html) |  서블릿/JSP 컨테이너의 구현이 스펙에 맞는지를 체크하는 호환성 검사  
**2) 프레임워크과 엔진**  
[Cactus](http://jakarta.apache-korea.org/cactus/index.html) |  Cactus(선인장)는 단위테스트를 필요로하는 서버측 자바코드를 위한 간단한 테스트 프레임웍이다.  
[HiveMind](http://jakarta.apache-korea.org/hivemind/index.html) |  HiveMind는 서비스와 환경설정 마이크로커널이다; 단순한 자바 객체와 인터페이스로부터 복잡한 어플리케이션을 만들기 위한 프레임웍이다.  
[Lucene](http://jakarta.apache-korea.org/lucene/index.html) |  Jakarta Lucene는 자바로 작성한 고성능의 통합 텍스트 검색 엔진이다. 이것은 full-text 검색을 필요로 하는 거의 모든 애플리케이션에 적합한 기술이다.  
[Tapestry](http://jakarta.apache-korea.org/tapestry/index.html) |  Tapestry는 고도로 재사용 가능하고 매우 순수하게 모델-뷰-컨트롤러 패턴으로 구성된 컴포넌트들에 기반한 웹 어플리케이션 프레임웍이다.  
[Turbine](http://jakarta.apache-korea.org/turbine/index.html) |  Velocity 또는 JSP와 함께 웹어플리케이션을 만드는 모델-뷰-컨트롤러 프레임웍이다.  
[Velocity](http://jakarta.apache-korea.org/velocity/index.html) |  Velocity는 일반적인 용도의 자바 기반의 템플릿(template) 엔진이다.  
**3) 서버 어플리케이션**  
[Alexandria](http://jakarta.apache-korea.org/alexandria/index.html) |  Alexandria는 오픈 소스 프로젝트에서 사용되는 CVS/Javadoc/Source code/Documentation 관리 시스템이다.  
[Slide](http://jakarta.apache-korea.org/slide/index.html) |  WebDAV를 활용한 컨텐츠 관리 시스템(CMS)  
[Tomcat](http://jakarta.apache-korea.org/tomcat/index.html) |  Tomcat 은 서블릿과 JSP 기술을 구현한 공식적인 참조 구현(RI:Reference Implementation)이다.  
  
4\. Jakarta 프로젝트들

[Apache Ant Project](http://jakarta.apache.org/#ant) (아파치 앤트 프로젝트) - 자바기반의 빌트툴

[Apache Avalon Project](http://jakarta.apache.org/#avalon) (아파치 아바론 프로젝트) - 컴포넌트지향 프로그래밍 프로젝트

[Apache Cocoon Project](http://jakarta.apache.org/#cocoon) (아파치 코쿤 프로젝트) - XML과 XSLT기술을 사용한 XML 프레임워크

[Apache DB Project](http://jakarta.apache.org/#db) (아파치 DB 프로젝트) - 퍼시스턴스 레이어 및 객체/관계 매핑 도구

[Apache Excalibur Project](http://jakarta.apache.org/#excalibur) (아파치 엑스칼리버 프로젝트) - 포트리스라는 자바로 된 경량의 이식가능한 컨테이너

[Apache Geronimo Project](http://jakarta.apache.org/#geronimo) (아파치 제로니모 프로젝트) - J2EE 호환 컨테이너를 만들기 위해서 새롭게 노력하는 제품

[Apache Gump Project](http://jakarta.apache.org/#gump) (아파치 검프 프로젝트) - 지속적인 통합 Continuous Integration을 위한 도구

[Apache HTTP WebServer Project](http://jakarta.apache.org/#httpd) (아파치 HTTP 웹서버 프로젝트) - 고성능의 인정받은 오픈소스 HTTP 서버

[Apache Incubator Project](http://jakarta.apache.org/#incubator) (아파치 인큐베이터 프로젝트) - 코드베이스를 위한 진입로를 제공

[Apache James Project](http://jakarta.apache.org/#james) (아파치 제임스 프로젝트) - 자바로 만들어진 이메일/뉴스/메시징 서버

[Apache Logging Services Project](http://jakarta.apache.org/#logging) (아파치 로깅 서비스 프로젝트) - 자바용 로깅 라이브러리 프로젝트

[Apache Maven Project](http://jakarta.apache.org/#maven) (아파치 메이븐 프로젝트) - 프로젝트 객체 모델(POM)로 자바 프로젝트 관리 총괄 도구 

[Apache Portals Project](http://jakarta.apache.org/#portals) (아파치 포털 프로젝트) - 자바 포탈 시스템 및 차세대 엔터프라이즈 포탈

[Apache Struts Project](http://jakarta.apache.org/#struts) (아파치 스트러츠 포르젝트) - 웹 애플리케이션 제작용 모델-뷰-컨트롤러 프레임워크

[Apache WebServices Project](http://jakarta.apache.org/#ws) (아파치 웹서비스 프로젝트) - 웹서비스 지원을 목표로 만들어진 프로젝트

[Apache XML Project](http://jakarta.apache.org/#xml) (아파치 XML 프로젝트) - XML관련 활동을 지원하는 프로젝트 

[Apache XMLBeans Project](http://jakarta.apache.org/#xmlbeans) (아파치 XML빈즈 프로젝트) - XML 스키마 기반의 XML-자바 바인딩 도구
