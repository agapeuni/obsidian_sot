1\. 개요

웹 애플리케이션을 개발할 때 가장 기본이 되는 기능 중 하나는 브라우저를 통해 콘텐츠를 전달하는 것이다. 이를 위해 많은 개발자들이 Node.js를 활용하고 있다. Node.js는 빠르고 쉬우며, 확장 가능한 비동기 이벤트 기반의 JavaScript 런타임 환경으로, 서버 사이드 개발에서도 널리 사용되고 있다.

​

이번 글에서는 Node.js의 http 모듈을 이용하여 간단한 텍스트와 HTML 파일을 브라우저에 출력하는 기본적인 웹 서버를 구현해보자.

​

**2\. 사용 모듈 선언**

먼저, http 모듈과 파일 시스템에 접근하기 위한 fs 모듈을 불러온다. 이 두 모듈은 Node.js에서 기본으로 제공되며, 별도의 설치 없이 바로 사용할 수 있다.

var http = require('http'); var fs = require('fs');

**​**

**3\. HTTP 서버 생성**

http.createServer() 메서드를 사용하여 서버를 생성하고, 요청(request)과 응답(response)을 처리하는 콜백 함수를 등록한다. 이 서버는 127.0.0.1의 1337번 포트를 리스닝한다.

http.createServer(function(request, response) { …(중략)… }).listen(1337, '127.0.0.1');

**​**

**4\. 요청 정보 출력**

사용자가 요청한 URL, 요청 방식(method), 요청 헤더(header) 정보를 화면에 출력할 수 있도록 코드를 작성한다. 이를 통해 클라이언트의 요청 정보를 실시간으로 확인할 수 있다.

headers += "Request URL = " + request.url + "<br>"; headers += "Request type = " + request.method + "<br>"; headers += "Request headers = " + JSON.stringify(request.headers) + "<br>";

​

**5\. 요청 경로에 따른 파일 처리**

사용자가 /text 또는 /html 경로로 접근했을 때 각각 20-http.txt 또는 20-http.html 파일을 읽어서 응답 본문에 포함시킨다.

if (request.url == '/text') { fileData = fs.readFileSync('20-http.txt', 'utf8'); } if (request.url == '/html') { fileData = fs.readFileSync('20-http.html', 'utf8'); }

​

**6\. 전체 코드**

아래는 앞서 설명한 내용을 종합하여 작성한 전체 코드다.

var http = require('http'); var fs = require('fs'); http.createServer(function(request, response) { var fileData = ""; var headers = ""; headers += "Request URL = " + request.url + "<br>"; headers += "Request type = " + request.method + "<br>"; headers += "Request headers = " + JSON.stringify(request.headers) + "<br>"; if (request.url == '/text') { fileData = fs.readFileSync('20-http.txt', 'utf8'); } if (request.url == '/html') { fileData = fs.readFileSync('20-http.html', 'utf8'); } response.writeHead(200, { 'Content-Type' : 'text/html; charset=utf-8' }); response.write('<h1>Hello World</h1><br>'); response.write(headers); response.write('<hr>'); response.end("<br><br>===== fileData =====<br>" + fileData); }).listen(1337, '127.0.0.1'); console.log('http://127.0.0.1:1337/text'); console.log('http://127.0.0.1:1337/html');

**​**
