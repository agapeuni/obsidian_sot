라즈베리 파이 2에 우분투를 설치하였고 데이터베이스 서버로 사용하기 위해 MySQL을 설치합니다. 아래는 MySQL 설치 명령어입니다. 

**sudo apt-get install mysql-server**

참고로 아래의 명령어로 라즈비안에 다시 설치 (2020-09-19)

**sudo apt-get install mariadb-server**

![](https://postfiles.pstatic.net/MjAyMDA5MTlfMTg4/MDAxNjAwNDY4NzgyMjc2.j57hC0x2OxMZMkrtz_eK4z5iK7kjcXk41hhBp-NxhuQg.a0P-dnSLngUnACVwww0b_H1VZoDh9gOKOTbzJhy97rcg.PNG.agapeuni/SE-27cb65de-29c7-4364-924f-7ebad7a70a96.png?type=w80_blur)

설치에 걸리는 상황에 따라 다를 수 있는데 마음 편하게 커피 한잔하고 오면 완료됩니다.

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMTE4/MDAxNTkyNjU0MzcwMjIy.TkQA0L8slDJhLsX92evHZW7PNi9TYO3jezQZ-F1G6d4g.Dh_aV6m5UQ6G6ootrQ22xVbg1U_n7YGmxdcP953317gg.PNG.agapeuni/SE-f10ada20-f59c-491b-8de0-b79c9f73eeae.png?type=w80_blur)

​

MySQL 설치가 끝나면 아래의 명령어로 MySQL에 접속할 수 있습니다.

**sudo mysql -u root**

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMzkg/MDAxNTkyNjU0MzcwOTg3.-scxsx8Gy153ofqDvRt5l67IwZxv1RPsiIuPEn2G-L8g.FiF6LkY0P15W77XoTnp7eRQ7ng3HIwW-WVSnU4JiBKUg.PNG.agapeuni/SE-49112275-a415-4349-991f-7fca689f20d1.png?type=w80_blur)

​

MySQL에 연결이 되면 다음의 명령어를 차례대로 입력하여 기존의 root 사용자의 암호를 초기화합니다.

​

> use mysql;

> update user set authentication_string=password('1234') where user='root';

​

다음의 명령어로 'root'@'%'의 레코드를 추가로 생성합니다.

**> grant all privileges on *.* to 'root'@'%' identified by '1234';**

​

변경사항을 적용하기 위해 다음의 명령어를 실행합니다.

**> flush privileges;**

**​**

**참고로 암호를 바꾸려고 할 때 MySQL 버전의 문제로 오류가 발생하는 경우에는 아래의 명령어로 비번을 바꾼다.**

**> set password for 'root'@'localhost' = password('1234');**

**​**

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMjkw/MDAxNTkyNjU0MzcxOTYw.HPNhnEULuCfBFJ3_1LdwLI64Fa8Uc-vUtTA4FEjHVjsg.mZ_X-Lsz4HbcbapyUhLBxg-gUBX6nMta5-JDoQHeQj0g.PNG.agapeuni/SE-2ea5216a-0236-49d1-b185-b2eda697fe8e.png?type=w80_blur)

​

mysql 데이터베이스의 user 테이블을 보면 root 사용자의 localhost의 plugin이 auth_socket으로 되어 있습니다.

> select user, host, plugin from mysql.user;

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMTYy/MDAxNTkyNjU0MzcyNzU3.8wL3nKLCI65cg7zl9xlLHP2unCt8ck6dhVmhEuoH4b0g.G56aLR-wsI-W2TFIfJJBKkvUzC7q1NVxUkMVZ_qu2V8g.PNG.agapeuni/SE-3b24ee8f-997f-4d91-8493-31e5d34ee6e8.png?type=w80_blur)

​

​

해당 레코드의 plugin을 'mysql_native_password'  로 변경합니다.

> update mysql.user

set plugin = 'mysql_native_password'

where user = 'root' and host ='localhost';

​

변경사항을 적용하기 위해 다음의 명령어를 실행합니다.

**> flush privileges;****​**

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMTQy/MDAxNTkyNjU0MzczNjA3.HNwXbsnjZGyHeAjHjJjYBHHNA95qJSlNgLov8o1V750g.LN1mGXJZ-tZH4b9XgTT7q82T6cQxygYGVV5v2pQfnCIg.PNG.agapeuni/SE-0ee24408-0581-4b19-be8f-dd83199a7254.png?type=w80_blur)

**​**

**​**

**이제는 아래의 명령으로 MySQL에 연결할 수 있습니다.**

> mysql -u root -p

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMjE1/MDAxNTkyNjU0Mzc0MzI3.Sd4v1xiDbGdgNjrKoFkA0qbYS8VKqM9xul5zxxWDXuQg.7SRMkTjCs6r_Eg_z2i5SDd0Gd6-S6ycyc5k2jaTc0M4g.PNG.agapeuni/SE-4e00eb23-d072-4e97-b044-6e483ad52eb3.png?type=w80_blur)

**​**

다른 시스템에서도 접근할 수 있게 아래의 파일을 수정하였다.

$ sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf 

​

그리고 bind-address 부분을 주석 처리하였다.

# bind-address = 127.0.0.1

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMjY1/MDAxNTkyNjU0MzYxNzM0.06Ce9wNRA_UT3vQkqXBlshzhPye6IU4wS26gB-d-O30g.lgMjIfMlHd0M7KXGZvOFygXzRSWARrWTCoiT2CSiXd0g.PNG.agapeuni/SE-0a016ae2-004e-4e22-9e9a-032ac1a89b65.png?type=w80_blur)

​

참고로 라즈비안에 MariaDB를 설치한 경우는 아래의 경로에 위치한 파일을 열어서 bind adress를 주석처리

**$ sudo nano /etc/mysql/mariadb.conf.d/50-server.cnf**

​

MySQL 서비스를 재시작 합니다. 시스템을 재부팅해도 괜찮습니다. 

**$ sudo systemctl stop mysql.service**

**$ sudo systemctl start mysql.service**

​

또는

**$ sudo systemctl restart mysql.service**

**​**

아니면 

**$ sudo reboot**

![](https://postfiles.pstatic.net/MjAyMDA2MjBfMjIg/MDAxNTkyNjU0Mzc1ODQ3.Uq5fiiiMmLVoRxnGVhUAPX9RjooznY6jyEv5A-KDYeAg.EJlMTTQHqBAALWZzx_1KcOIV-SHcrQ6K6-oKT4LnDvcg.PNG.agapeuni/SE-2f15c545-02ba-416f-ac31-fe5ab070c01f.png?type=w80_blur)

​

참고로 아래의 명령어는 mysql.service의 상태를 확인합니다.

$ sudo systemctl status mysql.service

​

**​**

혹시나 해서 MySQL이 사용하고 있는 3306 포트에 대해서 INPUT/OUTPUT 방화벽을 설정해 보았다. 

**$ sudo iptables -A INPUT -p tcp --dport 3306 -j ACCEPT**

**$ sudo iptables -A OUTPUT -p tcp --dport 3306 -j ACCEPT**

**$ sudo iptables-save**
