​

XHTML 1.0 Transitional은 HTML 4.01의 유연함과 XML의 엄격한 구문 규칙을 결합한 웹 페이지 마크업 언어이다. 이 형식은 웹 페이지 작성 시 HTML과 XML 규칙을 따르며, 이전의 HTML 문서와의 호환성을 유지하는 동시에 보다 체계적인 문서 구조를 제공한다. 

​

XHTML 1.0 Transitional은 XHTML(eXtensible HyperText Markup Language)의 버전 중 하나로, 웹 페이지를 작성하는 데 사용되는 엄격한 문법을 가지고 있다. 이 형식은 HTML 4.01과 호환성을 유지하면서도 XML의 엄격한 규칙을 따르는 것이 특징이다. XHTML 1.0 Transitional은 HTML과 XML의 장점을 결합하여 웹 페이지를 작성하는 데 사용된다. 이 버전은 이전 HTML 문서를 XHTML로 전환하거나 새로운 웹 페이지를 작성하는 데 유용하다.

​

HTML과 XHTML의 차이점은 태그뿐 아니라 코드 작성 규칙에도 있다. HTML로 작업할 때 브라우저는 속성이 올바르게 지정되지 않았다는 사실뿐만 아니라 구조의 다양한 사소한 결함과 결점을 인식하지 못한다. DOCTYPE에 XHTML 1.0 Strict로 정의하면 체계적인 문서로 유지할 수 있는데 많은 사람들이 XHTML 1.0 Transitional을 사용한다. 체계적인 문서도 중요하지만 브라우저 호환성을 보장해 주기 위해 "Transitional"을 선택한다. 

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> <html xmlns="http://www.w3.org/1999/xhtml" xml:lang="ko" lang="ko"> <head> <meta http-equiv="Content-Type" content="text/html; charset=EUC-KR" /> <title>XHTML 1.0 Transitional</title> </head> <body> <h1>환영합니다</h1> <p>XHTML 1.0 Transitional을 사용하여 페이지를 작성하고 있습니다.</p> </body> </html>

XHTML 1.0 Transitional을 사용하면 태그와 속성에 좀 더 엄격한 규칙이 적용되지만, HTML에서 지원하던 비표준 태그들도 일정 부분 허용되어 다양한 브라우저 환경에서 호환성이 보장된다. 예를 들어, <center>, <u>, <strike> 같은 태그도 Transitional 버전에서는 사용할 수 있다.

​

참고로 XHTML 1.0 Strict에서는 <center>, <u>, <strike>, <applet> 등의 태그를 사용하지 못한다. 하지만 여전히 많은 브라우저에서 위 태그들을 허용하고 있기 때문에 현재의 브라우저 호환성을 위해서는 XHTML 1.0 Transitional로 DOCTYPE를 규정하는 것이 어쩌면 당연하다고 할 수 있겠다. 

<?xml version="1.0" encoding="EUC-KR" ?> <!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> <html xmlns="http://www.w3.org/1999/xhtml" xml:lang="ko" lang="ko"> <head> <meta http-equiv="Content-Type" content="text/html; charset=EUC-KR" /> <title>XHTML 1.0 Transitional</title> <script type="text/javascript" src="/blackbird.js"></script> <link rel="stylesheet" type="text/css" href="/blackbird.css" /> <script language="javascript"> log.debug("this is a debug message"); log.info("this is a info message"); log.warn("this is a warn message"); log.error("this is a error message"); log.profile("this is an profile message"); </script> </head> <body> <h1>XHTML 1.0 Transitional</h1> <form name="frm" action="/select.do" method="post"> <table> <tr> <th>select:</th> <td><select name="sel"> <option value="o1">option 1</option> <option value="o1">option 2</option> <option value="o1">option 3</option> </select></td> </tr> <tr> <th>radio:</th> <td><input type="radio" name="rdo" value="radio 1" />radio 1<br /> <input type="radio" name="rdo" value="radio 2" checked="checked" />radio 2<br /> </td> </tr> <tr> <th>checkbox:</th> <td><input type="checkbox" name="chk" value="checkbox 1" />checkbox 1 <br /> <input type="checkbox" name="chk" value="checkbox 2" checked="checked" />checkbox 2 <br /> </tr> <tr> <th>text:</th> <td><input type="text" name="txt" id="txt" value="" /></td> </tr> <tr> <th>textarea:</th> <td><textarea name="txa" id="txa" rows="10" cols="48"></textarea> </td> </tr> <tr> <th>submit:</th> <td><input type="submit" value="submit" /></td> </tr> </table> </form> </body> </html>
