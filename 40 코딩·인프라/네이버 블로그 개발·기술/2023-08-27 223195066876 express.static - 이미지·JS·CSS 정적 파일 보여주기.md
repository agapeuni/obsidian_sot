**1\. 개요**

express.static 미들웨어 함수를 사용하여 public 폴더에 포함된 이미지, CSS 및 자바스크립트와 같은 정적파일을 서비스할 수 있다. 정적파일이 포함된 폴더의 이름을 express.static() 함수에 전달하면 그 폴더의 파일들을 / 경로 아래로 서비스할 수 있다. 

​

**2\. 예제**

이번 예제의 핵심 코드이다. 아래의 한 줄로 public 폴더의 파일들을 정적파일로 서비스해 준다.

app.use(express.static('public'));

​

public 폴더를 기준으로 이미지(images)와 css 그리고 자바스크립트(js) 파일이 있다.

![](https://postfiles.pstatic.net/MjAyMzA5MDFfMjc0/MDAxNjkzNTEzNjU5MjY3.U414mhzxPGt6NwZd_Ww6nsOkSLovZS9N4DEulUNNIxMg.CVst62oWYLTAEb2hXsErpDl3jEH4VPMIEW9M65GlSXYg.PNG.agapeuni/img.png?type=w80_blur)

​

now.jpg 이미지 파일의 경로는 public 폴더가 기준이 되어서 /images/now.jpg가 되고 hello.js 파일의 경로는 public 폴더가 기준이 되어서 /js/hello.js가 된다.

​

​

아래는 전체 코드이다.

var express = require('express'); var http = require('http'); var app = express(); app.use(express.static('public')); app.get("/", function(request, response) { response.writeHead(200, { 'Content-Type' : 'text/html; charset=utf-8' }); response.write("<h1>Main page</h1>"); response.write("<img src='/images/express.png'><br>"); response.write("<img src='/images/now.jpg'><br>"); response.end(""); }); app.get("/js", function(request, response) { response.writeHead(200, { 'Content-Type' : 'text/html; charset=utf-8' }); response.write("<h1>JavaScript page</h1>"); response.write('<script type="text/javascript" src="/js/hello.js"></script>'); response.write('<script>sayHello("Express");</script>'); response.end(""); }); http.createServer(app).listen(1337); console.log('http://127.0.0.1:1337');

​
