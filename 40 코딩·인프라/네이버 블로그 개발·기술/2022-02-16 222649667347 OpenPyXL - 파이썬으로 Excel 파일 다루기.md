1\. openpyxl 모듈

파이썬에서 openpyxl 모듈을 사용하면 Excel 파일을 읽고 쓰는 기능을 쉽게 구현할 수 있다. 사용법은 직관적이고 심플하다.

Excel 서식까지 포함하면 더 많은 양의 코딩을 해야 하기에, 이번 예제코드는 서식은 스킵하고 데이터 읽기 쓰기 기준으로 코딩하였다.

pip install openpyxl 

**기능** |  **코드**  
---|---  
엑셀 파일 생성 |  Workbook()  
엑셀 파일 저장 |  wb.save("파일명.xlsx")  
엑셀 파일 열기 |  load_workbook("파일명.xlsx")  
데이터 추가 |  ws.append(["값1", "값2"])  
특정 셀 값 읽기 |  ws["A1"].value  
시트 추가/삭제 |  create_sheet("이름") / remove("시트명")  
스타일 변경 |  Font(), PatternFill()  
엑셀 파일 삭제 |  os.remove("파일명.xlsx")

2\. 엑셀 파일 쓰기

Sheet에 Row 단위, Column 단위로 Cell을 추가하고 Workbook의 save() 함수를 사용하여 엑셀파일로 저장하는 예제이다.

소스코드 : excel_write.py

import os from openpyxl import Workbook # 폴더가 없으면 폴더생성 if not os.path.exists("data"): os.mkdir("data") # "Example" 이름으로 시트를 생성 wb = Workbook() ws = wb.create_sheet("Example") # 헤더 입력 ws['A1'] = 'Code' ws['B1'] = 'Name' ws['C1'] = 'Memo' item4 = "아이템4" # 행 단위로 추가 ws.append(['A1', 'item1', 20.2]) ws.append(['B2', 'item2', 'test']) ws.append(['C3', 'item3', '실험']) ws.append(['D4', item4, '2020-08-24']) # 열 단위로 추가 # ws.cell(row, column, value) ws.cell(7, 1, '7행 1열') ws.cell(7, 3, '7행 3열') ws.cell(7, 5, '7행 5열') # Excel 파일로 저장하기 wb.save('data/sample.xlsx') wb.close()

3\. 엑셀 파일 읽기

openpyxl load_workbook 함수를 사용하여 바로 이전의 코드에서 생성한 엑셀파일을 읽는 예제이다.

​

소스코드 : excel_read.py

import os from openpyxl import load_workbook file_path = "data/sample.xlsx" # 엑셀파일을 읽는 load_workbook 함수 # data_only=Ture로 해줘야 수식이 아닌 값으로 받아온다. wb = load_workbook(file_path, data_only=True) # 시트 이름으로 불러오기 ws = wb['Example'] # 엑셀의 셀주소로 값을 출력 print(ws['A1'].value) print(ws['B2'].value) print(ws['C3'].value) print() # 셀 좌표로 값 출력 print(ws.cell(2, 1).value) print(ws.cell(2, 2).value) print(ws.cell(2, 3).value) print() records = [] for row in ws.rows: records.append((row[0].value, row[1].value, row[2].value)) for record in records: print(record) wb.close()

4\. 주의할 점

Excel 파일을 처리하기 때문에 행과 셀을 그리고 데이터 유무에 대해 주의해야 한다. sample.xlsx 파일의 데이터를 보면 1행부터 5행까지 데이터가 있고 6행은 없이 7행으로 건너뛰었는데 Excel 파일을 읽어 반복문으로 처리할 때 포함하고 있다. 그럴 때는 다음과 같이 비어있는 행에 대해서 처리를 해주어야 한다. 여기서는 첫 번째 셀의 값을 읽고 None 일 경우 행이 비어있다고 판단했다.

... (생략) ... records = [] for row in ws.rows: if row[0].value is not None: records.append((row[0].value, row[1].value, row[2].value)) else: continue ... (생략) ...
