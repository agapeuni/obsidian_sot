​

**1\. sqlMap**

TBL_CODE 테이블은 공통코드를 관리하는 테이블이다. 

공통코드는 group_code로 구분한다.

<typeAlias alias="Code" type="com.test.Code" /> <sql id="selectCode"> SELECT code, code_name AS codeName FROM TBL_CODE </sql> <select id="getGrade" resultClass="Code"> <include refid="selectCode"/> WHERE group_code = '0002' ORDER BY group_code, display </select>

​

​

**2\. Dao**

Dao에서는 sqlMap에 정의된 getGrade을 지정하여 목록으로 가져온다.

@Override @SuppressWarnings("unchecked") public List<Code> getGrade() { return getSqlMapClientTemplate().queryForList("getGrade"); }

​

​

**3\. Controller**

Dao에서 전달한 Grade 목록을 gradeList 이름으로 모델에 담아둔다.

List<Code> gradeList = codeService.getGrade(); model.addAttribute("gradeList", gradeList);

**4\. JSP**

다음과 같이 <form:select> 태그를 사용하면 공통코드에서 가져온 목록을 선택박스로 나타낸다.

<form:select path="grade" items="${gradeList}" itemValue="code" itemLabel="codeName" multiple="false" cssClass="selectBox" cssStyle="width:72px"/>
