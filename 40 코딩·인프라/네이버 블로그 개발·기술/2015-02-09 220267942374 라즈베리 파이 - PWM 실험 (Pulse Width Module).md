아래의 목록과 그림은 이번 실험의 준비물입니다. 

​

**미니 브레드보드**

**고휘도 LED 1개**

**270옴 저항 1개**

**MM 점퍼선 2개**

![](https://postfiles.pstatic.net/20150605_166/agapeuni_14334653762007KTeX_JPEG/20150208_010217.jpg?type=w80_blur)

라즈베리 파이의 GPIO 핀번호를 BCM 기준으로 정리한 그림입니다. 

WiringPi 기준으로 사용할 필요가 있을 경우 W에 적힌 번호를 참고하면 됩니다. 

![](https://postfiles.pstatic.net/20150605_283/agapeuni_1433462840090ubmPR_JPEG/20150207_163729.jpg?type=w80_blur)

​

먼저 G18번에 파란 점퍼선을 연결하고 브레드보드의 고휘도 LED의 (+)에 연결합니다. GND 접지에 검정 점퍼선을 연결하고 270옴 저항을 사이에 두고 고휘도 LED의 (-)에 연결합니다. 이제 G18번 핀에 신호를 보내면 PWM 값에 따라 LED의 깜박임이 변하게 됩니다. 

![](https://postfiles.pstatic.net/20150605_247/agapeuni_1433462848633WpzrB_JPEG/20150208_010218.jpg?type=w80_blur)

​

​

**실험 1.**

**소스코드 (****PWM_Simple****.py)**

**첨부파일**

PWM_Simple.py

[ 파일 다운로드 ](https://download.blog.naver.com/open/2cb9308394cdc81439d6b98bb153285ef1a75abc60/EFsQbbZLxbbO_982E-QRigSVEg-Y5eNnZ1EWLmEPkAQoHI23VXgl7_m5De9g8mwl0UOdQU6r4COwXveiDweVS-gZkqhn/PWM_Simple.py)

아래의 코드는 GPIO18 핀으로 처음에는 PWM 1Hz (1초 주기) 값으로 시작합니다. 

키보드의 아무 카를 누르면 2Hz (0.5초 주기) 값으로 변화하고 다시 키를 누르면 5Hz (0.2초 주기) 값으로 변화하도록 설정하였습니다.

![](https://postfiles.pstatic.net/MjAyMDExMTlfMTk0/MDAxNjA1Nzk3NDE0NTQ1.XWSEzvHhyUZ3lKo4XZyKgj6ezJGfnV-OvP_6gNJiyOkg.3eZwXgO_gH9zeTT9jcy7UzMNGVS_kj3dZmc_0JgzaPIg.PNG.agapeuni/20201119_234954.png?type=w80_blur)

​

**동영상**

아래는 위의 코드에 대한 동영상입니다. 

1초마다 깜빡이다가 키를 누르면 0.5초 그다음에는 0.2초로 LED가 깜박입니다.
