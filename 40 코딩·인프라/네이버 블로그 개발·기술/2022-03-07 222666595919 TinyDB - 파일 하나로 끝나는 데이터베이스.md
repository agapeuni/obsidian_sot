1\. TinyDB 개요

TinyDB는 작은 규모의 프로젝트에서 간편하게 사용할 수 있는 **문서 지향 데이터베이스** 이다. Python으로 순수하게 작성되어 있으며, 외부 종속성이 없어 가벼운 용도로 사용하기에 적합하다. dictionary 형태의 문서로 저장할 수 있어 MongoDB와 같이 모든 문서를 TinyDB에 저장할 수 있다. 고급 기능이나 고성능에는 적합하지 않다.

![](https://postfiles.pstatic.net/MjAyMzA2MjFfOTMg/MDAxNjg3MzUzODgxMjY3.C5fucLPaADFNCk2Dwf6tjZsQCT33EX6r_n4jxEmmq44g.KptT5yTQFNnVGTNVP-YWui9HRno741ORiO6LgEq5lpcg.PNG.agapeuni/SE-ecb159bc-413d-477e-999b-e5cfb4c3525d.png?type=w80_blur)

TinyDB는 NoSQL로서 아주 작은 문서 지향 데이터베이스이다.

​

2\. 설치

TinyDB를 설치하기 위해 다음의 명령을 실행한다.

$ pip install tinydb

3\. 기본 사용

TinyDB는 Python dict 형태의 데이터를 다루며 JSON 모듈을 기본적으로 사용한다.

​

1) TinyDB 데이터베이스 설정

from tinydb import TinyDB, Query db = TinyDB("./data/example.tinydb")

2) 테이블 생성 

table = db.table("books")

3) 테이블 삭제

db.drop_table("books")

3) 데이터 삽입

insert 함수는 삽입된 문서의 ID를 반환한다.

table.insert({"name": "파이썬", "price": 24000}) table.insert({"name": "텐서플로", "price": 17000}) table.insert({"name": "케라스", "price": 18000})

4) 데이터 조회 : 전체 데이터

all() 함수는 데이터베이스에 저장된 모든 데이터를 가져온다.

list = table.all() print(list) print()

​

5) 데이터 조회 : name이 '텐서플로'인 데이터 검색

rs = table.search(Book.name == "텐서플로") print(rs[0]["price"]) print()

6) 데이터 조회 : price가 18000원 이상인 데이터 검색

rs = table.search(Book.price >= 18000) for item in rs: print(item["name"]) print()

7) 데이터 수정 : name이 파이썬인 데이터의 price를 수정

table.update({'price': 20000}, Book.name == '파이썬') list = table.all() print(list) 

8) 데이터 삭제 : price가 2만원미만인 데이터 삭제

table.remove(Book.price < 20000) list = table.all() print(list)

9) 데이터 제거 : 모든 데이터를 제거

table.truncate()

​

4\. 주요 API

  * db.insert() - 문서 삽입

  * db.all() - 모든 문서 가저오기

  * db.search(query) - 쿼리와 일치하는 문서 조회

  * db.update(fields, query) - 쿼리와 일치하는 문서 수정

  * db.remove(query) - 쿼리와 일치하는 문서 삭제

  * db.truncate() - 모든 문서 삭제

​
