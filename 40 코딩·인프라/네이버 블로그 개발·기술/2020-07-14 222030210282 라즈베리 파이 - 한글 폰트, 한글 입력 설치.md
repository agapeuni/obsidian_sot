# 2020-07-14 222030210282 라즈베리 파이 - 한글 폰트, 한글 입력 설치

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfNjIg/MDAxNzU4NDQ0ODU0NTc3.y7XHp6T2WR62nYIg11TrpzzBZjqGhPphxn85NI0zsx4g.Hi95YrhKSPRPwtTK-LTufQ9ZstEdvF6Gc3MOMmkuVXEg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(1\).png?type=w80_blur)

새로 설치한 라즈비안에서 블로그에 접속해 보니 한글 폰트가 없어서 메뉴와 카테고리 한글이 모두 깨져 보이네요. 이미지만 제대로 표시됩니다.

![](https://postfiles.pstatic.net/MjAyMDA3MTRfODgg/MDAxNTk0NjYzMDk4Nzk0.GC4rrW4qMIvI0UWF0A7_g0yNo4I9q6Oz9baVvEP-HLwg.cDYOwhhLIsiup7fTEX80nemo1H9vFtnwsArytDCKubMg.PNG.agapeuni/SE-0f7d6635-fcc6-4ddf-85b7-5762a7118e23.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyMDA3MTRfMTM2/MDAxNTk0NjYzMTAwMjUy.o9-xOcNBr_qQXnGXqSkymjLN_TMwoq8gZOoUvJmLLC8g.Wk6aRt54N9gsNBAZNAqKiqsV_0yTJmj6cCaJBWuFHzYg.PNG.agapeuni/SE-92e5eaf1-3189-4d38-b8f5-50044c6aedce.png?type=w80_blur)

​

​

Add/Remove Software에서 nanum을 입력하고 검색하면 아래와 같이 표시됩니다.

![](https://postfiles.pstatic.net/MjAyMDA3MTRfMTY5/MDAxNTk0NjYzMTAxMjA3.7jYVKN7E7Oxu-I9-kPTnUw_TN0JmmZIquYdYB-d0onUg.5x9TNKu0t1TJ6FuCeQlFcsgI2fRrCvI3E_dhyiwzwtgg.PNG.agapeuni/SE-2e8f7e8f-39ae-4723-ad95-95e7e85a4cd6.png?type=w80_blur)

​

​

Nanum Korean fonts를 선택하고 설치를 하였습니다. 참고로 프로젝트 진행할 때 사용하는 SW의 폰트를 "**나눔고딕코딩** "으로 설정합니다. D2Coding 폰트로 프로그래밍 할 때 괜찮습니다.

![](https://postfiles.pstatic.net/MjAyMDA3MTRfMjkx/MDAxNTk0NjYzMTAyMDI2.nXLds2ncuGzDS0uB5Cc-4E8i5K5Ht0XBSFQNsQohjSUg.0Ak2TgEvNhS5VDZf2iO3Ysp8NdWeKfUCkwtxcW7t5Xsg.PNG.agapeuni/SE-58dd4db3-f42a-49e9-926a-aa8272b58758.png?type=w80_blur)

​

​

터미널에서 다음의 명령어로 Nanum 폰트를 설치할 수도 있습니다. 

**sudo apt install fonts-nanum fonts-nanum-extra**

![](https://postfiles.pstatic.net/MjAyMDA3MTZfMTAx/MDAxNTk0ODI4MDg3NjY2.e0gjoaY6FPMAmvucCvOo3NktU5OUUpS3SdBQFgAuXRcg.I3VwsOu6aq4cYkyy0nO8yRHhL8DwibZsToGLPJuHSAYg.PNG.agapeuni/SE-85e543d8-02bd-41d7-aa44-d157644e49a8.png?type=w80_blur)

​

​

한글 폰트를 설치하고 블로그에 다시 접속해 보면 아래와 같이 한글이 잘 표시됩니다. 

![](https://postfiles.pstatic.net/MjAyMDA3MTRfMTU1/MDAxNTk0NjYzMTA0MzMw.HlmbR6487hxm0aj4sI_UX_E_Wjnx2OYt5zSESOjlTOgg.vfIsTEEeHjCrOuhng0GHcm7ApdFTtYEJaOTgiHXR2lEg.PNG.agapeuni/SE-239cc877-59c4-4fec-8747-dd6e5552daa6.png?type=w80_blur)

​

​

한글 입력을 위해 라즈비안에서 사용할 수 있는 nabi 한글 입력기를 설치합니다. 

**sudo apt install nabi**

![](https://postfiles.pstatic.net/MjAyMDA3MTZfNjkg/MDAxNTk0ODI4MjI1NjAw.8k3KtvlTcXtabB3f0AhIXu5_WfCoi-cHVVAgp0HgzIkg.1O5GOxBqV-NGoYRE8MPT7xjh-xS53ZV4cEaez7jE9zUg.PNG.agapeuni/SE-0b36672e-dab8-47e3-86c0-7c0827fe114b.png?type=w80_blur)

​

그리고 기본 입력기 지정을 위해 다음의 명령을 입력합니다. 설치를 마치면 '기본 설정' 메뉴에 입력기가 표시됩니다.

**sudo apt install im-config**

![](https://postfiles.pstatic.net/MjAyMDA3MTZfNCAg/MDAxNTk0ODI4Mjc5MjEw.MPnKY2j2Vn-XNhCuPj9apBYYG2rm9gshvxlLqk_r_Y4g.yXPbwYqSeKBcNQbhNMUdJ2KPvNFeTyVCv5bZwhN_ksMg.PNG.agapeuni/SE-2eb8c81b-41de-4aa1-9d2e-9fbcc1c2e695.png?type=w80_blur)

​

​

라즈비안에서 "기본 설정" 메뉴에서 "입력기"를 확인할 수 있습니다.

![](https://postfiles.pstatic.net/MjAyMDA3MTRfMjIw/MDAxNTk0NzI4ODQ1NDE4.aOelvNV5nHjNrp6yzBFdHGAw2lhsdOmUaEWL2rvSfyEg.oZm-6-2OKcrKs630ZaQ0eHHXU3-V_UHEHhuB7X8_bBsg.PNG.agapeuni/SE-3a2556d9-be65-43fa-8873-28c5872e02de.png?type=w80_blur)

​

​

보조 프로그램에 있는 Text Editor를 열어서 한글과 영문을 입력해 보았습니다. 한영 토글키는 Shift + Space 키.

![](https://postfiles.pstatic.net/MjAyMDA3MTRfMTU0/MDAxNTk0NzI4ODU2NDgz.pJVFM4lhzRJY2iq9wlYV-tj1E4v8pZRTcnrys8WClIwg.gObV-trefQctqov3R_qaJpnkXLPeX-hyHNPRe7O6huMg.PNG.agapeuni/SE-57257d58-bab9-48e1-9f84-9380e52f63c7.png?type=w80_blur)
