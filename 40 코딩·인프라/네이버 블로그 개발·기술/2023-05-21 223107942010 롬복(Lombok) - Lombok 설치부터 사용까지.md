1\. 롬복(Lombok) 개요

코딩을 하다 보면 VO 객체나 DTO 객체에 set/get 메서드와 toSting()을 작성한다. 롬복(Lombok)은 어노테이션으로 해결한다. 도메인 클래스에 멤버 변수를 변경할 때 set/get 메서드를 변경할 필요가 없어진다. 반복되는 메서드를 Lombok이 자동으로 관리한다.

​

Lombok을 사용하지 않을 경우 set/get 메서드와 toSting()을 직접 만들어 주어야 한다. 

package com.oneway; public class Board { private Long id; private String title; private String content; private String writer; public Long getId() { return id; } public void setId(Long id) { this.id = id; } public String getTitle() { return title; } public void setTitle(String title) { this.title = title; } public String getContent() { return content; } public void setContent(String content) { this.content = content; } public String getWriter() { return writer; } public void setWriter(String writer) { this.writer = writer; } public String toString() { return "Board [id=" + id + ", title=" + title + ", content=" + content + ", writer=" + writer + "]"; } }

​

Lombok을 적용할 경우 아래와 같이 코드가 심플해진다.

package com.oneway; import lombok.Getter; import lombok.Setter; import lombok.ToString; @Getter @Setter @ToString public class Board { private Long id; private String title; private String content; private String writer; }

​

​

2\. 롬복 설치

롬복을 사용하려면 먼저 아래의 주소로 접속하여 Lombok을 다운로드한다.

<https://projectlombok.org/download>

![](https://postfiles.pstatic.net/MjAyMzA1MjFfMTU5/MDAxNjg0NjY3MzQwODg3.CUwzjQt2Cj_TOKsJf821k8bCqSBhhOS62KrHnUf0wvQg.nm6PxOMxhfEtMgb-T7zIiA7wsK-JRL2jcCVbW4DEpK4g.PNG.agapeuni/image.png?type=w80_blur)

​

다운로드한 "lombok.jar" 파일을 이클립스가 있는 폴더로 이동한다.

![](https://postfiles.pstatic.net/MjAyMzA1MjFfNjIg/MDAxNjg0NjY3Mzg4NTAz.O4zYWpGKVp6dLGkAX-UXzQJHnG5EMVR_m0vyusC0yOwg.S3E3j6GK81dNPalcgA45ia2-Ml3haqz_mng76AfHrDog.PNG.agapeuni/image.png?type=w80_blur)

​

관리자 권한으로 명령 프롬프트를 실행하고 다음을 명령어로 롬복 JAR 파일을 실행한다.

> java -jar lombok.jar

![](https://postfiles.pstatic.net/MjAyMzA1MjFfMTI1/MDAxNjg0NjY3NDEyNzk4.gkWdUyN16rJySIJGcJ3_DEP-IQZr6mmjZDQEuAGsO74g.nG3-HctC6lT7O9p2mIT2XiUeQyb1VQt615Q7xLhlwxcg.PNG.agapeuni/image.png?type=w80_blur)

Project Lombok 인스톨러가 실행되고 IDE가 없다고 경고창이 뜰 수 있다. 

자동으로 찾지 못하면 "Specify location..."을 클릭한다.

![](https://postfiles.pstatic.net/MjAyMzA1MjFfMTMw/MDAxNjg0NjY3NDI4Njk3.iZGxasvw4FgpIcevGOFrZZImVicE6gjDaKppKBhbNgkg.VRbW6FdTR3fICDd0O4Wt4fSp9uYZK_p1WhTc_pjbWHsg.PNG.agapeuni/image.png?type=w80_blur)

이클립스 IDE의 경로를 지정해야 한다.

eclipse.exe 파일이 위치한 폴더로 이동하여 해당 파일을 선택한다.

![](https://postfiles.pstatic.net/MjAyMzA1MjFfMzgg/MDAxNjg0NjY3NDQ5NDM2.PVOyWaLmaqe53KtkroPJjqlgeFcQ1RMs5YvTIgxeiKAg.gfEKZ-hsVYEPdPLfwMZ9pxQlvdmyRhHM0urivyvulLYg.PNG.agapeuni/image.png?type=w80_blur)

"Install/Update"버튼을 클릭하면 설치가 완료된다. 설치가 완료되면 롬복이 이클립스에 추가된다.

3\. 롬복 확인

lombok 실치 완료 후에 이클립스를 재시작한다. 

이클립스가 다시 시작될 때 롬복이 정상적으로 로드되고 사용 가능해진다.

​

테스트를 위해서 Board 클래스를 만들고 lombok 이 적용되는지를 확인해 본다. 

@Getter, @Setter, @ToString 어노테이션을 추가하는 것으로 끝이다. 

멤버 변수를 수정하면 동적으로 적용된다. 참 신기한 라이브러리다.
