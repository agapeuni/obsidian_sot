1\. Table 생성

SQLite 연동을 위해 member 테이블을 하나 생성한다. 컬럼은 간단하게 이름과 나이가 있다.

CREATE TABLE [member]( [id] INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL, [name] VARCHAR(50) NOT NULL, [age] INTEGER(5) DEFAULT 0 );

생성된 member 테이블에 CRUD(Create, Read, Update, Delete)를 수행하는 기능을 구현한다. 즉, 추가(INSERT), 수정(UPDATE), 삭제(DELETE), 조회(SELECT)를 위한 각각의 파이썬 함수를 코딩한다.

2\. INSERT - create 함수

helloworld 폴더안의 __init__**.** py 에 sqlite를 임포트하고 create 함수를 구현한다. 데이터를 추가하고 홈페이지로 리다리렉트 한다.

import sqlite3 ...(생략)... @app.route("/create") def create(): name = request.args.get("name") age = request.args.get("age") conn = sqlite3.connect("./data/board.db") db = conn.cursor() db.execute("INSERT INTO member (name, age) VALUES (?,?)", (name, age)) conn.commit() conn.close() return redirect("/")

3\. SELECT - get 함수

helloworld 폴더안의 __init__.py 에 조회를 위한 함수를 작성한다. URL에 입력한 값이 조회를 위한 ID 값으로 지정된다.

...(생략)... @app.route("/get/<int:id_>") def get(id_): conn = sqlite3.connect("./data/member.db") db = conn.cursor() member = db.execute( "SELECT name, age FROM member WHERE id = ?", (id_,)).fetchone() return render_template("member.html", id_=id_, name=member[0], age=member[1])

4\. UPDATE - modify 함수

helloworld 폴더안의 __init__.py 에 수정을 위한 함수를 작성한다. URL에 입력한 값을 이용해 ID값을 지정하고 요청 파라미터로 값을 전달한다. 수정을 하고나서 조회를 위해 "/get"을 리다이렉트했다.

...(생략)... @app.route("/modify/<int:id_>") def modify(id_): name = request.args.get("name") age = request.args.get("age") conn = sqlite3.connect("./data/member.db") db = conn.cursor() db.execute("UPDATE member SET name = ?, age = ? WHERE id = ?", (name, age, id_)) conn.commit() return redirect("/get/" + str(id_))

아래의 URL을 브라우저에 입력하면 데이터를 수정하고 수정한 데이터로 페이지에 표시한다.

6\. CRUD 전체 코드

아래는 member 테이블을 대해 작성한 CRUD 전체 코드이다.

from flask import Flask, render_template, request, redirect import sqlite3 app = Flask(__name__) @app.route('/') def hello_world(): return '<h1>Hello, World!</h1>' @app.route('/info') def greet(): user = {'name': 'OneWay', 'age': "28"} return ''' <html> <head> <title>Name</title> </head> <body> <h1>Hello, ''' + user['name'] + '''!</h1> <h2>you’re ''' + user['age'] + ''' years old.</h2> </body> </html>''' @app.route('/hello') @app.route("/hello/<param>") def hello(param=None): return render_template('hello.html', name=param) @app.route("/create") def create(): name = request.args.get("name") age = request.args.get("age") conn = sqlite3.connect("./data/member.db") db = conn.cursor() db.execute("INSERT INTO member (name, age) VALUES (?,?)", (name, age)) conn.commit() conn.close() return redirect("/") @app.route("/get/<int:id_>") def get(id_): conn = sqlite3.connect("./data/member.db") db = conn.cursor() member = db.execute( "SELECT name, age FROM member WHERE id = ?", (id_,)).fetchone() return render_template("member.html", id_=id_, name=member[0], age=member[1]) @app.route("/modify/<int:id_>") def modify(id_): name = request.args.get("name") age = request.args.get("age") conn = sqlite3.connect("./data/member.db") db = conn.cursor() db.execute("UPDATE member SET name = ?, age = ? WHERE id = ?", (name, age, id_)) conn.commit() return redirect("/get/" + str(id_)) @app.route("/remove/<int:id_>") def remove(id_): conn = sqlite3.connect("./data/member.db") db = conn.cursor() db.execute("DELETE FROM member WHERE id = ?", (id_,)) conn.commit() return redirect("/") @app.route("/page/") def page(num=1): conn = sqlite3.connect("./data/member.db") db = conn.cursor() member_list = db.execute("SELECT * FROM member").fetchall() conn.commit() return render_template("member_list.html", member_list=member_list) if __name__ == '__main__': app.run(host="0.0.0.0", debug=True, port=8080)
