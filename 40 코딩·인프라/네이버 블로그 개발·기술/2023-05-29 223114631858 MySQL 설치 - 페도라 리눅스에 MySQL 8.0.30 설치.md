**​****4\. MySQL 시작**

다음의 명령어로 mysql 데몬을 시작한다.

> systemctl start mysqld

​

mysql 데몬이 시작되고 다음의 명령어를 입력하면 임시 비밀번호를 알 수 있다.

> sudo cat /var/log/mysqld.log | grep 'temporary password'

[pi@fedora ~]$ sudo cat /var/log/mysqld.log | grep 'temporary password' [sudo] pi 암호: 2022-09-03T14:09:00.458444Z 6 [Note] [MY-010454] [Server] A temporary password is generated for root@localhost: wK)NTyc:a3pq [pi@fedora ~]$

**5\. MySQL 설정****​**

다음의 명령어로 비밀번호를 변경한다.

> ALTER USER 'root'@'localhost' IDENTIFIED with mysql_native_password by 'Test1234!';

또는

> ALTER USER 'root'@'localhost' IDENTIFIED by 'Test1234!'; (현재 설정된 기본값은 caching_sha2_password이다)

mysql> ALTER USER 'root'@'localhost' IDENTIFIED with mysql_native_password by 'Test1234!'; Query OK, 0 rows affected (0.01 sec) mysql> ALTER USER 'root'@'localhost' IDENTIFIED by 'Test1234!'; Query OK, 0 rows affected (0.01 sec)

​

다음의 쿼리로 user 테이블을 확인해 본다.

> select host, user, plugin from user;

mysql> select host, user, plugin from user; +-----------+------------------+-----------------------+ | host | user | plugin | +-----------+------------------+-----------------------+ | localhost | mysql.infoschema | caching_sha2_password | | localhost | mysql.session | caching_sha2_password | | localhost | mysql.sys | caching_sha2_password | | localhost | root | mysql_native_password | +-----------+------------------+-----------------------+

​

다른 컴퓨터에서도 접속할 수 있도록 다음의 명령어를 수행한다.

> CREATE USER 'root'@'%' IDENTIFIED with mysql_native_password by 'Test1234!';

​

다음의 쿼리로 user 테이블을 확인해 본다.

> select host, user, plugin from user;

mysql> select host, user, plugin from user; +-----------+------------------+-----------------------+ | host | user | plugin | +-----------+------------------+-----------------------+ | % | root | mysql_native_password | | localhost | mysql.infoschema | caching_sha2_password | | localhost | mysql.session | caching_sha2_password | | localhost | mysql.sys | caching_sha2_password | | localhost | root | mysql_native_password | +-----------+------------------+-----------------------+ 5 rows in set (0.00 sec)

​

다음의 명령어로 현재 사용 중인 MySQL의 캐시를 지우고 새로운 설정을 적용한다.

> flush privileges;

mysql> flush privileges; Query OK, 0 rows affected (1.33 sec)
