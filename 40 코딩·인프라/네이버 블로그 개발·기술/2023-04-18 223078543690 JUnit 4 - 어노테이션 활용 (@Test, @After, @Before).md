1\. JUnit 4 개요

JUnit은 반복 가능한 테스트를 작성하는 간단한 프레임워크다. JUnit은 자바에서 사용하는 단위 테스트를 위한 xUnit 아키텍처의 인스턴스다. JUnit 4 어노테이션 알고 있으면 테스트 코드를 쉽게 작성할 수 있다. 자주 사용하는 @Test, @Ignore, @Before, @BeforeClass, @After, @AfterClass 어노테이션에 대해 알아보자.

​

​

2\. Test Case에서 활용

**@Test**

가장 기본이 되는 어노테이션이다. junit의 테스트 클래스를 생성할 때 'extends TestCase'와 메서드 앞의 'test'라고 붙여줘야 하는 불편함을 없애준다. TestCase를 확장하지 않았기 때문에 'assert*' 메서드를 사용하기 위해서 'import static org.junit.Assert.*;'가 필요하다.

import org.junit.Test; import static org.junit.Assert.*; public class ClassNameTest{ @Test public void methodName(){ … assertEquals(4, methodName(1, 3)); } }

​

**@Test(expected = Exception.class)**

@Test의 expected에 클래스 메서드 안의 try, catch에서 발생한 예외를 정의해 준다. 정의를 해준 예외는 메서드 안에서 try, catch 해 줄 필요가 없다.

@Test(expected = ArithmeticException.class) public void divisionZero(){ new Calculator().divide(4, 0); }

​

**@Test(timeout = 5000)**

@Test의 timeout은 메서드에 시간적인 제한을 줄 수 있다. 성능 테스트 시 일정 시간만 실행 후에 종료를 시킬 수 있다. 테스트가 종료되기 전에 timeout이 발생되면 다음과 같은 실패 메시지가 발생한다.

@Test(timeout = 5000) public void lengthyOperation(){ … }

java.lang.Exception : test timed out after 5000 milliseconds

​

​

**@Ignore("테스트 실행에서 제외되는 이유")**

@Ignore를 통해서 테스트 메서드 실행 시 해당 메서드를 제외할 수 있다. 제외하는 이유를 적어서 추후에 직관적으로 확인할 수도 있다.

import org.junit.Ignore; @Ignore("메소드가 아직 준비되지 않았습니다.") @Test public void yetMakeMethod(){ … }

​

**@Before**

테스트 메서드가 실행되기 전에 실행되는 메서드

import org.junit.Before; @Before public void setUp(){ … }

​

**@After**

테스트 메서드가 실행되고 난 후에 실행되는 메서드

import org.junit.After; @After public void tearDown(){ … }

​

**@BeforeClass, @AfterClass**

Class가 처음 시작할 때와 종료할 때 호출된다.

@BeforeClass public static void setupClass(){ System.out.println("setupClass"); } @AfterClass public static void finishClass(){ System.out.println("finishClass"); }

​​

3\. Test Suites에서 활용

**@RunWith(value=Suite.class) & @SuiteClasses**

Test Suites에서 추가할 테스트 클래스를 다음과 같이 간략하게 적용할 수 있다. 여러 개의 JUnit을 실행할 수 있다. @RunWith에서 정의한 Suite runner를 실행한다. @SuiteClasses는 Suite runner에 해당되는 class들을 포함시켜 준다.

​

어노테이션을 적용하기 전

public class AllTests extends TestCase{ public static Test suite(){ TestSuite suite = new TestSuite(); suite.addTestSuite(CalculatorTest.class); suite.addTestSuite(AnotherTest.class); return suite; } }

​

어노테이션을 적용한 후

@RunWith(value=Suite.class) @SuiteClasses(value={CalculatorTest.class, AnotherTest.class}) public class AllTests{ … }

​

**@RunWith(value=Parameterized.class)**

@Parameters에서 정의한 값으로 Test 메서드의 파라미터 값만 변경하여 실행한다.

@RunWith(value=Parameterized.class) public class FactorialTest{ private long expected; private int value; @Parameters public static Collection data(){ return Arrays.asList(new Object[][]{ {1, 0}, // expected, value {1, 1}, {2, 2}, {24, 4}, {5040, 7} }); } public FactorialTest(long expected, int value){ this.expected = expected; this.value = value; } @Test public void factorial(){ Calculator calculator = new Calculator(); assertEquals(expected, calculator.factorial(value)); } }

​

실행 결과

factorial#0: assertEquals( 1, calculator.factorial( 0 ) ); factorial#1: assertEquals( 1, calculator.factorial( 1 ) ); factorial#2: assertEquals( 2, calculator.factorial( 2 ) ); factorial#3: assertEquals( 24, calculator.factorial( 4 ) ); factorial#4: assertEquals( 5040, calculator.factorial( 7 ) );
