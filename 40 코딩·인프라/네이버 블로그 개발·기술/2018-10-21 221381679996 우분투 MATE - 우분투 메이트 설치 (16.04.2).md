가을의 시원함을 담고 있는 주말입니다. 

편안한 주말을 맞이하여 집에 있는 라즈베리 파이들이 잘 동작하는지 확인을 하였습니다.

​

sudo apt-get update와 sudo apt-get upgrade 한 번씩 실행해서 최신으로 업데이트해주었습니다.

그리고 SSH와 원격 데스크톱의 직관적인 연결을 위해 "**/etc/dhcpcd.conf** " 파일을 편집하여 고정 IP로 변경하였습니다.

​

interface eth0

static ip_address=192.168.0.XX

static routers=192.168.0.1

static domain_name_servers=192.168.0.1

static netmask=255.255.255.0

브라우저는 파이어폭스보다 크롬이 좋으니 아래의 명령어를 실행하여 파이어폭스를 제거하고 크롬을 설치합니다.

$ sudo apt-get purge firefox

$ sudo apt-get install chromium-browser
