# 2023-08-20 223188787310 PL SQL 예제 - MERGE와 CURSOR를 사용한 데이터 처리

​

이 PL/SQL 프로시저 PRC_SAMPLE은 입력된 특정 날짜(V_YMD)에 해당하는 데이터를 조회한 후, 그 결과를 기준으로 TB_TEST 테이블에 MERGE 문을 사용해 데이터를 갱신 또는 삽입하는 로직을 수행한다. 

​

PL/SQL에서 CURSOR와 MERGE 문을 함께 사용하여 데이터를 조작하는 프로시저 예제이다. CURSOR를 사용하여 조회한 데이터를 MERGE INTO를 사용하여 존재하는 경우에는 UPT_DATE를 변경하고 존재하지 않는 경우에는 데이터를 입력한다. CURSOR는 조회된 데이터를 반복 처리하는 데 사용되며, 해당 날짜에 이미 존재하는 CODE는 UPT_DATE만 업데이트, 존재하지 않는 경우에는 새로운 데이터로 INSERT된다.

​

**​**

**1\. 프로시저 선언**

CREATE OR REPLACE PROCEDURE PRC_SAMPLE (V_YMD IN VARCHAR2, V_CNT OUT NUMBER)

  * V_YMD: 처리할 날짜(년월일)를 입력받는 매개변수

  * V_CNT: 실행된 MERGE 횟수를 OUT 파라미터로 반환

**​**

**​**

**2\. 커서 정의**

CURSOR CURSOR_DATA (P_YMD IN VARCHAR2) IS SELECT YMD, CODE, COUNT(1) CNT FROM TB_SAMPLE WHERE YMD = P_YMD; 

  * TB_SAMPLE 테이블에서 입력받은 날짜에 해당하는 YMD와 CODE별 데이터 개수를 집계

  * 집계 결과는 CNT라는 별칭 컬럼으로 함께 조회됨

**​**

**​**

**3\. FOR LOOP 반복 처리**

FOR RECORD_DATA IN CURSOR_DATA(V_YMD) 

  * 커서를 통해 조회된 각 행을 하나씩 처리

  * 이 구조는 명시적인 OPEN, FETCH, CLOSE 없이 커서 반복을 자동으로 처리함

**​**

**​**

**4\. MERGE INTO 문**

MERGE INTO TB_TEST USING DUAL ON (YMD = RECORD_DATA.YMD AND CODE = RECORD_DATA.CODE) WHEN MATCHED THEN UPDATE SET UPT_DATE = SYSDATE WHEN NOT MATCHED THEN INSERT ... 

  * TB_TEST 테이블에서 같은 YMD와 CODE가 있는지를 기준으로 조건 비교

  * 존재하면 UPT_DATE를 현재 시간으로 업데이트

  * 존재하지 않으면 YMD, CODE, CNT와 함께 현재 시간을 삽입

**​**

**​**

**5\. 처리 건수 카운트**

V_CNT := V_CNT + 1; 

  * 반복이 한 번 실행될 때마다 카운트를 증가시켜 최종 처리 건수를 OUT 파라미터로 반환

**​**

**​**

**6\. COMMIT 및 예외 처리**

COMMIT; ... EXCEPTION WHEN OTHERS THEN DBMS_OUTPUT.PUT_LINE (...) ROLLBACK; 

  * 정상적으로 루프가 끝나면 변경 사항을 커밋

  * 에러 발생 시 예외 메시지를 출력하고 롤백 처리하여 데이터 무결성을 유지

**​**

**​**

**7\. 전체 코드**

CREATE OR REPLACE PROCEDURE PRC_SAMPLE (V_YMD IN VARCHAR2, V_CNT OUT NUMBER) IS CURSOR CURSOR_DATA (P_YMD IN VARCHAR2) IS SELECT YMD, CODE, COUNT (1) CNT FROM TB_SAMPLE WHERE YMD = P_YMD; RECORD_DATA CURSOR_DATA%ROWTYPE; BEGIN FOR RECORD_DATA IN CURSOR_DATA(V_YMD) LOOP MERGE INTO TB_TEST USING DUAL ON (YMD = RECORD_DATA.YMD AND CODE = RECORD_DATA.CODE) WHEN MATCHED THEN UPDATE SET UPT_DATE = SYSDATE WHEN NOT MATCHED THEN INSERT (YMD, CODE, CNT, INS_DATE, UPT_DATE) VALUES (RECORD_DATA.YMD, RECORD_DATA.CODE, RECORD_DATA.CNT, SYSDATE, SYSDATE); V_CNT := V_CNT + 1; END LOOP; COMMIT; EXCEPTION WHEN OTHERS THEN DBMS_OUTPUT.PUT_LINE ('SQLCODE = ' || TO_CHAR (SQLCODE) || ', SQLERRM = ' || SQLERRM); ROLLBACK; END;
