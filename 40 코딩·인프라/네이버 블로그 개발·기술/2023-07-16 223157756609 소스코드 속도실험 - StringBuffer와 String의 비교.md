​

자바에서 StringBuffer와 String은 문자열을 처리하는 데 사용되는 두 가지 클래스다. StringBuffer는 가변(mutable) 문자열을 나타내는 클래스로, 문자열에 대한 변경 작업을 수행할 수 있다. 반면에 String은 불변(immutable) 문자열을 나타내는 클래스로, 한 번 생성된 문자열은 변경할 수 없다.

​

StringBuffer와 String의 비교와 속도를 실험하기 위해서는 문자열 조작 작업을 수행하고 실행 시간을 측정해야 한다. 참고로, Java 5 이상에서는 컴파일러가 일부 String 연결 작업을 StringBuilder로 자동 변환하여 최적화한다.

​

반복 횟수를 증가하면서 StringBuffer와 String의 속도를 실험해 보았다. 적당한 반복 횟수에서는 String이 속도에 우위에 있었으나 반복 횟수를 증가할수록 StringBuffer가 속도가 좋게 나왔다. 실무에서는 그렇게 반복할 일이 자주 없겠지만 1000번 5000번 증가해 보면 처리 속도가 현저하게 차이가 난다.

​

**TestStringBuffer.java**

package test; import java.text.DecimalFormat; public class TestStringBuffer { public static void main(String[] args) { final int[] LOOP_COUNT = { 100, 1000, 5000, 10000, 20000 }; DecimalFormat df = new DecimalFormat("##,###.##"); for (int len : LOOP_COUNT) { System.out.println("\n======================="); System.out.println("반복회수 = " + len); // StringBuffer의 속도 테스트 StringBufferTest(len, df); // String 의 속도 테스트 StringTest(len, df); } } private static void StringBufferTest(int len, DecimalFormat df) { long startTime = System.nanoTime(); StringBuffer sb = new StringBuffer("Hello"); for (int i = 0; i < len; i++) { sb.append("Java"); } long endTime = System.nanoTime(); long elapTime = endTime - startTime; System.out.println("\nsb.append(\"JavaWorld\");"); System.out.println("걸린 시간 = " + df.format(elapTime) + "ns"); } private static void StringTest(int len, DecimalFormat df) { long startTime = System.nanoTime(); String str = "Hello"; for (int i = 0; i < len; i++) { str += "Java"; } long endTime = System.nanoTime(); long elapTime = endTime - startTime; System.out.println("\nstr += \"JavaWorld\";"); System.out.println("걸린 시간 = " + df.format(elapTime) + "ns"); } }
