Azure 기본 사항 소개

Azure는 계속 확장되는 서비스 세트를 포함하는 클라우드 컴퓨팅 플랫폼이다.

Azure는 클라우드에서 호스팅 하기 위한 간단한 웹 서비스가 있다. 

Azure는 완전히 가상화된 컴퓨터 실행을 지원한다.

Azure는 다양한 클라우드 기반 서비스를 제공한다.

​

Microsoft의 공식 인증(AZ-900) 취득

Azure 기본 사항을 학습하면 AZ-900 시험을 준비하는 데 도움이 된다. 

​

AZ-900 시험 다음과 같은 주제 영역으로 구성되어 있다.

  * 클라우드 개념에 대해 설명하기 25~30%

  * Azure 아키텍처 및 서비스 설명 35~40%

  * Azure 관리 및 거버넌스 설명 30~35%

​

클라우드 컴퓨팅 개요

클라우드 컴퓨팅이란 인터넷을 통해 컴퓨팅 서비스를 제공하는 것이다. 

가상 머신, 스토리지, 데이터베이스 및 네트워킹과 같은 일반적인 IT 인프라가 포함된다. 

​

클라우드 컴퓨팅은 인터넷을 사용하여 이러한 서비스를 제공한다. 

데이터 센터와 동일한 방식으로 물리적 인프라에 의해 제한되지 않는다.

클라우드를 사용하여 IT 공간을 빠르게 확장할 수 있다.

​

공동 책임 모델

공동 책임 모델을 간단히 말하면 클라우드 공급자와 소비자 간에 공동으로 책임을 지는 것이다.

온-프레미스에서는 사용자가 모든 것을 책임을 졌지만 클라우드 컴퓨팅에서는 일부 책임이 클라우드 공급자에게 이동한다.

​

IaaS, PaaS, SaaS에 따라 사용자와 클라우드 공급자의 책임 범위가 달라진다.

사용자는 저장되는 정보와 데이터 그리고 서비스 계정을 담당하고 클라우드 공급자는 데이터 센터, 네트워크, 호스트를 담당한다.

클라우드 모델 정의

클라우드 모델은 클라우드 리소스의 배포 유형에 따라 다음과 같이 정의한다.

  * 퍼블릭 클라우드

  * 프라이빗 클라우드

  * 하이브리드 클라우드

  * 다중 클라우드 

​

Azure Arc : 클라우드 환경 관리를 지원하는 기술.

Azure VMware 솔루션 : Azure에서 VMware 워크로드를 실행

​

사용량 기반 모델

IT 인프라 모델을 비교할 때 고려해야 할 두 가지 유형의 비용이 있다. 

  * CapEx(자본 지출) : 유형 리소스를 구입하거나 보호하기 위한 일회성 선불 지출

  * OpEx(운영 지출) : 시간이 지남에 따라 서비스 또는 제품에 지출되는 비용

​

전통적으로 IT 비용은 자본 지출(CapEx)로 간주. 클라우드로의 이동과 종량제 모델로 인해 조직은 예산을 확장할 수 있는 능력을 갖게 되었고 IT CapEx 비용을 운영 비용(OpEx)으로 전환.

_​_

클라우드 컴퓨팅은 사용하는 IT 리소스에 대한 비용을 지불하는 소비 기반 모델에서 작동하기 때문에 OpEx에 속한다. 클라우드 기반 모델에서는 리소스 요구 사항을 정확히 확보하지 않아도 된다. 사용하는 가상 머신에 대해서만 비용을 지불한다. 클라우드 애플리케이션을 빌드하거나 배포할 때 가장 큰 고려 사항 두 가지는 가동 시간(또는 가용성)과 수요(또는 스케일링)를 처리하는 기능.

​

클라우드의 고가용성

중단이나 발생할 수 있는 이벤트에 관계없이 최대 가용성을 보장.

리소스의 가용성을 확보하는 것이 중요.

​

클라우드의 확장성

스케일링 성능은 수요에 맞게 리소스를 조정하는 기능이다.

소비 기반 모델이라 사용하는 만큼에 대해서만 비용이 지불된다.

​

수직 스케일링 : 가상 머신에 CPU 또는 RAM을 더 추가하여 리소스의 기능을 늘리거나 줄인다.

수평 스케일링 : 수요에 따라 리소스의 수를 추가(스케일 아웃)하거나 뺀다(스케인 인).

​

클라우드의 안정성

시스템이 장애로부터 복구하고 기능을 계속할 수 있는 능력이다. 

분산형 디자인을 통해 전 세계 지역에 리소스를 배포할 수 있다. 

한 지역에 심각한 문제가 생겨도 다른 지역은 계속 가동되고 실행된다.

​

클라우드의 예측 가능성

**1) 클라우드의 성능**

필요한 리소스를 예측.

자동 스케일링, 부하 분산, 고가용성.

추가적인 리소스의 필요에 따라 자동 스케일링.

​

**2) 클라우드의 비용**

리소스를 모니터링하여 리소스 사용 실시간 추적.

클라우드 분석 정보를 사용하여 향후 비용을 예측하고 리소스를 조정

잠재적인 클라우드 지출을 예측.

​

클라우드의 보안 및 거너번스 이점

클라우드 기능은 거버넌스 및 규정 준수를 지원.

배포된 모든 리소스가 회사 표준과 정부 규제 요구 사항을 충족하는지 확인.

표준변경시 배포된 모든 리소스를 새 표준으로 업데이트 가능.

적절한 거버넌스 공간을 확립하면 클라우드 공간의 보안 및 관리를 잘 유지할 수 있다.

​

클라우드 관리

필요에 따라 리소스 배포 크기를 자동으로 스케일링.

미리 구성된 템플릿을 기반으로 리소스를 배포.

리소스의 상태를 모니터링하고 실패한 리소스를 자동으로 변경.

자동 경고 수신으로 실시간으로 성능을 인식.
