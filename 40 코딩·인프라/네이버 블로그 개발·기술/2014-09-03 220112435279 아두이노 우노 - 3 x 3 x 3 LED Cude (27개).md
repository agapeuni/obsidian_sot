# 2014-09-03 220112435279 아두이노 우노 - 3 x 3 x 3 LED Cude (27개)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220112435279&categoryNo=982
- 게시일: 2014. 9. 3. 20:28

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMjkg/MDAxNzU4NDI3MjQwODA4.yPdUrbkSM8ZBWV8OUhMazzdSKHa35gtJbTrbCWVwrTsg.R8IGt1vmKCfND1ciY_12L3QWr7MfOo1ZjazUfdXVCo0g.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001.png?type=w80_blur)

3*3*3 LED Cude를 실험해 보기 해당 부품과 공구를 준비했습니다.

그동안 기본적인 실험들로 어느 정도 내공이 쌓였으니 LED Cube 실험에 들어가 봅니다.

​

3*3*3큐브와 4*4*4큐브를 고려해서 빨강 LED 100개와 220옴 저항 100개를 구매하였습니다. 

  * 3*3*3 Cube = 27 개

  * 4*4*4 Cube = 64 개 

​

그런데 생각보다 저항은 그렇게 많이 필요하지 않습니다. 

실험할 때 220옴 저항을 많이 사용해야 겠네요.

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다.

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 빨강 LED 27개 (3 X 3 X3)

  * 220 옴 저항 9개

  * 점퍼선 12개

  * 납땜 인두 세트.

![](https://postfiles.pstatic.net/20160506_208/agapeuni_1462514117805gvHvQ_JPEG/20140903_004533.jpg?type=w966)

납땜을 위해서 작업대, 인두기, 땜납을 작업하기 좋은 위치에 배치하고서 안전을 위해 주변을 정리합니다.

![](https://postfiles.pstatic.net/20160506_7/agapeuni_1462514118155yfSsv_JPEG/20140903_004822.jpg?type=w80_blur)

LED의 애노느(+) 핀을 직각으로 구부린뒤 작업대에 두고서 납땜으로 연결합니다.

작업을 마치면 수평에 모든 애노느(+)가 서로 연결되게 됩니다. 

![](https://postfiles.pstatic.net/20160506_163/agapeuni_1462514120235WrQpV_JPEG/20140903_182445.jpg?type=w80_blur)

LED의 애노느(+) 핀이 서로 살짝 닿게 두고서 수초이내로 납땜을 합니다.

너무 오랜 시간 인두로 핀을 대고 있으면 LED가 손상될 수 있습니다. 

살짝 대고 순간 납땜한다는 느낌으로 2~3초정도에 승부를 봅니다. 

![](https://postfiles.pstatic.net/20160506_256/agapeuni_14625141208613a1MC_JPEG/20140903_182645.jpg?type=w80_blur)

3개씩 3줄 연결하였습니다. 아직 납땜이 서투른지 모양이 반듯하진 않네요. ㅎㅎ

![](https://postfiles.pstatic.net/20160506_297/agapeuni_1462514118395Lmgd7_JPEG/20140903_011205.jpg?type=w966)

이젠 수직열을 기준으로 캐소드(-)들을 서로 연결합니다.

윗층의 LED 줄의 캐소드(-) 핀의 끝을 살짝 구부려 놓으면 작업하기가 보다 쉽습니다.

![](https://postfiles.pstatic.net/20160506_172/agapeuni_1462514118978sYhfv_JPEG/20140903_012803.jpg?type=w966)

계속된 납땜 작업으로 이제 두판 작업하였습니다. 이젠 한판만 더 납땜하면 됩니다.

![](https://postfiles.pstatic.net/20160506_237/agapeuni_1462514119209tI6Cw_JPEG/20140903_013315.jpg?type=w80_blur)

3개의 판을 작업하고 나서 층별로 애노드(+) 핀을 서로 연결합니다. 

층별로 공통애노드가 3개가 생성되어 집니다. (1층, 2층, 3층)

![](https://postfiles.pstatic.net/20160506_24/agapeuni_1462514119623orCvG_JPEG/20140903_015235.jpg?type=w966)

위에서 보면 각층별로 좌우의 핀을 구부려서 가운데 핀과 서로 연결하였고 

가운데 핀을 Female 점퍼선을 꼽기쉽에 살짝 구부려 놓았습니다.

![](https://postfiles.pstatic.net/20160506_225/agapeuni_1462514121394oobfy_JPEG/20140903_202034.jpg?type=w966)

220옴 저항으로 LED 다리끝과 브레드보드의 GND와 서로 연결합니다. 모두 9개의 줄입니다.

220옴 저항이 많아서 브레드보드에 꼽기 편하도록 핀을 짧게 잘랐습니다. 저항이 보드의 에 딱붙어 있네요. 

![](https://postfiles.pstatic.net/20160506_104/agapeuni_1462514121176iwlSM_JPEG/20140903_202013.jpg?type=w80_blur)

**아두이노 우노**(Arduino UNO)의 2번핀부터 13번핀까지 점퍼선을 꼽습니다

2번핀부터 10번핀이 LED 바닥에 연결하게되고 11번부터 13번핀이 각층별로 하나씩 연결하게 됩니다.

![](https://postfiles.pstatic.net/20160506_268/agapeuni_1462514121694KY3yS_JPEG/20140903_202635.jpg?type=w80_blur)

​

**아두이노 우노**(Arduino UNO)에서 LED 수직 다리에 연결한 저항에 하나씩 연결합니다. 모두 9개입니다.

물놀이장 가면 색깔 레일을 시원하게 한사람씩 지나가는데 얼핏보면 유원지 놀이시설 같아 보입니다.

​

![](https://postfiles.pstatic.net/20160506_122/agapeuni_1462514122003aWUVD_JPEG/20140903_202644.jpg?type=w966)

마지막으로 각층별로 점퍼선을 연결합니다. 총 3개입니다.

![](https://postfiles.pstatic.net/20160506_24/agapeuni_1462514120037jB2FJ_JPEG/20140903_030649.jpg?type=w966)

​

이번 실험을 위해 완성된 모습입니다. 

![](https://postfiles.pstatic.net/20160506_96/agapeuni_1462514119824qbS8h_JPEG/20140903_030021.jpg?type=w966)

LED 조명이 그리 밝지 않아서 잘 보이도록 주변조명을 끄고서 촬영하였습니다. 

이번 실험은 납땜 작업이 있어서 시간이 참 많이 소요되었습니다.ㅎㅎ
