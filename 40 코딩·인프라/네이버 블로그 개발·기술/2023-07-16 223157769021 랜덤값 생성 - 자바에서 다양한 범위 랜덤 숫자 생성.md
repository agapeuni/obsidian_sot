자바(Java)에는 Math 클래스의 random 메서드와 java.util.Random 클래스를 이용하면 난수를 생성할 수 있다. Math 클래스의 random 메서드는 0부터 1 미만인 double형의 실수값을 반환한다. 반면 Random 클래스는 데이터형에 따른 메서드들이 각각 존재하고 있어서 원하는 유형의 반환값을 선택할 수 있다. 그리고 난수를 설정할 때 시드(Seed) 값을 설정해 줄 수 있다.

​

그럼 Random 클래스의 nextInt() 메서드와 Math 클래스 random() 메서드로 4가지 예제를 만들어 보고 결과를 살펴보자.

import java.util.Random; public class RandomTest { public static void main(String[] args) { Random random = new Random(); System.out.print("0 ~ 9"); System.out.print("\t\t\t"); System.out.print("1 ~ 10"); System.out.print("\t\t\t"); System.out.print("3 ~ 7"); System.out.print("\t\t\t"); System.out.print("2 ~ 4"); System.out.print("\t\t\t"); System.out.println(); System.out.print("======"); System.out.print("\t\t\t"); System.out.print("======"); System.out.print("\t\t\t"); System.out.print("======"); System.out.print("\t\t\t"); System.out.print("======"); System.out.print("\t\t\t"); System.out.println(); for (int i = 0; i < 10; i++) { // 0부터 9까지 랜덤값을 생성 int i1_1 = random.nextInt(10); System.out.print(i1_1); System.out.print("\t"); // 0부터 9까지 랜덤값을 생성 int i2_1 = (int) (Math.random() * 10); System.out.print(i2_1); System.out.print("\t"); System.out.print("\t"); // 1부터 10까지 랜덤값을 생성 int i1_2 = random.nextInt(10) + 1; System.out.print(i1_2); System.out.print("\t"); // 1부터 10까지 랜덤값을 생성 int i2_2 = (int) (Math.random() * 10 + 1); System.out.print(i2_2); System.out.print("\t"); System.out.print("\t"); // 3부터 7까지 랜덤값을 생성 int i3_1 = random.nextInt(5) + 3; System.out.print(i3_1); System.out.print("\t"); // 3부터 7까지 랜덤값을 생성 int i3_2 = (int) (Math.random() * 5 + 3); System.out.print(i3_2); System.out.print("\t"); System.out.print("\t"); // 2부터 4까지 랜덤값을 생성 int i1_4 = random.nextInt(3) + 2; System.out.print(i1_4); System.out.print("\t"); // 2부터 4까지 랜덤값을 생성 int i2_4 = (int) (Math.random() * 3 + 2); System.out.print(i2_4); System.out.print("\t"); System.out.print("\t"); System.out.println(); } } }

Random 클래스는 유사 난수를 생성하므로 보안적인 요구사항이 있는 경우에는 다른 방법을 사용해야 한다. Java 8부터는 java.util.concurrent.ThreadLocalRandom 클래스를 사용하여 보다 더 안전한 난수를 생성할 수 있다. ThreadLocalRandom 클래스를 사용하여 난수를 생성하는 방법은 java.util.Random 클래스와 유사하다. 

​

ThreadLocalRandom.current() 메서드를 사용하여 현재 스레드의 ThreadLocalRandom 객체를 얻는다. 그런 다음 nextInt() 메서드를 사용하여 정수 범위 내의 난수를 생성하거나, nextInt(int origin, int bound) 메서드를 사용하여 특정 범위 내의 난수를 생성할 수 있다. nextDouble() 메서드를 사용하면 부동소수점 형태의 난수를 얻을 수 있다. ThreadLocalRandom 클래스는 각 스레드에 대해 별도의 난수 생성기를 제공하므로 동시성 환경에서 안전하게 사용할 수 있다.

​

다음은 ThreadLocalRandom 클래스를 사용하여 난수를 생성하는 코드이다.

import java.util.concurrent.ThreadLocalRandom; public class RandomExample { public static void main(String[] args) { // 정수 범위 내의 난수 생성 int randomNumber = ThreadLocalRandom.current().nextInt(); System.out.println("랜덤 숫자: " + randomNumber); // 특정 범위 내의 난수 생성 int min = 1; int max = 100; int randomInRange = ThreadLocalRandom.current().nextInt(min, max + 1); System.out.println("1부터 100까지의 랜덤 숫자: " + randomInRange); // 부동소수점 난수 생성 double randomDouble = ThreadLocalRandom.current().nextDouble(); System.out.println("랜덤 소수: " + randomDouble); } }
