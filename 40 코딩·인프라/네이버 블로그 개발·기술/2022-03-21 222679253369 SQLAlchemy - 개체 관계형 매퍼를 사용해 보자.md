1\. SQLAlchemy 개요

SQLAlchemy는 파이썬에서 사용할 수 있는 SQL 툴킷 및 ORM(Object-Relational Mapping) 라이브러리다. SQLAlchemy를 사용하면 데이터베이스에 접근하고 조작하는 작업을 쉽게 수행할 수 있다. 개체 관계 매퍼는 말 그대로 객체와 관계로 매핑해 주는 것이다. SQLAlchemy는 데이터베이스를 단순한 테이블이 아닌 관계형 엔진으로 간주한다.

​

SQLAlchemy는 SQL 데이터베이스와 상호 작용하기 위한 고수준 인터페이스를 제공한다. 이를 통해 데이터베이스에 대한 SQL 쿼리를 작성하고 실행할 수 있으며, 데이터베이스 스키마를 정의하고 조작하는 데 사용할 수 있다.

​

SQLAlchemy는 파이썬 데이터베이스 애플리케이션 개발에 매우 유용한 도구로 알려져 있으며, 데이터베이스 조작 및 ORM 기능을 필요로 하는 프로젝트에서 널리 사용된다. SQLAlchemy는 다양한 데이터베이스 시스템과 호환되며, 데이터베이스 종류에 관계없이 일관된 인터페이스를 제공한다. SQLite, PostgreSQL, MySQL, Oracle 등 다양한 데이터베이스와 함께 사용할 수 있다._​_

4\. 테이블 조회

member 테이블의 전체 레코드를 조회하는 예제이다. 결과를 ResultSet과 pandas의 DataFrame으로 출력한다.

import sqlalchemy as db import pandas as pd db_url = "sqlite:///data/db/member.db" engine = db.create_engine(db_url, echo=True) connection = engine.connect() metadata = db.MetaData() member = db.Table("member", metadata, autoload=True, autoload_with=engine) # SELECT * FROM member query = db.select([member]) ResultProxy = connection.execute(query) ResultSet = ResultProxy.fetchall() for rs in ResultSet: print(rs) print(pd.DataFrame(ResultSet))

ResultProxy : 쿼리에서 반환된 데이터를 얻기 위해 사용한다. execute 함수에 의해 반환된 개체이다.

ResultSet : 쿼리로 요청한 실제 데이터이다. ResultProxy에서 fetchall() 함수를 사용한다.

5\. 조건 검색

**5.1 = 검색**

member 테이블에 특정한 레코드를 조회하는 예제이다. 나이가 33인 데이터를 찾는다.

import sqlalchemy as db import pandas as pd db_url = "sqlite:///data/db/member.db" engine = db.create_engine(db_url, echo=True) connection = engine.connect() metadata = db.MetaData() member = db.Table("member", metadata, autoload=True, autoload_with=engine) print(member.columns.keys()) # SELECT * FROM member where age = 33 query = db.select([member]).where(member.columns.age == 33) ResultProxy = connection.execute(query) ResultSet = ResultProxy.fetchall() for rs in ResultSet: print(rs) print(pd.DataFrame(ResultSet))

**5.2 IN 검색**

member 테이블에 IN 조건으로 검색하고 특정 컬럼(name, age)만 표시한다.

import sqlalchemy as db import pandas as pd db_url = "sqlite:///data/db/member.db" engine = db.create_engine(db_url, echo=True) connection = engine.connect() metadata = db.MetaData() member = db.Table("member", metadata, autoload=True, autoload_with=engine) # SELECT name, age FROM member WHERE name in ('user02', 'user03') query = db.select([member.columns.name, member.columns.age]).where( member.columns.name.in_(["user02", "user03"]) ) ResultProxy = connection.execute(query) ResultSet = ResultProxy.fetchall() for rs in ResultSet: print(rs) print(pd.DataFrame(ResultSet))

**5.3 AND 검색**

member 테이블에 AND 조건으로 검색하는 예제이다.

import sqlalchemy as db import pandas as pd db_url = "sqlite:///data/db/member.db" engine = db.create_engine(db_url, echo=True) connection = engine.connect() metadata = db.MetaData() member = db.Table("member", metadata, autoload=True, autoload_with=engine) # SELECT * FROM member WHERE id >= 2 AND age <= 44 query = db.select([member]).where( db.and_(member.columns.id >= 2, member.columns.age <= 44) ) ResultProxy = connection.execute(query) ResultSet = ResultProxy.fetchall() for rs in ResultSet: print(rs) print(pd.DataFrame(ResultSet))

import sqlalchemy as db import pandas as pd db_url = "sqlite:///data/db/member.db" engine = db.create_engine(db_url, echo=True) connection = engine.connect() metadata = db.MetaData() member = db.Table("member", metadata, autoload=True, autoload_with=engine) # SELECT * FROM member WHERE id < 2 OR age > 44 query = db.select([member]).where( db.or_(member.columns.id < 2, member.columns.age > 44) ) ResultProxy = connection.execute(query) ResultSet = ResultProxy.fetchall() for rs in ResultSet: print(rs) print(pd.DataFrame(ResultSet))

​6\. 테이블 추가

이번에는 데이터를 추가해 보자. 한 건을 추가하는 것과 여러 건을 추가하는 예제이다.

import sqlalchemy as db import pandas as pd import datetime as dt db_url = "sqlite:///data/db/member.db" engine = db.create_engine(db_url, echo=True) connection = engine.connect() metadata = db.MetaData() member = db.Table("member", metadata, autoload=True, autoload_with=engine) # 단일데이터 추가 query = member.insert().values(name='user0', age=66, birth_date=dt.date.today()) result = connection.execute(query) # 복수데이터 추가 query = member.insert() values = [{'name': 'user07', 'age': 77, 'birth_date': dt.date.today()}, { 'name': 'user08', 'age': 88, 'birth_date': dt.date.today()}] result = connection.execute(query, values) result.close()
