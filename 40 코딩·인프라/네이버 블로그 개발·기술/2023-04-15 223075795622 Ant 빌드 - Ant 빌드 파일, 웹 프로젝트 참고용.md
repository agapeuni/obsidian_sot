1\. Ant 빌드

Ant는 플랫폼에 독립적으로 실행 가능해 윈도우, 리눅스에서 실행할 수 있다. 복잡한 명령 대신 XML 기반으로 Task를 설정하기 때문에 작성하기 어렵지 않다. Web 프로젝트 진행시 Ant로 빌드환경 구성할 때 참고하기 위해 정리해 본다.

​

​

2\. Ant 빌드 파일

Ant 빌드 파일은 XML 문서로 되어 있다. Ant가 수행할 작업에 관한 정보를 기술한다. Maven으로 사용하기 어려운 특수한 작업을 진행할 때 자유도가 높은 Ant를 사용하는 것도 좋은 대안이 될 수 있다.

​

2.1 <project>

Ant 빌드의 루트 태그이다. 프로젝트를 정의하며 빌드 파일에서 유일하다. name 속성으로 프로젝트 이름을 정의하고 default 속성에 기본적으로 실행할 target을 정의한다. basedir 속성은 기준이 되는 디렉터리를 정의한다. 기본값은 빌드 파일이 위치하는 곳이다.

​

2.2 <target>

project 태그 안에 기술되며 target은 일반적으로 다음과 같이 구분한다. 프로젝트의 특성에 따라 target을 정의하면 된다.

  * prepare 

  * clean

  * copy

  * deploy

​

2.3 <task>

파일 복사, 파일 삭제, 컴파일 등 처럼 실제로 수행할 작업을 정의한다.

​

​

3\. 예제

아래의 코드는 실제 프로젝트에서 사용한 것을 참고로 하여 정리했다.

​

▣ build.xml (Ant 빌드)

<?xml version="1.0" encoding="UTF-8"?> <project name="prj-admin" default="all.deploy" basedir="."> <description>web-project</description> <!-- ================================= property ================================= --> <property name="app.name" value="prj-admin" /> <property name="src.home" value="${basedir}/WEB-INF/src" /> <property name="class.dir" value="${basedir}/WEB-INF/classes" /> <property name="jboss.dir" value="C:/jboss-5.0.0.GA" /> <property name="local.admin.dir" value="C:/admin" /> <property name="local.deploy.dir" value="${local.admin.dir}/deploy/${app.name}.war" /> <property name="server.admin.dir" value="Z:/admin" /> <property name="server.deploy.dir" value="${server.admin.dir}/deploy/${app.name}.war" /> <!-- ================================= classpath ================================= --> <path id="compile.classpath"> <fileset dir="${jboss.dir}/lib"> <include name="**/*.jar" /> </fileset> <fileset dir="${jboss.dir}/common/lib"> <include name="**/*.jar" /> </fileset> </path> <!-- ================================= patternset ================================= --> <patternset id="exclude.deploy"> <exclude name=".settings/**" /> <exclude name=".classpath" /> <exclude name=".project" /> <exclude name=".tomcatplugin" /> <exclude name="build.xml" /> </patternset> <!-- ================================= target: prepare ================================= --> <target name="prepare"> <tstamp> <format property="DSTAMP" pattern="yyyy-MM-dd" /> <format property="TSTAMP" pattern="HH:mm:ss" /> </tstamp> <echo message="Build started at : ${DSTAMP} ${TSTAMP}"> </echo> </target> <!-- ================================= target: clean ================================= --> <target name="local.clean" depends="prepare" description="Delete local directories"> <delete dir="${local.deploy.dir}" /> </target> <target name="server.clean" depends="prepare" description="Delete server directories"> <delete dir="${server.deploy.dir}" /> </target> <target name="all.clean" depends="local.clean, server.clean" description="Delete local/server directories" /> <!-- ================================= target: copy ================================= --> <target name="local.copy" description="Copy local directories"> <copy todir="${local.deploy.dir}" verbose="true"> <fileset dir="${basedir}"> <patternset refid="exclude.deploy" /> </fileset> </copy> </target> <target name="server.copy" description="Copy server directories"> <copy todir="${server.deploy.dir}" verbose="true"> <fileset dir="${basedir}"> <patternset refid="exclude.deploy" /> </fileset> </copy> </target> <target name="all.copy" depends="local.copy, server.copy" description="Copy local/server directories" /> <!-- ================================= target: deploy ================================= --> <target name="touch" description="Touch web.xml"> <touch file="${basedir}/WEB-INF/web.xml" /> </target> <target name="local.deploy" depends="touch" description="Deploy local"> <copy todir="${local.deploy.dir}" verbose="true"> <fileset dir="${basedir}"> <patternset refid="exclude.deploy" /> </fileset> </copy> </target> <target name="server.deploy" depends="touch" description="Deploy server"> <copy todir="${server.deploy.dir}" verbose="true"> <fileset dir="${basedir}"> <patternset refid="exclude.deploy" /> </fileset> </copy> </target> <target name="all.deploy" depends="local.deploy, server.deploy" description="Deploy local/server directories" /> </project>
