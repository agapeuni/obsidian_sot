​

**1\. mongoose 모듈**

mongoose는 Node.js 환경에서 MongoDB 데이터베이스를 사용하기 위한 고급 객체 모델링 도구이다. Mongoose를 사용하면 JavaScript 객체와 MongoDB 문서 간의 매핑을 쉽게 할 수 있다. Mongoose는 MongoDB의 기능을 활용하고 개발자가 데이터베이스 스키마, 모델, 쿼리 등을 정의하고 관리하는 데 도움을 주는 여러 기능을 제공한다.

Node.js에서 mongoose 모듈을 사용하여 간단한 CRUD 기능을 구현해 본다. 

예제에 사용하는 Book 스키마의 필드속성은 제목(title), 년도(year), 가격(price), 등록일(regdt)로 되어 있다.

var BookSchema = mongoose.Schema({title: String, year: String, price: String, regdt: {type: Date, default: Date.now}}); var Book = mongoose.model('Book', BookSchema);

​

**2\. mongoose 사용법**

**1) MongoDB 연결**

'mongodb://localhost/book' 연결문자열과 mongoose.connect() 함수로 mongoDB 에 연결하고 서버를 실행한다.

mongoose.connect('mongodb://localhost/book', function (err) { if (err) { console.log('err = ' + err); throw err; } http.createServer(app).listen(app.get('port'), function () { console.log('http://127.0.0.1:' + app.get('port')); }); });

​

**2) index.html 화면 표시**

'/' 요청시 index.html 파일을 읽어서 화면에 표시한다.

index.html 화면은 책의 정보인 제목, 년도, 가격을 입력하여 생성하는 페이지이다.

app.get('/', function (req, res, err) { fs.readFile('index.html', function (error, data) { res.end(data); }); });

index.html 파일의 전체코드

<!DOCTYPE html> <html> <head> <title>Mongoose Book</title> </head> <body> <h1>Mongoose Book</h1> <form name="book" method="post" action="/create"> <table> <tr> <td>Title</td> <td><input type="text" name="title"/></td> </tr> <tr> <td>Year</td> <td><input type="text" name="year"/></td> </tr> <tr> <td>Price</td> <td><input type="text" name="price"/></td> </tr> <tr> <td></td> <td><button type="submit">Submit</button></td> </tr> </table> </form> <br> <a href="/list">Go to List</a> <hr> </body> </html>

​

**3) Create**

index.html 페이지에서 입력항목에 값을 입력하고 submit 을 클릭하면 '/create'로 POST 방식으로 요청된다.

POST 방식으로 요청된 '/create' 를 처리하기 위해 app.post() 함수를 사용한다.

​

화면에서 입력항목에 대한 값을 req.body.xxx 형태로 받아온다. 예를들면, title 입력항목의 값을 받아오기 위해서는 req.body.title 이다. 제목과 년도, 가격을 받아와서 new Book()으로 생성핸 book 객체에 save() 함수를 실행하면 데이터가 저장된다.

app.post('/create', function (req, res, err) { var book = new Book({title: req.body.title, year: req.body.year, price: req.body.price, regdt: new Date()}); book.save(function (err, data) { if (err) { console.err(err); throw err; } console.log(data); res.send('<h1>Success create</h1><br><a href="/list">Go to List</a> | <a href="/">Regist</a>'); }); });

​

**4) List**

​'/list' 요청시 books 컬랙션의 값을 목록으로 받아와 화면에 표시한다.

app.get('/list', function (req, res, err) { var books = new Book(); Book.find().select().exec(function (err, books) { if (err) { console.err(err); throw err; } console.log(books); res.send(books); }); });

​

**5) View**

​'/view/:title' 요청시 /view 뒤에 있는 /:title 값을 req.params.title로 받을 수가 있다.

/view/mean 이라고 입력하면 /view 요청주소에 mean이라는 제목을 갖는 데이터를 조회한다.

app.get('/view/:title', function (req, res, err) { var books = new Book(); Book.find({'title': req.params.title}, function (err, book) { if (err) { console.err(err); throw err; } console.log(book); res.send(book); }); });

​

**6) Insert**

'/doInsert/:title/:year/:price' 요청시 /doInsert 뒤에 있는 각각의 값을 파라미터로 받아올 수가 있다.

/doInsert/제목/년도/가격으로 각각의 값을 파라미터로 받아와서 save() 함수를 호출해서 데이터를 등록한다.​

app.get('/doInsert/:title/:year/:price', function (req, res, err) { var book = new Book({title: req.params.title, year: req.params.year, price: req.params.price, regdt: new Date()}); book.save(function (err, data) { if (err) { console.err(err); throw err; } console.log(data); res.send('<h1>Success doInsert</h1><br><a href="/list">Go to List</a> | <a href="/">Regist</a>'); }); });

​

**7) Update**

'/doUpdate/:title/:year/:price' 요청시 /doUpdate 뒤에 있는 각각의 값을 파라미터로 받아올 수가 있다.

/doUpdate/제목/년도/가격으로 각각의 값을 파라미터로 받아와서 update() 함수를 호출해서 해당 제목의 데이터를 변경한다.

app.get('/doUpdate/:title/:year/:price', function (req, res, err) { Book.update({title: req.params.title}, { year: req.params.year, price: req.params.price }, function (err, numberAffected, data) { if (err) throw err; console.log(data); res.send('<h1>Success doUpdate</h1><br><a href="/list">Go to List</a> | <a href="/">Regist</a>'); }); });

​

**8) Delete**

'/doDelete/:title' 요청시 /doDelete 뒤에 있는 값을 파라미터로 받아올 수가 있다.

/doDelete/제목 으로 값을 파라미터로 받아와서 remove() 함수를 호출해서 해당 제목의 데이터를 삭제한다.

app.get('/doDelete/:title', function (req, res, err) { Book.remove({title: req.params.title}, function (err) { if (err) throw err; res.send('<h1>Success doDelete</h1><br><a href="/list">Go to List</a> | <a href="/">Regist</a>'); }); });

​
