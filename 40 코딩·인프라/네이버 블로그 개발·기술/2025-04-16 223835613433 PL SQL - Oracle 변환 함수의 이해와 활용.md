# 2025-04-16 223835613433 PL SQL - Oracle 변환 함수의 이해와 활용

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223835613433&categoryNo=982
- 게시일: 2025. 4. 16. 20:00

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfNzMg/MDAxNzQ0Nzc5NzI2MjYx.kqPOl2BoqqfeDWrTN9iCJfZdlIgEzBd8pDVHBy-25P4g.xnjsMFna7V_1HkuC2DW0RYBYdzhZxlrOWG9dcH_hudkg.PNG/PL_SQL-001_\(9\).png?type=w80_blur)

​

Oracle SQL에서 변환 함수(Conversion Function)는 가장 널리 사용되며 핵심적인 기능을 수행하는 함수 중 하나이다. 이러한 함수들은 서로 다른 데이터형 간의 변환을 가능하게 함으로써 데이터의 활용도를 극대화하고, 보다 유연한 쿼리 작성을 지원한다. 대표적인 변환 함수로는 TO_DATE, TO_CHAR, TO_NUMBER가 있으며, 이들의 사용법과 특징은 다음과 같다.

**​**

**​**

**1\. TO_DATE 함수**

TO_DATE 함수는 문자열을 날짜 형식으로 변환할 때 사용된다. 기본 문법은 다음과 같다.

TO_DATE(문자스트링, 서식, NLS_DATE_LANGUAGE)

서식을 명시하지 않을 경우, 기본 형식인 DD-MMM-YY가 자동으로 적용된다. 변환 대상 문자열은 220자를 초과할 수 없으며, 시간 표현 시 12시간제 또는 24시간제 중 하나를 선택하여 지정할 수 있다.

​

**주요 날짜 서식 마스크**

**서식** |  **설명**  
---|---  
MM |  01~12로 월을 표시함  
MONTH |  월 이름을 9자리 문자로 출력하며, 나머지는 공백으로 채움  
MON |  월 이름을 3자리로 표시함  
D |  1~7 사이의 요일을 숫자로 표시함  
DD |  01~31 범위의 날짜를 표시함  
DDD |  001~365의 형식으로 연중 날짜를 표시함  
DAY |  요일의 전체 철자를 9자리로 출력하고, 남는 부분은 공백 처리  
HH, HH12 |  1~12까지의 시간을 표시 (12시간제)  
HH24 |  0~23까지의 시간을 표시 (24시간제)  
MI |  분(0~59)  
SS |  초(0~59)  
SSSS |  자정부터 경과된 전체 시간을 초 단위로 표시함  
  
**​**

**​**

**2\. TO_CHAR 함수**

TO_CHAR 함수는 숫자나 날짜 데이터를 문자열로 변환하는 데 사용된다. 특히 날짜 데이터를 원하는 형식으로 출력하고자 할 때 유용하다. 예를 들어 다음과 같은 형식으로 사용할 수 있다.

TO_CHAR(SYSDATE, 'MONTH DDTH YYYY')

이와 같이 사용할 경우, 결과는 MAY 28TH 2007과 같이 출력된다. MONTH, Month, month는 각각 MAY, May, may와 같이 대소문자 및 공백 처리 방식에 차이를 둔다.

**​**

**​**

**3\. TO_NUMBER 함수**

TO_NUMBER 함수는 문자열을 숫자 데이터로 변환할 때 사용된다. 예컨대 문자로 저장된 입사일을 기준으로 근속년수를 계산하고자 할 경우, 해당 문자열을 TO_NUMBER를 통해 숫자형으로 변환한 후 계산을 수행할 수 있다. 다만, 이 함수를 빈번히 사용할 경우 시스템 부하가 발생할 수 있으므로 주의가 필요하다.

​

**주요 숫자 서식 마스크**

**서식** |  **설명**  
---|---  
9 |  유효한 자릿수로 간주되며, 앞의 0은 공백으로 표시됨  
0 |  숫자 앞뒤에 0이 있을 경우 이를 표시함 (예: 09999)  
$ |  통화 기호 표시  
B |  정수가 0이 아니면 일부를 공백으로 반환함  
MI |  음수일 경우 -, 양수일 경우 끝에 공백을 표시함  
S |  음수는 -, 양수는 + 부호를 표시함  
PR |  음수일 경우 < >로 감싸며, 양수는 공백을 추가함  
D |  소수점 위치를 지정함  
G |  그룹 분리자(쉼표 등)를 지정함  
C |  ISO 통화기호를 반환함  
L |  로컬 통화기호를 반환함  
, |  천 단위 구분 기호 삽입  
. |  소수점 위치 지정  
V |  10의 제곱수를 지정함 (예: 999V99는 100을 곱한 형태)  
EEEE |  지수 표기법 사용  
RM, rm |  로마 숫자로 표시함 (대문자/소문자 구분)  
FM |  출력 시 앞뒤 공백 제거  
  
**​**

**​**

**4\. 주요 예시**

\-- 문자열을 날짜로 변환 SELECT TO_DATE('070528','MMDDYY') FROM dual; \-- 결과: 28-MAY-07 SELECT TO_DATE('March 30', 'MONTH DD') FROM dual; \-- 결과: 30-MAR-07 \-- 날짜 연산 SELECT TO_DATE('070528','YYMMDD') + 3 FROM dual; \-- 결과: 31-MAY-07 \-- 날짜를 문자열로 변환 SELECT TO_CHAR(SYSDATE, 'YYYY-MM-DD') FROM dual; \-- 결과: 2007-05-28 SELECT TO_CHAR(SYSDATE, 'MONTH DDTH YYYY') FROM dual; \-- 결과: MAY 28TH 2007 \-- 숫자 변환 예시 SELECT TO_NUMBER('100.00', '9G999D99') FROM dual; \-- 결과: 100 

​

TO_DATE, TO_CHAR, TO_NUMBER 함수는 Oracle SQL을 활용함에 있어 필수적으로 이해해야 할 기본이자 강력한 도구이다. 각 함수의 용도와 서식 마스크를 숙지하고 적절히 활용함으로써, 데이터 처리의 정확성과 효율성을 크게 높일 수 있다. 특히 업무 보고서 작성이나 데이터 분석 시 자주 사용되므로, 반복적인 연습과 실전 적용이 권장된다.
