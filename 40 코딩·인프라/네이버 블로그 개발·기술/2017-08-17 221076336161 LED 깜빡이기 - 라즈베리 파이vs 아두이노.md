한동안 라즈베리 파이를 갖고 놀다가 한쪽 구석에 놓여 있는 아두이노를 함께 꺼내봅니다. 아래의 그림에서 상단에는 라즈베리 파이와 연결한 브레드보드이고 아래는 아두이노 우노와 연결한 브레드보드입니다. 이번에서 하나의 LED를 점등하는 실험이지만 이후에 진행하는 코드를 테스트하기 위해서 6개씩 연결해 두었습니다.

​

이번 예제는 프로그래밍 언어에 있어서 "Hello World"와 같은 예제와 같은 LED 깜빡이기입니다. 

단순한 예제이지만 아두이노 스케치와 Pi4J를 사용한 자바로 코딩해 보려고 합니다.

​

아두이노 스케치 코드입니다. 

7번 핀을 pin1 변수를 선언하고 OUTPUT으로 설정하고 반복 loop()에서 여 0.5초 간격으로 LED를 On/Off 합니다.

int pin1 = 7; int delayTime = 500; void setup() { pinMode(pin1, OUTPUT); } void loop() { digitalWrite(pin1, HIGH); delay(delayTime); digitalWrite(pin1, LOW); delay(delayTime); }

​

다음은 Pi4J로 구현한 자바 코드입니다. 

1번 핀을 pin1 변수로 선언하고 OUT으로 설정한 뒤 0.5초 간격으로 LED를 On/Off 합니다.

package com.pi4j.book.ch06; import static com.pi4j.util.Pi4jUtil.delay; import com.pi4j.io.gpio.GpioController; import com.pi4j.io.gpio.GpioFactory; import com.pi4j.io.gpio.GpioPinDigitalOutput; import com.pi4j.io.gpio.PinState; import com.pi4j.io.gpio.RaspiPin; public class S0601_OneLed { GpioController gpio = GpioFactory.getInstance(); GpioPinDigitalOutput pin1; int delayTime = 500; void setup() { System.out.println("S0601_OneLed"); pin1 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_01, PinState.LOW); } void loop() { System.out.println("LED isOn"); pin1.high(); delay(delayTime); System.out.println("LED isOff"); pin1.low(); delay(delayTime); } void shutdown() { gpio.shutdown(); } public static void main(String[] args) { S0601_OneLed instance = new S0601_OneLed(); instance.setup(); for (int i = 0; i < 7; i++) { instance.loop(); } instance.shutdown(); } }

​

다음은 LED 깜빡이기 코드를 실행한 영상입니다. 아래쪽이 아두이노 우노이고 위쪽은 라즈베리 파이입니다. 

아두이노 우노는 좌측에 있는 핀번호가 7이고 라즈베리 파이는 좌측에 있는 핀번호가 1번입니다.
