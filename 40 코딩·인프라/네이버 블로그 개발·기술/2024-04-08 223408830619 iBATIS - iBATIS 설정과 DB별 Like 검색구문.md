**iBatis LIKE 검색**

iBatis를 적용하여 LIKE 검색에서 % 기호를 사용할 때 주의가 필요하다.

​

**MySQL**

SELECT * FROM tbl_name WHERE column_name LIKE "%$username$%"

**ORACLE**

SELECT * FROM tbl_name WHERE column_name LIKE '%' || #username# || '%'

**MS-SQL**

SELECT * from tbl_name WHERE column_name LIKE '%' + #username# + '%'

변수명을 샵(#)으로 둘러싸는 것과 달러($)로 둘러싸는 것의 차이점을 알 필요가 있다. #의 경우에는 Prepare Statement로 등록이 되어 로그를 찍어봐도 ?로 치환된 이후 값이 대입된다. 하지만 $의 경우 바로 값이 치환되어 특정 변수가 바로 DB에 입력되므로 보안에 좀 더 신경을 써야 할 것으로 생각된다.
