Float는 무엇입니까?

Float는 CSS 위치 지정 속성입니다. 그 목적을 이해하기 위해 먼저 인쇄 디자인을 살펴볼 필요가 있습니다. 인쇄 레이아웃에서 이미지는 필요에 따라 텍스트가 이미지를 감싸도록 페이지에 설정할 수 있습니다. 이것은 일반적으로 "텍스트 줄 바꿈"이라고 합니다.

​

아래에 그 예가 있습니다.

![](https://postfiles.pstatic.net/MjAyMzA4MDVfMjcw/MDAxNjkxMjE5NTk2NTA0.i2r8JWQXoO5LBMQqRjQdJWW09w3uFc-63Oe4H3kzKRAg.69vOF6FOczxCvDcGbGr4ZTid7crdplka95glIc2VaRog.PNG.agapeuni/img.png?type=w80_blur)

페이지 레이아웃 프로그램에서 텍스트가 있는 상자는 텍스트 줄 바꿈을 적용하거나 무시하도록 지시할 수 있습니다. 텍스트 줄 바꿈을 무시하면 단어가 거기에 없었던 것처럼 이미지 위로 바로 흐를 수 있습니다. 이것은 해당 이미지가 페이지 _흐름_ 의 일부인지 아닌지의 차이입니다. 웹 디자인은 인쇄 디자인과 매우 유사합니다.

![](https://postfiles.pstatic.net/MjAyMzA4MDVfMTI4/MDAxNjkxMjE5NjAxMTM1.F76zNjiysBqbK8ExeJkp5OEiWEUt6kGUsICR7RG7xvgg.Lshin4m4Zh4hArMDoqnyXkqPeXgQ6UpJvdUD7e-PZ88g.PNG.agapeuni/img.png?type=w80_blur)

​

웹 디자인에서 CSS float 속성이 적용된 페이지 요소는 텍스트가 주변에 흐르는 인쇄 레이아웃의 이미지와 같습니다. float 요소는 웹 페이지 흐름의 일부로 남아 있습니다. 이것은 절대 위치 지정을 사용하는 페이지 요소와는 확연히 다릅니다. 인쇄 레이아웃의 텍스트 상자에 페이지 줄 바꿈을 무시하도록 지시한 경우와 같이 절대 위치에 있는 페이지 요소는 웹 페이지의 흐름에서 제거됩니다. 절대적인 위치로 배치된 페이지 요소는 다른 요소의 위치에 영향을 주지 않으며 다른 요소는 서로 접촉 여부에 관계없이 영향을 주지 않습니다.

​

CSS를 사용하여 요소에 float 설정은 다음과 같이 설정합니다.

#sidebar { float: right; }

​

float 속성에는 4 개의 유효한 값이 있습니다. Left 및 Rigit는 Float 요소는 각각 해당 방향입니다. None (기본값)은 요소가 float 하지 않고 해당 요소 부모 요소의 float 값 상속을 보장합니다.

Float 지우기 기술

계속되는 요소가 무엇인지 항상 알고 있는 상황에 있다면 clear를 적용할 수 있습니다. 이것은 추가 요소가 필요하지 않기 때문에 이상적입니다. 물론 일이 일반적으로 그런 식으로 작동하지 않으며 우리는 도구 상자에 더 많은 Float 제거가 필요합니다.

​

Empty Div Method는 말 그대로 빈 div입니다. <div style="clear: both;"></div>. 때로는 <br> 요소 또는 다른 임의의 요소가 사용되는 것을 볼 수 있지만 div는 브라우저 기본 스타일이 없고 특별한 기능이 없으며 일반적으로 CSS 로 스타일이 지정되지 않기 때문에 가장 일반적입니다. 이 방법은 그 존재가 페이지에 전혀 문맥상의 의미가 없고 순수하게 표현을 위해 존재합니다.

​

오버플로 방법 은 상위 요소에 대한 오버플로 CSS 속성 설정에 의존합니다. 이 속성이 부모 요소에서 auto 또는 hidden으로 설정되면 부모는 float를 포함하도록 확장되어 후속 요소에 대해 효과적으로 지워집니다. 이 방법은 추가 요소가 필요하지 않을 수 있으므로 의미가 아름답습니다. 그러나 이것을 적용하기 위해 새 div를 추가하는 경우 빈 div 메서드와 마찬가지로 의미가 없고 적응력이 떨어집니다. 또한 overflow 속성은 Float를 지우는 데 특별히 사용되지 않는다는 점을 명심하십시오. 콘텐츠를 숨기거나 원하지 않는 스크롤바를 트리거 하지 않도록 주의하십시오.

​

쉬운 지우기 방법 은 영리한 CSS 의사 선택기 ( :after)를 사용하여 float를 지웁니다. 부모에 오버플로를 설정하는 대신 "clearfix"와 같은 추가 클래스를 적용합니다. 그런 다음이 CSS를 적용합니다.

.clearfix:after { content: "."; visibility: hidden; display: block; height: 0; clear: both; }

​

이렇게 하면 Float를 지우는 부모 요소 뒤에 보기에서 숨겨진 약간의 콘텐츠가 적용됩니다. 이전 브라우저를 수용하기 위해 추가 코드를 사용해야 합니다.

Float 문제

Float는 종종 _깨지기 쉽다_ 는 이유로 몰매를 _맞습니다._ 이러한 취약성의 대부분은 IE 6과 그에 포함된 수많은 float 관련 버그에서 비롯됩니다. 점점 더 많은 디자이너가 IE 6에 대한 지원을 중단함에 따라 신경 쓰지 않을 수도 있지만 여기서 관심을 갖는 사람들에게는 빠른 요약이 있습니다.

​

푸시 다운 은 플로팅 된 항목 내부의 요소가 __ Float _자체_ (일반적으로 이미지) _보다 더 넓은_ 증상입니다. 대부분의 브라우저는 Float 외부에 이미지를 렌더링 하지만 튀어나온 부분이 다른 레이아웃에 영향을 주지 않습니다. IE는 이미지를 포함하도록 Float를 확장하며 종종 레이아웃에 큰 영향을 미칩니다. 일반적인 예는 메인 콘텐츠에서 튀어나온 이미지가 사이드 바를 아래로 내리는 것입니다.

대안

이미지 주위에 텍스트 줄 바꿈이 필요한 경우 실제로 float에 대한 대안이 없습니다. 말하자면, 불규칙한 모양 주위에 텍스트를 감싸는 다소 스마트한 기술을 확인하십시오. 그러나 페이지 레이아웃에는 확실히 선택 사항이 있습니다. 이것은 여러 가지 방법으로 float의 유연성과 절대 위치의 강도를 결합한 매우 흥미로운 기술입니다. CSS3에는 널리 채택될 경우 페이지 레이아웃 기술이 선택되는 템플릿 레이아웃 모듈이 있습니다.
