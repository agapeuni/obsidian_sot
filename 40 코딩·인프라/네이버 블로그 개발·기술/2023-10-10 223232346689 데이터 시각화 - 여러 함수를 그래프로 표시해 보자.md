1\. 함수의 그래프

import numpy as np import matplotlib.pyplot as plt x = np.linspace(-5, 5, 1001) y = 2*x - 3 plt.plot(x, y) plt.grid(color = 'green', linestyle = ':') plt.show()

위 코드는 파이썬을 사용하여 그래프를 그리는 간단한 예제이다. 코드는 주어진 수식을 사용하여 직선을 그래프로 그리고, 그래프에 녹색 점선 격자를 추가하여 시각적으로 나타낸다. 코드를 단계별로 살펴보자.

​

**1) import numpy as np**

'numpy' 라이브러리를 가져와서 'np'라는 별칭으로 사용한다. 

'numpy'는 수치 계산을 위한 파이썬 라이브러리로, 배열과 행렬과 같은 다차원 데이터를 다루기 쉽게 해준다.

​

**2) import matplotlib.pyplot as plt**

'matplotlib.pyplot' 라이브러리를 가져와서 'plt'라는 별칭으로 사용한다.

'matplotlib'은 데이터 시각화를 위한 라이브러리로, 그래프를 그리는 데 사용된다.

​

**3) x = np.linspace(-5, 5, 1001)**

'numpy'의 'linspace' 함수를 사용하여 '-5'부터 '5'까지의 범위에서 총 1001개의 등간격으로 값을 생성한다. 

그 값을 'x' 변수에 저장하는데 이것은 x축의 값을 나타냅니다.

​

**4) y = 2*x - 3**

'x' 값에 대해 연산을 수행하여 'y' 값을 계산하고 저장한다. 

간단한 수식인 '2*x - 3'을 사용하여 'y' 값을 계산한다. 이것은 직선의 방정식을 나타낸다.

​

**5) plt.plot(x, y)**

'x'와 'y' 값을 사용하여 그래프를 그린다. 

'plt.plot' 함수를 호출하여 'x' 값을 x축으로, 'y' 값을 y축으로 사용하는 선 그래프를 생성한다.

​

**6) plt.grid(color='green', linestyle=':')**

그래프에 격자를 추가한다.

격자의 색상은 녹색('green')이고, 격자의 선 스타일은 점선(':')으로 설정된다.

​

**7) plt.show()**

마지막으로 그래프를 화면에 표시한다. 이 명령을 실행하면 그래프가 시각적으로 표시된다.

6\. 정규분포 그래프

import numpy as np import matplotlib.pyplot as plt def f(x, m, sigma): coef = 1 / (np.sqrt(2*np.pi) * sigma) return coef * np.exp(-(x-m)**2 / (2*sigma**2)) x = np.linspace(-10, 10, 101) m = 0 for sigma in [0.7, 1, 2, 4, 6]: fx = f(x, m, sigma) s = str(sigma) plt.plot(x, fx, label=r'$\sigma$='+s) plt.legend() plt.grid(color='green', linestyle=':') plt.show()
