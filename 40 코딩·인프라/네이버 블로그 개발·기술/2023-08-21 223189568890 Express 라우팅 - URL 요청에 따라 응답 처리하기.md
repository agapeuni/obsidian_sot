**1\. 개요**

라우팅은 URI를 기준으로 HTTP 요청에 대한 애플리케이션의 응답을 결정하는 방법을 말한다.

HTTP 요청에 대한 핸들러 함수를 만들어 두면 URI가 일치할 때 라우팅이 일어난다.

![](https://postfiles.pstatic.net/MjAyMzA4MjFfMTM5/MDAxNjkyNjA4ODU2NjEy.qOUfLooVGHTxPBk8e_q0TPCNoJPM1mGKMKfBsFVPKnwg.Zl5tOo_raT7KX5lhJuWQ4v2mGE94U3fvw4zDvAinVmwg.PNG.agapeuni/img.png?type=w80_blur)

​

**2\. 예제**

다음은 요청 URL에 대하여 그에 대응하는 응답을 적용해 보는 간단한 예제이다.

var express = require('express'); var app = express(); app.get('/', function(req, res) { res.send('/'); }); app.get('/a*', function(req, res) { res.send('/a*'); }); var b1 = function(req, res, next) { console.log('b1'); next(); }; var b2 = function(req, res, next) { console.log('b2'); next(); }; var b3 = function(req, res) { res.send('/b*'); }; app.get('/b*', [ b1, b2, b3 ]); var server = app.listen(1337, function() { console.log('http://127.0.0.1:1337'); });

코드를 보면 요청 URL은 '/' 와 '/a*'와 '/b*'에 대해서 기술되어 있다.

(참고로 '*' 표시는 모든 문자열을 허용하는 기호, '?'는 하나의 문자열을 허용하는 기호)

​

요청 URL에 a와 b가 포함되는 URL에 대해 각각 어떻게 동작하는지 살펴보자.

'/' 와 '/a*'는 하나의 콜백 함수가 대응되어 있고 '/b*'는 [ b1, b2, b3 ] 와 같이 3개의 함수가 대응되어 있다.

​

핸들러 함수에는 HTTP 요청에 대한 응답 오브젝트인 res를 파라미터로 받아온다.

응답 메서드를 사용하여 클라이언트 요청에 응답을 보낸다. 예제 코드에서는 send() 메서드를 사용했다.

​

아래와 같은 응답 메서드가 있다.

  * res.send() - 다양한 유형의 응답을 전송.

  * res.sendFile() - 파일을 스트림의 형태로 전송.

  * res.sendStatus() - 응답 상태 코드 응답 본문으로 전송.

  * res.json() - JSON 응답을 전송.

  * res.jsonp() - JSONP 지원을 통해 JSON 응답을 전송.

  * res.redirect() - 요청의 경로를 재지정.

  * res.download() - 파일이 다운로드.

  * res.end() - 응답 프로세스를 종료.
