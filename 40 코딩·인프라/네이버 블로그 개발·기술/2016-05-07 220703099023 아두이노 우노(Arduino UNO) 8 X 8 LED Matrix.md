​

이번 실험은 8 X 8 LED Matrix를 이용하여 몇 가지 재미있는 실험을 해보려고 합니다.

​

![](https://storep-phinf.pstatic.net/james_special/original_22.png?type=p50_50)

이번 실험의 준비물은 아래와 같습니다.

​

  * **아두이노 우노(Arduino UNO)**

  * 브레드보드

  * 8 X 8 LED Matrix

  * 560옴 저항 16개

  * 74HC595AN 칩 2개

  * 단선 2개

  * 점퍼선 상당히 많이 (30개 정도)

​

![](https://postfiles.pstatic.net/20160506_292/agapeuni_1462546122674AcvEc_JPEG/20160506_232941.jpg?type=w966)

​

이번 실험에서 사용하는 LED Matrix를 브레드보드에 적절한 위치에 꼽아둡니다.

​

![](https://postfiles.pstatic.net/20160506_212/agapeuni_1462546121544jVMUo_JPEG/20160506_232701.jpg?type=w966)

​

560옴 저항을 LED Matrix 모든 핀에 연결해 둡니다. 

이때 브레브보드에 잘 연결하여 합선이 되지 않도록 주의합니다. 저항의 다리가 서로 닿지 않도록 간격을 벌려둡니다.

![](https://postfiles.pstatic.net/MjAyMzA2MjZfMTg4/MDAxNjg3NzkwMjE5ODI0.JhbZoYHuFnt2ITuf-aXQCHd_P0LjHvMxLOxbo5pt-ykg.PP8IE5WoFhL5wHV2DcYQc81hZ6LO_KkAD4oWAVcSTvEg.JPEG.agapeuni/20160506_232641.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyMzA2MjZfMzAg/MDAxNjg3NzkwMjE2MDAw.2dCOLXF_D22mEmd31NCwduE5nK4AzeErULKN1XhDAJsg.N38XcE_6jdyuVLneRrxf_dooNnGZ8s8x9dh81hWaXY0g.JPEG.agapeuni/20160506_232559.jpg?type=w80_blur)

​

LED Matrix의 위쪽 1번부터 8번 핀까지 560옴 저항을 연결하였습니다.

​

![](https://postfiles.pstatic.net/20160506_299/agapeuni_14625461210439eoin_JPEG/20160506_232614.jpg?type=w966)

​

LED Matrix의 아래쪽 9번부터 16번 핀까지도 560옴 저항을 연결합니다.

​

![](https://postfiles.pstatic.net/20160506_241/agapeuni_1462546120432oYMsW_JPEG/20160506_232553.jpg?type=w966)

​

3개의 핀으로 직렬 입력값을 16개의 출력값을 만들기 위해 74HC595AN 칩을 사용합니다.

74595칩을 보면 아래 적색 화살표에 반원이 파인 곳을 기준으로 핀번호를 확인합니다.

![](https://postfiles.pstatic.net/20160507_133/agapeuni_1462547814602iFueo_JPEG/20160506_232821.jpg?type=w80_blur)

​

74595칩 두 개를 브레드보드에 적당한 간격으로 꼽아둡니다. 그리고 초록색 단선으로 8번 핀에 GND 접지를 연결해 놓습니다.

![](https://postfiles.pstatic.net/20160506_188/agapeuni_1462546121846ET089_JPEG/20160506_232732.jpg?type=w80_blur)

아두이노 우노(Arduino UNO)의 2번과 4번 6번 핀에 점퍼선을 연결합니다.

![](https://postfiles.pstatic.net/20160506_17/agapeuni_1462546119835k2qNu_JPEG/20160506_232519.jpg?type=w80_blur)

노란색 점퍼선이 DATA 선이고 초록색 점퍼선이 LATCH, 갈색 점퍼선이 CLOCK입니다.

노란색은 74595칩의 14번 핀에 초록색은 74595칩의 12번 핀 그리고 갈색은 74595칩의 11번 핀에 꼽습니다.

![](https://postfiles.pstatic.net/20160506_238/agapeuni_1462546118805XSnl9_JPEG/20160506_232444.jpg?type=w80_blur)

​

두 개의 74595칩은 아래와 같이 연결하게 됩니다. 

![](https://postfiles.pstatic.net/20160507_189/agapeuni_14625485342905n4JU_JPEG/20140830_134345.jpg?type=w80_blur)

위의 그림을 참고하여 11번 핀과 11번 핀 이 파란색으로 12번 핀과 12번 핀이 노란색으로, 9번 핀과 14번 핀이 하얀색으로 서로 연결갑니다. 

![](https://postfiles.pstatic.net/20160506_179/agapeuni_1462546118542ClJYU_JPEG/20160506_232434.jpg?type=w80_blur)

​

먼저 왼쪽에 있는 ROW 용 74595에 VCC(10번 핀, 16번 핀)와 GND(13번 핀)를 연결합니다.

![](https://postfiles.pstatic.net/20160506_135/agapeuni_1462546118349vxV5i_JPEG/20160506_232427.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/20160506_177/agapeuni_1462546118094K3SiK_JPEG/20160506_232416.jpg?type=w80_blur)

​

그리고 오른쪽에 있는 Column 용 74595에도 VCC(10번 핀, 16번 핀)와 GND(13번 핀)를 연결합니다.

![](https://postfiles.pstatic.net/20160506_103/agapeuni_1462546117827fh9N0_JPEG/20160506_232410.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/20160506_290/agapeuni_1462546117580Ke4A7_JPEG/20160506_232358.jpg?type=w80_blur)

**▣ 소스코드 : led_matrix_1.ino**

#define DATA 2 #define LATCH 4 #define CLOCK 6 int delayTime = 500; void setup() { pinMode(LATCH, OUTPUT); pinMode(CLOCK, OUTPUT); pinMode(DATA, OUTPUT); } void loop() { showLine1(); displayOff(); showLine2(); displayOff(); showSquare(); showSquare(); displayOff(); } void displayOff() { displayMatrix(~B00000000, B00000000); } void showLine1() { displayMatrix(~B10000000, B11111111); displayMatrix(~B01000000, B11111111); displayMatrix(~B00100000, B11111111); displayMatrix(~B00010000, B11111111); displayMatrix(~B00001000, B11111111); displayMatrix(~B00000100, B11111111); displayMatrix(~B00000010, B11111111); displayMatrix(~B00000001, B11111111); } void showLine2() { displayMatrix(~B11111111, B10000000); displayMatrix(~B11111111, B01000000); displayMatrix(~B11111111, B00100000); displayMatrix(~B11111111, B00010000); displayMatrix(~B11111111, B00001000); displayMatrix(~B11111111, B00000100); displayMatrix(~B11111111, B00000010); displayMatrix(~B11111111, B00000001); } void showSquare() { displayMatrix(~B11110000, B11110000); displayMatrix(~B00001111, B11110000); displayMatrix(~B00001111, B00001111); displayMatrix(~B11110000, B00001111); } void displayMatrix(byte bCol, byte bRow) { digitalWrite(LATCH, LOW); shiftOut(DATA, CLOCK, MSBFIRST, bCol); // COL shiftOut(DATA, CLOCK, MSBFIRST, bRow); // ROW digitalWrite(LATCH, HIGH); delay(delayTime); }

**▣ 소스코드 : led_matrix_2_random.ino**

#define DATA 2 #define LATCH 4 #define CLOCK 6 int rows[] = { B00000001, B00000010, B00000100, B00001000, B00010000, B00100000, B01000000, B10000000 }; int row, col = 0; int count = 0; void setup() { pinMode(LATCH, OUTPUT); pinMode(CLOCK, OUTPUT); pinMode(DATA, OUTPUT); randomSeed(analogRead(0)); } void loop() { row = random(8); col = random(8); displayLed(row, col, 20); count++; if (count == 100) { delay(1000); count = 0; } } void displayLed(int row, int col, int delayPeriod) { digitalWrite(LATCH, LOW); shiftOut(DATA, CLOCK, MSBFIRST, ~rows[col]); // COL shiftOut(DATA, CLOCK, MSBFIRST, rows[row]); // ROW digitalWrite(LATCH, HIGH); delay(delayPeriod); }

**​**

**▣ 소스코드 : led_matrix_4_moving_arrows.ino**
