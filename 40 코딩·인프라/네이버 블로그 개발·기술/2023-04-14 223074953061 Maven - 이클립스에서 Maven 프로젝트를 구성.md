1\. Maven 프로젝트 생성

진행하는 프로젝트에서 자바 오픈소스 프로젝트를 수정하는 일이 생겨 이클립스 2022-06 버전을 설치했다. 

오픈소스 프로젝트의 빌드 환경은 Maven이다. 이클립스에서 메이븐으로 프로젝트를 시작하는 과정을 정리해 본다.

![](https://postfiles.pstatic.net/MjAyMzA0MTRfMjM2/MDAxNjgxNDc3MjU1MzMy.AyZhMVYah6FsgodZrI4P1EWdblJfhLoeJU5yjoArB9Ig.FkLtd0vHstQALWUZNIjHALiHJnjT6izAMh2DUfi4VqIg.PNG.agapeuni/img.png?type=w80_blur)

​

신규 프로젝트 생성을 실행하고 "Maven > Maven Project"를 선택한다.

![](https://postfiles.pstatic.net/MjAyMzA0MTRfMTQ1/MDAxNjgxNDc3MjU5NTQz.iFYWeW-BD3S29WvkL8HpsJBf33EkhZ26QZO1qBUA8n0g.5R_mN767EC2c3b7n0NbpFkqB4yB8f5YrIvor_WUHUMUg.PNG.agapeuni/img.png?type=w80_blur)

​

New Maven Project에서 아래의 그림과 같이 체크박스를 선택한다.

![](https://postfiles.pstatic.net/MjAyMzA0MTRfMTM3/MDAxNjgxNDc3MjY1NzM5.d3Tsb7SHDbvaEDL8CgXXMm1rhNmK5yQ2JfxHbAPW5T4g.3YbAE-f80rlBk5BgMC6sOlj7FgxdgPcVI-vZhJQnNGYg.PNG.agapeuni/img.png?type=w80_blur)

​

다음과 같이 프로젝트 정보를 입력하고 "Finish" 버튼을 클릭한다.

![](https://postfiles.pstatic.net/MjAyMzA0MTRfMTEx/MDAxNjgxNDgxODY4MDc2.3APw_8spfigNybvMixuHOfXO3TU7PqPdXmKZBME-nLYg.GhNhppsZPGbseEkALd-8qSbe9f3pX-zrYXcLpxSEPVcg.PNG.agapeuni/image.png?type=w80_blur)

  * Group Id : com.oneway

  * Aitifact Id : mvn-demo

  * Version : 0.0.1-SNAPSHOT

  * Packing : jar

  * Name : Maven Demo

  * Description : Maven Demo

​

Group Id - 프로젝트 속하는 그룹 식별 값으로 패키지 형식으로 기술한다.

Artifact Id - 프로젝트나 모듈을 나타내는 식별 값이다.

Version - 프로젝트 결과의 버전을 나타낸다.

Packaging - 만들어지는 결과형태를 선택한다. (jar, war)

​

​

2\. Maven 프로젝트 확인

다음과 같이 프로젝트가 구성되었다.

mvn-demo │ pom.xml │ ├─src │ ├─main │ │ ├─java │ │ └─resources │ └─test │ ├─java │ └─resources └─target ├─classes │ └─META-INF │ │ MANIFEST.MF │ │ │ └─maven │ └─com.oneway │ └─mvn-demo │ pom.properties │ pom.xml │ └─test-classes 

​

입력한 정보를 기준으로 pom.xml 파일이 생성되었다.

<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd"> <modelVersion>4.0.0</modelVersion> <groupId>com.oneway</groupId> <artifactId>mvn-demo</artifactId> <version>0.0.1-SNAPSHOT</version> <name>﻿Maven Demo</name> <description>﻿Maven Demo</description> </project>

​

​

자동생성된 pom.xml 파일을 일부 수정하면서 dependency에 junit을 추가했다.

<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd"> <modelVersion>4.0.0</modelVersion> <groupId>com.oneway</groupId> <artifactId>mvn-demo</artifactId> <version>0.0.1-SNAPSHOT</version> <name>Maven Demo</name> <description>Maven Demo</description> <url>http://maven.apache.org</url> <properties> <project.build.sourceEncoding>utf-8</project.build.sourceEncoding> <project.reporting.outputEncoding>utf-8</project.reporting.outputEncoding> </properties> <dependencies> <dependency> <groupId>junit</groupId> <artifactId>junit</artifactId> <version>4.13.2</version> <scope>test</scope> </dependency> </dependencies> <build> <plugins> <plugin> <groupId>org.apache.maven.plugins</groupId> <artifactId>maven-compiler-plugin</artifactId> <version>3.8.1</version> <configuration> <source>1.8</source> <target>1.8</target> </configuration> </plugin> </plugins> </build> </project>

4\. Maven 골(Goal) 실행

자주 사용하는 메이븐 골(Goal)이다.

1) mvn compile - 소스 코드를 컴파일 한다.

![](https://postfiles.pstatic.net/MjAyMzA0MTRfMjcw/MDAxNjgxNDg0MTE2OTI1.2eTslPJjT_AqgwIFVSM53SJHoetwBjLrVxwHbWXE2bIg.U0LpO5Dkd_RwxURL5UJJRhahmX4Zb-UGItpHO39gBncg.PNG.agapeuni/image.png?type=w80_blur)

​

2) mvn install - 로컬 리포지토리에 패키지를 설치한다.
