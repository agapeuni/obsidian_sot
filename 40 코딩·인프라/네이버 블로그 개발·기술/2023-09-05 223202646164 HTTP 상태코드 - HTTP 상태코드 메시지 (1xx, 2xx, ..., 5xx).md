# 2023-09-05 223202646164 HTTP 상태코드 - HTTP 상태코드 메시지 (1xx, 2xx, ..., 5xx)

HTTP 상태 코드는 웹 서버가 클라이언트 요청에 대한 응답을 전달할 때 사용하는 숫자 코드로, 요청이 성공적으로 처리되었는지 또는 어떤 문제가 발생했는지를 나타낸다. HTTP 상태 코드는 1xx, 2xx, 3xx, 4xx 및 5xx 범주로 나눌 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA5MDVfMjc3/MDAxNjkzODYzMjk5ODYx.sCN_1p0027Zho4Bmp_5he3N8ikTr_gNR_bk6P4vSlfQg.4Ppjm_FCI7RcC6aoNK4YwVTKz7O-dTnCh6IS8HcwMfwg.JPEG.agapeuni/img.jpg?type=w80_blur)

[출처] https://dev.to/bisrategebriel/http-status-codes-101-6jh

  * HTTP 상태 코드 (1**) : 정보 응답(informational responses)을 의미

  * HTTP 상태 코드 (2**) : 성공 응답(successful responses)을 의미

  * HTTP 상태 코드 (3**) : 리디렉션(redirects)을 의미

  * HTTP 상태 코드 (4**) : 클라이언트 오류(client errors)를 의미

  * HTTP 상태 코드 (5**) : 서버 오류(server errors)를 의미

​

​

1xx (Informational - 정보 전달)

메시지 |  설명  
---|---  
100 Continue |  서버가 요청 헤더를 수신했으며 클라이언트는 요청 본문 전송을 계속해야 한다  
101 Switching Protocols |  스위칭 프로토콜 요청자가 서버에 프로토콜 전환을 요청했다  
103 Early Hints |  초기 힌트 서버가 응답을 준비하는 동안 브라우저가 리소스 사전 로드를 시작할 수 있도록 Link 헤더와 함께 사용된다  
  
​

​

2xx (Successful - 성공)

메시지 |  설명  
---|---  
200 OK |  성공적인 HTTP 요청에 대한 표준 응답이다  
201 Created |  요청이 충족되었으며 새 리소스가 생성되었다   
202 Accepted |  요청이 처리를 위해 수락되었지만 처리가 완료되지 않았다  
203 Non-authoritative Information |  요청이 성공적으로 처리되었지만 다른 소스의 정보를 반환하고 있다  
204 No Content |  요청이 성공적으로 처리되었지만 콘텐츠를 반환하지 않았다  
205 Reset Content |  요청이 성공적으로 처리되었지만 내용을 반환하지 않고 있으며 요청자가 문서 보기를 재설정해야 한다  
206 Partial Content |  클라이언트가 보낸 범위 헤더로 인해 서버가 리소스의 일부만 배달하고 있다  
  
​

​

3xx (Redirection - 리디렉션)

메시지 |  설명  
---|---  
300 Multiple Choices |  사용자는 링크를 선택하고 해당 위치로 이동할 수 있습니다. 최대 5개의 주소   
301 Moved Permanently |  요청한 페이지가 새 URL로 이동되었다   
302 Found |  요청한 페이지가 일시적으로 새 URL로 이동되었다   
303 See Other |  요청한 페이지는 다른 URL에서 찾을 수 있다  
304 Not Modified |  요청된 페이지가 마지막 요청 이후 수정되지 않았음을 나타낸다  
307 Temporary Redirect |  요청한 페이지가 일시적으로 새 URL로 이동되었다  
308 Permanent Redirect |  요청한 페이지가 새 URL로 영구적으로 이동되었다  
  
​

​

4xx (Client Error - 클라이언트 오류)

메시지 |  설명  
---|---  
400 Bad Request |  구문이 잘못되어 요청을 수행할 수 없다  
401 Unauthorized |  요청이 합법적인 요청이었지만 서버가 응답을 거부하고 있다. 인증이 가능하지만 실패했거나 아직 제공되지 않은 경우 사용  
402 Payment Required |  향후 사용을 위해 예약  
403 Forbidden |  요청이 합법적인 요청이었지만 서버가 응답을 거부하고 있다  
404 Not Found |  요청한 페이지를 찾을 수 없지만 나중에 다시 사용할 수 있다  
405 Method Not Allowed |  해당 페이지에서 지원되지 않는 요청 메서드를 사용하여 페이지에 대한 요청이 생성되었다  
406 Not Acceptable |  서버는 클라이언트가 승인하지 않은 응답만 생성할 수 있다  
407 Proxy Authentication Required |  클라이언트가 먼저 프록시를 사용하여 자신을 인증해야 한다  
408 Request Timeout |  요청을 기다리는 동안 서버 시간이 초과되었다  
409 Conflict |  요청이 충돌하여 요청을 완료할 수 없다  
410 Gone |  요청한 페이지를 더 이상 사용할 수 없다  
411 Length Required |  내용 길이가 정의되지 않았다. 서버가 요청이 없으면 요청을 수락하지 않는다   
412 Precondition Failed |  서버에서 false로 평가된 요청에 지정된 전제 조건  
413 Request Entity Too Large |  요청 엔티티가 너무 크기 때문에 서버가 요청을 수락하지 않는다  
414 Request-url Too Long |  URI가 너무 길어서 서버가 요청을 수락하지 않는다. POST 요청을 쿼리 정보가 긴 GET 요청으로 변환할 때 발생한다  
415 Unsupported Media Type |  미디어 유형이 지원되지 않으므로 서버가 요청을 수락하지 않는다  
416 Range Not Satisfiable |  클라이언트가 파일의 일부를 요청했지만 서버가 해당 부분을 제공할 수 없다   
417 Expectation Failed |  서버가 예상 요청 헤더 필드의 요구 사항을 충족할 수 없다  
  
​

​

5xx (Server Error - 서버 오류)

메시지 |  설명  
---|---  
500 Internal Server Error |  더 이상의 특정 메시지가 적합하지 않을 때 제공되는 일반 오류 메시지  
501 Not Implemented |  서버가 요청 방법을 인식하지 못하거나 요청을 수행하는 기능이 부족하다  
502 Bad Gateway |  서버가 게이트웨이 또는 프록시 역할을 하고 있으며 업스트림 서버로부터 잘못된 응답을 받았다  
503 Service Unavailable |  서버를 현재 사용할 수 없다 (오버로드 또는 다운됨)  
504 Gateway Timeout |  서버가 게이트웨이 또는 프록시 역할을 하고 있으며 업스트림 서버로부터 적시에 응답을 받지 못했다  
505 HTTP Version Not Supported |  서버가 요청에 사용된 HTTP 프로토콜 버전을 지원하지 않는다  
511 Network Authentication Required |  네트워크 액세스를 얻으려면 클라이언트를 인증해야 한다
