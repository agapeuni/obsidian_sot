​

JSTL(JavaServer Pages Standard Tag Library)은 JSP(JavaServer Pages)에서 사용되는 태그 라이브러리다. JSTL에는 문자열 자르기 기능을 위한 커스텀 태그가 내장되어 있지 않는다. 직접 커스텀 태그를 작성하여 원하는 기능을 구현할 수 있다.

​

지정한 길이를 넘어서는 문자열을 자르는 커스텀 태그를 만들어 보자. 먼저 태그 클래스(StringCut)를 만들고 doStartTag()와 doEndTag()를 구현한다. 그리고 나서 TLD(Tag Library Descriptor) 파일을 생성하여 태그를 정의한다. TLD 파일에 정의된 커스텀 태그를 JSP 파일에서 사용한다.

![](https://postfiles.pstatic.net/MjAyMzA2MTdfMjE4/MDAxNjg3MDA5NzQ1MDc0.YDPv0piuuuSd0aeTfqZdVjsgrYxDg_DDV0aaEa3MPJog.Nhrr3nqj8SLgVogKZZlxCAFGa7CW3u22Ou_eWya66wgg.PNG.agapeuni/img.png?type=w80_blur)

**1\. Tag Class**

먼저 커스텀 태그 클래스를 작성한다.

​

파일 : StringCutTag.java

package comm.tag; import javax.servlet.jsp.JspException; import javax.servlet.jsp.tagext.TagSupport; public class StringCutTag extends TagSupport { private static final long serialVersionUID = 1L; private int length; private String value; public void setLength(int length) { this.length = length; } public void setValue(String value) { this.value = value; } @Override public int doEndTag() throws JspException { length = 0; value = null; return EVAL_PAGE; } @Override public int doStartTag() throws JspException { try { byte[] strByte = value.getBytes(); // 출력 String 길이가 짧으면 그냥 출력 if (strByte.length <= length || value == null) { pageContext.getOut().println(value); return SKIP_BODY; } // 바이트 길이 만큼 출력후 뒤에 글자를 날림 byte[] tempByte2 = new byte[length]; System.arraycopy(strByte, 0, tempByte2, 0, length); String temp = new String(tempByte2); temp = temp.substring(0, temp.length() - 1) + "..."; // SPAN 태그로 출력 temp = "<span href='#' title=\"" + value + "\">" + temp + "</span>"; pageContext.getOut().println(temp); } catch (Exception e) { e.printStackTrace(); throw new JspException(); } return SKIP_BODY; } }

​

**2\. Tag Library Descriptor**

커스텀 태그 라이브러리 디스크립터를 작성한다.

​

파일 : StringCut.tld

<?xml version="1.0" encoding="UTF-8"?> <!DOCTYPE taglib PUBLIC "-//Sun Microsystems, Inc.//DTD JSP Tag Library 1.2//EN" "http;//java.sun.com/dtd/web-jsptaglibrary_1_2.dtd"> <taglib> <tlib-version>1.0</tlib-version> <jsp-version>1.2</jsp-version> <short-name>tagLibrary</short-name> <tag> <name>StringCut</name> <tag-class>common.tag.StringCutTag</tag-class> <body-content>empty</body-content> <attribute> <name>length</name> <required>true</required> <rtexprvalue>true</rtexprvalue> <type>java.lang.Integer</type> </attribute> <attribute> <name>value</name> <required>true</required> <rtexprvalue>true</rtexprvalue> <type>java.lang.String</type> </attribute> </tag> </taglib>

​

​

**3\. JSP Page**

JSP 페이지에서 커스텀 태그를 사용한다.

​

파일 : StringCut.jsp

<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%> <%@ taglib prefix="m" uri="/WEB-INF/tld/StringCut.tld"%> <% request.setAttribute("test", "문자열 자르는 커스텀 태그 만들기. req"); %> <!DOCTYPE html PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd"> <html> <head> <meta http-equiv="Content-Type" content="text/html; charset=UTF-8"> <title>Insert title here</title> </head> <body> <m:StringCut length="10" value="문자열 자르는 커스텀 태그 만들기. 1" /> <p></p> <m:StringCut length="20" value="문자열 자르는 커스텀 태그 만들기. 2" /> <p></p> <m:StringCut length="30" value="문자열 자르는 커스텀 태그 만들기. 3" /> <p></p> <m:StringCut length="20" value="${test}" /> <p></p> <br> </body> </html>
