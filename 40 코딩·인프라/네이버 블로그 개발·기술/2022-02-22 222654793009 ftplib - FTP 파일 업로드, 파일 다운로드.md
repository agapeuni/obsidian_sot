1\. ftplib 개요

ftplib는 파이썬의 표준 라이브러리인 ftplib에 포함된 모듈이다. 이 모듈은 FTP(파일 전송 프로토콜)를 사용하여 파일을 전송하고 관리하는 기능을 제공한다. ftplib 모듈을 사용하면 FTP 서버에 연결하고 파일을 업로드하거나 다운로드할 수 있다. FTP 서버에 대한 인증(credentials)을 제공하고, 디렉토리를 탐색하고, 파일을 업로드하거나 다운로드하는 등의 작업을 수행할 수 있다.

​

파이썬에 내장되어 있는 ftplib 라이브러리를 사용하여 FTP로 파일을 다운로드하고 업로드 하는 예제이다. ftplib는 FTP 서버와의 상호 작용을 간단하게 처리할 수 있는 강력한 도구입니다. 파일 전송, 디렉토리 탐색, 파일 및 디렉토리 생성 등 다양한 FTP 작업을 수행할 수 있다. 예제 코드 수행을 위해 별도의 FTP 서버가 필요하다. Window에서 FTP 서버를 구축해도 되고 FileZilla Server를 설치하여 FTP 서버를 구축해도 좋다. 

​

2\. FTP 서버 구축

개인적으로 손쉽게 작업할 수 있는 라즈베리 파이로 FTP 서버를 구축해 두었다. 

​

PC에서 라즈베리 파이에 SSH로 접속해 아래의 명령어를 실행한다.

vsftpd.conf 파일에서 FTP Welcome 메세지를 변경하고 vsftpd를 재시작한다.

$ sudo nano /etc/vsftpd.conf

$ sudo service vsftpd restart

3\. FTP 서버 접속

FTP 서버에 접속하여 Welcome 메세지를 표시하고 /home/pi 홈디렉토리 목록을 표시해 보자.

​

소스 코드 : ftp_1.py

import ftplib # FTP 서버 접속 with ftplib.FTP("192.168.0.16") as ftp: try: # FTP 서버 로그인 ftp.login("pi", "pi") # Webcome Banner 표시 print(ftp.getwelcome()) print() # 홈디렉터리 목록 표시 print(ftp.dir()) except ftplib.all_errors as e: print("FTP error:", e)

5\. 파일 다운로드

이번에는 FTP 서버에 있는 파일을 파이썬을 실행하는 PC에 다운로드 해보자.

\- 서버 : /home/pi/nodejs/node-v11.15.0-linux-armv6l.tar.xz

\- 로컬 : d:/nodejs/node-v11.15.0-linux-armv6l.tar.xz

![](https://postfiles.pstatic.net/MjAyMjAyMjJfMjYz/MDAxNjQ1NTE4ODYxMDg5.ijU2ziD53kA3t70NvmkmpEME3-Cp0OVcJF3J1G5c7zYg._N7pw4pfJgZ4bkjjJqOTfExKVqIYJ7DKXuNpnuT1DnEg.PNG.agapeuni/4.png?type=w80_blur)

​

소스 코드 : ftp_3.py

# 파일 다운로드 import ftplib import os STR_226 = "226 Transfer complete." # FTP 서버 파일 ftp_server_file = "/home/pi/nodejs/node-v11.15.0-linux-armv6l.tar.xz" # 로컬에 저장할 파일명 local_file = "d:/nodejs/node-v11.15.0-linux-armv6l.tar.xz" # FTP 서버 접속 with ftplib.FTP("192.168.0.16") as ftp: try: # FTP 서버 로그인 ftp.login("pi", "pi") with open(local_file, "wb") as fp: res = ftp.retrbinary("RETR " + ftp_server_file, fp.write) # 다운로드 성공여부 확인 if not res.startswith(STR_226): print("Download failed.") if os.path.isfile(local_file): os.remove(local_file) else: print("Download complete.") except ftplib.all_errors as e: print("FTP error:", e) if os.path.isfile(local_file): os.remove(local_file)

6\. 파일 업로드

이번에는 로컬에 있는 파일을 FTP 서버에 업로드 해보자.

\- 로컬 : d:/nodejs/node-v11.15.0-linux-armv6l.tar.xz

\- 서버 : /home/pi/node.tar.xz

​

소스 코드 : ftp_4.py

import ftplib STR_226 = "226 Transfer complete." # 로컬 파일 local_file = "d:/nodejs/node-v11.15.0-linux-armv6l.tar.xz" # FTP 서버 ftp_server_file = "/home/pi/node.tar.xz" # FTP 서버 접속 with ftplib.FTP("192.168.0.16") as ftp: try: # FTP 서버 로그인 ftp.login("pi", "pi") with open(local_file, "rb") as fp: res = ftp.storlines("STOR " + ftp_server_file, fp) # 업로드 성공여부 확인 if not res.startswith(STR_226): print("Upload failed") else: print("Upload complete.") except ftplib.all_errors as e: print("FTP error:", e)
