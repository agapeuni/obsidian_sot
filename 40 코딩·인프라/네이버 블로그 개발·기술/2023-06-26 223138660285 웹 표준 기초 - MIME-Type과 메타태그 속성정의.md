**1\. MIME-Type**

MIME-Type(Multipurpose Internet Mail Extensions)은 인터넷에서 파일의 형식과 포맷을 식별하기 위해 사용되는 메커니즘이다. MIME-Type은 파일의 내용이 어떤 형식인지를 나타내는 정보를 포함하고 있다. 웹 브라우저와 웹 서버가 파일을 올바르게 해석하고 처리할 수 있도록 도와준다. 

​

MIME-Type은 일반적으로 파일의 확장자(file extension)와 관련되어 있다. 파일 확장자는 파일 이름 뒤에 붙는 점(.)으로 구분되는 문자열입니다. 파일 확장자는 파일의 형식을 가리키는 약속된 약어다. MIME-Type은 파일 확장자와 일치하여 파일의 형식을 식별합니다. 

​

MIME-Type은 다양한 종류의 파일을 식별할 수 있습니다. 예를 들어, "text/html"은 HTML 문서, "application/pdf"는 PDF 문서, "audio/mp3"은 MP3 오디오 파일을 나타낸다. MIME-Type은 확장자와 일치하지 않는 경우에도 사용될 수 있으며, 파일의 실제 형식을 정확하게 식별하는 데 사용된다.

**2\. 메타태그 속성정의**

메타태그(Meta tag)는 HTML 문서의 헤드(\<head>) 섹션에 추가되는 요소로서, 웹 브라우저에게 문서의 메타 데이터(metadata)를 제공한다. 메타 데이터는 문서의 설명, 제작자, 키워드 등과 같은 추가 정보를 포함하며, 검색 엔진이나 소셜 미디어 등에서 활용될 수 있다. 메타태그는 <meta> 요소를 사용하여 정의되며, 다양한 속성을 가질 수 있고 다양한 속성과 값들을 조합하여 사용할 수 있다.

<!-- 캐쉬 완료(파기)시간 정의. --> <META HTTP-EQUIV="Expire" CONTENT="-1"> <!-- 최종수정일을 정의 --> <META HTTP-EQUIV="Last-Modified" CONTENT="Mon,20 Jul 2007 19:30:30"> <!-- 캐쉬가 되지 않게 하는 태그 --> <META HTTP-EQUIV='Cache-Control' CONTENT='no-cache'> <META HTTP-EQUIV='Pragma' CONTENT='no-cache'> <!-- 웹문서의 언어 설정 --> <META HTTP-EQUIV="Content-type" content="text/html; charset=euc-kr"> <!-- 이미지에 마우스오버시 이미지관련 툴바가 생기지 않음 --> <META HTTP-EQUIV="Imagetoolbar" content="no"> <!-- 페이지이동 --> <META HTTP-EQUIV="Refresh" content="15;URL=www.naver.com"> <!-- 페이지 로딩시 트랜지션 효과(장면 전환 효과) --> <META HTTP-EQUIV="Page-Enter" content="RevealTrans(Duration=5/시간 초단위, Transition=21) "> <!-- 문서도 긁어가고, 링크된 문서도 긁어감 --> <META name="robots" content="index,follow" /> <!-- 문서는 긁어가고, 링크는 무시함 --> <META name="robots" content="index,nofollow" /> <!-- 문서도 긁지가지 않고, 링크도 무시함. --> <META name="robots" content="noindex,nofollow" /> <!-- 기타 속성 --> <META name="Subject" content="홈페이지주제 입력"> <META name="Title" content="홈페이지이름 입력"> <META name="Description" content="설명문 입력"> <META name="Keywords" content="키워드 입력"> <META name="Author" content="만든사람 이름"> <META name="Publisher" content="만든단체나회사 이름"> <META name="Other Agent" content="웹책임자 이름"> <META name="Classification" content="카테고리위치(분류)"> <META name="Generator" content="생성프로그램(에디터)"> <META name="Reply-To(Email)" content="메일주소 입력"> <META name="Filename" content="파일이름 입력"> <META name="Author-Date(Date)" content="제작일"> <META name="Location" content="위치"> <META name="Distribution" content="배포자"> <META name="Copyright" content="저작권"> <META name="Robots" content="ALL">
