1\. gRPC 개요

gRPC(gRPC Remote Procedure Calls)는 구글이 개발한 원격 프로세서 호출 프레임워크로 모든 환경에서 실행할 수 있다. 로컬 함수를 호출하는 것처럼 쉽게 분산된 애플리케이션을 연결할 수 있다. 프로세스간 통신은 보통 동기식 요청-응답 방식과 비동기식 이벤트 기반 방식으로 구현된다.

2\. gRPC 설치

인터페이스 정의 언어(IDL, Interface Definition Language)를 사용하여 서비스를 사용하는 방법과 원격으로 호출하는 메서드, 그리고 메서드를 호출하는 파라미터 및 메지지 형식을 정의한다. 서비스 인터페이스 정의는 프로토 파일(.proto)로 표현되고 protoc(프로토콜 버퍼 컴파일러)로 서버 스켈레톤과 클라이언트 스텁 코드를 생성한다.

3\. gRPC 서비스 정의

프로토콜 버퍼를 사용해 서비스 인터페이스를 정의해 보자. 원격에서 사용하는 메서드와 메시지 형식, 입출력 파라미터를 정의한다. 

​

**파일 : PartInfo.proto**

// 프로토콜 버퍼의 버전을 지정한다. syntax = "proto3"; // 네임스페이스처럼 다른 서비스와 충돌을 방지하기 위해 패키지이름을 부여한다. package partinfo; // gRPC의 서비스 인터페이스를 정의한다. service PartInfo { // 부품 정보를 추가하고 부품 ID를 반환하는 원격메소드다. rpc addPart (Part) returns (PartId) {} // 부품 ID를 기준으로 부품 정보를 가져오는 원격메소드다. rpc getPart (PartId) returns (Part) {} } // 부품 정보의 메시지 형식을 정의한다. // 필드에 지정된 번호는 식별하기 위해 사용한다. message Part { string id=1; string name=2; string desc=3; } // 부품 식별 ID 메시지다. message PartId { int32 value=1; }

서비스 로직을 구현하기 위해 서비스 정의를 바탕으로 필요한 파일을 생성한다.

**> python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. ./PartInfo.proto**

4\. 서버 구현

데이터를 저장하기 위해 SQLite를 사용하려고 했는데 간단한 확인용으로 파이썬 딕셔너리를 사용했다. 부품을 저장하기 위한 PartList 딕셔너리를 멤버 변수에 두고 addPart 메서드로 전달받은 값을 id를 키로 해서 Part 딕셔너리를 저장한다. getPart 메서드에서는 id 값을 키로 사용하여 Part 딕셔너리를 가져와서 결과로 리턴한다.

from concurrent import futures import grpc import PartInfo_pb2 import PartInfo_pb2_grpc class PartInfo(PartInfo_pb2_grpc.PartInfoServicer): # Part List PartList = {} def addPart(self, request, context): print("@@addPart call") print("id =", request.id) print("name =", request.name) print("desc =", request.desc) p_id = request.id # Part part = {} part["id"] = p_id part["name"] = request.name part["desc"] = request.desc self.PartList[p_id] = part return PartInfo_pb2.PartId(id=p_id) def getPart(self, request, context): print("@@getPart call") p_id = request.id part = self.PartList[p_id] print("part =", part) ret_id = part["id"] ret_name = part["name"] ret_desc = part["desc"] print("id =", ret_id) print("name =", ret_name) print("desc =", ret_desc) return PartInfo_pb2.Part(id=ret_id, name=ret_name, desc=ret_desc) def serve(): server = grpc.server(futures.ThreadPoolExecutor(max_workers=10)) PartInfo_pb2_grpc.add_PartInfoServicer_to_server(PartInfo(), server) # RPC를 허용하기 위한 포트를 오픈. server.add_insecure_port('[::]:50505') # gRPC 서비스 서버 시작 print("gRPC Server Start...") server.start() # 서버가 중지될 때까지 현재 스레드를 차단. server.wait_for_termination() if __name__ == '__main__': serve()

4\. 클라이언트 구현

PartInfo 서비스에서 정의한 addPart 메서드를 사용하여 Part 데이터를 추가한다. 

getPart 메서드를 사용하여 서버에 저장된 값을 가져온다.

import grpc import PartInfo_pb2 import PartInfo_pb2_grpc def run(): channel = grpc.insecure_channel('localhost:50505') stub = PartInfo_pb2_grpc.PartInfoStub(channel) response = stub.addPart(PartInfo_pb2.Part(id=10, name="T-10", desc="Test Module 10")) response = stub.addPart(PartInfo_pb2.Part(id=20, name="T-20", desc="Test Module 20")) response = stub.addPart(PartInfo_pb2.Part(id=31, name="T-31", desc="Test Module 31")) response = stub.addPart(PartInfo_pb2.Part(id=42, name="T-42", desc="Test Module 42")) for idx in [10, 20, 31, 42]: response = stub.getPart(PartInfo_pb2.PartId(id=idx)) print(response.id) print(response.name) print(response.desc) print() if __name__ == '__main__': run()
