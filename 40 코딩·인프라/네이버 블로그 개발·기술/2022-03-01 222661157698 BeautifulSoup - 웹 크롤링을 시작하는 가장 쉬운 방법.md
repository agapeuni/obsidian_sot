1\. BeautifulSoup 개요 

BeautifulSoup는 HTML과 XML 문서를 파싱하고 스크래핑하는 라이브러리이다. BeautifulSoup은 웹 스크래핑, 데이터 마이닝, 웹 크롤링 등 다양한 웹 데이터 추출 작업에 널리 사용되는 라이브러리다. 웹 스크래핑 작업을 단순화하고, 웹 페이지에서 데이터를 추출하는 데 유용한 기능을 제공하고 있어 원하는 정보를 쉽게 추출할 수 있다. 

​

BeautifulSoup은 잘 구조화된 HTML 또는 XML 문서를 파싱하여 트리 구조로 만들어 준다. 이를 통해 사용자는 문서의 특정 요소에 쉽게 접근하고 원하는 데이터를 추출할 수 있다. BeautifulSoup을 사용하면 HTML 문서의 요소를 탐색하고 조작할 수 있다. CSS 선택자를 사용하여 원하는 요소를 선택하거나, 태그 이름, 클래스, id 등을 사용하여 요소를 필터링할 수 있다. BeautifulSoup은 텍스트 데이터 추출 뿐만 아니라, 요소의 속성(attribute) 정보도 쉽게 가져올 수 있다. 링크 URL, 이미지 소스, 특정 속성 값 등을 추출하는 데 사용할 수 있다.

​

​

2\. 태그로 접근

다음과 같이 pip 명령으로 설치한다.

> pip install beautifulsoup4

​

'html.parser'를 이용하여 HTML을 분석하는 예제이다. html 구조를 기준으로 원하는 엘리먼트를 접근이 가능하다. p엘리먼트에서 next_sibling을 한번 하면 <p></p> 뒤에 있는 공백이 추출되니 next_sibling을 한번 더 사용하여 텍스트로 이동한다. 그런다음 string 속성으로 문자열에 접근한다.

from bs4 import BeautifulSoup html = """ <html> <body> <h1>BeautifulSoup</h1> <p>paragraph 1</p> <p>paragraph 2</p> </body> </html> """ soup = BeautifulSoup(html, 'html.parser') h1 = soup.html.body.h1 p1 = soup.html.body.p p2 = p1.next_sibling.next_sibling print() print("h1 = ", h1) print("p1 = ", p1) print("p2 = ", p2) print() print("h1.string = " + h1.string) print("p.string = " + p1.string) print("p.string = " + p2.string) 

**실행결과**

h1 = <h1>BeautifulSoup</h1> p1 = <p>paragraph 1</p> p2 = <p>paragraph 2</p> h1.string = BeautifulSoup p.string = paragraph 1 p.string = paragraph 2 

3\. ID로 접근

find() 메소드는 지정한 엘리먼트를 검색할 때 사용한다. "id=<값>" 형태로 매개변수를 지정하여 검색된 첫 번째 엘리먼트를 가져온다.

from bs4 import BeautifulSoup html = """ <html> <head> </head> <body> <h1 id="title">BeautifulSoup</h1> <p>paragraph 1</p> <p>paragraph 2</p> <p id="paragraph">paragraph 3</p> </body> </html> """ soup = BeautifulSoup(html, 'html.parser') title = soup.find(id="title") paragraph = soup.find(id="paragraph") print() print("title = ", title) print("paragraph = ", paragraph) print() print("title.string = " + title.string) print("paragraph.string = " + title.string)

실행결과

title = <h1 id="title">BeautifulSoup</h1> paragraph = <p id="paragraph">paragraph 3</p> title.string = BeautifulSoup paragraph.string = BeautifulSoup

4\. 멀티 항목 찾기

find_all() 메소드는 멀티 엘리먼트에 접근한다. 주어진 조건에 해당하는 모든 엘리먼트를 찾는다.

from bs4 import BeautifulSoup html = """ <html> <body> <div class='offiece'> <p>Word</p> <p>Excel</p> </div> <div class='language'> <p>Python</p> <p>Java</p> <p>C#</p> </div> <ul> <li><a href="http://www.naver.com">naver</a></li> <li><a href="http://www.google.com">google</a></li> </ul> </body></html> """ soup = BeautifulSoup(html, 'html.parser') lang = soup.find('div', class_='language') print("lang = ", lang) print() links = soup.find_all("a") for a in links: print("a = ", a) print() for a in links: href = a.attrs['href'] text = a.string print("href = ", href) print("text = ", text)

**실행결과**

lang = <div class="language"> <p>Python</p> <p>Java</p> <p>C#</p> </div> a = <a href="http://www.naver.com">naver</a> a = <a href="http://www.google.com">google</a> href = http://www.naver.com text = naver href = http://www.google.com text = google

find_all() 함수로 접근하면 영화이름을 차례로 접근할 수 있다.

import requests from bs4 import BeautifulSoup req = requests.get("https://movie.naver.com/movie/sdb/rank/rmovie.nhn?sel=pnt&date=20210708") html = req.text soup = BeautifulSoup(html, 'html.parser') movies_rank = soup.find_all('div', class_="tit5") for i in range(len(movies_rank)): print("{:2} : {}".format(i+1, movies_rank[i].get_text().strip()))
