# 2024-05-10 223441986711 VS Code 꿀팁 - Snippet으로 빠르게 컴포넌트 템플릿 만들기

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTJfMjc4/MDAxNzQ0NDYxOTI4MzA3.7qS6zRAZAJFI_ojCRuzODnMCoI5Y8mpHasUTm1PlrWMg.NzTwS87svKoVTrvSmhrqw5aUq1sCohCH0fdvoWkJ4wAg.PNG/Vue_js-001_\(7\).png?type=w80_blur)

​

현재 수행하고 있는 프로젝트에서 Front-End 기술로 Vue.js 3 적용하고 있고 개발도구는 VS Code를 사용한다. Vue.js용 Snippet을 저장해 두고 사용해보자. 참고로 Back-End는 Spring Boot 3를 적용하고 있고 개발도구는 STS를 사용한다.

​

Shift + Ctrl + P 키를 눌러 VS Code 명령창을 열고 snippet을 검색한 뒤에 Snippets: Configure User Snippets을 선택한다.

![](https://postfiles.pstatic.net/MjAyNDA1MTBfNDcg/MDAxNzE1Mjc5MDM5NTA0.2jZQ-crT0bHvFotUk8FShg12XJgHQPS0TkVLeLHHGckg.QiowSca7kSS59uq141byXHweu9cWbuXUIKPNhAVpG10g.PNG/image.png?type=w80_blur)

​

vue를 입력하고 vue (vue)를 선택한다. 그리고 나면 vue.json 파일을 편집할 수 있다.

![](https://postfiles.pstatic.net/MjAyNDA1MTBfMTAz/MDAxNzE1Mjc5MDg2NjYz.X-YkEGx2lUMVb1Qth4nM8rEXMoLDlDFdRay4D6t83yYg.X2esGEFs1x7N7MWiUVYB1ALrDaLPWizGNvXSYiJe3hQg.PNG/image.png?type=w80_blur)

​

다음은 Vue.js Snippet으로 적용할 코드이다. 

<template> <div></div> </template> <script> export default { name: 'VueInit', components: {}, data() { return { sampleData: '' }; }, setup() { }, created() { }, mounted() { }, unmounted() { }, methods: {} } </script>

​

body에 입력하기 위해서 개행문자는 '\n'으로 탭은 '\t'로 변경해야 한다.

![](https://postfiles.pstatic.net/MjAyNDA1MTBfMzUg/MDAxNzE1MjgwODI2MjU4.bMuXSTGVyB_6gbaWpx10rXWVfO-AFrml1aZh8Etn7wYg.A3JSmeZPsjkvXxMJbBI0rWEi5klNSx0Tw_8LgEG0YkUg.PNG/image.png?type=w80_blur)

​

vue.json에 다음과 같이 저장한다.

{ "vue-init": { "prefix": "vue-init", "body": [ "<template>\n\t<div></div>\n</template>\n\n<script>\nexport default {\n\tname: 'VueInit',\n\tcomponents: {},\n\tdata() {\n\t\treturn {\n\t\t\tsampleData: ''\n\t\t};\n\t},\n\tsetup() { },\n\tcreated() { },\n\tmounted() { },\n\tunmounted() { },\n\tmethods: {}\n}\n</script>" ], "description": "vue.js init snippet" } }

​

vue 파일에서 'vue'라고 입력하면 'vue-init'이 표시된다. vue-init을 선택하면 snippet으로 저장한 코드가 자동으로 생성된다.

![](https://postfiles.pstatic.net/MjAyNDA1MTBfMTUz/MDAxNzE1MjgwNTczNjE1.an5xYf-Nt9yU2H0dpetxq-SUtJB1g_715wb-u3OrH9Yg.iZSFEDTAQyqT_eg4hdMXfRXIGyNclIJz-uqr82H8K0sg.PNG/image.png?type=w80_blur)

​

신규로 생성한 VueInit.vue 파일의 기본적인 코드가 자동으로 생성되었다.
