​

jQuery는 웹 페이지의 동적 요소를 쉽게 조작할 수 있도록 도와주는 강력한 JavaScript 라이브러리다. 화면 구현 시 유용하게 사용할 수 있는 몇 가지 jQuery 팁을 정리해보자.

​

**​**

**1\. 속성 변경**

속성 변경: .css(), .attr(), .html(), .text() 등을 사용하여 요소의 스타일이나 속성을 변경할 수 있다.

$('#element').css('color', 'red'); // 글자 색 변경 $('#element').attr('src', 'image.png'); // 이미지 경로 변경 $('#element').html('<strong>새로운 내용</strong>'); // HTML 내용 변경

​

**2\. 커서 변경**

$('body').css('cursor', 'default'); $('body').css('cursor', 'wait');

​

**3\. Select Box에서 선택된 Value 찾기**

$('#search_sale_pernr_s option:selected').val();

​

**4\. Table의 타이틀 Row를 제외한 모든 Row 삭제하기**

$("#data_list_table > tbody").children("tr:not(:first)").remove();

​

**5\. Table의 마지막 Row 다음에 Row 추가하기**

$("#data_list_table > tbody:last").append("<tr><td>값1</td></tr>");

​

**6\. innerHTML 값 Setting 하기**

$("#id_total_price").html("<strong>값</strong>");

​

**7\. 해당 ID로 지정된 HTML 보이기/숨기기**

$("#placeholder").show(); $("#placeholder").hide();

​

**8\. ID로 지정된 Form Submit 하기8**

$("#csf_tab_menu_form").attr("target", "_top"); $("#csf_tab_menu_form").attr("action", "/sabisung/list.jsp"); $("#csf_tab_menu_form").submit();

**​**

**9\. Select Box의 Option 값 확인**

$("#search_sale_unit").find("option").each(function() { alert(this.value); });

​

**10\. Select Box의 특정 값을 가지는 Option 삭제하기**

$("#csf_menu_no").find("option").each(function() { if(this.value == "4") { //alert(this.selected); $(this).remove(); } });

​

**11\. Select Box의 특정 값 이후/이전에 Option 추가하기**

$("#csf_menu_no").find("option").each(function() { if(this.value == "3") { $(this).after("<option value=\"4\">텍스트</option>"); //$(this).before("<option value=\"4\">텍스트</option>"); return false; } });

​

**12\. each Loop에서의 break/continue 방법**

$("#csf_menu_no").find("option").each(function() { if(this.value == "3") { $(this).after("<option value=\"4\">텍스트</option>"); //$(this).before("<option value=\"4\">텍스트</option>"); return false; } });

​

**13\. Select Box의 모든 Option 삭제 후 Default Option 추가하기**

$("#search_sale_pernr_s").find("option").remove() .end().append("<option value=\"\">::사원 선택::</option>");

**​**

**15\. checkbox의 전체 개수와 선택된 개수 구하기**

\- 전체 갯수 : $("input:checkbox[name=is_check]").length \- 선택된 갯수 : $("input:checkbox[name=is_check]:checked").length \- 전체 checkbox 순회하기 $("input:checkbox[name=is_check]").each(function() { this.checked = true; });

​

**16\. checkbox의 체크 여부 확인**

if($("input:checkbox[name=complete_yn]").is(":checked")) == true) { ; //작업 }

**​**

**17\. Table의 특정(ID를 가지는) TR 다음에 TR Row를 추가하기**

$("#table_appr_pernr > tbody").children("tr").each(function() { if(("row_appr_pernr_" + row_no) == $(this).attr('id')) { $(this).after("<tr><td>사비성</td></tr>"); return false; } });

​

**18\. Table의 특정(ID를 가지는) TR Row를 삭제하기**

$("#table_appr_pernr > tbody").children("tr").each(function() { if(("row_appr_pernr_" + row_no) == $(this).attr('id')) { $(this).remove(); return false; } });

​

**19\. 숫자인지 체크**

function is_number(v) { var reg = /^(\s|\d)+$/; return reg.test(v); }
