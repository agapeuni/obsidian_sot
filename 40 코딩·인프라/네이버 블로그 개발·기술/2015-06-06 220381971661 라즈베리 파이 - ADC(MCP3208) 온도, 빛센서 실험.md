## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMzEg/MDAxNzU4NDM4Nzc2ODAw.L3nSCZO_dbGhQg9PVYVfagF9kLk6xEftTwpoziCYKjkg.F6-vNYDyx9Zmzo4bkv6OsqxAKdz5k2YuZCYZLhwYppIg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(11\).png?type=w80_blur)

​

이번의 실험에서 온도와 조도센서에서 읽히는 Analog 값을 라즈베리 파이에서 읽을 수 있도록 ADC인 MCP3208을 사용해 보겠습니다. 참고로 ADC는 아날로그 신호를 디지털 신호로 변환하는 전자회로이며 8채널 12비트입니다. 온도센서와 조도센서의 값을 MCP3208 칩을 통해서 라즈베리 파이에 표시해 보겠습니다. 이 실험을 통해서 다른 센서의 값도 동일한 원리로 적용해 볼 수 있습니다.

​

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

아래는 이번 실험의 준비물입니다. 

  * **MCP3208칩 1개**

  * **조도센서 2개 (****VT90N2 1****개, GL5537 1개)**

  * **온도센서 2개 (LM35DZ 1개, TMP36GT9Z 1개)**

  * **10K옴 저항 2개**

  * **MM 점퍼선 8개**

  * **단선 1X개 (Vcc, GND 연결용)**

![](https://postfiles.pstatic.net/20150606_286/agapeuni_1433584949154WLevp_JPEG/20150605_002645.jpg?type=w80_blur)

1번부터 8번 핀을 채널로 사용할 수 있습니다. 이번 실험에서는 1번부터 4번 핀 4개의 채널을 연결합니다.

![](https://postfiles.pstatic.net/20150606_6/agapeuni_1433585131111vwPT2_PNG/x_scaled_mcp3208.png.pagespeed.ic.t0WtkGjVuS.png?type=w80_blur)

MCP3208칩 10번 핀에 연결된 회색 선운 GPIO 확장 모듈 CE0에 연결하고, 

MCP3208칩 11번 핀에 연결된 흰 색선은 GPIO 확장 모듈 MOSI에 연결하고, 

MCP3208칩 12번 핀에 연결된 검정 선운 GPIO 확장 모듈 MISO에 연결하고, 

MCP3208칩 13번 핀에 연결된 갈색 선운 GPIO 확장 모듈 CLK에 연결합니다. 

![](https://postfiles.pstatic.net/20150606_272/agapeuni_1433584950881XPkuU_JPEG/20150605_004849.jpg?type=w80_blur)

라즈베리 파이 GPIO 확장 모듈이 없는 경우에는 아래의 핀번호를 참고하여 연결하면 됩니다.

MCP3208칩 10번 핀에 연결된 회색 선운 GPIO 24번 핀 CE0에 연결하고, 

MCP3208칩 11번 핀에 연결된 흰 색선은 GPIO 19번 핀 MOSI에 연결하고, 

MCP3208칩 12번 핀에 연결된 검정 선운 GPIO 21번 핀 MISO에 연결하고, 

MCP3208칩 13번 핀에 연결된 갈색 선운 GPIO 23번 핀 SCLK에 연결합니다.

아래의 코드는 ADC 값을 SPI 버스로 채널별로 읽어서 화면에 표시하는 코드입니다.

import spidevimport timeimport os spi = spidev.SpiDev()spi.open(0,0) def ReadAdc(chNum): if chNum > 7 or chNum < 0: return -1 adc = spi.xfer2([1, (8+chNum) << 4, 0]) data = ((adc[1] & 3) << 8) + adc[2] return data def ConvertVolt(data, places): volt = (data * 3.3) / float(1023) volt = round(volt, places) return volt def ConvertTMP36(data, places): temp = ((data * 330) / float(1023)) - 50 temp = round(temp, places) return temp def ConvertLM35DZ(data, places): temp = (data * 100 * 100) / float(1023) temp = round(temp, places) return temp delay = 1 temp1_channel = 0temp2_channel = 1light1_channel = 2light2_channel = 3 while True:​ print "--------------------------------------------"​ temp1_level = ReadAdc(temp1_channel) temp1_volt = ConvertVolt(temp1_level,2) temp1 = ConvertTMP36(temp1_level,2) print("TMP36 : Data {} ({}V) {} C".format(temp1_level, temp1_volt, temp1))​ temp2_level = ReadAdc(temp2_channel) temp2_volt = ConvertVolt(temp2_level,2) temp2 = ConvertLM35DZ(temp2_level,2) print("LM35DZ : Data {} ({}V) {} C".format(temp2_level, temp2_volt, temp2))​ light1_level = ReadAdc(light1_channel) light1_volt = ConvertVolt(light1_level,2) print("Light1: Data {} ({}V)".format(light1_level, light1_volt))​ light2_level = ReadAdc(light2_channel) light2_volt = ConvertVolt(light2_level,2) print("Light2: Data {} ({}V)".format(light2_level, light2_volt)) time.sleep(delay)

**동영상**

온도센서 TMP36은 라즈베리 파이의 Vcc로 적절한 온도를 반환하는데 LM35DZ는 값이 적게 나와 그냥 100을 두 번 곱했습니다. 개인적인 생각은 LM35DZ는 아두이노 우노에서 사용하기 적합한 센서이지 않은가 합니다. 조도 센서는 100 정도 차이가 나기는 하지만 둘 다 적절히 반응하고 있습니다.
