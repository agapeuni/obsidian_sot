# 2014-07-28 220073743732 라즈베리 파이 - XRDP 설치, 원격 데스크톱 연결

- 게시일: 2014. 7. 28. 1:06

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTA2/MDAxNzU4NDM3NzgxNDM3.oCbkwI7Tk9EpaMAFyGhVOOJ2NfuRsIJNGyP80xPja4Ag.jGgnvPvvnBbVzS4hJE3huqPMo2QzuVaQ6LKan1OQoogg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(10\).png?type=w80_blur)

​

XRDP는 Linux 시스템에서 원격 데스크톱 연결을 지원하기 위한 오픈 소스 프로젝트입니다. XRDP는 RDP(Remote Desktop Protocol) 프로토콜을 사용하여 원격 사용자가 Linux 기반 시스템에 접속하고 제어할 수 있도록 합니다. RDP는 마이크로소프트에서 개발한 원격 데스크톱 프로토콜로, Windows 운영 체제에서는 "원격 데스크톱 연결"로 알려져 있습니다.

​

XRDP를 설치하고 설정하면 라즈베리 파이나 다른 Linux 기반 시스템을 원격으로 접속하여 GUI 환경에 접근할 수 있습니다. XRDP는 X Window 시스템을 사용하여 원격 데스크톱 세션을 생성하므로, 원격 사용자는 리눅스 시스템의 데스크톱 환경을 그래픽으로 표시하고 마우스와 키보드를 사용하여 제어할 수 있습니다. XRDP를 설치하고 윈도우에서 원격 데스크톱 연결로 **라즈베리 파이**(Raspberry Pi)에 접속해 봅니다. 

​

먼저 라즈베리 파이에 XRDP를 설치하여 원격 데스크톱 연결을 설정하기 위해 SSH로 로그인합니다.

![](https://postfiles.pstatic.net/20150605_259/agapeuni_1433463623356MacBB_PNG/20140727_235316.png?type=w966)

​

접속한 후에 아래와 같이 xrdp를 설치합니다.

**$ sudo apt-get install xrdp**

​

![](https://postfiles.pstatic.net/20150605_227/agapeuni_14334636321253yfxi_PNG/20140727_235337.png?type=w966)

성공적으로 설치가 되면  [ ok ] Starting Remote Desktop Protocol server : xrdp sesman.  가 화면에 표시됩니다. 

그럼 XRDP 서비스를 바로 이용할 수 있습니다.

​

만약 서비스가 시작되지 않았다면 다음의 명령어로 XRDP 서비스를 시작합니다.

**$****sudo service xrdp start**

​

XRDP 서비스가 부팅 시 자동으로 시작되도록 설정합니다:

**$ sudo systemctl enable xrdp**

​

![](https://postfiles.pstatic.net/20150605_290/agapeuni_1433463641833D9gkU_PNG/20140727_235359.png?type=w966)

​

​

그럼 윈도우에서 시작 - 보조 프로그램 - 윈격 데스크톱 연결을 실행합니다.

![](https://postfiles.pstatic.net/20150605_111/agapeuni_1433463651403fHizy_JPEG/20140727_235531.jpg?type=w80_blur)

​

**라즈베리 파이**(Raspberry Pi)에 할당된 IP 주소를 입력합니다. 

​

![](https://postfiles.pstatic.net/20140728_211/agapeuni_1406475601629zVypd_JPEG/20140727_235410.png?type=w966)

위의 그림에서 좌측 하단의 옵션을 클릭하면 옵션 정보가 표시됩니다.

​

![](https://postfiles.pstatic.net/20140728_299/agapeuni_1406474996847JeaMj_PNG/20140727_235500.png?type=w966)

해상도를 화면 캡처에 용이하도록 1024*768로 설정하였습니다. 

​

![](https://postfiles.pstatic.net/20140728_203/agapeuni_1406474997154LWP6F_PNG/20140727_235506.png?type=w966)

연결 버튼을 클릭하면 사용자 자격 증명 입력 화면이 표시되고 확인 버튼을 클릭합니다. 

매번 입력의 수고를 덜기 위해 내 자격 증명 기억을 체크해 둡니다.

​

![](https://postfiles.pstatic.net/20140728_266/agapeuni_1406474997277eg1Ao_PNG/20140727_235533.png?type=w966)

이제 XRDP를 통해 원격으로 라즈베리 파이에 연결할 수 있습니다. XRDP는 기본적으로 라즈베리 파이의 X Window 시스템을 사용하여 원격 데스크톱 환경을 제공합니다. 아래와 같은 화면이 나타나면 당황하지 말고 차분한 마음으로 기다리면 됩니다.

​

![](https://postfiles.pstatic.net/20150605_182/agapeuni_1433463671294Vcj2L_PNG/20140727_235534.png?type=w966)

**라즈베리 파이**(Raspberry Pi)에 설치된 라즈비안의 그래픽 데스크톱 환경인 LXDE를 보실 수가 있습니다.

![](https://postfiles.pstatic.net/20150605_103/agapeuni_14334636831594wg1z_PNG/20140727_235741.png?type=w80_blur)

여기서 바로 코드를 입력하여 실행할 수 있지만 새로운 창을 열어 코드를 작성하고 파일로 저장하여 실행하겠습니다.

![](https://postfiles.pstatic.net/20150605_50/agapeuni_1433463700661BIuVP_PNG/20140728_002602.png?type=w966)

![](https://postfiles.pstatic.net/20150605_287/agapeuni_1433463718097vASO5_PNG/20140728_002756.png?type=w966)
