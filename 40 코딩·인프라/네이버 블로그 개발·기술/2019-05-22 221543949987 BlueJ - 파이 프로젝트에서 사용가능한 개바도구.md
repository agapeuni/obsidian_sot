# 2019-05-22 221543949987 BlueJ - 파이 프로젝트에서 사용가능한 개바도구

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221543949987&categoryNo=982
- 게시일: 2019. 5. 22. 16:51

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MDdfNDAg/MDAxNzQ0MDI5MDk2NzQz.-Odxo8sAjCi3wMoT3S0eGVvBmX-ixeirLwXlbRUvz58g.sylk5RUYRdEsMucUKolHLFJ9WEeZNxS-VGST0-0DzH0g.PNG/Pi-Software-001_\(14\).png?type=w80_blur)

​

라즈베리 파이에 라즈비안을 설치하면 BlueJ라는 자바 개발도구가 있습니다. 

BlueJ에서 Pi4J 프로젝트를 사용하는 방법에 대해서 설명해 보겠습니다.

​

먼저 다음의 명령을 사용하여 Pi4J를 설치합니다.

**$ curl – s get.pi4j.com | sudo bash**

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMTA3/MDAxNTU4NTEwODgyMzI2.bbLc1VSH9LkGwEpk_VBxRtTw2b8Em62with5toCD2xgg.QgNz6uVK19LeG-SqzpipvX_3AUOjkrkw8JInhEGgmQwg.PNG.agapeuni/20190522_162606.png?type=w80_blur)

​

성공적으로 설치가 완료되면 아래의 메시지가 화면에 표시됩니다.

====================================================

Pi4J INSTALLATION COMPLETE

====================================================

![](https://postfiles.pstatic.net/MjAxOTA1MjJfNTIg/MDAxNTU4NTEwODgyNzcz.A8_b0IZIGzBbP2V-T67N5wUOnYxcRdqoec9g_cPnZFgg.swl-eSsM2s44Y_qX9YL3JKc8XwqDOICecCUZwGJ_bNEg.PNG.agapeuni/20190522_162812.png?type=w80_blur)

​

/opt/pi4j/lib 폴더를 확인해 보면 아래의 화면과 같이 Pi4J 프로젝트 JAR 파일이 놓여 있습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMTQz/MDAxNTU4NTEwODgzMTE0.dNNla3t9lFb4q7JahHR4jXZHdmCEKHIvV5kTGKcnaTUg.VLsBqD0XXhwbFACSFUyP2DSlC5mu-YyIEcjHJHdfrqog.PNG.agapeuni/20190522_162931.png?type=w80_blur)

​

JAR 파일 확인이 되었으면 아래의 명령어로 BlueJ 설정 파일에 라이브러리 경로를 추가합니다.

**$ sudo nano /usr/share/bluej/bluej.defs**

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMTI3/MDAxNTU4NTEwODgzNDg4.nXwiDCocanRWnk_iOHcfFckJkBRnJyhCIF_7JJx2bKwg.5gBsGNSa2ZpJrpLDNJ9pB48k18Z8Mulj3nDVVHfVbB8g.PNG.agapeuni/20190522_163012.png?type=w80_blur)

​

nano 에디터로 BlueJ 설정 파일을 열고나서 Ctrl 키와 W 키를 눌러 "userlibL"를 입력하여 편집할 위치로 이동합니다. 

그러고 나서 아래의 설정 정보를 입력하고 저장하면 됩니다.

​

**bluej.userlibLocation=/opt/pi4j/lib**

​

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMjU2/MDAxNTU4NTEwODgzODg4.1cLw4mEOXebKb3aPbLuJaP2TBYgtCUnTZlnTtRWis6Ag.wLNdZwT5qURmAzdAx3k_447AddOMVJXxxxjh10D_PQ0g.PNG.agapeuni/20190522_163211.png?type=w966)

​

그럼 설정한 라이브러리가 잘 로드되었는지를 확인해 보겠습니다. 

BlueJ를 실행하여 “Tools” 메뉴에서 “Preferences”를 선택합니다. 

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMjMy/MDAxNTU4NTExMzE2MDQw.bFUCmTHIsEeKOE2LFSmp80L2mzW_RnP-506BGQGrk2wg.Y8DhxdeYCzREccbLW26A97vOx4FE1a7FIgydfSSc_ssg.PNG.agapeuni/20190522_164725.png?type=w80_blur)

​

“Preferences” 대화 상자가 열리면 아래와 같은 화면이 표시가 됩니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMjMg/MDAxNTU4NTExMzE2NDYw.SJ5Ej-LZgM1jDNSXk8G96FQNK_rZEcNl_jsG8i51ow4g.fC1ZjBsrTlV017WT35iRhXuFOqjRnDiY6DtdjcuZvcUg.PNG.agapeuni/20190522_164752.png?type=w80_blur)

​

“Libraries” 탭을 클릭하면 아래와 같이 설치한 버전의 Pi4J가 로드되어 있는 것을 확인할 수 있습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMjgg/MDAxNTU4NTExMzE2ODU0.JeFZKRSKM-4ftszsq1esS0HYMeUSvh5dkx7g_71qRbog.4cLHB79Xh094fN9AL14BpT9nnV7Ozpi1pz6B5fbzTeYg.PNG.agapeuni/20190522_164810.png?type=w80_blur)

​

소스코드가 잘 동작하는지 간단한 테스트를 해보겠습니다. 

테스트를 위해 LED 클래스를 만들고 소스코드를 컴파일 해보겠습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjJfMjQ3/MDAxNTU4NTExNzczOTg5.3LY-0UBdceUt05mlG3U7HHArifCpVvwjFtmw53OFwSgg.N8_Qh787z051cFbgst4uwEUGbUvMVnb1xMXyAmfr66Ig.PNG.agapeuni/20190522_165428.png?type=w80_blur)

​

"Complie"버튼을 클릭하여 컴파일합니다. 에러 없이 정상적으로 컴파일 되었네요. 

참고로 Pi4J 라이브러리 설정이 되어 있지 않으면 컴파일 시에 오류가 발생합니다. 

![](https://postfiles.pstatic.net/MjAxOTA1MjJfNDcg/MDAxNTU4NTExNzc0MzEy.V6mKxMH59GdaFXyIQbn3tWNEMvvQgNR4BERpCab0t6Ag.hArbEBynjZb-QiA3bJsC_R-UhjtT8MYHxF8Hg8z6B9Ug.PNG.agapeuni/20190522_165437.png?type=w80_blur)
