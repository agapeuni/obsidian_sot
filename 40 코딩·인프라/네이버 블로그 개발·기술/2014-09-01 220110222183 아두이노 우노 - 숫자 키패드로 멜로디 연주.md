![](https://postfiles.pstatic.net/MjAyNTA5MjFfMjYy/MDAxNzU4NDI2OTMxNzY4.B5KrlJwwnK1Olja4pkTqINU0YLVUbeEt4FtkXAId8nkg.tEhvqpqn59aEo8QJycPFOUbbOCaV2brvYxRRkXH7Ok0g.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(17\).png?type=w80_blur)

**아두이노 우노**(Arduino UNO) 와 숫자 키패드(Keypad)로 멜로디를 연주해보겠습니다.

숫자키패스 1번부터 순서대로 도레미파솔라시도...를 구현한뒤 간단한 곡을 연주해 보는 실험입니다.

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다. 

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 숫자키패드 1개 

  * 피에조 부저 1개

  * 1K 옴 저항 1개

![](https://postfiles.pstatic.net/20160506_217/agapeuni_1462513244765v9ekK_JPEG/20140901_011144.jpg?type=w966)

숫자키패드를 브레드보드에 손쉽게 꼽기 위해 핀헤더를 납땜으로 고정하였습니다. 우측에서 좌측으로 핀번호가 부여됩니다.

![](https://postfiles.pstatic.net/20160506_57/agapeuni_1462513244523ksaL7_JPEG/20140901_011117.jpg?type=w966)

숫자키패드를 브레드보드의 좌측 상단에 꼽았습니다. 적색 화살표가 1번핀입니다.

![](https://postfiles.pstatic.net/20160506_288/agapeuni_1462513405044W9eqf_JPEG/20140901_011103.jpg?type=w966)

​

**아두이노 우노**(Arduino UNO)의 2번부터 9번핀까지 점퍼선을 연결합니다.

![](https://postfiles.pstatic.net/20160506_184/agapeuni_1462513243846ocekB_JPEG/20140901_011052.jpg?type=w80_blur)

**아두이노 우노**(Arduino UNO)의 2번부터 9번핀까지 MM점퍼선의 순서대로 숫자키패드와 연결합니다.

**아두이노 우노**(Arduino UNO)의 2번핀 -- 숫자키패드 1번핀

**아두이노 우노**(Arduino UNO)의 3번핀 -- 숫자키패드 2번핀

**아두이노 우노**(Arduino UNO)의 4번핀 -- 숫자키패드 3번핀

**아두이노 우노**(Arduino UNO)의 5번핀 -- 숫자키패드 4번핀

**아두이노 우노**(Arduino UNO)의 6번핀 -- 숫자키패드 5번핀

**아두이노 우노**(Arduino UNO)의 7번핀 -- 숫자키패드 6번핀

**아두이노 우노**(Arduino UNO)의 8번핀 -- 숫자키패드 7번핀

극성이 있어서 적색이 (+)이고 흑색이 (-) 입니다.

그리고 먼저 1K옴 저항으로 피에조 부저의 흑색과 GND를 연결합니다.

이번에 사용한 숫자기패드의 배선도 입니다.

![](https://postfiles.pstatic.net/20140901_108/agapeuni_1409563361235RFQX6_PNG/20140831_233125.png?type=w80_blur)

Keypad.h를 include 한뒤 키에 대한 정의와 행과 열에 사용한 핀번호를 설정합니다.

Keypad 배선도를 보면 행이 2, 7, 6, 4 열이 3, 1, 5 입니다. 

​

**아두이노 우노**(Arduino UNO)의 2번핀부터 사용하였으므로 행을 {3, 8, 7, 5} 열을 {4, 2, 6} 로 값을 정의하였습니다.

![](https://postfiles.pstatic.net/20150605_268/agapeuni_1433467854631TAoQ9_PNG/20140901_005227.png?type=w966)

​

​

프로그램을 업로드하고서 시리얼 모니터로 확인해 보면 클릭한 버튼에 대한 문자가 표시됩니다.

![](https://postfiles.pstatic.net/20150605_128/agapeuni_1433467865992NlCN8_PNG/20140901_005258.png?type=w80_blur)

​

아래는 음계에 대한 주파수 입니다. 

도(C), 레(D), 미(E), 파(F), 솔(G), 라(A), 시(B), 도(C)

![](https://postfiles.pstatic.net/20140901_93/agapeuni_14095633676843jSqG_PNG/20140831_223400.png?type=w80_blur)

​

위의 음계에 대한 값을 tones 배열에 정의를 하였습니다.

각각의 키패드에 값에 대해 음을 출력하도록 해당주파수를 매개변수로 해서 piezoTone 함수를 호출합니다.

​

**▣ 소스코드**

#include <Keypad.h> const byte ROWS = 4; const byte COLS = 3; char keys[ROWS][COLS] = { { '1', '2', '3' }, { '4', '5', '6' }, { '7', '8', '9' }, { '*', '0', '#' } }; byte rowPins[ROWS] = { 3, 8, 7, 5 }; byte colPins[COLS] = { 4, 2, 6 }; Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS); int piezo = 9; int tones[] = { 262, 294, 330, 349, 392, 440, 494, 523, 587, 659, 698, 784 }; void setup() { pinMode(piezo, OUTPUT); } void piezoTone(int t) { tone(piezo, t); delay(200); noTone(piezo); } void loop() { char key = keypad.getKey(); if (key == '1') piezoTone(tones[0]); else if (key == '2') piezoTone(tones[1]); else if (key == '3') piezoTone(tones[2]); else if (key == '4') piezoTone(tones[3]); else if (key == '5') piezoTone(tones[4]); else if (key == '6') piezoTone(tones[5]); else if (key == '7') piezoTone(tones[6]); else if (key == '8') piezoTone(tones[7]); else if (key == '9') piezoTone(tones[8]); else if (key == '*') piezoTone(tones[9]); else if (key == '0') piezoTone(tones[10]); else if (key == '#') piezoTone(tones[11]); } 

누구나 들으면 알수 있는 간단한 곡을 연주해 보았습니다.
