고정 IP 주소를 설정하는 방법

1) 먼저 네트워크 인터페이스를 중지시킨다.

﻿$ sudo ifdown eth0

​

2) 네트워크 인터페이스 설정 파일을 수정한다.

﻿$sudo nano /etc/network/interfaces

고정 IP를 설정할 인터페이스 이름을 확인한다. 대부분의 경우 eth0이 기본 인터페이스이다. 고정 IP 설정하기 위해 인터페이스 정보를 추가한다. 인터페이스 이름과 IP 주소, 서브넷 마스크, 게이트웨이, DNS 서버 정보를 수정하여 입력한다. 

auto eth0 iface eth0 inet static address 192.168.0.100 netmask 255.255.255.0 gateway 192.168.0.1 dns-nameservers 168.126.63.1

﻿auto eth0 iface eth0 inet static address 192.168.0.100 netmask 255.255.255.0 network 192.168.0.0 broadcast 192.168.0.255 gateway 192.168.0.1 dns-nameservers 168.126.63.1 168.126.63.2

참고로 dhcp 설정은 다음과 같다.

﻿auto eth0 iface eth0 inet dhcp﻿

3) 네임 서버를 수정한다.

﻿$ sudo nano /etc/resolv.conf nameserver 168.126.63.1 nameserver 168.126.63.2

4) 네트워크 인터페이스를 동작시킨다.

﻿$ sudo ifup eth0

**​**

5) 네트워크 재시작하기

설정이 완료되면 네트워크를 재시작한다.

﻿$ sudo /etc/init.d/networking restart
