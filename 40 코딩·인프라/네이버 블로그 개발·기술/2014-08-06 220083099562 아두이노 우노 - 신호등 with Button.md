# 2014-08-06 220083099562 아두이노 우노 - 신호등 with Button

- 게시일: 2014. 8. 6. 8:28

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTg5/MDAxNzU4NDI1OTg2NzY0.NY49wMD3bSt93e3rqfgPdsrwLWLfVXxh8SmOSZHXJdgg.EW8De8bQGj9yeQ_Yfksid7ZtdrWTsS1lsyfIaMt87Rcg.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(8\).png?type=w80_blur)

​**아두이노 우노**(Arduino UNO)에서 이번에는 간단한 신호등을 시뮬레이션 해보겠습니다.

대기 중인 반대 차선에서 버튼을 누를 때 신호가 전환되는 실험입니다.

​

![](https://storep-phinf.pstatic.net/james_special/original_22.png?type=p50_50)

이번 실험의 준비물은 다음과 같습니다.

  * MM 점퍼선 11개

  * LED 6개, (빨2, 노2, 초2) 

  * 220옴 저항 6개 

  * 피에조 부저 1개 

  * 1K옴 저항 1개 

  * 버튼 2개 

  * 10K옴 저항 2개

![](https://postfiles.pstatic.net/20160506_15/agapeuni_1462509513316v6sUu_JPEG/20140805_163818.jpg?type=w966)

먼저 **아두이노 우노**(Arduino UNO)의 핀에 MM 점퍼선을 연결해 둡니다. 

![](https://postfiles.pstatic.net/20160506_176/agapeuni_1462509510126U8Pb8_JPEG/20140805_163148.jpg?type=w80_blur)

우측 브레드보드에 전자회로를 구성합니다. 

![](https://postfiles.pstatic.net/20160506_54/agapeuni_1462509512956y0V8v_JPEG/20140805_163634.jpg?type=w80_blur)

부저를 가운데 위치하고 스위치를 양옆에 벌려서 놓습니다. 

![](https://postfiles.pstatic.net/20160506_182/agapeuni_1462509512629R3JOX_JPEG/20140805_163604.jpg?type=w80_blur)

​

신호등을 나타내는 빨, 노, 초 LED를 부저 브레드보드의 좌우 측에 나란히 꼽습니다.

​

![](https://postfiles.pstatic.net/20160506_35/agapeuni_1462509512337kEeOi_JPEG/20140805_163549.jpg?type=w966)

먼저 아래와 같이 스위치를 연결합니다.

​

![](https://postfiles.pstatic.net/20160506_291/agapeuni_1462509512001qrDcq_JPEG/20140805_163525.jpg?type=w966)

그러고 나서 신호등을 나타내는 LED에 570옴 저항을 차례대로 연결합니다.

![](https://postfiles.pstatic.net/20160506_181/agapeuni_1462509511733ykkfB_JPEG/20140805_163459.jpg?type=w966)

스위치와 신호등 LED의 저항 연결이 완료되었습니다.

​

![](https://postfiles.pstatic.net/20160506_282/agapeuni_1462509511449sFdWN_JPEG/20140805_163435.jpg?type=w966)

**아두이노 우노**(Arduino UNO) 핀 번호를 확인하고 점퍼 색상으로 구분하여 브레드보드 상단에 꼽습니다.

![](https://postfiles.pstatic.net/20160506_29/agapeuni_14625095111387Uffe_JPEG/20140805_163423.jpg?type=w80_blur)

​

**아두이노 우노**(Arduino UNO) 핀과 브레드보드 핀이 연결되었습니다.

![](https://postfiles.pstatic.net/20160506_239/agapeuni_1462509510449HjPPt_JPEG/20140805_163159.jpg?type=w80_blur)

브레드보드에 배치된 부품들을 위에서 찍어보았습니다.

![](https://postfiles.pstatic.net/20160506_123/agapeuni_1462509510757uJ7XL_JPEG/20140805_163224.jpg?type=w80_blur)

빨간색으로 불 들어온 쪽의 버튼을 클릭하면 신호가 전환됩니다.

**▣ 소스코드**

#define westRed 2 #define westYellow 3 #define westGreen 4 #define westButton 5 #define buzzer 6 #define eastRed 8 #define eastYellow 9 #define eastGreen 10 #define eastButton 11 int blinkTime = 300; int flowTime = 1000; int changeDelay = 500; ​ boolean trafficWest = true; void setup() { pinMode(westButton, INPUT); pinMode(westRed, OUTPUT); pinMode(westYellow, OUTPUT); pinMode(westGreen, OUTPUT); pinMode(buzzer, OUTPUT); pinMode(eastButton, INPUT); pinMode(eastRed, OUTPUT); pinMode(eastYellow, OUTPUT); pinMode(eastGreen, OUTPUT); digitalWrite(westRed, LOW); digitalWrite(westYellow, LOW); digitalWrite(westGreen, HIGH); digitalWrite(eastRed, HIGH); digitalWrite(eastYellow, LOW); digitalWrite(eastGreen, LOW); } void loop() { if (digitalRead(westButton) == HIGH) { if (trafficWest != true) { trafficWest = true; delay(flowTime); digitalWrite(eastGreen, LOW); digitalWrite(eastYellow, HIGH); delay(changeDelay); digitalWrite(eastYellow, LOW); digitalWrite(eastRed, HIGH); delay(changeDelay); for (int i = 0; i < 5; i++) { digitalWrite(westYellow, HIGH); analogWrite(buzzer, 128); delay(blinkTime); digitalWrite(westYellow, LOW); analogWrite(buzzer, LOW); delay(blinkTime); } digitalWrite(westYellow, LOW); digitalWrite(westRed, LOW); digitalWrite(westGreen, HIGH); } } if (digitalRead(eastButton) == HIGH) { if (trafficWest == true) { trafficWest = false; delay(flowTime); digitalWrite(westGreen, LOW); digitalWrite(westYellow, HIGH); delay(changeDelay); digitalWrite(westYellow, LOW); digitalWrite(westRed, HIGH); delay(changeDelay); for (int i = 0; i < 5; i++) { digitalWrite(eastYellow, HIGH); analogWrite(buzzer, 128); delay(blinkTime); digitalWrite(eastYellow, LOW); analogWrite(buzzer, LOW); delay(blinkTime); } digitalWrite(eastYellow, LOW); digitalWrite(eastRed, LOW); digitalWrite(eastGreen, HIGH); } } }
