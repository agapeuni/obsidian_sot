아두이노 우노 2대를 서로 연결한 뒤 버튼을 누르면 UART 통신으로 신호를 보내 LED을 ON 하는 실험을 진행하려고 합니다. ^^

​

준비물은 아래와 같습니다.

  * **아두이노 우노(Arduino UNO) 2대**

  * 브레드보드 2판

  * 고휘도 LED 2개

  * 220옴 저항 2개

  * 10K옴 저항 2개

  * 점퍼선 9개

![](https://postfiles.pstatic.net/20160520_8/agapeuni_1463740107862ynrkM_JPEG/20160519_233534.jpg?type=w80_blur)

먼저 각각의 아두이노 우노에서 2번 핀에 노란색 점퍼선을 7번 핀에 하얀색 점퍼선을 연결합니다.

LED의 캐소드와 접지를 220옴 저항으로 연결합니다. 그리고 풀 다운 버튼을 구현합니다.

풀 다운 버튼은 아래와 같이 노란색과 같은 라인에 10K 저항으로 연결하고 다른 쪽에는 빨간색 점퍼선을 Vcc 전원과 연결합니다.

**▣ 소스코드 : serial_led_btn_master.ino**

이번 실험에서는 코드 업로드를 잘해야 합니다. 

코드를 업로드할 때는 아두이노 우노에 연결된 0번과 1번 핀의 점퍼선을 제거하고 올리시길 바랍니다.

​

Serial로 "1"을 받으면 LED를 On 하고 "2"을 받으면 Off 합니다. 

버튼이 클릭되면 "3" 릴리스 시에는 "4"을 Serial로 보냅니다.

int BUTTON = 2; int LED = 7; int btnState = 0; int prevState = 0; void setup() { Serial.begin(9600); pinMode(LED, OUTPUT); pinMode(BUTTON, INPUT); } void loop() { if (Serial.available()) { char c = (char)Serial.read(); if (c == '1') { digitalWrite(LED, HIGH); } else if (c == '2') { digitalWrite(LED, LOW); } } btnState = digitalRead(BUTTON); if (btnState != prevState) { if (btnState == 1) { Serial.print("3"); delay(50); } else { Serial.print("4"); delay(50); } prevState = btnState; } delay(50); }

​

​

**▣ 소스코드 : serial_led_btn_slave.ino**

이번 실험에서는 코드 업로드를 잘해야 합니다. 

코드를 업로드할 때는 아두이노 우노에 연결된 0번과 1번 핀의 점퍼선을 제거하고 올리시길 바랍니다.

Serial로 "3"을 받으면 LED를 On 하고 "4"를 받으면 Off 합니다. 버튼이 클릭되면 "1" 랄리즈시에는 "2"를 Serial로 보냅니다. ​

int BUTTON = 2; int LED = 7; int btnState = 0; int prevState = 0; void setup() { Serial.begin(9600); pinMode(LED, OUTPUT); pinMode(BUTTON, INPUT); } void loop() { if (Serial.available()) { char c = (char)Serial.read(); if (c == '3') { digitalWrite(LED, HIGH); } else if (c == '4') { digitalWrite(LED, LOW); } } btnState = digitalRead(BUTTON); if (btnState != prevState) { if (btnState == 1) { Serial.print("1"); delay(50); } else { Serial.print("2"); delay(50); } prevState = btnState; } delay(50); }
