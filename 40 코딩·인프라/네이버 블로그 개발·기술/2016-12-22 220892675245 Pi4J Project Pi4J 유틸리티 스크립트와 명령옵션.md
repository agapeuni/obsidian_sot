1\. Pi4J 유틸리티 스크립트 ​

이번에는 Pi4J를 설치하면 같이 제공되는 Pi4J 유틸리티 스크립트와 명령옵션에 대해서 알아보겠습니다.

​

라즈베리 파이에 Pi4J 라이브러리를 설치하면 'Pi4J' 유틸리티 스크립트가 설치되어 경로에 연결되어 시스템에 어디에서든지 호출 할 수 있습니다. Pi4J 유틸리티 스크립트는 Pi4J 라이브러리와 자바 프로젝트를 컴파일하고 실행하는데 도움이되는 단축옵션을 제공합니다.

다음 명령을 실행하면 옵션의 목록을 확인 할 수 있습니다.

$ Pi4J --help 

$ Pi4J ?

![](https://postfiles.pstatic.net/MjAxNzAzMjlfMjA2/MDAxNDkwNzY0NzM2NjEz.rsudRDULgoeExD3HA-Uim9gY62jGHftbE86xiJnCq28g.EUTLV8ykrQLnOg764sGPdTNEl2PlIcB9mX1uDh1sRGQg.PNG.agapeuni/20170329_141658.png?type=w966) ​

​

다음과 같은 내용이 표시됩니다:

==============================

Pi4J Utility Script

==============================

사용법: Pi4J [옵션] ...(<파일>)

(아무 옵션을 지정하지 않는 경우, '--run'옵션 가정합니다.)

옵션:

========

?, --help : 이 '도움말'을 표시

-v, --version: Pi4J 버전을 표시

-u, --update: Pi4J 확인 및 Pi4J 업데이트를 설치

-U, --uninstall: Pi4J를 제거

-c, --compile <FILE>: 클래스 경로에 Pi4J와 함께 javac 실행

-r, --run <FILE>: 클래스 경로에 Pi4J와 함께 java 실행

예:

=========

Pi4J --version (Pi4J 버전 표시)

Pi4J --update (업데이트 Pi4J 설치)

Pi4J --uninstall (Pi4J 패키지 제거)

Pi4J HelloWorld.java --compile ('HelloWorld.java'소스를 컴파일)

Pi4J HelloWorld.java -c ('HelloWorld.java'소스를 컴파일)

Pi4J --run HelloWorld (컴파일 된 'HelloWorld' 프로그램 실행)

Pi4J --r HelloWorld (컴파일 된 'HelloWorld' 프로그램 실행)

-v 옵션으로 pi4j의 버전을 확인하고 -u 옵션으로 업데이트를 실행해 보았습니다.

![](https://postfiles.pstatic.net/MjAxNzAzMjlfMzQg/MDAxNDkwNzY1MTc3MDEw.GoCFOJ8OkrZbK9j3sOrOvqRaZUh9QBpIye1hocl7si0g._o_NqqJVHU9auA0hAE5QxMpfsGX2lbxRLf3mteLowB4g.PNG.agapeuni/20170329_142113.png?type=w80_blur)

2\. Pi4J 유틸리티 명령 옵션

**① --compile | -c**

Pi4J 유틸리티는 --classpath의 Pi4J 라이브러리 JAR 파일을 포함하는 인수로 javac 컴파일러를 단순히 호출합니다.

​

아래의 예제 명령은 'HelloWorld.java' 파일을 컴파일하는 데 사용됩니다.

$ Pi4J --compile HelloWorld.java

​

다음과 같은 효과 명령입니다.

$ javac -classpath '.:classes:*:classes:/opt/Pi4J/lib/*' -d . HelloWorld.java

​

**②****\--run | -r**

Pi4J 유틸리티는 --classpath의 Pi4J 라이브러리 JAR 파일을 포함하는 인수로 필요한 권한으로 실행되기 위하여 sudo 명령어를 앞에 붙여서 실행가능한 Java 프로그램을 호출합니다.

​

아래의 예제 명령은 이미 컴파일 된 'HelloWorld' 프로그램을 실행하는 데 사용됩니다. 

$ Pi4J --run HelloWorld

​

당신이 명령 옵션을 지정하지 않으면, 다음 스크립트는 프로그램을 실행합니다.

이 명령은 아래의 '--run'옵션을 사용한 이전 명령과 동일한 기능을 보여줍니다.

​

$ Pi4J HelloWorld

​

위의 명령어 옵션은 아래와 같은 효과를 나타냅니다. 

$ sudo java -classpath '.:classes:*:classes:/opt/Pi4J/lib/*' HelloWorld

​

**③****\--version | -v**

RaspberryPi에서 --version 명령 옵션을 사용하여 Pi4J 라이브러리 JAR 파일의 현재 설치된 버전을 표시할 수 있습니다.

$ Pi4J --version

**④****\--update | -u**

RaspberryPi에서 --update 명령 옵션을 사용하여 새로운 사용 가능한 업데이트를 확인하고 Pi4J의 설치 버전을 업그레이드 할 수 있습니다. RaspberryPi가 인터넷에 연결되어 있고 쉬운 방법을 사용하여 Pi4J 설치한 경우에는 다음의 명령어 옵션으로 손쉽게 업그레이드가 가능합니다.

$ Pi4J --update

**⑤****\--uninstall | -U**

RaspberryPi에서 --uninstall 명령어 옵션을 사용하여 Pi4J 패키지를 제거할 수 있습니다.

$ Pi4J --uninstall

​

또는 다음의 명령을 실행하여 삭제 할 수 있습니다.

$ sudo apt-get remove Pi4J or Pi4J –uninstall
