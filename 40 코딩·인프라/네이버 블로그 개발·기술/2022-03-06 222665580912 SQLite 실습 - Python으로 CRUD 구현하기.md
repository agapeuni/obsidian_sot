1\. sqlite3 모듈

sqlite3 모듈은 Python에서 바로 사용할 수 있는 데이터베이스 라이브러리이다. 별도의 서버가 필요 없고 단일 파일이나 메모리 형태로 사용할 수 있다. sqlite3 모듈은 DB-API 2.0 명세를 준수하는 SQL 인터페이스를 제공한다. (PEP 249)​

![](https://postfiles.pstatic.net/MjAyMjAzMDZfOTIg/MDAxNjQ2NTcxNzg2MjQy.o1VdhixIed-kxHfqXs0jAAVJT5QmzXMsbowiN641N2cg.VdLU5xAqJhnNuNvdJExe8EFgEVgcB09zowxTIppFO4Qg.PNG.agapeuni/image.png?type=w80_blur)

sqlite3 모듈은 SQLite 데이터베이스을 처리할 수 있는 파이썬 라이브러리이다.

​

2\. 과정

**1) Connection 생성**

sqlite3를 import 하고 connect() 함수로 파일 위치를 지정한다. 만약 파일이 없으면 새로 생성하여 연결한다. connect() 에 인자로 파일경로를 입력하면 파일 DB로 연결하고 ":memory:"를 입력하면 메모리 DB로 연결한다.

import sqlite3 conn = sqlite3.connect("./data/example.db")

**​**

**2) Cursor 생성 및 Table 생성**

conn.cursor() 함수로 커서 하나를 생성한다. excutescript() 함수를 사용하여 예제 코드를 위한 테이블 하나를 생성한다. 

cursor = conn.cursor() cursor.executescript( """ DROP TABLE IF EXISTS items; CREATE TABLE items ( id integer primary key autoincrement, name text not null, qty integer, price real, date text ); DELETE FROM items; """ )

**​**

**3) 데이터 추가 (Insert)**

INSERT 쿼리를 작성하고 execute() 함수와 executemany() 함수를 사용하여 데이터를 추가한다.

sql = "INSERT INTO items (name, qty, price, date) VALUES (?, ?, ?, ?)" item = ("item1", 10, 2.5, "2020-09-16") cursor.execute(sql, item) sql = "INSERT INTO items (name, qty, price, date) VALUES (:name, :qty, :price, :date)" item = {"qty": 3, "price": 1.2, "name": "item2", "date": "2020-09-16"} cursor.execute(sql, item) sql = "INSERT INTO items (name, qty, price, date) VALUES (?, ?, ?, ?)" items = [ ("item3", 4, 3.1, "2020-09-15"), ("item4", 3, 2.5, "2020-09-16"), ("item5", 6, 0.5, "2020-09-17") ] cursor.executemany(sql, items)

​

**4) 데이터 조회 (Select)**

데이터 조회는 SELECT 문을 작성해 execute() 함수를 실행한다. 쿼리 실행을 통해 가저온 결과를 가져온다. fetchone()은 하나를 반환하고 fetchmany()는 여러건을 반환하고 fetchall()은 모든 결과를 가져온다.

sql = "SELECT * FROM items" cursor.execute(sql) print(cursor.fetchone()) cursor.execute("SELECT * FROM items") rows = cursor.fetchall() for row in rows: print(row)

**​**

**5) 데이터 수정 (Update)**

UPDATE 문을 사용하여 execute() 함수로 데이터를 수정한다.

sql = "UPDATE items SET name = ? WHERE id = ?" items = [("item14", 4), ("item15", 5)] cursor.executemany(sql, items) print("update count = ", cursor.rowcount)

**​**

**6) 데이터 삭제 (Delete)**

데이터 삭제는 DELETE 문을 작성하고 execute() 함수를 수행한다.

sql = "DELETE FROM items WHERE price < ?" cursor.execute(sql, (1,))

**​**

**7) Connection 닫기**

conn.close()를 실행하면 DB와의 연결을 종료한다.

conn.close()

**​**

3\. CRUD 예제코드

SQLite 데이터베이스에 items 이름의 테이블을 생성하고 기본적인 CRUD를 수행하는 코드이다. 간단한 Comment를 달아 두었다.

​

**소스코드 : db_sqlite3.py**

import sqlite3 # Connection 생성 conn = sqlite3.connect("./data/example.db") # Cursor 생성 cursor = conn.cursor() # Table 생성 cursor.executescript( """ DROP TABLE IF EXISTS items; CREATE TABLE items ( id integer primary key autoincrement, name text not null, qty integer, price real, date text ); DELETE FROM items; """ ) # 변경사항 저장 conn.commit() # Parameterized 방식으로 데이터 추가 sql = "INSERT INTO items (name, qty, price, date) VALUES (?, ?, ?, ?)" item = ("item1", 10, 2.5, "2020-09-16") cursor.execute(sql, item) # 추가한 데이터 확인 sql = "SELECT * FROM items" cursor.execute(sql) print(cursor.fetchone()) print() # Named Placeholder 방식으로 데이터 추가 sql = "INSERT INTO items (name, qty, price, date) VALUES (:name, :qty, :price, :date)" item = {"qty": 3, "price": 1.2, "name": "item2", "date": "2020-09-16"} cursor.execute(sql, item) # 조건으로 데이터 확인 sql = "SELECT * FROM items WHERE name = ?" search = ("item2",) cursor.execute(sql, search) print(cursor.fetchone()) print() # 한번에 많은 데이터를 추가 sql = "INSERT INTO items (name, qty, price, date) VALUES (?, ?, ?, ?)" items = [ ("item3", 4, 3.1, "2020-09-15"), ("item4", 3, 2.5, "2020-09-16"), ("item5", 6, 0.5, "2020-09-17") ] cursor.executemany(sql, items) # 데이터 조회 cursor.execute("SELECT * FROM items") rows = cursor.fetchall() for row in rows: print(row) print() # 데이터 수정 sql = "UPDATE items SET name = ? WHERE id = ?" items = [("item14", 4), ("item15", 5)] cursor.executemany(sql, items) print("update count = ", cursor.rowcount) print() # 데이터 조회 cursor.execute("SELECT * FROM items") rows = cursor.fetchall() for row in rows: print(row) print() # 데이터 삭제 sql = "DELETE FROM items WHERE price < ?" cursor.execute(sql, (1,)) print("delete count = ", cursor.rowcount) print() # 데이터 조회 cursor.execute("SELECT * FROM items") for row in cursor: print(row) print() # 변경사항 저장 conn.commit() # Connection 닫기 conn.close()
