이번에는 푸시 버튼과 LED로 두 가지 간단한 실험을 해보겠습니다. 첫 번째는 단순 버튼 기능으로 버튼을 누르고 있으면 LED에 불이 들어오고 버튼을 떼면 꺼지는 실험이고 두 번째는 토글 버튼 기능으로 한번 누르면 LED에 불이 켜지고 다시 한번 누르면 꺼지는 것을 반복하는 실험입니다.

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다. 

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 푸시 버튼 3개 

  * 10K옴 저항 3개

  * 연결선 3개

  * 적색 LED 3개

  * 220옴 저항 3개

  * 점퍼선 6개

**실험 1. 소스코드 (button_onoff_3.ino)**

현재의 상태와 이전의 상태를 비교하면서 입력이 여러 번 발생되는 바운스 현상을 제거합니다.

바운스 현상이란 순간 접점 시 발생하는 것으로 동시에 여러 번의 입력으로 NG가 되어 버립니다.

​

아래의 코드에서처럼 이전 입력 상태와 현재 입력 상태를 비교하면서 확실하게 구분하게 됩니다.

int BTN_NUM = 3; int btns[] = { 2, 3, 4 }; int leds[] = { 7, 8, 9 }; int nowStates[] = { 0, 0, 0 }; int oldStates[] = { 0, 0, 0 }; void setup() { for (int i = 0; i < 3; i++) { pinMode(btns[i], INPUT); pinMode(leds[i], OUTPUT); } } void loop() { for (int i = 0; i < BTN_NUM; i++) { nowStates[i] = digitalRead(btns[i]); if (nowStates[i] != oldStates[i]) { if (nowStates[i] == 1) { digitalWrite(leds[i], HIGH); } else { digitalWrite(leds[i], LOW); } oldStates[i] = nowStates[i]; } } delay(50); }

​

**실험 1. 동영상**

버튼을 클릭할 때에 해당하는 LED에 값이 출력 되어 불이 들어옵니다.

​

**실험 2. 소스코드 (button_toggle_4.ino)**

​

아래의 코드는 위의 코드와 다르게 버튼의 상태를 관리하는 **btnStates** 배열이 하다 더 있습니다. 

**btnStates** 배열의 값으로 버튼의 on/off 상태를 유지하도록 합니다. ​

int BTN_NUM = 3; int btns[] = { 2, 3, 4 }; int leds[] = { 7, 8, 9 }; int nowStates[] = { 0, 0, 0 }; int oldStates[] = { 0, 0, 0 }; int btnStates[] = { 0, 0, 0 }; void setup() { for (int i = 0; i < 3; i++) { pinMode(btns[i], INPUT); pinMode(leds[i], OUTPUT); } } void loop() { for (int i = 0; i < BTN_NUM; i++) { nowStates[i] = digitalRead(btns[i]); if (nowStates[i] != oldStates[i]) { if (nowStates[i] == 1) { if (btnStates[i] == 0) { digitalWrite(leds[i], HIGH); btnStates[i] = 1; } else { digitalWrite(leds[i], LOW); btnStates[i] = 0; } } oldStates[i] = nowStates[i]; } } delay(50); }

**실험 2. 동영상**

버튼을 한번 누르면 LED에 불이 들어오고 다시 한번 누르면 꺼지게 됩니다.
