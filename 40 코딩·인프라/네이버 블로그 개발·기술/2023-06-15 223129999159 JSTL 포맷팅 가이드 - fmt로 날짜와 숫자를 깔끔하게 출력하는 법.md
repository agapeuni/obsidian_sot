# 2023-06-15 223129999159 JSTL 포맷팅 가이드 - fmt로 날짜와 숫자를 깔끔하게 출력하는 법

​

JSTL은 JavaServer Pages Standard Tag Library(자바서버 페이지 표준 태그 라이브러리)이다. JSTL의 fmt 태그를 사용하여 날짜와 숫자의 형식을 지정할 수 있다. 날짜 포맷을 적용하려면 데이터가 Date 타입이어야 한다. 

​

소스코드와 결과화면을 보며 확인해 보자.

<%@ page language="java" contentType="text/html; charset=EUC-KR" pageEncoding="EUC-KR"%> <%@ taglib prefix="fmt" uri="http://java.sun.com/jsp/jstl/fmt"%> <%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core"%> <!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>JSTL Core - fmt</title> </head> <body> <%-- 현재 날짜를 가져온다. --%> <c:set var="currentDate" value="<%=new java.util.Date() %>"/> <H2>날짜형식 (formatDate) </H2> 날짜 : <fmt:formatDate value="${currentDate}" type="date"/> <br/> 시간 : <fmt:formatDate value="${currentDate}" type="time"/> <br/> 일시 : <fmt:formatDate value="${currentDate}" type="both" /> <br/> <br/> 형식1 : <fmt:formatDate value="${currentDate}" pattern="yyyy-MM-dd"/> <br/> 형식2 : <fmt:formatDate value="${currentDate}" pattern="yyyy-MM-dd HH:mm:ss"/> <br/> <H2>숫자형식 (formatNumber) </H2> 숫자 : <fmt:formatNumber value="123456789" type="number"/> <br/> 통화 : <fmt:formatNumber value="12345" type="currency" currencySymbol="$"/> <br/> 수수점 : <fmt:formatNumber value="123456.789" pattern=".00"/> <br/> 퍼센트 : <fmt:formatNumber value="0.78" type="percent"/> <br/> </body> </html>

​

주목해야 할 부분은 다음과 같다.

\- `<%@ taglib prefix="fmt" uri="[http://java.sun.com/jsp/jstl/fmt"](http://java.sun.com/jsp/jstl/fmt%22%C2%A0%25%3E%60:%C2%A0fmt%C2%A0%ED%83%9C%EA%B7%B8%C2%A0%EB%9D%BC%EC%9D%B4%EB%B8%8C%EB%9F%AC%EB%A6%AC%EB%A5%BC%C2%A0%EC%84%A0%EC%96%B8%ED%95%A9%EB%8B%88%EB%8B%A4.) %>`: fmt 태그 라이브러리를 선언한다.

\- `<fmt:formatDate>`: fmt 태그를 사용하여 날짜를 포맷팅합니다. 

`value` 속성에는 포맷팅할 날짜 값이 들어간다.

`pattern` 속성에는 원하는 날짜 형식을 지정한다.

`var` 속성을 통해 형식이 적용된 날짜를 변수로 저장한다.

\- `${formattedDate}`: JSTL EL(Expression Language)을 사용하여 형식이 적용된 날짜를 출력한다.
