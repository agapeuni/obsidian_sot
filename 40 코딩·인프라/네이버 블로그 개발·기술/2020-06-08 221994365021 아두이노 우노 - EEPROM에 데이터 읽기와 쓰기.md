# 2020-06-08 221994365021 아두이노 우노 - EEPROM에 데이터 읽기와 쓰기

## 본문

​

아두이노 우노에는 ATmega328이 사용됩니다. ATmega328에는 32KB의 플래시 메모리, 2KB의 SRAM, 1KB의 EEPROM 이렇게 세 종류의 메모리가 있습니다. 플래시 메모리에는 작성한 스케치를 저장하고 SRAM에는 변수를 저장합니다. 그리고 EEPROM은 데이터나 상태를 저장할 수 있습니다. 전기적으로 데이터를 지우고 기록할 수 있어서 전원을 꺼도 데이터를 유지합니다. EEPROM은 비휘발성 메모리이기 때문에 전원이 꺼져도 데이터를 유지할 수 있어 상태나 조건값 등을 저장하기에 좋습니다. 

​

다음은 EEROM에 데이터를 저장하는 스케치입니다. 메모리 0번지부터 값을 2씩 증가하며 기록하고 있습니다.

#include <EEPROM.h> int address = 0; int data = 0; void setup() { } void loop() { EEPROM.write(address, data); data = data + 2; address = address + 1; if (address == EEPROM.length()) { address = 0; } delay(100); }

​

다음은 EEROM에 데이터를 읽어오는 스케치입니다. EEPROM의 크기만큼 저장된 값을 읽어옵니다.

#include <EEPROM.h> int address = 0; byte value; void setup() { Serial.begin(9600); while (!Serial) { ; } } void loop() { value = EEPROM.read(address); Serial.print(address); Serial.print("\t"); Serial.print(value, DEC); Serial.println(); address = address + 1; if (address == EEPROM.length()) { address = 0; } delay(100); }

​

위의 스케치를 실행하면 시리얼 모니터에 주솟값에 저장되어 있는 값을 표시합니다.

다음은 EEROM에 데이터를 클리어하는 스케치입니다. 

EEPROM의 크기만큼 값을 0으로 설정합니다.

#include <EEPROM.h> void setup() { for (int i = 0 ; i < EEPROM.length() ; i++) { EEPROM.write(i, 0); } } void loop() { }

​

데이터를 클리어하고 EEPROM의 값을 읽어보면 주소마다 0으로 설정되어 있는 것을 확인할 수 있습니다.
