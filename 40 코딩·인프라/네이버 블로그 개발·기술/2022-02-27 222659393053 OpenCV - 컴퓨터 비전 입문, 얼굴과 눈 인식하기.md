1\. OpenCV 개요

OpenCV(Open Source Computer Vision Library)는 컴퓨터 비전 및 영상 처리에 사용되는 오픈 소스 라이브러리다. 이미지 및 비디오 데이터의 처리, 분석, 기계 학습, 객체 감지, 얼굴 인식, 모션 추적 등 다양한 컴퓨터 비전 작업에 사용된다. OpenCV는 C++, Python, Java 등 다양한 프로그래밍 언어에서 사용할 수 있으며, 플랫폼에 독립적이다. 이미지 및 비디오 데이터를 읽고 저장할 수 있는 기능부터 이미지 처리, 특징 검출, 객체 추적, 카메라 캡처 등 다양한 기능을 제공한다. 

​

OpenCV는 컴퓨터 비전 알고리즘의 구현을 지원하는 기능도 제공한다. 이미지 분할, 특징 검출, 객체 인식, 얼굴 감지 및 인식, 모션 추적 등의 작업에 사용된다. 기계 학습 알고리즘을 사용하여 이미지 분류, 객체 검출, 얼굴 인식 등의 작업을 수행할 수도 있다. OpenCV는 컴퓨터 비전 및 영상 처리 분야에서 널리 사용되는 라이브러리로 알려져 있으며, 산업, 연구, 학문 등 다양한 분야에서 활용된다.

5\. 얼굴과 눈 인식

다음 코드는 정면얼굴(haarcascade_frontalface_default.xml)과 눈(haarcascade_eye.xml) detector를 사용하여 인식한다.

소스 코드 : v_opencv_3.py

import os import cv2 from distutils.sysconfig import get_python_lib face_xml = get_python_lib() + "\\\cv2\\\data\\\haarcascade_frontalface_default.xml" eye_xml = get_python_lib() + "\\\cv2\\\data\\\haarcascade_eye.xml" face_cascade = cv2.CascadeClassifier(face_xml) eye_cascade = cv2.CascadeClassifier(eye_xml) image_file = os.getcwd() + "\\\mei.png" image = cv2.imread(image_file) image_gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) faces = face_cascade.detectMultiScale(image_gray, 1.1, 3) for x, y, w, h in faces: cv2.rectangle(image, (x, y), (x + w, y + h), (100, 150, 100), 2) face = image[y: y + h, x: x + w] face_gray = image_gray[y: y + h, x: x + w] eyes = eye_cascade.detectMultiScale(face_gray) for (ex, ey, ew, eh) in eyes: cv2.rectangle(face, (ex, ey), (ex + ew, ey + eh), (0, 0, 255), 2) cv2.imshow("face_image", image) cv2.waitKey()
