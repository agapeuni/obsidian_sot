# 2023-02-05 223006133905 전자부품 케이스 - 부품을 쉽게 찾을 수 있는 라벨 만들기

![](https://postfiles.pstatic.net/MjAyNTA0MDdfMTI1/MDAxNzQ0MDI2NjE2OTM0.vz9IU_KOtA8TrcJIO11oyRyu7Imi1R3JbodFu5TI0zMg.q-wDXvVrEOw8mfYaPbtZ4OCvkfVn9QDc4WKi51FO7BEg.PNG/%EC%A0%84%EC%9E%90%EA%B3%B5%EC%9E%91-%EB%B6%80%ED%92%88-001_\(6\).png?type=w80_blur)

​

"라즈베리 파이"와 "아두이노 우노"로 실험을 하면서 전자부품을 하나씩 주문하였다. 이제는 제법 전자부품이 많아져서 관리 차원에서 부품 케이스를 만들어본다. 전자부품을 케이스에 잘 정리해 두기 위해서 아래와 같이 작업을 한 뒤 라벨지에 컬러로 인쇄를 하였다.

![](https://postfiles.pstatic.net/MjAyMzAyMDVfMTA5/MDAxNjc1NTk5MDY3ODI1.pYnFOAMYVRJNV_utgz8kwpj58ebbPI-bmMxMk7EvlT8g.VEsCwwLWktKgSYxCYX_9YadkuEP6YFiFGKK_Ps2Kq0Yg.PNG.agapeuni/1.png?type=w80_blur)

다이소에서 부품을 답을 수 있는 적절한 케이스를 구매하였다. 

케이스 상단에 "라즈베리 파이"와 "아두이노 우노" 로고스키커를 붙였습니다. 

![](https://postfiles.pstatic.net/MjAyMzAyMDVfNTYg/MDAxNjc1NTk5MDcyNTg3.Qs0hwe4q_hhIbGruT8-XK6lGmJR8hET4XS8th8khxkkg.Dia6XWivSux7gMgos9DrSo5onNDxecVz6djMyzem-vYg.JPEG.agapeuni/2.jpg?type=w80_blur)

실험을 하다 보면 매번 저항을 사용하게 되는데 쉽게 찾기 위해서 색상과 저항값을 표시해 두었다.

![](https://postfiles.pstatic.net/MjAyMzAyMDVfMjk3/MDAxNjc1NTk5MDc3MTIx.VvNXQ9XydVdmDjATxTd9NJpOweNFFam907xWJVXLmKUg.B2ntkyczyyZqnvcgSn9LRZtcrP-hsxHp1TitwgbBDnMg.JPEG.agapeuni/3.jpg?type=w80_blur)

LED도 색상별로 담아둔다. 뭔가 잘 정돈된 느낌이다.

![](https://postfiles.pstatic.net/MjAyMzAyMDVfMTg2/MDAxNjc1NTk5MDgxNDA3.SMSrVmuZ4Vq6fna-XLs1h6d9WjwbyuHsESIrM0drugAg.4KU68tJjokIR162sOoo3Yj1WZDQujyvZuxBpY_c5V-kg.JPEG.agapeuni/4.jpg?type=w80_blur)

처음 실험할 때는 저항값을 확인하기 어려워 저항 다리에 스티커를 붙여서 표시해 두었다. 

자주 반복해서 그런지 이제는 색상 코드 값을 기준으로 저항값 계산하는 법이 그럭저럭 익숙해졌다.

![](https://postfiles.pstatic.net/MjAyMzAyMDVfMjAx/MDAxNjc1NTk5MDg0ODA2.X17CIvxALDZdbIZB4ujPcirB3YMTV6pW3IHRM_j1Gwog.Ei1T66FyWieBW6OJAVb-KEZN4xphcy9VxSlE3JVMhjwg.JPEG.agapeuni/5.jpg?type=w80_blur)

1M 옴이나 10M 옴을 사용할지 모르겠지만 혹시나 해서 구매해 두었습니다. 

![](https://postfiles.pstatic.net/MjAyMzAyMDVfMTYw/MDAxNjc1NTk5MDg4MzEx.cEYCllQP43POnxeN5qrFl_Qtu5bP0j-PDeWXE1P2k2Ug.TR9DjaansMBUuIbPXa0X64UPeXzvHNcPrzL7VL0_dh0g.JPEG.agapeuni/6.jpg?type=w80_blur)

파이 케이스의 투명도 나름 괜찮아 보이긴 하지만 남는 로고를 케이스에 상단에 붙여두었다.

![](https://postfiles.pstatic.net/MjAyMzAyMDVfMTUx/MDAxNjc1NTk5MDkxNjE5.d2KwsiJDfAe0jiMF0Y2lIVVShFbOzc1WRQlumgrJVOAg.3Yy4Sb5ojqXCi34kQf-jDmbJ-da4LVKEs0qDJWmnxOkg.JPEG.agapeuni/7.jpg?type=w80_blur)
