# 2023-04-15 223075801752 Ant 빌드 - 다른 프로젝트의 Ant파일을 실행하는 방법

​

소프트웨어를 개발할 때 기본적으로 필요한 단계는 '코딩 - 컴파일 - 실행 - 디버깅'이다. 프로젝트 수행을 위해 개발 환경을 구성하고 빌드 환경을 구성하고 나면 작업 과정을 반복하면서 원하는 결과를 만들어낸다. 진행하는 프로젝트에 따라 다른 프로젝트의 결과물과 연계가 되는 경우가 있다. 서브 프로젝트의 결과물이 만들어지고 그다음에 메인 프로젝트를 진행할 때 Ant 빌드를 사용하여 해결할 수 있다.

​

여러 서브 프로젝트가 있고 하나의 메인 프로젝트가 있을 때 메인에서 각각의 서브에 위치한 Ant 빌드를 실행하는 태스크를 추가하면 된다. 현재의 프로젝트는 "main project"이고 main을 위한 build.xml가 존재한다. 그리고 subproject1, subproject2 가 별도의 서브 프로젝트로 존재하며 각각의 build.xml을 갖고 있다.

​

그러면 "main project"의 build.xml 파일에서 <ant> 태그를 사용하여 서브 프로젝트에 위치한 build.xml 파일과 build.properties 파일을 정의하면 된다. 아래의 코드에는 deploy_sub_all이라는 Task를 정의하였고 각각의 서브 build 파일과 프로퍼티 파일을 설정했다.

<?xml version="1.0"?> <project name="ant_build_call" default="deploy" basedir="."> ... (생략) ... <target name="deploy_sub_all"> <ant antfile="../sub_prj_1/build.xml" inheritall="false"> <property file="../sub_prj_1/build.properties" /> </ant> <ant antfile="../sub_prj_2/build.xml" inheritall="false"> <property file="../sub_prj_2/build.properties" /> </ant> <ant antfile="../sub_prj_3/build.xml" inheritall="false"> <property file="../sub_prj_3/build.properties" /> </ant> </target> ... (생략) ... </project>
