1\. JSON 개요

JSON(Javascript Object Notation)은 경량 데이터 교환 형식으로 사람이 읽기 쉽고, 쓰기 쉽고, 또 기계에게도 해석과 생성이 용이하다. JSON은 가볍고 형식이 간단해서 Ajax에서 데이터 교환용 형식으로 XML을 대신하여 사용하고 있다. 이제는 거의 표준으로 자리 잡아 다른 프로그래밍 언어에서도 지원한다. 

​

2\. JavaScript 객체

다음은 JavaScript에서 객체를 기술하는 방법이다. 

객체(obj)를 만들면 obj.프로퍼티이름으로 값을 접근할 수 있다. 그리고 obj.메서드이름()으로 객체에 정의된 메서드를 호출할 수 있다.

﻿var obj = { "프로퍼티 이름" : "값", "메서드 : function() { alert('This is method') } }

3\. JavaScript 배열

JavaScript에서 배열은 다음과 같이 기술한다.

사과는 fruits[0]으로 접근할 수 있고 수박은 fruits[2]로 접근할 수 있다

​

var fruits = [ "사과", "딸기", "수박" ]

​

키가 있는 배열에 대해선 {키:값}을 사용한다.

var man = {

name : "한길",

height : "173"

};

var result = {

mans : [ {

name : "한길",

height : "173"

}, {

name : "두길",

height : "175"

} ]

}

키가 있는 배열은 다음과 같이 접근한다. 

result.mans[0].name; //한길

result.mans[1].name; //두길

​

4\. JavaScript 객체화

XML에 담긴 데이터가 많아질수록 XML DOM을 이용하여 객체로 표현하는 것은 매우 수고스러운 작업이 된다. JSON은 이러한 단점을 보완할 수 있는 표기법이다. JSON으로 표기된 문자열은 JavaScript에서 쉽게 객체로 사용할 수 있다.

var json_str = "{name:'한길', height:'173'}"; var man = eval("(" + json_str + ")"); alert(man.name); // 한길 alert(man.height); // 173

​

5\. JSON.parse()

JSON 문자열을 JavaScript 객체로 변환할 때는 JSON.parse()를 사용한다. 

JSON 문자열을 인자로 받아 JavaScript 객체를 반환한다. 

var json_str = "{name:'한길',height:'173'}"; var man = JSON.parse(str); console.log(man.name); console.log(man.height);

​

6\. JSON.stringify() 

JavaScript 객체를 JSON 문자열로 변환할 때는 JSON.stringify()를 사용한다. 

JavaScript 객체를 인자로 받아 JSON 문자열을 반환한다.

var obj = { name: "한길", height: 173 }; var str = JSON.stringify(obj); console.log(str); // '{"name":"한길","height":25}'
