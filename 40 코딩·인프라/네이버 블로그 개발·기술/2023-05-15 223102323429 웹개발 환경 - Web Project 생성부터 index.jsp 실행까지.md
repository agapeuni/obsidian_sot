1\. 웹 프로젝트 시작

이클립스에서 "Dynamic Web Project"를 선택하여 "SimpleWeb"이름으로 웹 프로젝트를 하나 만든다.

![](https://postfiles.pstatic.net/MjAyMzA1MTVfNTYg/MDAxNjg0MTExMjI5MTk0.meLdm8VkwJDwnWwDq8-Uab0aeDeeycYmy6wjtYj55jcg.MVcEyLYw-pd9adW76T84NKldL6dP9ksMspv5ADLLD_cg.PNG.agapeuni/img.png?type=w80_blur)

​

​

2\. web.xml 생성

프로젝트가 생성하고 나서 확인해 보면 WEB-INF 폴더 아래에 web.xml 파일이 안 보인다.

이때 이클립스에서 간단하게 생성하는 방법이 있다.

![](https://postfiles.pstatic.net/MjAyMzA1MTVfMzAg/MDAxNjg0MTExMjMzNDgw.Rmhm3ac17kjN3hc0dREKzDoRG0XmUZlqdmMtFah_Pl8g.gVwOqkDDLufAcxnzYPNInDhh5B36lMDjE50rdyyHylkg.PNG.agapeuni/img.png?type=w80_blur)

​

프로젝트에서 우측 마우스 클릭하여 "Java EE Tools > Generate Deployment Descriptor Stub"를 실행한다.

![](https://postfiles.pstatic.net/MjAyMzA1MTVfMTI4/MDAxNjg0MTExMjM3OTUx.zAWYcsiBjL29c07v2C-ikiZ3UvuEj-Jp7Uq7f01hyFUg.tdTR_TexE4t9xrT0C04ZCCG3AKNwA3XEbQ-I3QHlsO0g.PNG.agapeuni/img.png?type=w80_blur)

​

web.xml 파일이 자동으로 만들어진다.

<?xml version="1.0" encoding="UTF-8"?> <web-app xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns="http://xmlns.jcp.org/xml/ns/javaee" xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd" version="4.0"> <display-name>SimpleWeb</display-name> <welcome-file-list> <welcome-file>index.html</welcome-file> <welcome-file>index.htm</welcome-file> <welcome-file>index.jsp</welcome-file> <welcome-file>default.html</welcome-file> <welcome-file>default.htm</welcome-file> <welcome-file>default.jsp</welcome-file> </welcome-file-list> </web-app>

​

​

3\. <welcome-file-list>

<welcome-file-list>에서 index.jsp는 남겨두고 모두 지운다.

<?xml version="1.0" encoding="UTF-8"?> <web-app xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns="http://xmlns.jcp.org/xml/ns/javaee" xsi:schemaLocation="http://xmlns.jcp.org/xml/ns/javaee http://xmlns.jcp.org/xml/ns/javaee/web-app_4_0.xsd" version="4.0"> <display-name>SimpleWeb</display-name> <welcome-file-list> <welcome-file>index.jsp</welcome-file> </welcome-file-list> </web-app>

​

​

4\. index.jsp 파일

webapp 폴더에 index.jsp 파일을 생성한다.

![](https://postfiles.pstatic.net/MjAyMzA1MTVfNDgg/MDAxNjg0MTEyMzk1NDY3.sIkjW98ugI-n2bheOWCWB_vKTwDeuBCrEe0Q0W4ntlUg.9-Fh7S_TCCrW__F2RvhyjOvhT5p23WhDsZPZ9EJDkZog.PNG.agapeuni/img.png?type=w80_blur)

​

파일 : index.jsp

<%@ page language="java" contentType="text/html; charset=UTF-8" pageEncoding="UTF-8"%> <!DOCTYPE html> <html> <head> <meta charset="UTF-8"> <title>Insert title here</title> </head> <body> <%=new java.util.Date()%> </body> </html>
