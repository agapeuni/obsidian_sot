1\. 파일 업로드 개요

웹 프로젝트를 진행하면 90% 이상 파일 업로드 기능을 구현하게 된다. 프로젝트 비용으로 파일 업로드 컴포넌트를 구매하면 가이드를 참고하여 바로 사용하면 된다. 그렇지 않은 경우에는 멀티파트 업로드로 직접 구현해야 한다. HTML부터 JavaScript, Java까지 파일 업로드를 위한 코드를 작성해 보자.

​

​

2\. 코드 순서

웹 페이지에서 Ajax를 이용하여 파일을 업로드하는 코드를 작성해 보자.

1) 화면에 보이는 HTML 코드가 필요하다. Form 안에 <input type="file">을 추가한다.

2) 화면에서 선택한 파일을 서버로 전송하는 Ajax 코드가 필요합니다.

3) 업로드 요청에 대해 서버에서 처리하는 Java 파일이 필요합니다. 

​

2.1 HTML 코드 (화면)

form 태그에 enctype=_"multipart/form-data"_ 속성을 정의하고 type="file"인 입력항목을 추가한다.

<form id="frm" action="/file/uploadAjax" method="post" enctype="multipart/form-data"> <label>파일찾기</label><br/><br/> <span id="file" class="file"> <input id="fileUpload" name="file" type="file"> </span> </form>

​

2.2 Ajax 코드 (로직)

type="file"인 입력항목에 change 이벤트 핸들러를 적용한다. 값이 변경되면 서버로 전송할 url 을 기록하고 data 속성에 formData를 담아 서버로 전송한다. 성공과 실패 시 관련 alert가 화면에 표시된다.

$("#fileUpload").change(function() { var formData = new FormData($("#frm")[0]); $.ajax({ type : 'post', url : '/file/uploadAjax', data : formData, processData : false, dataType : "json", contentType : false, async : false, success : function(data) { alert("Fileupload OK"); }, error : function(error) { alert("Fileupload Err"); } }); });

​

2.3. Java 코드 (서버)

서버에서는 Multipart 요청을 받아 upload 경로에 파일을 저장한다. 이때 사용자가 올린 파일을 저장할 때 물리적 파일명을 일련의 규칙을 적용해 변경한다. 그리고 실제 파일명과 변경된 파일명을 DB에 저장해 두고 추후에 파일을 다운로드할 때 실제 파일명으로 변경한다.

@PostMapping(value = { "/file/uploadAjax" }) @ResponseBody public Map<String, object> uploadAjax(HttpServletRequest req) throws IOException { MultipartHttpServletRequest multipartRequest = (MultipartHttpServletRequest) req; Map<String, Object> result = new HashMap<>(); Path uploadPath = "D:/website/upload"; if (!Files.isDirectory(uploadPath)) { Files.createDirectories(uploadPath); } MultipartFile mFile = multipartRequest.getFileMap().values(); UUID tempFileName = UUID.randomUUID(); String originalFileName = mFile.getOriginalFilename(); String fileExt = FilenameUtils.getExtension(originalFileName); String logicalFileName = tempFileName.toString() + "." + fileExt; byte[] fileBytes = mFile.getBytes(); Path filePath = uploadPath.resolve(logicalFileName); Files.write(filePath, fileBytes); return result; }

3\. Ajax 모듈

객체 레퍼런스를 참조해서 콜백이 가능한 Ajax 모듈을 구현해 보았다. Ajax 기본적인 기능을 정의하고 prototype으로 setRequestHeader 메서드와 send 메서드를 정의하였다. params의 정의와 몇 가지 JavaScript 기술은 존레식의 Pro JavaScript Techiques을 참고하였다.

​

파일 : Ajax.js

function Ajax(params) { params = { _owner: params._owner || this, method: params.method || "POST", url: params.url || "", async: params.aysnc || true, data: params.data || "", timeout: params.timeout || 5000, fnCallback: params.fnCallback || function () { }, fnError: params.fnError || function () { } }; function _resData(res) { var ctype = res.getResponseHeader("content-type"); var data = (ctype && ctype.indexOf("xml") >= 0) ? res.responseXML : res.responseText; return data; } var xhr = new XMLHttpRequest(); var requestDone = false; var timeoutLength = params.timeout; setTimeout(function () { requestDone = true; }, timeoutLength); xhr.onreadystatechange = function () { if (xhr.readyState == 4 && !requestDone) { if (!xhr.status && location.protocol == "file:" || (xhr.status >= 200 && xhr.status < 300) || xhr.status == 304) { params.fnCallback.call(this._owner, _resData(xhr)); } else { params.fnError(); } xhr = null; } }; if (params.method == "GET" && params.data.length > 0) { if (params.data.charAt(0) == '?') { params.url = params.url + params.data; } else { params.params.url = url + "?" + params.data; } } xhr.open(params.method, params.url, params.aysnc); if (params.method !== 'POST') { params.data = null; } this.data = params.data; this.req = xhr; }; Ajax.prototype = { setRequestHeader: function (header, value) { try { if (this.req) { this.req.setRequestHeader(header, value); } } catch (e) { alert("Ajax.prototype.setRequestHeader() e = " + e + " " + e.message); } }, send: function () { try { this.req.send(this.data); } catch (e) { alert("Ajax.prototype.send() e = " + e + " " + e.message); } } };

​

4\. Ajax 콜백

Ajax를 생성하면서 객체 변수 obj와 callback을 위한 obj.fnCallback을 지정한다. 

ajax.send()로 요청을 보내고 성공적인 응답이 오면 fnCallback으로 지정한 함수가 콜백으로 불린다.

var ajax = new Ajax({ _owner: obj, fnCallback: obj.fnCallback, method: "GET", url: "http://localhost/test/ajax.dat", async: true, timeout: 3000 }); ajax.setRequestHeader("Content-type", "text/xml"); ajax.setRequestHeader("Content-length", 0); ajax.setRequestHeader("Connection", "close"); ajax.send();
