​

PIL(Python Imaging Library) 라이브러리인 Pillow를 사용하여 이미지에 다양한 효과를 적용해 보자.

> pip install pillow

​

먼저, Image 클래스의 open 함수를 사용하여 이미지를 읽어온다. Pillow는 다양한 필터를 제공하여 이미지를 변경할 수 있다.

from PIL import Image, ImageEnhance, ImageFilter image1 = Image.open("example1.jpg") image2 = Image.open("example2.jpg") image3 = Image.open("example3.jpg")

​

이미지를 Numpy 배열로 변환하여 shape를 표시해 보자. 

import numpy as np img_array1 = np.array(image1) img_array1.shape

(400, 300, 3)

​

첫 번째 행의 len 함수의 값을 표시하고 마지막 행의 shape를 표시한다. 

# 첫번째 행 len(img_array1[0])

300

# 마지막 행 img_array1[399].shape

(300, 3)

​

flatten 함수를 사용하여 값을 평탄화시키고 len 함수로 값을 표시해 본다.

img_flat = img_array1.flatten() img_flat

array([94, 81, 62, ..., 97, 80, 72], dtype=uint8)

# 300 * 400 * 3 = 360,000 len(img_flat) 

360000
