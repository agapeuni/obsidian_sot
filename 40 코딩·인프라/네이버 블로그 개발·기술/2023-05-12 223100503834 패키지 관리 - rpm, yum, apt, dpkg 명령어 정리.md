1\. 패키지 관리 명령어

리눅스 패키지(Linux Package)에는 리눅스 시스템에서 소프트웨어를 실행하는데 필요한 파일이 담겨 있는 묶음이다. 리눅스에서 패키지를 설치, 업데이트, 삭제, 검색하는 등의 작업을 수행하는 명령어가 있다. 이 명령어들은 리눅스 배포판마다 조금씩 다를 수 있지만, 대부분의 경우 비슷한 형태를 가지고 있다. 

​

패키지 관리(Package Management) 명령어는 바이너리 패키지(Binary Package)를 설치, 업데이트, 삭제를 수행한다. 저수준의 명령어는 실제 대상 패키지만을 설치하는데 고수준의 명령어는 대상 패키지와의 의존성(Dependency)을 파악하여 관련 패키지를 자동으로 설치한다.

​

2\. rpm (Redhat Package Manager)

Red Hat 계열 리눅스(RedHat, Fedora, CentOS)에서 사용하는 패키지 관리 명령어. (저수준)

패키지 설치rpm -ivh <Package Name>​패키지 설치 테스트 (실제 설치는 하지 않음)rpm -ivh --test <Package Name> ​패키지 설치 (강제) rpm -ivh --force <Package Name>​패키지 설치 (의존성 무시) rpm -ivh --nodeps <Package Name>​패키지 업그레이드 rpm -Uvh <Package Name>​패키지 업그레이드 (강제, 의존성 무시)rpm -Uvh --force --nodeps <Package Name>​패키지 삭제rpm -e <Package Name>​패키지 삭제 (의존성 무시)rpm -e --nodeps <Package Name>​패키지 정보rpm -qi <Package Name>​패키지 조회rpm -qa | grep <Package Name>​패키지 목록rpm -ql <Package Name>​패키지 확인rpm -qf <File Name>  
---  
  
​

3\. yum (Yellowdog Updater Modified)

Red Hat 계열 리눅스(RedHat, Fedora, CentOS)에서 사용하는 패키지 관리 명령어. (고수준)

패키지 설치 yum install <Package Name>​패키지 재설치 yum reinstall <Package Name>​패키지 삭제yum remove <Package Name>​패키지 갱신 yum update <Package Name>​패키지 정보 yum info <Package Name>​패키지 조회 yum search <Package Name>​패키지 목록 yum list​yum 캐시 지우기yum clean all​저장소 목록을 표시yum repolist​패키지 업데이트yum update <Package Name>​전체 패키지 업데이트 yum -y update​그룹 패키지 설치 yum groupinstall <Group Package Name>​그룹 패키지 삭제 yum groupremoe <Group Package Name>  
---  
  
​

4\. dpkg (Debian Package)

데비안 계열 리눅스(Debian, Ubuntu)에서 사용하는 패키지 관리 명령어. (저수준)

패키지 설치 dpkg -i <File Name>​패키지 설치 dpkg -R <Folder Name>​패키지 제거 (구성 정보 유지)dpkg -r <Package Name>​패키지 제거 (구성 정보 포함)dpkg -P <Package Name>​패키지 목록 dpkg -l (설치된 모든 Deb 패키지, 버전 번호 및 간단한 설명 표시)​패키지 정보 dpkg -I <File Name>​패키지 상태 dpkg -s <Package Name>​패키지 상세정보 dpkg -I <Package Name>  
---  
  
​

5\. apt (Advanced Packaging Tool)

데비안 계열 리눅스(Debian, Ubuntu)에서 사용하는 패키지 관리 명령어. (고수준)

패키지 설치 apt-get install <Package Name>​패키지 재설치 apt-get reinstall <Package Name>​패키지 복구 설치 apt-get -f install​패키지 제거 (설정파일 유지) apt-get remove <Package Name>​패키지 제거 (설정파일 포함) apt-get remove --purge <Package Name>​패키지 정보 apt-cache show <Package Name>​패키지 조회 apt-cache search <Package Name>​소스리스트 갱신 apt-get update​패키지 업그레이드 apt-get upgrade​시스템 업그레이드 apt-get dist-upgrade​손상된 의존성 확인 apt-get check​불필요한 패키지 정리 apt-get clean & apt-get autoclean​의존성 검사 수행하면서 업그레이드 apt-get -s dist-upgrade
