**1\. 개요**

Node.js(노드 제이에스)는 Chrome V8 엔진으로 개발된 JavaScript 런타임 환경으로 서버 측 애플리케이션을 구축하기 위한 플랫폼이다. Node.js는 이벤트 기반, 비동기식, 논블로킹 I/O 모델을 사용하여 가볍고 효율적인 네트워크 애플리케이션을 만들 수 있도록 설계되었다. 

​

Node.js는 주로 웹 서버 개발에 많이 사용되며, 실시간 애플리케이션, API 서버, 마이크로 서비스 등 다양한 영역에서도 활용된다. MEAN Stack에서 N에 해당하는 Node.js는 JavaScript 기반이라 배우기 쉽고 가벼워 확장성 있는 네트워크 애플리케이션을 만들 수 있다. 많은 기업과 개발자 커뮤니티에서 지속적으로 발전하고 있으며, JavaScript의 성장과 함께 Node.js도 계속해서 발전하고 있다.

Node.js 공식 사이트에 있는 10줄 정도 되는 "hello world" 예제다. 간단한 코드이지만 웹 서비스를 수행한다.

const http = require('node:http'); const hostname = '127.0.0.1'; const port = 3000; const server = http.createServer((req, res) => { res.statusCode = 200; res.setHeader('Content-Type', 'text/plain'); res.end('Hello World\n'); }); server.listen(port, hostname, () => { console.log(`Server running at http://${hostname}:${port}/`); });

**4\. 예제 2**

​

"hello world" 예제 코드에서 응답의 결과를 HTML로 표시하기 위해 Content-Type을 'text/html'로 변경하였다. 그리고 콘솔 로그에서 'Server running at ' 부분을 제거했다. 그대로 복사하면 브라우저에 바로 입력할 수 있어 편리하다.

const http = require('http'); const hostname = '127.0.0.1'; const port = 3000; const server = http.createServer((req, res) => { res.statusCode = 200; res.setHeader('Content-Type', 'text/html'); res.write('<h1>Hello Node.js</h1>'); res.write('<h2>Simple and Powerful</h2>'); res.write('<hr>'); res.end(); }); server.listen(port, hostname, () => { console.log(`http://${hostname}:${port}/`); });
