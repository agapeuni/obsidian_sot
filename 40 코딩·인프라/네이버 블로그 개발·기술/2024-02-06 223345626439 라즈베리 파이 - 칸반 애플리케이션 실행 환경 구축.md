2023년 삼성전자 DS Python 프로젝트를 종료하고 판교에 위치한 회사로 출근하고 있다. 3월부터 신규로 시작하는 삼성전자 DS Java 프로젝트 준비를 위해 지난주 제안서를 작성하였고 팀으로 함께 작업할 사람을 모집 중이다. 그리고 고객이 원하는 기능이나 요건을 매끄럽게 수행하기 위해 여러 가지 작업을 준비하고 있다.

그동안 집에서 쉬고 있던 라즈베리 파이(Pi 3)를 하나 회사로 가져왔다. 최신 라즈비안을 설치하고, 회사 인터넷에 와이파이로 접속한 것을 확인하고 모니터, 키보드, 마우스를 제거하고 전원만 연결하고 작업 노트북 위에 두었다. 할당받은 주소는 192.168.0.183이다.

​

칸반 애플리케이션을 편하게 실행하기 위해 .bashrc 파일에 아래와 같이 별칭을 만들어 두었다. 

alias go='cd /home/pi/github/mykanban' alias venv='export FLASK_APP=kanban;export FLASK_DEBUG=true;cd /home/pi/github/mykanban;. /home/pi/github/mykanban/venv/bin/activate' alias run='flask run --host 0.0.0.0 -p 8000' alias kanban='go;venv;run'

​

​

칸반(Kanban)은 파이썬으로 개발한 플라스크 기반의 웹 애플리케이션이다. 

kanban이라고 입력하면 애플리케이션 폴더로 이동해 가상환경을 활성화시키고 플라스크를 실행한다.
