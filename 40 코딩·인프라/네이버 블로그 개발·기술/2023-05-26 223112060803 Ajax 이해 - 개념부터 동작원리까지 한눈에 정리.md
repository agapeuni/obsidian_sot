**1\. Ajax 개요**

Ajax란 Asynchronous Javascript And Xml을 의미하며 웹 애플리케이션을 개발하기 위해 사용되는 프로그래밍 기술이다. 웹 애플리케이션의 구현 시 웹 페이지 전체를 다시 로딩하지 않고, 웹 페이지에서 데이터를 비동기적으로 서버와 통신하여 페이지의 부분적인 업데이트를 할 수 있다. 이는 페이지 전체를 새로 고치지 않고도 웹 페이지의 사용자 경험을 향상시키는 데 도움이 된다. 

​

Ajax는 새로운 프로그래밍 언어가 아니라, 기존의 표준을 사용하는 또 다른 방법이다. Ajax는 웹 애플리케이션의 사용자 경험을 향상시키는 데 많은 도움이 된다. 페이지의 특정 부분을 동적으로 업데이트할 수 있으므로 전체 페이지를 새로 고치는 것보다 효율적이다. 이로 인해 빠른 응답 시간, 부드러운 상호 작용 및 사용자 친화적인 UI(User Interface)를 제공할 수 있다.

​

**2\. Ajax 구성요소**

Ajax는 다음과 같은 주요 구성 요소로 이루어져 있다.

​

1) Asynchronous(비동기성)

Ajax는 브라우저와 플랫폼에 독립적이며 웹 표준 기술을 기반으로 사용한다. Ajax는 비동기적인 통신을 통해 데이터를 교환한다. 이는 페이지의 다른 부분을 업데이트하는 동안 사용자가 다른 작업을 수행할 수 있도록 한다.

​

2) JavaScript

Ajax는 JavaScript를 사용하여 클라이언트 측에서 서버로 데이터를 전송하고, 서버에서 반환된 데이터를 처리한다. JavaScript를 사용하여 DOM(Document Object Model)을 조작하여 웹 페이지의 일부분을 업데이트할 수 있다.

​

3) XML 또는 JSON 

Ajax는 웹 서버와 데이터를 교환하기 위해 XML 또는 JSON 형식을 사용한다. 초기에는 XML이 주로 사용되었지만, 최근에는 JSON이 더 널리 사용되고 있다. XML 또는 JSON 형식을 사용하여 데이터를 서버로 보내고, 서버에서 반환된 데이터를 클라이언트 측에서 처리할 수 있다.

​

**3\. Ajax 동작원리**

Ajax는 아래의 과정을 반복하여 웹 페이지의 일부분을 동적으로 업데이트하고, 서버와 비동기적으로 데이터를 교환한다. 

![](https://postfiles.pstatic.net/MjAyMzA1MjVfMjEg/MDAxNjg1MDIwMzM5NDAz.zgJDDt8LdaeIMT5uGWvkC1C2-oC7MSo-NEsZXAzADxAg.JV3JvaHILHx4c1UW75sTqhyDp6LaRuX0D6tGp6DSnpgg.PNG.agapeuni/img.png?type=w80_blur)

1) 사용자 요청으로 이벤트 발생, 이벤트 핸들러 호출.

2) JavaScript를 사용하여 XMLHttpRequest 객체를 생성.

3) XMLHttpRequest 객체를 사용하여 서버로 보낼 요청을 서버로 전송

4) 서버는 요청을 받고 처리한 후, 필요한 데이터를 응답으로 반환.

5) XMLHttpRequest 데이터가 도착하면 이벤트를 발생. 이를 콜백이라고 하고 이 이벤트에 핸들러 함수를 연결.

6) 콜백 이벤트 핸들러가 데이터를 처리하고 화면에 표시. 응답을 받으면 데이터를 조작하고 웹 페이지의 부분을 업데이트.
