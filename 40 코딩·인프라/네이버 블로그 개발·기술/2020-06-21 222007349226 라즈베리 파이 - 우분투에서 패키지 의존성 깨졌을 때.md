우분투에서 패지키를 설치하다 보면 패키지 의존성이 깨지는 경우가 발생합니다. 보통의 경우 sudo apt-get update와 sudo apt-get upgrade를 반복하면 패키지 설치가 잘 되는데 의존성이 깨지는 경우에는 몇 번 해보아도 좀처럼 해결이 되지 않습니다.

![](https://postfiles.pstatic.net/MjAyMDA2MjFfMTcy/MDAxNTkyNjcwMDkzNjY5.e15Jj4OhPLZFLIhi9MaMU8NzodcMYdzldl5q32un7w4g.7cGW30MZmssfxmuGJRKtHI2be04hMM4V1sHARy7y6mwg.PNG.agapeuni/SE-330ab053-4c2f-4bc8-9d6c-5ca9aea2398b.png?type=w80_blur)

​

그럴 때는 아래의 명령어를 입력하여 문제를 해결합니다. 

**$ sudo dkpg --configure -a**

**$ sudo apt --fix-broken install 또는 sudo apt-get install -f**

![](https://postfiles.pstatic.net/MjAyMDA2MjFfMjQ2/MDAxNTkyNjcwMDk0NTYx.OY_M6BjwZ56xMulwB1gw5EIMUSYrRwBqirVcZh2Csr0g.c_d4II_n7QorzjamMdsqq5lwYqj9RDX0bPHQFOw2jLkg.PNG.agapeuni/SE-ae1ad6ad-8400-4cde-a69a-e6d1d86c405d.png?type=w80_blur)

​

그러고 나서 **sudo apt-get update** 와 sudo apt-get upgrade를 수행합니다.

![](https://postfiles.pstatic.net/MjAyMDA2MjFfMjE5/MDAxNTkyNjcwMDkyNDc4.mp7Of9d9dC_wAJ6Gr3O7cJ3mAHjcj7I-Rh_vTbnPN7gg.GwkgpABMn-7gjUAYtgWImBCG9BO2tWPIDHz8-GJHBNwg.PNG.agapeuni/SE-f17f8eaf-4e0d-47ff-8720-75ffb51ac34c.png?type=w80_blur)

​

​

도움말을 기초로 해서 apt-get 명령어를 간단히 정리해 봅니다. 

> sudo apt-get update : 패키지 인덱스를 업데이트
> 
> sudo apt-get upgrade: 설치된 모든 패키지 업그레이드
> 
> sudo apt-get dist-upgrade : 의존성 검사하며 업그레이드
> 
> ​
> 
> sudo apt-get install 패키지명 : 지정한 패키지 설치 
> 
> sudo apt-get --reinstall install 패키지명 : 패키지 재설치 
> 
> sudo apt-get remove 패키지명 : 패키지 삭제 (구성파일은 제외)
> 
> sudo apt-get purge 패키지명 : 패키지 삭제 (구성파일도 삭제)
> 
> sudo apt-cache search 패키지명 : 패키지 검색
> 
> sudo apt-cache show 패키지명 : 패키지 정보 보기
> 
> sudo apt-get source 패키지명 : 패키지 소스코드 다운로드
