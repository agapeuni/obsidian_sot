HTML5의 <canvas> 요소를 사용하여 브라우저에 간단한 도형을 쉽게 그릴 수 있다. 

​

1\. 사각형과 원 그리기

<canvas> 요소를 생성하고 JavaScript를 사용하여 2D 렌더링 컨텍스트를 가져온 후, 각각의 도형을 그리기 전에 색상을 설정하고, fillRect 함수와 arc 함수를 사용하여 도형을 그린다.

<!DOCTYPE html> <html> <head> <title>Canvas 도형 그리기</title> </head> <body> <canvas id="myCanvas" width="400" height="400"></canvas> <script> // Canvas 요소 가져오기 var canvas = document.getElementById("myCanvas"); // 2D 렌더링 컨텍스트 가져오기 var ctx = canvas.getContext("2d"); // 사각형 그리기 ctx.fillStyle = "blue"; // 색상 설정 ctx.fillRect(50, 50, 100, 100); // (x, y, width, height) // 원 그리기 ctx.fillStyle = "green"; // 색상 설정 ctx.beginPath(); ctx.arc(200, 200, 50, 0, 2 * Math.PI); // (x, y, 반지름, 시작각, 종료각) ctx.fill(); </script> </body> </html>

2\. 여러 사각형 그리기

이번에는 2d로 가져온 객체에 fillStyle() 함수로 색을 지정하고 fillRect() 함수로 사각형을 그린다. html5의 canvas의 좌표는 좌우측 상단을 기준(0, 0)으로 한다. fillRect의 1번째와 2번째 인자는 그려질 좌표이고 3번째와 4번째 인자는 가로, 세로 길이다. 

<html> <head> <title>canvas_rect</title> <script type="text/javascript"> function draw() { var canvas = document.getElementById("canvas1"); if(canvas.getContext) { var ctx = canvas.getContext("2d"); ctx.fillStyle = "rgb(200, 0, 0)"; ctx.fillRect(10, 10, 55, 50); ctx.fillStyle = "rgba(0, 0, 200, 0.5)"; ctx.fillRect(30, 30, 55, 50); } var canvas = document.getElementById("canvas2"); if(canvas.getContext) { var ctx = canvas.getContext("2d"); ctx.fillRect(25, 25, 100, 100); ctx.clearRect(45, 45, 60, 60); ctx.strokeRect(50, 50, 50, 50); } } </script> </head> <body onload="draw()"> <canvas id="canvas1" width="150" height="150"></canvas> <canvas id="canvas2" width="150" height="150"></canvas> </body> </html>

3\. 말풍선 그리기

결과 화면에서 보듯이 quadratic curve는 control point(빨간 점)을 하나를 가지는 커브이다. quadraticCurveTo의 1, 2번째 인자는 control point의 좌표이고 3, 4번째 인자는 그리고자 원하는 점의 좌표이다.

<html> <head> <title>canvas_curv</title> <script type="text/javascript"> function draw() { var canvas = document.getElementById("canvas"); if(canvas.getContext) { var ctx = canvas.getContext("2d"); ctx.beginPath(); ctx.moveTo(75, 25); ctx.quadraticCurveTo(25, 25, 25, 62.5); ctx.quadraticCurveTo(25, 100, 50, 100); ctx.quadraticCurveTo(50, 120, 30, 125); ctx.quadraticCurveTo(60, 120, 65, 100); ctx.quadraticCurveTo(125, 100, 125, 62.5); ctx.quadraticCurveTo(125, 25, 75, 25); ctx.stroke(); } } </script> </head> <body onload="draw()"> <canvas id="canvas" width="150" height="150"></canvas> </body> </html>

4\. 빨간 하트 그리기

결과 화면에서 보듯이 bezier curve는 control point(빨간 점)이 두 개가 필요하다. bezier curve의 1, 2번째 인자는 첫 번째 control point의 좌표이고 3, 4번째 인자는 두 번째 control point의 좌표이고 5, 6번째 인자는 그리고자 원하는 점의 좌표이다.

<html> <head> <title>canvas_heart</title> <script type="text/javascript"> function draw() { var canvas = document.getElementById("canvas"); if(canvas.getContext) { var ctx = canvas.getContext("2d"); ctx.fillStyle = "rgb(200, 50, 50)"; ctx.beginPath(); ctx.moveTo(75, 40); ctx.bezierCurveTo(75, 37, 70, 25, 50, 25); ctx.bezierCurveTo(20, 25, 20, 62.5, 20, 62.5); ctx.bezierCurveTo(20, 80, 40, 102, 75, 120); ctx.bezierCurveTo(110, 102, 130, 80, 130, 62.5); ctx.bezierCurveTo(130, 62.5, 130, 25, 100, 25); ctx.bezierCurveTo(85, 25, 75, 37, 75, 40); ctx.fill(); } } </script> </head> <body onload="draw()"> <canvas id="canvas" width="150" height="150"></canvas> </body> </html>
