# 2017-08-09 221069889742 라즈베리 파이 - 릴리스 버전 설치 (2017. 7. 5)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221069889742&categoryNo=982
- 게시일: 2017. 8. 9. 1:42

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMiAg/MDAxNzU4NDQyODc0NTky.4oNV2mqsLUsB1oAQivUkyaAkopImrIBRB7Nl0DKU7yUg.m70S7-J_Mdp7CYsUUgkAF-rwIRx39Qmn3qDG_MEmfY8g.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(2\).png?type=w80_blur)

​

5월 중순에 시작한 프로젝트가 어느 정도 정리가 되어서 평일에도 약간의 시간이 주어지네요. RASPBIAN JESSIE WITH DEKTOP 은 설치 파일만 4GB 이상이라 SD카드 메모리는 최소 8GB 이상은 되어야 합니다. 4GB 메모리에 OS 설치를 하는 경우에는 RASPBIAN JESSIE LITE로 설치하면 됩니다.

​

![](https://postfiles.pstatic.net/MjAxNzA4MDlfNzQg/MDAxNTAyMjA2OTg0MTgx.dWqfnwrMEPVecK_OM1v5UiSDNVW4rPAiLiPttXC5_wgg.FUBwXdTipJyQ2JULvAICfOLjOC_DLfUp8k52zODzHnQg.PNG.agapeuni/20170808_194544.png?type=w966)

​

집에서 놀고 있는 파이 3대에 라즈비안을 신규로 설치하려고 합니다. 라즈베리 파이 사이트에 다운로드 한 파일을 SD 카드에 이미지 라이팅만 하면 OS 설치가 끝이라 3대에 설치하는 시간이 생각보다 길지는 않았습니다. 업데이트하는 대신 신규 설치가 빠를 수도 있습니다.

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMTY1/MDAxNTAyMjA2OTg0Nzg0.JHg3fpyX9rTpUs7nSA_e-vqjsxqUiEAgNx3V22JcE5Ug.OPPoWbvvHeXvyVGtTW00A9Jywy3oVcRr0zqW4V9Gw2wg.JPEG.agapeuni/IMG_20170808_193642.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/MjAxNzA4MDlfNTYg/MDAxNTAyMjA2OTg0OTc1.v53TAOrmP0S36zY8eg3Jx6XzUkcCFNv7IhK5Myv8KIEg.TjHVif3ytpIErkqjKnuYj_xmQzhqSbUu3e_TsFUuBaAg.JPEG.agapeuni/IMG_20170808_194031.jpg?type=w80_blur)

SD카드에 라즈비안 설치가 끝나면 SD 카드를 파이에 삽입하여 전원을 연결하여 실행하여 봅니다. 얼마간의 로그가 지나가고 Console로 실행하였는데도 아래의 사진처럼 모니터 중앙에 "Welcome to the Raspberry Pi Desktop"라는 문구와 함께 파이 로고가 함께 나타난 이미지가 표시됩니다.

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMjQ0/MDAxNTAyMjA2OTgzOTA2.WOrzkofudA-pzEhs9R_giQFK0uyxaB4xJvtBilaKt2sg.Pfrm_zGXhdxTpJ-ycqV28kFPa-9HbeRkTOy1R70uk8cg.JPEG.agapeuni/mail.naver.jpg?type=w80_blur)

​

Console 모드에서 "sudo raspi-config"로 환경설정 툴메뉴에서 설정 약간의 설정을 변경하고 나서 SSH로 원격으로 접속하여 작업을 진행합니다. 공유기로 연결하여 원격으로 접속하는데 같은 케이블에 파이를 연결하는데도 IP 주소가 바뀌네요. 지금은 192.168.0.12입니다.

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMTY5/MDAxNTAyMjExNzc4OTQz.oujg2idNQc0k1Ww_J_T4c4v7me6q1Gnl8R6Q2k0DBwog.wgX5d9ZC79yl7C48s4LrUnnWXZzTfbf0K7LbBgCk-X8g.PNG.agapeuni/20170809_014539.png?type=w80_blur)

​

원격으로 접속하여 로그인한 뒤 sudo apt-get update 문을 실행합니다.

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMTM1/MDAxNTAyMjExNzc5MzU3.pE4k1TsCx5RkNabi2FP-dBeurM8QS7VK-EdIVJE-K1sg.-B0PFeMgeuL5Hh2Afeg-Nx1yu-VJIriBeucrJ3oFu_og.PNG.agapeuni/20170809_020123.png?type=w80_blur)

​

그리고 sudo apt-get upgrade 문을 실행합니다. 

최신의 라즈비안을 설치하였는데도 Upgrade 할 패키지들이 좀 있네요.

![](https://postfiles.pstatic.net/MjAxNzA4MDlfODkg/MDAxNTAyMjExNzc5NzE3.3cm2Sky36p8SfV4gdq2pgPAO5J8pByQQ5CKScBrqaDkg.DYsQ14LZ82ObHDcDYfskBfqb06wzUlzDN5WhLU9ockQg.PNG.agapeuni/20170809_020139.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMTg4/MDAxNTAyMjEyMzA4Njcw.-KauUClzZkNDotT0wBzmuTgZrT8Q9zdHnWkr4Ky5LNUg.Qj0OyOEHHk_rgpX7IqgCx2LruR13MMlHH4Bd2DSqAGwg.PNG.agapeuni/20170809_021106.png?type=w80_blur)

한참을 업그레이드하더니 이제 작업을 마쳤나 봅니다.

​

이제 아래의 명령어를 입력하여 Java를 설치해 보겠습니다.

$ sudo apt-get install oracle-java8-jdk

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMjAy/MDAxNTAyMjEyNTcwOTcy.ghWy1ae6ybrUr2jexnsdsbPLQj0JH07aEWhy0HOX8Wsg.0XdDYZSFB7Wu6JFD1Mpr6Z1JzDwGMjXz45nw-JoyMYEg.PNG.agapeuni/20170809_021533.png?type=w80_blur)

​

패키지 설치를 마치면 java -version 을 입력하여 정상적으로 설치가 되었는지 확인해 봅니다.

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMjEw/MDAxNTAyMjEyOTUzNDkw.smX7jHlEhBG8zettDgw9bnpAxyMwMD1YVdEU-jQm-Ckg.CqSmYfFUDl2w6MaqdKqF5_9wRVL7apDZfofXYNNYWO4g.PNG.agapeuni/20170809_022004.png?type=w80_blur)

​

이제 아래의 명령을 입력하여 pi4j 유틸리티를 설치합니다. RaspberryPi에 Pi4J를 설치하는 가장 간단한 방법입니다.

$ curl -s get.pi4j.com | sudo bash

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMjg5/MDAxNTAyMjEzMDc4ODM1.lahggtje9sCpZcR8QH6EBRhnNs4lzH91jd8glA9w48Yg.qXf2wdhlMtWj9bCRPq__ZKkjfOjm6IObGG4WQBfsupsg.PNG.agapeuni/20170809_022417.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAxNzA4MDlfNjUg/MDAxNTAyMjEzMzkxNzk4.GFYs7pUlA4pZbN1N5zeaAhjmxQDWL0hEH0cvT33lpUAg.lHKQ9ix5PkLDhuZmGNMGquUBwXoAfsPiXNODohIFcRQg.PNG.agapeuni/20170809_022915.png?type=w80_blur)

​

현재 설치된 리눅스 커널 버전은 4.9.35인데 PI4J 실행 시 아래와 같은 메시지가 출력되며 실행이 되지 않는 문제가 있습니다.

unable to determine hardware version. i see: hardware : bcm2835

![](https://postfiles.pstatic.net/MjAxNzA4MDlfOCAg/MDAxNTAyMjEzNzgyODk4.lUqv3g2qlUq6zwdUptFNOZdiiNM-Rj6P60Myz-4CuGYg.Zks9jQ-1HqPJ6Lbo6dcycqAVns_UX3eYFjBXjmnLy04g.PNG.agapeuni/20170809_023538.png?type=w80_blur)

​

그래서 아래의 명령어를 입력하여 리눅스 커널 버전을 4.4.50로 변경합니다. 작업이 완료가 되면 재부팅이 필요합니다.

sudo rpi-update 52241088c1da59a359110d39c1875cda56496764

![](https://postfiles.pstatic.net/MjAxNzA4MDlfNzYg/MDAxNTAyMjE0MDI5MzAx.5CYQ6R-ZYvqNxSWcwuBb2Q_5O-72O5M2vL0E09bgNMAg.ShnjluyaQ2PrGNUW16I3ZukSOq221s3d4L3prfBybqQg.PNG.agapeuni/20170809_023947.png?type=w80_blur)

​

리부팅을 하고 리눅스 커널 버전을 확인해 보면 4.9.35에서 4.4.50으로 변경되어 있습니다. 

그리고 Hardware 가 BCM2708로 되어 있습니다. 

![](https://postfiles.pstatic.net/MjAxNzA4MDlfMTA3/MDAxNTAyMjE0MjI5NDIw.pKMOZkbUDcdUEnqZ_LN0C9sMP2lMq1RZbIeHDlWS19cg.HSBKIBs4ysLuvF67s7BgxVGPMMTu4CWUTEtxuMuxiXEg.PNG.agapeuni/20170809_024306.png?type=w80_blur)
