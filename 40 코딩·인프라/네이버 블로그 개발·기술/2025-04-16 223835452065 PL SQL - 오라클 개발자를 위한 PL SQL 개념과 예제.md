# 2025-04-16 223835452065 PL SQL - 오라클 개발자를 위한 PL SQL 개념과 예제

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfMjUz/MDAxNzQ0NzcyODQ4NDg3.B_9Q9DRGgU4NBVt3REvyJWq8m4gVP_d5mVkpJGqIuv8g.DwaH87DY5AbVf1_K9EYpcUFKtL1penmNiiauSttHGSMg.PNG/PL_SQL-001.png?type=w80_blur)

​

Oracle 데이터베이스를 다루는 개발자에게 있어, PL/SQL은 SQL을 보다 유연하고 강력하게 활용할 수 있도록 해주는 언어이다. PL/SQL은 Oracle DB 내에서 SQL의 기능을 확장하고, 더욱 유연한 데이터 처리 및 트랜잭션 관리를 가능하게 해주는 중요한 도구이다. 

​

본 글에서는 PL/SQL의 개념적 이해부터 실습에 필요한 환경 구성, 그리고 기본적인 코드 예제에 이르기까지 전반적인 내용을 소개하고자 한다.

**​**

**1\. PL/SQL이란 무엇인가?**

PL/SQL은 **Procedural Language / Structured Query Language** 의 약어로, SQL에 절차적 로직을 결합한 **오라클 고유의 프로그래밍 언어** 이다. 오라클사는 데이터베이스 내부에서 **절차적인 처리** 를 가능하게 하기 위해 이를 개발하였으며, 다음과 같은 특징을 지닌다.

  * SQL문을 **블록 구조** 로 작성할 수 있다.

  * **변수 선언** , **조건문** , **반복문** 등 전통적인 프로그래밍 기능을 지원한다.

  * **예외 처리** , **데이터 캡슐화** , **정보 은닉** , **객체 지향적 설계** 가 가능하다.

  * **Stored Procedure** 나 **Function** 등 재사용 가능한 단위로 관리된다.

​

​

**2\. PL/SQL의 처리 과정**

PL/SQL 코드는 Oracle의 **선행 컴파일러** 에 의해 Oracle Server 내부의 **PL/SQL 엔진** 으로 전달된다. 해당 엔진은 블록 내에 포함된 SQL문을 하나씩 분리하여 SQL 실행 엔진으로 전송하고, 나머지 절차적 로직은 자체적으로 처리한다. PL/SQL 코드는 Oracle Server에 저장될 수 있으며, 이 경우 **Stored Procedure** 또는 **Stored Function** 이라는 이름으로 관리된다. Oracle Developer와 같은 도구는 자체 PL/SQL 엔진을 가지고 있어 서버와는 독립적으로 코드 실행이 가능하다.

​

​

**3\. 실습을 위한 사전 준비**

**권한 설정**

PL/SQL 실습을 위해서는 다음과 같은 권한이 필요하다.

  * CREATE PROCEDURE

  * CREATE SESSION

  * CREATE TABLE

  * CREATE TRIGGER

  * CREATE VIEW

  * CREATE TYPE

**​**

**필수 패키지**

Oracle에서 제공하는 다양한 패키지를 활용할 수 있으며, 대표적으로는 다음과 같다.

  * DBMS_OUTPUT

  * DBMS_SQL

  * DBMS_PIPE

  * DBMS_ALERT

  * UTL_FILE

​

패키지의 존재 여부는 아래와 같은 SQL문으로 확인할 수 있다.

SELECT OBJECT_NAME FROM DBA_OBJECTS WHERE OWNER = 'SYS' AND OBJECT_TYPE = 'PACKAGE'; 

​

​

**4\. PL/SQL 블록 구조**

PL/SQL의 기본 구조는 다음과 같이 구성된다.

DECLARE \-- 변수 선언 BEGIN \-- 실행할 코드 EXCEPTION \-- 예외 처리 END; 

  * DECLARE : 변수, 커서, 서브 프로그램 등을 선언하는 영역

  * BEGIN : 실제 실행 코드가 들어가는 영역

  * EXCEPTION : 런타임 예외 발생 시 처리할 코드를 작성

  * 각 문장은 반드시 세미콜론(;)으로 끝을 표시해야 하며, 블록 내부에 다른 블록을 중첩할 수 있다.

**​**

**​**

**5\. 실습 예제**

**예제 1: 변수 선언 및 값 할당**

DECLARE x NUMBER; BEGIN x := 65400; END; / 

슬래시(/)는 SQL*Plus에서 코드 입력이 종료되었음을 나타내는 명령어이다.

**​**

**예제 2: 결과 출력**

DBMS_OUTPUT 패키지를 사용하여 결과를 출력할 수 있다. 출력이 가능하도록 하기 위해 먼저 다음 명령을 실행해야 한다.

SQL> SET SERVEROUTPUT ON; 

이후 아래와 같이 작성한다.

DECLARE x NUMBER; BEGIN x := 65400; dbms_output.put_line('The variable x = '); dbms_output.put_line(x); END; / 

긴 코드는 .sql 파일로 저장하여 불러오는 방식으로 관리할 수 있다:

$ vi /export/home/oracle/plsql/test.sql :wq SQL> @/export/home/oracle/plsql/test 

**​**

**예제 3: 사용자 정의 함수 작성**

$ vi /export/home/oracle/plsql/test.sql :wq SQL> @/export/home/oracle/plsql/test 

  * CREATE OR REPLACE는 동일한 이름의 함수가 존재할 경우 이를 덮어쓴다.

  * AS 이전은 선언부이며, 이후가 실행부이다.

  * 함수는 DB에 저장되므로, 이후 호출만으로 재사용이 가능하다.

함수 확인

SELECT * FROM DBA_OBJECTS WHERE OBJECT_NAME = 'SS_THRESH'; 

함수 호출

SELECT SS_THRESH FROM DUAL; 

단, 함수 생성 직후 STATUS가 INVALID로 표시되었다면 코드에 오류가 있는 것으로 판단되며, SHOW ERRORS 명령어를 통해 원인을 확인해야 한다.
