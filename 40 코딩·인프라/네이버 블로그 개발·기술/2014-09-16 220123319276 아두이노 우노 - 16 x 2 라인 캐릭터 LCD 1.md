16 x 2 Char LCD로 간단한 문자를 출력해 보는 실험과 프로그레스바를 표시해 보는 실험을 해보겠습니다. 

이번 실험을 위해 16 x 2 Line Char LCD (5V) 를 하나 장만하였습니다. 살림이 나날이 늘어가고 있습니다.

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다. 

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 16 x 2 Line Char LCD 1개 (헤더핀 납땜해둠)

  * Trimmers 가변저항 1개

  * 점퍼선 8개 + a

![](https://postfiles.pstatic.net/20160506_18/agapeuni_1462518962512JYTpL_JPEG/20140831_152657.jpg?type=w966)

아래는 16 x 2 Line Char LCD 인터페이스입니다. 핀 연결시 참고하세요.

![](https://postfiles.pstatic.net/20140916_183/agapeuni_14108259170682pVtb_JPEG/20140901_045339.png?type=w80_blur)

이 부품은 기판에 핀 인터페이스가 친절히 인쇄되어 있네요. ㅎㅎ

**▣ 소스코드**

#include <LiquidCrystal.h> LiquidCrystal lcd(2, 3, 4, 5, 6, 7); byte b00[8] = { 00, 00, 00, 00, 00, 00, 00, 00 }; byte b16[8] = { 16, 16, 16, 16, 16, 16, 16, 16 }; byte b24[8] = { 24, 24, 24, 24, 24, 24, 24, 24 }; byte b28[8] = { 28, 28, 28, 28, 28, 28, 28, 28 }; byte b30[8] = { 30, 30, 30, 30, 30, 30, 30, 30 }; byte b31[8] = { 31, 31, 31, 31, 31, 31, 31, 31 }; void setup() { lcd.begin(16, 2); lcd.print("One Way, Jesus!!"); lcd.createChar(0, b00); lcd.createChar(1, b16); lcd.createChar(2, b24); lcd.createChar(3, b28); lcd.createChar(4, b30); lcd.createChar(5, b31); } void loop() { lcd.setCursor(0, 1); for (int i = 0; i < 16; i++) { for (int j = 0; j < 6; j++) { lcd.setCursor(i, 1); lcd.write(j); delay(30); } } for (int i = 15; i > -1; i--) { for (int j = 5; j > -1; j--) { lcd.setCursor(i, 1); lcd.write(j); delay(30); } } }

Trimmers 가변저항을 적절히 맞추어야 Line Char LCD에 문자가 잘 표시됩니다.
