# 2015-02-25 220282599919 아두이노 우노 - 서보모터 실험 (Servo Motor)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220282599919&categoryNo=982
- 게시일: 2015. 2. 25. 2:47

![](https://postfiles.pstatic.net/MjAyNTA5MjFfNjcg/MDAxNzU4NDMwOTMxODEw.0-QEv0KkP16nqUU0Yre988Tk0Evpp2rusQrOXR8Y0b0g.HU8_5t-YWa1Y89fzc3EPooEP9ivYUH9q236XsnORfgYg.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(8\).png?type=w80_blur)

**​**

**아두이노 우노**(Arduino UNO)에서 서보모터를 이용한 간단한 실험을 해보겠습니다.

포텐셔미터(potentiometer)를 이용해서 서보모터의 움직임을 제어합니다.

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다. 

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * 서보모터 1개

  * 포텐셔미터 (연결선을 미리 납땜해둠)

  * 점퍼선 4개 

![](https://postfiles.pstatic.net/20160506_144/agapeuni_14625194815873toMd_JPEG/20150223_020711.jpg?type=w966)

​

먼저 **아두이노 우노**(Arduino UNO)의 2핀과 서보모터 제어선인 오렌지색 선과 연결합니다.

그리고 검정 점퍼선을 접지와 서보모터 갈색 선과 연결하고 빨강 점퍼선을 전원과 서보모터 적색 선과 연결합니다.

![](https://postfiles.pstatic.net/20160506_159/agapeuni_1462519481848RBcUd_JPEG/20150223_020715.jpg?type=w966)

​

포텐셔미터의 값을 **아두이노 우노**(Arduino UNO)에 입력하기 위해 A0핀과 포텐셔미터의 노란색 선과 연결합니다.

포텐셔미터의 초록 선과 접지를 연결하고 주황색 선과 전원을 연결합니다.

​

![](https://postfiles.pstatic.net/20160506_136/agapeuni_1462519482128YMCPf_JPEG/20150223_020717.jpg?type=w966)

포텐셔미터의 값이 노란색 선으로 **아두이노 우노**(Arduino UNO)에 입력값으로 들어가게 됩니다.

그리고 **아두이노 우노**(Arduino UNO)에서 하얀색 점퍼선으로 서보모터에 제어를 위한 신호를 출력하게 됩니다.

참고로 우측에 있는 버튼들은 이전에 다른 실험을 위해 사용한 것으로 이번 실험과는 무관합니다. 

![](https://postfiles.pstatic.net/20160506_103/agapeuni_1462519482392sF1Dx_JPEG/20150223_020744.jpg?type=w80_blur)

​

서보모터의 움직임을 확인하기 위해 철사를 이용하여 아래의 그림과 같이 좀 허접한 고정대를 만들어 보았습니다. 

![](https://postfiles.pstatic.net/20160506_77/agapeuni_1462519482605RvTRt_JPEG/20150223_020817.jpg?type=w80_blur)

![](https://storep-phinf.pstatic.net/james_special/original_11.png?type=p50_50)

이번 실험을 위해 완성된 모습니다.

![](https://postfiles.pstatic.net/20160506_294/agapeuni_14625194828169Vde1_JPEG/20150223_020818.jpg?type=w80_blur)

**실험. 소스코드 (servo_1.ino)**

이번 실험에 사용된 코드는 간단합니다. 

포텐셔미터에서 입력된 0~1023 범위의 값을 읽어서 0~179 출력값을 서보모터를 제어를 위해 2번 핀으로 보냅니다.

#include <Servo.h> Servo servo; void setup() { servo.attach(2); } void loop() { servo.write(map(analogRead(A0), 0, 1023, 0, 179)); delay(20); }

**​**

**실험. 동영상**

포텐셔미터를 움직이면 서보모터가 같이 움직입니다.
