**​**

날씨가 점점 더워지고 있습니다. 조만간 무더운 여름이 찾아오겠네요. DHT11이라는 온도 & 습도 센서를 하나 마련하여 센싱 실험을 해보았습니다. DHT11을 사용하여 스케치를 작성하기 전에 해당 라이브러리를 먼저 설치해야 합니다. 아두이노 IDE의 메뉴에서 "스케치 - 라이브러리 포함하기 - 라이브러리 관리"를 선택하면 라이브러리 매니저가 호출됩니다.

![](https://postfiles.pstatic.net/MjAyMDA2MTJfMjM4/MDAxNTkxOTY1MDAxMDQw.yr2mRcKBNV4YKRg1q_wLc9Ntv8kwnPB7ZfndvVWdM3Ig.j6fbxw2dWDIBrkK595B3RHtK8zfgIIKuZgcyaugSbFEg.PNG.agapeuni/SE-e9e48a15-b437-4d47-88ba-f498da9808ce.png?type=w80_blur)

​

​

라이브러리 매니저에서 dht를 입력하고 검색하면 "DHT sensor library"가 조회됩니다. 우측에 있는 설치 버튼을 클릭하면 관련 라이브러리를 다운로드합니다. 그럼 아두이노 스케치에서 DHT 라이브러리를 사용할 수 있습니다.

![](https://postfiles.pstatic.net/MjAyMDA2MTJfNjYg/MDAxNTkxOTY1MDAxNDM0.OUFBA4Q5ecIwWMnWn_v6UbmytX5fcekFyBADyLXLn4Qg.TTdSAF_M4NpyKWEfPwC2hZtDMZFhth3W-ez23akkabwg.PNG.agapeuni/SE-07a199f4-adae-4499-abd4-ea4b2367a5a1.png?type=w80_blur)

​

DHT11 센서는 4개의 핀이 있는데 왼쪽에서부터 첫 번째가 Vcc, 두 번째가 Data, 세 번째는 연결하지 않고 마지막 네 번째에 Gnd를 연결합니다. DHT11 센서의 Data 핀에 아래의 그림과 같이 4.7K 옴의 저항을 연결하고 점퍼선으로 아두이노 2번에 연결합니다.

다음은 습도와 온도(섭씨와 화씨)를 시리얼 모니터에 출력하는 코드입니다. 5초마다 주기적으로 표시하고 있습니다.

**첨부파일**

DHT11_1_simple.ino

[ 파일 다운로드 ](https://download.blog.naver.com/open/43d65feffaa3a77b56b9d6e4de3c473d98c93cd3fd/EFsQbbZLxr7O9ttdLuoSggWaFwbSq-VhdkQGNWY5_gMuGY-3VnUj6Pu5A4cOhihl0EmDbl7x51rTe5UMuKtiZ3bg72dr-7Q/DHT11_1_simple.ino)

#include "DHT.h" #define DHTPIN 2 #define DHTTYPE DHT11 DHT dht(DHTPIN, DHTTYPE); void setup() { Serial.begin(9600); dht.begin(); } void loop() { // 습도 float humidity = dht.readHumidity(); // 섭씨 float temperature = dht.readTemperature(); // 화씨 float fahrenheit = dht.readTemperature(true); if (isnan(humidity) || isnan(temperature) || isnan(fahrenheit)) { Serial.println("Failed"); return; } // 섭씨 보정 float heatTemperature = dht.computeHeatIndex(temperature, humidity, false); // 화씨 보정 float heatFahrenheit = dht.computeHeatIndex(fahrenheit, humidity); Serial.print("습도: "); Serial.print(humidity); Serial.print(" %\t"); Serial.print("섭씨: "); Serial.print(temperature); Serial.print("\t"); Serial.print("화씨: "); Serial.print(fahrenheit); Serial.print("\t"); Serial.print("섭씨보정: "); Serial.print(heatTemperature); Serial.print("\t"); Serial.print("화씨보정: "); Serial.print(heatFahrenheit); Serial.println(); delay(5000); }

스케치를 업로드하고서 얼마 후에 온도와 습도를 올리기 위해 센서를 손으로 잡고 계속하여 입김을 불어보았습니다. 

습도는 처음 59에서 80까지 올라갔고 섭씨온도는 25도에서 30도까지 올라갔습니다.
