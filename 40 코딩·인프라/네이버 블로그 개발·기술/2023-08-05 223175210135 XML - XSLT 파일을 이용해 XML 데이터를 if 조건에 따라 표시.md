**1\. XML 문서**

XSLT를 사용하여 XML 문서의 데이터를 if 조건에 따라 분기해서 표시해 보자. 

XSLT에서는 <xsl:if test="조건">, </xsl:if> 요소를 사용하여 조건을 처리한다.

​

아래의 XML 파일은 CD 목록을 관리하고 있고 cd_list_if.xsl 파일을 스타일시트로 읽고 있다.

**파일 : cd_list_if.xml**

<?xml version="1.0" encoding="ISO-8859-1"?> <?xml-stylesheet type="text/xsl" href="cd_list_if.xsl"?> <catalog> <cd> <title>Hide your heart</title> <artist>Bonnie Tyler</artist> <country>UK</country> <company>CBS Records</company> <price>9.90</price> <year>1988</year> </cd> <cd> <title>Greatest Hits</title> <artist>Dolly Parton</artist> <country>USA</country> <company>RCA</company> <price>9.90</price> <year>1982</year> </cd> <cd> <title>Still got the blues</title> <artist>Gary Moore</artist> <country>UK</country> <company>Virgin records</company> <price>10.20</price> <year>1990</year> </cd> <cd> <title>Maggie May</title> <artist>Rod Stewart</artist> <country>UK</country> <company>Pickwick</company> <price>8.50</price> <year>1990</year> </cd> <cd> <title>When a man loves a woman</title> <artist>Percy Sledge</artist> <country>USA</country> <company>Atlantic</company> <price>8.70</price> <year>1987</year> </cd> <cd> <title>For the good times</title> <artist>Kenny Rogers</artist> <country>UK</country> <company>Mucik Master</company> <price>8.70</price> <year>1995</year> </cd> <cd> <title>Tupelo Honey</title> <artist>Van Morrison</artist> <country>UK</country> <company>Polydor</company> <price>8.20</price> <year>1971</year> </cd> <cd> <title>Pavarotti Gala Concert</title> <artist>Luciano Pavarotti</artist> <country>UK</country> <company>DECCA</company> <price>9.90</price> <year>1991</year> </cd> <cd> <title>Picture book</title> <artist>Simply Red</artist> <country>EU</country> <company>Elektra</company> <price>7.20</price> <year>1985</year> </cd> <cd> <title>Unchain my heart</title> <artist>Joe Cocker</artist> <country>USA</country> <company>EMI</company> <price>8.20</price> <year>1987</year> </cd> </catalog>

​

**2\. XSLT 파일**

**<****xsl:for-each****select** =_"catalog/cd"_**> **태그로 catalog 안에 cd 태그를 반복하면서 출력한. **<****xsl:sort****select** =_"company"_**/ > **태그로 company 이름순으로 정렬을 한다. **<****xsl:if****test** =_"price &gt; 8"_**> **태그로 price가 8보다 큰 데이터를 표시한다. 

참고로 '&gt;'는 >를 '&lt;'는 < 를 나타낸다.

XSLT 파일은 다음과 같다.

**파일: cd_list_if.xsl**

<?xml version="1.0" encoding="ISO-8859-1"?> <xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform"> <xsl:template match="/"> <html> <body> <h2>My CD List</h2> <table border="1"> <tr bgcolor="#9ACDA2"> <th>Title</th> <th>Artist</th> <th>Company</th> <th>Price</th> </tr> <xsl:for-each select="catalog/cd"> <xsl:sort select="company" /> <xsl:if test="price&gt;8"> <tr> <td> <xsl:value-of select="title" /> </td> <td> <xsl:value-of select="artist" /> </td> <td> <xsl:value-of select="company" /> </td> <td> <xsl:value-of select="price" /> </td> </tr> </xsl:if> </xsl:for-each> </table> </body> </html> </xsl:template> </xsl:stylesheet>

​
