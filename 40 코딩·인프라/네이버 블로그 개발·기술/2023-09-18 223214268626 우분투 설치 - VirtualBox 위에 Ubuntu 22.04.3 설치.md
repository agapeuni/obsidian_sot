​

Oracle VM VirtualBox에서 Ubuntu를 설치해본다.

Ubuntu 22.04 LTS ISO 파일을 사용하여 가상 머신을 설치하는 것을 기반으로 한다.

​

​

1\. VirtualBox 설치

먼저 가상화 소프트웨어인 Oracle VM VirtualBox를 다운로드하고 윈도우에 설치한다.

​

다음 링크에서 최신 버전을 다운로드할 수 있다.

<https://www.virtualbox.org/>

![](https://postfiles.pstatic.net/MjAyMzA5MThfMjQz/MDAxNjk0OTY2NDgyMzkz.z6Z996D9F-rWluMCGH2z9LIt-Jsq-2FY106SH5-MlNog.NvynchszIG3zKYfbhwSr_Xxkbk63EVapXsamPAtMVi8g.PNG.agapeuni/button70.png?type=w80_blur)

​

설치 파일 : VirtualBox-7.0.10-158379-Win.exe

​

VirtualBox의 설치 경로는 기본 위치에 설치했다.

Location : C:\Program Files\Oracle\VirtualBox

![](https://postfiles.pstatic.net/MjAyMzA5MThfMTYw/MDAxNjk0OTY2NTkwMDQ3.9_GqUP_GxSb-kBAMtYuHRI3SjHyi4W54z6BGv22ooskg.7XbGWRl9FNMC2cn3-Sn2ySFGv7V1Gmg4pgWRL3L2rfUg.PNG.agapeuni/20230917_204612.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyMzA5MThfNDcg/MDAxNjk0OTY2NTkwMDM5.T7BD4e5F8GpzG3hNolUFVNMalVvFoVQm-6uI2zHlNssg.9RMeXYOsnWLi3cWPW3ECr0siW0U-ORTZf2UuoI9UBrsg.PNG.agapeuni/20230917_204616.png?type=w80_blur)

​

Network Interfaces와 Python Core / win32api 모두 Yes를 클릭한다.

![](https://postfiles.pstatic.net/MjAyMzA5MThfMTEy/MDAxNjk0OTY2NTk2NDMw.mjI_67ZM3le6BcJN29XPHhek8QkuP8uGSM7x7mvd8U8g.gOIOPSFNiPv4-Yv73Gq66DbSAQ27KAb-L2MsO9Ax48Yg.PNG.agapeuni/20230917_204620.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyMzA5MThfMTAx/MDAxNjk0OTY2NTk2NDMz.xlHMpunKGyGxbfP7mMpZ4txRtWflDRUv2bLPy3dewNwg.0eCKYPGcBIb07iv7J_Otxf9Py9egX2MVPSdTP7lvsa0g.PNG.agapeuni/20230917_204624.png?type=w80_blur)

​

Install 버튼을 클릭하여 설치를 진행한다. 

![](https://postfiles.pstatic.net/MjAyMzA5MThfMTIx/MDAxNjk0OTY2NjE1MjM4.5cBsT_hrxfdDy-4akSCwIvwb3xVW1lOlRJj_cG39xwog.lBM1PDggaRQzuX7EfyXxyzMzLCCI4JWX0c7jSTNy6agg.PNG.agapeuni/20230917_204627.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyMzA5MThfMjc3/MDAxNjk0OTY2NjE5MDgx.LYCfYHDzjMKaHyb3hbtudG6WEjbl9IpQpDmB9KRyq_Qg.-KqVsksJiJQibAh6SHf4MAEetopawLrtrxD1QOdRpgEg.PNG.agapeuni/20230917_204822.png?type=w80_blur)

​

2\. Ubuntu 22.04 LTS ISO 다운로드

Ubuntu 22.04 LTS의 ISO 이미지 파일을 다운로드한다.

2027년 4월까지 5년간 무료 보안 및 유지 관리 업데이트가 보장된다.

​

ISO 이미지 파일은 Ubuntu 공식 웹사이트에서 제공된다.

<https://ubuntu.com/download>

[ **Get Ubuntu | Download | Ubuntu** Download Ubuntu desktop, Ubuntu Server, Ubuntu for Raspberry Pi and IoT devices, Ubuntu Core and all the Ubuntu flavours. Ubuntu is an open-source software platform that runs everywhere from the PC to the server and the cloud. ubuntu.com ](https://ubuntu.com/download)

PC와 노트북을 지원하는 오픈 소스 데스크톱 운영체제인 Ubuntu Desktop 버전을 다운로드 한다.

ISO 파일 : ubuntu-22.04.3-desktop-amd64.iso

![](https://postfiles.pstatic.net/MjAyMzA5MThfMjEg/MDAxNjk0OTY2ODI0NTg5.sfN9DKAB0jJBKWPPeJHLksD-pVfVxpPb8lRhWPE7pdcg.hb4pRnx1g7HfI3K1MXRp90a7tGEF3uGjG8UzhC0kqHwg.PNG.agapeuni/image.png?type=w80_blur)

3\. VirtualBox 가상 머신 생성

Oracle VM VirtualBox 관리자를 실행하고 새로운 가상 머신을 만든다.

![](https://postfiles.pstatic.net/MjAyMzA5MThfNCAg/MDAxNjk0OTY3MTAwMzAw.nsyZNrRB0maagNZvRqeVpe11NUjHdTp_QqGCJku3rKkg.R2jx9-9Df_sHtns2NRvC5uTxevbO0k1BJKBNGSyAuHAg.PNG.agapeuni/image.png?type=w80_blur)

​

가상 머신 이름을 지정하고, 다운로드 한 Ubuntu ISO 파일을 선택한다.

가상 머신 이름은 Ubuntu로 하고 ISO 파일을 선택하면 자동으로 종류와 버전을 판별한다.

![](https://postfiles.pstatic.net/MjAyMzA5MThfMTUx/MDAxNjk0OTY3MjM2MDcw.lEXjFAj6o1e1Dne2qqwQOG5HK7EDRy7k8o7_W3oTyYog.m8y3Vep08UFuxKUq1pswJhrgQQwADY8MddtO2jrWeLEg.PNG.agapeuni/image.png?type=w80_blur)

​

Username은 user로 암호는 1234로 입력한다.

![](https://postfiles.pstatic.net/MjAyMzA5MThfNzkg/MDAxNjk0OTY3NDEzNDA3.efTmTmha8dV5JTf2jOjZ_6tLtpzDptm5g1fTtsXRf7gg.DLvZ_rk75zZK8Vq4RqG8USEkms8xI3h0q0S-zYu53tUg.PNG.agapeuni/image.png?type=w80_blur)

​

기본 메모리는 2048 MB (2 GB)로 프로세서는 1개로 지정한다.

![](https://postfiles.pstatic.net/MjAyMzA5MThfMTk0/MDAxNjk0OTY3NDQ4MTA5.InnljmFSPoyqo6NXhnaZDnFo7neg7Vmd-QiowPspoiEg.4MVEJAd8fNPIh5md2hQLYF5SfTolk-sYi5v0VBgACAog.PNG.agapeuni/image.png?type=w80_blur)

​

"가상 하드 디스크"는 일반적으로 최소 20GB 이상의 디스크 공간을 할당하는 것이 좋다. 여기서는 25 GB로 설정한다.

![](https://postfiles.pstatic.net/MjAyMzA5MThfNSAg/MDAxNjk0OTY3NTc2OTMw.36EOVkjd_5NMoVUxffLSauprX31halb7C6vQdrCLyyEg.HJo5s0N8rM-ODtAPRFyOiQQcIVExwBR4ek5qQhk2cVYg.PNG.agapeuni/image.png?type=w80_blur)
