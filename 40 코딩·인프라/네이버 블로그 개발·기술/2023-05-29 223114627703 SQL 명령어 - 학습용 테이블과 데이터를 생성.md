**1\. SQL 명령 개요**

SQL은 데이터베이스에서 작업을 실행하고 데이터베이스를 구성할 수 있게 해주는 언어이다. 

SQL은 CREATE, DROP, GRANT, INSERT 등과 같은 명령을 사용한다. SQL 명령은 DML, DDL, DCL, TCL과 같이 네 그룹으로 나눈다.

**2\. SQL 명령어**

구분 |  명령어 |  설명  
---|---|---  
데이터 조작어 (DML)Data Manipulation Language |  INSERTUPDATEDELETE  |  데이터베이스의 테이블에 들어 있는 데이터를 다루는 명령어  
SELECT  |  데이터베이스의 데이터를 조회하기 위한 명령어  
데이터 정의어 (DDL)Data Definition Language |  CREATEALTERDROPRENAMETRUNCATE  |  데이터베이스 개체를 만들고 테이블 구조를 정의하고 수정 및 삭제하기 위한 명령어  
데이터 제어어 (DCL)Data Control Language  |  GRANTREVOKE  |  데이터베이스에서 사용자 접근을 관리하는 명령어  
트랜잭션 제어어 (TCL)Transaction Control Language |  COMMITROLLBACKSAVEPOINT  |  논리적인 작업의 단위를 묶어 DML 작업 단위별로 제어하는 명령어  
  
​

​

**3\. 데이터 정의어 (DDL, Data Definition Language)**

SQL 연습을 위해 EXAMPLE 데이터베이스를 생성하고 부서, 직위, 사원 테이블을 생성해 보자.

CREATE DATABASE EXAMPLE; USE EXAMPLE; CREATE TABLE IF NOT EXISTS `TB_DEPT` ( `DEPT_CD` VARCHAR(2), `DEPT_NAME` VARCHAR(50), PRIMARY KEY (`DEPT_CD`) ); CREATE TABLE IF NOT EXISTS `TB_POSITION` ( `POS_CD` VARCHAR(2), `POS_NAME` VARCHAR(50), PRIMARY KEY (`POS_CD`) ); CREATE TABLE IF NOT EXISTS `TB_EMPLOYEE` ( `EMPL_ID` VARCHAR(5), `FULL_NAME` VARCHAR(50), `DEPT_CD` VARCHAR(2), `POS_CD` VARCHAR(2), `HIRE_DATE` VARCHAR(8), `GENDER` VARCHAR(1), `MARRIED` VARCHAR(1), `SALARY` INT(12), `MEMO` TEXT, PRIMARY KEY (`EMPL_ID`) );
