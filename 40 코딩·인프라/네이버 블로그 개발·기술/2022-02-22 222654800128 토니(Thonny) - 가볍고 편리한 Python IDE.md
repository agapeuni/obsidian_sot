1\. 토니(Thonny)

요즘 실무에서도 많이 사용하고 있는 Python을 준비하고자 시간이 나면 틈틈히 학습을 하고 있다. PyCharm Community 를 많이 사용하고 있지만 라즈비안에 설치되어 있는 Thonny Python IDE으로 손이 간다. 라즈베리 파이를 별도로 시작해야 하는 불편함은 있는데도 Python 코딩은 주로 Thonny Python IDE로 하고 있다.

![](https://postfiles.pstatic.net/MjAyMzA2MzBfNTcg/MDAxNjg4MDgxMzMxMDc5.H-imgmTlpXVQtMKDFU9wSKF3oY26YI0pm-fM1OBgP7Yg.5v1UB3wYssXyrQckWva7MdFdkZFQtaLqut0opF6kvcYg.PNG.agapeuni/screenshot.png?type=w80_blur)

[출처] <https://thonny.org/>

​

토니(Thonny)는 매우 심플하고 기능도 간단하여 Python 코딩을 쉽게 할 수 있다. 초보자에게 필요한 최소한의 기능을 담고 있어서 Python 입문자에게 괜찮은 개발도구이다. 화면도 직관적이라 적은 시간만 투자해도 원하는 기능을 충분하게 다룰 수 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMjJfNzQg/MDAxNjQ1NTE5MjI5OTkw.8--rHOIJ3d8tyOlOI60QyN7Dhvl7h_QcH-S0PH6FWKUg.8FqTEiWxfrDm5zitpVQOcfuE698n4hDiZ4JT6ZbBpW0g.PNG.agapeuni/1.png?type=w80_blur)

2\. 토니(Thonny) 특징

![](https://postfiles.pstatic.net/MjAyMjAyMjJfMTI3/MDAxNjQ1NTE5MjM3NTkx.Eg4okpC7j8tTxCnlI6jT5QqGJ1W6TE5oez84DMDtmIwg.kGMIOVaXucE3E-H7aLEuHsGKPpmfi-W9KmiHh_MacHMg.PNG.agapeuni/2.png?type=w80_blur)

**2-1. 디버깅**

디버깅을 하려면 라인번호에 더블클릭하면 브래이크포인터가 생긴다. 파이썬 코드를 실행하기 위해서는 F5키를 누르면 되고 디버깅을 하려면 Ctrl + F5키를 누르면 된다. 디버깅 모드에서 Step Over는 F6키 이고 Step Into는 F7키 그리고 Resume은 F8키이다. 디버깅 모드에서 함수를 만나게 되면 아래의 화면과 같이 함수를 별도의 화면으로 표시한다.

![](https://postfiles.pstatic.net/MjAyMjAyMjJfNSAg/MDAxNjQ1NTE5MjY1MTMy.nvxQStZvWV0pwnV3P9Sz_Y5yXAS1B7iaN1XUfZLYF9og.n40CR3aPeaCJb6sx011n2_1X7yi_Q-8U4vjFhoQKmbsg.PNG.agapeuni/3.png?type=w80_blur)

​

**2-2. Heap 모드**

Heap 모드는 현재의 변수가 가리키고 있는 Heap 메모드 주소와 Heap 영역에서 갖고 있는 값을 표시해 준다. Heap 모드에서 나오려면 Heap 탭을 닫으면 된다. Object inspector는 Varialbles 탭이나 Heap 탭에 있는 항목을 클릭하면 관련정보를 자세하게 보여준다.

![](https://postfiles.pstatic.net/MjAyMjAyMjJfMTMx/MDAxNjQ1NTE5Mjg3Mzc3.44veRU96GfKv0GeonjolbKyhnx_ku4FQcQv5orTvprcg.qcsf7wA6dvphUusbhBsnfz2pU1n5AS3Nx95XHR_CkTMg.PNG.agapeuni/4.png?type=w80_blur)

​

**2-3. 패키지 설치**

"Tools > Manage packages" 메뉴를 클릭하면 PyPI에서 패키지를 찾아주는 팝업화면이 열린다. 

패키지명을 검색하여 클릭으로 설치할 수 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMjJfMjQy/MDAxNjQ1NTE5Mjk2OTgx.KLLW49OCGctLjnOuUyQ_xQAZljKbj6Rdbwcl56QEipog.X8WKOwU6M4SWY2y6g4WXXwgw3EWNWTXZGA8R1T2HK-cg.PNG.agapeuni/5.png?type=w80_blur)

​

**2-4. 쉘 실행**

"Tools > Open system shell" 메뉴를 클릭하면 시스템 쉘 화면이 바로 표시된다.

![](https://postfiles.pstatic.net/MjAyMjAyMjJfMTY2/MDAxNjQ1NTE5MzA3ODcw._GcgbbodvmmGxsJziDd6JhhpzNWKHwB_ERRTYiQrT0Qg.bmAijkMA2GyB826yeEKeNEWiMJlAZiRUFMa_Z--JmPMg.PNG.agapeuni/6.png?type=w80_blur)
