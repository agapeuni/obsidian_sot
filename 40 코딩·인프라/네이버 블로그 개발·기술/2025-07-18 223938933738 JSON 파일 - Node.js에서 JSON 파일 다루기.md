1\. 개요

JSON(JavaScript Object Notation)은 텍스트 기반의 데이터 포맷으로, 키(key)와 값(value) 쌍으로 구성되어 있으며, 주로 서버와 클라이언트 간 데이터 전송에 활용된다. 이번 포스팅에서는 Node.js에서 JSON 파일을 불러오고, 이를 문자열로 변환하거나 다시 객체로 역변환하는 과정을 예제로 구현해 보자. 그리고 JSON 데이터를 파일로 저장하고 다시 불러오는 방법도 살펴보자.

**​**

2\. JSON 파일

Node.js에서는 별도의 외부 모듈 없이도 JSON 파일을 require()를 통해 직접 불러올 수 있다. 이렇게 불러온 JSON은 일반적인 JavaScript 객체 형태로 다룰 수 있으며, 특정 키에 접근하여 값을 출력하는 것도 가능하다.

​

아래는 예제로 사용될 JSON 파일입니다.

**hello-rainbow.json**

{ "red" : "빨강", "orange" : "주황", "yellow" : "노랑", "green" : "초록", "blue" : "파랑", "indigo" : "남색", "violet" : "보라" }

​

3\. JSON 파일 불러오기 및 키 값 접근

JSON 파일을 불러오는 것은 매우 간단하다. require() 함수를 사용하여 JSON 파일을 로드한 후, 객체처럼 키를 통해 원하는 값을 가져올 수 있다.

var json = require('./hello-rainbow.json'); console.log(json.red); // 출력: 빨강 console.log(json.orange); // 출력: 주황 

​

4\. JSON을 문자열로 변환 및 다시 객체로 변환

JSON 데이터를 문자열로 변환하고 싶을 때는 JSON.stringify() 함수를 사용한다. 반대로 문자열 데이터를 다시 객체로 만들고 싶을 때는 JSON.parse()를 사용한다. 

var text = JSON.stringify(json); // JSON → 문자열 console.log(text); var jsonObj = JSON.parse(text); // 문자열 → JSON 객체 console.log(jsonObj.green); // 출력: 초록 console.log(jsonObj.blue); // 출력: 파랑 

**실행 결과**

JSON.stringify() 함수는 JSON을 문자열로 변환한다. 

JSON.parse() 함수는 문자열을 JSON 개체로 변환한다.

{"red":"빨강","orange":"주황","yellow":"노랑","green":"초록","blue":"파랑","indigo":"남색","violet":"보라"} 초록 파랑 

​

5\. JSON 객체를 파일로 저장하고 다시 불러오기

JSON 데이터를 문자열로 저장한 후, 이를 파일로 기록하고 다시 읽어들이는 과정은 다음과 같다.

var jsonFile = require('./hello-rainbow.json'); var fs = require('fs'); // JSON 객체 → 문자열 변환 후 파일로 저장 var rainbowJson = JSON.stringify(jsonFile); fs.writeFileSync("hello-parsed.json", rainbowJson); // 저장한 파일 읽기 var data = fs.readFileSync("hello-parsed.json"); var json = data.toString(); console.log(json); // 문자열 출력 // 문자열 → JSON 객체로 역변환 var parsedJson = JSON.parse(json); console.log(parsedJson); // 객체 출력 

**실행 결과**

{"red":"빨강","orange":"주황","yellow":"노랑","green":"초록","blue":"파랑","indigo":"남색","violet":"보라"} { red: '빨강', orange: '주황', yellow: '노랑', green: '초록', blue: '파랑', indigo: '남색', violet: '보라' }
