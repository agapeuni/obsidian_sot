1\. 해시 함수 개요

해시 함수는 임의의 크기의 데이터를 고정된 크기의 값으로 매핑하는 함수다. 이렇게 변환된 값을 해시 값 또는 해시 코드라고 한다. 해시 함수는 주로 데이터의 식별이나 검색을 위해 사용되며, 데이터의 일관성과 무결성을 검증한다. 

​

해시 함수는 다양한 분야에서 활용된다. 암호학에서는 비밀번호의 저장과 검증에 사용되며, 데이터의 일관성을 검사하는 무결성 확인에도 활용된다. 해시 값으로 데이터가 변하지 않았다는 것을 보장할 수 있다. 또한, 데이터베이스에서 효율적인 검색을 위한 인덱스 구조로 해시 함수가 사용되기도 한다.

​

주요한 해시 함수로는 MD5, SHA-1, SHA-3, SHA-256 등이 있다. 보안 요구사항이 점점 더 강화되면서 보다 안전한 해시 함수가 필요해지고 있다. 최근에는 SHA-3과 Blake2와 같은 더 강력한 해시 함수들이 등장하여 사용되고 있다.

2\. 해시 함수 특징

1) 해시 함수는 입력값을 해시 값으로 변환하는데, 이 과정을 해싱이라 하고 일방향으로만 작동한다. 해시 값으로 원래 데이터를 복원하는 것은 거의 불가능하다.

​

2) 입력값의 크기와 상관없이 생성된 해시 값의 길이는 동일하다. 

​

3) 동일한 입력에 대해 항상 동일한 해시 값을 반환한다. 입력값이 조금만 변경되어도 해시 값은 완전히 다른 결과를 가져온다.

​

4) 해시 함수는 빠르게 계산되어 큰 데이터 집합에 대해 효율적으로 작동해야 한다.

​

5) 서로 다른 입력에 대해 충돌이 발생할 가능성이 적어야 한다. 서로 다른 입력에 대해 동일한 해시 값이 나오는 충돌 현상이 최소화되어야 한다.

​

​

3\. MD5(MD5 Message-Digest Algorithm)

MD5는 메시지 다이제스트 알고리즘의 일종으로, 1992년에 로널드 라이베스트(Ronald Rivest)에 의해 개발된 해시 함수다. MD5는 임의의 길이를 가진 데이터를 128비트의 고정된 해시 값으로 변환한다. MD5는 이제 주로 무결성 확인이나 간단한 데이터 검증 등의 비보안 관련 용도로 사용된다. 서로 다른 입력값으로부터 같은 해시 값이 만들어지는 취약점이 발견되면서 MD5를 사용하지 않고 있다.

​

아래의 예제 코드를 보면 hash1과 hash2의 입력값이 같다. 만들어지는 해시값도 동일하다. hash3에서는 입력값에서 하이픈(-)만 제거했는데 완전히 다른 해시값이 만들어진다. 그리고 만들어진 해시 값의 크기는 모두 16으로 동일하다.

import hashlib def hashMD5(str): enc = hashlib.md5() enc.update(str.encode('utf-8')) return enc.hexdigest() hash1 = hashMD5('MD5(MD5 Message-Digest Algorithm)는 메시지 다이제스트 알고리즘의 일종') hash2 = hashMD5('MD5(MD5 Message-Digest Algorithm)는 메시지 다이제스트 알고리즘의 일종') hash3 = hashMD5('MD5(MD5 Message Digest Algorithm)는 메시지 다이제스트 알고리즘의 일종') print('hash1 = {0} / length = {1}'.format(hash1, len(hash1))) print('hash2 = {0} / length = {1}'.format(hash2, len(hash2))) print('hash3 = {0} / length = {1}'.format(hash3, len(hash3)))

4\. SHA-1(Secure Hash Algorithm 1)

SHA-1은 미국 국립표준기술연구소(NIST)에서 개발한 해시 함수다. SHA-1은 메시지 무결성을 검증하기 위해 널리 사용되었으나, 현재는 보안적으로 취약한 알고리즘으로 간주되고 있다. SHA-1은 160비트(20바이트)의 고정된 해시 값을 생성한다.

​

SHA-1은 현재 업계에서 사용을 권장하지 않으며, 기존에 SHA-1을 사용하던 시스템은 더 강력한 해시 함수로 업그레이드하는 것이 좋다. 보안적으로 안전한 용도로 해시 함수를 사용해야 할 경우, SHA-256, SHA-3 등과 같은 더 강력한 해시 함수를 사용하는 것이 좋다. 

​

아래의 예제 코드를 보면 hash1과 hash2의 입력값이 같다. 만들어지는 해시값도 동일하다. 

hash3에서는 입력값에서 하이픈(-)만 제거했는데 완전히 다른 해시값이 만들어진다. 그리고 만들어진 해시 값의 크기는 모두 동일하다.

import hashlib def hashSHA1(str): enc = hashlib.sha1() enc.update(str.encode('utf-8')) return enc.hexdigest() hash1 = hashSHA1('SHA-1은 160비트(20바이트)의 고정된 해시 값을 생성') hash2 = hashSHA1('SHA-1은 160비트(20바이트)의 고정된 해시 값을 생성') hash3 = hashSHA1('SHA 1은 160비트(20바이트)의 고정된 해시 값을 생성') print('hash1 = {0} / length = {1}'.format(hash1, len(hash1))) print('hash2 = {0} / length = {1}'.format(hash2, len(hash2))) print('hash3 = {0} / length = {1}'.format(hash3, len(hash3)))

5\. SHA-2(Secure Hash Algorithm 2)

SHA-2는 SHA-1의 후속 알고리즘으로, 미국 국립표준기술연구소(NIST)에서 개발한 해시 함수다. SHA-2는 SHA-1보다 안전하고 보안성이 높은 해시 함수로 알려져 있다. SHA-2는 다양한 비트 수를 갖는 해시 값들을 생성할 수 있으며, 주로 사용되는 해시 값의 크기에는 SHA-224, SHA-256, SHA-384, SHA-512 등이 있다. 숫자는 각각 해시 값의 비트 수를 나타낸다.

​

SHA-2는 현재 보안 요구사항을 충족하는 대부분의 응용에서 널리 사용되고 있다. 그러나 계산 속도가 상대적으로 느릴 수 있으며, 더 강력한 보안 요구사항을 충족하기 위해 SHA-3과 같은 새로운 해시 함수도 등장하고 있다.

​

아래의 예제 코드에는 SHA-256과 SHA-512를 사용하였다. 만들어진 해시값의 길이는 SHA-256는 64이고 SHA-512는 128이다.

import hashlib def hashSHA256(str): enc = hashlib.sha256() enc.update(str.encode('utf-8')) return enc.hexdigest() def hashSHA512(str): enc = hashlib.sha512() enc.update(str.encode('utf-8')) return enc.hexdigest() hash1 = hashSHA256('SHA-2은 SHA-1의 후속 알고리즘') hash2 = hashSHA256('SHA-2은 SHA-1의 후속 알고리즘~') hash3 = hashSHA512('SHA-2은 SHA-1의 후속 알고리즘') hash4 = hashSHA512('SHA-2은 SHA-1의 후속 알고리즘~') print('hash1 = {0} / length = {1}'.format(hash1, len(hash1))) print('hash2 = {0} / length = {1}'.format(hash2, len(hash2))) print('hash3 = {0} / length = {1}'.format(hash3, len(hash3))) print('hash4 = {0} / length = {1}'.format(hash4, len(hash4)))

6\. SHA-3(Secure Hash Algorithm 3)

SHA-3는 NIST(National Institute of Standards and Technology)에서 2015년에 발표한 해시 함수로, SHA-2의 후속 알고리즘이다. SHA-3는 SHA-2와는 다른 구조와 알고리즘을 사용하여 보안성과 안정성을 제공한다. SHA-3은 다양한 해시 값 크기를 지원하며, 주로 사용되는 크기에는 SHA-224, SHA-256, SHA-384, SHA-512 등이 있다. 숫자는 각각 해시 값의 비트 수를 나타낸다.

​

SHA-3는 SHA-2와는 별개의 알고리즘을 사용하고 있기 때문에, SHA-2에 발견된 취약점은 SHA-3에는 영향을 미치지 않는다. 그러나 일부 응용에서는 SHA-2와의 하위 호환성을 유지하기 위해 SHA-3 대신 SHA-2를 계속 사용하는 경우도 있다. SHA-3는 현재 많은 보안 프로토콜 및 애플리케이션에서 권장되는 해시 함수로 인정받고 있으며, 보안 요구사항을 충족하는 무결성 검증 및 메시지 다이제스트 등 다양한 용도로 사용된다.

​

아래의 예제 코드에는 SHA-256과 SHA-512를 사용하였다. 만들어진 해시값의 길이는 SHA-256는 64이고 SHA-512는 128이다.

import hashlib def hashSHA256(str): enc = hashlib.sha3_256() enc.update(str.encode('utf-8')) return enc.hexdigest() def hashSHA512(str): enc = hashlib.sha3_512() enc.update(str.encode('utf-8')) return enc.hexdigest() hash1 = hashSHA256('SHA-3은 SHA-2의 후속 알고리즘') hash2 = hashSHA256('SHA-3은 SHA-2의 후속 알고리즘~') hash3 = hashSHA512('SHA-3은 SHA-2의 후속 알고리즘') hash4 = hashSHA512('SHA-3은 SHA-2의 후속 알고리즘~') print('hash1 = {0} / length = {1}'.format(hash1, len(hash1))) print('hash2 = {0} / length = {1}'.format(hash2, len(hash2))) print('hash3 = {0} / length = {1}'.format(hash3, len(hash3))) print('hash4 = {0} / length = {1}'.format(hash4, len(hash4)))
