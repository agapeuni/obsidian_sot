# 2023-08-04 223174380746 XML 외국 문자나 특수 문자가 있는 문서를 작성하는 방법

## 본문

​

XML은 다양한 문자를 표현할 수 있는 유연한 형식이다. 외국 문자나 특수 문자를 XML 문서에 포함시키기 위해서는 몇 가지 사항을 고려해야 한다. 

​

**1\. 문자 인코딩(Encoding)**

XML은 텍스트 데이터를 저장하기 때문에 문자 인코딩을 지정한다. 대부분의 경우 UTF-8 인코딩을 사용하는 것이 권장된다. UTF-8은 전 세계 대부분의 문자를 지원하며, XML 문서에서 특수 문자와 외국 문자를 표현하는 데 적합하다.

​

XML 선언 부분에 다음과 같이 인코딩을 지정한다.

﻿<?xml version="1.0" encoding="UTF-8"?>

​

**2\. 외국 문자**

UTF-8 인코딩하거나 다른 인코딩으로 지정할 수 있다. 

UTF-8 인코딩을 사용하면 대부분의 외국 문자를 지원할 수 있다. 

<?xml version="1.0" encoding="iso-8859-1"?>

​

XML 문서에 외국 문자가 포함될 수 있다.

<test> foreign characters (挾奬) </test>

**3\. 특수 문자**

XML은 몇 가지 특수 문자를 특별하게 처리해야 한다. 

XML에는 특수 문자가 예약되어 있으며 기술하는 방법이 있다.

<foo>This & that</foo>

위의 XML은 다음 오류를 발생시킨다. 

Whitespace is not allowed at this location.

Line 0000001: <foo>This & that</foo>

Pos 0000012: ----------^

앰퍼샌드(&)는 XML 데이터 소스에 놓이는 경우 앰퍼샌드로 해석되지 않아서 특수문자로 대체해야 한다.

< \- '&lt;'로 대체

> \-  '&gt;'로 대체

& \- '&amp;'로 대체

" \- '&quot;'로 대체

' \- '&apos;'로 대체

​

**4\. 따옴표**

따옴표는 태그 내에서 속성 값에 대한 구분 기호로 사용되며 따라서 속성 값 내에서는 항상 사용할 수 없다.

예를 들어 다음은 오류를 반환한다. 따옴표가 속성 구분 기호로 그리고 속성값 자체에서 모두 사용되었다.

<foo description='John's Stuff'>

이를 해결하려면 다음과 같이 특성 구분 기호에 대한 작은따옴표를 사용하거나 

<foo description="John's Stuff">

또는 큰따옴표를 엔티티 &apos;로 확장할 수 있다.

<foo description='John&apos; Stuff'>

바로 위의 두 경우는 XML 개체 모델(Object Model)의 getAttribute 메서드를 통해 속성 값 John's Stuff를 반환한다. 

​

**5\. CDATA**

텍스트를 CDATA 부분 내에 넣음으로써 요소 내용에 있는 특수 문자를 처리할 수 있다. 

<xml>

<![CDATA[ This & that <stuff> is just "text" content. ]]>

</xml>

XML 개체 모델은 CDATA 노드를 다음 문자열을 nodeValue로 반환하는 xml 노드의 자식으로 나타낸다.

This & that <stuff> is just "text" content.
