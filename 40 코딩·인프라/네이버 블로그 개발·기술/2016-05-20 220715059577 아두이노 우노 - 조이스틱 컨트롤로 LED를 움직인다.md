# 2016-05-20 220715059577 아두이노 우노 - 조이스틱 컨트롤로 LED를 움직인다

![](https://postfiles.pstatic.net/MjAyNTA5MjFfNCAg/MDAxNzU4NDMxMjg3OTI0._3zDuXHueMUpvG-OLV91MJ3TXkq2MLMjpunfdBLeuc8g.Z43hWmtUoW2uiIm7Zgrrg5pNXg8Tqyx77R7bXIYyl9Ig.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(11\).png?type=w80_blur)

​

조이스틱의 X, Y 값을 입력받아서 LED의 불빛이 움직이는 효과를 구현해 보겠습니다.

​

준비물은 아래와 같습니다.

  * **아두이노 우노(Arduino UNO)**

  * 브레드보드

  * 조이스틱

  * LED 9개

  * 220옴 저항 9개

  * MM 점퍼선 9개

  * MF 점퍼선 4개

![](https://postfiles.pstatic.net/20160520_275/agapeuni_14637421066233rQcC_JPEG/20160520_010153.jpg?type=w80_blur)

​

먼저 LED 9개를 적절한 간격으로 브레드보드에 꼽아둡니다. 이때 같은 라인에 꼽으면 합선이 되니 주의를 바랍니다. 

![](https://postfiles.pstatic.net/20160520_140/agapeuni_1463742106328VULeV_JPEG/20160520_010021.jpg?type=w80_blur)

​

9개 LED의 캐소드와 GND를 220옴 저항으로 연결합니다. 이때 저항도 서로의 다리가 닿지 않도록 주의를 바랍니다.

![](https://postfiles.pstatic.net/20160520_11/agapeuni_1463742106092m1RLJ_JPEG/20160520_005931.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/20160520_250/agapeuni_1463742105877Rkflt_JPEG/20160520_005926.jpg?type=w80_blur)

​

아두이노 우노의 2번에서 10번 핀까지 LED와 연결할 점퍼선 9개를 연결합니다.

![](https://postfiles.pstatic.net/20160520_151/agapeuni_1463742105042qX5SA_JPEG/20160520_005729.jpg?type=w80_blur)

​

점퍼선을 맨 윗줄부터 차례로 LED의 애노드와 연결합니다.

![](https://postfiles.pstatic.net/20160520_36/agapeuni_1463742105650AKSy7_JPEG/20160520_005841.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/20160520_71/agapeuni_14637421054497yhWb_JPEG/20160520_005821.jpg?type=w80_blur)

​

아래는 모두 연결한 모습입니다. 다행히 각각의 위치에 맞게 잘 연결되었습니다. ㅎㅎ

![](https://postfiles.pstatic.net/20160520_163/agapeuni_1463742105257qrs54_JPEG/20160520_005759.jpg?type=w80_blur)

​

조이스틱에 MF 점퍼선을 아래와 같이 GND는 검은색, 5V 전원에는 빨간색, VRx(X)에는 초록색, VRy(Y)에는 파란색 점퍼선을 연결합니다.

![](https://postfiles.pstatic.net/20160520_210/agapeuni_1463742104621odtN5_JPEG/20160520_005641.jpg?type=w80_blur)

​

검은색은 GND에 빨간색은 Vcc에 초록색은 A0핀에 파란색은 A1핀에 연결합니다.

![](https://postfiles.pstatic.net/20160520_41/agapeuni_146374210482638cWd_JPEG/20160520_005711.jpg?type=w80_blur)

​

이번 실험에 완성된 모습입니다. 

![](https://postfiles.pstatic.net/20160520_149/agapeuni_1463742104353mXNJo_JPEG/20160520_005543.jpg?type=w80_blur)

​

**▣ 소스코드 : led_joystick_nine.ino**

아래의 코드에선 X 값과 Y 값을 읽어 적절한 값으로 변환하고서 그에 따라 LED 위치를 어떻게 하였는지를 보시면 됩니다.

int posX = 1; int posY = 1; int pins[3][3] = { { 2, 5, 8 }, { 3, 6, 9 }, { 4, 7, 10 } }; void setup() { for (int i = 0; i < 3; i++) { for (int j = 0; j < 3; j++) { pinMode(pins[i][j], OUTPUT); } } } void loop() { digitalWrite(pins[posX][posY], LOW); int x = map(analogRead(0), 0, 1023, 0, 10); int y = map(analogRead(1), 0, 1023, 0, 10); if (x < 1 && posX > 0) { \--posX; } else if (9 < x && posX < 2) { ++posX; } if (y < 1 && posY > 0) { \--posY; } else if (9 < y && posY < 2) { ++posY; } digitalWrite(pins[posX][posY], HIGH); delay(100); }

​

조이스틱을 움직이는 방향에 따라 LED도 상하좌우로 움직이는 동영상입니다.
