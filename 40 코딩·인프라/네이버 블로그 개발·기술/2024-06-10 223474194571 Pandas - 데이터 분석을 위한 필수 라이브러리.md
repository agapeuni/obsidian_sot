판다스 개요

판다스(Pandas)는 데이터 분석과 조작을 위한 강력한 라이브러리이다. 판다스는 구조화된 데이터를 다루기 위한 다양한 기능을 제공하며, 데이터 프레임(DataFrame)과 시리즈(Series)라는 두 가지 주요 데이터 구조를 사용한다. 판다스를 사용하면 다양한 방식으로 데이터를 쉽게 다룰 수 있다. 판다스는 데이터 분석과 관련된 많은 기능을 제공하므로, 데이터 과학, 금융, 연구 등 여러 분야에서 널리 사용된다.

​

​

판다스 데이터 구조

판다스는 Series와 DataFrame 구조를 지원한다.

​

1) 시리즈(Series)

판다스의 시리즈(Series)는 일차원 배열의 형태를 가진 데이터 구조로, 동일한 데이터 타입을 가지며, 각 데이터에는 고유한 인덱스가 붙어 있다. 시리즈는 데이터 프레임의 한 열을 구성하는 기본 요소이다. 시리즈는 인덱스를 통해 데이터에 접근할 수 있으며, 넘파이(NumPy) 배열과 유사한 기능을 제공한다.

​

2) 데이터 프레임(DataFrame)

판다스의 데이터프레임(DataFrame)은 2차원 표 형식의 데이터 구조로, 행과 열로 구성되어 있습니다. 데이터프레임은 다양한 데이터 타입을 포함할 수 있으며, SQL의 테이블이나 엑셀의 시트와 유사한 개념이다. 데이터프레임은 데이터 분석과 조작을 위한 다양한 기능을 제공한다.

​

​

판다스 기능

1\. 데이터 읽기 및 쓰기 : CSV, Excel, SQL 등 다양한 형식의 파일을 읽고 쓸 수 있다.

2\. 데이터 정리 : 결측치 처리, 중복 데이터 제거, 데이터 필터링, 정렬 등.

3\. 데이터 조작 : 데이터 병합, 집계, 변환 등.

4\. 데이터 분석 : 기술 통계, 그룹화, 피벗 테이블 등.

​
