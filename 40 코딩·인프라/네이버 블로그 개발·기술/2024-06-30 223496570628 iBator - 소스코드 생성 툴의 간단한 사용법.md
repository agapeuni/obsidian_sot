**iBator 란**

iBator란 아파치 재단에서 개발한 데이터 매핑 프레임워크인 iBatis를 위한 소스 생성 도구이다. 이 툴은 데이터베이스 테이블에 대한 기본적인 CRUD(Create, Read, Update, Delete) 작업을 수행할 수 있는 소스를 자동으로 생성하는 데 도움을 준다. iBator는 주로 다음과 같은 소스 파일을 생성한다:

​

  * SqlMap XML Files: SQL 쿼리를 매핑하는 XML 파일로, iBatis와 데이터베이스 간의 상호작용을 정의한다.

  * Java Classes: 데이터베이스 테이블의 기본 키 및 필드와 일치하는 Java 클래스를 생성한다.

  * DAO Classes: 데이터베이스 접근 객체(Data Access Object) 클래스를 생성하여 데이터베이스와의 상호작용을 간소화한다.

​

이 외에도 iBator는 Eclipse 플러그인으로 설치할 수 있으며, 이를 통해 사용자는 효율적으로 개발 환경을 설정하고 소스를 생성할 수 있다. iBator를 활용하면 반복적인 작업을 줄이고, 코드의 일관성을 유지하는 데 유용하다. 이와 같은 특성 덕분에 많은 개발자들이 iBatis와 함께 iBator를 사용하여 프로젝트의 생산성을 높이고 있다.

​

​

**Eclipse plugin 설치**

  1. Take the "Help > install new software..." Menu Option

  2. Press the "Add" button

  3. Enter the following information: Location: <http://ibatis.apache.org/tools/ibator>

  4. Press OK

  5. Check the box next to "Apache iBATIS Ibator Feature"

  6. Press the "Install" button

  7. Follow the remainder of the install wizard
