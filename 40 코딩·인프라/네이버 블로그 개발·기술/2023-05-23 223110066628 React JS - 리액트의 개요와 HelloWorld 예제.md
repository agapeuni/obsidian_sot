**1\. 개요**

신규로 진행하는 프로젝트들을 가만히 살펴보면 리엑트 프로젝트가 간간히 보인다. 리엑트(React)는 사용자 인터페이스를 구축하기 위한 JavaScript 라이브러리다. Facebook에서 개발하였으며, 단일 페이지 애플리케이션(SPA) 개발에 주로 사용된다. React는 컴포넌트 기반 아키텍처를 기반으로 하며, 재사용 가능하고 유지 보수가 쉬운 UI 구성 요소를 만들 수 있게 해준다.

​

웹 애플리케이션 개발할 때 일반적으로 페이지 단위로 개발하였다. 하지만 최근에는 SPA(Single Page App) 모델을 기반으로 컴포넌트 방식으로 개발을 한다. 다른 페이지로 이동하는 멀티 페이지 방식이 아니라 하나의 페이지에서 동적인 콘텐츠로 기능을 구현한다. React는 커뮤니티와 생태계가 매우 활발하며, 다양한 개발 도구와 라이브러리가 제공됩니다. React 개발자들은 공식 문서, 온라인 자습서, 커뮤니티 포럼 등을 통해 지원을 받을 수 있다.

​

**2\. 특징**

React의 핵심 개념은 가상 DOM(Virtual DOM)이다. React는 가상 DOM을 사용하여 브라우저의 실제 DOM과 상호 작용하며 효율적인 UI 업데이트를 관리한다. 가상 DOM은 메모리에 존재하며, React는 상태 변화에 따라 가상 DOM을 조작하고 변경 사항을 실제 DOM에 일괄 적용한다. React는 필요한 최소한의 DOM 조작만 수행하여 성능을 최적화한다.

​

React는 UI와 데이터의 바인딩 기능을 지원하고 상태 관리를 관리한다. 화면 컴포넌트들을 독립적인 모듈로 구현할 수 있고 JSX를 사용하여 쉽게 정의할 수 있다. JSX는 JavaScript와 XML을 결합한 문법을 사용하여 HTML과 유사해 별다른 어려움 없이 쉽게 접근할 수 있다. 이를 통해 컴포넌트의 렌더링 로직과 UI 구조를 하나의 파일에서 관리할 수 있다.

​

React는 단방향 데이터 흐름을 지향한다. 부모 컴포넌트에서 자식 컴포넌트로 데이터를 전달할 수 있지만, 자식 컴포넌트에서 직접 부모 컴포넌트의 상태를 변경할 수는 없다. 데이터의 변경은 항상 상위 컴포넌트에서 이루어져야 하며, 변경된 데이터는 props를 통해 하위 컴포넌트로 전달된다.

​

React는 확장성이 뛰어나며 다른 라이브러리나 프레임워크와 쉽게 통합될 수 있다. React Router를 사용하면 React 애플리케이션 내에서 라우팅을 관리할 수 있고, Redux를 사용하여 상태 관리를 할 수 있다. 또한, React Native를 사용하면 React를 기반으로 웹이 아닌 네이티브 애플리케이션을 개발할 수도 있다. 

​

**3\. 예제**

다음은 React로 구현한 Hello, world 예제이다. container에 return에 정의된 내용을 표시한다.

​

파일 : hello_world.html

<!DOCTYPE html> <html> <head> <script src="https://unpkg.com/react@18/umd/react.development.js" crossorigin></script> <script src="https://unpkg.com/react-dom@18/umd/react-dom.development.js" crossorigin></script> <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script> </head> <body> <div id="container"></div> <script type="text/babel"> function Hello() { return <h1>Hello World!</h1>; } const container = document.getElementById('container'); const root = ReactDOM.createRoot(container); root.render(<Hello />) </script> </body> </html>
