1\. 그레이들 프로젝트 생성 (init)

gradle를 다운로드하여 "D:\app\gradle-8.1"에 압축을 풀었다. 

그리고 환경 변수에 추가하고 PATH를 설정하면 명령창에서 그레이들을 실행할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA0MTVfODYg/MDAxNjgxNTM4ODUzNTQ3.nap3NiN-XlAaZ8lDWW7st2_Spo4ZG-6EBzi0UEfZr1Ig.bU2u6bmPAzS7XEWY5-v1Rk0T2UXL7PrHPfH-t89fOhcg.PNG.agapeuni/image.png?type=w80_blur)

​

다음의 명령을 실행하여 그레이들 프로젝트를 생성한다.

build script DSL은 Groovy를 선택했고 test framework는 JUnit 4를 선택했다. 그리고 나머지 입력값은 기본값을 선택했다.

> gradle init --type java-library

![](https://postfiles.pstatic.net/MjAyMzA0MTVfMTQ1/MDAxNjgxNTM5MDUzODcx.T4J22XUP0NKrUsvXi0poS-3bcgchHA6-o0KjXmWz4RQg.pnZwgUDUtw1bhVGICqRlWCCJCdR6wdrESNPICFKalGAg.PNG.agapeuni/image.png?type=w80_blur)

​

2\. 그레이들 프로젝트 구성

다음과 같이 build.gradle 파일과 settings.gradle 파일이 만들어졌다.

build.gradle 파일은 빌드 내용이 있고 settings.gradle 파일은 빌드 설정 정보가 담겨있다.

D:\work\gradle\> │ │ .gitattributes │ .gitignore │ gradlew │ gradlew.bat │ settings.gradle │ ├─.gradle │ file-system.probe │ ├─gradle │ └─wrapper │ gradle-wrapper.jar │ gradle-wrapper.properties │ └─lib │ build.gradle │ └─src ├─main │ ├─java │ │ └─gradle │ │ └─pilot │ │ Library.java │ │ │ └─resources └─test ├─java │ └─gradle │ └─pilot │ LibraryTest.java │ └─resources

​

​**파일 :****build.gradle**

/* * This file was generated by the Gradle 'init' task. * * This generated file contains a sample Java library project to get you started. * For more details take a look at the 'Building Java & JVM projects' chapter in the Gradle * User Manual available at https://docs.gradle.org/8.1/userguide/building_java_projects.html */ plugins { // Apply the java-library plugin for API and implementation separation. id 'java-library' } repositories { // Use Maven Central for resolving dependencies. mavenCentral() } dependencies { // Use JUnit test framework. testImplementation 'junit:junit:4.13.2' // This dependency is exported to consumers, that is to say found on their compile classpath. api 'org.apache.commons:commons-math3:3.6.1' // This dependency is used internally, and not exposed to consumers on their own compile classpath. implementation 'com.google.guava:guava:31.1-jre' } // Apply a specific Java toolchain to ease working on different environments. java { toolchain { languageVersion = JavaLanguageVersion.of(17) } } 

​

**파일 : settings.gradle**

/* * This file was generated by the Gradle 'init' task. * * The settings file is used to specify which projects to include in your build. * * Detailed information about configuring a multi-project build in Gradle can be found * in the user manual at https://docs.gradle.org/8.1/userguide/multi_project_builds.html */ plugins { // Apply the foojay-resolver plugin to allow automatic download of JDKs id 'org.gradle.toolchains.foojay-resolver-convention' version '0.4.0' } rootProject.name = 'gradle-pilot' include('lib') 

​

**파일 :****Library.java**

/* * This Java source file was generated by the Gradle 'init' task. */ package gradle.pilot; public class Library { public boolean someLibraryMethod() { return true; } } 

​

**파일 :****LibraryTest.java**

/* * This Java source file was generated by the Gradle 'init' task. */ package gradle.pilot; import org.junit.Test; import static org.junit.Assert.*; public class LibraryTest { @Test public void someLibraryMethodReturnsTrue() { Library classUnderTest = new Library(); assertTrue("someLibraryMethod should return 'true'", classUnderTest.someLibraryMethod()); } }

​3\. 그레이들 컴파일(compileJava)

다음의 명령어로 그레이들 프로젝트를 컴파일한다.

> gradle compileJava

5\. 그레이들 실행 (run)

build.gradle 파일에 다음과 같이 plugin을 추가한다.

...(생략)... plugins { // Apply the java-library plugin for API and implementation separation. id 'java-library' id 'application' } application { mainClass = 'gradle.pilot.Library' } ...(생략)...

테스트를 위해 Library 클래스에 main 메소드를 만들었다.

파일 : Library.java

/* * This Java source file was generated by the Gradle 'init' task. */ package gradle.pilot; /** * */ public class Library { public static void main(String[] args) { System.out.println("Hello, Gradle"); } /** * @return true */ public boolean someLibraryMethod() { return true; } } 

다음의 명령어로 그레이들 프로젝트를 실행한다.

> gradle run​

6\. 그레이들 클린 (clean)

다음의 명령어로 그레이들 프로젝트에서 생성한 파일을 모두 지운다.

build 폴더 아래의 결과물이 모두 지워진다.

> gradle clean

7\. 이클립스 임포트 (eclipse)

그레이들 프로젝트를 이클립스에서 이용할 수 있게 해보자.

build.gradle 파일에 다음과 같이 plugin을 추가한다.

...(생략)... plugins { // Apply the java-library plugin for API and implementation separation. id 'java-library' id 'eclipse' } ...(생략)...

다음의 명령어를 실행한다.

> gradle eclipse

![](https://postfiles.pstatic.net/MjAyMzA0MTVfMjIz/MDAxNjgxNTQ0MjMyNjMy.vivRquX2Ln7wJApRaPm0ysPwzecBlFSpRXmbS0nHGjkg.SSEeWsCnzJjEUQBEsSgh-a4Lswm8J8vbZySUfKVfKtEg.PNG.agapeuni/image.png?type=w80_blur)
