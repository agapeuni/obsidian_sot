# 2023-10-01 223225799935 optgroup 태그 - select 태그 선택 목록을 그룹화하기

- 게시일: 2023. 10. 1. 20:55

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTNfMjQ3/MDAxNzQ0NDcyNzcwNTU2.uuG8mOUOc_0j36cZ_ETZNCsnYYA9z_DuWBDfgbLdEWkg.qHaZhDEWJ3T1ZkxmheKjpN9qQczLEG1vGD0Ixm43RJgg.PNG/HTML-001_\(3\).png?type=w80_blur)

​

HTML의 <select> 태그 내에서 <optgroup> 태그를 사용하면 선택 목록을 그룹화하여 사용자에게 더 구조적이고 이해하기 쉽게 표시할 수 있다. <optgroup> 요소를 사용하여 관련된 옵션들을 하위 그룹으로 묶을 수 있다. <select> 태그 안에 <optgroup> 태그를 사용하여 여러 옵션 그룹을 만들 수 있다. 이를 통해 사용자에게 관련된 옵션들을 그룹화하여 선택할 수 있는 편리한 UI를 제공할 수 있다. 

​

두 개의 <optgroup> 요소를 사용하여 "Swedish Cars"과 "German Cars"로 두 그룹을 만들었습니다. 각 <optgroup> 요소 내에는 해당 그룹에 속하는 옵션들을 나열한다. 이렇게 하면 사용자가 선택 목록을 사용할 때 관련 옵션이 그룹화되어 표시되므로 목록이 더 구조적이고 사용자 친화적으로 보인다.

​

파일 : optgroup.html

<html> <head> <meta http-equiv="Content-Type" content="text/html; charset=euc-kr" /> <title>optgroup</title> </head> <body> <b>&lt;optgroup&gt; Tag</b> <br/> <select> <optgroup label="Swedish Cars"> <option value="volvo">Volvo</option> <option value="saab">Saab</option> </optgroup> <optgroup label="German Cars"> <option value="mercedes">Mercedes</option> <option value="audi">Audi</option> </optgroup> </select> </body> </html>
