1\. CSV 파일

CSV(Comma Separated Values) 파일은 쉼표(,)로 구분하여 엑셀과 같은 행렬의 데이터를 텍스트 파일로 저장할 수 있는 파일이다. 파이썬은 csv 모듈을 사용하여 CSV 파일을 읽고 쓰는 기능을 손쉽게 코딩할 수 있다. 사람이 읽을 수 있는 형식으로 많은 양의 표 데이터를 저장하는 데 적합하며 CSV 파일의 첫 번째 줄을 선택적 헤더로 사용할 수 있다. CSV는 거의 모든 프로그래밍 언어에 사용할 수 있는 라이브러리를 지원한다.

​

​

2\. CSV 파일 쓰기

csv.writer() 함수를 사용하여 파일을 저장.

코드 : file_csv_write.py

import csv items1 = [ ['2020-09-08', '서울경기', '23.1', '20.7', '26.1'], ['2020-09-09', '서울경기', '20.5', '18.3', '24.7'], ['2020-09-10', '서울경기', '22.2', '18.2', '26.5'], ['2020-09-11', '서울경기', '22.1', '19.1', '26.6'], ['2020-09-12', '서울경기', '19.9', '17.8', '22.3'] ] with open('data/example1.csv', 'w', encoding='utf-8', newline='') as f1: csv_writer1 = csv.writer(f1) for item in items1: csv_writer1.writerow(item) items2 = [ ['1', '한국', 'Korea'], ['2', '중국', 'China'], ['3', '미국', 'America'], ['4', '독일', 'Germany'], ['5', '일본', 'Japan'] ] with open('data/example2.csv', 'w', encoding='utf-8', newline='') as f2: csv_writer2 = csv.writer(f2) for item in items2: csv_writer2.writerow(item)

**3) 최저기온과 최고기온 확인**

그럼 해당 데이터를 입력하여 파이썬으로 지금까지 서울 경기 지점에서의 최저기온과 최고기온을 확인해 보겠습니다.

​

소스코드 : file_csv_read_temp.py

import csv all_min_temp = 100 all_min_date = '' all_max_temp = -100 all_max_date = '' # CSV 파일열기 with open("data/temperature.csv", encoding='utf-8') as input: csv_reader = csv.reader(input) # 메타정보, 헤더 for i in range(8): next(csv_reader) min_temp = 0 max_temp = 0 for row in csv_reader: min_temp = float(row[3]) max_temp = float(row[4]) # 최저기온 처리 if(all_min_temp > min_temp): all_min_temp = min_temp all_min_date = row[0] # 최고기온 처리 if(all_max_temp < max_temp): all_max_temp = max_temp all_max_date = row[0] print(all_min_date, "역대 최저기온 =", all_min_temp) print(all_max_date, "역대 최고기온 =", all_max_temp)
