**1\. 부트스트랩 개요**

부트스트랩(Bootstrap)은 웹 개발을 위한 오픈 소스 프런트엔드 프레임워크이다. Twitter에서 개발되었으며, 초기 버전은 2011년에 출시되었다. 부트스트랩은 HTML, CSS 및 JavaScript를 사용하여 웹 페이지나 웹 애플리케이션을 디자인하고 개발할 때 일관된 디자인 및 레이아웃을 손쉽게 만들 수 있다. 부트스트랩을 이용하여 깔끔하고 단정한 페이지를 손쉽게 만들어보자. 

​

**2\. 부트스트랩 특징**

1) 반응형 디자인

부트스트랩은 모바일 장치에서도 웹 페이지가 잘 보이도록 반응형 디자인을 지원한다. 그 결과, 다양한 화면 크기와 디바이스에 대해 일관된 사용자 경험을 제공할 수 있다.

​

2) 그리드 시스템

부트스트랩은 강력한 그리드 시스템을 제공하여 페이지 레이아웃을 구성한다. 이를 통해 콘텐츠를 유연하게 배치하고 조정할 수 있다.

​

3) UI 컴포넌트

부트스트랩은 버튼, 폼 요소, 탐색 메뉴, 카드, 모달 등 다양한 UI 컴포넌트를 미리 디자인하여 제공한다. 이러한 컴포넌트를 사용하여 웹 페이지를 구축할 때 디자인 시간을 절약하고 일관성을 유지할 수 있다.

​

4) 테마 및 스타일링

부트스트랩은 기본적인 디자인 요소와 스타일을 포함하며, CSS 클래스를 사용하여 간단하게 스타일을 적용하거나 커스터마이징할 수 있다. 또한 다양한 테마와 스타일 설정을 제공하여 웹 사이트의 룩앤필을 빠르게 변경할 수 있다.

​

5) JavaScript 플러그인

부트스트랩은 모달, 드롭 다운, 슬라이더 등 다양한 상호작용 요소를 구현하기 위한 JavaScript 플러그인도 제공한다. 이를 통해 사용자와의 상호작용을 개선할 수 있다.

​

6) 커스터마이징

부트스트랩은 SASS(Syntactically Awesome Style Sheets)를 기반으로 하여 스타일을 커스터마이징할 수 있는 기능을 제공한다. 개발자는 필요한 경우 기본 스타일을 수정하거나 추가적인 스타일을 작성하여 고유한 디자인을 만들 수 있다.

​

**4\. CSS, JS 추가 (CDN 방식)**

모바일에서도 반응형으로 동작하도록 <meta> 태그로 viewport를 정의한다. 

<link> 태그를 추가하여 bootstrap.min.css 를 참조한다.

<!doctype html> <html lang="en"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Bootstrap</title> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.1/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-4bw+/aepP/YC94hEpVNVgiZdgIC5+VKNBQNGCHeKRQN+PtmoHDEXuppvnDJzQIu9" crossorigin="anonymous"> </head> <body> <h1>Hello, world!</h1> </body> </html>

</body> 태그 전에 부트스트랩을 사용하기 위해 <script> 태그로 bootstrap.bundle.min.js 를 추가한다.

이렇게 하여 부트스트랩(Bootstrap)으로 페이지 만들기 위한 기본 준비를 마쳤다.

<!doctype html> <html lang="en"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Bootstrap demo</title> <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.1/dist/css/bootstrap.min.css" rel="stylesheet" integrity="sha384-4bw+/aepP/YC94hEpVNVgiZdgIC5+VKNBQNGCHeKRQN+PtmoHDEXuppvnDJzQIu9" crossorigin="anonymous"> </head> <body> <h1>Hello, world!</h1> <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.1/dist/js/bootstrap.bundle.min.js" integrity="sha384-HwwvtgBNo3bZJJLYd8oVXjrBZt8cqVSpeBNS5n7C8IVInixGAoxmnlMuBnhbgrkm" crossorigin="anonymous"></script> </body> </html>
