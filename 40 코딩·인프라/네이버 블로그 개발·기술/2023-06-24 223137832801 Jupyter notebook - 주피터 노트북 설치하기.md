1\. 주피터 노트북 개요

주피터 노트북(Jupyter Notebook)은 데이터 분석, 과학 연구, 프로토타이핑 등을 위한 인터랙티브한 개발 환경이다. 주피터 노트북은 데이터 분석에 주로 사용되고 최근에는 머신러닝과 딥러닝에도 많이 활용되고 있다. Python에서 많이 사용하는데 다양한 프로그래밍 언어를 지원한다. 

​

주피터 노트북은 웹 브라우저에서 실행되며, 코드, 텍스트, 그래프 등을 포함한 문서를 작성하고 실행할 수 있다. 주피터 노트북으로 작성하면 소스코드뿐만 아니라 시각화를 위한 그래프 및 마크다운 언어로 설명도 추가할 수 있어 편리하다. 

​

2\. 주피터 노트북 설치

주피터 노트북을 설치하기 위해서는 다음 단계를 따른다.

​

**1) 파이썬 설치**

주피터 노트북을 설치하기 위해서는 먼저 Python을 설치해야 한다. Python 공식 웹사이트에서 최신 버전의 Python을 다운로드하고 설치한다. 설치 시 "Add Python to PATH" 옵션을 선택하여 PATH 환경 변수에 Python을 등록한다.

​

**2) 주피터 노트북 설치**

Python이 설치되었다면, 주피터 노트북을 설치하기 위해 터미널 또는 명령 프롬프트를 열고 다음 명령을 실행한다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMjE1/MDAxNjg3NjEwMTQ1ODMz.bd6CPcaVtStJ1as0LfTJK_qKfiF_q19J32J6yWCdMswg.qI_86kpWtfCwnGRvedzYPDclGApycALPYkxJHn1ib7cg.PNG.agapeuni/image.png?type=w80_blur)

​

다음의 명령으로 pip를 사용하여 주피터 노트북을 설치한다. pip는 Python 패키지 관리자로, Python 패키지 설치를 위해 사용된다.

> pip install jupyter

​

4\. 주피터 노트북 사용법

주피터 노트북(Jupyter Notebook)은 대화형 코드와 문서를 하나의 환경에서 작성하고 실행할 수 있는 툴이다. 주피터 노트북을 사용하는 기본적인 방법과 기능에 대해 알아보자.

​

1) 노트북 생성

주피터 노트북을 실행한 후, 대시보드에서 "New" 버튼을 클릭하고 "Python 3 (ipykernel)"을 선택하여 새 노트북을 생성한다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMTEy/MDAxNjg3NjExOTE2MDY0.BGBMLe_V9U6_4S7y3At913sWiHKRx6LtfHzss80_zPkg.FJrgtGZQu7Te3CJTOrIb5g0BGnzUEqZS4wOmGgRFZL4g.PNG.agapeuni/image.png?type=w80_blur)

​

2) 셀(Cell) 사용

주피터 노트북은 셀 단위로 코드와 텍스트를 작성한다. 셀은 코드 실행이 가능한 단위다.

\- 코드 셀: 코드를 입력하고 실행할 수 있는 셀이다. 코드를 입력한 후, Shift + Enter를 누르면 코드가 실행되고 결과가 출력된다.

\- 마크다운 셀: 텍스트, 문서, 이미지 등을 작성할 수 있는 셀이다. 문서를 작성할 때 Markdown 문법을 사용하여 텍스트 서식을 지정할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMTMw/MDAxNjg3NjEyOTEwNzgz.s3fr_15b8i42B_SVw1tQ6k9_XtunT4yyBYt7UJQXGzsg.ErwohhZVwJXzo0TsX01PveSnYLYcS092Ht_vwAYxI50g.PNG.agapeuni/image.png?type=w80_blur)

​

3) 코드 실행 

코드 셀에 코드를 작성하고 Shift + Enter를 누르면 코드가 실행된다. 코드의 실행 결과나 출력 값은 해당 셀 아래에 표시된다.

​

4) 셀 실행 순서

노트북은 셀을 순서대로 실행하며, 실행 순서는 숫자로 표시된다. 실행 순서는 셀이 실행된 순서대로 변경될 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMTcy/MDAxNjg3NjEyOTcyODE1.IqIdLTfF7oHtasF-i5sB4-XN93dXUyKppMqHqGZ8HE0g.6xfApr6mE9IyuF6SeFr9q2QbEzuUEoLblBBLwN4R30Eg.PNG.agapeuni/image.png?type=w80_blur)

​

5) 셀 편집

셀 내에서 코드 또는 텍스트를 편집하려면 더블 클릭하여 편집 모드로 진입한다. 편집이 완료되면 Shift + Enter를 눌러 실행한다.

​

6) 저장과 내보내기

주피터 노트북은 자동으로 변경 내용을 저장하며, "File" 메뉴에서 "Save and Checkpoint"를 통해 수동으로 저장할 수 있다. 또한, "File" 메뉴에서 노트북을 다른 형식으로 내보내거나, HTML, PDF, Markdown, Python 스크립트 등으로 변환할 수 있다.
