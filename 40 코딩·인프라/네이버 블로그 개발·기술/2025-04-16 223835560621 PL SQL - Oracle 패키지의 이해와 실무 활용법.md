# 2025-04-16 223835560621 PL SQL - Oracle 패키지의 이해와 실무 활용법

- 게시일: 2025. 4. 16. 17:00

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfNTcg/MDAxNzQ0Nzc3NjgzNjIx.VZZ7v0vVkRE3aA1j1j9DpwHiLdMsQXAj1Ex5qVMPNXMg.Fhu5MwCcK6FFfa6YyU6_HfCjrCLXx71gg5rnzqK6c6kg.PNG/PL_SQL-001_\(6\).png?type=w80_blur)

​

데이터베이스 시스템을 Oracle로 구축한 현업 환경에서는 다양한 PL/SQL 패키지를 활용하는 사례를 자주 접하게 된다. 처음 접하는 이에게는 '패키지'라는 개념이 다소 생소하게 느껴질 수 있으나, 실제 업무 환경에서는 매우 강력하고 유용한 도구로 활용된다.

**​**

**​**

**1\. 패키지를 사용하는 이유**

Oracle의 PL/SQL 패키지는 여러 가지 이유로 실무에서 널리 사용된다.

  * **코드 재사용성 향상** : 반복되는 로직을 매번 작성할 필요 없이, 정의된 패키지를 호출함으로써 효율적인 개발이 가능하다.

  * **코드 관리 용이** : 관련된 함수와 프로시저들을 하나의 단위로 묶어 관리할 수 있으므로 유지보수가 용이하다.

  * **성능 개선** : 패키지는 최초 호출 시 전체 코드가 메모리에 로드되므로, 이후 호출 시 빠른 응답 속도를 기대할 수 있다.

  * **보안 및 권한 관리** : 사용자별로 패키지 단위의 권한을 부여함으로써 데이터 접근 제어와 보안 수준을 강화할 수 있다.

**​**

**​**

**2\. 실무 예시 – 사용자 ID 조회**

Oracle 패키지가 어떻게 사용되는지를 인사관리 시스템의 예를 통해 살펴보자.

**​**

**예시 시나리오**

회사 DB에는 모든 임직원의 인사 정보가 저장되어 있다. 인사부는 이를 기반으로 다양한 작업을 수행하며, 인사 프로그램을 통해 ‘사용자 ID 조회’ 기능을 제공한다. 사용자가 ‘강용운’이라는 이름을 입력하면, 해당 이름에 대응하는 사용자 ID가 화면에 출력되는 방식이다.

**​**

**흐름 설명**

**1\. 프로그램에서 패키지 호출**

인사 프로그램은 입력된 이름 정보를 바탕으로, Oracle DB 내 q_account 패키지에 정의된 get_userid 프로시저를 호출한다. 동일 패키지에 여러 프로시저가 존재할 수 있으므로 정확한 프로시저명을 지정해야 한다.

**​**

**2\. DB에서 사용자 정보 조회**

get_userid 프로시저는 전달받은 이름(예: ‘강용운’)을 기반으로 해당 사용자의 ID를 조회하는 SQL 문을 실행한 뒤, 그 결과를 리턴한다.

**​**

**3\. 프로그램 화면에 결과 출력**

인사 프로그램은 반환된 사용자 ID를 받아 화면에 출력함으로써, 사용자는 직관적으로 원하는 정보를 확인할 수 있다.

**​**

**​**

**3\. Oracle 패키지 작성법**

**① 패키지 선언부**

패키지 선언부는 인터페이스 역할을 하며, 외부에서 접근 가능한 변수나 프로시저, 함수의 목록을 정의한다.

CREATE PACKAGE emp_package IS PROCEDURE get_emp_info(p_emp_id IN NUMBER); END emp_package; / 

​

**② 패키지 몸체**

패키지의 몸체는 선언부에서 정의한 요소들의 실제 구현 내용을 담고 있다.

CREATE PACKAGE BODY emp_package IS PROCEDURE get_emp_info(p_emp_id IN NUMBER) IS v_name VARCHAR2(100); v_salary NUMBER; BEGIN SELECT emp_name, emp_salary INTO v_name, v_salary FROM employees WHERE emp_id = p_emp_id; DBMS_OUTPUT.PUT_LINE('사원 이름: ' || v_name); DBMS_OUTPUT.PUT_LINE('사원 연봉: ' || v_salary); END get_emp_info; END emp_package; / 

​

**③ 패키지 호출 예시**

BEGIN emp_package.get_emp_info(101); END; / 

​

이와 같이 Oracle 패키지는 데이터베이스 애플리케이션의 성능과 유지보수성을 크게 향상시키는 도구이다. 특히, 시스템의 모듈화를 통해 명확한 구조를 유지하면서도 확장성과 보안을 동시에 확보할 수 있다는 점에서, 현업 개발자들에게 없어서는 안 될 기능이라 할 수 있다.
