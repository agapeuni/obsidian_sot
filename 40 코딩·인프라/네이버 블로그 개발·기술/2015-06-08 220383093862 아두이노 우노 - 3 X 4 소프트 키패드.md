# 2015-06-08 220383093862 아두이노 우노 - 3 X 4 소프트 키패드

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTkx/MDAxNzU4NDMwNzY5ODYz.bM5-GlvhafDakzV1rt9JLD1bdtfjWGAiQud468u5fL4g.l-N8G-ZC8izne7jhUrttB4CU4R1XliruW-StGvRU3tUg.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(6\).png?type=w80_blur)

​

**아두이노 우노**(Arduino UNO) 와 3 X 4 소프트 키패드를 사용하여 빛과 소리를 내는 실험을 해보겠습니다.

키패스를 적용하고 1번키, 2번키부터 순서대로 도레미파솔...를 구현하고서 키에 따라 색상에 대한 빛을 표하려고합니다.

​

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다.

**아두이노 우노**(Arduino UNO)와 브레드보드

  * 3 X 4 소프트 키패드 1개 

  * MM 점퍼선 11개

  * 피에조 부저 1개

  * 1K 옴 저항 1개

  * 3Color LED 1개

![](https://postfiles.pstatic.net/20160506_205/agapeuni_1462519945532YaLIV_JPEG/20150607_235203.jpg?type=w80_blur)

​

​

**아두이노 우노**(Arduino UNO)의 2번부터 12번핀까지 점퍼선을 연결합니다.

2번핀부터 8번핀은 키패드에 연결하고 9번핀은 피에조 부저에 연결합니다.

10, 11, 12번핀은 RGB 3Color LED에 10번은 레드, 11번은 그린, 12번은 블루와 연결합니다. (점퍼선 색상도 RGB)

![](https://postfiles.pstatic.net/20160506_106/agapeuni_1462519944438cPvD9_JPEG/20150607_235022.jpg?type=w80_blur)

​

**아두이노 우노**(Arduino UNO)의 2번부터 9번핀까지 MM점퍼선의 순서대로 숫자키패드와 연결합니다.

![](https://postfiles.pstatic.net/20160506_250/agapeuni_1462519947379MGYgK_PNG/arduino-and-keypad_bb-1024x512.png?type=w80_blur)

![](https://postfiles.pstatic.net/20160506_141/agapeuni_1462519946879NwnRi_PNG/arduin-and-keypad_schem-1024x575.png?type=w80_blur)

​

**아두이노 우노**(Arduino UNO)의 8번핀 -- 숫자키패드 1번핀 (회색)

**아두이노 우노**(Arduino UNO)의 7번핀 -- 숫자키패드 2번핀 (보라)

**아두이노 우노**(Arduino UNO)의 6번핀 -- 숫자키패드 3번핀 (파랑)

**아두이노 우노**(Arduino UNO)의 5번핀 -- 숫자키패드 4번핀 (초록)

**아두이노 우노**(Arduino UNO)의 4번핀 -- 숫자키패드 5번핀 (노랑)

**아두이노 우노**(Arduino UNO)의 3번핀 -- 숫자키패드 6번핀 (주황)

**아두이노 우노**(Arduino UNO)의 2번핀 -- 숫자키패드 7번핀 (빨강)에 연결합니다.

![](https://postfiles.pstatic.net/20160506_138/agapeuni_1462519944864YGbTv_JPEG/20150607_235041.jpg?type=w966)

그리고 브래드 보드에 3Color Led를 연결하고 LED 2번째 핀에 Vcc 전원을 연결합니다. 

**주의: 2번 핀에 GND 접지를 연결하는 타입도 있습니다.**

​

![](https://postfiles.pstatic.net/20160506_150/agapeuni_1462519943480H84yY_JPEG/20150607_235001.jpg?type=w966)

​

1번에 레드(우노 10번), 3번에 초록(우노 11번), 4번에 블루(우노 10번) 점퍼선과 함께 270옴 저항으로 연결합니다.

아두이노 신호에 따라 여러가지 색상을 표시할 준비가 되었습니다.

![](https://postfiles.pstatic.net/20160506_238/agapeuni_1462519943163etsER_JPEG/20150607_234951.jpg?type=w80_blur)

​

​

​

2번핀에 Vcc 전원이 입력고 나면 1, 3, 4번 핀에 따라 색상이 달라집니다.

1번 핀이 Low이면 Red

3번 핀이 Low이면 Green

4번 핀이 Low이면 Blue

​

1, 3번 핀이 Low이면 빨초 => Yellow, 

3, 4번 핀이 Low이면 초파 => Cyan, 

1, 4번 핀이 Low이면 빨파 => Magenta, 

1, 3, 4번 핀이 Low이면 빨초파 => White 가 표시됩니다.

​

![](https://postfiles.pstatic.net/20150608_300/agapeuni_1433690183638b2G2B_JPEG/%BA%FB%C0%C7-3%BF%F8%BB%F6.jpg?type=w80_blur)

브래드보드에 피에조 부저를 꼽아둡니다. 극성이 있어서 적색이 (+)이고 흑색이 (-) 입니다.

**아두이노 우노**(Arduino UNO)의 9번핀 하얀색 점퍼선을 피에조 부저의 적색(+)에 연결합니다.

그리고 피에조 부저의 흑색(-)에 1K옴 저항으로 GND 접지를 연결합니다.

아두이노의 신호에 따라 소리를 낼 준비가 되었습니다. 

![](https://postfiles.pstatic.net/20160506_300/agapeuni_14625199438075PbpT_JPEG/20150607_235009.jpg?type=w80_blur)

이번 실험에 사용한 키패드에 해당하는 값은 행이 8, 7, 6, 5 열이 4, 3, 2 입니다.

이번에는 피에조 부저에 소리를 내기 위한 코드를 프로그램 해보겠습니다.

​

아래는 음계에 대한 주파수 입니다. 

도(C), 레(D), 미(E), 파(F), 솔(G), 라(A), 시(B), 도(C)

​

![](https://postfiles.pstatic.net/20140901_93/agapeuni_14095633676843jSqG_PNG/20140831_223400.png?type=w2)

​

​

키를 누를때 소리를 내기 위해서 음계에 대한 값을 tones 배열에 정의를 해둡니다.

키패드에 값에 대해 음을 출력하도록 해당주파수를 매개변수로 해서 piezoTone 함수를 호출합니다.

​

키패드 "1" ~ "7"의 값에는 3Color LED를 제어하기 위한 코드를 추가하였습니다.

키패드 "1"은 Red

키패드 "2"은 Green

키패드 "3"은 Blue

키패드 "4"은 Yellow

키패드 "5"은 Cyan

키패드 "6"은 Magenta

키패드 "7"은 White

​

​

**▣ 소스코드 : keypad_soft_2_piezo_led3.ino**

#include <Keypad.h> const byte ROWS = 4; const byte COLS = 3; char keys[ROWS][COLS] = { { '1', '2', '3' }, { '4', '5', '6' }, { '7', '8', '9' }, { '*', '0', '#' } }; byte rowPins[ROWS] = { 8, 7, 6, 5 }; byte colPins[COLS] = { 4, 3, 2 }; Keypad keypad = Keypad(makeKeymap(keys), rowPins, colPins, ROWS, COLS); int piezo = 9; int tones[] = { 262, 294, 330, 349, 392, 440, 494, 523, 587, 659, 698, 784 }; int ledRed = 10; int ledGreen = 11; int ledBlue = 12; void setup() { pinMode(piezo, OUTPUT); pinMode(ledRed, OUTPUT); pinMode(ledGreen, OUTPUT); pinMode(ledBlue, OUTPUT); } void piezoTone(int t) { tone(piezo, t); delay(200); noTone(piezo); } void loop() { digitalWrite(ledRed, HIGH); digitalWrite(ledGreen, HIGH); digitalWrite(ledBlue, HIGH); char key = keypad.getKey(); if (key == ' ') { ; } else if (key == '1') { digitalWrite(ledRed, LOW); digitalWrite(ledGreen, HIGH); digitalWrite(ledBlue, HIGH); piezoTone(tones[0]); } else if (key == '2') { digitalWrite(ledRed, HIGH); digitalWrite(ledGreen, LOW); digitalWrite(ledBlue, HIGH); piezoTone(tones[1]); } else if (key == '3') { digitalWrite(ledRed, HIGH); digitalWrite(ledGreen, HIGH); digitalWrite(ledBlue, LOW); piezoTone(tones[2]); } else if (key == '4') { digitalWrite(ledRed, LOW); digitalWrite(ledGreen, LOW); digitalWrite(ledBlue, HIGH); piezoTone(tones[3]); } else if (key == '5') { digitalWrite(ledRed, HIGH); digitalWrite(ledGreen, LOW); digitalWrite(ledBlue, LOW); piezoTone(tones[4]); } else if (key == '6') { digitalWrite(ledRed, LOW); digitalWrite(ledGreen, HIGH); digitalWrite(ledBlue, LOW); piezoTone(tones[5]); } else if (key == '7') { digitalWrite(ledRed, LOW); digitalWrite(ledGreen, LOW); digitalWrite(ledBlue, LOW); piezoTone(tones[6]); } else if (key == '8') { piezoTone(tones[7]); } else if (key == '9') { piezoTone(tones[8]); } else if (key == '*') { piezoTone(tones[9]); } else if (key == '0') { piezoTone(tones[10]); } else if (key == '#') { piezoTone(tones[11]); } delay(100); }
