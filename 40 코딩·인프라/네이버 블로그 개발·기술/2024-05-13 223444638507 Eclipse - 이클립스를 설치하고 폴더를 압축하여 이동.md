# 2024-05-13 223444638507 Eclipse - 이클립스를 설치하고 폴더를 압축하여 이동

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTlfMjgz/MDAxNzQ1MDE3OTcyMDg2.LfU25zu48W14dlPdSPSycXNNU6chpXJXuMjJZZ8hItwg.T_mjLFl5x93-SVcXagw3Ufj6aXOtq63b6XfymXtmcckg.PNG/%EA%B0%9C%EB%B0%9C%ED%99%98%EA%B2%BD-001_\(22\).png?type=w80_blur)

1\. 개요

이클립스와 필요한 플러그인을 설치하고 폴더채 압축해서 다른 곳으로 이동하려고 한다. 예전에는 이클립스 폴더만 압축해서 옮겨도 문제없이 실행이 되었는데 개인폴더 아래에 있는 .eclipse 폴더와 .p2 폴더안의 파일이 없어 실행이 되지 않는다. 그래서 깨끗하게 설치하고 관련 파일을 모두 압축하여 이동할 계획이다.

​

아래의 URL에서 이클립스 설치 파일을 다운로드 한다.

URL : <https://www.eclipse.org/downloads/>

파일 : eclipse-inst-jre-win64.exe

![](https://postfiles.pstatic.net/MjAyNDA1MTJfMTE1/MDAxNzE1NDUwOTEyODEy.NmDiy98bxUYhr8wLc5NV3gC1Qv0AL5jQ_FnLWN-1KjEg.o9mlwaQnPxW85QlWzp3GQShUlkZ3OaNMK34_pmp3MnEg.PNG/image.png?type=w80_blur)

​

​

2\. eclipse 설치

내려받은 "eclipse-inst-jre-win64.exe"을 실행한다.

![](https://postfiles.pstatic.net/MjAyNDA1MTJfMjI5/MDAxNzE1NTIwNjY4MjQw.eNpQOMyBT6foTWrN-aehBkvGjrNXf6TSfztoi9bDdXkg.YRquotfOc7FQGuwVlTQyCBVBDVNuZcHEz2EtW8YpT6Ug.PNG/image.png?type=w80_blur)

​

"Eclipse IDE for Enterprise Java and Web Developers"를 선택하고, Installation Foler는 "D:\dev"를 선택하고 인스톨한다.

![](https://postfiles.pstatic.net/MjAyNDA1MTJfMjEg/MDAxNzE1NTIwNzE2NDY5.wSxfHB-sZzTNYiquf_yeYFjJcu3xoNOf2Lln2402ifYg.a3EWVItaOnwCCpKQBDJpgncvoCRWtcSMNRRwH7m4U9Mg.PNG/image.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyNDA1MTJfMzcg/MDAxNzE1NTIwODQxNzA4.Hv8XOKnFg1kPD1DV59Oua3FMmcpEz9Kh9LxMValGH5kg.ehPCVG0QcegVd0YuHrQMXI1abbeVsfq-o0bFmHKjMzgg.PNG/image.png?type=w80_blur)

​

설치 완료하고 실행하면 workspace를 선택하는 창이 표시된다. 이클립스가 설치된 폴더 아래의 workspace로 지정했다.

경로 : D:\dev\eclipse\workspace

4\. AmaterasUML 확인

AmateraUML이 잘 설치된 것 같은데 New Class Diagram으로 새로운 파일을 생성하려고 하는데 Finish 버튼이 클리되지 않는다.

![](https://postfiles.pstatic.net/MjAyNDA1MTJfMTkz/MDAxNzE1NTIyMTk5NjE5.BWjijEmY2wTnds9FxCpWpxEH-Pnw--BkpsXr2xAPUKEg.KBClHNN46pcgT1f9cCvrp0KsllgL7R96TWgD_zWFn3Qg.PNG/image.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyNDA1MTJfNzYg/MDAxNzE1NTIyMjcyOTYy.3Ey0oUjz6xtDFW2O0AwPhK2aKVCUiwzTBjMT5zaPjjUg.BgGLPNKLnIb0jIv-Xq2XdosavE43rDevpaEG_N6f4f4g.PNG/image.png?type=w80_blur)

​

탐색기에서 uml 폴더를 만들고 test.cld 파일을 강제로 만들고 이클립스를 열었다. 그리고 화면을 Dark 모드에서 Classic으로 변경했다. 예전에는 드래그 앤 드롭 기능을 지원한 것으로 기억하는데 클래스 하나 하나 지1정해줘야 등록된다. 무엇보다 이클립스 상위버전을 지원하지 못하는지 작업하는데 매끄럽지가 못하다. UML 작업을 하는데 문제가 없기를 바란다.

![](https://postfiles.pstatic.net/MjAyNDA1MTJfMjkz/MDAxNzE1NTIzMDM3MTA1.URcKUFWqoB4X3P3AQEc3Z3IbrgfcwWAxMwi52Jh_wDgg.ad6rRA1ieNqV-BwJbRCP_USClJK52loKCpM3uA3RCkgg.PNG/image.png?type=w80_blur)

​
