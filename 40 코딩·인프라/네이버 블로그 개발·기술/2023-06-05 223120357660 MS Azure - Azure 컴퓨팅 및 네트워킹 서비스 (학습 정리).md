Azure Virtual Machines

Azure VM을 사용하여 클라우드에서 VM을 만들고 사용할 수 있으며 IaaS를 가상화된 서버 형식으로 제공한다. 

실제 하드웨어를 구입 및 유지 관리하지 않아도 되지만 VM에서 실행되는 소프트웨어를 구성, 업데이트 및 유지 관리해야 한다.

​

Azure Virtual Machines에 대한 가용성 옵션

​

Azure에서 VM 스케일링

VM을 그룹화하여 고가용성, 확장성 및 중복성을 제공할 수 있다. 

VM 그룹화도 관리할 수 있다.

Azure는 가상 머신 확장 집합을 사용하여 대부분의 작업을 자동화한다.

확장 집합을 이용하면 몇 분 만에 수많은 VM을 관리, 구성, 업데이트할 수 있다. 

가상 머신 가용성 집합은 고가용성인 환경을 빌드하는 데 도움이 되는 도구이다.

​

VM을 사용하여 클라우드로 이동

VM은 물리적 서버에서 클라우드로 이동할 때도 좋다. 

물리적 서버의 이미지를 만들고 가상 머신 내에서 호스트 할 수 있다. 

​

Azure Virtual Desktop

Azure Virtual Desktop은 클라우드에서 실행되는 데스크톱 가상화 서비스다. 

Azure Virtual Desktop은 디바이스 및 운영 체제 간에 작동한다. 

​

<https://learn.microsoft.com/ko-kr/azure/virtual-desktop/>

[ ![](https://dthumb-phinf.pstatic.net/?src=%22https%3A%2F%2Flearn.microsoft.com%2Fen-us%2Fmedia%2Flogos%2Flogo-ms-social.png%22&type=ff120) ](https://learn.microsoft.com/ko-kr/azure/virtual-desktop/) [ **Azure Virtual Desktop 설명서** Azure Virtual Desktop은 가상 데스크톱 및 원격 앱을 안전하게 제공하고 사용자에게 유일한 다중 세션 Windows 11 및 Windows 10 환경을 제공합니다. learn.microsoft.com ](https://learn.microsoft.com/ko-kr/azure/virtual-desktop/)

​

보안 강화

Azure Virtual Desktop은 Azure AD를 사용하는 사용자의 데스크톱에 대한 중앙 집중식 보안 관리를 제공한다.

다단계 인증을 사용하여 사용자 로그인을 보호할 수 있다. 

세부적인 RBAC(역할 기반 액세스 제어)를 사용자에게 할당하여 데이터 액세스를 보호할 수도 있다.

​

Azure Virtual Desktop을 사용하면 데이터와 앱이 로컬 하드웨어에서 분리된다.

실제 데스크톱 및 앱이 클라우드에서 실행되므로 개인 디바이스에 기밀 데이터가 남을 위험이 줄어든다.

또한 사용자 세션은 단일 및 다중 세션 환경 모두에서 격리된다.

​

다중 세션 Windows 10 또는 Windows 11 배포

Azure Virtual Desktop은 광범위한 애플리케이션 지원을 통해 보다 일관된 환경을 제공한다.

Azure Virtual Desktop을 사용하면 단일 VM에서 여러 명의 사용자를 지원하는 다중 세션을 사용할 수 있다. 

​

Azure 컨테이너

가상 머신은 단일 운영 체제로 제한된다.

가상 머신은 물리적 하드웨어에 필요한 투자 비용을 줄이는 좋은 방법이다.

가상 머신은 하드웨어를 추상화하고 컨테이너는 운영체제를 추상화한다.

​

컨테이너란?

컨테이너는 가상화 환경으로 물리적 호스트에서 여러 가상 머신을 실행하는 것과 매우 유사하다.

컨테이너는 경량이며, 동적으로 생성, 스케일링 아웃, 중지할 수 있도록 설계되었다. 

Azure에서 지원하는 Docker가 가장 많이 사용되는 컨테이너 엔진 중 하나이다.

​

Azure Container Instances

Azure Container Instances는 PaaS(Platform as a Service) 제품이다.

Azure Container Instances는 Azure에서 컨테이너를 실행하는 가장 빠르고 간단한 방법을 제공한다.

​

Azure Functions

Azure Functions는 이벤트 기반의 서버리스 컴퓨팅 옵션이다. 

Azure Functions는 로 가상 머신이나 컨테이너 유지가 필요 없다. 

​

Azure Functions의 이점

Azure Functions는 서비스를 실행하는 코드에 대해서만 관심이 있는 경우에 이상적이다. 

수요에 따라 자동으로 스케일링되므로 수요가 가변적일 때 좋은 선택이 될 수 있다.

Azure Functions를 사용하면 코드를 실행하고 함수가 완료될 때 자동으로 리소스 할당을 해제한다.

​

Azure 애플리케이션 호스팅 옵션

VM과 컨테이너는 모두 훌륭한 호스팅 솔루션을 제공한다.

VM을 사용하면 호스팅 환경을 최대한 제어할 수 있다. 

​

Azure App Service

Azure App Service를 사용하면 원하는 프로그래밍 언어로 호스트 할 수 있다. 

Azure App Service를 사용하여 사용자는 앱을 빌드하고 유지 관리하는 데 집중한다.

Azure App Service는 웹 애플리케이션, REST API 및 모바일 백 엔드를 호스트 하는 HTTP 기반 서비스다. 

​

앱 서비스 유형

Azure App Service는 웹에 액세스가 가능한 앱을 호스팅 할 때 다루는 대부분의 인프라 결정을 처리한다.

Azure App Service를 사용하면 웹앱, API 앱, WebJobs, 모바일 앱과 같은 앱 서비스를 호스팅 할 수 있다.

​

Azure Virtual Network

Azure Virtual Network는 Azure 클라우드 환경에서 가상 네트워크를 구축하고 관리하기 위한 서비스다. 

Azure Virtual Network로 온 프레미스 네트워크와 연결되거나 인터넷과 연결하여 하이브리드 환경을 구축할 수 있다.

​

Azure 가상 네트워킹은 퍼블릭 엔드 포인트와 프라이빗 엔드 포인트를 모두 지원한다.

  * 퍼블릭 엔드 포인트 : 공용 IP 주소를 사용.

  * 프라이빗 엔드 포인트 : 가상 네트워크의 주소 공간 내에서 개인 IP 주소를 사용.

​

격리 및 구분

Azure Virtual Network를 사용하면 격리된 가상 네트워크를 만들 수 있다. 

IP 범위는 가상 네트워크 내에만 존재하며 인터넷 라우팅이 불가능하다.

​

인터넷 통신

공용 IP 주소를 Azure 리소스에 할당하거나 리소스를 공용 부하 분산 장치 뒤에 배치하여 

인터넷에서 들어오는 연결이 가능하도록 설정할 수 있다.

​

Azure 리소스 간 통신

가상 네트워크는 VM뿐만 아니라 다른 Azure 리소스도 연결할 수 있다.

서비스 엔드 포인트를 다른 Azure 리소스 형식에 연결할 수 있다. 

​

온-프레미스 리소스와 통신

로컬 환경과 클라우드 환경 모두에 걸쳐 있는 네트워크를 만들 수 있다.

Azure 가상 네트워크를 사용하면 온-프레미스 환경 및 Azure 리소스를 함께 연결할 수 있다. 

​

클라이언트 컴퓨터는 암호화된 VPN 연결을 시작하여 Azure 가상 네트워크에 연결한다.

온-프레미스 VPN 디바이스 또는 게이트웨이를 가상 네트워크의 Azure VPN 게이트웨이에 연결한다.

​

네트워크 트래픽 라우팅

Azure에서는 연결된 가상 네트워크의 서브넷, 온-프레미스 네트워크 간에 트래픽을 라우팅한다.

​

네트워크 트래픽 필터링

Azure 가상 네트워크를 사용하면 서브넷 간 트래픽을 필터링할 수 있다.

​

가상 네트워크 연결

가상 네트워크 피어링을 사용하여 가상 네트워크를 함께 연결할 수 있다. 

피어링을 사용하면 두 가상 네트워크끼리 서로 직접 연결할 수 있다. 

피어링을 사용하면 각 가상 네트워크의 리소스가 서로 통신할 수 있다. 

​

Azure VPN(가상 사설망)

Azure VPN은 다른 네트워크 내에서 암호화된 터널을 사용한다. 

Azure VPN을 사용하면 네트워크에서 중요한 정보를 안전하게 유지하며 공유할 수 있다.

​

VPN 게이트웨이

Azure VPN Gateway는 가상 네트워크와 온 프레미스 네트워크 간에 안전한 연결을 제공하는 서비스다. 

Azure VPN Gateway는 VPN 연결을 설정하여 데이터를 암호화하고 인증하여 안전한 통신을 보장한다.

​

전송되는 모든 데이터는 인터넷을 통과할 때 프라이빗 터널 내부에서 암호화된다.

VPN Gateway를 배포할 때 VPN 유형을 정책 기반 또는 경로 기반으로 지정한다.

​

Azure ExpressRoute

Azure ExpressRoute를 사용하면 프라이빗 연결을 통해 온-프레미스 네트워크를 클라우드로 확장할 수 있다. 

Azure ExpressRoute는 온 프레미스 네트워크와 Azure 클라우드 간에 전용, 안전하고 고성능의 연결을 제공하는 서비스다. 

​

ExpressRoute 연결 모델

ExpressRoute는 온-프레미스 네트워크를 클라우드에 연결하는 데 다음과 같은 모델을 지원한다.

  * 클라우드 교환의 공동 배치

  * 지점 간 이더넷 연결

  * 임의 네트워크

  * ExpressRoute 사이트에서 직접

​

보안 고려 사항

ExpressRoute를 사용하면 데이터가 퍼블릭 인터넷을 통해 이동하지 않으므로 인터넷 통신과 관련된 잠재적인 위험에 노출되지 않는다.

​

Azure DNS

Azure DNS는 Microsoft Azure 인프라를 사용하여 이름 분석을 하는 DNS 도메인용 호스팅 서비스다. Azure에 도메인을 호스트 하면 다른 Azure 서비스와 동일한 자격 증명, API, 도구 및 대금 청구를 사용하여 DNS 레코드를 관리할 수 있다.
