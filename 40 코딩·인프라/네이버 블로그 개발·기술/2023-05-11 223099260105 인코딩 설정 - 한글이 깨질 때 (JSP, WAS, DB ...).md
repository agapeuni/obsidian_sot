1\. 기본 용어

1) Character Set

영문 표현 그대로 문자 집합이라는 의미. 컴퓨터에서 문자를 표현하기 위해 각 문자를 정숫값에 대응시켜 놓은 체계를 말한다. Character Set을 제대로 지정해 주지 않으면 원래 의도된 내용이 아니 깨진 문자들이 나타난다. 

2) Encoding 

CharSet이 문자에 대해 정숫값을 지정한 것이라면, encoding은 문자를 표현하는 정숫값을 어떤 bit 배열로 표현할 것인지를 의미한다. 즉, encoding은 CharSet에서 더 나아가 컴퓨터 퓨터 상에서 어떻게 표현되는 가까지 정해진 상태의 문자의 집합이다.

​

CharSet이 같다면 그 CharSet을 지원하는 어떤 encoding을 사용하든지 각 문자에 대응하는 논리적인 정숫값은 동일하다고 할 수 있지만 실제로 기록되는 bit 배열은 encoding에 따라 달라질 수 있다. 이 경우, 제대로 데이터를 주고받으려면 CharSet뿐만 아니라 encoding도 맞춰야 한다.

2\. HTML 인코딩

1) 소스파일을 UTF-8로 저장 (3byte)

표준화를 고려하여 UFT-8로 저장하는 것이 좋다.

​

2) 메타태그 언어 설정 바꾸기

charset=utf-8를 통하여 브라우저는 파일에서 문자를 표시하는 방법을 결정

﻿<meta charset="utf-8"> <meta http-equiv="Content-Type" content="text/html; charset=utf-8">

​

3\. JSP 인코딩

1) JSP 내에서의 PageEncoding

\- JSP 페이지 자체의 캐릭터 인코딩을 설정 

2) JSP 내에서의 ContentType

\- JSP 페이지가 생성하는 응답 인코딩

※ JSP 2.0부터는 pageEncoding 설정으로 응답 페이지(ContentType)까지 pageEncoding의 설정값으로 대체. 

​

4\. Request / Response 인코딩

1) request.setCharacterEncoding()

\- 요청 파라미터의 캐릭터 인코딩을 설정

※ request.setCharacterEncoding()과 ContentType의 비교

<%@ page contentType="text/html;charset=euc-kr"%>

서버 ==> 웹 브라우저 형태의 한글 출력을 원활하게 해주는 역할

​

<% request.setCharacterEncoding("euc-kr")%>

웹 브라우저 ==> 서버 형태의 한글 출력을 원활하게 해주는 역할 

2) response.setCharacterEncoding()

\- 전송받는 파라미터의 캐릭터 인코딩을 설정

​

5\. Filter 인코딩

\- 사용 목적 :

매번 페이지에 request를 이용해서 캐릭터 인코딩을 하게 되면 페 이지가 늘어날수록 번거롭게 된다. 또한 인코딩이 변경될 시에는 모 든 페이지의 인코딩을 바꿔주어야 한다. 이를 좀 더 편하게 하기 위해 web.xml 파일에 filter를 써서 설정을 하여 페이지에 접근할 때 인코딩을 처리하게 해주는 것이다.

​

\- 사용 방법 :

프레임워크를 사용하는 환경이라면 프레임워크에서 지원하는 filter 클래스를 사용하면 되고, 그렇지 않으면 내장 WAS에서 제공하는 Filter를 사용하면 된다.

ex) Tomcat의 Filter path

클래스 패스=%CATALINA_HOME%\webapps\jsp-examples\WEB-INF\classes\filters

filter 클래스를 상속하여 편리한 데로 사용

​

web.xml 추가

<filter> <filter-name>Set Character Encoding</filter-name> <filter-class>filters.SetCharacterEncodingFilter</filter-class> <init-param> <param-name>encoding</param-name> <param-value>EUC_KR</param-value> </init-param> </filter> <filter-mapping> <filter-name>Set Character Encoding</filter-name> <url-pattern>/*</url-pattern> </filter-mapping>

ex) Spring의 Filter path

클래스 패스=org.springframework.web.filter

.characterEncodingFilter

​

web.xml 추가

<filter> <filter-name>Set Character Encoding</filter-name> <filter-class> org.springframework.web.filter.characterEncodingFilter </filter-class> <init-param> <param-name>encoding</param-name> <param-value>EUC-KR</param-value> </init-param> </filter> <filter-mapping> <filter-name>Set Character Encoding</filter-name> <url-pattern>/*</url-pattern> </filter-mapping>

6\. Database 인코딩

데이터베이스 입력 시 및 덤프 파일을 사용할 경우 인코딩 문제가 발생할 수 있다.

1) DB 생성 시 UTF8 옵션 추가

ex) create database test DEFAULT CHARACTER SET UTF8 collate utf8_general_ci

2) Table 생성 시 UTF8옵션 추가

ex) create table test(

내용 삽입

) default character set utf8 collate utf8_general_ci

3) INPUT/OUTPUT 실행 시 CONNECT 후 다음 쿼리 설정

ex) set names utf8;

​

​

7\. WAS 인코딩

1) WebLogic 한글 인코딩 (8.1 기준)

\- 웹로직의 weblogic.xml 파일에 jsp-param value를 UTF-8로 변경

ex)

<jsp-param>

<param-name>encoding</param-name>

<param-value>utf-8</param-value>

</jsp-param>

\- web.xml 파일

ex)

<context-param>

<param-name>weblogic.httpd.inputCharset./*</param-name>

<param-value>UTF-8</param-value>

</context-param>

-jsp 페이지 설정

ex) <%@ page contentType = "text/html;character=UTF-8"%>

\- sp 8.0 이상에서의 한글 깨짐 현상

weblogic.properties에 weblogic의 자동 인코딩을 막으면 된다.

weblogic.properties 파일에 다음을 문장을 추가

weblogic.httpd.inputCharset./*=iso-8859-1

weblogic.httpd.charsets.iso-8859-1=8859_1

2) WebSphere 한글 파라미터

-default.client.encoding=utf-8, client.encoding.override=utf-8 추가

3) ZEUS 한글 데이터 입력 깨짐

-webmain.xml에 다음의 코드를 추가​

<encoding>

<request-encoding>

<default>euc-kr</default>

<forced>euc-kr</forced>

</request-encoding>

<response-encoding>

<default>euc-kr</default>

</response-encoding>

<postdata-encoding>

<default>euc-kr</default>

</postdata-encoding>

</encoding>

​

8\. Web Server 인코딩

1) 아파치 인코딩

\- 아파치의 기본 인코딩은 AddDefaultCharset

\- 인코딩을 AddDefaultCharset UTF-8로 변환

\- 여러 가지 인코딩을 사용할 경우에는 AddDefaultCharset off로 하고 브라우저에서 설정한 charset을 인식하도록 한다. 

​

9\. 리눅스 인코딩

1) 현제의 인코딩 설정 확인

-[root@localhost etc]$ echo $LANG

ko_kr.UTF-8

2) 인코딩 설정 해제

-[root@localhost sysconfig]# unset LANG

-[root@localhost sysconfig]# LANG=C

3) 사용 가능한 인코딩 설정 확인

-[root@localhost etc]$ locale -a | grep ko 

4) /etc/sysconfig/i18n 파일 수정

-[root@localhost sysconfig]# vi i18n

#LANG="ko_KR.UTF-8" 

5) .bash_profile을 통해 인코딩을 기본 설정

-. bash_profile에 export LANG=ko_KR.EUC-KR 추가
