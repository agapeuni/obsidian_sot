아래의 그림은 서툴지만 Fritzing으로 한번 그려보았습니다. 자주 그리다 보면 차차 나아지리라 생각됩니다.

아래와 같이 스케치를 작성하여 **아두이노 우노**(Arduino UNO)에 업로드합니다.

아래의 코드 중에서 참으로 유용한 map 함수가 있습니다. 입력된 값의 범위를 재설정 하여 줍니다.

​

map(입력값, 입력 최솟값, 입력 최댓값, 설정 최솟값, 설정 최댓값)

map(val, 0, 1023, 0, 3) 은 val 값이 0 ~ 1023 범위에서 0~3으로 재설정하게 됩니다.

​

int redPin = 2; int yellowPin = 3; int greenPin = 4; int analogPin = A0; void setup() { pinMode(redPin, OUTPUT); pinMode(yellowPin, OUTPUT); pinMode(greenPin, OUTPUT); } void loop() { int val = analogRead(analogPin); int mapVal = map(val, 0, 1023, 0, 3); switch (mapVal) { case 0: setLights(LOW, LOW, HIGH); break; case 1: setLights(LOW, HIGH, LOW); break; case 2: setLights(HIGH, LOW, LOW); break; } } void setLights(int red, int yellow, int green) { digitalWrite(redPin, red); digitalWrite(yellowPin, yellow); digitalWrite(greenPin, green); }

​

포텐셔미터(potentiometer)를 좌우로 돌리면 입력값이 재설정되어 1, 2, 3으로 값이 변경됩니다. 

변경된 값에 따라 LED가 ON/OFF 됩니다. 실제 신호등을 이렇게 바꾸면 안 되겠습니다. ㅎㅎ
