1\. 파이썬(Python)

파이썬도 자바와 같은 컴퓨터 프로그래밍 언어이기 때문에 기본적인 문법은 유사한 점이 있다. 하지만 파이썬은 동적 타입 언어이고 자바는 강력한 타입 언어이다. 자바와는 다른 문법을 가지고 있어 자바 개발자에게 익숙하지 않은 표현들이 있다. 자바 개발자가 익숙하지 않는 파이썬의 표현들을 정리해 보자.

​

​

2\. 파이썬 객체(Object) 생성

파이썬에서도 클래스(Class)를 정의하여 객체(Object)를 생성할 수 있다. __init__ 함수는 생성자이고 show_car는 메서드(Method)이다. 객체(Object)는 프로그램 내의 개체(Entity)를 나타낸다. 클래스(Class)는 속성과 행동을 포함하는 객체를 정의한다. 메서드(Method)는 객체의 행동을 나타내며 속성을 조작하고 태스크를 수행한다.

class Car(object): def __init__(self, name, price): self.name = name self.price = price def show_car(self,): return "<Car (%s, %s)>" % (self.name, self.price) p = Car("SM6", 3200) print("type = ", type(p)) print("id = ", id(p)) print(p.show_car())

실행 결과

type = <class '__main__.Car'> id = 17384400 <Car (SM6, 3200)>

3\. try...except...else 문

파이썬에서는 에러가 발생할 가능성이 있는 코드와 에러와 상관이 없는 코드와 명확하게 구별하기 위해 try...except...else 문을 사용한다. try 문에 추가된 코드는 에러 처리를 담고 있어서 else 문이 보다 성능이 좋다고 하는데 사람이 느끼기 어려운 정도의 차이다.

​

try 블록 안에서 예외가 발생하면 exception을 처리하고 else 문은 건너뛴다. 

try 블록 안에서 에러가 발생하지 않으면 exception을 건너뛰고 else 문이 실행된다. 

# 경로파일이 존재하여 정상적인 처리 try: print("try") f = open("bk_pythonic/02/test_file.txt", "r") except: print("except") else: print("else") print(f.read()) f.close() finally: print("finally") # 일부터 없는 파일을 지정해 에러를 발생 print() try: print("try") f = open("bk_pythonic/02/not_file.txt", "r") except: print("except") else: print("else") print(f.read()) f.close() finally: print("finally")

**실행 결과**

처음에는 오류 없이 정상적으로 실행되어 try 문 이후에 else 문을 실행했고 마지막으로 finally를 실행했다. 

그다음에는 파일 오픈 시 에러가 발생하여 except 문을 실행하고 else를 건너뛰고 finally를 실행했다.

try else TEST FILE finally try except finally

4\. 함수를 변수에 저장

파이썬은 함수를 변수에 저장할 수 있다. square 함수를 func에 할당하고 func을 함수로 실행한다.

def square(x): return x * x print(square(5)) func = square print(func(6))

실행 결과

25 36

5\. 내부(Inner) 함수와 외부(Outer) 함수

파이썬은 함수안에서 함수를 정의할 수 있다. 함수 안에 있는 함수를 내부(Inner) 함수라고 하고 밖에 있는 함수를 외부(Outer) 함수라고 한다. scope chain에 의해 내부 함수에서는 외부 함수의 메모리에 접근할 수 있다.

def calc(x): def add(y): return x + y return add func = calc(3) print(func(4)) print(func(5)) 

실행 결과

7 8

6\. 데코레이터(Decorator)

클로저 함수와 @ 키워드를 사용하여 파이썬의 데코레이터를 구현한다. 함수를 매개변수로 하여 내부 함수에 전달하여 호출한다.

import time def log_time(func): def wrapper(*args, **kwargs): start = time.time() print("start =", start) result = func(*args, **kwargs) end = time.time() print("end =", end) print("logging =", end - start) return result return wrapper @log_time def test(delay_time): time.sleep(delay_time) test(1) test(2) 

실행 결과

start = 1614425721.264247 end = 1614425722.2652667 logging = 1.0010197162628174 start = 1614425722.2692559 end = 1614425724.2712839 logging = 2.002027988433838

7\. 가변 매개변수(*args)와 키워드 매개변수(**kwargs)

파이썬은 가변 매개변수를 지원한다. 가변 매개변수를 사용하면 함수에 값을 자유롭게 전달할 수 있다. 관행적으로 *args와 **kwargs를 사용한다. *args는 키가 없는 가변 인자이고 **kwargs는 키워드 가변 인자를 말한다. *args 매개변수는 리스트로 전달받고 **kwargs는 키값이 있는 딕셔너리로 전달받는다.

def print_list(*args): for item in args: print("%s" % item) def print_dict(**kwargs): for keyword, value in kwargs.items(): print("keyword : %s, value : %s" % (keyword, value)) print("= List =") list = ["A", "B", "C", "D"] print_list(*list) print("= Dict =") dict = {"A": "one", "B": "two", "C": "three", "D": "four"} print_dict(**dict) 

실행 결과

= List = A B C D = Dict = keyword : A, value : one keyword : B, value : two keyword : C, value : three keyword : D, value : four 

​

함수에 전달된 고정 매개변수와 가변 매개변수 그리고 키워드 매개변수를 출력해 보자.

def func(x, *args, **kwargs): print("=== 고정 매개변수 ===") print(x) print("=== 가변 매개변수 ===") for arg in args: print("arg =", arg) print("=== 키워드 매개변수 ===") for keyword, arg in kwargs.items(): print(keyword, ":", arg) args = ["Apple", "Bus", "Cat"] kwargs = {"one": "1", "two": "2", "three": "3"} func("python", *args, **kwargs) print() func("anaconda", "Dog", "Egg", four="4", five="5")

실행 결과

=== 고정 매개변수 === python === 가변 매개변수 === arg = Apple arg = Bus arg = Cat === 키워드 매개변수 === one : 1 two : 2 three : 3 === 고정 매개변수 === anaconda === 가변 매개변수 === arg = Dog arg = Egg === 키워드 매개변수 === four : 4 five : 5
