JSTL(JSP Standard Tag Library)은 JSP(JavaServer Pages)를 개발할 때 사용되는 태그 라이브러리다. 

JSTL은 JSP 페이지에서 자주 사용되는 로직을 단순화하고 표준화하기 위해 개발되었다. 

​

​

**1\. JSTL 태그 라이브러리**

JSTL은 여러 개의 모듈로 구성되어 있으며, 주요 모듈은 다음과 같다

\- Core: 변수 선언, 조건문, 반복문 등을 포함한 핵심 기능을 제공한다.

\- Formatting: 숫자와 날짜의 형식 지정을 위한 기능을 제공한다.

\- SQL: 데이터베이스 액세스를 위한 기능을 제공한다.

\- XML: XML 문서를 조작하는 기능을 제공한다.

​

​

**2\. JSTL 사용 방법**

JSTL을 사용하려면 먼저 해당 태그 라이브러리를 선언해야 한다. 

JSP 페이지 상단에 다음과 같이 태그 라이브러리를 선언한다.

﻿<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>﻿

\- `prefix`는 태그를 사용할 때의 접두사(prefix)를 정의하며, `uri`는 태그 라이브러리의 위치를 지정한다.

\- 선언한 태그 라이브러리를 사용하여 JSTL 태그를 JSP 페이지에서 사용할 수 있다.

​

​

**3\. JSTL Core 태그 예제**

\- JSTL Core 모듈은 JSP 페이지에서 자주 사용되는 기본적인 로직을 단순화한다.

​

아래는 JSTL Core 태그를 사용한 예제 코드다.

`<c:set>` 태그를 사용하여 변수를 선언하고, `<c:if>` 태그를 사용하여 조건문을 처리한다. `<c:forEach>` 태그는 반복문을 처리한다.

<c:set var="name" value="John Doe" /> <c:if test="${name ne null}"> <p>Welcome, ${name}!</p> </c:if> <c:forEach var="i" begin="1" end="5"> <p>Iteration ${i}</p> </c:forEach>

JSTL Core 태그를 사용하면 자바 코드를 사용하지 않고도 간단하게 로직을 구현할 수 있다. JSTL은 JSP 개발에서 유용한 기능을 제공하며, 코드의 가독성과 유지 보수성을 향상시킬 수 있다. JSTL 태그 라이브러리의 모듈과 해당 모듈이 제공하는 태그들을 적절히 활용하여 개발하면 효율적이고 표준화된 JSP 애플리케이션을 개발할 수 있다.

​

​

**4\. BooksServlet 예제**

BooksServlet.java

package app.servlet; import java.io.IOException; import java.util.ArrayList; import java.util.List; import javax.servlet.RequestDispatcher; import javax.servlet.ServletException; import javax.servlet.annotation.WebServlet; import javax.servlet.http.HttpServlet; import javax.servlet.http.HttpServletRequest; import javax.servlet.http.HttpServletResponse; @WebServlet(urlPatterns = { "/books" }) public class BooksServlet extends HttpServlet { private static final long serialVersionUID = -8868318797864424567L; @Override public void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException { List<Book> books = new ArrayList<Book>(); Book book1 = new Book("9788960771468", "토비의 스프링 3", 50.00); Book book2 = new Book("9788960772762", "Node.js 노드제이에스 프로그래밍", 28.00); Book book3 = new Book("9788960771512", "알짜만 골라 배우는 자바", 25.00); books.add(book1); books.add(book2); books.add(book3); request.setAttribute("books", books); RequestDispatcher rd = request.getRequestDispatcher("/books.jsp"); rd.forward(request, response); } }

​

books.jsp

<%@page contentType="text/html; charset=utf-8" pageEncoding="utf-8"%> <%@ taglib uri="http://java.sun.com/jsp/jstl/core" prefix="c"%> <html> <head> <title>책 목록</title> <style> table, tr, td { border: 1px solid brown; } </style> </head> <body> 간단한 표로 표시한 책 목록 <table> <tr> <td>ISBN</td> <td>제목</td> </tr> <c:forEach items="${requestScope.books}" var="book"> <tr> <td>${book.isbn}</td> <td>${book.title}</td> </tr> </c:forEach> </table> <br /> 스타일을 입힌 표로 표시한 책 목록 <table> <tr style="background: #ababff"> <td>ISBN</td> <td>제목</td> </tr> <c:forEach items="${requestScope.books}" var="book" varStatus="status"> <c:if test="${status.count%2 == 0}"> <tr style="background: #eeeeff"> </c:if> <c:if test="${status.count%2 != 0}"> <tr style="background: #dedeff"> </c:if> <td>${book.isbn}</td> <td>${book.title}</td> </tr> </c:forEach> </table> <br /> ISBNs만 표시: <c:forEach items="${requestScope.books}" var="book" varStatus="status"> ${book.isbn}<c:if test="${!status.last}">,</c:if> </c:forEach> </body> </html>

**5\. BigCitiesServlet 예제**

BigCitiesServlet.java

package app.servlet; import java.io.IOException; import java.util.HashMap; import java.util.Map; import javax.servlet.RequestDispatcher; import javax.servlet.ServletException; import javax.servlet.annotation.WebServlet; import javax.servlet.http.HttpServlet; import javax.servlet.http.HttpServletRequest; import javax.servlet.http.HttpServletResponse; @WebServlet(urlPatterns = { "/bigCities" }) public class BigCitiesServlet extends HttpServlet { private static final long serialVersionUID = -520238711783191871L; @Override public void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException { Map<String, String> capitals = new HashMap<String, String>(); capitals.put("인도네시아", "자카르타"); capitals.put("말레이시아", "쿠알라룸프르"); capitals.put("태국", "방콕"); request.setAttribute("capitals", capitals); Map<String, String[]> bigCities = new HashMap<String, String[]>(); bigCities.put("호주", new String[] { "시드니", "멜번", "퍼스" }); bigCities.put("뉴질랜드", new String[] { "오클랜드", "크라이스트처치", "웰링턴" }); bigCities.put("인도네시아", new String[] { "자카르타", "수라바야", "메단" }); request.setAttribute("capitals", capitals); request.setAttribute("bigCities", bigCities); RequestDispatcher rd = request.getRequestDispatcher("/bigCities.jsp"); rd.forward(request, response); } }
