1\. 주피터 노트북 개요

주피터 노트북에 원격접속을 설정하고 다른 머신에서 노트북에 접속하려고 할 때 명령창에 표시되는 token을 알려주지 않으면 접속이 안된다. 실행할 때 마다 관리자가 토큰을 공지해주어도 되지만 비밀번호를 설정하면 인증화면에 비밀번호를 입력하여 사용할 수 있다. 이번에는 비밀번호 설정하는 방법에 대해서 알아보자. 

​

예) token=a7b869ffe0c72ca467cd6a2e5dd775311ec33f56b527c919

2\. 설정 파일

다음의 주소에 위치한 설정파일을 수정한다.

설정파일 위치 : C:\Users\<username>\\.jupyter\jupyter_notebook_config.py

![](https://postfiles.pstatic.net/MjAyMTExMDVfMTE3/MDAxNjM2MDQxNzQ2NTU1._CBIByG7rxZvj9qz0BD1m0t-CtT4C5MGFjsi3fhPzzEg.JlXwo3YiSFv40rICUMG2N_ZWcD7puJZFeQY4IaJBTKQg.PNG.agapeuni/image.png?type=w966)

​

1) 해시값 생성

token 인증을 대신해서 비밀번호를 설정하기 위해 ipython을 실행하여 다음의 파이썬 코드를 입력한다. IPython.lib의 passwd 함수를 import 하고 passwd() 항수를 실행하여 비밀번호를 입력한다. 비밀번호를 2번 입력을 하고 나면 웹 인증에 사용할 해시값이 출력되는데 출력된 해시값을 복사해서 주피터 설정파일에 저장한다.

![](https://postfiles.pstatic.net/MjAyMTExMDZfODAg/MDAxNjM2MTkxNDkwMTQx.1kQzUyu2DTHuEEnTgaDl7CzK7N63BtfwUP_ORaiB4Bsg.evXOOz5KIQHcZDuORrenKpmHLJ6eozEn2UStMBdsvI4g.PNG.agapeuni/image.png?type=w80_blur)

from IPython.lib import passwd passwd()

​

2) 주피터 설정

복사한 해시값을 설정파일에 저장한다. 값의 형식은 'type:salt:hashed-password'이다.

​

그리고 사용자가 주피터 서버의 암호의 설정을 사용하도록 한다.

3\. 확인

주피터 노트북을 실행하니 명령창에 표시되는 token 정보가 없는 URL이 된다. URL을 복사해 브라우저에서 접속해 보자.
