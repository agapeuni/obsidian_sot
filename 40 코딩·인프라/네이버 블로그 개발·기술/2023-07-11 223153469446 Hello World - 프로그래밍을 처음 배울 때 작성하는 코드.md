​

프로그래밍을 처음 배울 때 'Hello World'를 작성해 본다. 컴퓨터 언어를 처음 배울 때는 그 언어의 문법, 개발 환경, 실행 환경 등 모든 것이 낯설고 생소하다. 새로운 언어를 배울 때는 직접 코딩하면서 자연스럽게 배우는 것이 좋다. 그럴 때 Hello World를 출력하는 코드를 작성하고 그것을 실행해 보면서 첫걸음을 시작한다.

public class Hello { public static void main(String[] args) { System.out.println("Hello World"); } }

**실행 화면**

간단한 코드라 Java를 알고 있는 사람에게는 아쉬 쉬운 내용이다. 

Java 소스를 컴파일하고 실행한 결과를 그대로 보여준다.

**Java 환경**

그런데 여기서 한번 생각해 볼 것은 위와 같이 Java 코드를 명령 프롬프트에서 실행할 수 있으려면 먼저 Java 환경이 구성되어야 한다. Java로 작성된 코드를 실행하기 위해 JVM(Java Virtual Machine)이라는 컴파일러가 필요하다. Java 프로그램을 실행하기 위한 환경을 구성해야 위와 같이 실행해 볼 수 있다. 

​

JDK(Java Development Kit)에는 Java 컴파일러(javac), 실행환경(java), 디버깅 도구 등이 포함되어 있다. Oracle JDK 또는 OpenJDK를 선택할 수 있는데 설치하는 과정은 어렵지 않다.

​

1) OpenJDK 공식 사이트에서 다운로드 페이지로 이동한다. ([https://openjdk.java.net/)](https://openjdk.java.net/%29)

2) 운영체제에 맞는 JDK 패키지를 다운로드하고 설치한다. 

3) JDK 설치가 완료되면, 시스템 환경 변수에 JAVA_HOME 변수를 설정하고, PATH 환경 변수에 JDK의 bin 디렉터리 경로를 추가한다. 이렇게 함으로써 컴파일러와 실행환경을 사용할 수 있다.

​

**첫 번째 라인**

public class Hello {

첫 번째 라인 "public class Hello { ... } "를 보면 클래스의 이름과 타입을 정의하고 있다. Java 프로그램을 만드는 것은 Java 클래스를 만드는 것이다. Java 코드를 작성할 때는 하나의 클래스로 정의하고 public으로 클래스 타입을 지정해 주어야 한다. 그러고 나서 Hello처럼 클래스 이름을 지정해야 물결 괄호 '{ ... }'에 둘러싸인 범위가 클래스의 내용이 된다.

​

클래스 이름에도 관례적인 규칙이 있다. 자바에서 클래스 이름은 대문자로 시작하며, 카멜 표기법을 따른다. 클래스의 이름은 생성하고자 하는 객체를 명확하게 표현할 수 있는 단어가 좋으며 가급적 명사로 만든다.

​

​

**두 번째 라인**

public static void main(String[] args) {

그럼 이번에는 두 번째 라인 "public static void main(String[] args) {"을 살펴보자. 두 번째 라인은 Java 프로그램을 시작하면 먼저 호출되는 함수를 정의한 코드이다. Java 프로그램의 시작점(Entry Point)을 정의하는 메서드(Method)다. 그냥 복붙해서 사용하거나 자동 생성해서 사용하는 코드라 실무에서 일일이 직접 타이핑하는 사람은 없는 편이다. 자신의 코딩 실력을 보이고 싶은지 위 코드를 그냥 치는 사람도 가끔 있다. 

​

각각의 키워드와 표현에 대한 설명은 다음과 같다.

​

1) public

public은 접근 제어자(access modifier)로, 해당 클래스 또는 멤버(메서드, 변수 등)가 다른 클래스에서 접근 가능함을 나타낸다. public 키워드를 사용하면 다른 클래스에서 해당 클래스 또는 멤버에 접근할 수 있다.

​

2) static

static은 정적(static) 키워드로, 해당 멤버 또는 메서드가 클래스 수준에 속함을 나타낸다. static으로 선언된 멤버는 객체의 생성 없이도 클래스 이름으로 직접 접근할 수 있다.

​

3) void

void는 반환 타입(return type)으로, 메서드가 값을 반환하지 않음을 나타낸다. void 반환 타입을 갖는 메서드는 호출되면 작업을 수행하고 결과를 반환하지 않는다.

​

4) String[] args

String[]은 문자열 배열을 나타내는 자료형으로, 프로그램 실행 시 커맨드 라인에서 전달되는 인수(arguments)를 저장하는 매개변수다. args는 매개변수의 이름으로, 다른 이름을 선택하여 사용할 수도 있다. Java 가상 머신은 프로그램 실행 시 main 메서드를 찾아 실행하게 되는데 main 메서드의 매개변수 args는 커맨드 라인에서 전달되는 인수들을 문자열 배열로 받아올 수 있다.

​

​

**세 번째 라인**

System.out.println("Hello World");

세 번째 라인에서 'Hello World'를 출력하고 있다. 

이제 세 번째 라인에 대해 알아보자.

​

1) System

System 클래스는 표준 입출력을 담당하고 있다. java.lang 패키지에 속한 클래스인데 java.lang 패키지의 클래스들은 import 문을 사용하지 않고 바로 사용할 수 있다.

​

2) out

System 클래스 뒤에 점(.)을 하고 out을 썼는데 이러한 기법을 Dot Notation이라고 한다. Java에서 클래스의 속성에 접근하는 방법이다. System 클래스를 보면 PrintStream 클래스로 out이라는 변수를 정의하고 있다. out을 통해 PrintStream 클래스의 println() 메서드를 사용할 수 있게 된다. 참고로 System 클래스에는 표준 입출력을 위해 in, out, err 변수가 정의되어 있다.

​

3) println

println() 메서드는 표준 출력 스트림을 통해 출력 장치(화면)으로 전달된 데이터를 표시한다. 참고로 print() 메서드로 동일한 기능을 하는데 줄 바꿈을 하지 않는다. 

​

4) "Hello World"

Java에서는 문자로 구성된 문자열을 정의할 때 큰따옴표(")로 감싼다. 

​

5) ; (세미콜론)

코드의 끝에는 ; (세미콜론)를 붙여주어 문장의 끝을 알려준다.

​

​

**네 번째 라인**

}

main 메서드의 블록 끝을 나타낸다. 

​

​

**다섯 번째 라인**

}

Hello 클래스의 블록 끝을 나타낸다.
