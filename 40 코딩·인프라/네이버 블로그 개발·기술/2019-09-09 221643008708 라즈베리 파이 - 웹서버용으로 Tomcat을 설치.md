# 2019-09-09 221643008708 라즈베리 파이 - 웹서버용으로 Tomcat을 설치

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221643008708&categoryNo=982
- 게시일: 2019. 9. 9. 0:54

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTU2/MDAxNzU4NDQzODE5MjY0.t94avtqzp6PppOBUevgWYL1fZFInJ3TicKUkTN4QfM8g.roNPjZyd0zd0ps_fzVQ5MhG47F-JAkNj7bviNezo12kg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(10\).png?type=w80_blur)

​

지난번에는 데이터 센터로 사용하기 위한 목적으로 192.168.0.10을 고정 IP로 하여 MariaDB, MongoDB를 설치하였습니다. 

이번에는 다른 라즈베리 파이에 웹서버로 사용하기 위해 Tomcat을 설치해 보겠습니다.

​

먼저 다음의 명령어로 tomcat이 포함된 패키지를 검색해 봅니다.

**$ sudo apt-cache search tomcat**

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMTcx/MDAxNTY3OTU3NzQyOTg4.kIRWnCNxHaRmlfOWhVJpnsYP-XtQT1Yqs1PMQfzP9sYg.FAjoYz-zixKGbNNH2bSofbTx3qL0cmt9An2Nsr_6LM4g.PNG.agapeuni/20190909_003118.png?type=w80_blur)

tomcat9를 설치해 볼까 했지만 우선 tomcat8로 설치를 진행합니다. 

**$ sudo apt-get install tomcat8**

![](https://postfiles.pstatic.net/MjAxOTA5MDlfNzYg/MDAxNTY3OTU3NzM2MjM0.Q-IlcPNM-iB8uDTik3oMICPi8jWfSWAFPGkN2ABWRA0g.ndqzBTStAmVI8BS6XuvP8k_QYMm9cH0YwmkDJlY8xQ8g.PNG.agapeuni/20190909_003213.png?type=w80_blur)

웹페이지에도 나와 있듯이 해당 페이지 경로는 다음과 같습니다.

**/var/lib/tomcat8/webapps/ROOT/index.html**

​

설치를 마치고 웹브라우저에서 접근을 시도해 봅니다. 정상적으로 잘 표시됩니다. 

[**http://192.168.0.11:8080**](http://192.168.0.11:8080)

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMzAg/MDAxNTY3OTU3NzI5MzA1.5PJ_j0C-JN3JKgCI73DjnuNUN5DYZYtPrYaAjfnWjLMg.dwcr5BSPNDF6L-Zgk3EmZEyZ-3bZaEdBVIM2s2Du6tAg.JPEG.agapeuni/20190909_003643.png?type=w80_blur)

​

JSP로 서비스되는지 /var/lib/tomcat8/webapps/ROOT/ 경로에 index.jsp 페이지를 만들어 테스트를 해봅니다.

**$ cd /var/lib/tomcat8/webapps/ROOT/**

**$ sudo nano index.jsp**

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMjE4/MDAxNTY3OTU3OTEyNTMz.iUmFBrmRnslLp0QnQzfIZZV4pa_JY9LQWebLK6SFblEg.aCHLx8x6phTD0gZlsM3bvVycTWfk31rPwkn0AmyaKYYg.PNG.agapeuni/20190909_005137.png?type=w80_blur)

​

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMjcw/MDAxNTY3OTU3NzUzNzA2.XPSzZecS1Vq_UNzMUWQqvprFChkGiP0q2mPyjaAZOl8g.0YgymqkHydTXafm91iHG-SB8zK9lClc_jAMioIcGxUQg.PNG.agapeuni/20190909_003637.png?type=w80_blur)

아래에 URL로 접속하여 JSP가 서비스되는지 확인합니다. java.util.Date()가 잘 변환되어서 표시되네요. 

[**http://192.168.0.11:8080/index.jsp**](http://192.168.0.11:8080/index.jsp)

![](https://postfiles.pstatic.net/MjAxOTA5MDlfMjcy/MDAxNTY3OTU3OTMzMTI4.Hy2FHHj4nn3FXa0g5mGHqxT1pe--HVYFcpZA9C0iPM0g.GTS5d4um6UPOp_l6uBsa9aSmx9i-gsSZ_gFAKZwz0ZUg.PNG.agapeuni/20190909_003640.png?type=w80_blur)

​

정상적으로 설치된 것을 확인하였으니 서비스를 재시작 하고 마치겠습니다.

**$ sudo service tomcat8 restart**
