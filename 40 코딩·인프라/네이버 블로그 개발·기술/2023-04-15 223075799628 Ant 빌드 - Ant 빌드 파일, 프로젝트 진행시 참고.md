1\. Ant 빌드

Spring 프로젝트 진행할 때 참조하기 위해 만든 Ant 빌드 (build.xml) 파일이다. 

잘 작성된 빌드 파일 하나 있으면 두고두고 재사용할 수 있어 편리하다. 

​

아래의 코드는 실제 프로젝트에서 사용한 것을 참고로 하여 정리했다.

target의 단계는 다음과 같이 구분하였다.

  * init

  * usage

  * build

  * deploy

  * deploywar

  * buildtests

  * tests

  * dbTests

  * createTables

  * dropTables

  * loadData

  * printData

  * clearData

  * shutdownDb

​

2\. target의 단계

2.1 project & property 정의

프로젝트 이름과 Ant 빌드 파일에서 사용하는 경로를 정의한다.

​

<?xml version=_"1.0"_?>

<project name=_"springapp"_ basedir=_"."_ default=_"usage"_ >

<property file=_"build.properties"_ />

<property name=_"src.dir"_ value=_"src"_ />

<property name=_"web.dir"_ value=_"war"_ />

<property name=_"build.dir"_ value=_"${web.dir}/WEB-INF/classes"_ />

<property name=_"name"_ value=_"springapp"_ />

​

​

2.2 main classpath 정의

말 그대로 main class path를 정의한다.

​

<path id=_"main-classpath"_ >

<fileset dir=_"${web.dir}/WEB-INF/lib"_ >

<include name=_"*.jar"_ />

</fileset>

<fileset dir=_"${appserver.lib}"_ >

<include name=_"servlet*.jar"_ />

</fileset>

<pathelement path=_"${build.dir}"_ />

<pathelement path=_"${test.dir}"_ />

</path>

...(생략)...

</project>

​

2.3 init (target) 정의

빌드파일을 시작할 때 init 메시지를 표시한다.

​

<target name=_"init"_ >

<tstamp>

<format property=_"DSTAMP"_ pattern=_"yyyy-MM-dd"_ />

<format property=_"TSTAMP"_ pattern=_"HH:mm:ss"_ />

</tstamp>

<echo message=_"${ant.project.name} build started at : ${DSTAMP} ${TSTAMP}"_ />

</target>

​

2.4 usage (target) 정의

build 파일에 정의된 target 사용법을 표시한다.

​

<target name=_"usage"_ >

<echo message=_""_ />

<echo message=_"${name} build file"_ />

<echo message=_"-----------------------------------"_ />

<echo message=_""_ />

<echo message=_"Available targets are:"_ />

<echo message=_""_ />

<echo message=_"build -- > Build the application"_ />

<echo message=_"deploy -- > Deploy application as directory"_ />

<echo message=_"deploywar -- > Deploy application as a WAR file"_ />

<echo message=_"install -- > Install application in Tomcat"_ />

<echo message=_"reload -- > Reload application in Tomcat"_ />

<echo message=_"start -- > Start Tomcat application"_ />

<echo message=_"stop -- > Stop Tomcat application"_ />

<echo message=_"list -- > List Tomcat applications"_ />

<echo message=_""_ />

</target>

​

2.5 build (target) 정의

src 폴더에 위치한 Java 파일을 컴파일한다.

​

<target name=_"build"_ description=_"Compile main source tree java files"_ >

<mkdir dir=_"${build.dir}"_ />

<javac destdir=_"${build.dir}"_ source=_"1.5"_ target=_"1.5"_ debug=_"true"_

deprecation=_"false"_ optimize=_"false"_ failonerror=_"true"_ >

<src path=_"${src.dir}"_ />

<classpath refid=_"main-classpath"_ />

</javac>

</target>

​

2.6 deploy (target) 정의

빌드한 파일을 WAS에 배포한다.

​

<target name=_"deploy"_ depends=_"build"_ description=_"Deploy application"_ >

<copy todir=_"${deploy.path}/${name}"_ preservelastmodified=_"true"_ >

<fileset dir=_"${web.dir}"_ >

<include name=_"**/*.*"_ />

</fileset>

</copy>

</target>

​

2.7 deploywar (target) 정의

빌드한 war 파일을 WAS에 배포한다.

​

<target name=_"deploywar"_ depends=_"build"_ description=_"Deploy application as a WAR file"_ >

<manifest file=_"${web.dir}/WEB-INF/classes/MANIFEST.MF"_ >

<attribute name=_"Project"_ value=_"${ant.project.name}"_ />

<attribute name=_"Ant-java-version"_ value=_"${ant.java.version}"_ />

<attribute name=_"Compile-java-version"_ value=_"${java.version}"_ />

<attribute name=_"Library-Version"_ value=_"${ant.project.name} : 1.5"_ />

<attribute name=_"Comments"_ value=_"common & production & quality & maintenance"_ />

<attribute name=_"Built-By"_ value=_"${user.name}"_ />

</manifest>

<war destfile=_"${name}.war"_ webxml=_"${web.dir}/WEB-INF/web.xml"_ >

<fileset dir=_"${web.dir}"_ >

<include name=_"**/*.*"_ />

</fileset>

</war>

<copy todir=_"${deploy.path}"_ preservelastmodified=_"true"_ >

<fileset dir=_"."_ >

<include name=_"*.war"_ />

</fileset>

</copy>

</target>

​

​

2.8 clean (target) 정의 

빌드 디렉터리에 파일을 삭제한다.

​

<target name=_"clean"_ description=_"Clean output directories"_ >

<delete>

<fileset dir=_"${build.dir}"_ >

<include name=_"**/*.class"_ />

</fileset>

</delete>

</target>

​

2.9 undeploy (target) 정의

배포한 파일을 삭제한다.

​

<target name=_"undeploy"_ description=_"Un-Deploy application"_ >

<delete>

<fileset dir=_"${deploy.path}/${name}"_ >

<include name=_"**/*.*"_ />

</fileset>

</delete>

</target>

​

2.10 buildtests (target) 정의

test 폴더에 위치한 java 파일을 컴파일한다.

​

<target name=_"buildtests"_ description=_"Compile test tree java files"_ >

<mkdir dir=_"${build.dir}"_ />

<javac destdir=_"${build.dir}"_ source=_"1.5"_ target=_"1.5"_ debug=_"true"_

deprecation=_"false"_ optimize=_"false"_ failonerror=_"true"_ >

<src path=_"${test.dir}"_ />

<classpath refid=_"main-classpath"_ />

</javac>

</target>

​

2.11 test classpath 정의

test classpath를 정의한다.

​

<path id=_"test-classpath"_ >

<fileset dir=_"${web.dir}/WEB-INF/lib"_ >

<include name=_"*.jar"_ />

</fileset>

<pathelement path=_"${build.dir}"_ />

<pathelement path=_"${test.dir}"_ />

<pathelement path=_"${web.dir}/WEB-INF/classes"_ />

</path>

​

2.12 tests (target) 정의

빌드한 파일로 단위테스트를 실시한다.

​

<target name=_"tests"_ depends=_"build, buildtests"_ description=_"Run tests"_ >

<junit printsummary=_"on"_ fork=_"false"_ haltonfailure=_"false"_ failureproperty=_"tests.failed"_ showoutput=_"true"_ >

<classpath refid=_"test-classpath"_ />

<formatter type=_"brief"_ usefile=_"false"_ />

<batchtest>

<fileset dir=_"${build.dir}"_ >

<include name=_"**/*Test.*"_ />

<exclude name=_"**/Jdbc*Test.*"_ />

</fileset>

</batchtest>

</junit>

<fail if=_"tests.failed"_ >

tests.failed=${tests.failed}

***********************************************************

**** One or more tests failed! Check the output... ****

***********************************************************

</fail>

</target>

​

2.13 dbTests (target) 정의

Jdbc 테스트를 수행한다.

​

<target name=_"dbTests"_ depends=_"build, buildtests, dropTables, createTables, loadData"_ description=_"Run db tests"_ >

<junit printsummary=_"on"_ fork=_"false"_ haltonfailure=_"false"_ failureproperty=_"tests.failed"_ showoutput=_"true"_ >

<classpath refid=_"test-classpath"_ />

<formatter type=_"brief"_ usefile=_"false"_ />

<batchtest>

<fileset dir=_"${build.dir}"_ >

<include name=_"**/Jdbc*Tests.*"_ />

</fileset>

</batchtest>

</junit>

<fail if=_"tests.failed"_ >

tests.failed=${tests.failed}

***********************************************************

**** One or more tests failed! Check the output... ****

***********************************************************

</fail>

</target>

​

2.14 createTables (target) 정의

데이터베이스에 테이블을 생성한다.

​

<target name=_"createTables"_ >

<echo message=_"CREATE TABLES USING: ${db.driver} ${db.url}"_ />

<sql driver=_"${db.driver}"_ url=_"${db.url}"_ userid=_"${db.user}"_ password=_"${db.pw}"_ onerror=_"continue"_

src=_"db/create_tables.sql"_ >

<classpath refid=_"main-classpath"_ />

</sql>

</target>

​

2.15 dropTables (target) 정의

데이터베이스에 테이블을 삭제한다.

​

<target name=_"dropTables"_ >

<echo message=_"DROP TABLES USING: ${db.driver} ${db.url}"_ />

<sql driver=_"${db.driver}"_ url=_"${db.url}"_ userid=_"${db.user}"_ password=_"${db.pw}"_ onerror=_"continue"_ >

<classpath refid=_"main-classpath"_ />

DROP TABLE products; 

</sql>

</target>

​

2.16 loadData (target) 정의

데이터베이스에 생성한 테이블에 데이터를 로드한다. 

​

<target name=_"loadData"_ >

<echo message=_"LOAD DATA USING: ${db.driver} ${db.url}"_ />

<sql driver=_"${db.driver}"_ url=_"${db.url}"_ userid=_"${db.user}"_ password=_"${db.pw}"_ onerror=_"continue"_

src=_"db/load_data.sql"_ >

<classpath refid=_"main-classpath"_ />

</sql>

</target>

​

2.17 printData (target) 정의

데이터가 잘 로드되었는지 확인한다.

​

<target name=_"printData"_ >

<echo message=_"PRINT DATA USING: ${db.driver} ${db.url}"_ />

<sql driver=_"${db.driver}"_ url=_"${db.url}"_ userid=_"${db.user}"_ password=_"${db.pw}"_ onerror=_"continue"_ print=_"true"_ >

<classpath refid=_"main-classpath"_ />

SELECT * FROM products; 

</sql>

</target>

​

2.18 clearData (target) 정의

테이블에 데이터를 모두 지운다.

​

<target name=_"clearData"_ >

<echo message=_"CLEAR DATA USING: ${db.driver} ${db.url}"_ />

<sql driver=_"${db.driver}"_ url=_"${db.url}"_ userid=_"${db.user}"_ password=_"${db.pw}"_ onerror=_"continue"_ >

<classpath refid=_"main-classpath"_ />

DELETE FROM products; 

</sql>

</target>

​

2.19 shutdownDb (target) 정의

데이터베이스를 셧다운 한다.

​

<target name=_"shutdownDb"_ >

<echo message=_"SHUT DOWN DATABASE USING: ${db.driver} ${db.url}"_ />

<sql driver=_"${db.driver}"_ url=_"${db.url}"_ userid=_"${db.user}"_ password=_"${db.pw}"_ onerror=_"continue"_ >

<classpath refid=_"main-classpath"_ />

SHUTDOWN; 

</sql>

</target>
