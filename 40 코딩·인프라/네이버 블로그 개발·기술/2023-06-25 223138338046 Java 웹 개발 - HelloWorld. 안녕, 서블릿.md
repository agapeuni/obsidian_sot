**1\. Servlet 및 JSP 개요**

Servlet 및 JSP는 웹의 기능을 확장하는 Java 프로그램이다. Java 서블릿은 웹 애플리케이션 컨텍스트에서 HTTP 요청에 응답하도록 설계되었다. 작업 컴퓨터에 서블릿을 구동하기 위한 설정은 이미 되어있다고 가정하고 서블릿을 사용하여 브라우저에 출력해 보자.

**2\. HelloServlet.java (서블릿 소스)**

이 코드는 간단한 HTML 페이지를 나타낸다. HttpServlet을 상속받은 HelloWorldServlet 클래스를 정의한다. doGet 메서드에서는 HTML을 생성하고 클라이언트로 전송한다. "Hello Servlet. *^^*" 텍스트가 화면에 표시된다.

import java.io.IOException; import java.io.PrintWriter; import javax.servlet.ServletException; import javax.servlet.http.HttpServlet; import javax.servlet.http.HttpServletRequest; import javax.servlet.http.HttpServletResponse; public class HelloServlet extends HttpServlet { protected void doGet(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException { response.setContentType("text/html;charset=euc-kr"); PrintWriter out = response.getWriter(); out.println("<html>"); out.println(" <head>"); out.println(" <title>Hello Servlet</title>"); out.println(" </head>"); out.println(""); out.println(" <body>"); out.println(" <b>Hello Servlet. *^^*</b>"); out.println(" </body>"); out.println("</html>"); } }
