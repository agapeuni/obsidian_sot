​먼저 노트북에서 원격 데스크톱 연결로 라즈베리 파이에 접속합니다. 

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTcz/MDAxNTU4NjkzMzAzODcz.79AbEJ1qS1oMvvozcetdOEYNS0GOVc_nnffIvuqetzcg.AG7OJRYPp55BSjz8mLv5MzImbElbWTXyMewBe3cU_6wg.PNG.agapeuni/20190524_183049.png?type=w80_blur)

​

톰켓(Tomcat)을 설치하기 위해 다음의 명령어를 수행합니다. 설치를 하려면 "Y"를 입력하고 엔터(Enter)키를 누르면 계속 진행됩니다.

**$ sudo apt-get install tomcat8**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjAy/MDAxNTU4NjkxOTg1ODk2.obFzRR-3wuwa-ME7uMVf2xEsp83ZgPkw5lkgLp3eDesg.jnuehJ5LBIfG7Seh_nI25VdMw4KeJyxQzfViYNQvz7Ag.PNG.agapeuni/20190524_183827.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjYg/MDAxNTU4NjkxOTg2NTg0.fDhlmZHEiQNDFKprXritkRkKAMlcAApDMjnciJOiabgg.uKCOBpWgQUPJhicg-dC1KfiWQJXXP9ya4-pHtxV-2zYg.PNG.agapeuni/20190524_183846.png?type=w80_blur)

**​**

Tomcat이 설치된 **"/usr/share/tomcat8"** 디렉토리로 가서 파일을 한번 살펴보았습니다.

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTQx/MDAxNTU4NjkxOTg3MjQy.AE6nY49W1899ZvvvtWMPw04uWj6myWGAjPV1v4QOWXsg.FunkeG5rJH3zMfYusJXVGQR4LY-7TQBKQL20FkeUZTUg.PNG.agapeuni/20190524_184036.png?type=w80_blur)

다음의 명령어로 Tomcat 서비스를 시작해보겠습니다. 그리고 tomcat이 실행되어 있는지 프로세스도 확인해 봅니다.

**$ sudo service tomcat8 start**

**$ ps -ef | grep tomcat**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfNzYg/MDAxNTU4NjkxOTg4MzA1.ijS8Ay1EzaE9FyZ3DkVIbPwfKvcEyVR_5OI7NPzOWf0g.APv-eKEMhvaZNzOb1i_WlNpFoD3PcDkzdlW2bcxsz10g.PNG.agapeuni/20190524_184511.png?type=w80_blur)

​

​

이 글을 작성하고 있는 노트북에서 톰켓이 실행되고 있는 라즈베리 파이로 접속해 봅니다. IP는 사용자마다 다릅니다. 

[**http://192.168.1.15:8080/**](http://192.168.1.15:8080/)

**​**

아래와 같이 페이지가 표시됩니다. 

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMTM0/MDAxNTU4NjkxOTg3NzMx.YOqWOgiin_cy6wAQhbjrK_VWETIABRia9IOE4CNAFRIg.MKnf8_IYxLU-dukfif6iIWxCec--tm0nc8l65UyiG0Yg.PNG.agapeuni/20190524_184219.png?type=w80_blur)

​

다음의 명령어로 Tomcat 서비스를 종료해 보겠습니다. 

그리고 tomcat이 잘 종료되었는지 프로세스도 확인해 봅니다.

**$ sudo service tomcat8 stop**

**$ ps -ef | grep tomcat**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfODUg/MDAxNTU4NjkxOTg4OTA0.hi-h03fX46QHFQfZCdhiIqtHeHs__60uLyKmWHld5TIg.OWPGeENT1FNM7RxNoW_4zrGajtIqdyJtoX7P55LkXKMg.PNG.agapeuni/20190524_184513.png?type=w80_blur)

이번에는 기본적으로 표시된 웹페이지를 변경해 보겠습니다. Welcome 페이지는 index.html 은 아래의 경로에 위치하고 있습니다.

**/var/lib/tomcat8/webapps/ROOT**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjkw/MDAxNTU4NjkxOTg5NzIx.bR4IVfWcHROhEL6eKErWkXmXloOfYL1x5Y48loVgfBUg.ctMLgrw83BXEGOskYoTXmVzzRMd-omwjR8WTL1R8rcwg.PNG.agapeuni/20190524_185753.png?type=w80_blur)

​

nano 에디터로 index.html 을 열어봅니다. 아까 크롬에서 표시된 페이지와 유사한 내용이 표시되고 있습니다.

**$ sudo nano index.html**

![](https://postfiles.pstatic.net/MjAxOTA1MjRfMjgx/MDAxNTU4NjkxOTkwNTA0.AcFW1S_PaAP_90FVTmDNgYmuZnAC27Ws2wyewCsSkfog.OYS0T3pAPRtqZDuoROG0CdKhCqPp55lnZiqR3UUMf6Ug.PNG.agapeuni/20190524_185805.png?type=w80_blur)

​

nano 에디터에서 아래와 같이 "Hello, Tomcat!" 이라는 내용만 표시되도록 페이지를 수정해 보았습니다. 

수정을 마치고나서 Tomcat을 시작합니다.
