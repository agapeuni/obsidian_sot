# 2024-06-30 223495899805 전자정부 프레임워크 - eGovFrame 웹 프로젝트 구축

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTlfMjkw/MDAxNzQ1MDE4MzUzNjI3.llntnGavd00NYO9Gf2CCUEeSSPGJUQZmUB7ZS1F4-Fcg.qjVcD4bPp0ZkfxyQASPzeyrvCLK5ndyx0F9ugdPbDi8g.PNG/%EA%B0%9C%EB%B0%9C%ED%99%98%EA%B2%BD-001_\(26\).png?type=w80_blur)

​

전자정부 웹 프로젝트 구축을 위해 작업 노트북에 전자정부 표준프레임워크 개발환경을 구축한다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfODQg/MDAxNzE5Njk3NDQyMjAz.8WnJZ_QNr6B9LsrhFuh0TGHYagvRLJHNOj8uV6xAy9cg.WzL0m6inMkNWtwxHTAQ6JwnDykZtdwpap2Xp0ISc9oEg.PNG/img1.daumcdn.png?type=w80_blur)

​

다음은 파일을 받는 과정을 캡처한 동영상이다.

상단 메뉴에서 "다운로드 - 개발환경"을 먼저 선택하고 좌측에 "**3.x 다운로드** "를 선택하여 해당 파일을 다운로드한다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfNDIg/MDAxNzE5Njk3NTEwODM2.V3CTFZDK-EWtfxiUWmsd_FKAYlcx5dfq2B2X4SRvvMUg.CtMf__JdYipqPGXCnzdmOySIC22ZBTn3YHNLpIdYv60g.PNG/image.png?type=w80_blur)

​

다운로드가 완료되면 파일을 실행하여 D 드라이브에 설치한다. 참고로 64bit 용 파일을 받았다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfNDYg/MDAxNzE5Njk3NTE5OTk3.STgItD3Q4l0WpGR9eZdD63scwfwcNQJLBKva8RV9agog.s5uLL-aIq3HBHYGiOMQ_SheaYOUSrfM3LeK7drEzgbUg.PNG/img1.daumcdn.png?type=w80_blur)

​

반디집이 설치되어 있어서 해당 파일을 클릭하니 반디집이 실행되었다. 

압축 풀기 경로를 "D:\eGov"로 입력하고 압축 풀기를 클릭한다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMzMg/MDAxNzE5Njk3NTI0Nzkz.23Vcrk_WZ1vDkASLR5o6LW1RCM06cbYYNDhyzODB1a4g.abIzYujqDhRp34rLTS-KghbGGscFxpOt0ElllnysoQEg.PNG/img1.daumcdn.png?type=w80_blur)

​

"D:\eGov" 아래에 "eGovFrameDev-3.9.0-64bit" 폴더가 생겼는데 접근하기 쉽게 아래와 같이 변경하였다.

**D:\eGov\eclipse**

**D:\eGov\workspace**

**​**

**Java는** jdk-8u251-windows-x64 버전을 D:\app\Java\jdk1.8.0_251에 설치했다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMjc0/MDAxNzE5Njk3NTI4NDMw.8JMGHyFaOk7djmkAi4PTrtB25NwVOnXadFqM0wRB0_Ig.UNRP5OT5TMz8Uqe-twlyisdqt9YYKAmPEVzh69L30rYg.PNG/img1.daumcdn.png?type=w80_blur)

**​**

이클립스 실행파일은 D:\eGov\eclipse 폴더에 있다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfNjQg/MDAxNzE5Njk3NTMzNzk5.3TfyXC8QHdInBVJE72T7lRLvU8YbX438PltSAFBvfa8g.S8BYUsS1TB07YbDzuFunysC0JFNH4q9uhS571zzQ9IYg.PNG/img1.daumcdn.png?type=w80_blur)

​

실행하면 아래와 같이 스플래시 윈도우가 표시된다.

혹시 실행환경이 맞지 않으면 오류메시지가 표시되는데 메시지 내용을 구글링 하면 해결 방법이 나온다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMjcy/MDAxNzE5Njk3NTM4MDMw.pR4FKWamyvlAgNZQllfVx8jf8xxgGNhNPwoVyfMrflcg.UgIdx2NSNJdk0vR1WoRQJPdJE_5pNabEe1rurLgmfBYg.PNG/img1.daumcdn.png?type=w80_blur)

​

Eclipse Launche 화면에서 workspace를 선택하라고 물어본다.

디폴트 값을 지우고 "D:\eGov\workspace"룰 입력하고 다시는 물어보지 말라고 아래의 체크박스를 선택했다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMjgz/MDAxNzE5Njk3NTQyMTc0.Ia77jgdkjcarZgz7w6eHZjvZVbt5IGLP1W6JAPBCydIg.417IWuSRPCeVGTF8bDtogv_DQs1wqzegFOALYW-S9j0g.PNG/img1.daumcdn.png?type=w80_blur)

​

정상적으로 실행되고 나서 바로 eGovFrame Web Project를 만들어 보았다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMTEx/MDAxNzE5Njk3NTQ2MzMy.aijjDO3RNUkJpXlNIUHE5kSXXbPsUCBJa16YerXEo38g.dZdGLSk6FprM6v8FRCwlnXeIfKF8m6P8roh16pwxE14g.PNG/img1.daumcdn.png?type=w80_blur)

​

Workbench로 전환하고 Project Explorer에 보면 아무것도 표시되는 게 없다.

빈 영역에서 마우스 우측 버튼을 클릭하면 콘텍스트 메뉴가 표시된다. 거기서 "New > Other..."를 선택

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMjE5/MDAxNzE5Njk3NTUwMzQ5.a8aXzlofb0S5aL3-X0e7GS4-vu9yqKCSheLpoi3frR0g.dJ8sEQLFKBhObPeMphuaJNM8ohAcEsbfnzGffcFt38kg.PNG/img1.daumcdn.png?type=w80_blur)

​

Wizard 창이 열리면 이클립스를 설치했을 때 보다 많은 항목들이 표시된다.

eGov에서 지원하는 항목들이 추가되었다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMTU1/MDAxNzE5Njk3NTU1NTU3.855frIJIPsuid_m5NcyJoxem7nL4PUtnl1_V5sOpiEAg.J4CkRhdT6hT6RDbsnTYVUeWK49QMpBT00k1SH7u515kg.PNG/img1.daumcdn.png?type=w80_blur)

​

상단의 Wizards: 입력란에서 Web이라고 입력하면 아래의 항목 중에 이름에 Web이 있는 것만 필터가 되어 찾기가 쉽다.

eGovFrame Web Project를 선택하고 Next 버튼을 클릭한다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMzQg/MDAxNzE5Njk3NTYwMTU2.Us-NaFFT1XJXbjFXS13eDWj1pVYiG72A8Cz-E1GemxAg.HmN-83HaZDTN4WOr16DuHALgutbIMrR3cHzIK9YwBDwg.PNG/img1.daumcdn.png?type=w80_blur)

​

프로젝트 이름을 "com.oneway.test"라고 했다. Group Id로 "com.oneway" Artifact Id로 "test"가 자동으로 입력된다.

Target Runtime을 선택하기 위해 그 옆에 있는 New 버튼을 클릭한다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMTEg/MDAxNzE5Njk3NTY2OTAy.snmsE2-sQzwddIcwmPrxiYQNWLJScpGhxHNZ55ptl2kg.25s-A75tZlqLnlzTiClXn0MPjaUbVo5uyMeYW44Jz-Eg.PNG/img1.daumcdn.png?type=w80_blur)

​

New Server Runtime Enviroment에서 자신에게 맞는 것을 선택하면 되는데 Apache Tomcat v9.0을 선택했다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMTMx/MDAxNzE5Njk3NTczNTA2.5VxCwVeXTfrLvVlLu08y0l7TF7U3Cpipm-UTBPObGMsg.E64bFyaHGgw2NADv7LtB5d1xbZXS9-N8S_bxwFqihcYg.PNG/img1.daumcdn.png?type=w80_blur)

​

​

Next 클릭하고 Tomcat이 설치된 폴더를 선택하면 된다.

D:\app\apache-tomcat-9.0.36

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMjE3/MDAxNzE5Njk3NTc4OTg0.C66xZexMj3p2viKNZ-AYKg8m8aFnWvrqfwxibuQt1B4g.bWODT3vBCw6y-x9MeVRiMsOTTWecZJ_sMureAcjAY58g.PNG/img1.daumcdn.png?type=w80_blur)

​

​

이 화면에서 필요한 설정은 마쳤으니 Next를 클릭한다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfMjY5/MDAxNzE5Njk3NTg0Mzgy.iJbMmyNB7TmNzO85lhUWAG8GsN6tBOdgGAWsaxyAL28g.IAhWnOwMC60CqwreiMTUuFvOFoOR4a1P9wcVnavMxT4g.PNG/img1.daumcdn.png?type=w80_blur)

​

​

다음 Generate Example 화면에서는 예제 소스를 생성할 수 있다. 체크박스를 선택하면 기본적인 예제 파일이 같이 생성이 된다. Finish 버튼을 클릭하면 처음 구성 시에는 Maven 레파지토리에서 관련 라이브러리를 다운로드하기 때문에 시간이 얼마간 소요된다.

![](https://postfiles.pstatic.net/MjAyNDA2MzBfODIg/MDAxNzE5Njk3NTg4NDky.eSy4N3y1bYZWRkWoRPS3fewANMg-38wLn3ntdFEpiyUg.37onoFldZm2vYchmC2-NpIBI1kH5_qQikcs-GjEYdEEg.PNG/img1.daumcdn.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyNDA2MzBfNDUg/MDAxNzE5Njk3NTk4MTk3.E8gbUfKwqv6my6k_0W5cqW_GFRqt0ZrkvmbaVDI6l8sg.wMGXv86lW7HwRviL2Noi852ygjp8yI7JZQJquf0pmgEg.PNG/img1.daumcdn.png?type=w80_blur)
