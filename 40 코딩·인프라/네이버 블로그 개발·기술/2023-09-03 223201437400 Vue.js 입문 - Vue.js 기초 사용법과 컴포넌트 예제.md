**1\. 개요**

Vue.js는 사용자 인터페이스(UI)를 구축하기 위한 프론트앤드 프레임워크이다. 프로그레시브 프레임워크로 웹 애플리케이션을 개발할 때 유연하게 대응할 수 있다. 성능이 우수하고 배우기가 쉬워 앵귤러나 리액트보다 학습곡선이 낮은 편이다.

Vue.js의 대표적인 기능은 컴포넌트 단위로 조합하여 구성이 가능하고 화면에 표시하기 위한 데이터를 데이터 바인딩으로 관리할 수 있고 빠른 렌더링으로 화면을 갱신할 수 있다. Virtual DOM을 적용하고 있어 고속의 렌더링이 가능하다. 실제 DOM과 동일한 구조의 가상 DOM을 만들어 처리한다. 

​

​

**2\. 적용**

Vue.js를 쉽게 적용하려면 CDN 방식으로 소스를 참고하면 된다.

// 최신버전을 사용 <script src="https://cdn.jsdelivr.net/npm/vue/dist/vue.js"></script> // 특정한 버전을 명시하여 사용 <script src="https://cdn.jsdelivr.net/npm/vue@2.5.2/dist/vue.js"></script> <script src="https://cdn.jsdelivr.net/npm/vue@2.6.10/dist/vue.js"></script>

​

Vue.js에서는 HTML 요소와 Vue 인스턴스를 다음의 방법으로 연결한다.

<div id="app"></div> new Vue( { el: '#app' , // ...생략... } )

​

데이터 바인딩으로 데이터 갱신과 DOM의 갱신을 실시한다.

<p> {{ message }} </p> data: { message: 'Hello Vue.js' }

​

Vue.component 에서 <cnt-btn>라는 컴포넌트를 정의한다. 컴포넌트는 재사용이 가능한 Vue 인스턴스이다. v-on 디렉티브로 이벤트를 처리할 수 있다. <button v-on:click="increase">라고 정의하면 마우스 클릭 시 increase 함수를 호출한다.

<div id="btn-components"> <p><cnt-btn></cnt-btn></p> <p><cnt-btn></cnt-btn></p> </div> Vue.component("cnt-btn", { template: '<button v-on:click="increase">{{ count }}번 눌렀습니다 </button>', data: function () { return { count: 0, }; }, methods: { increase: function () { this.count++; }, }, });

​

**3\. 예제**

위에서 설명한 내용으로 간단한 예제를 만들어 본다. 

입력항목에 입력한 내용이 바로 표시되고 버튼을 클릭하면 클릭한 카운트를 표시한다.

<!DOCTYPE html> <html> <head> <meta charset="utf-8" /> <title>Vue Sample</title> </head> <body> <div id="app"></div> <div id="btn-components"> <p><cnt-btn></cnt-btn></p> <p><cnt-btn></cnt-btn></p> </div> <script src="https://cdn.jsdelivr.net/npm/vue/dist/vue.js"></script> <script> new Vue({ el: "#app", template: ` <div> <p><input v-model="message"></p> <p> {{ message }} </p> </div>`, data: { message: "Hello Vue.js!", }, }); Vue.component("cnt-btn", { template: '<button v-on:click="increase">{{ count }}번 눌렀습니다 </button>', data: function () { return { count: 0, }; }, methods: { increase: function () { this.count++; }, }, }); new Vue({ el: "#btn-components" }); </script> </body> </html>
