1\. Selenium개요

Selenium(셀레니움)은 웹브라우저를 자동화할 수 있도록 지원하는 다양한 도구로 사용되는 라이브러리다. Selenium은 웹 브라우저를 제어하고 웹 페이지와 상호 작용하는 기능을 제공하여 웹 애플리케이션의 테스트 및 자동화를 수행할 수 있다. Selenium은 다양한 프로그래밍 언어에서 사용할 수 있으며, 가장 널리 사용되는 언어인 Python과의 통합이 잘 되어 있다. 

​

Selenium의 핵심은 WebDriver이며 다양한 브라우저에서 호환 가능한 인터페이스이다. Selenium은 WebDriver를 이용하여 Chrom, Firefox, Internet Explorer, Opera, Safari와 같은 모든 주요 브라우저들을 지원한다. Selenium API를 통해 직관적인 방식으로 WebDriver의 모든 기능에 액세스할 수 있다. Selenium은 다양한 브라우저에 대한 드라이버를 사용하여 웹 브라우저를 제어한다. 

​

Selenium은 웹 애플리케이션의 테스트를 자동화하는 데 사용되지만, 웹 스크래핑과 데이터 수집 작업에도 활용한다. Selenium을 사용하여 웹 페이지를 로드하고, 원하는 데이터를 추출하거나 상호 작용한다. 웹 데이터를 자동으로 수집하거나 웹 애플리케이션과 상호 작용하여 데이터를 입력하고 결과를 확인한다.

우측 마우스를 클릭하면 컨텍스트 메뉴가 표시되는데 Copy - Copy full xPath를 선택한다. 그러면 XPath 값이 클립보드에 복사가 된다.

/html/body/div[2]/div[2]/div[1]/div/div[3]/form/fieldset/div/input

​

아래의 순서로 자동으로 수행되는 코드를 작성해 본다.

1\. 크롬 브라우저를 열고 네이버에 접속한다. 

2\. 입력항목에 '주한길'을 입력하고 엔터를 클릭한다. 

3\. 결과가 나오면 상단에 있는 VIEW 메뉴를 클릭한다. 

4\. 결과 목록에서 첫 번째 글의 제목을 클릭한다.

from selenium import webdriver from selenium.webdriver.common.keys import Keys from time import sleep delay_time = 2 options = webdriver.ChromeOptions() options.add_experimental_option("excludeSwitches", ["enable-logging"]) options.add_argument('window-size=1024,768') browser = webdriver.Chrome('chromedriver', options=options) browser.implicitly_wait(time_to_wait=5) # 브라우저에서 URL을 호출한다. browser.get(url='https://www.naver.com/') sleep(delay_time) # 입력항목에 검색어를 입력하고 엔터 search_box = browser.find_element_by_xpath( '/html/body/div[2]/div[2]/div[1]/div/div[3]/form/fieldset/div/input') search_box.send_keys('주한길') search_box.send_keys(Keys.RETURN) sleep(delay_time) # 상단에 VIEW 메뉴를 클릭 menu = browser.find_element_by_xpath( '/html/body/div[3]/div[1]/div/div[2]/div[1]/div/ul/li[2]/a') menu.click() sleep(delay_time) # 첫번째 결과 클릭 link = browser.find_element_by_xpath( '/html/body/div[3]/div[2]/div/div[1]/section/div/div[2]/panel-list/div/more-contents/div/ul/li[1]/div[1]/div/a') link.click() sleep(delay_time) browser.close()
