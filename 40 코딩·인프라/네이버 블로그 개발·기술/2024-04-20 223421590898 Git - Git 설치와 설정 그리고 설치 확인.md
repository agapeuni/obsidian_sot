2\. Git 설정

Git을 설치한 후에는 사용자 정보를 설정해야 한다. 

터미널 또는 명령 프롬프트에서 아래 명령어를 입력한다.

git config -g user.name "Kim Seung Gu" git config -g user.email "agapeuni@naver.com"

​

커밋 메시지를 작성할 때 사용할 텍스트 에디터를 설정할 수 있다. 

기본 에디터는 Vim으로 되어 있는데 개인적으로 Nano가 익숙해서 Nano로 설정한다. 

git config --global core.editor "nano"

​

3\. Git 확인

다음 명령어를 입력하여 Git이 잘 설치되었는지 확인한다.

$ git -v git version 2.44.0.windows.1

다음 명령어를 입력하여 설정이 제대로 되었는지 확인한다.

git config --list
