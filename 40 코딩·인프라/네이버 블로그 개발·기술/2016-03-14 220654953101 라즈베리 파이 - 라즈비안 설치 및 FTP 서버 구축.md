# 2016-03-14 220654953101 라즈베리 파이 - 라즈비안 설치 및 FTP 서버 구축

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTMz/MDAxNzU4NDQyNzE1MTI4.P63bsStHdXn8JB4Af05WVJN_iqNQCKwckClgYoVPCrAg.8FvyycdMEC7sm10j2J4HMjBI3OXObM2ogJUj3Zc3bHwg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001.png?type=w80_blur)

​

한동안 독서경영과 자격시험 준비로 먼지가 쌓인 라즈베리 파이를 새롭게 갱신해 봅니다.

​

아래의 명령으로 업데이트하고서 한참동안 업그레이드하고 있는 중입니다. ㅎㅎ

**$****sudo apt-get update**

**$****sudo apt-get upgrade**

​

​

기다리다 지처 라즈베리 파이 공식 사이트에 가니 2016년 2월 26일자 버전이 올라와 있어서 JESSIE LITE 버전으로 새롭게 설치하였습니다. 

![](https://postfiles.pstatic.net/20160314_168/agapeuni_145795890837543uIV_PNG/20160314_213210.png?type=w80_blur)

​

라즈비안 설치를 마치고 나니 파이로 SSH 접속은 되는데 FTP 접속이 안되네요.

​

그래서 FTP 서버를 설치해 봅니다.

**$ sudo apt-get install vsftpd**

![](https://postfiles.pstatic.net/20160314_264/agapeuni_1457959130541J0MGU_PNG/20160314_213110.png?type=w80_blur)

![](https://postfiles.pstatic.net/20160314_18/agapeuni_14579593066704TAHD_PNG/20160314_214138.png?type=w80_blur)

​

**vsftpd** 설치가 완료되면 vsftpd.conf 파일을 열어서 설정을 해줍니다. 설정 파일 위치는 /etc/vsfptd.conf입니다.

개인적으로는 라즈비안에서 vi 에디터를 사용하는 것보다 nano 에디터를 사용하는 게 편리합니다.

​

**$ sudo nano /etc/vsftpd.conf**

​

vsftpd.conf 파일에 주요한 설정 정보를 알아보면 다음과 같습니다.

​

**익명 FTP를 허용 여부 (YES/NO)**

# Allow anonymous FTP? (Disabled by default).

**anonymous_enable=NO**

​

**FTP 쓰기 권한, 파일 작성 (YES/NO)**

# Uncomment this to enable any form of FTP write command.

**write_enable=YES**

​

**다운로드의 로깅을 활성화**

# Activate logging of uploads/downloads.

**xferlog_enable=YES**

​

다시 정리해 보면

anonymous_enable=NO -> 공개 형태로 FTP 서버로 운영할 것인지... 아니니**NO**

local_enable=YES -> 로컬 계정 사용자 접속 허용 여부 ... 사용하니**YES**

write_enable=YES -> write 명령어 사용 여부 ... 사용하니**YES**

xferlog_enable=YES -> 파일 전송 로그 기록할지 여부 ... 남겨야하니**YES******

![](https://postfiles.pstatic.net/20160314_133/agapeuni_1457959514477cY6Xq_PNG/20160314_214423.png?type=w80_blur)

​

이제 아래의 명령어로 vsftpd를 재시작을 해주면 FTP 서버로 작동합니다.

**$ sudo service vsftpd restart**

​

FileZilla를 사용해서 IP 주소와 계정 정보를 입력하고 나니 성공적으로 연결이 됩니다. 이제 마음껏 윈도 PC에서 작성한 코드나 다운로드한 예제를 라즈베리 파이에 손쉽게 올려서 실행해 볼 수 있습니다.
