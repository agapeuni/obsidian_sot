## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfODcg/MDAxNzU4NDMwMjUxMTY3.UYDqh6YmPZiA9OPiRltn58v-JjgeMsiEpC6AcQpfoAAg.2B7gY8TE1jFeFa_KuMjWfOXCzC3xlvgVO48bo_ADHf4g.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001.png?type=w80_blur)

​

이번에는 적외선(IR) 장애물 감지센서를 실험해 보겠습니다. 

적외선 센서를 구매할 때 같이 구매했는데 감지 범위가 10~12mm 정도라 가까이 다가가야 반응합니다.

​

무슨 용도로 사용되는지는 정확히 설명되어 있지는 않습니다. 

홈페이지는 전방 감지 센서 모듈이라고 되어 있습니다.

​

보드에는 J1 Photosensor v1.1이라고 써져 있고 별도의 LED가 내장되어 있어 쉽게 확인이 가능합니다.

핀홀이 3개 있는데 -, +, S라고 적혀있습니다. 그리고 3개 헤더 핀으로 납땜 작업이 필요합니다.

​

![](https://postfiles.pstatic.net/20160506_36/agapeuni_1462522668414UoWTI_JPEG/20150819_222423.jpg?type=w966)

​

아래와 같이 초음파 센서에는 5개 핀에 더를 적외선 센서에는 3개 핀헤더를 납땜하여 연결합니다.

![](https://postfiles.pstatic.net/20160506_97/agapeuni_1462522667715aNqtv_JPEG/20150819_222357.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/20160506_226/agapeuni_1462522668945w1O8W_JPEG/20150819_222836.jpg?type=w80_blur)

​

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

이번 실험의 준비물은 다음과 같습니다. 

  * 아두이노 우노(Arduino UNO)와 브레드보드

  * 적외선(IR) 장애물 감지센서

  * 빨강 LED 1개

  * 220 옴 저항 1개 

  * 연결 전선 2개

  * MM 점퍼선 2개 ​

![](https://postfiles.pstatic.net/20160506_204/agapeuni_1462522670443IolTF_JPEG/20150819_233148.jpg?type=w80_blur)

​

먼저 하드웨어 구성을 위해 브레드보드에 적외선 센서와 LED을 삽입합니다.

![](https://postfiles.pstatic.net/20160506_72/agapeuni_1462522669240xSvQS_JPEG/20150819_232126.jpg?type=w80_blur)

​

적외선 센서에는 GND와 Vcc를 연결 전선으로 연결하고 LED에는 220 옴 저항으로 GND와 연결합니다.

![](https://postfiles.pstatic.net/20160506_284/agapeuni_1462522669512iDnmq_JPEG/20150819_232212.jpg?type=w80_blur)

아두이노 우노(Arduino UNO)의 2번과 3번 핀에 점퍼선을 연결합니다. 

![](https://postfiles.pstatic.net/20160506_15/agapeuni_1462522669725B6yjl_JPEG/20150819_232253.jpg?type=w80_blur)

​

아두이노 우노(Arduino UNO)의 2번에 연결한 점퍼선을 적외선 센서의 S 핀에 꼽습니다.

아두이노 우노(Arduino UNO)의 3번에 연결한 점퍼선을 LED의 애노드(+)에 연결합니다.

![](https://postfiles.pstatic.net/20160506_260/agapeuni_1462522670009sBQh5_JPEG/20150819_232536.jpg?type=w80_blur)

**▣ 소스코드 : ir_sensor_1.ino**

int IR_PIN = 2; int LED_PIN = 3; ​ void setup() { pinMode(IR_PIN, INPUT); pinMode(LED_PIN, OUTPUT); } void loop() { int irState = digitalRead(IR_PIN); if (irState == HIGH) { digitalWrite(LED_PIN, HIGH); } else { digitalWrite(LED_PIND, LOW); } } 

​

아래는 위의 코드로 실행한 동영상입니다. 손을 가까이하면 센서가 반응하여 LED에 불이 들어옵니다.

적외선 센서의 LED가 먼저 반응하고 보드에서 신호를 받은 LED가 반응을 합니다. ​
