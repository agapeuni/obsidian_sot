1\. UUID(Universally Unique Identifiers)

UUID는 범용 고유 식별자로, 128비트(16바이트)의 값을 가지는 식별자다. UUID는 특정 시스템이나 네트워크에서 전역적으로 고유한 값을 생성하기 위해 사용된다. UUID는 임의로 생성되며, 일반적으로 MAC 주소, 시간 정보, 임의의 값 등을 기반으로 생성된다. 이러한 구성 요소들을 조합하여 UUID를 생성하므로, 동일한 조건으로 UUID를 생성한다 하더라도 충돌이 거의 발생하지 않는다.

​

UUID의 일반적인 용도로는 데이터베이스 레코드 식별자, 고유한 파일 이름, 세션 식별자, 임시 파일 식별자 등에 활용된다. 그리고 분산 시스템에서 여러 노드 간에 고유한 식별자를 생성하는 데에도 사용된다. UUID는 보편적으로 사용되는 버전인 UUID v4를 비롯하여 다른 버전들도 있다. 각 버전은 고유한 생성 알고리즘과 구조를 가지고 있으며, 식별자의 특성이나 보안 요구사항에 따라 선택하여 사용할 수 있다.

​

​

2\. UUID 구조

UUID는 32개의 16진수 숫자와 하이픈('-')으로 구성된 5개의 그룹으로 나누어져 있다. UUID는 전역적으로 고유한 값을 나타내며, 각 구성 요소의 조합에 따라 다른 목적에 사용될 수 있고 구조적인 특징을 통해 UUID의 생성 방식과 정보를 파악할 수 있다.

​

UUID는 다음과 같은 구성 요소로 이루어져 있다.

​

1) 시간 정보(Time-Based) 

UUID의 첫 번째 그룹은 타임스탬프와 버전 정보를 포함한다. 

이를 통해 생성 시간과 UUID 버전을 알 수 있습니다.

​

2) 버전 정보(Version)

UUID의 버전을 나타내는 숫자로, 1부터 5까지의 값을 가질 수 있다. 

버전에 따라 UUID 생성 알고리즘이 달라진다.

​

3) 시퀀스 번호(Sequence Number)

시간 기반 UUID(v1)에서 사용된다. 중복을 방지하기 위해 같은 시간에 생성되는 UUID들 사이에 순차적인 시퀀스 번호가 할당된다.

​

4\. 랜덤 값(Random Value)

랜덤 UUID(v4)에서 사용된다. 이 그룹은 완전히 임의의 값으로 채워진다.

​

5\. 네임스페이스 식별자(Namespace Identifier)와 이름 정보(Name-Based): 

이름 기반 UUID(v3, v5)에서 사용된다. 네임스페이스 식별자와 이름을 조합하여 해시 함수를 적용하여 UUID를 생성한다.

​

​

3\. UUID 버전

UUID는 여러 가지 버전이 존재한다. 각 버전은 다른 방식으로 UUID를 생성하고 구조화하는 데 사용되는 알고리즘을 가지고 있다. 각 UUID 버전은 다른 목적과 요구사항을 충족하기 위해 설계되었다. 주로 사용되는 버전은 v1과 v4이며, v4는 랜덤성이 높고 충돌 가능성이 낮기 때문에 일반적인 사용에 적합하다.

​

가장 일반적으로 사용되는 UUID 버전은 다음과 같다.

​

1) UUID v1 (타임스탬프와 MAC 주소 기반)

현재 시간과 MAC 주소를 기반으로 UUID를 생성한다. 유일성은 대부분 보장되지만, 개인 정보 보호 관련 이슈로 인해 사용이 제한될 수 있다.

​

2) UUID v2 (DCE 보안 버전)

네트워크 식별자와 시퀀스 번호를 포함한 UUID를 생성합니다. 사용이 제한되고 거의 사용되지 않는다.

​

3) UUID v3 (이름 기반 MD5 해시)

네임스페이스 식별자와 이름을 조합하여 MD5 해시 함수를 사용하여 UUID를 생성한다.

​

4) UUID v4 (랜덤 UUID)

완전히 임의의 값으로 UUID를 생성한다. 가장 일반적으로 사용되며 충돌 가능성이 매우 낮다.

​

5) UUID v5 (이름 기반 SHA-1 해시) 

네임스페이스 식별자와 이름을 조합하여 SHA-1 해시 함수를 사용하여 UUID를 생성한다.

​

​

4\. 예제

uuid 모듈을 사용하면 UUID를 쉽게 만들 수 있다.

import uuid print(uuid.uuid1()) # 네임스페이스와 MD5 해시를 사용 print(uuid.uuid3(uuid.NAMESPACE_DNS, 'oneway')) # 랜덤 UUID print(uuid.uuid4()) # 네임스페이스와 SHA-1 해시를 사용 print(uuid.uuid5(uuid.NAMESPACE_DNS, 'oneway'))
