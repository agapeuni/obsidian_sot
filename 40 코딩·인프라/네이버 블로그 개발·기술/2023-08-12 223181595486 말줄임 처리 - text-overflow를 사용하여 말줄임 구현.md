# 2023-08-12 223181595486 말줄임 처리 - text-overflow를 사용하여 말줄임 구현

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTJfNzMg/MDAxNzQ0NDY5MzQ3ODA3.gnfQavssgsyEaMk5MBGwlIAWBXBK1z7PLH3fqIQojQcg.eYaW9nEIrNbfnhTutx86yMlaUpZiEa6hOHDfiJ_1MpIg.PNG/CSS-001_\(4\).png?type=w80_blur)

​

웹 프로젝트를 진행하다 보면 제한된 넓이나 공간에 텍스트를 표시할 때 넘치는 글자를 감추기 위해 말줄임을 많이 사용한다. 이때 CSS를 사용하면 말줄임을 쉽게 구현할 수 있다. 말줄임을 적용하고자 하는 태그에 display : block으로 설정하고 text-overflow: ellipsis;로 설정한다. 그리고 다음의 스타일 속성을 white-space: nowrap; overflow: hidden 적용하면 된다. 

​

text-overflow:ellipsis;는 정해진 넓이에서 넘치는 글을 '...'으로 생략해 준다.

이 속성과 함께 overflow:hidden; 과 white-space:nowrap; 도 같이 적용한다. 

​

  * text-overflow:ellipsis; 말줄임

  * overflow:hidden; 넓이를 넘을 때 숨김

  * white-space:nowrap; 문장을 한 줄로 인식

<style> body { padding: 10px; } body * { margin: 0; padding: 0; box-sizing: border-box; } .news { width: 300px; padding: 10px 10px 10px 30px; border: 2px solid lightgray; } .news > li { padding: 5px 0; } .item { display: block; text-decoration: none; color: #333; text-overflow: ellipsis; white-space: nowrap; overflow: hidden; } .item:hover { text-decoration: underline; } </style> <ul class="news"> <li><a href="#" class="item">웹 프로젝트를 진행하다 보면 </a></li> <li><a href="#" class="item">제한된 넓이나 공간에 텍스트를 표현할 때</a></li> <li><a href="#" class="item">넘치는 글자를 감추기 위해 말줄임일 많이 사용한다.</a></li> <li><a href="#" class="item">text-overflow:ellipsis;는 넓이네 넘치는 글을 '...' 으로 생략해준다.</a></li> <li><a href="#" class="item">이 속성과 함꼐 overflow:hidden; 과 white-space:nowrap; 도 같이 적용해야 한다.</a></li> </ul>

​

첫 문장은 300px을 넘지 않아서 그대로 표시하였고 다른 문장은 지정한 너비를 넘어서 말줄임이 적용되었다.
