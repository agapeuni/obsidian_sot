1\. Spring Tool Suite 4 개요

Spring Tool Suite 4 (STS 4)는 개발자들이 Spring Framework 기반 애플리케이션을 개발, 테스트 및 디버깅하기 위한 통합 개발 환경이다. STS 4는 Eclipse IDE를 기반으로 구축되었으며, Spring 애플리케이션 개발에 필요한 다양한 기능과 도구를 제공한다. STS 4는 Spring 개발자들에게 높은 생산성과 개발 경험을 제공하기 위해 만들어진 강력한 개발 도구다.

​

스프링 프레임워크에 특화되어 있는 STS4(Spring Tool Suite 4)를 컴퓨터에 설치하고 간단한 Spring Starter 프로젝트를 구축해 보자. 참고로 STS4를 설치하기 전에 Java가 설치되어 있어야 한다.

![](https://postfiles.pstatic.net/MjAyMzA2MDZfMTI3/MDAxNjg2MDM4Njc3NDY4.ipQt9rQlTyVFPUQNbHMypLtwcawK50xCpRx6xiHKrP0g.dwJAj-qcrqVVQQtVN9rIUEqm8cU_1qfllb1gAj7m19cg.PNG.agapeuni/img.png?type=w80_blur)

2\. STS4 다운로드

아래의 주소에서 "WINDOWS X86_64-BIT"를 클릭해 윈도우 버전을 다운로드한다.

<https://spring.io/tools>

![](https://postfiles.pstatic.net/MjAyMzA2MDZfMjYg/MDAxNjg2MDM4Njg0MzE3.vtoHozEihswbu_LN7zWQ6wXjGajs25TjDRY_pNSPUVEg.QKp1P1iK8GfQwMck4pmAR7LLi9Tnck5u0O3cqYctnWkg.PNG.agapeuni/img.png?type=w80_blur)

​

다운로드가 완료되면 적절한 폴더에 압축 해제한다. 

명령창에서 java -jar 파일명.jar를 입력하면 jar 파일을 실행할 수 있다.

파일명 : spring-tool-suite-4-4.17.2.RELEASE-e4.26.0-win32.win32.x86_64.self-extracting.jar

![](https://postfiles.pstatic.net/MjAyMzA2MDZfMjU1/MDAxNjg2MDM4NzA5OTcx.duP-krT8-ElGR9YNwJ22hw1f0q--LzmnpUZh5Tu7pd4g.gSuCRVUndhisYUg1uxZiAXI5okqMkC2wrMnulCgu6H8g.PNG.agapeuni/img.png?type=w80_blur)

​

jar 압축파일의 내용을 살펴보면 "SelfExtractor.class"파일과 "contents.zip" 파일이 들어 있다. 

![](https://postfiles.pstatic.net/MjAyMzA2MDZfMjgw/MDAxNjg2MDM4NzEzNDU5.9cQNJNQI2YVfSQxWg5oyiQCEoOkV48ivyPhvKjrUzz0g.suZ3DGLOIWKbMz4LeYlVEY1mGs42VmY5cCOfllAhhVwg.PNG.agapeuni/img.png?type=w80_blur)

​

"SelfExtractor.class"파일을 디컴파일 해보니 압축 해제를 위한 코드가 구현되어 있다.

![](https://postfiles.pstatic.net/MjAyMzA2MDZfNzUg/MDAxNjg2MDM4NzE5ODE3.t7nMWWyjuT7yK4SYWMGOlGTVDLbYurRiS5VfGbHMLAwg._kLro_VOjT3wX1ZcOgqsKwhXqTvBuDoGK2p7FGkVSw4g.PNG.agapeuni/img.png?type=w80_blur)

3\. 압축 해제

JAR파일을 실행하여 압축을 해제해 보자. 다음의 명령을 입력하면 해당 폴더에 STS 파일을 자동으로 해제한다.

> java -jar spring-tool-suite-4-4.17.2.RELEASE-e4.26.0-win32.win32.x86_64.self-extracting.jar

​

압축 해제의 진행과정을 알 수 있도록 자바스러운 프로그레스 바를 표시해 준다.

​

압축 해제가 완료되었다. 폴더이름은 "sts-4.17.2.RELEASE"이다.

![](https://postfiles.pstatic.net/MjAyMzA2MDZfMSAg/MDAxNjg2MDM4NzQyMTUy.yHVAo3IhohR-0tb97m1WK-h8AnXo77-FbERcidxoPLcg.7J-PLhKc8aF1Ms9yZki5tKbJ4helBWY8INWCYQNWzlMg.PNG.agapeuni/img.png?type=w80_blur)

5\. 프로젝트 생성

STS4가 실행된 모습이다. 프로젝트를 하나 생성해 보자.

![](https://postfiles.pstatic.net/MjAyMzA2MDZfMTIw/MDAxNjg2MDM5MDQxNzg1.m9pJWC21zvRW43JovJa7GkbXsgAFBzORSyUdQCxyHLEg.SSYQ3HUFVFsW_7kCNCO_4qpmEP9-L3kqhz0XQv_1stwg.PNG.agapeuni/img.png?type=w80_blur)

​

"Create new Spring Starter Project"를 선택하여 프로젝트를 하나 생성한다.

"New Spring Starter Project"에서는 기본적인 값은 그대로 두고 다음과 같이 설정했다. 

  * Type : Maven

  * Java Version : 19

  * Group : com.oneway

  * Package : com.oneway.demo

![](https://postfiles.pstatic.net/MjAyMzA2MDZfODMg/MDAxNjg2MDM5MTg1NzY0.luHbSiGyIfMNDI3yP5IDfs77fVzOvd6RB-FsrX3xgiMg.ia-sqlmNFQQ28vurUAAXEtlkNCMYQapjGfex6n1cSDAg.PNG.agapeuni/image.png?type=w80_blur)
