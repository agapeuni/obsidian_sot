​

**JDBC(Java Database Connectivity)** 는 데이터베이스에 접속하기 위한 자바 API이다. 

Java 애플리케이션에서는 JDBC를 통해 데이터베이스에 있는 자료를 조회하거나 추가, 수정, 삭제를 한다. 

​

다음은 데이터베이스와 연동하는 JDBC API 호출 순서이다.

1\. JDBC Driver 로드

2\. DB Connection 객체 생성

3\. 쿼리 실행 객체 생성

4\. 쿼리 수행

5\. 쿼리 실행 결과 반환

6\. 데이터베이스 자원 해제

​

데이터베이스에 연결하기 위해 벤더마다 제공하는 클래스와 URL이 조금씩 다르다. 

실무에서 자주 사용하는 벤더에 관해 JDBC 설정 정보를 정리해 본다.

​

**1\. Oracle**

oracle.jdbc.driver.OracleDriver jdbc:oracle:thin:@hostname:port:SID String url = "jdbc:oracle:thin:@localhost:1521:SID"; Class.forName("oracle.jdbc.driver.OracleDriver");

**​**

**2\. MS-SQL**

com.microsoft.sqlserver.jdbc.SQLServerDriver jdbc:sqlserver://hostname:port/database=db_name String url="jdbc:sqlserver://localhost:10161;database=db"; Class.forName("com.microsoft.sqlserver.jdbc.SQLServerDriver");

**​**

**3\. MySQL**

com.mysql.jdbc.Driver jdbc:mysql://db_url:port/db_name String url = "jdbc:mysql://localhost:3306/db"; Class.forName("com.mysql.jdbc.Driver");

**​**

**4\. MariaDB**

org.mariadb.jdbc.Driver jdbc:mariadb://db_url:port/db_name String url = "jdbc:mariadb://localhost:3306/db"; Class.forName("com.mariadb.jdbc.Driver");

**​**

**5\. PostgreSQL**

org.postgresql.Driver jdbc:postgresql://host:port/db_name String url = "jdbc:postgresql://localhost:5432/db"; Class.forName("org.postgresql.Driver");

​

​**6\. Tibero**

com.tmax.tibero.jdbc.TbDriver jdbc:tibero:thin:@host:port/db_name String url = "jdbc:tibero:thin:@localhost:8629/db"; Class.forName("com.tmax.tibero.jdbc.TbDriver");

​

​**7\. Sybase**

com.sybase.jdbc3.jdbc.SybDriver jdbc:sybase:Tds:db_url:port/db_name String url = "jdbc:sybase:Tds:localhost:3344/db"; Class.forName("com.sybase.jdbc3.jdbc.SybDriver");

**​**

**8\. DB2**

com.ibm.db2.jcc.DB2Driver jdbc:db2://url:port/db_name String url = "jdbc:db2://localhost:9010/db"; Class.forName("com.ibm.db2.jcc.DB2Driver");
