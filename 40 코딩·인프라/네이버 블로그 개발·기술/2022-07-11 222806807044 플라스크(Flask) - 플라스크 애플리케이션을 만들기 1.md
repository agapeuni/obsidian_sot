**2\. 플라스크 개발 기초 공사**

플라스크 프로젝트 구조

﻿D:\bk_flask_jump ├── pybo/ │ ├─ __init__.py │ ├─ models.py │ ├─ forms.py │ ├─ views/ │ │ └─ main_views.py │ ├─ static/ │ │ └─ style.css │ └─ templates/ │ └─ index.html └── config.py

  * 데이터베이스를 처리하는 **models.py 파일**

  * 서버로 전송된 폼을 처리하는 **forms.py 파일**

  * 화면을 구성하는 **views 디렉터리**

  * CSS, JS, Iamage 파일을 저장하는 **static 디렉터리**

  * HTML 파일을 저장하는**templates 디렉터리**

  * 파이보 프로젝트를 설정하는 **config.py 파일**

*** 블루프린트(Blueprint)**

라우트 함수를 구조적으로 관리하기 위해 블루프린트(Blueprint) 사용

​

다음의 경로에 화면을 구성하는 views 파일 생성

D:/bk_flask_jump/pybo/views/main_views.py

from flask import Blueprint bp = Blueprint('main', __name__, url_prefix='/') @bp.route('/hello') def hello_pybo(): return 'Hello, Pybo!!' @bp.route('/') def index(): return 'Pybo index' 

pybo 패키지에 블루프린트 적용

D:/bk_flask_jump/pybo/__init__.py

from flask import Flask def create_app(): app = Flask(__name__) from .views import main_views app.register_blueprint(main_views.bp) return app

*** config.py 파일**

ORM을 적용하기 위해 설정 파일을 추가. sqlite 경로를 지정.

import os BASE_DIR = os.path.dirname(__file__) SQLALCHEMY_DATABASE_URI = 'sqlite:///{}'.format(os.path.join(BASE_DIR, 'pybo.db')) SQLALCHEMY_TRACK_MODIFICATIONS = False

*** ORM 적용하기 (__init__.py 수정)**

D:/bk_flask_jump/pybo/__init__.py

from flask import Flask from flask_migrate import Migrate from flask_sqlalchemy import SQLAlchemy import config db = SQLAlchemy() migrate = Migrate() def create_app(): app = Flask(__name__) app.config.from_object(config) # ORM db.init_app(app) migrate.init_app(app, db) # Blueprint from .views import main_views app.register_blueprint(main_views.bp) return app

*** 모델 만들기**

D:/bk_flask_jump/pybo/models.py

​

질문과 답변 모델

from pybo import db class Question(db.Model): id = db.Cloumn(db.Integer, primary_key=True) subject = db.Cloumn(db.String(200), nullable=False) content = db.Cloumn(db.Text, nullable=False) create_date = db.Cloumn(db.Datetime(), nullable=False) class Answer(db.Model): id = db.Column(db.Integer, primary_key=True) question_id = db.Column(db.Integer, db.ForeignKey('question.id', ondelete='CASCADE')) question = db.relationship('Question', backref=db.backref('answer_set')) content = db.Column(db.Text(), nullable=False) create_date = db.Column(db.DateTime(), nullable=False)
