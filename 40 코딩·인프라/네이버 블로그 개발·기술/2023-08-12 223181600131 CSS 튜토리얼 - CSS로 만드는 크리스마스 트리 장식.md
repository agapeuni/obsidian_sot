<ul> 태그와 <li> 태그

<ul> 태그와 <li> 태그 4개를 만들고 CSS를 사용하여 크리스마스 트리장식을 만드는 예제이다. <div>태그에 bauble 클래스와 각각의 red-, blue-, yello-, green-에 CSS를 적용하여 구현한다. <ul> 태그에 부여한 적인 bauble-container이라는 id를 기억하자.

<body> <ul id="bauble-container"> <li> <div class="bauble red-bauble"></div> </li> <li> <div class="bauble blue-bauble"></div> </li> <li> <div class="bauble yellow-bauble"></div> </li> <li> <div class="bauble green-bauble"></div> </li> </ul> </body>

​

bauble 영역

bauble의 영역을 잡아 주고 네 개의 <li> 태그에 트리 장식의 일부를 표현하는데 홀수 번째와 짝수 번째에 따라 각도를 다르게 표현한다.

#bauble-container { list-style: none; width: 568px; margin: 150px auto; padding: 0; } #bauble-container li { margin: 0 20px; float: left; } #bauble-container li:before { content: ""; background: #dadada; background: -moz-linear-gradient(bottom, #9c9c9c, rgba(255, 255, 255, 0)); background: -webkit-gradient(linear, left bottom, right top, from(#9c9c9c), color-stop(100%, rgba(255, 255, 255, 0))); height: 50px; width: 2px; display: block; margin: 0 auto; } #bauble-container li:nth-child(odd) { -moz-transform: rotate(-5deg); /* Firefox */ -webkit-transform: rotate(-5deg); /* Chrome and Safari */ -o-transform: rotate(-5deg); /* Opera */ -ms-transform: rotate(-5deg); /* Surprise! IE9 with its own prefix */ } #bauble-container li:nth-child(even) { -moz-transform: rotate(5deg); -webkit-transform: rotate(5deg); -o-transform: rotate(5deg); -ms-transform: rotate(5deg); }

장식 만들기

.bauble { -moz-border-radius: 100px; border-radius: 100px; -moz-box-shadow: 0 0 5px #777777; box-shadow: 0 0 5px #777777; -webkit-box-shadow: 0 0 5px #777777; border: 1px solid rgba(0, 0, 0, 0.3); position: relative; height: 100px; width: 100px; }
