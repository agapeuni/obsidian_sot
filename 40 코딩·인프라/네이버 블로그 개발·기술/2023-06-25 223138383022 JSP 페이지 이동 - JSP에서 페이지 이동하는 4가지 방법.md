1\. 페이지 이동

JSP에서 페이지 이동은 다양한 방법으로 구현할 수 있는데 여기에서는 가장 일반적으로 사용되는 두 가지 방법, 리다이렉트(Redirect)와 포워딩(Forwarding)을 소개한다. 그리고 Meta 태그로 이동하는 방법과 JavaScript를 사용하여 페이지 이동하는 방법을 다뤄보자.

2\. response.sendRedirect

리다이렉트는 클라이언트에게 새로운 URL로 이동하도록 요청하는 방법이다. 이를 통해 다른 JSP 페이지, HTML 파일 또는 외부 URL로 이동할 수 있다. 리다이렉트는 response.sendRedirect("이동할_페이지"); 메서드를 사용하여 구현할 수 있다.

​

response.sendRedirect를 이용하여 페이지를 이동하게 되면 HTTP 헤더 정보를 변경하여 redirect 시키기 때문에 브라우저의 주소창이 변경된다. sendRedirect가 실행되기 전 output 되는 코드들은 모두 실행되지 않으며 데이터를 공유할 수 없다.

<% if (obj == null) { response.sendRedirect("main.jsp"); } else { response.sendRedirect("login.jsp"); } %>

​

3\. forward

포워딩은 현재의 요청을 다른 JSP 페이지나 서블릿으로 전달하여 처리하도록 하는 방법이다. 클라이언트는 이 과정을 알지 못하며, 서버에서는 요청을 전달한 후 결과를 클라이언트에게 반환한다. 포워딩은 <jsp:forward> 액션 태그나 request.getRequestDispatcher("이동할_페이지").forward(request, response) 메서드를 사용하여 구현할 수 있다.

​

서버에서 바로 main.jsp로 이동하기 때문에 데이터를 공유할 수 있으며 브라우저 주소창이 바뀌지 않는다.

<% if (ojb == null) { %> <jsp:forward page="main.jsp"/> <% } else { %> <jsp:forward page="login.jsp"/> <% } %>

​

4\. meta 태그 이용

HTML의 `<head>` 태그 내에서 Meta 태그를 사용하여 페이지 이동을 구현할 수 있다. 이 방법은 일정 시간이 지난 후에 자동으로 페이지를 이동하도록 설정하는 방법이다. 

​

meta 태그를 이용하여 페이지를 이동한다. 1초 후에 입력한 main.jsp로 이동한다.

<META http-equiv="refresh" content="1;url=main.jsp">

​

5\. JavaScript를 이용

JavaScript를 사용하여 동적으로 페이지 이동할 수 있다. window.location.href 속성을 사용하여 새로운 URL로 이동하도록 JavaScript를 작성한다. location.href, location.replace에 주소를 설정하면 클라이언트에서 주소를 다시 요청한다.

<% if (ojb == null) { %> <script> location.href = "main.jsp"; </script> <% } else { %> <script> window.history.back(); </script> <% } %>

​

6\. 결론

페이지 이동은 클라이언트에게 다른 페이지를 표시하거나 작업을 전달하기 위해 사용됩니다. 리다이렉트는 클라이언트의 주소 표시줄이 변경되고 새로운 요청이 전송되는 반면, 포워딩은 클라이언트가 이를 인식하지 못하고 요청이 서버에서 처리되는 것처럼 보입니다. 페이지 이동 방법은 사용 목적에 따라 선택하면 됩니다.
