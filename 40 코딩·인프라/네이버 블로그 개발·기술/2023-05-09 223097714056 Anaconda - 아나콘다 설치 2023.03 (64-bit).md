1\. 아나콘다 개요

Anaconda는 Python 언어를 이용한 프로젝트 수행 시 필요한 환경을 구성해 주기 위한 통합 프로그램이다. Anaconda는 데이터 과학 및 기계 학습을 위한 오픈 소스 플랫폼입이다. 파이썬 기반으로 만들어져 있으며, 데이터 분석 및 시각화, 머신러닝, 딥러닝 등 다양한 분야에서 사용된다. Anaconda는 단일 시스템에서 Python 데이터 과학 및 기계 학습을 수행하는 가장 쉬운 방법을 제공한다.

​

Anaconda에는 파이썬 프로그래밍 언어와 함께 데이터 과학을 위한 다양한 라이브러리와 도구가 포함되어 있다. 이를 통해 데이터 처리 및 분석 작업을 보다 쉽고 빠르게 할 수 있다. 또한, Anaconda는 패키지 관리자인 conda를 통해 패키지 설치 및 관리를 지원한다. 이를 통해 파이썬 패키지들의 버전 관리와 의존성 관리를 쉽게 할 수 있다. 데이터 과학자들이나 머신러닝 개발자들에게 매우 인기 있는 플랫폼 중 하나이다.

3\. 아나콘다 설치

다운로드한 "Anaconda3-2023.03-1-Windows-x86_64.exe" 설치 파일을 실행한다.

![](https://postfiles.pstatic.net/MjAyMzA1MDlfOTEg/MDAxNjgzNjM0NjU2NDMx.RAX2ClmnXw06o2qUhBBAWx444SOVwxsCp2i4DSA2mK0g.zoI4xW7F2fEDAc0Rzz-pUfvACdnrVi9dJTfBRFtES4cg.PNG.agapeuni/image.png?type=w80_blur)

내려받은 파일을 실행해 Anaconda 설치를 시작한다.

"Next" 버튼을 클릭.

![](https://postfiles.pstatic.net/MjAyMzA1MDlfNjUg/MDAxNjgzNjM0NzAwMDc3.K3uqlaTPHmbDRXIJAWNhO3mZvLbWJvCCP24PCbznI74g.kqeVLXx7bGaVRFpuwzkfvY5dd8Bj5nq0E4lTduHOjKcg.PNG.agapeuni/image.png?type=w80_blur)

Anaconda를 설치하기 전에 라이선스 조건을 검토 "I Agree" 버튼을 클릭해 동의한다.

![](https://postfiles.pstatic.net/MjAyMzA1MDlfMTEx/MDAxNjgzNjM0NzExNzk5.d-t0loOZyxfPqfN7F6Sptv0hgILNwzgr3K3uAbtw2T4g.7IvaSE3wtGM6ettJZphEfAZTKc8crvCJbMwBnuTyFtIg.PNG.agapeuni/image.png?type=w80_blur)

**3단계. Select Installation Type**

Anaconda 설치 유형에 관한 내용이다.

"Just Me"를 추천하고 있으니 그냥 "Next" 버튼을 클릭.

![](https://postfiles.pstatic.net/MjAyMzA1MDlfMjIy/MDAxNjgzNjM0NzI1NjQy.F4NjsGqcKdzqLXhYopu853kWiq6VVC1ZZH6DooTe3vQg.Cz1fx89JNo6xnipCBwt12rzGoN3p80asUYTql4lTCggg.PNG.agapeuni/image.png?type=w80_blur)

​

**4단계. Choose Install Location**

설치 위치를 선택하는 화면이다. 설치 프로그램은 "Destination Folder"에 Anaconda를 설치한다.

C 드라이브의 부담을 덜어주기 위해 보통 개발과 관련된 툴은 D 드라이브에 설치한다.

​

"D:\dev\anaconda" 폴더를 선택하고 "Next" 버튼을 클릭.

주의사항 : 공백이나 유니코드 문자가 포함되지 않은 폴더에 Anaconda를 설치해야 한다.

![](https://postfiles.pstatic.net/MjAyMzA1MDlfMjA2/MDAxNjgzNjM0NzcxNDEw.Ke2RiUZE-T8BeHQvNoVm46MgvYETmPfMYXQL0vFmneQg.XacHSc2GpJKVepRC9cQ-PEsI3WmLCitAV7u-gYhO_hwg.PNG.agapeuni/image.png?type=w80_blur)

​

​

**5단계. Advanced Installation Options**

고급 설치 옵션에 관한 내용이다.

​

"Register DS_Anaconda3 as my Python 3.10"을 선택하고 "Install" 버튼을 클릭하면 설치를 시작한다. "Register DS_Anaconda3 as my Python 3.10"을 선택하면 Anaconda의 Python을 환경 변수에 추가한다. 이 옵션을 선택하면 Python 도구, PyCharm, Wing IDE, PyDev 및 MSI 바이너리 패키지와 같은 다른 프로그램이 시스템에서 Anaconda의 Python을 기본 Python으로 자동 감지할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA1MDlfMTQx/MDAxNjgzNjM0ODEyODQz.caVnU7ENwiCVaiLQDnhKes35Io1up4rR2Zxi6bdtr30g.1k4DgQ6dqqo1nYYfs_8GCXE5PeRMUKAkunSZI4kIyk4g.PNG.agapeuni/image.png?type=w80_blur)

​

​주의사항 : 다른 소프트웨어를 방해할 수 있으므로 Anaconda를 PATH 환경 변수에 추가하지 않는 것이 좋다.

"Add Anaconda3 to my PATH environment variable"을 선택하면 Anaconda를 환경 변수에 추가한다. 이 옵션을 사용하면 이전에 설치된 Python 보다 먼저 Anaconda를 찾을 수 있지만, Anaconda를 제거하고 다시 설치해야 하는 문제가 발생할 수 있어 권장하지 않는다.
