# 2014-06-30 220046141434 라즈베리 파이 - 손바닥 위 작은 컴퓨터 (Model B)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220046141434&categoryNo=982
- 게시일: 2014. 6. 30. 22:08

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMjUg/MDAxNzU4NDM2OTAzMTIy.rMPqNVnweIA9vwWUTk3kD39hSSEx8kBg9k0JTJcPD9og.5NzpWiNsD5K0Ab1YJfqd4rbSl2_pNHKANjylMYFkY1gg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001.png?type=w80_blur)

**​**

라즈베리 파이(Raspberry Pi)는 신용카드 크기의 작은 컴퓨터로, 영국의 라즈베리 파이 재단에서 개발한 저렴하고 강력한 개방형 싱글 보드 컴퓨터입니다. 주로 교육 및 개인 프로젝트에 활용되며, 다양한 운영 체제를 지원합니다. 라즈베리 파이는 일반적인 컴퓨터와 비슷한 구조를 가지고 있으며, 프로세서, 메모리, 입출력 포트 등을 내장하고 있습니다. 일반적으로 HDMI 포트를 통해 모니터와 연결하고, USB 포트를 통해 키보드, 마우스 등의 주변기기를 연결할 수 있습니다.

​

개인적인 호기심을 충족하면서 앞으로 재미있고 즐거운 여러 실험을 해보기 위해 라즈베리 파이 Model B를 하나 구매하였습니다. 아래의 공식 사이트에 가보면 보다 자세한 정보를 볼 수가 있습니다.

URL : <http://www.raspberrypi.org/>

![](https://postfiles.pstatic.net/MjAyMzA2MjdfMTg1/MDAxNjg3ODc1NTUwMzI1.oYxx6j4AllnVJtT5IIncQdrtbJggMFM08MxVvL2r2zAg.OmLQ5p4wSqhC4nP3UTZWq4W14WwJRq55RtgAf7f77Bcg.PNG.agapeuni/image.png?type=w80_blur)

​

가격은 모델 A는 25달러, 모델 B는 35달러인데 10달러를 더 주고서 이더넷 포트가 있는 모델 B를 구매하는 것이 좋습니다. 모델 B에는 모델 A와는 다르게 USB 포트가 1개 더 있고 네트워크를 할 수 있는 이더넷 포트가 있습니다. USB 포트를 이용해서 무선 네트워크를 이용할 수도 있지만 LAN 케이블을 사용해서 네트워크를 사용하는 경우가 자주 있습니다. 모델 B는 국내에서는 5만 원 정도에 구매할 수 있습니다. 

![](https://postfiles.pstatic.net/20140630_123/agapeuni_14041336133051cPns_JPEG/pi_model_a26b.jpg?type=w80_blur)

**▲ Raspberry Pi - 모델 A와 모델 B의 모습 ▲**

인터넷에서 구매를 하고 집에 도착한 택배를 열어보면 아래의 그림처럼 "Getting Started"라는 문구와 라즈베리 파이 URL이 적혀있는 박스 하나 달랑 들어있습니다. 안전한 배송을 위한 뽁뽁이와 파이가 담겨있는 박스 이외에는 다른 것은 아무것도 없어서 뭔가 부족해 보입니다. 

![](https://postfiles.pstatic.net/20150605_245/agapeuni_1433461779302tvmvC_JPEG/20140412_120656.jpg?type=w80_blur)

박스를 열어보면 신용카드 크기 정도의 라즈베리 파이의 몸체가 들어있습니다. 어찌나 아담하고 작은 크기인지 손바닥 위해 놓으니 참 귀엽기까지 하더군요. 크기의 비교를 위해 운전면허증과 같이 찍어 보았습니다. 

![](https://postfiles.pstatic.net/20150605_63/agapeuni_1433461787643paBpn_JPEG/20140412_120933.jpg?type=w80_blur)

​

라즈베리 파이는 교육적인 목적부터 IoT 프로젝트, 멀티미디어 장비, 홈 오토메이션 시스템 등 다양한 분야에서 사용되며, 소형이지만 강력한 컴퓨팅 능력을 제공합니다. 이렇게 작은 크기의 보드가 다양한 기기와 연결 가능하고 운영체제까지 설치할 수 있다는 게 신기할 따름입니다. 앞으로 당분간은 이 녀석과 재미있는 시간을 보내게 될 거 같네요. 개인적으로 라즈베리 파이와의 첫 만남은 좋은 인상을 남겼습니다.
