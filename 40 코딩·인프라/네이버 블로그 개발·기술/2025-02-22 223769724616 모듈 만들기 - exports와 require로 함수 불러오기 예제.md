1\. 개요

Node.js는 모듈 시스템을 기반으로 구성되어 있으며, exports와 require를 이용하여 코드의 재사용성과 유지보수성을 높일 수 있다. 특정 기능을 독립된 파일로 분리하고, 해당 기능을 외부에서 사용할 수 있도록 내보내는 방식으로 모듈을 정의할 수 있다. 이러한 방식은 대규모 프로젝트에서 코드의 가독성과 효율적인 관리에 큰 도움이 된다.

​

Node.js에서 exports와 require를 사용해서 모듈을 구성할 수 있다. 독립적이며 재사용 가능한 기능 단위로 만들 수 있다. exports 객체에 속성이나 메서드를 정의하여 모듈을 만들고 requeire() 함수를 사용하여 외부 모듈을 불러온다.

​

​

2\. 예제

모듈을 정의하기 위해서는 exports 객체를 활용하여 함수나 속성을 외부에 노출시킨다. 다음은 사칙연산 기능을 각각의 함수로 정의하고 exports를 통해 내보낸 예제이다. 모듈로 만들려고 하는 js 파일에 함수를 정의하고 참조 변수 앞에 exports를 붙임으로 정의된 함수를 내보낼 수 있다. add 함수와 sub 함수, mul 함수와 div 함수를 모두 exports 한다.

​

파일 : 12-exports.js

/** exports */ exports.add = function(x, y) { x = parseInt(x); y = parseInt(y); return x + y; }; exports.sub = function(x, y) { x = parseInt(x); y = parseInt(y); return x - y; }; exports.mul = function(x, y) { x = parseInt(x); y = parseInt(y); return x * y; }; exports.div = function(x, y) { x = parseInt(x); y = parseInt(y); return x / y; };

​

"12-require.js" 파일에서 exports를 정의한 "12-exports.js" 파일을 require() 함수를 사용해서 로드한다.

require로 파일을 기술할 때 현재의 폴더에 있으면 './'를 추가해 준다. 파일명에서 '. js'는 생략 가능하다.

​

참고로 특정 폴더에 있으면 폴더명을 같이 기재하면 모듈을 사용할 수 있다.

참고로 파일을 'index.js'로 작성하면 모듈을 불러올 때 폴더명만 기재하면 된다.

​

"12-exports.js" 에서 정의한 함수들을 mod 참조 변수를 통해 다음과 같이 사용할 수 있다.

​

파일 : 12-require.js

/** require */ var mod = require('./12-exports.js'); console.log("mod.add(100, 10) = " + mod.add(100, 10)); console.log("mod.sub(100, 10) = " + mod.sub(100, 10)); console.log("mod.mul(100, 10) = " + mod.mul(100, 10)); console.log("mod.div(100, 10) = " + mod.div(100, 10));

실행 결과

mod.add(100, 10) = 110 mod.sub(100, 10) = 90 mod.mul(100, 10) = 1000 mod.div(100, 10) = 10

​

3\. 예제

다음과 같이 내부에서 사용하는 함수명과 다르게 exports를 사용할 수도 있다.

​

파일 : 13-exports.js

/** exports */ const msg = 'Hello Node.js'; const firstFunc = () => { console.log("First") } const secondFunc = () => { console.log("Second") } module.exports = { hello: msg, first: firstFunc second: secondFunc }

​

다음과 같이 require() 함수로 모듈을 불어오면 참조변수 없이 바로 사용할 수 있다.

​

파일 : 13-require.js

/** require */ const { hello, first, second } = require("./13-exports"); console.log(hello); first(); second();

실행 결과

Hello Node.js First Second
