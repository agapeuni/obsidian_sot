## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMzAg/MDAxNzU4NDQzNjk0OTUz.tbslO01gMLqaFKtXjY3GLN7qMSdZjdevmTNvQFKpxsog.9ANKohmtlyN5jVGVhCw68InwXrMyvC9L4Pk-jxkmP4Yg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(9\).png?type=w80_blur)

​

MongoDB는 대표적인 NoSQL이며 JSON 형식으로 데이터를 저장하고 SQL과 유사한 쿼리로 수행 가능한 문서 지향 데이터베이스입니다. 이전 MariaDB에 이어서 이번에는 라즈베리 파이에 MongoDB를 설치합니다.

​

원격으로 연결한 뒤 아래의 명령어로 MongoDB를 설치합니다. 

약간의 시간 뒤에 "Do you want to continue? [Y/n]" 가 표시되면 y를 입력합니다.

**$ sudo apt-get install mongodb-server**

![](https://postfiles.pstatic.net/MjAxOTA5MDhfMjQ4/MDAxNTY3ODg3OTkyMTQ5.UR5y264QaU1_pU6dpzABd3K0k4ESY8ZS-58-EhXPjKcg.3gBD8SysUEw1dfkgbhHjD4wcYTstY6M05R5Rl_OqTXwg.PNG.agapeuni/20190908_001921.png?type=w80_blur)

**​**

![](https://postfiles.pstatic.net/MjAxOTA5MDhfNTkg/MDAxNTY3ODg3OTkyNjAx.70h-j8I3xxRMEkN_2lvtbDbGIUTOPeCP_Fah8OVsVZ0g.keDLIYlezGT23Kvz9fVRuPqzHfrF20lEyVLR4bJObfQg.PNG.agapeuni/20190908_001943.png?type=w80_blur)

설치가 완료되면 아래의 명령어로 설치된 버전을 확인할 수 있습니다. 

**$ mongo --version**

**$ mongod --version**

​

그런데 mongo를 입력하면 접속이 되지 않고 아래의 메시지가 표시됩니다. 

설치가 완료된 후에 외부에서도 접속할 수 있도록 설정을 해야 합니다.

Error : couldn't connect to server 127.0.0.1:27017 at src/mongo/shell/mongo.js:145

![](https://postfiles.pstatic.net/MjAxOTA5MDhfMjA4/MDAxNTY3ODg3OTkyOTc4.eeU7BIA_c9tY_yh1U_hhIx-njXWx8LV4UtNBpI85qFkg.7yYGIBsE34QjU6NgsQPlq1NIqH6JGBIrn9Or99RHmf0g.PNG.agapeuni/20190908_052329.png?type=w80_blur)

nano 에디터로 "mongodb.conf" 파일의 설정 정보를 수정합니다. 

**$ sudo nano /etc/mongodb.conf -l**

​

11번 라인의 bind_ip = 127.0.0.1 앞에 주석(#)을 입력하고 저장합니다.

참고로 dbpath가 /var/lib/mongodb로 잡혀있네요.

![](https://postfiles.pstatic.net/MjAxOTA5MDhfMjU0/MDAxNTY3ODg3OTkzMzg0.L-nKCkEWie8AdLLwHHmdQo04_eq7HbH2HeLe1ILoY9gg.iqZ2NYNffmAeWhXtHTIFW7EOVqpzuCF-OoczO2QsNK8g.PNG.agapeuni/20190908_031740.png?type=w80_blur)

​

그러고 나서 mongodb 서비스를 재시작합니다. 

**$ sudo service mongodb restart**

​

재시작 후에 혹시나 해서 수리를 위해 repair 옵션을 실행해 보았습니다. dbpath를 지정해 주지 않았네요. ㅎㅎ

**$ sudo mongod --repair**

​

*********************************************************************

ERROR: dbpath (/data/db/) does not exist.

Create this directory or give existing directory in --dbpath.

See <http://dochub.mongodb.org/core/startingandstoppingmongo>

*********************************************************************

![](https://postfiles.pstatic.net/MjAxOTA5MDhfNzUg/MDAxNTY3ODg3OTkzODkz.mxhkiBUq61E4k2W_uNEYHGXTWVdKlkVWGPGsZDqC8AIg.SZ6H4YiYTIMWQJJ5ShWqj2v0G1SYTKaJ1uvIXJ2LDS8g.PNG.agapeuni/20190908_034152.png?type=w80_blur)

임시로 /home/pi/mongodb 디렉터리를 생성하고 다음의 명령어로 mongod를 실행합니다.

**$ sudo mongod --dbpath /home/pi/mongodb/**

​

다음의 오류가 표시되면 --journal 옵션을 추가한다.

32-bit servers don't have journaling enabled by default. Please use --journal if you want durability.

**$ sudo mongod --journal --dbpath /home/pi/mongodb/**

![](https://postfiles.pstatic.net/MjAxOTA5MDhfMTc2/MDAxNTY3ODg3OTk0MzYx.sXCBpkGNGUMF6jzvOydaQxeKmKp61d_oxT17GF6xTv4g.QsbOaUkP3Uh6PX5Wr6_WmJqzim_-xNFupVat8au90dkg.PNG.agapeuni/20190908_052607.png?type=w80_blur)

다른 터미널을 새로 열어 mongo를 입력하여 MongoDB Shell에 접속합니다.

동작 확인을 위해 test DB를 만들로 member 컬렉션을 만들고 조회해 보았습니다.
