# 2025-04-16 223835574460 PL SQL - PL SQL 제어문과 반복문의 이해

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfMTIz/MDAxNzQ0Nzc4MTQyNDE3.mhIWrndjY2dMAawXDG5DJEzSLIz5tqhRWtcLEEuk4MAg.In72amJaAoyEzuWh5MgPgON_5LJdCEnC4u1BjlnWSE0g.PNG/PL_SQL-001_\(7\).png?type=w80_blur)

​

Oracle의 PL/SQL은 절차적 언어로서, 다양한 제어 구조를 통해 복잡한 로직을 구현할 수 있다. 그중에서도 IF 문, LOOP 문은 가장 기본적이면서도 중요한 구조다. 본 글에서는 조건문과 반복문을 중심으로 PL/SQL의 핵심 제어 흐름에 대해 살펴보고자 한다.

**​**

**​**

**1\. IF 문**

IF 문은 조건에 따라 특정 구문을 실행할 수 있도록 하는 제어 구조입니다. 기본 형태는 다음과 같다.

IF (조건) THEN \-- 조건이 참일 경우 실행 ELSE \-- 조건이 거짓일 경우 실행 END IF; 

**​**

**예제 코드**

DECLARE i NUMBER := 0; BEGIN IF i = 0 THEN DBMS_OUTPUT.PUT_LINE('i = 0'); ELSE NULL; END IF; END; / 

**​**

**​**

**2\. 중첩 IF 문**

IF 문은 다른 IF 문 안에 중첩하여 사용할 수 있다. 여러 조건을 순차적으로 평가해야 할 경우 유용하다.

IF (조건1) THEN IF (조건2) THEN \-- 조건1, 조건2 모두 참일 경우 ELSE IF (조건3) THEN \-- 조건3만 참일 경우 ELSE \-- 모든 조건이 거짓일 경우 END IF; END IF; END IF; 

복잡한 중첩 구조는 가독성을 떨어뜨릴 수 있으므로, 다음에서 설명할 ELSIF 문을 사용하는 것이 더 권장된다.

**​**

**​**

**3\. IF...ELSIF 문**

ELSIF 문은 중첩 IF 구조를 간결하게 표현할 수 있게 해준다. IF와 END IF는 한 번만 사용되며, 여러 조건을 연속적으로 평가할 수 있다.

IF (조건1) THEN \-- 조건1이 참일 경우 ELSIF (조건2) THEN \-- 조건2가 참일 경우 ELSIF (조건3) THEN \-- 조건3이 참일 경우 ELSE \-- 모든 조건이 거짓일 경우 END IF; 

​

**예제 코드**

DECLARE v_Score NUMBER := 85; v_Grade CHAR(1); BEGIN IF v_Score >= 90 THEN v_Grade := 'A'; ELSIF v_Score >= 80 THEN v_Grade := 'B'; ELSIF v_Score >= 70 THEN v_Grade := 'C'; ELSIF v_Score >= 60 THEN v_Grade := 'D'; ELSE v_Grade := 'E'; END IF; DBMS_OUTPUT.PUT_LINE('Grade is ' || v_Grade); END; / 

​

**​**

**4\. FOR LOOP 문**

FOR LOOP는 지정된 범위 내에서 반복적으로 코드를 실행한다.

FOR 변수 IN [REVERSE] 시작값..끝값 LOOP \-- 실행할 구문 END LOOP; 

**​**

**예제 코드**

BEGIN FOR v_outer IN 1..2 LOOP FOR v_inner IN 1..4 LOOP DBMS_OUTPUT.PUT_LINE( 'Outer Loop: ' || v_outer || ', Inner Loop: ' || v_inner); END LOOP; END LOOP; END; / 

**​**

**​**

**5\. WHILE LOOP 문**

WHILE 문은 주어진 조건이 참인 동안 반복된다. 조건이 처음부터 거짓이라면, 한 번도 실행되지 않을 수 있다.

WHILE (조건) LOOP \-- 반복 실행할 구문 END LOOP; 

**예제 코드**

DECLARE v_Cnt NUMBER := 0; BEGIN WHILE v_Cnt <= 10 LOOP v_Cnt := v_Cnt + 1; DBMS_OUTPUT.PUT_LINE('The Value of v_Cnt is ' || v_Cnt); END LOOP; END; / 

​

**​**

**6\. EXIT 및 EXIT WHEN 문**

LOOP를 중간에 종료하고자 할 때 사용하는 명령어다.

  * EXIT : 조건과 무관하게 즉시 루프를 빠져나온다.

  * EXIT WHEN : 특정 조건이 참이 되었을 때 루프를 종료한다.

​

**예제 코드 1 (EXIT 사용)**

DECLARE v_Cnt NUMBER := 1; BEGIN WHILE TRUE LOOP DBMS_OUTPUT.PUT_LINE('v_Cnt is ' || v_Cnt); IF v_Cnt = 10 THEN EXIT; END IF; v_Cnt := v_Cnt + 1; END LOOP; END; / 

​

**예제 코드 2 (EXIT WHEN 사용)**

DECLARE v_Cnt NUMBER := 1; BEGIN WHILE TRUE LOOP DBMS_OUTPUT.PUT_LINE('v_Cnt is ' || v_Cnt); EXIT WHEN v_Cnt = 10; v_Cnt := v_Cnt + 1; END LOOP; END; / 

​

**​**

**7\. 단순 LOOP**

단순 LOOP는 별도의 종료 조건 없이 무한 반복된다. 반드시 EXIT 또는 EXIT WHEN을 통해 종료 조건을 명시해야 한다.

**​**

**예제 코드**

DECLARE v_Cnt NUMBER := 1; BEGIN LOOP DBMS_OUTPUT.PUT_LINE('v_Cnt is ' || v_Cnt); EXIT WHEN v_Cnt = 10; v_Cnt := v_Cnt + 1; END LOOP; END; / 

​

이와 같이 PL/SQL에서는 다양한 제어문을 통해 조건 분기와 반복 처리를 효율적으로 수행할 수 있다. 실제 실무에서도 매우 자주 활용되는 문법이므로, 각 구조의 형태와 특징을 정확히 이해하고 직접 코드를 작성해보는 것이 중요하다.
