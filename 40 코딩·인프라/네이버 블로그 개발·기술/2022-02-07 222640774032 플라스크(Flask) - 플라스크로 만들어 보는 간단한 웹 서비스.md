1\. 플라스크 개요

플라스크(Flask)는 단순하고 유연하여 웹 프로그래머가 파이썬으로 처음 시작하기에 적합한 프레임워크다. 마이크로 웹 프레임워크인 Flask에는 템플릿 엔진(Jinja)과 WSGI toolkit(Werkzeug) 라이브러리가 내장되어 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMDdfNDgg/MDAxNjQ0MTc2MzAzNTY0.1RYcBsS2WO8X7wNyeWmXnHitNGQDMyLeYCQ9HVQY19Yg.GmuNgYkRxffqJe3e1eExP5v3VYj_3hCBDdCe25TWhjcg.PNG.agapeuni/1.png?type=w80_blur)

플라스크(Flask)는 파이썬으로 작성된 마이크로 웹 프레임워크이다. 웹 서비스 및 웹 API를 포함한 웹 애플리케이션 개발을 지원한다.

​

2\. 설치

아래의 명령어로 플라스크(Flask)를 설치하고 "Hello World" 웹 프로그램을 시작해보자.

﻿$ pip install flask

3\. __init__.py 작성

hellowwold 폴더를 생성하고 폴더에서 __init__.py 파일을 만든다.

![](https://postfiles.pstatic.net/MjAyMjAyMDdfNDMg/MDAxNjQ0MTc2NTE5NjM3.NN0WDvk42E97rw7JIMhPBF7tYtkCpomrUyql1a1FLewg.iokElruxWFwYZ3rlghb92kd7OuS1GPFDL6wPyUTgcUUg.PNG.agapeuni/2.png?type=w80_blur)

flask 모듈을 임포트하고 Flask 앱을 실행하고 구성하는 데 사용하는 Flask 객체를 포함하는 변수를 선언한다. route() 데코레이터를 사용하여 URL 요청에 대해 서비스할 함수를 정의한다.

from flask import Flask app = Flask(__name__) @app.route('/') def hello_world(): return 'Hello, World!' if __name__ == "__main__": app.run(debug=True, port=8080)

​

4\. app.py 작성

app.py 파일을 helloworld 폴더 위에 만든다.

helloworld 폴더안의 __init__.py 에서 선언한 app 변수를 사용하여 run 메소드를 실행한다.

from helloworld import app if __name__ =="__main__": app.run(host="0.0.0.0", debug=True, port=8080)

5\. HTML 표시

이번에는 단순 문자열이 아닌 HTML 코드를 화면에 표시해보자. @app.route("/info")을 새롭게 추가하고 user 딕션너리를 만들어 이름과 나이를 정의한다. user 딕셔너리에 정의되어 있는 값을 사용하여 HTML 테그안에 텍스트로 출력한다.

from flask import Flask app = Flask(__name__) @app.route('/') def hello_world(): return 'Hello, World!' @app.route('/info') def greet(): user = {'name': 'OneWay', 'age': "28"} return ''' <html> <head> <title>Name</title> </head> <body> <h1>Hello, ''' + user['name'] + '''!</h1> <h2>you’re ''' + user['age'] + ''' years old.</h2> </body> </html>''' if __name__ == '__main__': app.run(host="0.0.0.0", debug=True, port=8080)

6\. render_template()

Flask는 html 파일들을 렌더링할 수 있도록 'render_template'를 제공한다. Jinja2 템플릿 엔진을 사용하여 웹 페이지를 동적으로 생성할 수 있다. 화면을 HTML 코드로 표시하고 있지만 HTML 코드가 Python 소스에 있어 변경할 때마다 소스를 수정해야 한다. HTML 파일을 별도로 만들어 Jinja2 템플릿 엔진으로 처리해 보자. 그리고 @app.route('/hello')를 추가하고 index.html을 render_template() 함수로 담아둔다.

from flask import Flask, render_template app = Flask(__name__) @app.route('/') def hello_world(): return 'Hello, World!' @app.route('/info') def greet(): user = {'name': 'OneWay', 'age': "28"} return ''' <html> <head> <title>Name</title> </head> <body> <h1>Hello, ''' + user['name'] + '''!</h1> <h2>you’re ''' + user['age'] + ''' years old.</h2> </body> </html>''' @app.route('/hello') def hello(): return render_template('index.html', name="OneWay") if __name__ == '__main__': app.run(host="0.0.0.0", debug=True, port=8080)

​

index.html 은 간단하다.

name 값에 유무에 따라 분기하여 표시한다. templates 폴더를 만들고 그 안에 index.html을 작성한다.

<html> <body> {% if name %} <h2>Hello {{ name }}.</h2> {% else %} <h2>Hello.</h2> {% endif %} </body> </html>

7\. static 폴더

HTML 페이지에 CSS 파일을 적용하기 위해서는 static 폴더를 이용한다.

​static/css/common.css

h2 { color: blueviolet; }  
---  
  
static/js/common.js

function btnCall() { alert("Button Call") }

​

마지막으로 CSS와 JS를 적용하기 위해 index.html 파일을 수정한다.

templates/index.html

<!DOCTYPE html> <html lang="ko"> <head> <meta charset="UTF-8" /> <meta name="viewport" content="width=device-width, initial-scale=1.0" /> <meta http-equiv="X-UA-Compatible" content="ie=edge" /> <title>Flask template2</title> <link href="{{url_for('static', filename = 'css/common.css')}}" rel="stylesheet" /> <script src="{{url_for('static', filename = 'js/common.js')}}"></script> </head> <body> {% if name %} <h2>Hello {{ name }}.</h2> {% else %} <h2>Hello.</h2> {% endif %} <button onclick="btnCall()">Button</button> </body> </html>

​

CSS가 적용되어 글자 색상이 보라색으로 변경되었고 버튼에 적용된 JavaScript 함수가 정상적으로 호출되었다.
