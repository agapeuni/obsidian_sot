**1\. 개요**

Node.js의 내장 모듈인 fs(File System)을 활용하여 파일을 생성하고 내용을 기록한 후, 해당 파일의 존재 여부를 확인하고 내용을 읽어오는 과정을 소개한다. 이를 통해 기본적인 파일 처리 기능을 이해할 수 있다.

​

Node.js에서 fs 모듈을 사용하여 파일을 읽고 써보자. 그리고 파일과 경로의 존재여부를 확인해 본다.

​

​

**2\. 사용법**

fs.writeFile() 함수는 지정한 파일에 문자열 데이터를 기록할 수 있는 함수이다. 

아래는 간단한 텍스트 파일을 생성하는 코드이다.

/** fs : FileSystem */ var fs = require('fs'); var filename = "hello-file.txt"; fs.writeFile(filename, 'This is text file. Hello, Node.js', 'utf8', function(err) { if (err) { throw err; } console.log(filename + ' writeFile OK'); });

**​**

**결과화면**

> node ex_fs_write.js hello-file.txt writeFile OK 

해당 코드를 실행하면 hello-file.txt 파일이 생성되고, 파일 안에는 "This is text file. Hello, Node.js"라는 문자열이 저장된다. 파일을 열어보면 작성한 내용이 올바르게 기록되어 있음을 확인할 수 있다.

​

hello-file.txt 파일을 열어보면 코드에서 기록한 내용이 잘 저장되어 있다.

![](https://postfiles.pstatic.net/MjAyNTA0MjBfNDEg/MDAxNzQ1MTUzNTgxMzcy.o7YHJa5PMVML8EwyTEyFQY4KSpvN6UkxCXx9kPh4Ef4g.vcEexjUAxDHucsNmmLiDZwGyR4DVQ1CepOrhR-bBMUcg.PNG/img1.daumcdn.png?type=w80_blur)

​

다음 코드는 파일의 존재 여부를 확인하고, 존재할 경우 내용을 읽어 출력하는 예제이다. fs.exists() 함수로 파일이나 디렉토리의 존재 여부를 확인하고, fs.readFile()로 파일의 내용을 비동기 방식으로 읽어온다.

/** fs : FileSystem */ var fs = require('fs'); var filename = "hello-file.txt"; fs.exists(filename, function(isExists) { console.log(filename + (isExists ? " -- Exist. " : " -- None.")); if (isExists) { fs.readFile(filename, 'utf8', function(err, data) { if (err) { throw err; } console.log(filename + ' readFile OK'); console.log(data); }); } }); fs.exists('C:\Temp', function(isExists) { console.log("C:\\\Temp " + (isExists ? " -- Exist. " : " -- None.")); });

​

**결과화면 (파일이 없을때)**

파일이 없어서 -- None.으로 표시.

C:\Temp 경로는 존재함으로 -- Exist 로 표시.

> node ex_fs_read.js hello-file.txt -- None. C:\Temp -- Exist.

**결과화면 (파일이 있을때)**

hello-file.txt 파일이 존재하여 -- Exist 표시.

C:\Temp 경로도 존재하여 -- Exist가 바로 표시.

hello-file.txt 파일을 읽은 내용을 비동기 방식으로 출력.

> node ex_fs_read.js hello-file.txt -- Exist. C:\Temp -- Exist. hello-file.txt readFile OK This is text file. Hello, Node.js
