# 2025-05-03 223854462177 PL SQL - Collection 개념 및 실용적 활용

## 본문

​

Oracle PL/SQL에서는 여러 개의 데이터를 하나의 논리적 단위로 묶어 관리할 수 있는 기능으로 Collection(컬렉션)을 제공한다. 이는 일반적인 프로그래밍 언어에서의 배열(Array)과 유사한 개념이며, 데이터를 순차적으로 저장하거나 반복적으로 처리하는 데 있어 매우 유용하다.

**​**

Oracle PL/SQL의 컬렉션 기능은 데이터베이스 내에서 복잡한 데이터 구조를 효율적으로 처리할 수 있게 해주는 강력한 도구이다. 업무 요구사항에 따라 연관 배열, 중첩 테이블, 가변 배열 중 적절한 구조를 선택하여 활용함으로써 코드의 효율성과 가독성을 높일 수 있다. 특히 PL/SQL 내에서 반복 처리, 조건 분기, 임시 저장소가 필요한 경우 컬렉션을 적절히 활용하면 복잡한 로직을 간결하게 구현할 수 있다.

​

PL/SQL에서 제공하는 컬렉션은 크게 세 가지 유형으로 구분된다.

  1. 연관 배열 (Associative Array, 이전 명칭: Index-by Table)

  2. 중첩 테이블 (Nested Table)

  3. 가변 배열 (VARRAY, Variable-Size Array)

​

**​**

**1\. 연관 배열 (Associative Array)**

연관 배열은 키와 값을 쌍으로 저장하는 자료구조로, 키로는 숫자형 또는 문자열형 값을 사용할 수 있다. 이 컬렉션은 메모리 내에서만 존재하며, SQL 문장에서는 직접적으로 사용할 수 없다. 하지만 PL/SQL 내부에서 데이터를 임시로 저장하고 반복 처리할 때 매우 유용하다.

**선언 예시**

TYPE population_type IS TABLE OF NUMBER INDEX BY VARCHAR2(64); country_population population_type; 

위의 예에서는 문자열을 키로 하여 인구 수를 저장하는 country_population 변수를 선언하였다. 이 변수에 값을 대입하거나 참조함으로써, 일종의 사전(dictionary) 구조로 활용할 수 있다.

​

**주요 메서드**

연관 배열은 다음과 같은 메서드를 통해 조작할 수 있다.

  * EXISTS(key) : 지정된 키가 존재하는지 확인한다.

  * DELETE(key) : 특정 키의 항목을 삭제하거나, 키를 생략하면 전체를 삭제한다.

  * FIRST / LAST : 배열의 첫 번째 및 마지막 키를 반환한다.

  * NEXT(key) / PRIOR(key) : 특정 키 기준 다음 또는 이전 키를 반환한다.

**​**

**사용 예시**

DECLARE TYPE population_type IS TABLE OF NUMBER INDEX BY VARCHAR2(64); country_population population_type; total NUMBER; BEGIN country_population('Greenland') := 100000; country_population('Iceland') := 750000; total := country_population('Greenland'); DBMS_OUTPUT.PUT_LINE('그린란드 인구: ' || total); END; / 

​

**2\. 중첩 테이블 (Nested Table)**

중첩 테이블은 연관 배열과 달리 SQL에서 컬럼 타입으로도 사용할 수 있는 컬렉션이다. 배열처럼 동작하지만, 요소의 삭제로 인해 인덱스가 비연속적으로 될 수 있다.

​

**선언 및 사용 예**

DECLARE TYPE number_table IS TABLE OF NUMBER; nums number_table := number_table(10, 20, 30, 40, 50); BEGIN nums.DELETE(3); -- 세 번째 항목 삭제 FOR i IN 1 .. nums.COUNT LOOP IF nums.EXISTS(i) THEN DBMS_OUTPUT.PUT_LINE('요소 ' || i || ': ' || nums(i)); END IF; END LOOP; END; / 

​

**3\. 가변 배열 (VARRAY)**

가변 배열은 요소의 개수가 제한되어 있는 컬렉션으로, 배열의 길이가 고정되어 있으며, 요소의 순서가 유지된다. SQL에서도 사용 가능하며, 정해진 개수만큼 데이터를 관리할 수 있는 장점이 있다.

​

**선언 및 사용 예**

DECLARE TYPE grade_array IS VARRAY(5) OF NUMBER; grades grade_array := grade_array(85, 90, 95); BEGIN FOR i IN 1 .. grades.COUNT LOOP DBMS_OUTPUT.PUT_LINE('점수 ' || i || ': ' || grades(i)); END LOOP; END; / 

**​**

**4\. 컬렉션 유형 간 비교**

**항목** |  **연관 배열 (Associative Array)** |  **중첩 테이블 (Nested Table)** |  **가변 배열 (VARRAY)**  
---|---|---|---  
인덱스 유형 |  문자열 또는 숫자 |  숫자 |  숫자  
최대 크기 제한 여부 |  없음 |  없음 |  있음  
초기 상태 |  비어 있음 |  NULL |  NULL  
SQL 사용 가능 여부 |  불가능 |  가능 |  가능  
요소 순서 보존 여부 |  보장되지 않음 |  보장되지 않음 |  보장됨  
  
**​**

**5\. 활용 예제: 직원 정보 관리**

다음 예제는 RECORD 타입과 연관 배열을 함께 활용하여, 여러 명의 직원 정보를 동적으로 저장하고 출력하는 방식이다.

DECLARE TYPE emp_record IS RECORD ( first_name VARCHAR2(50), last_name VARCHAR2(50), email VARCHAR2(100) ); TYPE emp_table_type IS TABLE OF emp_record INDEX BY BINARY_INTEGER; emp_table emp_table_type; BEGIN emp_table(1).first_name := 'YongWoon'; emp_table(1).last_name := 'Kang'; emp_table(1).email := 'tangamjaelt@korea.com'; DBMS_OUTPUT.PUT_LINE( '직원 1: ' || emp_table(1).first_name || ' ' || emp_table(1).last_name || ', 이메일: ' || emp_table(1).email ); END; / 

이 예제는 employees 테이블의 구조와 유사한 데이터를 메모리 내에서 다루는 데 활용할 수 있으며, 대량의 데이터를 임시 저장하거나 필터링 처리할 때 유용하다. 

​

컬렉션은 PIPELINED FUNCTION이나 BULK COLLECT와 같은 고급 기능과도 연계하여 사용할 수 있으므로, 이를 함께 익혀둔다면 더욱 성능 높은 PL/SQL 프로그램을 작성하는 데 도움이 될 것이다.
