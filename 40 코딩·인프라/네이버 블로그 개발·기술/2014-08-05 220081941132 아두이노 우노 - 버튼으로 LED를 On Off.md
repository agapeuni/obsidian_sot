# 2014-08-05 220081941132 아두이노 우노 - 버튼으로 LED를 On Off

- 게시일: 2014. 8. 5. 7:41

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTA3/MDAxNzU4NDI1ODQ4MTA3.-Lj1JbnAnq5nsWV2LN4H-iuqvlm5eLz_h5t02Tc52gQg.5nVTsmsNPt9wZRJDNNNDlSXoy6p4sbXkjQcUVG2BWYYg.PNG/%EC%95%84%EB%91%90%EC%9D%B4%EB%85%B8-%EC%9A%B0%EB%85%B8-001_\(7\).png?type=w80_blur)

​

**아두이노 우노**(Arduino UNO)에서 이번에는 간단한 실험을 해보겠습니다.

버튼을 누를 때 LED가 켜지고 버튼을 놓을 때 LED가 꺼지는 실험입니다.

![](https://storep-phinf.pstatic.net/james_special/original_22.png?type=p50_50)

이번 실험의 준비물은 아래와 같습니다. 

  * **아두이노 우노**(Arduino UNO)와 브레드보드

  * MM 점퍼선 3개

  * LED 1개

  * 버튼 1개

  * 220옴 저항 1개

  * 10K옴 저항 1개 

![](https://postfiles.pstatic.net/20160506_49/agapeuni_1462509302902mVFri_JPEG/20140804_092739.jpg?type=w80_blur)

이번에 회로 구성은 아래와 같이 LED와 버튼을 잘 연결하면 됩니다.

**아두이노 우노**(Arduino UNO) 2번 핀(입력)과 버튼을 연결하였고 3번 핀(출력)과 LED를 연결하였습니다. 

![](https://postfiles.pstatic.net/20160506_202/agapeuni_1462509303235xhLDi_JPEG/20140805_074523.jpg?type=w80_blur)

​

LED 캐소드(-)에는 220옴을 접지에 연결하고 애노드(+)에는 **아두이노 우노**(Arduino UNO) 3번 핀과 연결합니다.

![](https://postfiles.pstatic.net/20160506_147/agapeuni_1462509303674v9Tgi_JPEG/20140805_074625.jpg?type=w966)

버튼의 좌측 하단은 10K옴을 접지에 연결하고 우측 하단은 5V 전원에 연결합니다.

그리고 좌측 상단에는 **아두이노 우노**(Arduino UNO) 22번 핀과 연결합니다.

![](https://storep-phinf.pstatic.net/james_special/original_4.png?type=p50_50)

버튼을 클릭하면 하단에 연결된 5V의 전원이 화살표로 흘러서 **아두이노 우노**(Arduino UNO) 22번 핀의 입력으로 들어갑니다.

![](https://postfiles.pstatic.net/20160506_72/agapeuni_1462509303466foCcz_JPEG/20140805_074601.jpg?type=w966)

​

​

다음의 코드를 입력하고 **아두이노 우노**(Arduino UNO)에 업로드합니다.

![](https://postfiles.pstatic.net/20150605_7/agapeuni_1433466755050g5UGA_PNG/20140805_071243.png?type=w80_blur)

버튼을 클릭하면 LED 불이 들어옵니다. 

고휘도 LED라서 밝게 표시됩니다.
