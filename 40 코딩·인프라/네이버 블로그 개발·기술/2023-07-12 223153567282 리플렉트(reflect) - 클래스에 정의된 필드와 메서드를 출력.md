리플렉션(Reflection)는 자바에서 실행 중인 프로그램의 클래스, 인터페이스, 필드, 메서드 등에 대한 정보를 동적으로 얻고 조작할 수 있는 기능을 말한다. 리플렉션에 필요한 클래스는 java.lang.reflect 패키지를 통해 제공되며 정적인 코드에서는 알 수 없는 런타임 정보에 접근할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA3MTJfMjUg/MDAxNjg5MDk0NjEwMDgw.9LkVa_z61uMz7lB2S0N3JzxYqH0M_CnLo0KTUbO8VYUg.McUqk6l58LSZ4ygwalaioB7a7NbrDv0QSd9ja2c5Onog.PNG.agapeuni/javalang.png?type=w80_blur)

​

리플렉션을 사용하여 클래스에 정의된 필드와 메서드의 정보를 동적으로 얻을 수 있지만 리플렉션은 일반적으로 성능 저하와 보안 위험성을 동반하므로 신중하게 사용해야 한다. 실무에서 프레임워크를 구현할 때나 애플리케이션에서 동적으로 기능을 수행할 때 리플렉트를 사용하면 반복적인 코딩을 줄일 수 있다. 

​

1) 클래스(Class) 객체

Class.forName() 메서드를 사용하거나, 객체의 getClass() 메서드를 호출하여 클래스(Class)를 얻을 수 있다.

​

2) 필드(Field)와 메서드(Method)

Class 클래스의 다양한 메서드들을 사용하여 필드와 메서드의 배열을 가져올 수 있다. getDeclaredFields() 메서드를 사용하여 모든 필드를 가져올 수 있고, getDeclaredMethods() 메서드를 사용하여 모든 메서드를 가져올 수 있다.

​

3) 필드와 메서드의 이름(Name), 타입(Type), 접근 제어자(Modifier) 등의 정보

필드와 메서드의 이름은 Field와 Method 클래스의 getName() 메서드를 통해 얻을 수 있으며, 타입은 getType() 메서드를 통해 얻을 수 있다. 접근 제어자는 getModifiers() 메서드를 통해 얻을 수 있다.

​

4) 필드의 값을 읽거나 설정

필드의 값을 읽으려면 Field 클래스의 get() 메서드를 사용하고, 값을 설정하려면 set() 메서드를 사용한다.

​

5) 메서드 호출

메서드를 호출하려면 Method 클래스의 invoke() 메서드를 사용한다.

* * *

리플렉션을 확인해 보기 위한 예제 코드로 ClassInfo 클래스를 작성했다. ClassInfo 클래스에는 code, name 필드를 갖고 있고 각각의 필드를 반환하는 get 메서드가 있다. 클래스의 필드 및 메서드 정보를 표시해 주는 showParameters(), showDeclaredMethods(), showMethods() 메서드를 사용하여 어떻게 반환되는지 확인해 보자. 

![](https://postfiles.pstatic.net/MjAyMzA3MTJfMjQ3/MDAxNjg5MDg3NjE5MDcx.Srz04ejEA1Z-Mhe6JmYQ48KtlZUjWyGmQF4xwY9GR0wg.9Myt6Gw_RJdLlvbleQmMOJhmkpm8v93qc-ig7B2xMgsg.PNG.agapeuni/img.png?type=w80_blur)

**​**

**예제 코드 (ClassInfo.java)**

import java.lang.reflect.Field; import java.lang.reflect.Method; public class ClassInfo { public String code; public String name; public String getCode() { return code; } public String getName() { return name; } /** * Parameters */ public static void showParameters() { System.out.println("### Parameters ###"); try { Class clazz = Class.forName("ClassInfo"); Field[] fields = clazz.getDeclaredFields(); for (Field f : fields) { System.out.println(f.getName()); } } catch (Exception e) { e.printStackTrace(); } } /** * Methods */ public static void showMethods() { System.out.println("\n### Methods ###"); try { Class clazz = Class.forName("ClassInfo"); Method[] methods = clazz.getMethods(); for (Method m : methods) { System.out.println(m.getName()); } } catch (Exception e) { e.printStackTrace(); } } /** * Declared Methods */ public static void showDeclaredMethods() { System.out.println("\n### Declared Methods ###"); try { Class clazz = Class.forName("ClassInfo"); Method[] methods = clazz.getDeclaredMethods(); for (Method m : methods) { System.out.println(m.getName()); } } catch (Exception e) { e.printStackTrace(); } } public static void main(String[] args) { ClassInfo.showParameters(); ClassInfo.showDeclaredMethods(); ClassInfo.showMethods(); } }

​

클래스를 실행하면 콘솔 창에 아래와 같이 표시된다. 

선언된 메서드와 출력된 메서드를 확인해 보면 자신의 메서드뿐만 아니라 상속된 메서드도 같이 표시하고 있다.
