1\. Maven 개요

메이븐(Maven)은 아파치 소프트웨어 재단에서 제공하는 자바 프로젝트 빌드 도구이다. 개발 프로세스가 정의되어 있어 정형화된 기능의 반복 작업을 간소화할 수 있다. 플러그인을 확장하여 사용할 수 있고 라이브러리 간의 종속성을 해결하여 자동으로 다운로드한다. 다운로드한 라이브러리는 로컬 저장소에 저장한다. 

​

​

3\. POM(Project Object Model)

pom.xml 파일은 프로젝트를 관리하는 Maven의 설정 파일이다. 

pom.xml 파일 하나를 잘 작성해 프로젝트 환경을 구축하면 다른 개발자들에게 이 파일만 전달해 주면 된다. 

​

  * modelversion : pom 버전

  * artifactId : 프로젝트명

  * groupId : 프로젝트 패키지명

  * version : 프로젝트 버전

  * packaging : 패키징 타입

  * name : 프로젝트 표시명

  * url : 프로젝트 사이트의 URL

  * properties : pom에서 사용하는 속성을 정의

  * dependencies : 프로젝트에 의존하는 라이브러리 정보

​

​

간단한 POM이지만 주요한 핵심 요소들을 표시하고 있다.

<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd"> <modelVersion>4.0.0</modelVersion> <groupId>com.agapeuni</groupId> <artifactId>hello-maven</artifactId> <version>0.0.1-SNAPSHOT</version> <name>my-app</name> <url>http://www.example.com</url> <properties> <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding> <java.version>1.8</java.version> </properties> <dependencies> <dependency> <groupId>junit</groupId> <artifactId>junit</artifactId> <version>4.11</version> <scope>test</scope> </dependency> </dependencies> <build> <plugins> <plugin> <groupId>org.apache.maven.plugins</groupId> <artifactId>maven-compiler-plugin</artifactId> <version>3.6.1</version> <configuration> <source>${java.version}</source> <target>${java.version}</target> </configuration> </plugin> </plugins> </build> </project>

​

프로젝트는 다음과 같은 디렉터리 구조로 생성된다.

my-app |-- pom.xml `-- src |-- main | `-- java | `-- com | `-- agapeuni | `-- App.java `-- test `-- java `-- com `-- agapeuni `-- AppTest.java

​

아주 간단한 POM

<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd"> <modelVersion>4.0.0</modelVersion> <groupId>com.agapeuni</groupId> <artifactId>hello-maven</artifactId> <version>1.0.0</version> ... 4\. Maven 사용법

메이븐으로 컴파일하려면 pom.xml 파일이 있는 위치에서 다음을 실행한다. 소스 코드를 실행할 수 있는 클래스로 변환한다. 

compile을 실행하면 컴파일에 필요한 라이브러리를 메이븐 저장소에서 다운로드한다.

> mvn compile

​

메이븐으로 테스트하려면 다음을 실행한다. 

**/Test*.java, **/*Test.java, **/*TestCase.java와 같은 조건의 파일이 실행된다.

> mvn test

​

메이븐으로 작성이 완료된 JAR 파일을 로컬 저장소에 설치하려면 다음을 실행한다.

> mvn install

​

메이븐으로 패키징 하려면 다음을 실행한다.

> mvn package

​

JAR 파일을 게시하려면 다음을 실행한다.

> mvn deploy
