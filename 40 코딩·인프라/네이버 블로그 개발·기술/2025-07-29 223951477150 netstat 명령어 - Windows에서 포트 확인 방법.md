# 2025-07-29 223951477150 netstat 명령어 - Windows에서 포트 확인 방법

## 본문

![](https://postfiles.pstatic.net/MjAyNTA3MzBfMTU5/MDAxNzUzODEzMDU2NTgy.9w1tWK7n3lQtvF2fUieCZ-I3wt8fDVwvJF_wHZRocIcg.UyM41bCgbd75g5jsE3pp9-KJVp3SvvB4r5Frjp5pZ3wg.PNG/%EB%84%A4%ED%8A%B8%EC%9B%8C%ED%81%AC-001_\(2\).png?type=w80_blur)

​

윈도우 기반의 컴퓨터 환경에서 보안 점검을 수행하거나 네트워크 트래픽을 모니터링할 때, 특정 포트가 열려 있는지 또는 어떤 프로세스가 해당 포트를 사용하는지를 확인하는 일이 자주 발생한다. 이러한 작업에 유용하게 활용할 수 있는 대표적인 명령어가 바로 netstat이다.

​

netstat 명령어는 시스템 보안 진단, 네트워크 트래픽 모니터링, 포트 충돌 확인 등 다양한 목적으로 활용할 수 있는 매우 강력한 도구다. 특히 윈도우 환경에서 GUI 기반의 정보 확인이 어려운 경우, 명령어 기반의 netstat는 빠르고 직관적인 해결책이 될 수 있다. Windows 환경에서 netstat 명령어를 사용하여 포트를 확인하는 방법을 단계별로 살펴보자.

​

​

1\. netstat란?

netstat(network statistics)은 현재 시스템에서 이루어지고 있는 네트워크 연결 상태를 보여주는 명령어이다. TCP, UDP 프로토콜을 통해 어떤 IP 및 포트가 연결되어 있는지, 그리고 어떤 프로세스(PID)가 해당 포트를 점유하고 있는지를 확인할 수 있다.

​

윈도우뿐만 아니라 리눅스, macOS 등 다양한 운영체제에서 지원되지만, 사용 가능한 옵션에는 다소 차이가 있다. 본 포스트에서는 Windows 기준으로 설명한다.

​

​

2\. 기본 사용 방법

먼저 명령프롬프트(CMD)를 실행한 후, 다음과 같이 입력하면 netstat 명령어에 대한 전체 옵션을 확인할 수 있다.

> netstat /? 

C:\Users\OneWay>netstat /? 프로토콜 통계와 현재 TCP/IP 네트워크 연결을 표시합니다. NETSTAT [-a] [-b] [-e] [-f] [-n] [-o] [-p proto] [-r] [-s] [-t] [-x] [-y] [interval] -a 모든 연결 및 수신 대기 포트를 표시합니다. -b 각 연결 또는 수신 대기 포트 생성과 관련된 실행 파일을 표시합니다. 잘 알려진 실행 파일이 여러 독립 구성 요소를 호스팅할 경우 연결 또는 수신 대기 포트 생성과 관련된 구성 요소의 시퀀스가 표시됩니다. 이러한 경우에는 실행 파일 이름이 아래 [] 안에 표시되고 위에는 TCP/IP에 도달할 때까지 호출된 구성 요소가 표시됩니다. 이 옵션은 시간이 오래 걸릴 수 있으며 사용 권한이 없으면 실패합니다. -e 이더넷 통계를 표시합니다. 이 옵션은 -s 옵션과 함께 사용할 수 있습니다. -f 외부 주소의 FQDN(정규화된 도메인 이름)을 표시합니다. -n 주소 및 포트 번호를 숫자 형식으로 표시합니다. -o 각 연결의 소유자 프로세스 ID를 표시합니다. -p proto proto로 지정한 프로토콜의 연결을 표시합니다. proto는 TCP, UDP, TCPv6 또는 UDPv6 중 하나입니다. -s 옵션과 함께 사용하여 프로토콜별 통계를 표시할 경우 proto는 IP, IPv6, ICMP, ICMPv6, TCP, TCPv6, UDP 또는 UDPv6 중 하나입니다. -q 모든 연결, 수신 대기 포트 및 바인딩된 비수신 대기 TCP 포트를 표시합니다. 바인딩된 비수신 대기 포트는 활성 연결과 연결되거나 연결되지 않을 수도 있습니다. -r 라우팅 테이블을 표시합니다. -s 프로토콜별 통계를 표시합니다. 기본적으로 IP, IPv6, ICMP, ICMPv6, TCP, TCPv6, UDP 및 UDPv6에 대한 통계를 표시합니다. -p 옵션을 사용하여 기본값의 일부 집합에 대한 통계만 지정할 수 있습니다. -t 현재 연결 오프로드 상태를 표시합니다. -x NetworkDirect 연결, 수신기 및 공유 끝점을 표시합니다. -y 모든 연결에 대한 TCP 연결 템플릿을 표시합니다. 다른 옵션과 함께 사용할 수 없습니다. interval 다음 화면으로 이동하기 전에 지정한 시간(초) 동안 선택한 통계를 다시 표시합니다. 통계 다시 표시를 중지하려면 <Ctrl+C>를 누르세요. 이 값을 생략하면 현재 구성 정보가 한 번만 출력됩니다. 

​

자주 사용하는 옵션은 아래와 같다.

  * -a: 모든 포트를 보여준다. (Listening 중인 포트 + Established 연결 포함)

  * -n: 호스트 이름 대신 IP 주소와 포트 번호를 숫자로 출력한다.

  * -o: 포트를 사용하는 프로세스의 PID(Process ID)를 함께 표시한다.

​

이 옵션들을 조합하여 활용하면 다양한 정보를 손쉽게 확인할 수 있다.

​

​

3\. 현재 열린 포트 확인

시스템에서 현재 열려 있는 열려 있는 TCP 포트를 확인할 때는 다음 명령어를 사용한다.

> netstat -anpo tcp | find "LISTEN"

C:\Users\OneWay>netstat -anpo tcp | find "LISTEN" TCP 0.0.0.0:135 0.0.0.0:0 LISTENING 1104 TCP 0.0.0.0:445 0.0.0.0:0 LISTENING 4 TCP 0.0.0.0:2179 0.0.0.0:0 LISTENING 2864 ...(중략)... TCP 192.168.33.1:139 0.0.0.0:0 LISTENING 4 TCP 192.168.45.146:139 0.0.0.0:0 LISTENING 4 TCP 192.168.192.1:139 0.0.0.0:0 LISTENING 4 C:\Users\OneWay>

​

시스템에서 현재 열려 있는 열려 있는 UDP 포트를 전체 확인할 때는 다음 명령어를 사용한다.

> netstat -anpo udp

C:\Users\OneWay>netstat -anpo udp 활성 연결 프로토콜 로컬 주소 외부 주소 상태 PID UDP 0.0.0.0:53 *:* 3900 UDP 0.0.0.0:1900 *:* 4724 UDP 0.0.0.0:3389 *:* 1240 ...(중략)... UDP 192.168.192.1:49588 *:* 4724 UDP 192.168.192.1:62245 *:* 4788 UDP 192.168.192.1:65502 *:* 5980 C:\Users\OneWay>

​

4\. 특정 포트로 접속한 IP 확인

어떤 IP가 특정 포트를 통해 접속하고 있는지를 확인하려면 다음과 같이 명령어를 입력한다.

​

  * 현재 로컬 컴퓨터에 443번 포트로 접속한 외부 IP 확인. 4433 포트도 함께 출력된다.

> netstat -ano | find ":443" 

C:\Users\OneWay>netstat -ano | find ":443" TCP 0.0.0.0:4433 0.0.0.0:0 LISTENING 5980 TCP 0.0.0.0:4433 0.0.0.0:0 LISTENING 5980 TCP 192.168.45.146:51985 54.180.210.170:443 ESTABLISHED 9820 ...(중략)... TCP 192.168.45.146:61197 125.209.233.30:443 ESTABLISHED 16460 TCP 192.168.45.146:61233 135.171.2.152:443 ESTABLISHED 8448 TCP [::]:4433 [::]:0 LISTENING 5980 C:\Users\OneWay>

  * 특정 IP에서 80번 포트로 접속한 연결 확인

> netstat -ano | find "특정IP:80" 

C:\Users\OneWay>netstat -ano | find "211.115.106.73:80" TCP 192.168.45.146:61053 211.115.106.73:80 CLOSE_WAIT 5820 TCP 192.168.45.146:61055 211.115.106.73:80 CLOSE_WAIT 5820 TCP 192.168.45.146:61056 211.115.106.73:80 CLOSE_WAIT 5820 TCP 192.168.45.146:61059 211.115.106.73:80 CLOSE_WAIT 5820 TCP 192.168.45.146:61060 211.115.106.73:80 CLOSE_WAIT 5820 TCP 192.168.45.146:61075 211.115.106.73:80 CLOSE_WAIT 5820 TCP 192.168.45.146:61076 211.115.106.73:80 CLOSE_WAIT 5820 C:\Users\OneWay>
