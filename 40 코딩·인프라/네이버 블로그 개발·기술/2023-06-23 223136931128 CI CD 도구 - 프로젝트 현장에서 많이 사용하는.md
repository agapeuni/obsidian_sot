**​**

**1\. Jenkins**

<https://jenkins.io/>

[ ![](https://dthumb-phinf.pstatic.net/?src=%22https%3A%2F%2Fwww.jenkins.io%2Fimages%2Flogo-title-opengraph.png%22&type=ff500_300) ](https://jenkins.io/) [ **Jenkins** Jenkins – an open source automation server which enables developers around the world to reliably build, test, and deploy their software jenkins.io ](https://jenkins.io/)

오픈 소스 자동화 서버인 Jenkins는 모든 프로젝트 구축, 배포 및 자동화를 지원하는 수백 개의 플러그인을 제공한다. Jenkins는 중앙 빌드 및 지속적인 통합 프로세스가 가능하며, Windows, macOS 및 Unix 계열 운영체제용 패키지가 포함된 독립형 Java 기반 프로그램이다. 수백 개의 플러그인을 사용할 수 있는 Jenkins는 소프트웨어 개발 프로젝트의 빌드 파이프라인 구성, Build 자동화의 확립, 배포 및 테스트 자동화 등을 지원한다.

![](https://postfiles.pstatic.net/MjAyMzA2MjNfMzAg/MDAxNjg3NTA2MzkyODgw.jWvNnp-MksWf-ofrmHNDLSslX5tHz6Q5nmP6_Fe8Shwg.GO5qH3KhHc_moyUgW7gTm8Jj8FXoKjRFI46pjtbVEjcg.PNG.agapeuni/img.png?type=w80_blur)

**​**

**2\. CircleCI**

<https://circleci.com/>

[ ![](https://dthumb-phinf.pstatic.net/?src=%22https%3A%2F%2Fd3r49iyjzglexf.cloudfront.net%2Fcircleci-logo-horizontal-twitter-48d4d4cde22c26476d5c81b91630c2da5357c0cd21ff3183a0ae997d3e999bb2.png%22&type=ff500_300) ](https://circleci.com/) [ **Continuous Integration and Delivery** Get the best continuous integration and delivery for any platform, in our cloud or on your own infrastructure. circleci.com ](https://circleci.com/)

CircleCI는 코드 구축과 테스트 그리고 배포에 이르기까지 사용자의 파이프라인에 신속한 소프트웨어 개발 및 게시를 지원하는 CI/CD 자동화 도구이다. CircleCI를 GitHub, Bitbucket, Gitlab과 통합하여 사용할 수 있다는 장점이 있다.

​

**3\. TeamCity**

<https://www.jetbrains.com/teamcity/>

[ ![](https://dthumb-phinf.pstatic.net/?src=%22https%3A%2F%2Fresources.jetbrains.com%2Fstorage%2Fproducts%2Fteamcity%2Fimg%2Fmeta%2Fpreview.png%22&type=ff500_300) ](https://www.jetbrains.com/teamcity/) [ **TeamCity: the Hassle-Free CI/CD Tool by JetBrains** Try TeamCity - the powerful Continuous Integration and Deployment tool for Developers and DevOps Engineers. www.jetbrains.com ](https://www.jetbrains.com/teamcity/)

TeamCity는 JetBrains의 빌드 관리 및 지속적 통합 서버로써 Java 환경에서 실행되며 Visual Studio 및 IDE와 통합될 수 있는데, Windows 및 Linux 서버에 모두 설치할 수 있으며 .NET 및 개방형 스택 프로젝트도 지원한다.
