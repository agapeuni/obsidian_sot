SQL 문법이 잘 기억나지 않을 때 그냥 가져다 사용할 수 있는 템플릿들을 정리해 본다.

**1\. DML Template**

​

**\-- SELECT 문**

**SELECT** <column_list>

**FROM** <table_list>

**WHERE** <condition_list>

**ORDER** **BY** <column_list>;

​

**\-- INSERT 문**

**INSERT** **INTO** <table_name>

<(column_list)>

**VALUES**

<(value_list)>;

​

**\-- INSERT SELECT 문**

**INSERT** **INTO** <table_name>

<(column_list)>

**SELECT** <column_list>

**FROM** <table_list>

**WHERE** <condition_list>;

​

**\-- UPDATE 문**

**UPDATE** <table_name>

**SET** <expression_list>

**WHERE** <condition_list>;

​

**\-- DELETE 문**

**DELETE** **FROM** <table_list>

**WHERE** <condition_list>;

**2\. DDL Template**

**\-- CREATE TABLE 문**

**CREATE** **TABLE** <table_name>

(

<column_list>

)

TABLESPACE <tablespace_name>

PCTFREE 10

PCTUSED 40

STORAGE (INITIAL <initial_size>

NEXT <next_size>

MINEXTENTS 1

MAXEXTENTS 128

PCTINCREASE 0);

**\-- CRATE TABLE AS SELECT 문**

**CREATE** **TABLE** <table_name>

(

<column_list>

)

TABLESPACE <tablespace_name>

PCTFREE 10

PCTUSED 40

STORAGE (INITIAL <initial_size>

NEXT <next_size>

MINEXTENTS 1

MAXEXTENTS 128

PCTINCREASE 0)

**AS**

<select_statement>

**\-- CREATE INDEX 문**

**CREATE** **INDEX** <index_name>

**ON** <table_name> (<column_list>)

TABLESPACE <tablespace_name>

PCTFREE 10

STORAGE (INITIAL <initial_size>

NEXT <next_size>

MINEXTENTS 1

MAXEXTENTS 128

PCTINCREASE 0);

**\-- CREATE SEQUENCE 문**

**CREATE** SEQUENCE <sequence_name>

START **WITH** 1 INCREMENT **BY** 1;

**\-- CREATE SYNONYM 문**

**CREATE** SYNONYM <synonym_name> FOR <object_name>;

**\-- CREATE VIEW 문**

**CREATE** **VIEW** <view_name> **AS**

<select_statement>;

**\-- CREATE DATABASE LINK 문**

**CREATE** DATABASE LINK <database_link_name>

CONNECT TO <user_name> IDENTIFIED **BY** <password> **USING** '<connect_string>'; 

**3\. PL/SQL Template**

**\-- CREATE FUNCTION 문**

**CREATE** **OR** REPLACE FUNCTION <function_name> (argument **IN** /OUT **type** , argument **IN** /OUT **type** , ...) RETURN <datatype>

**IS**

<variable_decalration>

**BEGIN**

<statements>

**END** ;

**\-- CREATE PROCEDURE 문**

**CREATE** **OR** REPLACE **PROCEDURE** <procedure_name> (argument **IN** /OUT **type** , argument **IN** /OUT **type** , ...)

**IS**

<variable_declaration>

**BEGIN**

<statements>

**END** ;

**\-- CREATE TRIGGER 문**

**CREATE** **OR** REPLACE TRIGGER <trigger_name>

<BEFORE | AFTER |INSTEAD OF>

<dml_statement>

**ON** <**schema** >

WHEN (condition)

<pl/sql_block | call_procedure_statement>
