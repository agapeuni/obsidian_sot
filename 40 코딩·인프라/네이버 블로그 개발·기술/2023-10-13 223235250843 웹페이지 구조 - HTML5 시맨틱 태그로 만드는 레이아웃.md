**1\. 개요**

HTML5로 페이지를 만들 때는 이전보다 간결한 코드로 만들 수 있다. 플러그인(plug-in)이나 액티브엑스(ActiveX)를 설치하지 않아도 순수 기술만으로 많은 기능을 구현할 수 있게 되었으며 웹표준과 웹 접근성을 보다 높여주었다. 이제는 공공기관뿐만 아니라 일반 기업에서 웹 프로젝트를 수행할 때 웹표준과 시큐어코딩을 적용하는 것이 당연시되고 있다. 

​

​

**2\. IE 코드 추가**

간혹 HTML5를 지원하지 않는 IE 브라우저를 사용하는 사람을 위해 아래와 같은 코드를 추가한다. 예전에는 IE에서만 동작하면 구현을 완료한 것으로 간주되었는데 요즘은 크롬에서 먼저 지원되기를 바라는 고객도 있다. 

<!doctype html> <html lang="ko"> <head> <meta charset="UTF-8"> <title>HTML5</title> <link rel="stylesheet" href="./css/style.css"> <!--[if IE]> // 인터넷에 연결하여 사용하는 경우 <script src="http://html5shim.googlecode.com/svn/trunk/html5.js"></script> <![endif]--> <!--[if IE]> // 자바스크립트 파일을 다운로드하여 사용하는 경우 <script src="../js/html5.js"></script> <![endif]--> </head> <body> <svg> <circle r="24" cx="24" cy="24" fill="red"/> </svg> </body> </html>

  1. DOCTYPE : 맨 위에 간결하게 한 줄 구현한다.

  2. Encoding : 이제는 따로 생각할 필요도 없이 "UTF-8"을 적용한다.

  3. SVG(Scalable Vector Graphics) : 2차원 그래픽을 표현하기 위한 태그이다.

​

​

**3\. 시멘틱(Semantic) 엘리먼트**

HTML5에서 추가된 시멘틱(Semantic) 엘리먼트로 내용에 대한 구조를 표현하는 태그들이다.

엘리먼트 |  설명  
---|---  
Header |  문서의 Header를 표현  
Footer |  문서의 Footer를 표현  
Nav |  문서 내에 Navigation 요소를 표현  
Section |  문서의 영역을 구성, H1~H6 와 함께 사용하여 구조를 표현  
Article |  독립된 내용을 표시할 때 사용  
Aside |  메인 콘텐츠 이외의 참고가 되는 내용을 표현  
Figure |  그림, 비디오와 같은 콘텐츠의 Caption 을 표현  
Figcaption |  캡션에 사용

**4\. HTML5 웹페이지**

HTML5 시맨틱 엘리먼트를 설명하는 이미지와 비슷하게 웹페이지를 구현해 보았다. 레이아웃을 구분하기 2px의 border에 색상을 적용했다. 모든 요소에 margin과 padding을 5px 적용했다.

<!doctype html> <html lang="ko"> <head> <meta charset="UTF-8"> <title>HTML5</title> <style> * { text-align: center; margin : 5px; padding : 5px; } header { border: 2px solid red; height: 60px; } nav { border: 2px solid orange; height: 150px; } article { border: 2px solid green; height: 320x; } article section { border: 2px solid #0099ff; height: 120px; } footer { border: 2px solid blue; width: 68%; height: 60px; float: left; } aside { border: 2px solid blueviolet; background-color: lightgray; width: 28%; height: 60px; float: right; } ul { list-style: none; padding-left: 0px; } </style> </head> <body> <header> Header </header> <nav> <ul> <li>Menu1</li> <li>Menu2</li> <li>Menu3</li> </ul> </nav> <article> Article <section> Section1 </section> <section> Section2 </section> </article> <aside> Aside </aside> <footer> Footer </footer> </body> </html>
