**1\. JSP 프로그램**

JSP(JavaServer Pages) 프로그램은 서블릿 기반의 웹 애플리케이션 개발을 위한 기술이다. JSP는 HTML 코드와 Java 코드를 혼합하여 동적 웹 페이지를 생성할 수 있게 해준다. JSP 파일은 .jsp 확장자를 가지며, 서버에서 동적으로 처리되어 HTML로 변환되어 클라이언트에게 전송된다.

​

JSP 프로그램에서는 <% ... %>를 기본적으로 사용한다. 

지시자를 나타내는 <%@ ... %>, 

주석을 나타내는 <%-- ... --%>, 

선언부를 나타내는 <%! ... %>, 

표현식을 나타내는 <%= ... %>, 

그리고......</jsp:forward> 등의 형식으로 나타내는 액션 태그 등을 사용하여 프로그래밍한다.

​

1에서 100까지의 합을 계산하는 JSP 프로그램이다. 간단한 JSP 프로그램을 통해 JSP 프로그래밍을 이해하고 코드에 기술된 각 명령문들을 이해해 보자. 

<%@ page contentType="text/html; charset=euc-kr"%> <html> <head> <title>1에서 100까지의 합</title> </head> <body> <h1>JSP 프로그래밍 예제</h1> <%-- JSP 주석 --%> <% int sum = 0; for (int i = 1; i <= 100; i++) { sum += i; } out.println("1에서 100까지의 합 : " + sum); %> <br> 1에서 100까지의 합은 <%=sum%>이다. </body> </html>

**2\. 지시자 (Directive)****​**

JSP 파일에서는 지시자(Directive)를 사용하여 JSP 페이지의 속성을 설정할 수 있다. JSP 지시자는 `<%@`와 `%>` 사이에 위치하며, JSP 컨테이너에게 특정 지시를 제공한다. 지시자는 전체 페이지와 관련된 정보를 JSP 엔진에 전달하기 위해 사용된다. 주요한 지시자로는 `page`, `include`, `taglib` 등이 있습니다.

![](https://postfiles.pstatic.net/MjAyMzA2MjVfMTAz/MDAxNjg3Njg1MjQ1ODYy.sz-iB99uQKul8K2N05CO8OYeoKEJ-b20sJhJUeVE85Eg.7mcaR3akYVV25NA-7kIX1meaasSbtuJTRAokyPydYasg.PNG.agapeuni/img.png?type=w80_blur)

**① page 지시자**

먼저, page 지시자는 JSP 페이지의 속성을 지정하는 데 사용하는 것으로서, JSP에서 지정할 수 있는 속성은 language, import, extends 등 총 11개가 있다. page 지시자의 속성을 지정하는 방식은 다음과 같다.

​

<%@page attribute1=“value1” attribute2=“value2” attribute3=“value3”... %>

​

■ language

JSP 페이지의 프로그래밍 언어를 지정한다. 기본값은 java이며 현재 쓰일 수 있는 유일한 값도 java이다. JSP에서는 현재 스크립팅 언어로 java 외의 언어가 쓰이는 일이 없기 때문이다.

​

<%@page language = “java” >

​

■ contentType

클라이언트에게 응답할 문서의 MIME 타입을 지정하는 것으로서, text/html 이외에 서블릿의 기본 타입인 text/plain 그리고 이미지를 위한 image/gif 등의 타입도 있다. 그 형식을 보면 type에는 응답할 타입을 지정하고, 추가로 인코딩 방식이 필요할 때에는 charset 이란 속성을 써 준다. 여기서 euc-kr은 HTML 문서에 포함된 한글 문자를 처리하기 위해 필요로 한다. 디폴트 값은 "text/html; charset=ISO-8859-1"이다.

​

<% page contentType = “text/html; charset = euc-kr”>

​

■ extends

JSP 페이지 요청 시 생성되는 서블릿의 부모 클래스를 지정하는데 쓰인다. 하지만 서블릿 컨테이너는 컨테이너 개발사에서 이미 만들어진 최적의 부모 클래스를 사용하여 동적으로 서블릿을 생성하는 경우가 대부분이다. 따라서 사용빈도가 거의 없는 속성이라고 볼 수 있다.

​

<%@page extends = “father.class” %>

​

■ info

해당 페이지에 대한 설명을 지정할 때 쓰이는 속성으로 이것을 지정하면 나중에 getServerInfo() 메서드로 지정한 정보를 알아볼 수 있다.

​

<%@ page info = “JSP 지시자” %>

​

■ import

JSP가 요청되어 변환된 서블릿이 import 할 클래스를 지정한다. 즉, 서블릿이 기본적으로 import 하는 java.lang.*, javax.servlet.*, javax.servlet.jsp.*, javax.servlet.http.*외에 필요한 패키지가 있을 경우 import로 지정해서 사용을 해야 한다. 사용 형식은 다음과 같다.

​

<%@page import = “java.util.*” %>

<%@page import = “user.*, bbs.*” %>

​

■ session

페이지가 HttpSession을 사용할지 여부를 지정한다. 속성은 true와 false로 나뉘어, true 일 경우에는 세션이 이미 존재할 경우 그 세션을 유지하고 존재하지 않을 경우는 새로운 세션을 생성하여 연결되지만, false 일 경우에는 세션이 연결되지 않는다. 기본값은 true이다.

​

<%@page session = “true” %>

<%@page session = “false” %>

​

■ buffer

클라이언트로의 전송을 담당하는 out객체(JspWirter out)의 버퍼 크기를 설정한다. 버퍼를 설정하면 지정된 버퍼 크기만큼의 데이터 단위로 클라이언트에 전송된다. 즉 버퍼의 크기가 30kb이라면 버퍼는 30kb의 데이터를 채우기 전까지는 클라이언트에게 전송하지 않고 30kb가 되는 순간 또는 30kb가 안되더라도, 페이지 처리가 완료되는 순간 클라이언트로 전송하게 된다. 여기서 none으로 설정하면 버퍼를 사용하지 않음을 의미한다.

​

<%@page buffer = “30kb” %>

<%@page buffer = “none” %>

​

■ autoflush

출력 버퍼가 꽉 찼을 때 이를 제어할 방법을 지정한다. true로 지정할 경우 출력 버퍼를 클라이언트로 보내주고 내용을 비우며, false로 할 경우 버퍼를 비우지 않고 예외를 발생시킨다. 위에서 buffer의 크기를 none으로 지정했다면 autoflush 속성을 true로 지정할 수 없다. 기본값은 true다.

​

<%@page autoflush = “true” %>

<%@page autoflush = “false” %>

​

■ isThreadSafe

JSP에서 생성된 서블릿이 SingleThreadModel Interface를 구현하는지의 여부를 지정한다. SingleThreadModel은 4장에서 이미 살펴보았던 것으로, 서블릿에서 스레드로 자원에 접근할 때 공유로 인한 문제점이 있을 경우 한 번에 하나의 스레드만 자원에 접근하도록 해 주는 표시(marker) 인터페이스이다. 기본값은 true로 되어 있으며 SingleThreadModel을 구현하려면 값을 false로 지정해야 한다.

​

<%@page isThreadSafe = “true” %>

<%@page isThreadSafe = “false” %>

​

■ errorPage

페이지에서 어떠한 예외 상황이 발생할 경우 그 에러를 처리할 페이지를 지정한다. 이렇게 지정된 페이지로 exception 객체가 에러를 가지고 넘어간다.

​

<%@page errorPage= “errManage.jsp” %>

​

■ isErrorPage

페이지가 다른 페이지의 에러 처리 페이지가 될 것인가의 여부를 지정한다. 즉, 위에서 errorPage 속성으로 exception을 넘겼을 때 그것을 받아서 처리할 것인가의 여부를 결정한다. 기본값은 false이다.

​

<%@page isErrorPage= “true” %>

<%@page isErrorPage= “false” %>

​

**② include 지시자**

두 번째 지시자로서, JSP 페이지에 다른 HTML 문서나 JSP 페이지를 삽입하기 위해 사용되는 include 지시자는 다음과 같이 선언되며 이 지시자에 기술할 수 있는 속성으로는 삽입할 파일의 URL을 기술하는 file 속성만을 사용할 수 있다. 이 지시자는 JSP 프로그램의 임의의 위치에 올 수 있다.

​

<%@ include file="header.inc" %>

​

​

**③ taglib 지시자**

JSP에서는 사용자가 자신만의 새로운 태그를 정의하여 사용하거나 혹은 제삼자가 개발한 태그 라이브러리를 사용할 수가 있는데, 이들 태그 라이브러리를 프로그램상에 사용하기 위해서는 다음과 같이 taglib 지시자를 선언하여야 한다.

﻿<%@ taglib uri="newTag.lib" prefix="newTag" %> <newTag:tag01> ...... </newTag:tag01> <newTag:tag02> ...... </newTag:tag02>

**3\. 스크립트 모듈****​**

스크립트 모듈은 JSP 페이지 내에서 실제 실행이 이루어지는 부분으로서 변수나 메서드를 선언하는 선언부, 연산 결과를 HTML로 출력하는 표현식, 그리고 JSP 프로그래밍을 의미하는 스크립트릿 등 세 가지로 구성되어 있다.

**① 선언부 (Declaration)**

선언부는 JSP 페이지 내에서 사용될 변수나 메서드를 정의할 때 사용되며, 여기서 선언된 변수와 메서드는 세션이 종료될 때까지 지속적으로 사용된다. 이것은 뒤에서 설명될 스크립트릿에서 선언한 변수가 해당 페이지에서만 사용되는 것과 다른 점이라 할 수 있다.

<%! int count = 50; %> <%! public int add(int a, int b) { int sum = a + b; return sum; } %>

**② 표현식 (Expression)**

표현식은 JSP의 변수 혹은 연산의 결과를 HTML로 출력하기 위해 사용하는 것으로서 HTML의 디자인을 그대로 둔 채로 변수의 값을 삽입하여 결과를 출력할 수 있도록 한다.

​

스크립트릿에서 out.println() 메서드를 이용하여 변수의 값을 출력할 수도 있으나, HTML 소스 중간에 <%= sum %> 형식으로 지정함으로써 sum 변수의 값을 HTML로 출력할 수 있다.

​

<%= 표현값 %>

​

다음은 현재의 시각을 화면에 출력하는 JSP 프로그램의 예이다.

<%@ page contentType="text/html; charset=euc-kr"%> <html> <head> <title>현재시각을 표현함</title> </head> <body> <h1>JSP 표현식의 예</h1> 현재 시각은 <%=new java.util.Date()%> 입니다. </body> </html>

위의 프로그램에서 java.util 패키지에 포함되어 있는 Date() 메서드를 사용하기 위해 page 지시자에 import 문을 추가하면 다음과 같이 프로그램을 수정할 수도 있다. 

<%@ page import="java.util.*" contentType="text/html; charset=euc-kr"%> <html> <head> <title>현재시각을 표현함</title> </head> <body> <h1>JSP 표현식의 예</h1> 현재 시각은 <%=new Date()%> 입니다. </body> </html>

**③ 스크립트릿 (Scriptlet)**

JSP 페이지에서 실행해야 할 Java 코드를 작성한다. 스크립트릿은 하나의 JSP 페이지에 여러 개가 존재할 수 있다. 

﻿<% Java 코드 1; Java 코드 2; %>
