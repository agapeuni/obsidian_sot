**1\. MEAN Stack 개요**

JavaSctipt가 놀라운 발전을 거듭하여 이제는 프런트앤드부터 백앤드까지 풀스택으로 개발이 가능해졌다. LAMP 스택 환경에서는 리눅스 관리자, 웹서버 관리자, 개발자(PHP, Perl, Python) 그리고 MySQL 가능자가 있어야 웹서버 구축이 가능했는데 이제는 JavaScript로 코딩이 가능한 한 명의 개발자만 있으면 웹 서비스를 쉽게 구축할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA0MjdfMTQy/MDAxNjgyNTYzMDAwNzEz.0wajon2IxhdE5GDQHlQuxSld44DxW6PvAsJuHWnKHMAg.c8J4tyzk1axQI85Yuq7Tt0TExGJ6vv3usPUotF8VJlwg.PNG.agapeuni/img.png?type=w80_blur)

​

MEAN Stack은 동적 웹사이트 및 웹 애플리케이션을 개발하는 데 사용되는 JavaScript 기반 기술이다. Mongo DB, Express, Anagula.js, Node.js로 구성되어 있고 각각의 요소 기술의 앞 글자를 표시한 용어이다. 클라이언트에서 서버, 데이터베이스에 이르기까지 JavaScript 언어로 풀스택 개발이 가능하다.

**2\. MongoDB**

![](https://blog.kakaocdn.net/dn/bvBMul/btr0h1dnu1O/DBtezRw5IMZOK0ZVK0eXQ0/img.png)

**MEAN에서 M** 은 MongoDB를 말한다.

​

JSON과 같은 형식으로 데이터를 저장하고 SQL과 유사한 쿼리를 수행할 수 있는 문서 지향 NoSQL의 데이터베이스이다. MongoDB는 NoSQL 데이터베이스의 선두 주자로서 기업의 민첩성과 확장 성을 높여준다.

​

MongoDB는 스키마가 없는 NoSQL 데이터베이스 시스템이다. MongoDB는 클라이언트와 서버 간에 데이터를 쉽게 전달할 수 있도록 바이너리 JSON 형식으로 데이터를 저장한다.

**3\. Express**

![](https://blog.kakaocdn.net/dn/viXxB/btr0fKi9mVN/IJQVsNkUxkTFPkGj0lWgq1/img.png)

MEAN에서 **E는** Express를 말한다.

​

NodeJS에서 실행되며 많이 사용되고 있는 웹 애플리케이션 프레임워크이다. Express는 최소 및 유연한 node.js 웹 응용 프로그램 프레임 워크로서 단일 및 다중 페이지 및 하이브리드 웹 응용 프로그램을 작성하기 위한 강력한 기능 세트를 제공한다.

​

Express는 노드에서 웹 응용 프로그램을 작성하는 데 사용되는 경량 프레임워크이다. 단일 및 다중 페이지 웹 응용 프로그램을 구축하기 위한 강력한 기능을 제공한다. Express는 유명한 Ruby 프레임워크인 Sinatra에서 영감을 얻었다.

**4\. AngularJs**

![](https://blog.kakaocdn.net/dn/325M4/btr0jiTtiaW/mtgYXvrD1bhDeHE7yJKvlK/img.png)

MEAN에서 **A** 는 AngularJs를 말한다.

​

AngularJS는 Google에서 개발 한 JavaScript 프레임워크이다. 양방향 데이터 바인딩과 같은 멋진 기능을 제공한다. 신속하고 멋진 프런트 엔드 개발을 위한 완벽한 솔루션이다.

​

단일 페이지와 데이터 중심의 애플리케이션 작성을 용이하게 하는 자바스크립트 웹 프레임워크이다. AngularJS를 사용하면 응용 프로그램에 대한 HTML 어휘를 확장할 수 있다. 그 결과 환경은 매우 표현력이 풍부하고 읽기 쉽고 빠르게(?) 개발된다고 한다.

**5\. Node.js**

![](https://blog.kakaocdn.net/dn/bm3UC9/btr0jjx4I2b/kAaKksIGDUn2eWzLVZNUOk/img.png)

MEAN에서 N은 Node.js를 말한다.

​

**6\. MEAN Stack 장점**

MEAN Stack을 사용하여 개발할 때의 장점은 다음과 같다.

1\. JavaScript 언어로 화면, 서버, 디비까지 개발이 가능하고 유연하게 구현할 수 있다.

2\. 구성하고 있는 요소 기술이 모두 오픈소스이고 MVC (Model View Controller) 아키텍처를 지원한다.

3\. 대규모 프로젝트에서 유용한 MongoDB를 사용하고 유연한 JSON 문서 구조를 제공한다.

4\. Node.js에서 제공되는 수많은 다양한 라이브러리가 있으며 Node.js의 빠른 아키텍처를 이용할 수 있다.

**7\. MEAN Stack 처리 과정**

![](https://postfiles.pstatic.net/MjAyMzA0MjdfMjU5/MDAxNjgyNTYyOTYxMzI4.m2o60kgVPzmdtX0diOO0MHAk8cmmsbWi1Pf_2kBx6fgg.CJXCyxiKmqxI768LcuqonU12O--sB_PG_6eHovbOTqcg.JPEG.agapeuni/img.jpg?type=w80_blur)

클라이언트에서 요청한 정보를 서버에서 처리하고 응답하여 화면에 표시하기까지의 처리 과정이다.

  1. 요청하기 (Make Request)

  2. 요청 구문 분석 (Parse Request)

  3. 데이터 가져오기 (Get Database)

  4. 데이터 반환 (Return Database)

  5. 요청 반환 (Return Request)

  6. 요청 표시 (Display Request)
