# 2024-02-23 223362741610 microSD 복사 - Win32 Disk Imager v1.0

## 본문

1\. 문제(Problem)

라즈베리 파이(Raspberry PI)에 우분트(Ubuntu)를 설치하고 한다. 애플리케이션 실행에 필요한 프로그램을 설치하고 환경설정까지 마친다. 그리고 데이터베이스를 설치하고 원격에서 접속 가능하도록 환경을 구성한다. 우분투 패키지를 최신화하기 위해 업데이트 및 업그레이드를 진행한다. 여기까지만 해도 상당한 작업을 반영하였고 처음 설치하고 나서 많은 변경이 일어났다.

​

시간이 지나 라즈베리 파이를 다시 사용하려고 할 때, 혹은 정상적으로 잘 사용하다가 문제가 생기는 경우가 있다. 위의 작업을 다시 진행하려고 하니 좀 난감한 상황이다. 그래서 작업된 시점까지 이미지를 그대로 복사하는 방법을 찾아보았다.

​

2\. 해결(Solution)

다행히 이미지를 그대로 복사해 주는 프로그램을 찾았다. Win32 SD Imager 프로그램을 사용하여 여분의 microSD 카드에 작업한 그대로의 이미지를 복사(클론)을 해두고 문제가 발생할 때 바로 사용하자. 

​

운영체제부터 패키지, 환경 구성 모두를 백업하기 위해 Win32 SD Imager로 원본 microSD 카드를 읽어 이미지 파일을 만든다.

원본 microSD카드를 삽입하면 Device에 표시되는데 microSD카드 용량 이상의 충분한 공간에 이미지 파일을 생성한다. 

​

카드를 넣고 Device에 인식되면 Win32 Disk Imager에서 Image File을 지정하고 Read 버튼을 클릭한다.
