**1\. MongoDB 개요**

MongoDB의 레코드는 필드와 값으로 구성된 데이터 구조 문서이다. RDBMS와 쉽게 비교해 보면 Table에 해당하는 것이 Collection이고 Record에 해당하는 것이 Document이다. 그리고 Column에 해당하는 것이 Key/Field로 볼 수 있다.

​

MongoDB는 기존의 관계형 데이터베이스 시스템과는 다른 접근 방식을 가지고 있다. 관계형 데이터베이스에서는 테이블과 스키마를 사용하여 데이터를 구조화하고 관리하지만, MongoDB는 컬렉션(collection)과 문서(document)라는 개념을 사용한다. 컬렉션은 문서들의 그룹이며, 각 문서는 유연한 JSON 형태의 데이터 구조로 저장된다. 이러한 유연성은 MongoDB를 스키마리스(schemaless)라는 특징을 가지게 한다. 각 문서는 자체적으로 필드와 값을 가지며, 다른 문서들과 구조가 다를 수 있다.

​

이번에는 MongoDb로 기본적인 CRUD를 진행해 보자. 참고로 CRUD는 Create(생성), Read(읽기), Update(갱신), Delete(삭제)를 말한다. 참고로 CRUD는 씨알유디, 크러드(크루드)로 읽는다.

​

  * **C : Create**

  * **R : Read**

  * **U : Update**

  * **D : Delete**

**2\. MongoDB Shell 다운로드**

MongoDB Shell은 MongoDB에 연결하고 작업하는 괜찮은 방법이다. 구문 강조 표시, 지능적인 자동 완성 기능이 있다. 명령 줄 인터페이스를 사용하여 데이터를 쉽게 쿼리하고 구성하는 작업을 실행할 수 있다. 참고로 MongoDB Shell은 MongoDB 서버와 별도로 개발된 오픈 소스(Apache 2.0) 제품이다.

**6\. C****R****UD (2)**

데이터를 조회할 때 SQL의 WHERE 절과 같이 조건을 입력할 수 있다. 

2013년도 미만의 데이터를 조회해 보려고 할 때는 다음과 같이 입력합니다.

> db.car.find({ year: {$lt : 2013} })

​

2013년도 초과의 데이터를 조회해 보려고 할 때는 다음과 같이 입력합니다.

> db.car.find({ year: {$gt : 2013} })

​

참고로 MongoDB 비교 쿼리 연산자는 아래와 같다.

$eq - 지정된 값과 동일한 값을 일치시킨다. $gt - 지정된 값보다 큰 값을 일치시킨다. $gte - 지정된 값보다 크거나 같은 값을 일치시킨다. $lt - 지정된 값보다 작은값을 일치시킨다. $lte - 지정된 값보다 작거나 같은 값을 일치시킨다. $ne - 지정된 값과 동일하지 않은 모든 값을 일치시킨다. $in - 배열에 지정된 값으로 일치시킨다. $nin - 배열에 지정된 값이 일치하지 않는다.

​

2013년도 미만의 데이터를 조회하면서 이름순으로 정렬해 보자. 

참고로 오름차순은 1이고 내림차순은 -1이다.

​

> db.car.find({ year: {$lt : 2013} }).sort({name : 1})

> db.car.find({ year: {$lt : 2013} }).sort({name : -1})

**7\. CR****U****D**

컬렉션에 문서를 수정하는 메서드가 다음과 같이 제공한다.

  * db.collection.updateOne()

  * db.collection.updateMany()

  * db.collection.replaceOne()​

​

​

이름이 "SM3"인 데이터의 연도를 2022로 변경한다. 변경 전에는 2002년이었는데 실행 후에는 2022로 변경되었다.

> db.car.find({ name: "SM3" })

> db.car.update({ name : "SM3"}, { $set : { "year" : 2022 } })

> db.car.find({ name: "SM3" })
