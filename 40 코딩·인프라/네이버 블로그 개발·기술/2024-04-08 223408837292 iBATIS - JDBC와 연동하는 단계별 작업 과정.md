Member 테이블을 관리하는 DAO를 JDBC와 iBATIS로 구현해 본다. JDBC를 사용한 코드와 iBATIS를 사용한 코드를 비교해서 얼마나 많은 반복적인 코드가 간결해지는지 확인한다. 

**1\. Setup Program**

jdk-6u13-windows-i586-p.exe (JDK 1.6.0 - http://java.sun.com) eclipse-SDK-3.4.2-win32.zip (eclipse - http://www.eclipse.org) mysql-5.0.67-win32.exe (MySQL - http://www.mysql.com)

**2\. Required Library**

ibatis-2.3.4.726.jar (iBATIS - http://ibatis.apache.org) mysqljdbc.jar (MySQL - http://dev.mysql.com)

​

**3\. Create Table**

테스트를 위한 MEMBER 테이블이다. 구분하기 쉽도록 컬럼명에 MEMBER_ 를 붙였다. 

CREATE TABLE `member` ( `MEMBER_SN` int(11) NOT NULL, `MEMBER_NAME` varchar(20) default NULL, `MEMBER_AGE` int(11) default '0', PRIMARY KEY (`MEMBER_SN`) )

**4\. Model (Member.java)**

public class Member { private int sn; private String name; private int age; public Member() { } public String toString() { StringBuffer buffer = new StringBuffer(); buffer.append("Member["); buffer.append(" sn = ").append(sn); buffer.append(" name = ").append(name); buffer.append(" age = ").append(age); buffer.append("]"); return buffer.toString(); } public int getSn() { return sn; } public void setSn(int sn) { this.sn = sn; } public String getName() { return name; } public void setName(String name) { this.name = name; } public int getAge() { return age; } public void setAge(int age) { this.age = age; } }

**7\. iBATIS (MemberDaoImpl.java)**

iBATIS를 사용하여 구현한 코드는 간결하고 직관적이다.

import java.io.IOException; import java.io.Reader; import java.sql.SQLException; import java.util.List; import sample.db.dao.Member; import sample.db.dao.MemberDao; import com.ibatis.common.resources.Resources; import com.ibatis.sqlmap.client.SqlMapClient; import com.ibatis.sqlmap.client.SqlMapClientBuilder; public class MemberDaoImpl implements MemberDao { private SqlMapClient getSqlMap() { SqlMapClient sqlMap = null; try { Reader reader = Resources.getResourceAsReader("SqlMapConfig.xml"); sqlMap = SqlMapClientBuilder.buildSqlMapClient(reader); reader.close(); } catch (IOException e) { e.printStackTrace(); } return sqlMap; } @Override public List listMember() throws SQLException { return getSqlMap().queryForList("listMember"); } @Override public Member getById(int sn) throws SQLException { return (Member) getSqlMap().queryForObject("getMember", sn); } @Override public void addMember(Member member) throws SQLException { getSqlMap().insert("addMember", member); } @Override public void editMember(Member member) throws SQLException { getSqlMap().update("editMember", member); } @Override public void delMember(Member member) throws SQLException { getSqlMap().delete("delMember", member.getSn()); } }

**8\. iBATIS SqlMap 파일 (MemberSqlMap.xml)**

XML을 사용해서 SQL을 Java와 구분한다.

<?xml version="1.0" encoding="UTF-8" ?> <!DOCTYPE sqlMap PUBLIC "-//ibatis.apache.org//DTD SQL Map 2.0//EN" "http://ibatis.apache.org/dtd/sql-map-2.dtd"> <sqlMap namespace="Member"> <typeAlias alias="member" type="sample.db.dao.Member" /> <resultMap id="member-resultMap" class="member"> <result property="sn" column="MEMBER_SN" /> <result property="name" column="MEMBER_NAME" /> <result property="age" column="MEMBER_AGE" /> </resultMap> <select id="listMember" resultMap="member-resultMap"> SELECT * FROM MEMBER </select> <select id="getMember" parameterClass="int" resultMap="member-resultMap"> SELECT * FROM MEMBER WHERE MEMBER_SN = #sn# </select> <insert id="addMember" parameterClass="member"> INSERT INTO MEMBER (MEMBER_SN, MEMBER_NAME, MEMBER_AGE ) VALUES ( #sn#, #name#, #age# ) </insert> <update id="editMember" parameterClass="member"> UPDATE MEMBER SET MEMBER_NAME = #name#, MEMBER_AGE = #age# WHERE MEMBER_SN = #sn# </update> <delete id="delMember" parameterClass="int"> DELETE FROM MEMBER WHERE MEMBER_SN = #sn# </delete> </sqlMap>
