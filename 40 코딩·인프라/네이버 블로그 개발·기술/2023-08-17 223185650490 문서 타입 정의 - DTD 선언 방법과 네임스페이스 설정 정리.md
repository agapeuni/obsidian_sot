**DTS 개요**

웹 표준을 준수하기 위해서는 DTD(Document Type Definition), 즉 문서형 정의는 필수이다. 웹브라우저는 문서형 정의가 없는 문서를 쿼크 모드로 렌더링 하지만 문서형 정의가 있는 문서를 표준 모드로 렌더링 하기 때문이다. 그렇다면 표준을 준수한 홈페이지를 제작하기 위해서는 DTD를 선언해야 한다.

​

쿼크 모드 (Quirks mode)는 오래된 웹 브라우저를 위하여 디자인된 웹 페이지의 하위 호환성을 유지하기 위해 W3C나 IETF의 표준을 엄격히 준수하는 표준모드를 대신하여 쓰이는 웹브라우저 기술, 같은 코드라도 웹 브라우저마다 서로 다르게 해석하므로 전혀 다른 결과물을 보여준다.

​

그럼 DTD 선언은 어떤 것일까? 쉽게 설명하자면 xhtml 문서를 제작하기에 앞서 처음 부분에 명시를 해주면 된다. DTD 선언은 문서의 버전에 맞게 사용하면 된다. 각 버전마다 DTD 선언 방식이 조금씩 다르다. 또한 HTML 4.01과 XHTML 1.0의 문서 버전은 또 Strict, Transitional, Frameset으로 나누어진다.

​

​

**XHTML 1.0 Transitional (권장)**

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

**네임 스페이스와 언어 코드**

네임 스페이스는 필수 요소이다. XML 기반의 많은 문서들은 최상위 요소에 필수적으로 xmlns 설정이 필요하다. 그다음으로 언어 코드이다. 언어 코드는 xml:lang 속성으로 정의한다. 한국어는 'ko', 영국 영어는 'en', 미국 영어는 'en-US', 프랑스어는 'fr', 중국어는 'zh' 등이다. 하위호환성을 고려하여 lang 속성에도 같은 값을 지정해 둔다.

<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="ko" lang="ko">

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd"> <html xmlns="http://www.w3.org/1999/xhtml" xml:lang="ko" lang="ko"> <head> <meta content="text/html; charset=UTF-8" http-equiv="Content-Type" /> <title></title> </head>

​

​

**XHTML 1.1**

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN" "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd">

**네임 스페이스와 언어 코드**

xhtml 1.1 버전에서는 lang 속성이 없기 때문에 xml:lang 속성만으로 사용한다.

<html xmlns="http://www.w3.org/1999/xhtml" xml:lang="ko">

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN" "http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd"> <html xmlns="http://www.w3.org/1999/xhtml" xml:lang="ko"> <head> <meta content="text/html; charset=UTF-8" http-equiv="Content-Type" /> <title></title> </head>

**​**

**XML 선언 (생략 가능)**

XHTML은 XML 애플리케이션의 한 종류이기 때문에 문서의 처음 부분에 XML 선언을 기술한다. 문자 코드 세트를 사용하는 때는 XML 선언 생략이 가능하다고 한다. 하지만 어떤 문자코드세트를 이용하는 경우에도 정확히 지정하는 것을 강하게 추천한다. 버전 속성은 '1.0'이건 '1.1'이건 '1.0'으로 지정한다. 인코딩 속성에는 인코딩에 사용되는 문자코드세트를 지정한다.

<?xml version="1.0" encording="UTF-8"?>
