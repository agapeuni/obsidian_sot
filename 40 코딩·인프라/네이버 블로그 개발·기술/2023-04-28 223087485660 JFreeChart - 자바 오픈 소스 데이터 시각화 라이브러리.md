1\. JFreeChart 개요

JFreeChart는 Java 언어로 작성된 오픈 소스 데이터 시각화 라이브러리이다. Java 응용 프로그램에 차트를 쉽게 표시할 수 있도록 해준다. 사용이 어렵지 않으며 GNU LGPL(Lesser General Public License)의 조건에 따라 배포된다. JFreeChart는 다양한 종류의 차트를 생성하고, 다양한 출력 형식으로 저장할 수 있다. 

​

JFreeChart는 스윙(Swing)과 호환되며, 다른 그래픽 라이브러리와 함께 사용할 수도 있다. 이 라이브러리는 또한 다른 Java 라이브러리와 쉽게 통합할 수 있으며, 오픈 소스이므로 무료로 사용할 수 있다. JFreeChart는 다양한 차트 유형을 지원한다. 선 그래프, 막대 그래프, 산점도, 파이 차트, 거품 차트 등이 있다.
