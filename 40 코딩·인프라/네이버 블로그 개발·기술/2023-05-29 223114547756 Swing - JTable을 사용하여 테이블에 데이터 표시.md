**1\. 개요**

Swing의 JTable은 표 형식의 데이터를 표시하는 데 사용되는 컴포넌트다. JTable은 행과 열로 구성된 데이터를 표시하고, 사용자가 데이터를 편집하거나 선택할 수 있다. JTable을 사용하여 데이터를 표시하려면 데이터 모델을 정의해야 한다. 데이터 모델은 테이블의 내용과 구조를 제공한다. 

​

JTable은 javax.swing.table.TableModel 인터페이스를 구현하는 데이터 모델을 사용한다. 기본적으로 Swing은 DefaultTableModel 클래스를 제공하여 간단한 데이터 모델을 생성할 수 있다. JTable은 테이블 데이터를 동적으로 변경할 수도 있다. DefaultTableModel 클래스는 행 또는 열을 추가, 삭제, 수정하는 메서드를 제공하여 데이터 모델을 업데이트할 수 있다. 또한 사용자의 편집 작업을 감지하고 테이블 데이터를 업데이트하는 기능도 제공한다.

​

​

**2\. 예제1**

JTable을 생성하고 데이터 모델을 설정하는 코드는 다음과 같다. Swing JTable을 사용하여 데이터를 테이블 목록으로 표시해 본다. JTable에 표시할 데이터를 2차원 배열로 정의하고, 열 제목을 문자열 배열로 정의한다. 그런 다음 DefaultTableModel을 사용하여 데이터 모델을 생성하고 데이터와 열 제목을 설정한다. 

​

파일 : JTableExample.java

import javax.swing.JFrame; import javax.swing.JScrollPane; import javax.swing.JTable; import javax.swing.table.DefaultTableModel; public class JTableExample { public static void main(String[] args) { JFrame frame = new JFrame("JTable Example"); frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); // 테이블 데이터 Object[][] data = { { "홍길동", 25, "한국" }, { "왕서방", 30, "중국" }, { "나까무라", 28, "일본" }, { "김철수", 25, "한국" }, { "등소평", 30, "중국" }, { "요시다", 28, "일본" } }; // 테이블 열 제목 String[] columnNames = { "이름", "나이", "국가" }; // DefaultTableModel 생성 및 데이터 설정 DefaultTableModel model = new DefaultTableModel(data, columnNames); // JTable 생성 및 데이터 모델 설정 JTable table = new JTable(model); // JTable을 JScrollPane에 추가하여 스크롤 가능하게 함 JScrollPane scrollPane = new JScrollPane(table); // 프레임에 JScrollPane 추가 frame.add(scrollPane); frame.pack(); frame.setVisible(true); } }

**3\. 예제2**

JTable은 생성된 데이터 모델을 사용하여 데이터를 표시한다. 

마지막으로 JTable을 JScrollPane에 추가하여 스크롤 가능한 테이블을 생성하고, JScrollPane를 JFrame에 추가한다.

​

파일 : JTableModel.java​

import java.awt.BorderLayout; import java.awt.event.MouseEvent; import java.awt.event.MouseListener; import javax.swing.JFrame; import javax.swing.JPanel; import javax.swing.JScrollPane; import javax.swing.JTable; import javax.swing.ListSelectionModel; import javax.swing.table.DefaultTableModel; class JTableModel extends JPanel implements MouseListener { private static final long serialVersionUID = 1L; public JTableModel() { setLayout(new BorderLayout()); final String[][] data = { { "한길", "컴퓨터과학", "Python" } , { "두길", "컴퓨터공학", "Java" } , { "세길", "소프트웨어공학", "C++" } , { "홍길동", "전산과", "C#" } }; final String[] columnNames = { "이름", "학과", "과목" }; DefaultTableModel model = new DefaultTableModel(data, columnNames); JTable jtable = new JTable(model); jtable.setSelectionMode(ListSelectionModel.SINGLE_SELECTION); jtable.addMouseListener(this); JScrollPane pane = new JScrollPane(jtable); add(pane, BorderLayout.CENTER); } public static void main(String[] args) { JFrame f = new JFrame("Swing JTable"); f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE); JTableModel table = new JTableModel(); f.add(table); f.setSize(300, 200); f.setVisible(true); } public void mouseClicked(MouseEvent e) { } public void mouseEntered(MouseEvent e) { } public void mouseExited(MouseEvent e) { } public void mousePressed(MouseEvent e) { } public void mouseReleased(MouseEvent e) { } }
