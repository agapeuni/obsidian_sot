**1\. 객체직렬화란?**

객체 직렬화(Object Serialization)는 Java에서 사용되는 중요한 기능 중 하나로, 자바 객체를 바이트 스트림으로 변환하거나, 반대로 바이트 스트림을 자바 객체로 변환하는 프로세스를 말한다. 이를 통해 객체를 파일에 저장하거나 네트워크를 통해 전송하는 등의 용도로 활용할 수 있다.

​

​

**2\. 프로그램 작성 방법**

java.io.Serializable interface를 implements 한다.

\- 이 인터페이스는 구현해주어야 할 메소드가 없다.(Flag 인터페이스라 함)

\- 이 interface를 구현하지 않은 객체 직렬화 시, NotSerializableException

ex) class A implements Serializable{}

​

\- 직렬화하지 않을 변수는 transient를 붙여준다.

\- 직렬화된 클래스를 상속받은 클래스도 직렬화 가능하다.

​

\- UnicastRemoteObject 상속받는 

원격 클래스 객체는 스텁 객체로 복사되어 전달

다른 클래스 객체는 직렬화되어 전달

\- Serializable 구현한 클래스에서 참조하는 객체들까지 모두 Serializavle 해야 한다.

또는 2. java.io.Externalizable interface를 implements 한다.

class A extends Parent implements Externalizable{}

class A의 변수 중

직렬화하지 않을 변수는 앞에 transient를 붙여주고,

직렬화할 변수는 stream.writeLong(pData); 이런 식으로 하나씩 다 처리해주어야 한다. 

​

​

**3\. 예제**

import java.io.FileInputStream; import java.io.FileOutputStream; import java.io.IOException; import java.io.ObjectInput; import java.io.ObjectInputStream; import java.io.ObjectOutputStream; import java.io.Serializable; class Serial implements Serializable { private static final long serialVersionUID = 1L; int data; }; class SerializableTest { public static void main(String[] args) throws IOException, ClassNotFoundException { Serial serial1 = new Serial(); serial1.data = 10; ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("object.dat")); oos.writeObject(serial1); serial1.data = 500; // 이미 직렬화된 객체가 있으면 // reset()을 하기전까지는 그 객체가 변경되지 않는다. // oos.reset(); oos.writeObject(serial1); oos.close(); ObjectInput ois = new ObjectInputStream(new FileInputStream("object.dat")); Serial serial2 = (Serial) ois.readObject(); System.out.println("serial2.data = " + serial2.data); Serial serial3 = (Serial) ois.readObject(); System.out.println("serial3.data = " + serial3.data); serial2.data = 100; System.out.println("serial2.data = " + serial2.data); System.out.println("serial3.data = " + serial3.data); } }
