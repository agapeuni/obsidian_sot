**1\. Log4Ajax 개요**

Ajax 코딩은 서버와 비동기적으로 동작하여 디버깅하기가 쉽지 않다. Log4Ajax를 사용하면 편리하고 간단하게 Ajax 디버깅을 할 수 있다. Log4Ajax를 활용하면 Ajax 기반의 데이터 송 수신 및 렌더링 정보를 로그로 찍어 볼 수 있다. 웹 화면 개발할 때 코드에 로그를 작성해 두면 버그가 발생하거나 오류가 생겼을 때 로그를 바로 출력한다.

​

**2.****Log4Ajax****예제**

Log4Ajax 사용하려는 페이지에 JavaScript 파일을 추가한다.

<script type="text/javascript" src="js/request.js"></script> <script type="text/javascript" src="js/log4ajax.js"></script>

​

로깅이 필요한 곳에 debug, info 메서드를 사용한다.

LOG.debug('버튼 클릭: ' + this.id);

LOG.info('버튼 클릭: ' + this.id);

​

파일 : Log4Ajax.html

<html> <head> <title>Log4Ajax 예제</title> <link rel="stylesheet" href="style.css" type="text/css" /> <script type="text/javascript" src="js/request.js"></script> <script type="text/javascript" src="js/log4ajax.js"></script> </head> <body> <center> <h2> <code>Log4Aajax 예제</code> </h2> <br /> <table> <tr> <td><input type="button" id="button1" value="버튼1" onclick="LOG.debug('버튼1 클릭: ' + this.id);" onmouseover="LOG.debug('버튼1 Mouseover: ' + this.id);" /></td> <td><input type="button" id="button2" value="버튼2" onclick="LOG.debug('버튼2 클릭: ' + this.id);" onmouseover="LOG.info('버튼2 Mouseover: ' + this.id);" /></td> </tr> </table> <!-- Log Console --> <table align="center"> <tr align="center"> <td><input type="button" id="clearLogConsole" value="Clear Debug Console" onclick="getElementById('logConsole').innerHTML='';" /></td> </tr> <tr> <td> <div class="consoleDiv" id="logConsole"></div> </td> </tr> </table> </center> <script type="text/javascript"> LOG.debug("초기화"); </script> </body> </html>
