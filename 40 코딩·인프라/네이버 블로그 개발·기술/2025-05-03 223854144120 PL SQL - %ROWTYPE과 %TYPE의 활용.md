# 2025-05-03 223854144120 PL SQL - %ROWTYPE과 %TYPE의 활용

- 게시일: 2025. 5. 3. 12:00

## 본문

![](https://postfiles.pstatic.net/MjAyNTA1MDNfMTA2/MDAxNzQ2MjM3MDgxMjQw.c5QfdCG9D6iWMrFjYoi3H3UfNRWYXA1mF9YW8sVgwtwg.7zbWiajnIAlL5W2BqkQgeqTK_jaCrM3wCyJEyGjzI9sg.PNG/PL_SQL-001_\(2\).png?type=w80_blur)

​

PL/SQL에서는 일반적으로 BOOLEAN, CHAR, VARCHAR2, DATE, NUMBER와 같은 데이터 타입을 변수 선언에 사용한다. 그러나 보다 유연하고 효율적인 프로그래밍을 위해, 특정 **테이블이나 컬럼과 동일한 형식의 데이터 타입** 을 직접 변수에 지정할 수 있는 기능이 제공된다. 이를 위해 사용하는 것이 바로 **%ROWTYPE** 과 **%TYPE** 속성이다.

**​**

**1\. %ROWTYPE의 개념**

%ROWTYPE은 **특정 테이블 또는 뷰의 한 행(row) 전체와 동일한 구조** 를 갖는 변수(레코드)를 선언할 때 사용하는 속성이다. 말하자면, 하나의 변수 안에 해당 테이블의 모든 컬럼 구조와 동일한 메모리 공간이 자동으로 생성된다. 이는 C 언어의 구조체(struct)와 유사하며, 여러 개의 관련된 필드를 한꺼번에 다루고자 할 때 매우 유용하다.

​

가령 다음과 같은 구조를 가진 brand라는 테이블이 있다고 가정하자.

**BID** |  **BRAND_NAME** |  **BRAND_TEL** |  **BRAND_ADDR**  
---|---|---|---  
B1 |  SAMSUNG |  031-333-3333 |  경기 수원시 권선구  
  
이 테이블과 같은 구조를 가지는 하나의 변수를 PL/SQL에서 선언하면 다음과 같이 작성한다.

DECLARE brand_record brand%ROWTYPE; 

이렇게 선언된 brand_record는 아래와 같은 구성의 구조를 갖는다.

  * brand_record.bid

  * brand_record.brand_name

  * brand_record.brand_tel

  * brand_record.brand_addr

​

각 항목은 brand 테이블의 컬럼과 동일한 데이터 타입과 길이를 가지며, 값은 다음과 같이 할당할 수 있다.

brand_record.bid := 'B100'; brand_record.brand_name := 'NOKIA'; 

즉, brand_record 변수는 brand 테이블의 한 행 전체를 담을 수 있는 하나의 복합 변수로 동작한다.

​

**사용 시 장점**

  * 테이블의 열 수나 데이터 타입을 일일이 몰라도 사용 가능

  * 테이블 구조가 변경되면 변수 선언도 자동 반영됨

  * SELECT * 문으로 데이터를 한 번에 할당하기에 적합

  * 전체 행을 조작할 때 매우 편리

**​**

아래는 brand 테이블에 새로운 브랜드 'NOKIA'를 추가하되, 기존의 'LG' 브랜드와 **전화번호 및 주소** 정보를 공유하도록 하는 예제이다.

DECLARE brand_new brand%ROWTYPE; BEGIN SELECT * INTO brand_new FROM brand WHERE brand_name = 'LG'; INSERT INTO brand VALUES ('B5', 'NOKIA', brand_new.brand_tel, brand_new.brand_addr); COMMIT; END; / 

이 예제에서 brand_new 변수는 'LG' 브랜드의 행 전체를 그대로 가져온 후, 그 중 일부 필드를 사용하여 'NOKIA' 브랜드를 삽입하는 데 활용된다.

**​**

**​**

**2\. %TYPE의 개념**

%TYPE은 **특정 테이블 또는 뷰의 단일 컬럼과 동일한 데이터 타입을 가진 변수** 를 선언할 때 사용하는 속성이다. 이 방식은 변수의 데이터 타입을 직접 지정하지 않고, 테이블에 정의된 컬럼의 타입을 참조함으로써, 유지 보수를 보다 유연하게 만든다.

v_brand_name BRAND.BRAND_NAME%TYPE := 'KTFT'; 

위 선언은 brand 테이블의 brand_name 컬럼과 **동일한 데이터 타입** 을 가지는 v_brand_name이라는 변수를 선언하는 것이다.

만약 brand_name 컬럼의 타입이 나중에 VARCHAR2(50)에서 VARCHAR2(100)으로 변경되더라도, v_brand_name은 자동으로 해당 변경 사항을 반영하게 된다.

​

**주요 장점**

  * 컬럼 타입이 변경될 경우 별도의 변수 수정 없이 자동 반영

  * 변수 선언의 일관성 유지

  * 에러 발생 가능성을 줄이고, 가독성 향상

**​**

**​**

PL/SQL에서 %ROWTYPE과 %TYPE은 변수 선언 시 매우 유용한 도구이다. 각각 다음과 같은 상황에서 효과적으로 활용할 수 있다.

**속성** |  **사용 목적**  
---|---  
%ROWTYPE |  테이블 전체 행을 저장하거나 조작할 때  
%TYPE |  특정 컬럼과 동일한 타입의 단일 변수 선언 시  
  
이러한 동적 타입 지정은 코드의 유지 보수성과 안정성을 높이는 데 큰 도움이 되며, 특히 테이블 구조가 자주 변경될 수 있는 환경에서는 더욱 유용하다.

​

​

**%ROWTYPE과 %TYPE을 활용한 고급 예제**

**​**

**예제 1: 행 복사 및 데이터 일부 수정 후 삽입 (%ROWTYPE 활용)**

DECLARE v_old_emp emp%ROWTYPE; BEGIN \-- 기존 사원 정보 복사 SELECT * INTO v_old_emp FROM emp WHERE empno = 7369; \-- 사번 변경 및 신규 직원으로 삽입 v_old_emp.empno := 8001; v_old_emp.ename := 'NEW_SCOTT'; v_old_emp.hiredate := SYSDATE; INSERT INTO emp VALUES v_old_emp; COMMIT; END; / 

​**활용 포인트**

  * 기존 사원의 모든 정보를 복사하여 새로운 사원으로 추가

  * %ROWTYPE 덕분에 모든 컬럼을 따로 지정할 필요 없음

**​**

**​**

**예제 2: 컬럼 데이터타입 변경에도 안전한 변수 선언 (%TYPE 활용)**

DECLARE v_sal emp.sal%TYPE; v_comm emp.comm%TYPE; BEGIN SELECT sal, comm INTO v_sal, v_comm FROM emp WHERE empno = 7788; DBMS_OUTPUT.PUT_LINE('급여: ' || v_sal || ', 커미션: ' || NVL(v_comm, 0)); END; / 

​**활용 포인트**

  * sal과 comm 컬럼의 타입 변경 시, 코드 수정 없이 자동 반영

  * 실무에서 급여, 수당 등 재무 관련 처리 시 유용

**​**

**​**

**예제 3: 테이블 변경에도 유연하게 대응하는 조회 로직**

DECLARE v_dept dept%ROWTYPE; BEGIN FOR dept_rec IN (SELECT * FROM dept) LOOP v_dept := dept_rec; DBMS_OUTPUT.PUT_LINE(v_dept.deptno || ': ' || v_dept.dname || ' - ' || v_dept.loc); END LOOP; END; / 

**활용 포인트**

  * dept 테이블 구조가 변경되더라도 자동 반영

  * 반복문과 %ROWTYPE을 결합하여 코드 간결화
