1\. urllib.request 개요

urllib.request는 URL(Uniform Resource Locator)을 가져오기 위한 라이브러리이다. Python에 내장되어 있어 설치가 필요없고 URL을 접근하기 위한 함수와 클래스가 정의되어 있다.

​

​

2\. URL 가져오기

urllib.request의 기본적인 예제로 urlopen을 사용하여 페이지 내용을 출력하는 예제이다. utf-8로 디코드를 해야 한글이 잘 표시된다.

import urllib.request as req with req.urlopen("http://agapeuni.dothome.co.kr/") as res: html = res.read().decode('utf-8') print(html)

3\. URL 저장하기

urlopen으로 가져온 정보를 파일에 저장하는 예제이다. 파일 내용은 위의 예제 결과와 같다.

import urllib.request as req with req.urlopen("http://agapeuni.dothome.co.kr/") as res: html = res.read().decode("utf-8") with open("example_app/urllib/urllib_2.html", mode="w") as f: f.write(html)

4\. 헤더 정**보**

헤더 정보를 표시하는 예제이다. getHeaders() 함수로 전체로 접근할 수 있고 getHeader() 함수로 개별적으로 접근할 수 있다.

import urllib.request as req with req.urlopen("http://agapeuni.dothome.co.kr/") as res: # 상태코드 print(res.status) print() # 헤더정보 print(res.headers) print() # 헤더정보 header = res.getheaders() for item in header: print(item) print() # 헤더정보 개별접근 content_type = res.getheader("content-type") print(content_type)
