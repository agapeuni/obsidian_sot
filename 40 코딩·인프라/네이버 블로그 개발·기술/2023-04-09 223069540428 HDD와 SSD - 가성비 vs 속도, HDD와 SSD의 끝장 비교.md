# 2023-04-09 223069540428 HDD와 SSD - 가성비 vs 속도, HDD와 SSD의 끝장 비교

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223069540428&categoryNo=982

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTBfMTUg/MDAxNzQ0MjI4MDI2MDIx.7MWYhMrihsBtW478ibQFnMANr43NEZC9aXQ4fLBo_F4g.EGATbquhApsZSiHajQxPNPvva2a-KqBep9UKHLAmRkMg.PNG/%EC%A3%BC%EB%B3%80%EC%9E%A5%EC%B9%98-001_\(9\).png?type=w80_blur)

​

HDD와 SSD는 컴퓨터의 데이터 저장 장치로 사용되는 두 가지 유형의 하드 드라이브이다. HDD(Hard Disk Drive)는 회전하는 원판에 자기장을 이용하여 데이터를 저장하고 읽는 방식으로 작동한다. 반면에, SSD(Solid State Drive)는 반도체 기술을 사용하여 데이터를 저장하고 읽는다.

​

얼마전까지만 해도 SSD의 빠른 장점과 HDD의 가성비로 인해 함께 사용하는 경우가 많다. SSD는 C 드라이브로 설정하여 윈도와 프로그램을 설치하고 HDD는 별도의 드라이브로 할당하여 사진이나 동영상 등의 데이터를 저장한다. 최근에는 SSD 용량도 커지면서 이전보다 가격이 낮아저 SSD만으로 구성된 제품이 출시된다.

​

**1\. HDD의 개요**

HDD는 Hard Disk Drive(하드 디스크 드라이브)의 약자로 SSD가 나오기까지 오랜 시간 동안 저장장치의 역할을 담당해 왔다. 상대적으로 저렴한 가격으로 대용량 데이터를 저장할 수 있어 지금까지 널리 사용되고 있다.

​

HDD의 내부를 보면 데이터를 저장하는 원판 모양의 플래터가 있고 컴퍼스처럼 생긴 액츄에이터 끝에 자기헤드가 있다. 고속으로 회전하는 플래터 위에 헤드가 움직이면서 데이터를 읽고 쓴다. 약간의 틈을 두고 움직이기 때문에 회전 중에 외부 충격으로 인해 고장이 발생할 수 있다. (아래의 사진을 참고)

![](https://postfiles.pstatic.net/MjAyMzA0MDlfMTA3/MDAxNjgxMDQyOTI0ODgx.S9td9GqK77eU2abjdlZGhU-aCvTt_U0NtDILOdaBjlsg.-uAmXvuu9CZZP_cU-lN5xUN--QbFswzASYOc6EYicRcg.PNG.agapeuni/img.png?type=w80_blur)

**1.1 HDD의 장점**

  * 저장할 수 있는 용량이 크고 "용량 단가"가 저렴하다.

  * 대용량 파일을 저장할 수 있고 데이터를 오랜시간 보존할 수 있어 안정성이 높다.

​

​

**1.2 HDD의 단점**

  * 기계적인 움직임으로 인해 동작음과 진동이 발생한다.

  * 외부 충격에 약하고 소비전력이 크다.

  * SSD에 비해 읽고 쓰는 속도가 느리다.

​

​

**2\. SSD의 개요**

SSD는 Solid State Drive(솔리드 스테이트 드라이브)의 약자로 반도체 메모리를 사용하여 데이터 읽고 쓰는 속도가 빠르다. RAM 휘발성 메모리라 전원을 끄면 데이터가 날아가는데 SSD에는 플래시 메모리를 사용해 전원을 꺼도 데이터가 사라지지 않는다. HDD보다 전력 소모가 작아 노트북에 많이 사용한다.

![](https://postfiles.pstatic.net/MjAyMzA0MDlfMTIw/MDAxNjgxMDQyOTMxNjE0.LJIjjJxHSPltUdey-YGLnrMjNqtPFX7EJq72S3om8f0g.R8V-9NfyC1cB9CQZ9Oj_h5C9Amoyuyvn3vyTEpV1wHgg.JPEG.agapeuni/img.jpg?type=w80_blur)

**2.1 SSD의 장점**

  * HDD에 비해 전송속도가 빠르다.

  * 외부 충격에 강하고 소비 전력이 적다.

  * HDD에 비해 발열이 적고 작동음과 진동이 없다.

​

​

**2.2 SSD의 단점**

  * 저장할 수 있는 용량이 작고 "용량 단가"가 HDD에 비해 높다.

  * 고장이 발생하면 데이터를 복구하기 어렵다.

  * 한 번에 쓰거나 지워지는 데이터의 양에 제한이 있다.
