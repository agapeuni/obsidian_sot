**1\. 개요**

웹 페이지에서 폼 엘리먼트((input, textarea, checkbox, radio, select)에 사용자가 입력한 정보를 v-model 디렉티브를 사용하여 데이터와 연결하는 방법을 알아보자.

​

**2\. input과 textarea 예제**

input과 textarea는 사용자의 입력을 위한 대표적인 폼 엘리먼트이다. input과 textarea를 만들고 사용자의 입력을 데이터와 연결해 보자.

<!DOCTYPE html> <html> <head> <meta charset="UTF-8" /> <title>Vue.js</title> <script src="https://cdn.jsdelivr.net/npm/vue@2.6.12/dist/vue.js"></script> </head> <body> <div id="app"> <input v-model="text1" /> <p>input = {{ text1 }}</p> <p>length = {{ text1.length }}</p> <br /> <textarea v-model="text2"></textarea> <p>textarea = {{ text2 }}</p> <p>length = {{ text2.length }}</p> </div> <script> new Vue({ el: "#app", data: { text1: "input", text2: "textarea" }, }); </script> </body> </html>

**3\. checkbox와 radio 예제**

checkbox와 radio는 사용자의 선택을 위한 대표적인 폼 엘리먼트이다. checkbox와 radio를 만들고 사용자의 입력을 데이터와 연결해 보자.

<!DOCTYPE html> <html> <head> <meta charset="UTF-8" /> <title>Vue.js</title> <script src="https://cdn.jsdelivr.net/npm/vue@2.6.12/dist/vue.js"></script> </head> <body> <div id="app"> <input type="checkbox" v-model="check1" /> <p>checkbox1 = {{ check1 }}</p> <br /> <input type="checkbox" value="one" v-model="check2" /> <input type="checkbox" value="two" v-model="check2" /> <input type="checkbox" value="three" v-model="check2" /> <p>checkbox2 = {{ check2 }}</p> <br /> <input type="radio" value="1" v-model="radio1" /> 1 <input type="radio" value="2" v-model="radio1" /> 2 <input type="radio" value="3" v-model="radio1" /> 3 <p>radio1 = {{ radio1 }}</p> </div> <script> new Vue({ el: "#app", data: { check1: false, check2: ["three"], radio1: "3", }, }); </script> </body> </html>

select는 옵션이 많을 때 사용자의 선택을 위한 대표적인 폼 엘리먼트이다. select를 만들고 사용자의 입력을 데이터와 연결해 보자.

<!DOCTYPE html> <html> <head> <meta charset="UTF-8" /> <title>Vue.js</title> <script src="https://cdn.jsdelivr.net/npm/vue@2.6.12/dist/vue.js"></script> </head> <body> <div id="app"> <select v-model="select1"> <option disabled value="">= Select =</option> <option>onw</option> <option>two</option> <option>three</option> </select> <p>select1 = {{ select1 }}</p> <br /> <select v-model="select2" multiple> <option disabled value="">= Select =</option> <option>onw</option> <option>two</option> <option>three</option> </select> <p>select2 = {{ select2 }}</p> </div> <script> new Vue({ el: "#app", data: { select1: "two", select2: ["onw", "two"], }, }); </script> </body> </html>
