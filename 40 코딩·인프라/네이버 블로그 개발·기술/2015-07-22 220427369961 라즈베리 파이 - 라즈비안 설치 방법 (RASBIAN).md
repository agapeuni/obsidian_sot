# 2015-07-22 220427369961 라즈베리 파이 - 라즈비안 설치 방법 (RASBIAN)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220427369961&categoryNo=982
- 게시일: 2015. 7. 22. 1:05

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTQy/MDAxNzU4NDQyMjQ5NzI4.FUOJPwfTw3rFwQtcWRwQJSGkJldYpSW7rxlvYkqNhckg.ya7a6q-AmSG4Eo_pQddDa5o-LvDiSvhDkhsejojgxl0g.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(12\).png?type=w80_blur)

​

이번에는 라즈베리 파이에 라즈비안 위지를 설치하는 방법에 대해서 알아보겠습니다.

![](https://postfiles.pstatic.net/20150721_107/agapeuni_1437406047074tSCtI_JPEG/_%B1%D7%B8%B21_%B6%F3%C1%EE%BA%A3%B8%AE_%C6%C4%C0%CC.jpg?type=w80_blur)

​

먼저 라즈베리 파이 사이트에 가서 Downloads 메뉴를 클릭한 뒤 최신의 RASBIAN을 다운로드합니다. 

현재 기준으로는 Release date: 2015-05-05 가 최신입니다.

<https://www.raspberrypi.org/>

![](https://postfiles.pstatic.net/20150721_202/agapeuni_1437465469537hl073_JPEG/20150228_034938.png?type=w80_blur)

​

다른로드 받은 2015-02-16-raspbian-wheezy.iso 파일입니다.

![](https://postfiles.pstatic.net/20150721_143/agapeuni_1437465540825waOtG_JPEG/20150228_035852.png?type=w80_blur)

**​**

**SDFormatter** 프로그램으로 SD 카드를 포맷합니다.

SD 카드를 넣고 Format 버튼을 클릭합니다.

![](https://postfiles.pstatic.net/20150721_122/agapeuni_14374060480427xOer_PNG/20150228_035912.png?type=w80_blur)

아래의 문구가 나오면 확인을 눌러줍니다. "빠른 포맷을 원하십니까?"

![](https://postfiles.pstatic.net/20150721_256/agapeuni_1437406049174XRS9v_PNG/20150228_035925.png?type=w80_blur)

아래의 문구가 나오면 확인을 눌러줍니다. "정말 포맷을 하시겠습니까?"

![](https://postfiles.pstatic.net/20150721_216/agapeuni_1437406049440a1sLU_PNG/20150228_035931.png?type=w80_blur)

​

포맷이 진행이 됩니다. SD 카드 포맷이라 금방 포맷이 완료됩니다.

![](https://postfiles.pstatic.net/20150721_263/agapeuni_1437406049672HEKE1_PNG/20150228_035935.png?type=w80_blur)

메모리 카드 포맷이 완료되었습니다.

![](https://postfiles.pstatic.net/20150721_209/agapeuni_14374060499113Wrdl_PNG/20150228_035937.png?type=w80_blur)

​

그럼 이번에는**Win32 Disk Imager** 프로그램으로 SD카드에 다운로드한 이미지 파일을 Write 합니다.

![](https://postfiles.pstatic.net/20150721_218/agapeuni_1437406051172tdEio_PNG/20150228_040518.png?type=w80_blur)

​

다운로드한 2015-02-16-raspbian-wheezy.iso 파일을 불러옵니다.

그리고 Write 버튼을 클릭합니다.

![](https://postfiles.pstatic.net/20150721_101/agapeuni_1437406051376NtdBM_PNG/20150228_040545.png?type=w80_blur)

쓰기가 완료되었습니다.

![](https://postfiles.pstatic.net/20150721_94/agapeuni_14374060516365cwTl_PNG/20150228_041055.png?type=w80_blur)

**SDFormatter** 프로그램으로 SD 카드를 포맷하고**Win32 Disk Imager** 프로그램으로 SD카드에 다운로드한 이미지 파일을 Write 하고 나서 라즈베리 파이에 SD 카드를 장착하고 모니터, 키보드를 연결한 뒤 전원을 꼽고 잠시 기다리면 아래의 화면이 표시됩니다.

​

​

**1\. 파일시스템 확장 (Expand Filesystem)**

SD카드에 이미지로 Write 하고 남은 공간을 전체로 사용할 수 있습니다. 메뉴를 선택하고 <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_202/agapeuni_1437406051868bhFv9_JPEG/SAM_6783.JPG?type=w80_blur)

루트 파티션은 크기가 조정되었습니다. 

파일 시스템은 다음 재부팅 시 확대됩니다. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_99/agapeuni_14374060520893P1Tm_JPEG/SAM_6784.JPG?type=w80_blur)

​

**2\. 사용자 비밀번호 변경 (Change User Password)**

디폴트 사용자 pi의 비밀번호를 변경합니다. 메뉴를 선택하고 <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_14/agapeuni_143740605232004hiV_JPEG/SAM_6785.JPG?type=w80_blur)

​

이제 파이 사용자에 대한 새 암호를 입력해야 합니다. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_292/agapeuni_1437406052492szeei_JPEG/SAM_6786.JPG?type=w80_blur)

아래에 새로운 비밀번호를 입력하는 프롬프트가 표시됩니다. 한 번 입력하고 확인으로 한번 더 입력합니다.

![](https://postfiles.pstatic.net/20150721_162/agapeuni_1437406052687XfNIB_JPEG/SAM_6787.JPG?type=w80_blur)

비밀번호가 성공적으로 변경되었습니다.

![](https://postfiles.pstatic.net/20150721_110/agapeuni_14374060529294MleH_JPEG/SAM_6788.JPG?type=w80_blur)

**3\. 바탕화면 부팅 활성화 (Enable Boot to Desktop/Scratch)**

데스크톱 환경으로 부팅할지 커맨드 라인으로 부팅할지 선택하는 메뉴입니다. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_188/agapeuni_1437406053159Wt9lC_JPEG/SAM_6789.JPG?type=w80_blur)

디폴트로 텍스트 콘솔 모드가 선택되어 있습니다. 필요에 따라 다른 것은 선택할 수 있습니다. <Cancel>을 선택합니다.

![](https://postfiles.pstatic.net/20150721_9/agapeuni_1437406053327XArpv_JPEG/SAM_6790.JPG?type=w80_blur)

**4\. 국제화 옵션 (Internationalisation Options)**

언어나 지역적인 설정을 하는 메뉴입니다.

![](https://postfiles.pstatic.net/20150721_288/agapeuni_1437406053533hbVG7_JPEG/SAM_6791.JPG?type=w80_blur)

**I1. 로케일 변경 (Change Locale)**

사용자의 위치에 맞게 언어 및 지역 설정. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_13/agapeuni_1437406053885QkfhJ_JPEG/SAM_6792.JPG?type=w80_blur)

로케일 선택하는 화면이 표시됩니다.

![](https://postfiles.pstatic.net/20150721_190/agapeuni_1437406054089OQEm1_JPEG/SAM_6793.JPG?type=w80_blur)

​

en_GB.UTF-8, en_US.UTF-8 체크합니다.

![](https://postfiles.pstatic.net/20150721_297/agapeuni_1437406054286Md1Ue_JPEG/SAM_6794.JPG?type=w80_blur)

ko_KR.UTF-8 체크 후 <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_251/agapeuni_1437406054516ISu9u_JPEG/SAM_6795.JPG?type=w80_blur)

​

시스템 기본 로케일로 en_US.UTF-9 체크. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_125/agapeuni_1437406054858Frvw2_JPEG/SAM_6796.JPG?type=w80_blur)

​

아래쪽에 로케일 생성 로그가 표시됩니다.

![](https://postfiles.pstatic.net/20150721_99/agapeuni_1437406055335fats4_JPEG/SAM_6798.JPG?type=w80_blur)

​

생성이 완료되었습니다.

![](https://postfiles.pstatic.net/20150721_34/agapeuni_1437406056111giN7T_JPEG/SAM_6802.JPG?type=w80_blur)

**I3. 키보드 레이아웃 변경 (Change Keyboard Layout)**

키보드 설정을 하는 메뉴입니다. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_93/agapeuni_14374060563077luIN_JPEG/SAM_6803.JPG?type=w80_blur)

**​**

키보드 모델로 Generic 105-key (Intl) PC 선택후 <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_189/agapeuni_1437406056712EhYO6_JPEG/SAM_6805.JPG?type=w80_blur)

​

키보드 레이아웃으로 English (UK) 선택후 <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_79/agapeuni_1437406057171US6H8_JPEG/SAM_6807.JPG?type=w80_blur)

The default for the keyboard layout 선택 후 <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_195/agapeuni_1437406057675FDX0q_JPEG/SAM_6809.JPG?type=w80_blur)

No compose key 선택 후 <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_283/agapeuni_14374060578905vtcF_JPEG/SAM_6810.JPG?type=w80_blur)

Control + Atl + Backspace 키 조합으로 X Server 종료를 사용하지를 확인하는 화면입니다. <No> 선택합니다.

![](https://postfiles.pstatic.net/20150721_99/agapeuni_1437406058385NbHRX_JPEG/SAM_6812.JPG?type=w80_blur)

**5\. 카메라 활성 (Enable Camera)**

라즈베리 파이 카메라로 작업할 경우 활성화합니다. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_271/agapeuni_1437406058604ro2zL_JPEG/SAM_6813.JPG?type=w80_blur)

라즈베리 파이 카메라에 대한 지원을 활성화하시겠습니까? <Disable> 선택합니다.

![](https://postfiles.pstatic.net/20150721_280/agapeuni_1437406058795hl3G1_JPEG/SAM_6814.JPG?type=w80_blur)

**6\. Rastrack에 추가 (Add to Rastrack)**

[http://rastrack.co.uk/에](http://rastrack.co.uk/) 이 파이를 등록하는 경우에 선택하는 메뉴. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_66/agapeuni_1437406059033SNvHD_JPEG/SAM_6815.JPG?type=w80_blur)

<http://rastrack.co.uk/> 웹사이트에 등록한다는 안내 문구. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_147/agapeuni_1437406059226WK1Ab_JPEG/SAM_6816.JPG?type=w80_blur)

사용자명이나 닉네임을 입력. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_300/agapeuni_1437406059784OVRjr_JPEG/SAM_6818.JPG?type=w80_blur)

​

이메일 주소를 입력. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_268/agapeuni_143740609875920soL_JPEG/SAM_6819.JPG?type=w80_blur)

성공적으로 등록하면 아래와 같이 <http://rastrack.co.uk/> 사이트에 표시됩니다. 참고로 사이트에서 등록하였습니다.

![](https://postfiles.pstatic.net/20150722_158/agapeuni_1437493322038kzglV_PNG/20150722_004143.png?type=w80_blur)

​

**7\. 오버클럭 (Overclock)**

파이 오버클러킹 설정을 하는 메뉴입니다. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_72/agapeuni_1437406099203UiXrP_JPEG/SAM_6821.JPG?type=w80_blur)

오버클러킹을 하면 파이의 생명이 줄어든다는 안내 문구입니다. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_193/agapeuni_1437406099436k0kex_JPEG/SAM_6822.JPG?type=w80_blur)

700부터 800, 900, 950 최대 1000MHz까지 오버클럭이 됩니다. <Ok> 선택하고 싶은 유혹이 들지만 자제합니다.

![](https://postfiles.pstatic.net/20150721_44/agapeuni_14374060995846OG9T_JPEG/SAM_6823.JPG?type=w80_blur)

라즈베리 파이의 수명연장을 생각하여 <Cancel>을 선택하여 기본인 700MHz로 사용합니다.

![](https://postfiles.pstatic.net/20150721_266/agapeuni_1437406099773KPomF_JPEG/SAM_6824.JPG?type=w80_blur)

​

**8\. 고급 옵션 (Advanced Options)**

고급 옵션 설정하는 메뉴입니다. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_168/agapeuni_14374061001050Kqqd_JPEG/SAM_6826.JPG?type=w80_blur)

**A3. 메모리 분할 (Memory Split)**

GPU 메모리 크기를 설정한다. 전체 512M에서 GPU 메모리를 설정하고 나머지를 ARM CPU 메모리로 사용합니다.

![](https://postfiles.pstatic.net/20150721_18/agapeuni_1437406100260hMNTK_JPEG/SAM_6827.JPG?type=w80_blur)

GPU 메모리를 얼마나 설정할지를 입력합니다. 주로 콘솔 모드로 사용할 것이므로 64를 입력하고 <Ok> 선택합니다.

(512 - 64 = 448) 448MB가 ARM CPU 메모리로 사용합니다.

![](https://postfiles.pstatic.net/20150721_84/agapeuni_1437406100413P8KTA_JPEG/SAM_6828.JPG?type=w80_blur)

**A0. 업데이트 (Update)**

최신 버전으로 업데이트를 하는 메뉴입니다. <Select> 선택하면 인터넷이 연결되어 있으면 바로 Update를 진행합니다.

![](https://postfiles.pstatic.net/20150721_285/agapeuni_1437406100585R1gjj_JPEG/SAM_6829.JPG?type=w80_blur)

최신 버전 업데이트 진행 중입니다.

![](https://postfiles.pstatic.net/20150721_80/agapeuni_1437406100785Uxyqk_JPEG/SAM_6832.JPG?type=w80_blur)

업데이트가 완료되었습니다. 

![](https://postfiles.pstatic.net/20150721_209/agapeuni_1437406100988xIoVB_JPEG/SAM_6833.JPG?type=w80_blur)

**9\. 라즈베리 파이 설정에 대하여 (About raspi-config)**

이 설정 도구에 대한 정보입니다. <Select> 선택합니다.

![](https://postfiles.pstatic.net/20150721_232/agapeuni_1437406101252RdO6g_JPEG/SAM_6834.JPG?type=w80_blur)

라즈베리 파이를 위해서 잘 만들었으니 언제든지 안심하고 사용하라는 문구입니다. <Ok> 선택합니다.

![](https://postfiles.pstatic.net/20150721_8/agapeuni_1437406101424JclM7_JPEG/SAM_6835.JPG?type=w80_blur)

​

모든 설정을 마쳤으면 <Finish> 선택합니다.

![](https://postfiles.pstatic.net/20150721_64/agapeuni_1437406101576G94Rv_JPEG/SAM_6836.JPG?type=w80_blur)

지금 재부팅 하시겠습니까? <Yes> 선택합니다.

![](https://postfiles.pstatic.net/20150721_88/agapeuni_1437406101802ePwsm_JPEG/SAM_6837.JPG?type=w80_blur)

재부팅 들어가는 중입니다.

![](https://postfiles.pstatic.net/20150721_94/agapeuni_14374061019677iLf3_JPEG/SAM_6839.JPG?type=w80_blur)

다시 부팅되어 표시되는 로그들입니다.

![](https://postfiles.pstatic.net/20150721_299/agapeuni_1437406102121zxEmw_JPEG/SAM_6840.JPG?type=w80_blur)

여전히 부팅 진행 중입니다.

![](https://postfiles.pstatic.net/20150721_12/agapeuni_1437406102282ct8GS_JPEG/SAM_6841.JPG?type=w80_blur)

부팅이 완료되고 나서 사용자를 물어보는 로그인 프롬프트가 표시됩니다.

![](https://postfiles.pstatic.net/20150721_37/agapeuni_1437406102518svtzU_JPEG/SAM_6842.JPG?type=w80_blur)

디폴트 사용자 pi와 변경한 암호를 입력하여 로그인합니다. (비밀번호 변경을 하지 않았으면 기본으로 raspberry입니다)

![](https://postfiles.pstatic.net/20150721_136/agapeuni_1437406102726nhWin_JPEG/SAM_6843.JPG?type=w80_blur)

드디어 라즈비안 설치와 부팅과 로그인이 완료되었습니다.

![](https://postfiles.pstatic.net/20150721_289/agapeuni_1437406102977EzJoX_JPEG/SAM_6844.JPG?type=w80_blur)
