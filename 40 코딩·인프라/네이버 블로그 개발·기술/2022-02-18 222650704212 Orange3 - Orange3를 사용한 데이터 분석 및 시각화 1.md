# 2022-02-18 222650704212 Orange3 - Orange3를 사용한 데이터 분석 및 시각화 1

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=222650704212&categoryNo=982

## 본문

![](https://postfiles.pstatic.net/MjAyMzEwMThfMTkz/MDAxNjk3NTU0ODEyMjM0._jpXPBzg2NXYze7ZWd2EjzOCpI1rdzk0-JjyhrIrAtYg.M-OcH2ZyBOTIiazxblVOE1MpeJwxc4s0376uJGSt-UMg.PNG.agapeuni/%ED%8C%8C%EC%9D%B4%EC%8D%AC-001_\(12\).png?type=w80_blur)

​

1\. 오렌지3

오렌지(Orange 3)는 코딩없이 GUI 환경에서 위젯을 드래그 앤 드롭하며 데이터 분석 및 시각화, 머신러닝을 할 수 있는 소프트웨어이다. 초보자와 전문가를 위한 구성 요소 기반 데이터 마이닝 프레임워크이며 다양한 워크플로우 템플릿이 포함되어 있다. 직관적인 UI를 갖추고 있어 기본적인 위젯은 몇 번의 사용으로 쉽게 이해하고 사용할 수 있다.

​

2\. 설치와 실행

아나콘다가 설치되어 있어 Anaconda Navigator Home에 표시되는 Orange 3 카드의 Install 버튼을 클릭하여 설치했다. 

![](https://postfiles.pstatic.net/MjAyMjAyMTdfMjEx/MDAxNjQ1MTA2MjAwNTkx.18zN7f0xJyJRHtFWyM33WJCmr5RtLxhqK-eUZTJGGJ8g.CcsKRD0pCYC7gTYd1tYGYmTAB0GwpNXDwqKog3SFLXIg.PNG.agapeuni/20220217_225523.png?type=w80_blur)

​

설치를 완료하면 아래의 이미지처럼 Install 버튼이 Launch 버튼으로 바뀐다. 

Launch 버튼을 클릭하면 Orange3가 실행된다.

![](https://postfiles.pstatic.net/MjAyMjAyMTdfMjM4/MDAxNjQ1MTA2NDA1MTQ1.UN8adRuH9zJA7v_ofs8UF1LZy_ykZGcygnYnFgoJkgAg.gw8G4dAPThheD2tBReXAhWNjcqfSjtunHJCE-2blTlYg.PNG.agapeuni/image.png?type=w80_blur)

​

오렌지는 Anaconda 프롬프트에서 다음의 명령으로 설치할 수 있다.

**> conda install orange3**

![](https://postfiles.pstatic.net/MjAyMjAyMTdfMTcg/MDAxNjQ1MTA3MDg2ODU5.r4_hXa45Nmv5QUEuO0A8IlBnKw6_CCYr-cjYOr-b_EYg.Kt5RXGfJe20gXzmOxaGlnEsmdB2jZ9w8AzUUwORl_qAg.PNG.agapeuni/image.png?type=w80_blur)

**​**

orange3 패키지 하나 설치하는데 신규로 설치하는 패키지가 생각보다 너무 많다.

![](https://postfiles.pstatic.net/MjAyMjAyMTdfMjA4/MDAxNjQ1MTA5NzA0ODky.eYBoSNM_77fUzJN2GEbmAr9DCbspPN6hs2IfskV8ec4g.g3X5XxB0nPkkDKBSnOFqiacT-ewKfGTyZQIi-Nkg59Qg.PNG.agapeuni/20220217_235403.png?type=w80_blur)

**​**

Anaconda 프롬프트에서 오렌지를 실행하려면 아래와 같이 입력한다.

**> orange-canvas**

![](https://postfiles.pstatic.net/MjAyMjAyMTdfMTI3/MDAxNjQ1MTA4OTE4NTcw.7R0XA98oinxQSugZo4yhy5T2mM5NE8jvfGXNujgpXqEg.nrAp8zNI-R8aMWMkP_vZyx-FHBti0tBt_Xs-cPvc2Wwg.PNG.agapeuni/image.png?type=w80_blur)

​

​

3\. 실행과 구성

실행하면 처음에 환영 화면이 표시된다. 

상단의 연두색은 오렌지 파일과 관련된 기능이고 하단 주황색은 튜토리얼, 시작하기, 템플릿 예제, 문서와 연결된다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfNzUg/MDAxNjQ1MTE0MDE1OTcw.YJCmqOgtCGxsz7_MPVm2s74qEP-K_8v9o86A4_dWC04g.roASTWGbl9Ioj3KH63kjaABPR96xSpoBZRP79vnHR40g.PNG.agapeuni/image.png?type=w80_blur)

​

실행한 화면은 상단에 메뉴가 있고 와 좌측에 커다란 아이콘이 그룹지어진 위젯이 있다. 

그리고 아무것도 없는 하얀 캔버스가 우측에 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfMjk3/MDAxNjQ1MTE0MTc2NTk5.0zwajv3-u7pPeKVppeJHwzwwOit9xfVgrak635RoYAcg.XvxbuGf6xv1J4fpl6je7kvQfuNY096XQWjEPnwLANg8g.PNG.agapeuni/image.png?type=w80_blur)

​

1) Data : 데이터 조작을 위한 위젯들이 있다. 데이터 파일을 열거나 데이터 테이블로 표시하는 등의 작업을 할 수 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfMjUy/MDAxNjQ1MTEwMTkyMTIw.EtR68FrY8BboK26n-YVq5nouggD-54zrjOWH2nk2Tqkg.TIaO0eNDnn2aYz2umJgLxnNPbDq8QxVP2wXWrw19g1sg.PNG.agapeuni/image.png?type=w80_blur)

​

2) Visualize : 데이터 시각화를 위한 위젯들이 있다. 데이터에 담겨있는 정보를 다양한 모양의 Plot으로 보여준다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfMjEy/MDAxNjQ1MTEwMTc1MjU3.m76fQXV_pUbKd6Tu24i73xLLrvKu8c5ZaaztbKbnySUg.c_x3PT8Iy4r2grStkBF4W6y1KdjtnxqWhioYsGvQEQ0g.PNG.agapeuni/image.png?type=w80_blur)

​

3) Model : 선형회귀, 로지시틱 회귀, 랜덤 포레스트, kNN, SVM 과 같은 다양한 모델이 위젯으로 준비되어 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfMTcx/MDAxNjQ1MTEwMTU4MDY0.MIk6onJ5rVjdYbysdFe9hDGj3zkzkP2pY_9T3zWQwlcg.x5c1Q_X4y4ovFv8A__tIVmURx8-FXpmho83BdreoZmkg.PNG.agapeuni/image.png?type=w80_blur)

​

4) Evaluate : 학습과 테스트 데이터로 구분하는 작업이나 예측과 같은 작업을 할 수 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfMTMy/MDAxNjQ1MTEwMTMyMTYw.sdoL26o2uogtc3sDQHm24LfVGDZah7m6OorYV-66ok4g.1Lh1ApHFsDw-aQXJM8l3ah5_t-5VXpHjFxfUdkD-4uQg.PNG.agapeuni/image.png?type=w80_blur)

​

​

메뉴 Options > Add-on을 클릭하면 보다 다양한 위젯을 추가할 수 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMThfNjYg/MDAxNjQ1MTE0OTY5Mzgw.DzcCpMBnWUoAfL4D1gns68Z19Q-8ny9_J9FN_SvtlgMg.PgnQI41RdmCoCFPSXwZtfvGtFd05ls8YnC-AbPkdzZ4g.PNG.agapeuni/image.png?type=w80_blur)
