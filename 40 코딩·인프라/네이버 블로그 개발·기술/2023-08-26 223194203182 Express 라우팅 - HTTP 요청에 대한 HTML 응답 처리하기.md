​

요청 URL에 대해 그에 대한 응답을 HTML로 표시하는 예제이다.

요청 URL은 '/' 와 '/about'과 '/hello/:user' 그리고 '/sample'에 대해 기술되어 있다.

​

'/hello/:user' 요청에서 ':user'는 요청된 파라미터 값을 동적으로 전달할 수가 있다.

'/sample' 요청에는 html 파일을 응답으로 보낸다.

var express = require('express'); var app = express(); app.get("/", function(request, response) { response.end("<h1>Main Page</h1>"); }); app.get("/about", function(request, response) { response.end("<h1>About Page</h1>"); }); app.get("/hello/:user", function(request, response) { response.end("<h1>Hello, " + request.params.user + "</h1>"); }); app.get("/sample", function(request, response) { response.sendFile(__dirname + "/sample.html"); }); app.get("*", function(request, response) { response.end("<h1>404 error<br> File not found</h1>"); }); var server = app.listen(1337, function() { console.log('http://127.0.0.1:1337'); });
