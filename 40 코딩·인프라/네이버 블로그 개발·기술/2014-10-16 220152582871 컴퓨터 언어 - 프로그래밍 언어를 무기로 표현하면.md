컴퓨터 프로그래밍 언어는 수 많은 종류가 있다. 프로그래밍 언어는 각각의 특징들이 있다. 닮은 듯 하면서도 다른 프로그래밍 언어는 저 같은 프로그래밍 언어를 모르는 일반인들은 뭐가 뭔지 잘 모른다. 그런데 Floobits에서 소프트웨어를 개발하고 있는 Bjorn Tipling씨가 16가지의 컴퓨터 프로그래밍 언어를 재래식 무기로 표현한 글이 화제다.

**프로그래밍 언어를 무기로 표현하면?**  
---  
  
**순서**

  1. C언어 : M1 개런드

  2. C++ : 쌍절곤

  3. Perl : 화염병

  4. JAVA : M240기관총

  5. Scala : 뭔 소리인지 이해가 안가는 훈련 메뉴얼

  6. 자바 스크립트 : 손잡이 없는 칼

  7. GO : 초보용 권총

  8. Rust : 3D 프린터로 만든 총

  9. bash : 장도리

  10. 파이썬 : 더블 배럴 형 샷건

  11. Ruby : 빛나는 검

  12. PHP : 호스

  13. 매스메티카 : 저궤도에 떠 있는 우주 대포

  14. C # : 당나귀에 단 강력한 레이저 라이플

  15. Prolog : 인공 지능 무기

  16. Lisp : 칼

​

​

**1\. C언어 : M1 개런드**

컴퓨터 프로그래밍의 기본이라고 할 수 있는 C언어는 미국의 반자동 소총인 M1 개런드라고 했네요. 이유는 비록 오래된 소총이지만 신뢰성이 높은 무기이기 때문이다.

![](https://postfiles.pstatic.net/20141016_73/agapeuni_1413446270675K6veJ_PNG/1zrekyewqiaxq.png?type=w80_blur)

**​**

**​**

**2\. C++ : 쌍절곤**

C언어의 확장 버전인 C++는 잘만 사용하면 강력한 능력을 발휘하지만 쌍절곤을 제대로 돌리려면 몇 년의 고된 수행이 필요하기 때문에 쌍절곤으로 표현 했다. 종종 다른 것을 사용하고 싶다는 생각이 든다.

![](https://postfiles.pstatic.net/20141016_3/agapeuni_1413446273469rtju4_PNG/nbipbvfwmqb7va.png?type=w80_blur)

​

​

**3\. Perl : 화염병**

펄(Perl)은 화염병이 유용했던 시대도 있었지만 지금은 거의 사용하지 않게 않는 모습이 펄과 닮았다. 화염병은 2차 대전 때 보병들이 탱크에 던져서 안에 타고 있는 군인에게 피해를 주는 효과가 좋아서 많이 사용 했던 무기지만 거의 사용하지 않는다. 그러나 몇몇 사람들은 지금도 사용한다.

![](https://postfiles.pstatic.net/20141016_239/agapeuni_1413446271210AhMi4_PNG/4bukyhephoe7g.png?type=w80_blur)

​

​

**4\. JAVA : M240기관총**

객체지향 언어의 대표주자인 자바는 미군들이 많이 사용하는 M240기관총이다. 그 이유는 탄약벨트(프로그램 코드)가 문제가 발생하면 Null PointerException 예외 오류가 발생해서 폭발을 하고 기관총 사수는 사망을 한다.

![](https://postfiles.pstatic.net/20141016_155/agapeuni_14134462743503COBY_PNG/qmhanlakiyccw.png?type=w80_blur)

​

**5\. Scala : 뭔 소리인지 이해가 안가는 훈련 메뉴얼**

자바에서 파생된 언어인 스칼라는 스칼라를 배우는 메뉴얼이 너무 난해하게 작성 되어 있어서 뭔 소리인지 모를 군대 훈련 메뉴얼로 비유 했다.

![](https://postfiles.pstatic.net/20141016_119/agapeuni_1413446273997FoLHs_PNG/odb1et34erhiq.png?type=w80_blur)

**​**

**​**

**6\. 자바 스크립트 : 손잡이 없는 칼**

웹 브라우저에서 자주 많이 사용하고 이 자바 스트립트가 없으면 인터넷이 재미 없을 정도로 정말 많은 사람들이 사용하고 있다. 한 때 자바스크립트를 이해하고 소스를 고쳐서 홈페이지를 꾸민적이 많이 있었다. 자바 스크립트는 칼자루가 없는 칼이다. 그 이유는 칼 부분은 아주 좋은데 칼자루가 없는 칼 처럼 나쁜 면도 혼재하고 있다. 

![](https://postfiles.pstatic.net/20141016_134/agapeuni_1413446274612aGjmB_PNG/tdsjt1pa55fafg.png?type=w80_blur)

​

**​**

**​**

**7\. GO : 초보용 권총**

구글이 개발 하고 있는 Go는 초보자용 권총이다. 권총을 발사한 후에 정말 발사가 되었는지, 또 명중 했는지를 확인해야 한다.

![](https://postfiles.pstatic.net/20141016_46/agapeuni_1413446270929KKPVz_PNG/2apco7plivhetq.png?type=w80_blur)

**​**

**​**

**8\. Rust : 3D 프린터로 만든 총**

모질라재단에서 개발하고 있는 Rust는 3D프린터로 만든 총이다. 지금은 나오지 않았지만 언젠가는 주변에서 많이 사용하게 될 것이기 때문이다. 

![](https://postfiles.pstatic.net/20141016_65/agapeuni_1413446273760KSpuA_PNG/ngydoijonok5sg.png?type=w80_blur)

**9\. bash : 장도리**

유닉스의 소프트웨어 환경을 모두 프리웨어로 제공하는 것으로 목적으로 하는 GNU프로젝트를 위해 만들어진 언어이다. 이는 엄지 손가락만 노리는 저주 받은 장도리와 비슷하기 때문이다. 

![](https://postfiles.pstatic.net/20141016_51/agapeuni_14134462754868avnr_PNG/zjgvgtmrhgmpw.png?type=w80_blur)

**​**

**​**

**10\. 파이썬 : 더블 배럴 형 샷건**

대학의 입문용 프로그래밍 언어로 인기를 끌고 있는 파이썬은 무기로 비유하면 총신이 2개인 더블 배럴 형 샷건과 비슷하다. 항상 교대로 총탄이 발사 되지만 정작 중요할 때는 발사가 되지 않는다. 

![](https://postfiles.pstatic.net/20141016_53/agapeuni_14134462716633h00h_PNG/dvtsddj7yqfna.png?type=w80_blur)

**​**

**11\. Ruby : 빛나는 검**

일본 프로그래머인 마쓰모토 유키히로가 만든 이 Ruby라는 언어는 빛나게 하는 용도로만 사용하기 때문에 빛나는 검으로 비유했다.

![](https://postfiles.pstatic.net/20141016_157/agapeuni_1413446275262TIItY_PNG/ysu6nkp3etd8yw.png?type=w80_blur)

**​**

**​**

**12\. PHP : 호스**

동적 웹 페이지를 구축하기 위한 PHP는 호스로 비유했다. 호스 한쪽을 자동차 배기구에 꽂고 한쪽을 차내로 끌어와서 시동을 건다고 하는데 무슨 의미인지 좀 이해가 안간다. 배기 가스 재활용을 표현한 것인가?

![](https://postfiles.pstatic.net/20141016_191/agapeuni_1413446272047RL5iT_PNG/hxqywt4ymqxqza.png?type=w80_blur)

​

**​**

**13\. 매스메티카 : 저궤도에 떠 있는 우주 대포**

매스메티카는 우주 저궤도에서 띄워진 우주 대포이다. 성능은 엄청난데 가격이 너무 비싸서 쉽게 사용하지도 누구나 사용하지도 못한다.

![](https://postfiles.pstatic.net/20141016_137/agapeuni_1413446271854X5kCQ_PNG/f38gi2tpijc7q.png?type=w80_blur)

​

**​**

**​**

**14\. C # : 당나귀에 단 강력한 레이저 라이플**

마이크로소프트에서 개발한 객체 지향 프로그래밍 언어인 C#은 당나귀 등에 묶여진 강력한 레이저 라이플이다. 레이저 라이플은 탄낙차가 없어서 조준하기도 쉽고 성능도 좋다. 당나귀 위에 올려져 있는 것처럼 이동성은 떨어진다. 이는 C#이 컴파일 된 중간 코드를 실행할 수 있기 때문에 레이저 라이플 같은 강력한 성능을 보여주기도 하지만 당나귀처럼 구식의 실행환경이 걸림돌이 되고 있다. 

![](https://postfiles.pstatic.net/20141016_192/agapeuni_1413446271462kX6os_PNG/ddmvewfmbobm0g.png?type=w80_blur)

​

​

**15\. Prolog : 인공 지능 무기**

Prolog는 인공 지능 무기다. 명령을 내리면 그대로 실행한다. 터미네이터처럼 언젠가는 너의 엄마를 죽이러 올 것이라고 말하고 있다. 

![](https://postfiles.pstatic.net/20141016_25/agapeuni_14134462722420VBQd_PNG/i7vzcuof4i61a.png?type=w80_blur)

**16\. Lisp : 칼**

가장 오래된 고급 언어 중 하나인 LISP은 칼이다. 칼은 아주 다양한 형태와 디자인을 가지고 있다. 누구나 쉽게 칼을 사용할 수 있지만 그 칼로 인해 위험해질 수도 있다.

![](https://postfiles.pstatic.net/20141016_187/agapeuni_1413446274953zp8ci_PNG/w15natoim2lezq.png?type=w80_blur)
