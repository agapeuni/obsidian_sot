# 2025-04-16 223835542674 PL SQL - PL SQL 함수의 정의와 사용법

- 게시일: 2025. 4. 16. 16:00

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfMTYx/MDAxNzQ0Nzc2OTM4OTEx.OrnkQEbLFBTO4wvvzK4nWDEnCYTOsz7R4krIxKEp04Mg.HzWz9tUH-3L6usTwIBLr2XefK42q1VwqgD6-hqvJJ5Eg.PNG/PL_SQL-001_\(5\).png?type=w80_blur)

​

Oracle 데이터베이스에서 PL/SQL 함수는 프로그램의 구조를 모듈화하고, 코드 재사용성을 높이며, 유지보수성을 향상시키는 데 매우 중요한 역할을 한다. 본 글에서는 PL/SQL 함수의 정의 및 사용 방법, 그리고 함수 작성 시 유의할 점들에 대해 체계적으로 정리하고자 한다.

**​**

**​**

**1\. 함수를 사용하는 이유**

PL/SQL 함수는 다음과 같은 장점을 지닌다.

  * **코딩량 감소** : 반복되는 코드를 줄여 개발 효율성을 높일 수 있다.

  * **모듈 단위 접근** : 논리적으로 관련된 기능을 별도의 블록으로 분리하여 관리할 수 있다.

  * **재사용성 향상** : 한번 정의한 함수를 여러 곳에서 반복해서 호출할 수 있다.

**​**

**​**

**2\. 함수 정의 구문**

FUNCTION 함수명 [(파라미터 {IN | OUT | IN OUT})] RETURN 반환데이터형 IS | AS 선언문 BEGIN 실행문 EXCEPTION 예외처리문 END 함수명; / 

  * **IS | AS** : 지역 변수 등을 선언할 수 있는 키워드

  * **RETURN** : 함수에서 반환할 데이터의 자료형을 지정

  * **EXCEPTION** : 오류 발생 시 예외 처리를 위한 선택적 블록

**​**

**​**

**3\. 파라미터 설명**

  * **파라미터** 는 함수로 값을 전달하기 위한 변수이며, 세 가지 MODE로 구분된다:

**MODE** |  **설명**  
---|---  
IN [NOCOPY] |  읽기 전용, 외부에서 값을 전달하고 함수 내에서는 변경 불가  
OUT [NOCOPY] |  쓰기 전용, 외부 값은 무시되고 함수 내에서 할당  
IN OUT [NOCOPY] |  읽기/쓰기 가능, 함수 종료 시 변경된 값이 외부로 반영됨  
  
  * **NOCOPY** 는 대용량 데이터의 경우 값을 복사하지 않고 참조로 전달하도록 하는 컴파일러 힌트이다.

  * **actual parameter** : 호출 시 실제 전달되는 값

  * **formal parameter** : 함수 내부에서 사용하는 파라미터 선언

**예시**

v_stuid VARCHAR2 := '-'; v_txn_count NUMBER DEFAULT 10; 

​

**​**

**4\. 반환 데이터형**

모든 함수는 반드시 반환 데이터형(RETURN type)을 정의해야 하며, 반환되는 데이터는 단 하나만 실행된다.

**​**

**​**

**5\. 예외 처리 (Exception)**

오류 발생 시 예외 처리를 통해 함수의 비정상 종료를 방지할 수 있다.

EXCEPTION WHEN OTHERS THEN \-- 오류 처리 코드 

​

**​**

**6\. 스토어드 함수 (Stored Function)**

스토어드 함수란, 데이터베이스에 저장되어 다른 PL/SQL 블록이나 SQL 문장에서 호출할 수 있는 함수이다. 작성 시에는 CREATE [OR REPLACE] FUNCTION 구문을 사용한다.

CREATE OR REPLACE FUNCTION 함수명 [(파라미터)] RETURN 반환데이터형 IS | AS 선언문 BEGIN 실행문 EXCEPTION 예외처리문 END 함수명; / 

​

**​**

**7\. 예제: 파라미터가 없는 스토어드 함수**

CREATE OR REPLACE FUNCTION mypi RETURN NUMBER IS BEGIN RETURN 3.14; END mypi; / 

​

**호출 예시**

SET SERVEROUTPUT ON; BEGIN DBMS_OUTPUT.PUT_LINE('mypi value is ' || mypi); END; / 

​

**​**

**8\. 디버깅 방법**

함수 작성 중 오류가 발생하면 해당 함수는 **INVALID 상태** 가 된다. 이 경우 다음 명령어로 오류를 확인할 수 있다.

SHOW ERRORS; 

오류 메시지는 LINE/COLUMN 형식으로 표시되며, 예를 들어 6/2는 6번째 줄의 두 번째 위치에 오류가 있음을 의미한다.

​

이와 같이 PL/SQL 함수는 복잡한 로직을 간결하고 체계적으로 구성할 수 있도록 도와준다. 함수를 효과적으로 작성하고 활용함으로써 개발 생산성과 코드 품질을 동시에 높일 수 있다.
