# 2023-08-08 223177683954 IME 모드 설정 - IME와 inputmode로 입력 방식 제어

## 본문

​

IME(Input Method Editor)는 사용자가 텍스트 입력을 위해 키보드를 사용할 때 언어 또는 문자 체계를 지정하는 것을 말한다. 웹 페이지에서는 특정 입력 필드에 IME 모드를 지정하여 사용자가 해당 필드에 적절한 언어나 문자 체계로 입력할 수 있다.

​

IME는 한글이나 한자처럼 컴퓨터 자판에 있는 글자보다 수가 더 많은 문자를 조합하여 주는 입력 시스템이다. inputmode 속성은 브라우저에서 IME 모드를 올바르게 적용하는 데 도움을 주는 힌트를 제공한다. 그러나 브라우저의 지원 상태나 사용자의 환경 설정에 따라 동작이 달라질 수 있다. 따라서 일부 특정 IME 모드는 모든 브라우저에서 일관되게 동작하지 않을 수 있으며, 특히 모바일 기기에서의 동작은 다를 수 있음을 유의해야 한다.

​

HTML에서 IME(Input Method Editor) 모드를 지정하면, 사용자가 특정 입력 필드에 포커스를 맞출 때 입력 방식이 자동으로 전환되어 문자를 입력할 수 있다. 예를 들어, 한국어나 일본어와 같은 IME 입력이 필요한 경우, inputmode 속성을 사용하여 입력 방식을 설정할 수 있다.

​

기본적으로 input 태그에 inputmode 속성을 지정하여 IME 모드를 설정할 수 있다. 주요 inputmode 속성 값은 다음과 같다.

  * inputmode="text" : 일반 텍스트 입력을 위한 설정

  * inputmode="numeric" : 숫자 입력을 위한 설정

  * inputmode="tel" : 전화번호 입력을 위한 설정

  * inputmode="email" : 이메일 주소 입력을 위한 설정

  * inputmode="url" : URL 입력을 위한 설정

​

HTML에서는 다음과 같이 input 요소의 inputmode 속성을 사용하여 IME 모드를 지정할 수 있다.

<!-- 일반 텍스트 필드에 대한 IME 모드 지정 --> <input type="text" inputmode="text"> <!-- 숫자 입력 필드에 대한 IME 모드 지정 --> <input type="text" inputmode="numeric"> <!-- 전화번호 입력 필드에 대한 IME 모드 지정 --> <input type="tel" inputmode="tel"> <!-- 이메일 주소 입력 필드에 대한 IME 모드 지정 --> <input type="email" inputmode="email"> <!-- URL 입력 필드에 대한 IME 모드 지정 --> <input type="url" inputmode="url"> <!-- 패스워드 입력 필드에 대한 IME 모드 지정 (비밀번호 입력 시 OS에 따라 다르게 동작할 수 있음) --> <input type="password" inputmode="text"> <!-- 기타 입력 필드에 대한 IME 모드 지정 (예: 한글 입력 필드) --> <input type="text" inputmode="verbatim">

프로젝트에 따라 적합한 IME 모드를 선택하고, 각 입력 필드에 올바른 inputmode 값을 지정하여 사용자가 좀 더 편하게 텍스트를 입력할 수 있도록 지원하면 좋다.

​

▣ Syntax

HTML : { ime-mode : sMode }

JavaScript : object.style.imeMode [ = sMode ]

▣ auto (기본값)

ime-mode 값이 지정되지 않은 것과 같다.

▣ active (활성화)

기본적으로 한글이 입력됩니다.

﻿<input type="text" style="ime-mode:active;">﻿

▣ inactive (비활성화)

값을 입력하면 기본적으로 영문이 입력된다.

﻿<input type="text" style="ime-mode:inactive;">﻿

▣ disabled (해제)

한영 키를 눌러도 한글로 변환하지 않고 영문만 입력 가능하다.

﻿<input type="text" style="ime-mode:disabled;">﻿
