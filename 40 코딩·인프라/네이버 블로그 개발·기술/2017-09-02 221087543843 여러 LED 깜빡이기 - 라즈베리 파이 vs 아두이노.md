프로젝트를 처음 진행할 때는 관련 기술과 지식이 우선적으로 필요하지만 시간이 지나 어느정도 익숙해 지고나면 기술보다는 체력이 필요합니다. 프로젝트 후반부에는 일정과 업무에 쫓기어 축적된 에너지와 체력이 받쳐주어야 어렵지 않게 업무를 수행할 수 있습니다. 프로젝트 오픈을 앞두고 남겨진 기능들을 구현하느라 많이 지쳐서 인지 이번주는 지각도 많이 하고 오후에는 근무하다가 꾸벅꾸벅 졸기도 했습니다.

지난 예제에서 사용했던 모습 그대로 입니다. 오늘은 6개의 LED를 사용해 보려고 합니다. 코드도 상당히 단순하고 비효율적이기도 합니다. 위쪽이 라즈베리 파이이고 아래쪽이 아두이노 우노입니다. ^^

먼저 아두이노 스케치 코드를 살펴보겠습니다. 

7번 핀부터 2번 핀까지 pin1 ~ pin6 변수를 선언하고 OUTPUT으로 설정합니다. 

그리고 반복 loop() 에서 여 0.5초 간격으로 LED를 On/Off 합니다.

int pin1 = 7; int pin2 = 6; int pin3 = 5; int pin4 = 4; int pin5 = 3; int pin6 = 2; int delayTime = 500; void setup() { pinMode(pin1, OUTPUT); pinMode(pin2, OUTPUT); pinMode(pin3, OUTPUT); pinMode(pin4, OUTPUT); pinMode(pin5, OUTPUT); pinMode(pin6, OUTPUT); } void loop() { // All Led is On digitalWrite(pin1, HIGH); digitalWrite(pin2, HIGH); digitalWrite(pin3, HIGH); digitalWrite(pin4, HIGH); digitalWrite(pin5, HIGH); digitalWrite(pin6, HIGH); delay(delayTime); // All Led is Off digitalWrite(pin1, LOW); digitalWrite(pin2, LOW); digitalWrite(pin3, LOW); digitalWrite(pin4, LOW); digitalWrite(pin5, LOW); digitalWrite(pin6, LOW); delay(delayTime); // Left is On, Right is Off digitalWrite(pin1, HIGH); digitalWrite(pin2, HIGH); digitalWrite(pin3, HIGH); digitalWrite(pin4, LOW); digitalWrite(pin5, LOW); digitalWrite(pin6, LOW); delay(delayTime); // Left is Off, Right is On digitalWrite(pin1, LOW); digitalWrite(pin2, LOW); digitalWrite(pin3, LOW); digitalWrite(pin4, HIGH); digitalWrite(pin5, HIGH); digitalWrite(pin6, HIGH); delay(delayTime); // All Led is Off digitalWrite(pin1, LOW); digitalWrite(pin2, LOW); digitalWrite(pin3, LOW); digitalWrite(pin4, LOW); digitalWrite(pin5, LOW); digitalWrite(pin6, LOW); delay(delayTime); }

다음은 Pi4J로 구현한 자바 코드입니다. 

라즈베리 파이에 정의된 순서대로 1번, 2번, 3번, 4번, 5번, 6번 핀을 차례로 pin1부터 pin6까지 변수로 설정합니다. 

그리고 0.5초 간격으로 LED를 On/Off 합니다.

package com.pi4j.book.ch06; import static com.pi4j.util.Pi4jUtil.delay; import com.pi4j.io.gpio.GpioController; import com.pi4j.io.gpio.GpioFactory; import com.pi4j.io.gpio.GpioPinDigitalOutput; import com.pi4j.io.gpio.PinState; import com.pi4j.io.gpio.RaspiPin; public class S0602_MultiLed_1 { GpioController gpio = GpioFactory.getInstance(); GpioPinDigitalOutput pin1; GpioPinDigitalOutput pin2; GpioPinDigitalOutput pin3; GpioPinDigitalOutput pin4; GpioPinDigitalOutput pin5; GpioPinDigitalOutput pin6; int delayTime = 500; void setup() { pin1 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_01, PinState.LOW); pin2 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_02, PinState.LOW); pin3 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_03, PinState.LOW); pin4 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_04, PinState.LOW); pin5 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_05, PinState.LOW); pin6 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_06, PinState.LOW); } void loop() { System.out.println("All Ledis On"); pin1.high(); pin2.high(); pin3.high(); pin4.high(); pin5.high(); pin6.high(); delay(delayTime); System.out.println("All Ledis Off"); pin1.low(); pin2.low(); pin3.low(); pin4.low(); pin5.low(); pin6.low(); delay(delayTime); System.out.println("Left isOn, Right is Off"); pin1.high(); pin2.high(); pin3.high(); pin4.low(); pin5.low(); pin6.low(); delay(delayTime); System.out.println("Left isOff, Right is On"); pin1.low(); pin2.low(); pin3.low(); pin4.high(); pin5.high(); pin6.high(); delay(delayTime); System.out.println("All Ledis Off"); pin1.low(); pin2.low(); pin3.low(); pin4.low(); pin5.low(); pin6.low(); delay(delayTime); } void shutdown() { gpio.shutdown(); } public static void main(String[] args) { S0602_MultiLed_1 instance = new S0602_MultiLed_1(); instance.setup(); for (int i = 0; i < 5; i++) { instance.loop(); } instance.shutdown(); } }

다음은 여러개의 LED 깜빡이기 코드를 실행한 영상입니다. 아래쪽이 아두이노 우노이고 위쪽은 라즈베리 파이입니다. 

아두이노 우노는 가장좌측에 있는 핀번호가 7이고 6, 5, 4, 3, 2, 1 순으로 LED가 꼽혀 있습니다.

라즈베리 파이는 가장좌측에 있는 핀번호가 1번이고 2, 3, 4, 5, 6 순으로 LED가 꼽혀 있습니다.
