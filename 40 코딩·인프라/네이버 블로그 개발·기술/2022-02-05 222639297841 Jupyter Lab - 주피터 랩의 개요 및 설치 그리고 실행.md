1\. Jupyter Lab 개요

Jupyter Lab은 Jupyter 노트북, 코드 및 데이터를 위한 차세대 웹 기반 대화형 개발 환경이다. Jupyter Lab은 데이터 과학, 과학 컴퓨팅, 기계 학습의 광범위한 워크 플로를 지원하도록 유연한 사용자 인터페이스를 구성한다. Jupyter Lab은 확장이 가능하고 모듈 식으로 새 구성 요소를 추가하고 기존 구성 요소와 통합하는 플러그인을 제공한다. 동일한 창에서 여러 개의 노트북 또는 파일을 탭으로 열 수 있어 이미지와 CSV 파일, PDF 파일 등 다양한 파일을 열어 볼 수 있다. IDE와 유사한 경험을 제공한다.

2\. Jupyter Lab 설치

아나콘다(Anaconda)를 설치하면 기본적으로 Jupyter Lab 이 설치된다.

만약 설치가 되어 있지 않으면 conda 가상환경에서 다음의 명령어를 실행하여 설치한다.

​

> conda install jupyterlab

또는

> pip install jupyterlab​

3\. Jupyter Lab 실행

윈도우 시작 > Anaconda3 (64-bit) > Anaconda Prompt 클릭하여 가상환경 콘솔창을 실행한다.

콘솔창에서 작업경로로 이동한 후 "jupyterlab" 또는 "jupyter lab"을 입력한다.

기본으로 설정된 브라우저가 자동으로 실행한다.

다른 브라우저에서 실행하고 싶을 때는 터미널에 출력된 URL을 복사해서 주소에 입력하면 된다.

4\. Jupyter Lab 화면

JupyterLab은 상당히 편리한 구성을 제공한다. 기존에 사용하던 통합 개발 환경에서 볼 수 있는 기능도 지원한다. 이미지 파일이나 텍스트 파일로 열어볼 수 있다. 왼쪽에 위치한 사이드바에는 파일 브라우저(File Browser), 실행 중인 터미널 및 커널(Running Terminals ann Kernels), 명령(Commands) 등 일반적으로 사용되는 탭들이 있다. 작업 영역을 자유롭게 구성할 수 있다.

![](https://postfiles.pstatic.net/MjAyMjAyMDVfNTcg/MDAxNjQ0MDA1MDI5ODkw.NnGSG5wOjsvImmb5Tae_zmtfDP0oTf5eMkv_bluqDNkg.U31jrhLWyPTW5FxA9qm4Zt2gE6u6v43G_8jEJNUNOBQg.PNG.agapeuni/6.png?type=w80_blur)

​

5\. Jupyter Lab 메뉴

  * File : 파일 및 디렉토리와 관련된 작업

  * Edit : 문서 편집 및 기타 활동과 관련된 작업

  * View : JupyterLab의 모양을 변경하는 작업

  * Run : 노트북 및 코드 콘솔과 같은 다양한 활동에서 코드를 실행하기 위한 작업

  * Kernel : 코드 실행을 위한 별도의 프로세스 인 커널 관리 작업

  * Tabs : 도킹 패널에서 열려있는 문서 및 활동 목록

  * Settings : 공통 설정 및 고급 설정 편집기

  * Help: JupyterLab 및 커널 도움말 링크 목록​
