1\. 도커 이미지 개요

Docker 컨테이너는 도커 이미지 기반으로 생성한 실행되는 상태를 말한다. Docker 이미지의 인스턴스라고 볼 수 있고 하나의 Docker 이미지를 사용하여 여러 개의 컨테이너를 생성할 수 있다. 다시 말하면 Docker 이미지는 Docker 컨테이너를 생성하기 위한 탬플릿을 말한다. Docker 이미지는 기존의 Docker 이미지를 참조하여 새로운 이미지를 생성할 수 있다.

3\. 도커 이미지 생성

도커 이미지를 생성하기 위한 Dockerfile을 작성한다. 

Dockerfile로 이미지를 빌드하고 도커 컨테이너로 실행한다.

![](https://postfiles.pstatic.net/MjAyNTA0MTlfMjE3/MDAxNzQ1MDExMDY2NTQ1.X8yyiXWwxDjvd3RK9qQgtAcGZDh2x0koDXj50iaprF8g.1Pksr9UxgnaaEMNaQMSvMj2Obu4fPnJvn_cjAXD8qNog.PNG/img1.daumcdn.png?type=w80_blur)

​

**파일 : Dockerfile**

FROM alpine:latest RUN apk update && apk add figlet ADD ./text /text CMD cat /text | figlet

FROM |  베이스 이미지를 선택한다. alpine은 기본적인 커맨드가 설치되어 있는 경량의 리눅스이다.  
---|---  
RUN |  컨테이너에서 실행할 명령어를 기술한다. 패키지 매니저 apk를 업데이트하고 입력된 텍스트를 AsciiText로 변환하는 figlet 패키지를 설치한다.  
ADD |  컨테이너에 배치할 파일이나 디렉터리를 지정한다.  
CMD |  컨테이너가 기동한 이후에 실행하는 명령어를 지정한다.  
  
​

5\. Go 언어로 구현한 웹서버

Go 언어로 구현한 간단한 웹 서버를 Docker 이미지로 만들고 Docker 컨테이너로 실행하여 브라우저에서 서비스를 요청해 보자.

​

**1) Dokerfile 작성**

FROM golang:1.9 RUN mkdir /test COPY main.go /test CMD ["go", "run", "/test/main.go"]

**2) main.go 작성**

실행할 main.go 파일을 작성한다. 

브라우저에서 "~/hello"로 요청하면 "Request : (/hello)"를 응답으로 표시한다.

package main import ( "fmt" "log" "net/http" ) func hello(w http.ResponseWriter, r *http.Request) { fmt.Fprintln(w, "<h1>Request : (/hello)</h1>") log.Println("Request : (/hello)") } func logging(f http.HandlerFunc) http.HandlerFunc { return func(w http.ResponseWriter, r *http.Request) { log.Println("logging : ", r.URL.Path) f(w, r) } } func main() { http.HandleFunc("/hello", logging(hello)) log.Println("Server Started ^^") err := http.ListenAndServe(":8888", nil) if err != nil { log.Fatal("err : ", err) } else { fmt.Println("Server Started! -> Port(8888)") } }

**6) Docker 컨테이너 실행**

아래의 명령을 실행하여 Docker 컨테이너를 실행한다. 

> docker container run -p 9000:8888 goweb/goweb:latest

​

-p 옵션으로 포트 포워딩이 되어, 호스트 PC에서 9000 포트를 요청하면 8888로 포트를 포워딩한다.
