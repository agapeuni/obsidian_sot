# 2014-07-22 220068579278 라즈베리 파이 - 삼바 연결 (Samba)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220068579278&categoryNo=982
- 게시일: 2014. 7. 22. 22:20

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTIy/MDAxNzU4NDM3NzExNDk1.PkLgWEfEidynYpk45daNATaVjipW0jkJTcV0R-ElXPcg.2Spz4vP0fBfPJ-pjXFhOj6NMocjrFpTrWHiUzZ2PrFUg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(9\).png?type=w80_blur)

​

라즈베리 파이와 삼바(Samba)를 연결하여 네트워크에서 파일 공유를 할 수 있습니다. 삼바로 연결하면 윈도우 탐색기에서 파이의 폴더에 쉽게 접근할 수가 있습니다.

​

먼저 파이에 SSH로 로그인하고서 아래와 같이 삼바(Samba)를 설치합니다.

**$ sudo apt-get install samba samba-common-bin**

![](https://postfiles.pstatic.net/20150605_153/agapeuni_1433463477620LNnqB_PNG/20140722_222220.png?type=w80_blur)

​

삼바가 성공적으로 설치된 후에 아래의 파일의 내용을 일부 편집합니다.

**$ sudo vi /etc/samba/smb.conf**

​

secutiry = user

rean only = no

![](https://postfiles.pstatic.net/20150605_192/agapeuni_1433463486203Vv69y_PNG/20140722_222451.png?type=w80_blur)

ex 모드에서 set nu를 입력하면 라인 번호가 표시됩니다. 

![](https://postfiles.pstatic.net/20150605_198/agapeuni_1433463494562nqdpR_PNG/20140722_222503.png?type=w80_blur)

​

102 라인에서 secutiry = user로 수정합니다. 

![](https://postfiles.pstatic.net/20150605_225/agapeuni_1433463504541ceMA9_PNG/20140722_222604.png?type=w80_blur)

250 라인에서 rean only = no로 수정합니다.

![](https://postfiles.pstatic.net/20150605_292/agapeuni_1433463513733uldVC_PNG/20140722_222627.png?type=w80_blur)

삼바(Samba) 설정 파일의 수정을 마치고서 삼바(Samba)를 재기동합니다. 

**$ sudo /etc/init.d/samba reload**

​

참고로 서비스 재시작은 

**$ sudo service samba restart**

![](https://postfiles.pstatic.net/20150605_110/agapeuni_1433463524567R2SSy_PNG/20140722_222714.png?type=w80_blur)

​

외우기 쉬운 삼바(Samba) 암호를 설정합니다. 보안은 약하지만 외우기 위한 "1234"

**$ sudo smbpasswd -a pi**

![](https://postfiles.pstatic.net/20150605_137/agapeuni_14334635385379spOS_PNG/20140722_222732.png?type=w80_blur)

​

호스트명을 바꾸지 않았으면 아래와 같으리라 생각됩니다.

**$ hostname**

![](https://postfiles.pstatic.net/20150605_297/agapeuni_1433463546499FII0h_PNG/20140722_222748.png?type=w80_blur)

이제 라즈베리 파이의 파일을 공유하기 위해 Samba가 설정되었습니다. 다른 컴퓨터에서 네트워크에서 라즈베리 파이에 액세스할 수 있습니다. 윈도우즈에서는 탐색기에서 `\\\파이_IP주소`를 입력하여 공유 폴더에 액세스할 수 있습니다. 맥이나 리눅스에서는 파일 관리자에서 `smb://파이_IP주소`를 입력하여 액세스할 수 있습니다. 액세스할 때는 Samba 사용자 이름과 비밀번호를 입력해야 합니다. 설정한 Samba 비밀번호를 사용하여 로그인할 수 있습니다.

​

윈도우 탐색기나 실행에서 아래와같이 입력하면 파이에 삼바로 연결이 됩니다. 

**\\\raspberrypi\pi**

![](https://postfiles.pstatic.net/20150605_75/agapeuni_1433463558322Jt1mW_PNG/20140722_222956.png?type=w966)

윈도우에서 편하게 새로운 폴더를 생성합니다.

![](https://postfiles.pstatic.net/20150605_219/agapeuni_1433463569782edMpb_PNG/20140722_224359.png?type=w966)

​

라즈베리 파이에서 확인해 보면 윈도우에서 생성한 폴더가 표시됩니다. 이렇게 편리할 수가... ^^

![](https://postfiles.pstatic.net/20150605_271/agapeuni_1433463579588WPh1k_PNG/20140722_224428.png?type=w80_blur)

파이에서도 한글명으로 폴더를 생성해 봅니다.

파이에서 생성한 폴더 권한은 755인데 반해 윈도우에서 생성한 폴더 권한은 700입니다.

![](https://postfiles.pstatic.net/20150605_24/agapeuni_1433463597235JM89w_PNG/20140722_224643.png?type=w966)
