**1\. JMC 개요**

Oracle JMC(Java Mission Control)는 이클립스 RCP 기반으로 개발된 자바 가상 머신(JVM)의 모니터링, 진단 및 프로파일링을 위한 고급 도구이다. JMC는 JVM을 분석하여 애플리케이션의 성능을 개선하고 시스템 성능 문제를 해결할 수 있는 다양한 도구를 제공한다. JDK를 설치하면 %JAVA_HOME%\bin 폴더에 존재하기 때문에 따로 설치할 필요 없이 "jmc.exe" 파일을 더블클릭하여 실행하면 된다.

![](https://postfiles.pstatic.net/MjAyMzA0MjJfMTM3/MDAxNjgyMTM0NDM0NTUy.qfrQcWFMkaye4iOvywLcdOWgF8jqDYRuem6vkGxYnsIg.UujLaEgAzwMKfbS3mlhNmj3O1dS5SsRY4MRTXk7Mtygg.PNG.agapeuni/img.png?type=w80_blur)

​

​

**2\. JMC 특징**

Oracle JMC는 JVM 모니터링 및 진단을 위한 강력한 도구로 자바 애플리케이션의 성능 개선 및 문제 해결에 필수적이다. JMC의 주요 특징은 다음과 같다.

​

1) 사용이 간편하다

JMC는 사용하기 쉬운 GUI를 제공하므로 JVM 모니터링 및 성능 분석에 필요한 복잡한 설정과 명령어를 배우지 않고도 쉽게 사용할 수 있다.

​

2) JVM 상태 모니터링

JMC는 JVM 내부에서 실행되는 애플리케이션의 상태를 실시간으로 모니터링할 수 있다. 이는 JVM 메모리 사용량, 쓰레드 상태, 클래스 로딩 및 가비지 컬렉션 등을 포함한다.

​

3) 이벤트 브로커

JMC는 이벤트 브로커를 제공하여 JVM의 상태 변경에 대한 이벤트를 수집하고 이벤트에 대한 세부 정보를 제공한다.

​

4) Profiler

JMC는 프로파일러를 제공하여 애플리케이션의 성능 문제를 파악하고 해결하는 데 도움을 준다.

​

5) Flight Recorder

JMC는 Flight Recorder라는 고급 분석 도구를 제공한다. Flight Recorder는 JVM에서 발생하는 이벤트를 수집하여 분석하는 데 사용된다.

​

6) 다양한 플러그인

JMC는 다양한 플러그인을 제공하여 애플리케이션 및 JVM의 성능 문제를 진단할 수 있다.

​

​

**3\. JMC 실행**

Oracle JMC를 실행하면 좌측 JVM 브라우저에 모니터링 가능한 자바 애플리케이션이 표시된다. 여기서는 Apache JMeter를 선택하였다. 좌측에 선택한 애플리케이션은 상단의 탭으로 표시되고 선택한 애플리케이션의 하단에 보면 여러 가지 탭이 따로 표시된다.

![](https://postfiles.pstatic.net/MjAyMzA0MjJfMTY4/MDAxNjgyMTM0NDQxODE0.lxR0AIfqGy9hTWIysJ9Hib3SFiZhEXPw3l7sVcpfNyEg.3hYClbkFfnXkiJaIHigZglRa-QP6w_XhJkyBKlPwbGMg.PNG.agapeuni/img.png?type=w80_blur)

**"Overview" 탭**

"Overview" 탭에는 Java Heap Memory, JVM CPU Usage, Live Set + Fragmentation 이 게이지 형태로 대시보드에 표시되고 시간 흐름에 따라 Processor와 Memory가 그래프로 표시된다.

![](https://postfiles.pstatic.net/MjAyMzA0MjJfMTk0/MDAxNjgyMTM0NDQ3OTA1.SPnZ-k5cJLNdr2wiZD8PoY9U36Cmi18d7OxFTzCrJPwg.z2HYzbGhlWeQegu3El4V1SDpU9oyG0M29rjn1AWaggIg.PNG.agapeuni/img.png?type=w80_blur)

**"MBean Browser" 탭**

"MBean Browser" 탭에는 MBean Tree와 MBean Features로 나누어져 있다. MBean Tree에서 항목을 선택하면 MBean Features에 관련 정보가 표시된다. MBean은 Managed Bean으로 모니터링을 위한 객체다.
