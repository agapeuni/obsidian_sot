1\. 전체 선택자

선택자에 아스테리스크(*)를 기술하여 모든 요소에 스타일을 지정한다. 

모든 요소에 적용되는 것인 만큼 변동 사항이 없을 때 쓰면 되지만, 로딩 속도가 저하된다. 

형식은

요소명 {속성 : 값;} = * {margin:0; padding;0;}

​

​

2\. 요소(Element) 선택자

가장 기본적인 선택자로, HTML 요소를 선택하여 스타일을 적용한다. 

HTML 요소명을 선택자로 사용하는 것을 말한다. 선택자는 요소의 이름으로 표시된다.

형식은

요소명 {속성 : 값;} = p {color:red;} = h1 {font-size:20px;}

위와 같이 HTML 모든 요소는 선택자로 사용할 수 있다.

​

3\. 클래스(Class) 선택자와 아이디(ID) 선택자

HTML 요소에 클래스 속성을 추가하고, 클래스 선택자를 사용하여 해당 클래스를 가진 요소를 선택한다. 클래스 선택자는 점(.)으로 시작한다. HTML 요소에 고유한 아이디 속성을 추가하고, 아이디 선택자를 사용하여 해당 아이디를 가진 요소를 선택한다. 아이디 선택자는 샵(#)으로 시작한다.

​

HTML 요소에 class 혹은 id 값이 부여된 경우 해당 요소로 바로 접근이 가능하다. 클래스 선택자는 여러 번 사용이 가능하고, 여러 요소를 한꺼번에 선택하여 일관된 스타일을 지정할 때 유용하다. 아이디 선택자는 유일한 요소에 접근할 때 쓰고, #으로 id 값을 나타낸다.

<style type=_"text/css"_ >

p _.note_ {

color: _blue_ ;

}

=_.note_ {

color: _blue_ ;

}

</style>

<p class="sample">요소(p)를 생략하고 바로 클래스명(.sample)을 써도 된다.</p>

4\. 속성(Attribute) 선택자

어떤 표현을 위해 굳이 더미 태크를 쓰지 않고도 표현할 수 있다는 점에서 유용하다.

하지만, 이 방식은 ie6과 기타 구버전 브라우저에서 지원을 하지 않는다.

​

요소명[속성명="속성값"] {속성 : 값;}

<style type=_"text/css"_ >

a[href^="http"] {

background-color: _red_ ;

}

a[href^="http://"] {

font-size: _22px_ ;

}

</style>

a 요소 중에 href 속성의 값이 "http://"로 시작하는 요소만 font-size를 22px로 크게 보여달라는 뜻이다. 

<ul>

<li><a href=_"#test.html"_ >속성선택자 테스트</a></li>

<li><a href=_"_[_http://www.css3.com/_](http://www.css3.com/)_"_ >속성선택자 테스트</a></li>

</ul>

5\. 가상 요소와 가상 클래스

**1) first-child가상 클래스**

<style type=_"text/css"_ >

_.lyrics_ {

font-size: _12px_ ;

font-weight: _bold_ ;

color: _#44C4DF_ ;

width: _500px_ ;

}

_.lyrics_ p _:first-child_ {

color: _#E7963D_ ;

font-size: _15px_ ;

text-indent: _1em_ ;

}

</style>

​

lyrics 클래스의 자식 요소 중에 첫 번째 p 요소에만 속성이 적용된다.

적절히 쓰면 불필요한 클래스를 사용하지 않아도 되는 방법이다.

<div class="lyrics">

<p>옛날의 금잔디 동산에 메기같이 앉아서 놀던 곳 물레방아 소리 들린다 메기야 희미한 옛생각</p>

<p>동산 수풀은 우거지고 장미화는 피어 만발 하였다 물레방아 소리 그쳤다 메기</p>

</div>

**2) 링크 가상 클래스**

이 부분은 많이들 쓰는 것이니 간단히 정의만 보겠다.

<style type=_"text/css"_ >

/* 방문하지 않은 링크 */

_.a_ {

text-decoration: _none_ ;

a: _link_{_color_ :_blue_ ;

}

/* 방문한 링크 */

a _:visited_ {

color: _pink_ ;

}

/* 링크 위에 마우스를 올렸을 때 */

a _:hover_ {

color: _orange_ ;

}

/* 활성화된 링크 */

a _:active_ {

color: _red_ ;

}

/* 링크 위에 포커스 되었을 때

a _:focus_ {

background-color: _#ffc_ ;

}

</style>

선언 순서에 유의해야 한다.

link -> visited -> hover -> active -> focus 순으로 지정한다. 

​

<style type=_"text/css"_ >

</style>

6\. 선택자 조합 

**1) 하위 선택자**

가장 많이 쓰이는 방법이다.

상위 요소가 포함하는 하위 요소에 스타일을 지정하고자 할 때 쓰이며, 선택자와 선택자 사이에 공백으로 구분한다.

​

<style type="text/css">

div p {color:red;}

</style>

<div>

<p>div가 아닌 p 요소에 적용됩니다.</p>

</div>

​

**2) 자식 선택자**

하위 선택자와 다른 점은 상속이 되질 않는다는 것이다.

​

<style type="text/css">

.parent > p {color:red;}

</style>

​

<div class="parent">

<p>자식선택자</p> <\- 이곳에만 적용

<div>

<p 하위선택자</p>

</div>

</div>

​

**3) 인접 선택자**

같은 레벨에서의 요소 중에 첫 번째 요소 + 두 번째 요소라고 생각하면 된다.

​

<style type="text/css">

h1 + h2 {color:gray;} : h2 요소에 적용된다.

</style>

​

<h1>첫번째요소</h1>

<h2>두번째요소</h2> <\- 이곳에만 적용

<p></p>

<h2>세번째요소</h2>

<p></p>

h2가 같은 레벨에 두 군데가 있지만, 첫 번째 요소와 인접한 요소에만 적용된다.

​

7\. 선택자 그룹화

다수 요소에 동일한 선언을 하고 싶을 때, 콤마(,)로 구분하여 지정할 수 있다.

​

div>p, p.note {color:blue;} 

두 가지 다른 요소에 색상을 파랑으로 한 번에 지정해 줄 수 있다.
