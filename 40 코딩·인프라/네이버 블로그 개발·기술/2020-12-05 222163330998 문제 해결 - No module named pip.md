# 2020-12-05 222163330998 문제 해결 - No module named pip

- 게시일: 2020. 12. 5. 0:29

## 본문

![](https://postfiles.pstatic.net/MjAyMzEwMThfMjk5/MDAxNjk3NTU5MzU4MzE2.Xyqhdx8YmcYH0TASz5dyvBEyp3OZIKu29tXH8UZrPjQg.5iVG9CatqSgkT9TX_vIRkp_IYUvfrR3qwUDZaGnn-TYg.PNG.agapeuni/%ED%8C%8C%EC%9D%B4%EC%8D%AC-001_\(6\).png?type=w80_blur)

​

1\. 문제(Problem)

파이썬에서 라이브러리를 설치하다보면 pip version을 업그레이드 하라는 WARNING이 표시된다.

![](https://postfiles.pstatic.net/MjAyMDEyMDVfNzUg/MDAxNjA3MDk1MTc0NzM3.n8Y9gjfCAK-3MFr3kucVAjaI2Mv1FsNpnnMDCFerpuog.M_VixH5-PB1MHwhOSBwBp0ZUTMwGoG_MEoMLuzyL7C4g.PNG.agapeuni/image.png?type=w80_blur)

> No module named pip

다음의 명령을 실행하면 pip 업그레이트가 실행되는데 간혹 오류가 발생하는 경우가 있다. 

**> python.exe -m pip install --upgrade pip**

![](https://postfiles.pstatic.net/MjAyMDEyMDVfMTE5/MDAxNjA3MDk1MjY2MDY5.1T6dws8uFmZcEkslXWmrSPz1vOSslnkUllon0S3Rx1Eg.EodUCLxydDkg2z_p6wCSft5D0_PvNillGL4XejqRa88g.PNG.agapeuni/image.png?type=w80_blur)

​

2\. 해결(Solution)

그럴때는 다음의 명령어로 pip를 재설치 하면 된다. 

참고로 PyPA(Python Packaging Authority)는 Python 패키징에 사용되는 핵심 소프트웨어 프로젝트를 유지 관리하는 작업 그룹이다.

​

**> curl **[**https://bootstrap.pypa.io/get-pip.py**](https://bootstrap.pypa.io/get-pip.py)**-o get-pip.py**

**> python get-pip.py --force-reinstall**
