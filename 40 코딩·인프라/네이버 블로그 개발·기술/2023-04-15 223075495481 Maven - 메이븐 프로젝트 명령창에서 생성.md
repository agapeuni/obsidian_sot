1\. 메이븐 프로젝트 생성 

apache maven을 다운로드하여 "D:\app\apache-maven-3.6.3"에 압축을 풀었다. 

그리고 Maven을 환경 변수에 추가하고 PATH를 설정했다. 명령창에서 메이븐을 실행할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA0MTVfMTI2/MDAxNjgxNTMxODcyNDY4.ajvTi5NV--ZOkBKWyVFwbJc3PpB9T3ut2ARpPKCovAAg.bKsA-PO9-kJAnqEAEoY_Q4sJr4o1KwJxeJsISg-9iOIg.PNG.agapeuni/image.png?type=w80_blur)

​

다음의 명령을 실행하여 메이븐 프로젝트를 생성한다.

> mvn archetype:generate

![](https://postfiles.pstatic.net/MjAyMzA0MTVfOTUg/MDAxNjgxNTMxNTUxNDY1.FakxNAOMqzb2guuoMl5u_O-jm5iJXein2er94_7R9uUg.OjHlTy0qBk0mdtfaTGl4I2klPSKKvU0itPe1g4N-5rog.PNG.agapeuni/image.png?type=w80_blur)

​

기본적으로 maven-archetype-quickstart가 선택된다. 

버전의 기본값은 최신 버전으로 지정되어 있다. 그냥 Enter를 친다.

groupId: com.oneway artifactId: mvn-pilot version: 1.0-SNAPSHOT package: com.oneway

![](https://postfiles.pstatic.net/MjAyMzA0MTVfNDkg/MDAxNjgxNTMxNjQ2ODQ0.F_0khkB1AJYmkKRCqQz9IKEcnGaXWthyqaxdZoyuLVMg.xK1bZfyhDxEjDSaUbUBlln_fn0jTxxU5n9b1fLFQbYYg.PNG.agapeuni/image.png?type=w80_blur)

​

2\. 메이븐 프로젝트 구성

다음과 같이 생성이 되었고 과 App.java, AppTest.java 파일과 pom.xml 파일이 만들어졌다.

mvn-pilot │ pom.xml │ └─src ├─main │ └─java │ └─com │ └─oneway │ App.java │ └─test └─java └─com └─oneway AppTest.java

​

파일 : App.java

package com.oneway; /** * Hello world! * */ public class App { public static void main( String[] args ) { System.out.println( "Hello World!" ); } } 

​

파일 : AppTest.java

package com.oneway; import static org.junit.Assert.assertTrue; import org.junit.Test; /** * Unit test for simple App. */ public class AppTest { /** * Rigorous Test :-) */ @Test public void shouldAnswerWithTrue() { assertTrue( true ); } } 

​

3\. 메이븐 컴파일

다음의 명령어로 메이븐 프로젝트를 컴파일한다.

> mvn compile

![](https://postfiles.pstatic.net/MjAyMzA0MTVfMjk4/MDAxNjgxNTMyODQyMTMz.qxS7FQyUolshbAcCV80qqstxQEmtAdF_oLulagYa84kg.CyzJfikw8L9da6hwIdPCTiuIU6wdJUeeRqcfsxpG3wQg.PNG.agapeuni/image.png?type=w80_blur)

​

컴파일이 성공적으로 실행한 이후에 다음과 같이 target 폴더에 컴파일한 결과물이 생성되었다.

mvn-pilot │ │ pom.xml │ ├─src │ ├─main │ │ └─java │ │ └─com │ │ └─oneway │ │ App.java │ │ │ └─test │ └─java │ └─com │ └─oneway │ AppTest.java │ └─target ├─classes │ └─com │ └─oneway │ App.class │ ├─generated-sources │ └─annotations └─maven-status └─maven-compiler-plugin └─compile └─default-compile createdFiles.lst inputFiles.lst

4\. 메이븐 테스트

다음의 명령어로 메이븐 프로젝트를 테스트한다.

> mvn test

![](https://postfiles.pstatic.net/MjAyMzA0MTVfMTgg/MDAxNjgxNTMzMDMzMjE1.HoECByYn1CoXIz6g4p8gZQVeFUxjpVdjPyKu1NRnz3Ug.nE0iTeNzXozmyguo1y_FGjc3KlPuMCvfxrh0qvDxPpcg.PNG.agapeuni/image.png?type=w80_blur)

mvn-pilot │ │ pom.xml │ ├─src │ ├─main │ │ └─java │ │ └─com │ │ └─oneway │ │ App.java │ │ │ └─test │ └─java │ └─com │ └─oneway │ AppTest.java │ └─target ├─classes │ └─com │ └─oneway │ App.class │ ├─generated-sources │ └─annotations ├─generated-test-sources │ └─test-annotations ├─maven-status │ └─maven-compiler-plugin │ ├─compile │ │ └─default-compile │ │ createdFiles.lst │ │ inputFiles.lst │ │ │ └─testCompile │ └─default-testCompile │ createdFiles.lst │ inputFiles.lst │ ├─surefire-reports │ com.oneway.AppTest.txt │ TEST-com.oneway.AppTest.xml │ └─test-classes └─com └─oneway AppTest.class

5\. 메이븐 패키지

다음의 명령어로 메이븐 프로젝트를 패키징 한다.

> mvn package

![](https://postfiles.pstatic.net/MjAyMzA0MTVfMjY0/MDAxNjgxNTMzMTY2NzU4.9zRT9ROWrGHF5tOPyvJsgLMMqKKTGIJijT9HCSuJUxkg.BzRI_y7kmQf9LMZMDgCmz0_QFxnD1w91qalXDu5q1WIg.PNG.agapeuni/image.png?type=w80_blur)

​

패키지가 성공적으로 실행되면 "mvn-pilot-1.0-SNAPSHOT.jar" 파일이 target 폴더에 생성된다.
