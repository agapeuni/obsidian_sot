**1\. 웹 서버와 WAS**

웹 서버(Web Server)와 WAS(Web Application Server)는 웹 애플리케이션을 실행하기 위한 서버 소프트웨어다. 그러나 두 개의 서버는 서로 다른 역할과 기능을 가지고 있다.

​

**1) 웹 서버**

웹 서버는 클라이언트로부터 HTTP 요청을 받아들여 정적인 웹 페이지, 이미지, HTML 파일 등을 제공한다. 일반적으로 웹 서버는 클라이언트와의 통신에서 정적인 콘텐츠를 제공하는 역할을 담당하며, 주로 정적 파일을 저장하고 HTTP 요청에 응답하는 기능을 제공한다. 웹 서버의 예로는 Apache HTTP Server, Nginx 등이 있다.

​

**2) WAS**

반면에 WAS는 동적인 웹 애플리케이션을 실행하기 위한 서버다. 웹 애플리케이션은 동적인 콘텐츠를 생성하고 데이터베이스와의 상호작용 등을 수행하는데, 이러한 동적인 기능을 처리하기 위해 WAS가 사용된다. WAS는 웹 서버와 달리 애플리케이션 실행 환경을 제공하고, 여러 가지 기능들을 포함하고 있다. 이러한 기능에는 웹 애플리케이션의 수명주기 관리, 스레드 관리, 데이터베이스 연결 관리, 보안 등이 포함된다. WAS의 예로는 Apache Tomcat, JBoss, WebLogic 등이 있다.

​

**3) 웹 서버와 WAS의 협력**

일반적으로 웹 서버와 WAS는 협력적으로 동작하여 웹 애플리케이션을 제공한다. 클라이언트의 요청이 들어오면 웹 서버가 정적인 콘텐츠를 처리하고, 동적인 처리가 필요한 경우에는 웹 서버가 WAS로 요청을 전달하여 해당 기능을 수행한다. 이런 방식으로 웹 서버와 WAS가 협력하여 웹 애플리케이션을 실행하고 결과를 클라이언트에게 제공한다.

**2\. 기본적인 웹 사이트 구성**

![](https://postfiles.pstatic.net/MjAyNTA1MDFfNjcg/MDAxNzQ2MTAyNTk2NTY5.iKI1Hh41a4arQxwqWxzc_UGP6RY7xEgssTb-tkRlqpQg.lTAkJ7HP3rCooavB2ysURZ9H7FKdlay17g9hf6TcMUYg.JPEG/SE-f47746a6-8e2b-4200-92ca-e59ef227661f.jpg?type=w80_blur)

<그림 1>은 가장 기본적인 웹 사이트의 구성 환경이다.

하나의 서버에서 웹 서버와 WAS의 역할을 동시에 수행하여 제공하는 콘텐츠를 집중하여 관리한다. 간단한 구성으로 되어 있어 개발과 테스트가 용이하지만 이용할 수 있는 사용자가 제한되어 있고 트래픽이 적을 때 활용성이 높아진다.

​

​

**3\. 웹 서버와 WAS로 구성된 환경**

![](https://postfiles.pstatic.net/MjAyNTA1MDFfMTUx/MDAxNzQ2MTAyNTk3MjAx.i-Phaof5wqVv6spNEEWFBZo8V-bARB2K-i79v4OSDbsg.8QgWPA5XcCKhkihQmbC7tVaT37T4-EPtby7lFWy2Jb8g.JPEG/SE-06e40a09-fed8-458e-bfc9-67d1724e40db.jpg?type=w80_blur)

<그림 2>는 웹 서버와 WAS의 기능을 분리하여 분산환경으로 구성하였다. 정적인 콘텐츠는 웹 서버에서 제공하고, 동적인 콘텐츠는 WAS가 제공한다. WAS는 웹 애플리케이션 기능에 집중할 수가 있어 보다 많은 사용자에게 서비스를 제공할 수 있고 보다 많은 트래픽을 처리할 수 있다.

​

​

**4\. 특정 서버를 별도로 구성**

![](https://postfiles.pstatic.net/MjAyMzA2MDhfNDAg/MDAxNjg2MTk5Nzc2MzM2.S1BXMzhNeChDYbvqNb3uYVUCGjR6IjPIXQVWkI6suMog.ZUfoJ6IgaIZHPKU6oOhBFC21AU0Tr37MTSpuWaIVpYog.JPEG.agapeuni/img.jpg?type=w80_blur)

UI가 점점 복잡해지고 화려해짐에 따라 이미지의 사용이 높아져서 이미지만을 위한 별도의 웹 서버를 구성하였다. 웹 서버는 이미지를 제외한 정적인 콘텐츠만을 제공하여 로드를 보다 효과적으로 분산할 수 있다. 이런 구성은 다양한 환경에 대해 대처할 수 있지만 구성이 복잡해 개발이나 테스트가 어렵다.

​

​

**5\. WAS를 로직으로 구분하여 구성**
