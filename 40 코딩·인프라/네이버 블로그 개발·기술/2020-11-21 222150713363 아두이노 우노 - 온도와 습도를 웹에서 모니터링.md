온습도 센서를 이용하기 위해 DHT.h를 추가하고 이더넷으로 웹 서비스를 제공하기 위해 SPI.h 와 Ethernet.h를 추가한다.

#include <DHT.h> #include <SPI.h> #include <Ethernet.h>

​

다음은 DHT를 정의한다. 2번 핀에 연결하였고 Type은 DHT11이다.

#define DHTPIN 2 #define DHTTYPE DHT11 DHT dht(DHTPIN, DHTTYPE);

​

MAC 주소와 IP 주소를 정의한다.

MAC 주소는 네트워크 상에 존재하지 않는 것으로 임의로 만든다. 

​

IP 주소는 네트워크 환경에 따라 적절히 부여한다. 192.168.0.10으로 지정했다.

EthernetServer 객체는 웹의 기본 포트인 80으로 지정했다.

byte MAC_ADRS[] = { 0xB1, 0x13, 0xFA, 0x35, 0x1A, 0xE2 }; byte IP_ADRS[] = { 192, 168, 0, 10 }; EthernetServer ethernetServer(80); 

setup 함수에서 Serial은 9600으로 설정하고 위에서 정의한 MAC 주소와 IP 주소를 갖고 Ethernet.begin 함수를 호출한다.

그리고 eternetSetver의 begin 함수도 호출한다.

void setup() { Serial.begin(9600); Ethernet.begin(MAC_ADRS, IP_ADRS); ethernetServer.begin(); dht.begin(); } 

다음은 loop 함수를 작성해 보자.

먼저 dht 센서에서 습도와 온도를 읽어온다. 읽어온 값이 유효하면 Serial로 전송하고 유효하지 않으면 Failed를 전송한다.

float humidity = dht.readHumidity(); float temperature = dht.readTemperature(); if (isnan(humidity) || isnan(temperature)) { Serial.println("Failed"); return; } Serial.print(humidity); Serial.print(","); Serial.print(temperature); Serial.println(); delay(1000);

​

다음은 EthernetClinet를 작성해 본다. 여기에서는 서비스하려는 웹페이지를 구현한다.

클라이언트와 연결이 되면 먼저 성공 메시지를 보낸다. 

그리고 센서에서 읽은 값을 화면에 표시하고 meta 태그를 이용해 1초마다 반복한다.

습도는 파랑, 온도 빨강으로 지정했다.

EthernetClient ethernetClient = ethernetServer.available(); if (ethernetClient) { while (ethernetClient.connected()) { ethernetClient.println("HTTP/1.1 200 OK"); ethernetClient.println("Content-Type: text/html"); ethernetClient.println("Pragma: no-cache"); ethernetClient.println(); ethernetClient.println("<!DOCTYPE html>"); ethernetClient.println("<html lang='ko'>"); ethernetClient.println("<head>"); ethernetClient.println("<meta http-equiv='refresh' content='1'/>"); ethernetClient.println("</head>"); ethernetClient.println("<body>"); ethernetClient.println("<h1 style='color:#0aa784'>Arduino UNO</h1>"); ethernetClient.print("<h1 style='color:blue'> H : "); ethernetClient.print(humidity); ethernetClient.println("</h1>"); ethernetClient.print("<h1 style='color:red'> T : "); ethernetClient.print(temperature); ethernetClient.println("</h1>"); ethernetClient.println("</body>"); ethernetClient.println("</html>"); ethernetClient.stop(); } delay(100); }

Serial을 COM3로 지정하고 속도를 9600에 맞춘다.

import serial ser = serial.Serial( port='COM3', baudrate=9600, )

값을 읽어 콤마(,)로 split 하여 arr에 담는다. 그리고 습도와 온도에 각각 출력한다.

while True: if ser.readable(): res = ser.readline() arr = res.decode()[:len(res)-1].split(',') print("습도", arr[0], "온도", arr[1])
