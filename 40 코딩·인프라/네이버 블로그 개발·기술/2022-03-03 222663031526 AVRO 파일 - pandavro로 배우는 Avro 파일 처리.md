1\. pandavro 모듈

pandavro는 Apache Avro와 Pandas DataFrame 간의 인터페이스이며 AVRO 형식의 데이터 파일 처리에 사용되는 Python 라이브러리이다.

​

Apache Avro는 특정 언어에 종속되지 않은 언어 중립적 데이터 직렬화 시스템으로 만든 프로젝트이다. 다른 시스템과 비슷하게 언어 독립 스키마로 기술된다. 특정 스키마를 사전에 알지 못하더라도 해당 스키마에 부합하는 데이터를 읽고 쓸 수 있다. AVRO의 스키마는 JSON으로 작성하며 데이터는 바이너리 포맷으로 인코딩된다. 데이터를 읽는데 사용되는 스키마와 데이터를 쓰는 데 사용되는 스키마가 같지 않아도 된다. 새로운 필드는 적당히 무시하고 기존 데이터 작업처럼 처리할 수 있다.

​

pandavro는 다음과 같은 기본 유형(null, boolean, Int, long, float, double, bytes, string)을 처리 할 수 있다.

Numpy/pandas 유형 |  Avro 기본 유형  
---|---  
np.bool_ |  boolean  
np.float32 |  float  
np.float64 |  double  
np.unicode_ |  string  
np.object_ |  string  
np.int8, np.int16, np.int32 |  int  
np.uint8, np.uint16, np.uint32 |  int  
np.int64, np.uint64 |  long  
pd.Int8Dtype, pd.Int16Dtype, pd.Int32Dtype |  int  
pd.UInt8Dtype, pd.UInt16Dtype, pd.UInt32Dtype |  unsigned int  
pd.Int64Dtype |  long  
pd.UInt64Dtype |  unsigned long

2\. Avro 파일 쓰기

pandavro의 to_avro 함수를 사용하여 "example.avro" 파일로 저장한다.

import pandavro import numpy as np import pandas as pd df = pd.DataFrame( { "String": ["one", "two", "three", "four"], "DateTime64": [ pd.Timestamp("20210709"), pd.Timestamp("20210710"), pd.Timestamp("20210711"), pd.Timestamp("20210712"), ], "Boolean": [True, False, True, False], "Float32": np.random.randn(4), "Float64": np.random.randn(4), "Int64": np.random.randint(0, 10, 4), } ) pandavro.to_avro("./data/example.avro", df)

3\. Avro 파일 읽기

pandavro의 read_avro 함수를 사용하여 Avro 파일을 읽거 화면에 출력하는 예제이다. Avro 파일을 읽어 pandas DataFrame에 맞춘다.

import os import pandavro df = pandavro.read_avro("./data/example.avro") print(df)

4\. Avro 예제

리스트로 member 정보를 작성해 pandas의 DataFrame으로 출력하고 avro 파일로 저장한다. 저장된 avro 파일을 읽어 출력하는 예제이다.

import pandas as pd import pandavro # member 리스트 member = [ {"name": "유재석", "birth": "1972-08-14", "job": "MC, 개그맨"}, {"name": "강호동", "birth": "1970-05-11", "job": "MC, 개그맨"}, {"name": "김구라", "birth": "1970-10-03", "job": "MC, 개그맨"}, ] # DataFrame df1 = pd.DataFrame.from_records(member) print(df1) print() # Avro 쓰기 pandavro.to_avro("./data/member.avro", df1) # Avro 읽기 df2 = pandavro.from_avro("./data/member.avro") print(df2)

실행결과 ​

name birth job 0 유재석 1972-08-14 MC, 개그맨 1 강호동 1970-05-11 MC, 개그맨 2 김구라 1970-10-03 MC, 개그맨 name birth job 0 유재석 1972-08-14 MC, 개그맨 1 강호동 1970-05-11 MC, 개그맨 2 김구라 1970-10-03 MC, 개그맨
