1\. HTML 탄생

HTML(HyperText Markup Language)은 웹 페이지를 만들기 위해 사용되는 마크업 언어다. HTML은 1990년대 초에 탄생하였으며, 웹의 발전과 함께 계속 발전하고 있다. HTML은 웹의 구조를 정의하고 정보를 제공하는 역할을 하며, 웹의 발전과 함께 새로운 기능과 기술들을 수용하고 있다. 

​

HTML은 스위스 유럽 입자물리 연구소(CERN)의 물리학자 팀 버너스 리에 의해 만들어졌다. 컴퓨터 정보 수집 및 제어 관계 연구원이었던 팀 버너스 리는 1990년 인터넷을 편리하게 사용할 수 있는 하이퍼텍스트(HyperText) 프로젝트를 제안하고 웹(WWW, World Wide Web)의 개념을 고안했다. 멀리 떨어져 있는 연구자들끼리 연구에 대한 여러 정보를 효과적으로 공유하기 위한 목적으로 그는 하이퍼텍스트를 이용한 정보 전달 방법을 제안했다.

이후 1990년 말에 NeXT라는 컴퓨터에서 동작하는 최초의 WWW 소프트웨어가 발표되었다. 이 소프트웨어를 이용한 시연회가 CERN 위원회에서 개최한 세미나와 하이퍼텍스트 학술대회에서 발표되었다. 이후 웹(WWW)은 1992년 모자이크(Mosaic)라는 브라우저가 등장과 함께 대중화되었다. 

​

HTML은 웹의 발전과 함께 새로운 기술과 기능들을 수용하고 있다. CSS(Cascading Style Sheets)와 JavaScript와의 통합을 통해 웹 페이지의 디자인과 동적인 기능을 제공하며, 반응형 웹 디자인, 멀티미디어 지원, 웹 접근성 등 다양한 측면에서 발전하고 있다.

2\. HTML의 역사 

HTML은 사용자에게 정보를 제공하고 문서를 구조화하는 역할을 한다. 초기의 HTML 버전은 매우 단순하고 제한적이었지만, 시간이 흐름에 따라 계속 발전하면서 새로운 기능과 태그들이 추가되었다. HTML은 팀 버너스 리에 의해 개발되었으며, W3C에 의해 표준화되고 발전해 왔다. HTML의 발전은 웹 표준화 기구인 W3C에 의해 주도되었다. 

​

W3C(World Wide Web Consortium)는 웹 기술의 표준을 제정하고 관리하는 단체로서, HTML의 발전과 호환성을 유지하기 위한 노력을 하였다. 팀 버너스 리는 현재 인터넷 표준을 제정하는 미국에 있는 비영리법인인 "W3 컨소시엄"에 참여하여 계속 발전시키고 있다. W3C는 HTML 4.01(1999년), XHTML 1.0(2000년), HTML5(2014년), ... 등 다양한 HTML 버전을 발표하였으며, 현재는 HTML Living Standard로 알려진 HTML5.3 버전을 유지하고 있다.

버전 |  년도  |  설명  
---|---|---  
**HTML 1.0** |  1993년 07월 |  Hyper Text 기능 위주. (HTML 1.0 발명은 1991년)   
**HTML 2.0** |  1995년 11월 |  HTML 2.0은 RFC 1866으로 게시. 그 뒤로 4차례 업데이트됨  
HTML 3.0 |  1995년 04월 |  구현이 복잡하여 브라우저 개발사에서 일부분만 수용.  
HTML 3.1은 정식 제안조차 될 수 없었음.   
**HTML 3.2** |  1997년 01월 |  HTML 3.2는 W3C 권장사항으로 발표.  
HTML 3.0 대부분의 기능들은 빠지고 브라우저의 필요를 채워줌.  
HTML 4.0 |  1997년 12월 |  HTML(구조)과 CSS(표현)로 분리하도록 표준화.   
SGML을 준수하는 SGML 응용 프로그램  
**HTML 4.01** |  1999년 12월 |  HTML 4.0의 몇 가지 수정됨. W3C이 인정하는 공식 버전.   
수년간 새로운 HTML 버전에 변동이 없음. 이후 HTML 5로 진행.   
XHTML 1.0 |  2000년 01월 |  HTML 4.0 및 4.01과 동일한 변형을 제공.  
HTML의 대중성과 XML의 확장성을 수용함.  
XHTML 1.1 |  2001년 05월 |  약간의 변경 사항을 적용. XHTML의 모듈화.  
XHTML 2.0 |  2006년 07월 |  XHTML 1.X와 호환되지 않은 새로운 버전임.  
HTML5 및 XHTML 5에 대한 작업을 위해 2009년에 작업이 중단.  
HTML 5.0 |  2014년 10월 |  HTML5의 최종 권고안이 확정.  
HTML 5.1 |  2016년 11월 |  W3C 권장 사항으로 게시  
HTML 5.2 |  2017년 12월 |  W3C 권장 사항으로 게시  
HTML Living Standard |  2019년 05월 |  따로 표준을 발표하던 W3C와 WHATWG가 이제 함께 표준 작업을 진행두 개의 표준을 단일화해 WHATWG가 하나의 표준을 발표  
2021년 01월 |  W3C가 공식적으로 HTML5.1, HTML5.2 표준과 HTML5.3 표준화 작업을 모두 폐기.
