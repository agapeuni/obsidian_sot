1\. gRPC 개요

gRPC(gRPC Remote Procedure Calls)는 구글이 개발한 원격 프로세서 호출 프레임워크로 모든 환경에서 실행할 수 있다. 고성능의 서비스를 효율적으로 지원한다. 서비스 정의가 심플하고 런타임 및 개발 환경을 쉽게 지원한다.

4\. 서비스 인터페이스 정의 파일

gRPC는 프로토콜 버퍼를 IDL로 사용해 서비스 인터페이스 정의 파일을 만든다. 

SayHello 서비스와 HelloRequest 요청 메시지 그리고 HelloReply 응답메시지를 정의한다.

​

**파일명 : helloworld.proto**

syntax = "proto3"; package helloworld; service Hello { rpc SayHello (HelloRequest) returns (HelloReply) {} } message HelloRequest { string name = 1; } message HelloReply { string message = 1; }

6\. 서버 구현

protoc(프로토콜 버퍼 컴파일러)로 생성된 서버 스켈레톤을 참조해 서버 로직을 구현한다.

grpc와 같은 폴더에 있는 helloworld_pb2.py 와 helloworld_pb2_grpc.py 모듈을 import 한다.

import grpc import helloworld_pb2 import helloworld_pb2_grpc

​

SayHello() 함수에서 Request 메지지에 담겨있는 name을 print 하였고 Reply로 'Hello, %s!'라는 message를 반환했다.

**​**

**파일 : hello_server.py**

from concurrent import futures import logging import grpc import helloworld_pb2 import helloworld_pb2_grpc class Hello(helloworld_pb2_grpc.HelloServicer): def SayHello(self, request, context): print("Hello server received :", request.name) return helloworld_pb2.HelloReply(message='Hello, %s!' % request.name) def serve(): server = grpc.server(futures.ThreadPoolExecutor(max_workers=10)) helloworld_pb2_grpc.add_HelloServicer_to_server(Hello(), server) server.add_insecure_port('[::]:50051') server.start() print("gRPC Server Start...") server.wait_for_termination() if __name__ == '__main__': logging.basicConfig() serve() 

**실행 결과**

**> python hello_server.py**

(grpc) D:\grpc\helloworld>python hello_server.py gRPC Server Start... Hello server received : gRPC Hello server received : gRPC

7\. 클라이언트 구현

프로토콜 버퍼 컴파일러로 생성된 클라이언트 스텁을 참조해 클라이언트 로직을 구현한다. stub을 통해 name을 'gRPC'로 지정한 뒤 SayHello를 호출한다. 정상적으로 호출되면 서버에서 반환한 message 가 화면에 표시된다.

​

**파일 : hello_client.py**

from __future__ import print_function import logging import grpc import helloworld_pb2 import helloworld_pb2_grpc def run(): with grpc.insecure_channel('localhost:50051') as channel: stub = helloworld_pb2_grpc.HelloStub(channel) response = stub.SayHello(helloworld_pb2.HelloRequest(name='gRPC')) print("Hello client received :" + response.message) if __name__ == '__main__': logging.basicConfig() run()

**실행 결과**

**> python hello_client.py**

(grpc) D:\grpc\helloworld>python hello_client.py Hello client received: Hello, gRPC! (grpc) D:\grpc\helloworld>python hello_client.py Hello client received: Hello, gRPC! (grpc) D:\grpc\helloworld>
