1\. PIL 개요

이미지를 Red, Green, Blue(RGB)로 분리하는 작업을 수행하였다. 이미지 파일 처리를 위해 Python Imaging Library(PIL)를 사용하였으며, 결과를 화면에 표시하기 위해 matplotlib 라이브러리를 활용하였다. RGB 분리를 확실하게 구분하기 위해 아래의 이미지를 사용하였다. 

​

입력 이미지 : rgb.png

2\. RGB 분리

입력 이미지는 다양한 RGB 색상 스펙트럼을 포함하고 있다. 먼저 이미지를 열어 Numpy 라이브러리를 통해 픽셀 배열로 변환하였다. 이후 원본 이미지를 보여주고, 각각 Red, Green, Blue 성분만 분리한 이미지를 별도로 표시하였다.

​

RGB 분리 작업은 다음과 같은 절차로 이루어졌다.

  * Red 분리: Green, Blue 채널을 0으로 설정

  * Green 분리: Red, Blue 채널을 0으로 설정

  * Blue 분리: Red, Green 채널을 0으로 설정

​

소스 코드 : img_01.py

import numpy as np import matplotlib.pyplot as plt import PIL.Image as pimg image = pimg.open("images/rgb.png") pixel = np.array(image) plt.subplot(141) plt.imshow(pixel) plt.axis("off") plt.title("RGB") # Red 분리 pixel_R = pixel.copy() pixel_R[:, :, (1, 2)] = 0 plt.subplot(142) plt.imshow(pixel_R) plt.axis("off") plt.title("R(Red)") # Green 분리 pixel_G = pixel.copy() pixel_G[:, :, (0, 2)] = 0 plt.subplot(143) plt.imshow(pixel_G) plt.axis("off") plt.title("G(Green)") # Blue 분리 pixel_B = pixel.copy() pixel_B[:, :, (0, 1)] = 0 plt.subplot(144) plt.imshow(pixel_B) plt.axis("off") plt.title("B(Blue)") plt.show()

이때 흰색 영역은 RGB 모든 값이 포함되어 있기 때문에, 분리해도 모든 채널에 색이 남는다. 

반면 검정색은 색상값이 없으므로, 어떤 채널로 분리해도 검정색으로 유지된다.

3\. 흑백 이미지

RGB 이미지는 세 가지 숫자(R, G, B)의 조합으로 표현된다. 이를 흑백 이미지로 변환하기 위해, 각 픽셀의 R, G, B 값을 합산한 뒤 3으로 나눈 평균값을 사용하여 새로운 픽셀값을 생성하였다.

​

물론 PIL 등 라이브러리의 내장 함수를 이용하면 훨씬 간편하게 흑백 변환이 가능하지만, 이번 실습에서는 계산 과정을 직접 구현하여 학습의 효과를 높이고자 하였다. 변환된 결과는 원본 이미지와 나란히 비교하여 확인하였다.

​

소스 코드 : img_02.py

import numpy as np import matplotlib.pyplot as plt import PIL.Image as pimg # 입력 이미지 im1 = pimg.open("images/mei4.png") pixel1 = np.array(im1) pixel1 = (1/255) * pixel1 pixelSize = np.array(pixel1.shape) pixel2 = np.empty(pixelSize) # 흑백이미지로 변환 for i in range(pixelSize[0]): for j in range(pixelSize[1]): graypixel = (pixel1[i][j][0] + pixel1[i][j][1] + pixel1[i][j][2]) / 3 pixel2[i, j] = (graypixel, graypixel, graypixel) plt.subplot(141) plt.imshow(pixel1) plt.axis("off") plt.title("Nagano Mei", fontsize=9) plt.subplot(142) plt.imshow(pixel2) plt.axis("off") plt.title("Gray Mei", fontsize=9) plt.show()

4\. 이미지 파일 종류

이미지 파일의 종류는 생각보다 다양하고 종류가 많다. 여기서는 대표적으로 많이 사용하는 이미지 파일 종류에 대해 알아보자.

​

1) BMP (Bitmap Image)

24비트의 색을 표현할 수 있고 비트맵 이미지를 저장하는데 사용한다. BMP는 파일압축을 하지 않아 다른 종류에 비해 파일 크기가 크다.

​

2) GIF (Graphics Interchange Format)

8색을 표현할 수 있으며 투명한 배경을 지원한다. 표현하는 색상은 256색으로 적지만 하나의 파일에 여러 이미지를 저장하여 움직이는 효과를 표현할 수 있다. 

​

3) JPG (Joint Picture Experts Group)

인터넷에서 가장 널리 사용된다. 주로 사진을 저장하는데 많이 사용한다. 이미지를 압축할 수 있는데 압축율을 높이면 이미지 품질이 떨어진다.

​

4) PNG (Potable Network Graphics)

비손실 압축방식으로 이미지 손상없이 파일을 저장한다. 투명한 배경을 지원하고 디지털 사진 저장이나 컴퓨터에서 작업하는데 많이 사용한다.

​
