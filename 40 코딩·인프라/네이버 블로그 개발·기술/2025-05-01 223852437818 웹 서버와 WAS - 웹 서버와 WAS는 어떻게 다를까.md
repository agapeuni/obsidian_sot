# 2025-05-01 223852437818 웹 서버와 WAS - 웹 서버와 WAS는 어떻게 다를까

## 본문

​

웹 서버(Web Server)와 WAS(Web Application Server)는 웹 개발과 배포에 꼭 필요한 두 가지 핵심 구성 요소다. 이러한 구조를 통해 성능 분산, 확장성 향상, 보안 강화 등의 이점을 얻을 수 있다.

![](https://postfiles.pstatic.net/MjAyNTA1MDFfMjAx/MDAxNzQ2MDkxMTUyMTc3.v-ByBDrXpSkS4KlCLbITXny2JzbeiFu4ARMtfUUT9pgg.LiBFaozdi7IWGYPHGtoO_f8v9IPniOKwUH2QLNLz3QUg.PNG/ChatGPT_Image_2025%EB%85%84_5%EC%9B%94_1%EC%9D%BC_%EC%98%A4%ED%9B%84_05_53_13.png?type=w80_blur)

**​**

**1\. 웹 서버 (Web Server)**

웹 서버란 클라이언트, 주로 웹 브라우저로부터의 요청을 수신하여 HTML, CSS, JavaScript, 이미지 등의 정적 콘텐츠를 제공하는 소프트웨어를 의미한다.

​

**1) 주요 기능**

  * 정적 파일(HTML, CSS, JS, 이미지 등)의 제공

  * HTTP 프로토콜을 기반으로 한 요청 수신 및 응답 처리

  * 로드 밸런싱 기능을 통한 트래픽 분산

  * HTTPS를 통한 보안 통신 지원

​

**2) 대표적인 웹 서버**

  * Apache HTTP Server

  * Nginx

  * Microsoft IIS 등

​

**3) 동작 예시**

사용자가 웹 브라우저를 통해 www.example.com/index.html을 요청할 경우, 웹 서버는 해당 HTML 파일을 찾아 그대로 클라이언트에게 반환한다.

​

​

**2\. 웹 애플리케이션 서버 (WAS: Web Application Server)**

웹 애플리케이션 서버는 사용자 요청을 기반으로 동적인 콘텐츠를 생성하며, 주로 백엔드의 비즈니스 로직을 수행하는 역할을 담당한다. 정적인 콘텐츠와 달리, 프로그램을 실행하여 결과를 생성한 후 이를 클라이언트에게 전달한다.

​

**1) 주요 기능**

  * 비즈니스 로직의 실행

  * 데이터베이스 연동 및 처리

  * 동적 콘텐츠의 생성 (예: JSP, Servlet, PHP 등)

  * 트랜잭션, 세션, 인증 등 서버 측 기능 제공

​

**2) 대표적인 WAS**

  * Apache Tomcat

  * JBoss / WildFly

  * WebLogic, WebSphere

  * Node.js (웹 서버와 WAS의 기능을 동시에 수행 가능)

​

3) 동작 예시

사용자가 www.example.com/user?id=123과 같은 요청을 보낼 경우, WAS는 해당 ID에 해당하는 사용자의 정보를 데이터베이스에서 조회한 후 HTML 형식으로 동적으로 페이지를 생성하여 응답한다.

​

​

**3\. 웹 서버와 WAS의 차이 비교**

항목 |  웹 서버 (Web Server) |  웹 애플리케이션 서버 (WAS)  
---|---|---  
주요 역할 |  정적 파일 제공, 요청 라우팅 |  로직 수행, 데이터 처리  
처리 대상 |  정적 콘텐츠 전달 |  동적 콘텐츠 생성  
처리 파일 |  HTML, CSS, JS, 이미지 |  JSP, Servlet, PHP, Python 등  
처리 속도 |  상대적으로 빠름 |  상대적으로 느림 (복잡한 로직 처리 필요)  
대표 SW |  Apache HTTP Server, Nginx 등 |  Tomcat, JBoss, WebLogic 등  
  
​

**4\. 웹 서버와 WAS의 관계**

실제 웹 시스템에서는 웹 서버와 WAS를 함께 구성하여 안정성과 효율성을 도모한다.

​

일반적인 처리 순서는 다음과 같다.

1) 클라이언트의 요청을 웹 서버가 수신한다.

2) 요청이 정적 콘텐츠에 해당할 경우 웹 서버가 직접 응답한다.

3) 동적 처리가 필요한 경우 요청을 WAS에 전달한다.

4) WAS가 요청을 처리한 후, 결과를 웹 서버를 통해 클라이언트에게 반환한다.
