# 2015-02-16 220274455578 라즈베리 파이 - PWM 실험 LED 점멸과 부저로 배우는 제어

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=220274455578&categoryNo=982
- 게시일: 2015. 2. 16. 1:30

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTQ4/MDAxNzU4NDM4NTMzNzc1.7N28gFZCi3SeILsfupUZXEurdc1Ltdwr-MHxgxRXxy8g.r3X45Of93oj4HwFWKDg78zUZ2gbREX-EX7gacZ74YR4g.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(7\).png?type=w80_blur)

이번 실험에서는 PWM에 대해서 좀 더 알아보고 부저 스피커를 사용하여 간단한 소리를 내보려고 합니다. ^^

​

![](https://blogimgs.pstatic.net/sticker/pc/james_special/original/22.png)

아래의 목록과 그림은 실험의 준비물입니다. 

부저 스피커를 브레드보드에 꼽기 편하게 선을 연결해 두었습니다.

​

**부저 스피커 1개**

**고휘도 LED 1개**

**270옴 저항 1개**

**MM 점퍼선 2개**

![](https://postfiles.pstatic.net/20150605_32/agapeuni_1433465422674cMD9T_JPEG/20150215_210507.jpg?type=w80_blur)

​

먼저 G18번에 노란 점퍼선을 연결하고 브레드보드의 고휘도 LED의 (+)에 연결합니다. GND 접지에 검정 점퍼선을 연결하고 270옴 저항을 사이에 두고 고휘도 LED의 (-)에 연결합니다. 부저 스피커의 빨간 선을 고휘도 LED의 (+)에 연결하고 부저 스피커의 검정선을 고휘도 LED의 (-)에 연결합니다. 

![](https://postfiles.pstatic.net/20150605_133/agapeuni_1433465435011jKAaV_JPEG/20150215_210207.jpg?type=w80_blur)

​

**실험 1.**

**소스코드 (PWM_Blink.py)**

**첨부파일**

PWM_Blink.py

[ 파일 다운로드 ](https://download.blog.naver.com/open/d540c972605e5febcf2143754cabdea80c5da086/EFsQbbZLxbbO9tNcLuoSggWaFwbSq-VhdkQGNWY5_gMuGY-5W3og6fy6A4UO72hl1xWkbkfmkNk-0Bp84ZOE75lVDrPm-w/PWM_Blink.py)

GPIO18 핀으로 사용자가 입력한 값으로 DutyCycle 값으로 설정합니다. 

0부터 10단위씩 증가하며 입력하여 LED의 깜박임을 확인해 보겠습니다.

![](https://postfiles.pstatic.net/20150605_61/agapeuni_1433465443722BRDIN_PNG/20150215_211255.png?type=w80_blur)

​

**동영상**

아래는 위의 코드에 대한 동영상입니다. 

10단위씩 증가시키면서 값을 입력하여 어떻게 표시되는지 확인해 보겠습니다.

​

​

**실험 2.**

**소스코드 (PWM_Buzzer.py)**

**첨부파일**

PWM_Buzzer.py

[ 파일 다운로드 ](https://download.blog.naver.com/open/17820bb8acf3f32f02ed82b08a681365ca9c6180ef/EFsQbbZLxbbO9d1fLuoSggWaFwbSq-VhdkQGNWY5_gMuGY-5W3og6Pi9CYEOhS5t3C7wbkfmDaYAKi1gjdfMkPxWTY93zQ/PWM_Buzzer.py)

부저의 소리를 확인하기 위해 먼저 Pitch 값을 입력하여 음의 높이를 입력하고 Duration을 초 단위로 입력합니다.

​

![](https://postfiles.pstatic.net/20150605_43/agapeuni_1433465459536Xkukx_PNG/20150215_211215.png?type=w966)

​

입력창에서 코드를 실행시키고 아래와 같이 값을 입력하였습니다. 

결과 화면은 아래의 실험 2. 동영상을 보시면 됩니다.

![](https://postfiles.pstatic.net/20150605_130/agapeuni_1433465474762Ig7FM_PNG/20150215_211011.png?type=w80_blur)
