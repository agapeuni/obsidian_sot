# 2025-04-16 223835492456 PL SQL - PL SQL 블럭 구조와 종류별 사용법 정리

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTZfMTQx/MDAxNzQ0Nzc1NDgxNjY2.sPCb_TbrvE1tG2rIGYxR4LiufIilsP6jvt4sgTnCSSsg.RNodoK8Cig4hLWUwqHry6v7_64zDU0CD-TUexzE_7zwg.PNG/PL_SQL-001_\(2\).png?type=w80_blur)

​

Oracle 데이터베이스를 보다 유연하고 효율적으로 다루기 위해서는 PL/SQL에 대한 이해가 필수적이다. 특히 PL/SQL의 핵심이라 할 수 있는 **블럭 구조** 와 각 블럭의 종류 및 사용법에 대한 숙지는 PL/SQL 프로그래밍 능력 향상에 큰 도움이 된다.

​

​

**1\. Anonymous Block (이름 없는 블럭)**

이름 없는 블럭은 **프로시저나 함수, 트리거의 본문을 구성하지 않고 단독으로 실행되는 블럭** 이다. 주로 SQL*Plus와 같은 도구에서 인라인 스크립트로 사용되며, 오류 처리 목적으로 다른 블럭 내에 삽입되기도 한다. 기본 구조는 다음과 같다.

DECLARE \-- 변수 선언부 (선택사항) BEGIN \-- 실행부 (필수) EXCEPTION \-- 예외 처리부 (선택사항) END; 

  * DECLARE: 변수, 커서, 사용자 정의 예외 등을 선언 (선택적)

  * BEGIN: SQL 및 PL/SQL 실행문 포함 (필수)

  * EXCEPTION: 오류 발생 시 수행할 처리 정의 (선택적)

  * END: 블럭 종료 (필수)

**​**

**​**

**2\. Function Block (함수 블럭)**

함수 블럭은 특정 값을 반환하는 PL/SQL 구조로, 식(expression)에서 사용될 수 있는 점이 특징이다. 함수는 DECLARE가 아닌 **함수 헤더로 시작** 하며, 반환형을 반드시 명시해야 한다.

FUNCTION 함수명 [(매개변수)] RETURN 반환형 IS \-- 변수 선언 BEGIN \-- 실행 코드 EXCEPTION \-- 오류 처리 코드 END; 

**​**

**예제**

FUNCTION iifn(boolean_expression IN BOOLEAN, true_number IN NUMBER, false_number IN NUMBER) RETURN NUMBER IS BEGIN IF boolean_expression THEN RETURN true_number; ELSIF NOT boolean_expression THEN RETURN false_number; ELSE RETURN NULL; END IF; END; 

이와 같이 작성된 함수는 논리 조건에 따라 숫자를 반환하는 용도로 활용할 수 있다.

**​**

**​**

**3\. Procedure Block (프로시저 블럭)**

프로시저는 함수와 구조적으로 유사하지만, **반환값을 가지지 않으며 식 내부에서 사용될 수 없다** 는 차이점이 있다. 주로 여러 동작을 절차적으로 처리하고자 할 때 활용된다.

PROCEDURE 프로시저명 [(매개변수)] IS \-- 변수 선언 BEGIN \-- 실행 코드 EXCEPTION \-- 오류 처리 END; 

​

**예제**

PROCEDURE swapn(num_one IN OUT NUMBER, num_two IN OUT NUMBER) IS temp_num NUMBER; BEGIN temp_num := num_one; num_one := num_two; num_two := temp_num; END; 

이 프로시저는 두 숫자의 값을 서로 바꾸는 기능을 수행한다.

**​**

**​**

**4\. Nested Block (중첩 블럭)**

중첩 블럭은 하나의 블럭 안에 또 다른 블럭이 포함되는 구조를 말하며, **블럭 단위로 지역 범위(Scope)를 형성** 한다. 상위 블럭의 변수는 하위 블럭에서 사용 가능하나, 그 반대는 불가능하다.

DECLARE \-- 외부 블럭 변수 BEGIN DBMS_OUTPUT.PUT_LINE('시작'); DECLARE \-- 내부 블럭 변수 BEGIN \-- 내부 블럭 실행 코드 EXCEPTION \-- 내부 블럭 예외 처리 END; \-- 외부 블럭 실행 코드 EXCEPTION \-- 외부 블럭 예외 처리 END; 

중첩 구조를 통해 로직을 더 유연하고 세밀하게 구성할 수 있으며, 오류의 원인을 구체적으로 파악하고 처리할 수 있다.

​

**​**

**5\. Trigger Block (트리거 블럭)**

트리거 블럭은 **특정 이벤트(INSERT, UPDATE, DELETE 등)가 발생했을 때 자동으로 실행되는 코드** 를 정의하는 데 사용된다. 주로 데이터 무결성을 유지하거나, 특정 동작을 감시할 필요가 있을 때 활용된다. 트리거는 데이터베이스 보안과 자동화된 데이터 처리에서 핵심적인 역할을 수행한다.

CREATE [OR REPLACE] TRIGGER 트리거명 {BEFORE | AFTER} 이벤트 ON 테이블명 [FOR EACH ROW] DECLARE \-- 선언부 BEGIN \-- 실행부 END; 

  * **동사 목록** : 트리거를 발생시키는 SQL 동작 (예: INSERT, DELETE)

  * **테이블명** : 트리거가 작동하는 테이블

  * **선언문** : 변수, 커서, 예외 등 선언

  * **실행 코드** : 트리거 실행 시 수행할 로직

​

PL/SQL 블럭은 이처럼 다양한 구조와 용도로 구성되어 있으며, 각 블럭의 특성과 목적에 따라 적절하게 활용하는 것이 중요하다. 이를 통해 Oracle 데이터베이스에서 더욱 안정적이고 유연한 프로그래밍이 가능해진다.
