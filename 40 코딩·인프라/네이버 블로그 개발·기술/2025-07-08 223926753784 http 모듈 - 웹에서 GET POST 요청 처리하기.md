1\. 개요

본 예제는 Node.js의 http 모듈을 이용하여 웹 브라우저에서 들어오는 GET 및 POST 요청을 처리하는 간단한 서버 프로그램을 구현하는 내용을 다룬다. GET 요청의 경우 HTML 파일을 브라우저에 출력하고, POST 요청의 경우 전송된 데이터를 분석하여 브라우저에 표시하는 구조로 구성되어 있다.

​

​

2\. 구현 방식

우선, 서버에서 필요한 기본 모듈들을 선언한다. HTTP 요청을 처리하기 위한 http 모듈과 파일 입출력을 위한 fs 모듈을 사용한다.

var http = require('http'); var fs = require('fs');

그 후, 요청을 처리할 콜백 함수 onRequest()를 생성한다.  콜백 함수의 파라미터로 request와 response를 받는다. 해당 함수 내에서 HTTP 요청의 메서드(GET 또는 POST)에 따라 다른 응답을 제공하도록 구현한다. 

function onRequest(request, response) { …(중략)… }

서버는 http.createServer() 함수를 통해 Server를 생성하며, 콜백 함수로 onRequest를 지정해 준다. 그리고 1337번 포트에서 요청을 수신하도록 설정한다.

http.createServer(onRequest).listen(1337, function() { console.log('http://127.0.0.1:1337'); });

요청 Method에 따라 GET인 경우는 html 파일을 전송해 주고 POST인 경우는 파라미터 정보를 표시해 준다.

if (request.method == 'GET') { fs.readFile('http-page.html', function(error, data) { response.end(data); }); } else if (request.method == 'POST') { …(중략)… }

**​**

3\. 서버 코드

아래는 전체 서버 코드이다. 요청이 GET일 경우 hello-page.html 파일을 읽어 응답하고, POST일 경우 전송된 데이터를 분석하여 브라우저에 출력하는 방식이다.

/** GET/POST */ var http = require('http'); var fs = require('fs'); function onRequest(request, response) { response.writeHead(200, { 'Content-Type' : 'text/html' }); if (request.method == 'GET') { fs.readFile('hello-page.html', function(error, data) { response.end(data); }); } else if (request.method == 'POST') { request.on('data', function(data) { param = data.toString(); console.log("param = " + JSON.stringify(param)); params = param.split('&'); console.log("params = " + params); response.writeHead(200, { 'Content-Type' : 'text/html' }); for ( var i = 0; i < params.length; i++) { var vals= params[i].split('='); response.write('<h3>' + vals[0] + ' = ' + vals[1] + '</h3>'); } response.write('<hr>'); response.write('<footer style="text-align: center;">'); response.write(' <a href="http://blog.naver.com/agapeuni">" target="_blank" class="con_link"></a>">">http://blog.naver.com/agapeuni'); response.write('</footer>'); response.end(); }); } } http.createServer(onRequest).listen(1337, function() { console.log('http://127.0.0.1:1337'); });

**​**

4\. HTML 파일

아래는 GET 요청 시 클라이언트에 표시될 HTML 파일이다. 

사용자가 이름(name)과 버전(version)을 입력하고 제출 버튼을 클릭하면 해당 데이터가 POST 방식으로 서버에 전송된다.

<!DOCTYPE html> <html> <head> <title>Node.js Example</title> </head> <body> <fieldset> <legend>Send Data</legend> <form method="post"> <table> <tr> <td><label>name</label></td> <td><input type="text" name="name" value="Node" /></td> </tr> <tr> <td><label>version</label></td> <td><input type="text" name="version" value="v0.12.2" /></td> </tr> </table> <input type="submit" /> </form> </fieldset> <hr> <footer style="text-align: center;"> <a href="http://blog.naver.com/agapeuni">http://blog.naver.com/agapeuni</a> </footer> </body> </html>
