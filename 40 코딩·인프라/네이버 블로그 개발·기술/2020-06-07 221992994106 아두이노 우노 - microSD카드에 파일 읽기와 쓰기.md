오픈소스 하드웨어에 대해 어설프게 알고 있는 사람은 아두이노 우노나 라즈베리 파이가 단순히 LED 정도 On/Off 하고 버튼 입력하고 모터 정도 움직이는 디바이스로 이해합니다. 제대로 배우고 활용하는 사람에겐 길거리에 떨어져 있는 돌이나 나무라 할지라도 응용하고 활용하여 하나의 작품으로 만들어 내는데 반해 설익은 지식으로 자신을 속이는 사람은 다이아몬드 원석을 보고도 그냥 돌멩이로 단정해 버리기 쉽습니다.

​

microSD 카드를 이용하여 값을 파일에 읽고 쓰는 실험을 하려고 합니다. 물리적인 세상에서 온도나 습도, 빛과 같은 정보를 센서로 감지하여 데이터를 파일에 주기적으로 저장하면 반영구적으로 데이터를 기록해 둘 수 있으며 나중에 다른 디바이스에서 활용할 수 있습니다.

![](https://postfiles.pstatic.net/MjAyMDA2MDhfMTc4/MDAxNTkxNjEwMTA2MzU0.yDaR5wWTfdYQA79dT3BjN6HZ-39415DxrMmU5D8zTGYg.KzHR76KfIC2qNNClT0UUBbsc8baAhemVv-fxwSPFAtkg.JPEG.agapeuni/SE-dfd7f059-641b-402a-bfb1-cc76ed08533a.jpg?type=w80_blur)

​

이두이노 이더넷 실드는 microSD 카드를 지원합니다. 주의할 점은 이더넷 모듈 핀이 10번을 사용하므로 SD 카드의 CS 핀은 4번 핀으로 이동되었습니다. SD 카드 기능을 사용할 때는 CS가 4번 핀으로 설정해야 합니다. 

![](https://postfiles.pstatic.net/MjAyMDA2MDhfMjk1/MDAxNTkxNjEwMTA3NTU3.lgg1LBL5xEzihUIdTL_hhwAQzRtxmHEZWd3eQhkezfgg.gCR6SC1Gb6cW1oyWHFAJzADX13f05lWcvnLUNDTgoa0g.JPEG.agapeuni/SE-9c20196c-bbd7-4d40-9cd2-52f2f2cc2a34.jpg?type=w80_blur)

​

Micro-SD 브레이크 아웃보드도 Micro-SD 카드를 지원합니다. CLK은 13핀, DO는 12핀, DI 11핀, CS는 10핀으로 연결합니다. 

10핀을 사용하는 경우에는 SD.begin() 함수를 사용하여 핀을 변경할 수 있습니다. microSD 카드와 이더넷 실드만 필요하여 점퍼선과 부품을 모두 클리어하였습니다. 이더넷 포트 위에 남는 Intel 스티커를 붙여두었습니다.

#include <SPI.h> #include <SD.h> const int CS = 4; // CS(4), MOSI(11), MISO(12), CLK(13) int val = 0; File myFile; String fileName1 = "Temp_01.txt"; String fileName2 = "Temp_02.txt"; void setup() { Serial.begin(9600); while (!Serial) { ; } Serial.print("Initializing SD card..."); if (!SD.begin(CS)) { Serial.println("initialization failed!"); return; } Serial.println("initialization done."); myFile = SD.open(fileName1, FILE_WRITE); if (myFile) { Serial.print("Writing..."); Serial.println(fileName1); for (int i = 0; i < 10; i++) { myFile.print(i); myFile.print(" X 2 = "); val = i * 2; myFile.println(val, DEC); } myFile.close(); Serial.println("Done."); } else { Serial.println("error opening file"); } myFile = SD.open(fileName2, FILE_WRITE); if (myFile) { Serial.print("Writing..."); Serial.println(fileName2); for (int i = 0; i < 10; i++) { myFile.print(i); myFile.print(" X 3 = "); val = i * 3; myFile.println(val, DEC); } myFile.close(); Serial.println("Done."); } else { Serial.println("error opening file"); } myFile = SD.open(fileName1); if (myFile) { Serial.print("Reading..."); Serial.println(fileName1); while (myFile.available()) { Serial.write(myFile.read()); } myFile.close(); } else { Serial.println("error opening file"); } myFile = SD.open(fileName2); if (myFile) { Serial.print("Reading..."); Serial.println(fileName2); while (myFile.available()) { Serial.write(myFile.read()); } myFile.close(); } else { Serial.println("error opening file"); } } void loop() { // None }

다음의 스케치는 SD 라이브러리를 사용하여 SD 카드에 대한 정보를 보여줍니다. 

SD 카드의 작동 여부를 확인하거나 SD 카드를 테스트하는 데 유용합니다. 아두이노 IDE에서 "**파일 - 예제 - SD - CardInfo"에** 위치합니다.

![](https://postfiles.pstatic.net/MjAyMDA2MDhfMTYw/MDAxNTkxNjEwMTEyMDk5.AS0XpIQjgyjgwML-2kOF34sABdoqUy9fiHuziSthcqsg.MsU8kwyCGYHAcOX81r6j2ZaCfDzWIVZCXtYUujI9l-kg.PNG.agapeuni/SE-6f8bbce6-93b7-4bcf-9ec0-cb75c8eeb2dc.png?type=w80_blur)

/* SD card test This example shows how use the utility libraries on which the' SD library is based in order to get info about your SD card. Very useful for testing a card when you're not sure whether its working or not. The circuit: SD card attached to SPI bus as follows: ** MOSI - pin 11 on Arduino Uno/Duemilanove/Diecimila ** MISO - pin 12 on Arduino Uno/Duemilanove/Diecimila ** CLK - pin 13 on Arduino Uno/Duemilanove/Diecimila ** CS - depends on your SD card shield or module. Pin 4 used here for consistency with other Arduino examples created 28 Mar 2011 by Limor Fried modified 9 Apr 2012 by Tom Igoe */ // include the SD library: #include <SPI.h> #include <SD.h> // set up variables using the SD utility library functions: Sd2Card card; SdVolume volume; SdFile root; // change this to match your SD shield or module; // Arduino Ethernet shield: pin 4 // Adafruit SD shields and modules: pin 10 // Sparkfun SD shield: pin 8 // MKRZero SD: SDCARD_SS_PIN const int chipSelect = 4; void setup() { // Open serial communications and wait for port to open: Serial.begin(9600); while (!Serial) { ; // wait for serial port to connect. Needed for native USB port only } Serial.print("\nInitializing SD card..."); // we'll use the initialization code from the utility libraries // since we're just testing if the card is working! if (!card.init(SPI_HALF_SPEED, chipSelect)) { Serial.println("initialization failed. Things to check:"); Serial.println("* is a card inserted?"); Serial.println("* is your wiring correct?"); Serial.println("* did you change the chipSelect pin to match your shield or module?"); while (1); } else { Serial.println("Wiring is correct and a card is present."); } // print the type of card Serial.println(); Serial.print("Card type: "); switch (card.type()) { case SD_CARD_TYPE_SD1: Serial.println("SD1"); break; case SD_CARD_TYPE_SD2: Serial.println("SD2"); break; case SD_CARD_TYPE_SDHC: Serial.println("SDHC"); break; default: Serial.println("Unknown"); } // Now we will try to open the 'volume'/'partition' - it should be FAT16 or FAT32 if (!volume.init(card)) { Serial.println("Could not find FAT16/FAT32 partition.\nMake sure you've formatted the card"); while (1); } Serial.print("Clusters: "); Serial.println(volume.clusterCount()); Serial.print("Blocks x Cluster: "); Serial.println(volume.blocksPerCluster()); Serial.print("Total Blocks: "); Serial.println(volume.blocksPerCluster() * volume.clusterCount()); Serial.println(); // print the type and size of the first FAT-type volume uint32_t volumesize; Serial.print("Volume type is: FAT"); Serial.println(volume.fatType(), DEC); volumesize = volume.blocksPerCluster(); // clusters are collections of blocks volumesize *= volume.clusterCount(); // we'll have a lot of clusters volumesize /= 2; // SD card blocks are always 512 bytes (2 blocks are 1KB) Serial.print("Volume size (Kb): "); Serial.println(volumesize); Serial.print("Volume size (Mb): "); volumesize /= 1024; Serial.println(volumesize); Serial.print("Volume size (Gb): "); Serial.println((float)volumesize / 1024.0); Serial.println("\nFiles found on the card (name, date and size in bytes): "); root.openRoot(volume); // list all files in the card with date and size root.ls(LS_R | LS_DATE | LS_SIZE); } void loop(void) { }
