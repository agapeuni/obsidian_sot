PL/SQL(Procedural Language/SQL)은 Oracle 데이터베이스에서 SQL에 절차적 로직을 결합하여 더욱 유연하고 강력한 프로그래밍을 가능하게 하는 언어이다. 이 언어의 기본 단위는 **블럭 구조** 이며, 각 블럭은 실행 코드뿐 아니라 변수 선언문도 함께 포함하고 있다.

**​**

**​**

**1\. 스칼라 변수의 종류**

PL/SQL에서 자주 사용되는 스칼라 변수는 다음과 같다.

  * **VARCHAR2** : 가변 길이 문자 스트링

  * **CHAR** : 고정 길이 문자 스트링

  * **NUMBER** : 고정 또는 부동 소수점 숫자

  * **DATE** : 날짜와 시간

  * **BOOLEAN** : TRUE/FALSE 값을 저장

**​**

**​**

**2\. 변수 명명 규칙**

변수명을 정의할 때에는 다음과 같은 규칙을 따른다:

  1. 문자, $, _, #로 구성된다.

  2. 문자로 시작해야 한다.

  3. 최대 30자까지 가능하다.

  4. 대소문자를 구분하지 않는다.

  5. 식별 가능하게 작성한다 (예: empyearsal → emp_year_sal).

  6. 예약어와 혼동을 피하기 위해 예약어는 대문자로 사용하는 경우가 많다.

**​**

**​**

**3\. 변수 선언 및 값 할당**

student_id VARCHAR(16); student_name VARCHAR2(10000); student_id := 'kangyw'; student_name := 'kangyw'; 

​

**​**

**4\. CHAR vs VARCHAR2**

**CHAR** 는 고정 길이 문자열을 저장하며, 남는 공간은 공백으로 채운다. 이 공백 또한 비교 시 포함되므로 **문자열 비교 시 주의가 필요** 하다. 반면 **VARCHAR2** 는 필요한 만큼만 메모리를 사용하며, 나머지는 차지하지 않는다.

**예제 1: CHAR와 VARCHAR2 비교**

DECLARE student_id CHAR(20); student_name VARCHAR(20); BEGIN student_id := 'kangyw'; student_name := 'kangyw'; IF student_id = student_name THEN DBMS_OUTPUT.PUT_LINE('Same'); ELSE DBMS_OUTPUT.PUT_LINE('Not Same'); END IF; END; / 

위 예제에서는 student_id 변수에 공백이 포함되기 때문에 Not Same이 출력된다.

​

​

**예제 2: RTRIM으로 공백 제거**

IF RTRIM(student_id) = student_name THEN DBMS_OUTPUT.PUT_LINE('Same'); END IF; 

RTRIM 함수로 오른쪽 공백을 제거하면 문자열 비교가 정확하게 이루어지며 결과는 Same이 된다.

**​**

**​**

**5\. NUMBER 데이터형**

NUMBER는 정밀도(전체 자릿수)와 스케일(소수점 위치)를 함께 지정하여 숫자를 정의한다.

  * 예: NUMBER(4,2) → 총 4자리, 소수점 아래 2자리 (예: 73.13)

  * 예: NUMBER(3) → 정수 3자리, 자동 반올림 발생

  * 예: NUMBER(5,-2) → 100단위로 반올림, (예: 10345 → 10300)

**​**

**예제 3: NUMBER 사용**

DECLARE number1 NUMBER(4,2); number2 NUMBER(3); number3 NUMBER(5,-2); BEGIN number1 := 73.127; number2 := 345.1; number3 := 10345; DBMS_OUTPUT.PUT_LINE(number1); -- 73.13 DBMS_OUTPUT.PUT_LINE(number2); -- 345 DBMS_OUTPUT.PUT_LINE(number3); -- 10300 END; / 

​

**​**

**6\. DATE 데이터형**

DATE는 날짜뿐 아니라 시간까지 포함하여 저장된다. 시간을 지정하지 않으면 기본적으로 자정(00:00:00)으로 설정된다. 날짜만 비교하고자 할 경우에는 TRUNC() 함수를 사용한다.

  * 범위: BC 471년 1월 1일 ~ AD 4712년 12월 31일

**​**

**예제 4: DATE 사용**

DECLARE birthday DATE; BEGIN birthday := TO_DATE('28-12-1982', 'DD-MM-YYYY'); DBMS_OUTPUT.PUT_LINE(birthday); END; / 

PL/SQL에서 변수의 선언과 데이터형의 선택은 코드의 정확성과 성능에 직접적인 영향을 미친다. 특히 CHAR와 VARCHAR2, NUMBER의 정밀도와 스케일 설정 등은 실무에서 자주 부딪히는 이슈이므로 반드시 정확한 이해가 필요하다.
