5\. 코드 작성

이제 원격에 있는 MariaDB와 연계하기 위한 준비는 마쳤다. Python 코드에서 pymysql 모듈을 사용하여 동작하는 코드를 작성해 본다.

pymysql 모듈은 MariaDB와 MySQL 데이터베이스을 처리할 수 있는 Python 라이브러리이다.

pymysql 모듈은 DB-API 2.0 명세를 준수하는 SQL 인터페이스를 제공한다. (PEP 249)

​

**1) Connection 생성**

conn = pymysql.Connection(host="192.168.0.3", port=3306, user="root", passwd="1234", db="example")

**2) Cursor 생성**

cursor = conn.cursor(pymysql.cursors.DictCursor)

**3) Init 스크립트**

cursor.execute("DELETE FROM items") cursor.execute("ALTER TABLE items AUTO_INCREMENT = 1")

**4) 데이터 추가 (Insert)** ​

sql = "INSERT INTO items (name, qty, price) VALUES (%s, %s, %s)" item = ("item1", 10, 2.5) cursor.execute(sql, item) sql = "INSERT INTO items (name, qty, price) VALUES (%s, %s, %s)" items = [("item2", 4, 3.1), ("item3", 3, 2.5), ("item4", 6, 0.5)] cursor.executemany(sql, items)

**​**

**5) 데이터 조회 (Select)**

cursor.execute("SELECT * FROM items") row = cursor.fetchone() print(row) cursor.execute("SELECT * FROM items") rows = cursor.fetchall() for row in rows: print(row) print()

**6) 데이터 수정 (Update)**

sql = "UPDATE items SET name = %s WHERE id = %s" items = [("item11", 1), ("item12", 2)] cursor.executemany(sql, items)

**7) 데이터 삭제 (Delete)**

sql = "DELETE FROM items WHERE price < %s" cursor.execute(sql, (1,))

**8) Connection 닫기**

conn.close()

​

6\. CRUD 코드

다음은 MariaDB 데이터베이스에 items 이름의 테이블을 생성하고 기본적인 CRUD를 수행하는 코드이다.

소스코드에 Comment를 달아 두었다. 실행결과와 함께 확인해 보면 쉽게 알 수 있다.

​

**소스코드**

import pymysql # Connection 생성 conn = pymysql.Connection(host="192.168.0.3", port=3306, user="root", passwd="1234", db="example") # Cursor 생성 cursor = conn.cursor(pymysql.cursors.DictCursor) # 기존의 데이터를 삭제하고 AUTO_INCREMENT를 1로 설정 cursor.execute("DELETE FROM items") cursor.execute("ALTER TABLE items AUTO_INCREMENT = 1") # 단일 데이터 추가 sql = "INSERT INTO items (name, qty, price) VALUES (%s, %s, %s)" item = ("item1", 10, 2.5) cursor.execute(sql, item) print(cursor.rowcount, "record inserted, ID:", cursor.lastrowid) print() # 멀티 데이터 추가 sql = "INSERT INTO items (name, qty, price) VALUES (%s, %s, %s)" items = [("item2", 4, 3.1), ("item3", 3, 2.5), ("item4", 6, 0.5)] cursor.executemany(sql, items) print("insert count = ", cursor.rowcount) print() # 데이터 조회 cursor.execute("SELECT * FROM items") rows = cursor.fetchall() for row in rows: print(row) print() # 데이터 수정 sql = "UPDATE items SET name = %s WHERE id = %s" items = [("item11", 1), ("item12", 2)] cursor.executemany(sql, items) print("update count = ", cursor.rowcount) print() # 데이터 조회 (1건) cursor.execute("SELECT * FROM items") row = cursor.fetchone() print(row) # 데이터 조회 rows = cursor.fetchall() for row in rows: print(row) print() # 데이터 삭제 sql = "DELETE FROM items WHERE price < %s" cursor.execute(sql, (1,)) print("delete count = ", cursor.rowcount) print() # 데이터 조회 cursor.execute("SELECT * FROM items") rows = cursor.fetchall() for row in rows: print(row) print() # 데이터 조회 with 페이징 cursor.execute("SELECT * FROM items LIMIT 1, 2") rows = cursor.fetchall() for row in rows: print(row) print() # 변경사항 저장 conn.commit() # Connection 닫기 conn.close()
