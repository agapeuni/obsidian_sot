**1\. XML 문서**

XSLT (eXtensible Stylesheet Language Transformations)를 사용하여 XML 데이터를 정렬하는 것은 간단하고 효과적이다. XSLT는 XML 문서를 변환하는 데 사용되는 스타일 시트 언어이다. 

​

XSLT 파일을 이용하여 XML 데이터를 정렬하는 방법은 다음과 같습니다.

​

아래의 XML 파일은 CD 목록을 관리하고 있다. 

**파일 : cd_list.xml**

<?xml version="1.0" encoding="ISO-8859-1"?> <catalog> <cd> <title>Hide your heart</title> <artist>Bonnie Tyler</artist> <country>UK</country> <company>CBS Records</company> <price>9.90</price> <year>1988</year> </cd> <cd> <title>Greatest Hits</title> <artist>Dolly Parton</artist> <country>USA</country> <company>RCA</company> <price>9.90</price> <year>1982</year> </cd> <cd> <title>Still got the blues</title> <artist>Gary Moore</artist> <country>UK</country> <company>Virgin records</company> <price>10.20</price> <year>1990</year> </cd> <cd> <title>Maggie May</title> <artist>Rod Stewart</artist> <country>UK</country> <company>Pickwick</company> <price>8.50</price> <year>1990</year> </cd> <cd> <title>When a man loves a woman</title> <artist>Percy Sledge</artist> <country>USA</country> <company>Atlantic</company> <price>8.70</price> <year>1987</year> </cd> <cd> <title>For the good times</title> <artist>Kenny Rogers</artist> <country>UK</country> <company>Mucik Master</company> <price>8.70</price> <year>1995</year> </cd> <cd> <title>Tupelo Honey</title> <artist>Van Morrison</artist> <country>UK</country> <company>Polydor</company> <price>8.20</price> <year>1971</year> </cd> <cd> <title>Pavarotti Gala Concert</title> <artist>Luciano Pavarotti</artist> <country>UK</country> <company>DECCA</company> <price>9.90</price> <year>1991</year> </cd> <cd> <title>Picture book</title> <artist>Simply Red</artist> <country>EU</country> <company>Elektra</company> <price>7.20</price> <year>1985</year> </cd> <cd> <title>Unchain my heart</title> <artist>Joe Cocker</artist> <country>USA</country> <company>EMI</company> <price>8.20</price> <year>1987</year> </cd> </catalog>

​

**2\. XSLT 파일**

이제 XSLT 파일을 작성해 본다. XSLT 파일은 XML 문서를 변환시킬 때 사용하는 기술이다. 보통 XML 문서를 HTML 문서로 변환할 때 자주 사용한다. XML 파일에 담겨 있는 각각의 CD를 반복하면서 Title과 Artist를 목록으로 보여준다.

​

**<****xsl:sort****select** =_"artist"_**/ >**로 Artist로 정렬해서 표시한다. 기본값은 ascending(오름차순)이다. 내림차순으로 정렬하려면 order 속성에 descending을 작성한다. **<****xsl:sort****select** =_"artist"_**order** =_"descending"_**/ >** 로 하면 역순으로 정렬된다. 

​

이 XSLT 파일은 <catalog> 요소 안에 있는 <cd> 요소들을 <artist> 기준으로 오름차순으로 정렬한다.

**파일: cd_list.xsl**

<?xml version="1.0" encoding="ISO-8859-1"?> <xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform"> <xsl:template match="/"> <html> <body> <h2>My CD List</h2> <table border="1"> <tr bgcolor="#9ACDA2"> <th>Title</th> <th>Artist</th> <th>Company</th> <th>Price</th> </tr> <xsl:for-each select="catalog/cd"> <xsl:sort select="artist" /> <tr> <td> <xsl:value-of select="title" /> </td> <td> <xsl:value-of select="artist" /> </td> <td> <xsl:value-of select="company" /> </td> <td> <xsl:value-of select="price" /> </td> </tr> </xsl:for-each> </table> </body> </html> </xsl:template> </xsl:stylesheet>

​

XSLT 파일을 작성하고 XML 파일 상단에 <?xml-stylesheet type="text/xsl" href="cd_list.xsl"?>를 추가한다.

<?xml version="1.0" encoding="ISO-8859-1"?> <?xml-stylesheet type="text/xsl" href="cd_list.xsl"?> <catalog> <cd> <title>Hide your heart</title> <artist>Bonnie Tyler</artist> ... (생략) ...
