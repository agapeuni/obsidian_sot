1\. Java 설치

아래의 주소에서 설치파일을 다운로드하여 지정한 경로에 설치를 한다.

다운로드: <https://www.oracle.com/kr/java/technologies/downloads/>

설치파일: jdk-19_windows-x64_bin.msi

설치경로: D:\app\jdk-19

![](https://postfiles.pstatic.net/MjAyMzA1MTVfMjg2/MDAxNjg0MTA2NzU4MTIz.4vCQ4B6j2gMSOwZfy9eK3weft1xLVtKa2A9BAda7p50g.IT2RvNixf99cY_IJWxkW3n5mTzjpFREfGMKsCb3tFdcg.PNG.agapeuni/img.png?type=w80_blur)

아래와 같이 환경설정을 하고서 정상적으로 작동하는지 확인한다.

CLASSPATH = .;

JAVA_HOME = D:\app\jdk-19

PATH = %JAVA_HOME%\bin;

![](https://postfiles.pstatic.net/MjAyMzA1MTVfNTEg/MDAxNjg0MTA2NzY0NDUz.a889yKTr4Pw77mSMWCKdt_V_FZHqq_ggTPzTviTva90g.N0t_cQIRes5LHoIH6JuvXXhPqahtPjkSELMcmTcmn9Ag.PNG.agapeuni/img.png?type=w80_blur)
