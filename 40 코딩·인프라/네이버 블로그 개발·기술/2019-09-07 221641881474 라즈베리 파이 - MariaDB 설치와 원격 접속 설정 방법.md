# 2019-09-07 221641881474 라즈베리 파이 - MariaDB 설치와 원격 접속 설정 방법

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTgz/MDAxNzU4NDQzNTM3ODg3.zuwv60uHs92zbwG6N7tE7GMdJe9EQ_Xu82IBz5ZQb7Qg.kRJ95BezKEdok6fbiGsFEnexIolxrv49wSzvTJXUhwsg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(8\).png?type=w80_blur)

​

MariaDB는 세계에서 가장 널리 사용되는 데이터베이스 중 하나이며 MySQL이 오라클에 인수가 되면서 MySQL의 개발자에 의해 오픈소스로 만들어졌습니다. MySQL과 거의 완벽하게 호환되고 있어서 그냥 단순히 이름과 라이센스 정도만 다르다고 생각해도 됩니다.

​

아래의 명령어로 MySQL이 잘 설치되었는데 아래와 같이 메세지가 표시되네요. 

**$ sudo apt-get install mysql-server**

![](https://postfiles.pstatic.net/MjAxOTA5MDdfMjIg/MDAxNTY3ODQ2MTc4MzMz.0InyoU9jpVjep-8HJon2iRKCqqKxRhrvT83Ux9vtTbkg.j1TqR9tC6WBG7jI6iVflC3iPS4Kp070oWswPdoB11I0g.PNG.agapeuni/20190907_152831.png?type=w80_blur)

​

다른 방법으로 MySQL을 설치할 수도 있지만 바로 MariaDB로 설치합니다. 그럼 파일럿 프로젝트를 위해 MariaDB를 설치합니다. 

**$ sudo apt-get install mariadb-server**

![](https://postfiles.pstatic.net/MjAxOTA5MDdfMTcz/MDAxNTY3ODQ2MTc4ODk1.2KxYS3teRfnuGUiFlc6zjylNDJ8tsz6Pn94ViPFazvsg.G9dVH_7wB7b1BWFbRfLr4N_MGoUv5RYzpBl6KTdIBXAg.PNG.agapeuni/20190907_152909.png?type=w80_blur)

관련 패키지가 상당히 많으니 잠시 티타임을 갖는 것도 괜찮습니다. 

![](https://postfiles.pstatic.net/MjAxOTA5MDdfMjc4/MDAxNTY3ODQ2MTc5NDQw.rOFwGVvM5i7fStGqw9T-VJnWFYkhLChCpXVtRcK45RIg.mH9a58P-Unb9mbTvwUcA27babKLRL7VX1zSkiclmsScg.PNG.agapeuni/20190907_154121.png?type=w80_blur)

​

설치를 마치고 아래의 명령어로 MariaDB에 접속해 봅니다. 

**$ sudo mysql -u root**

​

**mysql -u root** 를 입력하면 아래와 같은 메세지가 표시됩니다.

ERROR 1698 (28000): Access denied for user 'root'@'localhost'

![](https://postfiles.pstatic.net/MjAxOTA5MDdfNyAg/MDAxNTY3ODQ2OTEzMzI3.RJ7ALZkU4AdkqAA6AKjhf39VYn4Wf3-rR37RhzpNpz8g.MkS4tQkoAPmm0EPkSlZJXOT5-nQuZG1CanNPaEk17Tgg.PNG.agapeuni/20190907_180127.png?type=w80_blur)

​

먼저 mysql 데이터베이스로 전환합니다.

**> use mysql**

​

사용자 테이블 정보를 확인해보고

**> select user, host, password from user;**

​

root 사용자의 암호를 1234로 변경합니다.

**> update user set password=PASSWORD('1234') where user='root'****;**

​

그리고 'root' 계정의 레코드를 추가로 생성합니다.

**> grant all privileges on *.* to 'root'@'localhost' identified by '1234';**

**> grant all privileges on *.* to 'root'@'127.0.0.1' identified by '1234';**

**> grant all privileges on *.* to 'root'@'%' identified by '1234';**

​

변경사항을 적용하기 위해 다음을 실행합니다.

**> flush privileges;**

![](https://postfiles.pstatic.net/MjAyMDExMjVfNDEg/MDAxNjA2MjM4MDM4NDU5.eXQXGb6fhXuIRuEFxYfYwQwiddJKocR9uLx0yc8n_sMg.c-F2wRsEWz99Kzm8srh75GWiYHZVxT8xRGzBt322-_Eg.PNG.agapeuni/20201125_021350.png?type=w80_blur)

​

이제 다음의 명령어로 접속이 되는지 시도해 봅니다.

**$ mysql -u root -p**

​

그리고 데이터가 잘 생성되어 있는지 user 테이블을 조회해 봅니다.

**> select user, host, password from user;**

![](https://postfiles.pstatic.net/MjAxOTA5MDdfMTQ1/MDAxNTY3ODQ3OTg4OTUw.vgGsk3Dk6IyC1ut_Eg_DwyL2swDsWoAiW9WcUfzZs-og.ylgzXzQ0ryvbAIhrSH5rx_tI0nvoAxZBIQ6VijUyxe8g.PNG.agapeuni/20190907_181921.png?type=w80_blur)

​

원격에서도 연결이 가능하도록 설정을 진행합니다. 먼저 my.cnf 파일을 열고 파일 아래에 'bind-address = 0.0.0.0'를 입력합니다.

**$ sudo nano /etc/mysql/my.cnf**

**$ sudo systemctl stop mariadb**

**$ sudo systemctl start mariadb**

**$ sudo systemctl restart mariadb**
