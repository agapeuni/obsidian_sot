​

​

Oracle Database는 다양한 내장 함수를 제공하여 프로그래머가 보다 효율적이고 간결하게 데이터를 처리할 수 있도록 지원한다. 이러한 내장 함수는 문자, 숫자, 날짜, 변환, 집계 등 용도에 따라 구분되며, SQL 쿼리 내에서 자유롭게 활용할 수 있다. 본 포스트에서는 Oracle 내장 함수의 개요와 주요 분류에 대해 정리한다.

**​**

**​**

**1\. SQL 함수 개요**

Oracle에서 제공하는 SQL 함수는 사전에 정의된 기능을 수행하며, 일반적인 SQL 문과 함께 사용할 수 있다. PL/SQL로 작성된 사용자 정의 함수와 혼동하지 않도록 유의해야 한다.

​

SQL 함수는 일반적으로 입력 인수를 받아 특정 계산이나 변환을 수행하고 결과를 반환한다. 입력 인수가 NULL인 경우 대부분의 함수는 NULL을 반환하지만, 일부 함수(CONCAT, NVL, REPLACE, REGEXP_REPLACE)는 예외적인 동작을 보인다. 테스트 목적의 결과 확인은 DUAL 테이블을 통해 수행할 수 있다.

**​**

**​**

**2\. 단일 행 함수**

단일 행 함수는 테이블의 각 행에 대해 하나의 결과값을 반환한다. SELECT 절, WHERE 절, HAVING 절, START WITH 절 등에서 사용 가능하며 다음과 같은 범주로 나뉜다.

​

**숫자 함수**

숫자를 입력으로 받아 계산된 숫자 값을 반환하는 함수이다.

  * 주요 함수: ABS, CEIL, FLOOR, MOD, ROUND, TRUNC, SIN, COS, LOG, POWER, SQRT 등

**​**

**문자 반환 함수**

문자열을 조작하거나 반환하는 함수로, 반환 값은 일반적으로 VARCHAR2 또는 NVARCHAR2 타입이다.

  * 주요 함수: CONCAT, LOWER, UPPER, SUBSTR, TRIM, REPLACE, REGEXP_REPLACE, LPAD, RPAD 등

**​**

**숫자 반환 문자 함수**

문자 데이터를 분석하거나 길이, 위치 등을 숫자로 반환한다.

  * 주요 함수: ASCII, INSTR, LENGTH, REGEXP_INSTR

**​**

**날짜/시간 함수**

날짜나 시간 값을 기준으로 계산하거나 변환을 수행한다.

  * 주요 함수: SYSDATE, CURRENT_DATE, LAST_DAY, ADD_MONTHS, ROUND(date), TO_DATE, TO_CHAR(datetime) 등

**​**

**NLS 문자 함수**

국제 문자 집합 관련 정보를 반환한다.

  * 주요 함수: NLS_CHARSET_ID, NLS_CHARSET_NAME, NLS_CHARSET_DECL_LEN

**​**

**​**

**3\. 변환 함수**

데이터를 한 유형에서 다른 유형으로 변환하는 함수이다.

  * 주요 함수: TO_NUMBER, TO_DATE, TO_CHAR, CAST, CONVERT, TO_TIMESTAMP, TO_CLOB, TO_NCHAR 등

**​**

**​**

**4\. 집합 관련 함수**

  * **일반 비교 함수** : GREATEST, LEAST

  * **NULL 관련 함수** : NVL, NVL2, NULLIF, COALESCE, LNNVL

  * **인코딩/디코딩 함수** : DECODE, DUMP, VSIZE, ORA_HASH

  * **환경 및 식별자 함수** : USER, UID, USERENV, SYS_CONTEXT, SYS_GUID

**​**

**​**

**5\. 집계 함수**

집계 함수는 여러 행을 그룹으로 묶고 하나의 결과값을 반환한다. GROUP BY와 함께 자주 사용되며 HAVING, ORDER BY 절에서도 사용 가능하다. KEEP 절을 활용하여 특정 조건에 맞는 행 집합에서의 최솟값/최댓값 등을 집계할 수 있다.

  * 주요 함수: COUNT, SUM, AVG, MAX, MIN, MEDIAN, VARIANCE, STDDEV, RANK, DENSE_RANK, PERCENTILE_CONT, COLLECT

​

**​**

**6\. 분석 함수**

분석 함수는 집계 함수와 유사하나, 집계된 결과값을 행별로 반환한다는 점에서 차별화된다. 윈도우 함수와 유사한 개념으로, 순위, 누적값, 이동 평균 등을 계산하는 데 사용된다.

  * 주요 함수: ROW_NUMBER, RANK, LAG, LEAD, FIRST_VALUE, LAST_VALUE, NTILE, CUME_DIST, PERCENT_RANK, AVG, SUM, STDDEV

**​**

**​**

**7\. 기타 특수 함수**

**LOB 함수**

  * 대용량 객체(LOB) 처리: EMPTY_BLOB, EMPTY_CLOB, BFILENAME

**​**

**컬렉션 함수**

  * 중첩 테이블 처리: CARDINALITY, COLLECT, SET, POWERMULTISET

**​**

**계층 함수**

  * 계층적 경로 처리: SYS_CONNECT_BY_PATH

**​**

**데이터 마이닝 함수**

  * 예측 및 분류 기능 제공: PREDICTION, FEATURE_ID, CLUSTER_ID 등

**​**

**XML 함수**

  * XML 데이터 처리: EXTRACT, EXISTSNODE, XMLAGG, XMLSERIALIZE 등

**​**

**​**

Oracle 내장 함수는 데이터 처리의 효율성과 정확성을 높이는 핵심 도구이다. 각 함수의 역할과 사용 방법을 정확히 이해하고 적재적소에 활용하는 것이 숙련된 Oracle 개발자로 가는 길이다. 본 정리를 참고하여 실무 또는 학습에 도움이 되기를 바란다.
