1\. 작업표시줄 (Win + No)

윈도우 작업표시줄에는 자주 사용하는 프로그램을 10개 고정해 둔다. "Win" 키와 함께 숫자키를 입력하면 작업표시줄에 있는 프로그램을 바로 실행할 수 있다. 윈도우와 돋보기는 지나서 맨 왼쪽에 있는 아이콘부터 1번으로 시작한다. 그렇게 1번부터 차례대로 이어지다가 10번째에 위치한 이클립스는 Win키와 함께 "0"을 입력하면 실행한다.

​

아래의 그림을 참고하면 크롬을 실행하려면 Win + 2를 입력하면 되고 VS Code를 실행하려면 Win + 8을 입력하면 된다. 프로그램이 실행되어 있을 때 다시 입력하면 '비활성/활성'으로 토글된다. 새창으로 프로그램을 실행하고 싶을 때는 Shift 키를 같이 눌러주면 된다.

![](https://postfiles.pstatic.net/MjAyMzA0MTNfOTUg/MDAxNjgxMzk0NDA0NjE4.Y8kkvYsfiIlIuetqZIwhIMOmQLuqLpHi1jTob3Jw9jMg.6-HgxAofmwSg4YSynEupVaZfGyM_fFhlLG9UrSzw-sYg.PNG.agapeuni/img.png?type=w80_blur)

​

2\. 브라우저 탭 (Ctrl + No)

인터넷에서 자료를 검색하다 보면 브라우저에 여러 탭을 열리게 된다. 자료를 빠르게 참고하려고 할 때는 마우스 보다 키보드가 훨씬 빠르고 편리하다. Ctrl + Tab 키와 Ctrl + Shift + Tab 키로 탭 앞뒤로 이동할 수 있고 Ctrl 키와 숫자키를 입력하면 해당 탭으로 바로 이동한다. 브라우저 탭을 이동하는 단축키는 Ctrl + 1 ~ 9이다.참고로 Ctrl + 0은 화면의 배율을 100%로 맞추는 단축키이다. 아래의 그림을 예를 들면 Ctrl + 4를 입력하면 바로 4번째에 위치한 Papago 탭이 선택된다.

![](https://postfiles.pstatic.net/MjAyMzA0MTNfODYg/MDAxNjgxMzk0NDE4NDcw.mEsot38TkEc_77XTnJ-GPXyYV65N7G1tAJPzPxRCweog.D4uHWinHcwARnlCYU7ZP9yIlqMb75tCZ-r9XVE-wTqwg.PNG.agapeuni/img.png?type=w80_blur)

5\. 관리창 (Win + X)

윈도우 시작 버튼에서 마우스 우클릭하면 프로그램 실행메뉴가 열린다.

Win 키와 X를 누르면 동일한 기능을 수행한다.

![](https://postfiles.pstatic.net/MjAyMzA0MTNfOTgg/MDAxNjgxMzk0NDc4MDA4.QEZZ1YpJ2u5WJI10w8PEC07axpjAvO-Nj6pDe1MDp6sg.hEopDA5DRy0qy9u2jPHlOhA5KzCwtMmslqObpLTnhqkg.PNG.agapeuni/img.png?type=w80_blur)

개인적으로 "장치 관리자, 디스크 관리, 컴퓨터 관리, 명령 프롬프트(관리자)를 자주 사용하는데 메뉴명 옆에 보이는 영문을 입력하면 바로 실행한다. 디스크 관리를 실행하려면 Win 키와 X를 누르고 프로그램 실행메뉴가 열리면 바로 K를 누르면 된다.

![](https://postfiles.pstatic.net/MjAyMzA0MTNfOTMg/MDAxNjgxMzk0NDgxNzQ2.kuwdl3HopZ-xOzA55AQZdBxCmf_GFNHDN9I4vna2MqIg.c1Lwg7X0g7eZ2p8Pve-LkeuD2TLPnqw43qSpCL2dl1Eg.PNG.agapeuni/img.png?type=w80_blur)

6\. 이모지, 카오모지, 특수문자 입력 (Win + .)

윈도우에서 특수문자를 입력할 때 한글 자음을 누르고 바로 한자 키를 입력한다.

예를 들면, ㅁ을 입력하고 한자 키를 누르면 아래와 같은 선택 창이 표시된다.
