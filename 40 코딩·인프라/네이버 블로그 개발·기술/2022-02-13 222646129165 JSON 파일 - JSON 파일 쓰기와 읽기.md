JSON(JavaScript Object Notation)은 사람이 읽고 쓰기에 좋은 경량의 데이터 직렬화 형식이다. JSON은 언어에 독립적이며 거의 모든 프로그래밍 언어에서 지원하고 있어 JSON을 읽고 쓰기에 편리하다. 

​

JSON 객체의 이름 / 값 쌍에 있는 이름은 항상 문자열이다. 어떤 유형의 날짜 형식도 지원하지 않으며 안타깝게도 JSON은 주석을 지원하지 않는다.

​

JSON에서 파일을 Open 할때의 방식은 Text 파일을 Open할때와 동일하다.

r : 읽기모드 (기본값) - 파일이 없으면 오류가 발생 w : 쓰기모드 - 파일이 없으면 생성 a : 추가모드 - 파일이 없으면 생성 x : 만들기모드 - 파일을 만들고 파일이 있으면 오류를 반환 t : 텍스트 모드 (Text) b : 바이너리 모드 (Binary)

​

JSON 파일 쓰기

JSON 파일을 생성하기 위해 먼저 파일을 쓰기모드로 open하고 json.dump() 함수 사용하여 파일을 작성한다.

​

소스코드 : json_write.py

import json import os # JSON Data json_data = {} json_data['items'] = [] # items 생성 json_data['items'].append({ "Code": "A1", "Name": "item1", "Date": "2020-09-19" }) json_data['items'].append({ "Code": "A2", "Name": "item2", "Date": "2020-09-19", "Hobby" : ["Tennis", "Cook"] }) json_data['items'].append({ "Code": "B1", "Name": "item1", "Date": "2020-09-20", "Memo": {"Hobby1": "Music", "Hobby2": "Movie"} }) json_data['items'].append({ "Code": "B2", "Name": "item1", "Date": "2020-09-20" }) # 폴더가 없으면 폴더생성 if not os.path.exists("data"): os.mkdir("data") # 파일쓰기 모드로 열기 with open("data/sample.json", "w") as f: json.dump(json_data, f, indent=4)

실행결과

{ "items": [ { "Code": "A1", "Name": "item1", "Date": "2020-09-19" }, { "Code": "A2", "Name": "item2", "Date": "2020-09-19", "Hobby": [ "Tennis", "Cook" ] }, { "Code": "B1", "Name": "item1", "Date": "2020-09-20", "Memo": { "Hobby1": "Music", "Hobby2": "Movie" } }, { "Code": "B2", "Name": "item1", "Date": "2020-09-20" } ] } ​

​

JSON 파일 읽기

이번에는 만들어진 JSON 파일을 읽어오는 코드를 작성해 본다.

JSON을 읽어 load 함수를 사용하여 파이썬에 담아둔다. json.load() 함수 사용한다.

​

소스코드 : json_read.py

import json import os file_path = "ex/file/sample.json" # 파일이 존재하면 파일읽기 if os.path.exists(file_path): # 파일읽기 모드로 열기 with open(file_path, "r") as f: json_data = json.load(f) print(json_data['items'][0]['Code']) print(json_data['items'][1]['Name']) print(json_data['items'][2]['Date']) print() print(json_data['items'][3])

실행결과

A1 item2 2020-09-20 {'Code': 'B2', 'Name': 'item1', 'Date': '2020-09-20'}

​

JSON에서는 다음과 같이 파이썬 데이터 구조를 지원한다.

파이썬 |  JSON  
---|---  
dict |  오브젝트(object)  
list, tuple |  배열(array)  
str |  문자열(string)  
int, float, int와 float |  숫자(number)  
True |  true  
False |  false  
None |  null
