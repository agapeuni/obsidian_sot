​

다음의 명령어로 SQLite3을 설치합니다.

**$ sudo apt-get install sqlite3**

​

설치된 버전은 3.27.2입니다.

**$********sqlite3 -version**

![](https://postfiles.pstatic.net/MjAyMDExMjBfMTU5/MDAxNjA1ODAyNjg5MjMy.jXE5KE-ImMBytsg9JthHAW4kD6zMr4x-P4Qdh1z96yMg.yoPnUx3gNDQhAC0QwBuUN8V9KxO-uINU4Z6Nj1sRmqwg.PNG.agapeuni/image.png?type=w80_blur)

**​**

sqlite3를 실행하면서 DB 명을 입력하면 없으면 새로 만들고 존재하면 로드한다.

**$ sqlite3 example.db**

​

SQLite 쉘에서 create 문을 사용하여 테이블 tb_temp를 만들고 4건의 데이터를 추가합니다. 

**> create table tb_temp (id integer primary key, value text);**

**> insert into tb_temp (value) values ('A');**

**> insert into tb_temp (value) values ('B');**

**> insert into tb_temp (value) values ('C');**

**> insert into tb_temp (value) values ('D');**

​

잘 입력되었는지도 확인합니다.

**> select * from tb_temp;**

**> select last_insert_rowid();**

![](https://postfiles.pstatic.net/MjAyMDExMjBfMjk0/MDAxNjA1ODAzMTE5ODAx.S4zboGto_IgMaSGC7qoBDB7uUCSpCC9f4I15SGRMLFQg.5zyb0VDJ1dPrqAdfYPboXisp99VLri_2pHun9OZmM0gg.PNG.agapeuni/image.png?type=w80_blur)

​

다음과 같은 명령으로 값을 설정을 하고 테이블을 조회하면 설정한 값에 따라 목록이 표시됩니다.

**> .mode column - 모드 설정**

**> .headers on - 머리글 표시 켜기 또는 끄기**

**> .nullvalue NULL - NULL 값에 지정한 STRING으로 표시**

![](https://postfiles.pstatic.net/MjAyMDExMjBfMjk5/MDAxNjA1ODAzMjI0ODQ2.GiKRWzugvoSPiPoJWwaqLKEfTkKIWJK60XB0ijPUfnAg.bNqJgR5M6_H_o0zxRN8w4zddM3OQXQQBqf9N7Id8bVAg.PNG.agapeuni/image.png?type=w80_blur)

​

그 밖에 다른 명령을 실행해 봅니다.

**> .database - 데이터베이스의 이름 및 파일 표시**

**> .tables - LIKE 패턴과 일치하는 테이블 이름 표시**

**> .schema tb_temp - 패턴과 일치하는 CREATE 문 표시**

**> .quit - 프로그램 종료**

![](https://postfiles.pstatic.net/MjAyMDExMjBfMTE4/MDAxNjA1ODAzNjIzMTY2.swOeso5x8QpH4EeR1P5kyq-DptQtTesf_Y0zEbvEaOYg.SLpqz2CURe_8UUfm5jDU7CLk88ewHqGO4_Ld4LVWOpQg.PNG.agapeuni/image.png?type=w80_blur)

다음의 명령어로 테이블의 데이터를 CSV 파일로 생성합니다.

**> .output tb_temp.csv**

**> .separator , - 열 및 행 구분자 변경**

**> select * from tb_temp;**

**> .output stdout**

![](https://postfiles.pstatic.net/MjAyMDExMjBfMjcw/MDAxNjA1ODA0MTg1MTM2.74FIZjN5GugIaAUSUxfj3E-A43E0B7afwm1l_NO4ji4g.q7aSDvV3qAit2R4ttKKq7gUs9TpYxlREfcGq81ayPngg.PNG.agapeuni/image.png?type=w80_blur)

![](https://postfiles.pstatic.net/MjAyMDExMjBfMTcy/MDAxNjA1ODA0MTIyNzk4.YRZ6ldkhzDiVviHPek5j5hoYVQNadGTyQJPl2Q1o9ykg.McfvSTcXbvFZnX8Jv7Daqp8x71UxUaHfu6MMU6uynacg.PNG.agapeuni/image.png?type=w80_blur)

​

다음의 명령어로 데이터베이스를 SQL 파일로 생성합니다.

**> .output tb_temp.sql - FILE이 생략된 경우 FILE 또는 stdout으로 출력 전송**

**> .dump - 모든 데이터베이스 콘텐츠를 SQL로 렌더링**

**> .output stdout**
