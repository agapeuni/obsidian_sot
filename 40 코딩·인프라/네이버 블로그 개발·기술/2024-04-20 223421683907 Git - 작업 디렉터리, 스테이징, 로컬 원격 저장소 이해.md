​

Git은 파일의 변경 이력을 관리하고 협업을 위해 사용되는 분산 버전 관리 시스템이다. Git을 사용하면 프로젝트의 모든 파일을 관리하고 변경 사항을 추적할 수 있다. Git은 빠르고 효율적이며 시스템 관리자와 오픈 소스 프로젝트에서 리포지토리를 강화하는 데 사용된다.

​

Git을 사용하기 위해서는 작업 디렉터리, 스테이징 영역, 로컬 저장소, 그리고 원격 저장소의 개념을 잘 이해하면 된다.

1\. 작업 디렉터리 (Working Directory)

작업 디렉터리는 Git이 관리하는 프로젝트의 실제 파일이 위치하는 곳이며 현재 작업 중인 프로젝트 폴더다. 이 디렉터리는 로컬 컴퓨터에 있는 프로젝트 폴더를 의미한다. 여기에 프로젝트의 모든 파일과 하위 디렉터리가 포함되어 있다. 

​

작업 디렉터리에서는 파일을 수정하고 새 파일을 추가할 수 있습니다. 이 디렉터리는 실제 파일들이 존재하고, 여기에서 파일을 수정하거나 추가할 수 있다. Git은 작업 디렉터리 내의 모든 파일을 추적하고 변경 사항을 관리한다. Git에 의해 추적되는 파일은 Git의 관리 아래에 있게 된다.

​

​

2\. 스테이징 영역 (Staging Area)

스테이징 영역은 작업 디렉터리에서 변경된 파일 중 일부를 선택하여 저장하는 영역이다. 스테이징 영역은 Git이 추적하고 있는 변경 사항을 일시적으로 저장하는 영역이다. 이 영역은 커밋(commit)을 수행하기 전에 커밋에 포함될 변경 사항을 정리하는 공간이다. 

​

작업 디렉터리에서 변경된 파일 중 일부를 선택하여 스테이징 영역에 추가한다. 이 과정을 "파일 스테이징"이라고 한다. 작업 디렉터리에서 3개의 파일이 수정되었을 때, 이 중 2개의 파일만을 스테이징 영역에 추가할 수 있다. 스테이징 영역에 추가된 파일들은 다음 커밋에서 포함한다.

​

작업 디렉터리에서 파일을 수정하고 Git에게 이 변경 사항을 알리기 위해서는 `git add` 명령어를 사용하여 변경 사항을 스테이징 영역에 추가해야 한다.

git add

​

3\. 로컬 저장소 (Local Repository)

로컬 저장소는 Git의 버전 관리 기록이 저장되는 곳이다. Git은 로컬 저장소에 커밋 된 변경 사항을 저장하고 버전 기록을 관리한다. 스테이징 영역에 있는 변경 사항을 로컬 저장소에 영구적으로 기록하기 위해서는 `git commit` 명령어를 사용한다. 

git commit

커밋을 통해 스테이징 영역의 변경 사항이 로컬 저장소에 저장되며, 각 커밋은 고유한 해시값(버전 ID)을 가진다. 로컬 저장소는 로컬 컴퓨터에 위치하며, 프로젝트의 모든 변경 이력이 저장된다.

​

​

4\. 원격 저장소 (Remote Repository)

원격 저장소는 프로젝트의 Git 저장소를 호스팅하는 서버이다. 원격 저장소는 다른 개발자들과 협업하기 위한 공유 저장소이다. 원격 저장소는 여러 사용자가 함께 작업하고 변경 사항을 공유한다. 주로 GitHub, GitLab, Bitbucket 등의 웹 호스팅 서비스를 통해 원격 저장소를 생성하고 관리한다. 

​

개발자들은 로컬 작업 디렉터리에서 작업한 내용을 커밋하여 로컬 저장소에 저장한 후, 원격 저장소에 푸시(push)하여 변경 사항을 공유한다. 원격 저장소는 프로젝트의 중앙 버전을 보관하고, 다른 개발자들과 협업할 수 있는 플랫폼을 제공한다.

​

로컬 저장소의 변경 사항을 원격 저장소로 전송하기 위해서는 `git push` 명령어를 사용한다. 이렇게 하면 로컬 저장소의 커밋 내용이 원격 저장소로 업로드되어 다른 개발자들과 공유할 수 있다.

git push

반대로 원격 저장소의 변경 사항을 로컬로 가져오려면 `git pull` 명령어를 사용한다.

git pull

​

5\. Git 작업 흐름

1) 작업 디렉터리 : 파일을 추가하고 파일을 수정하여 작업합니다. 프로젝트 파일을 수정하고 변경 사항을 추적한다.

2) 스테이징 영역 : 작업 디렉터리에서 변경된 파일 중 일부를 선택하여 스테이징 영역에 추가하여 커밋 할 준비를 한다.

3) 로컬 저장소 : 스테이징 영역에 있는 변경 사항을 커밋 하여 로컬 저장소에 저장한다. 고유한 해시값(버전 ID)이 생긴다.

4) 원격 저장소 : 로컬 저장소의 변경 사항을 원격 저장소로 푸시 하여 다른 개발자와 공유하여 협업을 한다.

​

이렇게 Git은 작업 디렉터리에서부터 시작하여 스테이징 영역을 통해 변경 사항을 정리하고, 로컬 저장소와 원격 저장소를 통해 버전 관리와 협업을 수행한다. Git을 사용하면 프로젝트의 효율성과 협업성을 높일 수 있다. Git 개발에서 필수적인 개념이므로 잘 숙지하는 것이 필요하다.
