이번 예제는 이전의 "**[Pi4J] 여러개의 LED 깜빡이기 (라즈베리 파이 vs 아두이노)** "와 회로도는 같습니다. 하지만 저번 예제의 코드는 핀의 정의를 단순하게 나열하였고 LED On/Off를 매번 호출하여서 기능에 비해 소스의 길이도 길고 비효율적입니다. 이번에는 보다 효율적인 코드로 변경하려고 합니다. 

​

라즈베리 파이와 아두이노에서 LED와 핀연결은 지난번과 같습니다. 육체의 피곤함을 핑계로 보름전에 구성해 둔 LED를 그냥 계속 꼽아두고 있습니다. 라즈베리 파이와 연결한 늘솜 보드에서는 아래의 사진에 보이는데로 G18, G27, G22, G23, G24, G25 핀의 순서대로 연결하였습니다. 라즈베리 파이의 1, 2, 3, 4, 5, 6핀에 해당합니다. BCM 핀정의에 따르면 늘솜 보드의 라벨과 같고 Pi4J에 정의된 핀정의에 따르면 1, 2, 3, 4, 5, 6 순 입니다.

먼저 아두이노 스케치 코드입니다.

7번 핀부터 2번 핀까지 pin1 ~ pin6 변수를 선언하고 OUTPUT으로 설정하였고 loop() 에서 여 0.5초 간격으로 LED를 On/Off 합니다.

​

**지난 블로그의 아두이노 코드 (S0602_MultiLed_1) - 단순 나열 코드**

int pin1 = 7; int pin2 = 6; int pin3 = 5; int pin4 = 4; int pin5 = 3; int pin6 = 2; int delayTime = 500; void setup() { pinMode(pin1, OUTPUT); pinMode(pin2, OUTPUT); pinMode(pin3, OUTPUT); pinMode(pin4, OUTPUT); pinMode(pin5, OUTPUT); pinMode(pin6, OUTPUT); } void loop() { // All Led is On digitalWrite(pin1, HIGH); digitalWrite(pin2, HIGH); digitalWrite(pin3, HIGH); digitalWrite(pin4, HIGH); digitalWrite(pin5, HIGH); digitalWrite(pin6, HIGH); delay(delayTime); // All Led is Off digitalWrite(pin1, LOW); digitalWrite(pin2, LOW); digitalWrite(pin3, LOW); digitalWrite(pin4, LOW); digitalWrite(pin5, LOW); digitalWrite(pin6, LOW); delay(delayTime); // Left is On, Right is Off digitalWrite(pin1, HIGH); digitalWrite(pin2, HIGH); digitalWrite(pin3, HIGH); digitalWrite(pin4, LOW); digitalWrite(pin5, LOW); digitalWrite(pin6, LOW); delay(delayTime); // Left is Off, Right is On digitalWrite(pin1, LOW); digitalWrite(pin2, LOW); digitalWrite(pin3, LOW); digitalWrite(pin4, HIGH); digitalWrite(pin5, HIGH); digitalWrite(pin6, HIGH); delay(delayTime); // All Led is Off digitalWrite(pin1, LOW); digitalWrite(pin2, LOW); digitalWrite(pin3, LOW); digitalWrite(pin4, LOW); digitalWrite(pin5, LOW); digitalWrite(pin6, LOW); delay(delayTime); }

​

지난 코드에서는 핀마다 변수를 설정하였고 LED On/Off도 문장 하나하나 작성하였습니다.

하지만 배열로 선언하면 핀의 정의와 설정을 for 문으로 사용하여 편리하게 할 수 있습니다. 

​

아래의 코드를 보면 동일한 기능을 수행하는데 코드가 이전 보다 상당히 줄었습니다.

핀을 배열로 선언하여 핀 모드를 설정할 때나 LED On/Off 를 할 때 for 문을 사용하였습니다.

​

**개선한 아두이노 코드 (S0602_MultiLed_2)**

int pins[] = { 7, 6, 5, 4, 3, 2 }; int countLed = 6; int delayTime = 500; void setup() { for (int i = 0; i < countLed; i++) { pinMode(pins[i], OUTPUT); } } void loop() { // All Led is On for (int i = 0; i < countLed; i++) { digitalWrite(pins[i], HIGH); } delay(delayTime); // All Led is Off for (int i = 0; i < countLed; i++) { digitalWrite(pins[i], LOW); } delay(delayTime); // Left is On, Right isOff for (int i = 0; i < 3; i++) { digitalWrite(pins[i], HIGH); } for (int i = 3; i < countLed; i++) { digitalWrite(pins[i], LOW); } delay(delayTime); // Left is Off, Right isOn for (int i = 0; i < 3; i++) { digitalWrite(pins[i], LOW); } for (int i = 3; i < countLed; i++) { digitalWrite(pins[i], HIGH); } delay(delayTime); // All Led is Off for (int i = 0; i < countLed; i++) { digitalWrite(pins[i], LOW); } delay(delayTime); }

**​**

다음은 Pi4J로 구현한 자바 코드입니다. 아두이노 코드처럼 단순 나열형으로 되어 있습니다. 핀마다 변수를 설정하였고 LED On/Off도 문장 하나하나 작성하였습니다. 늘솜 보드에 표시된 BCM 18번, 27번, 22번, 23번, 24번, 25번 핀을 차례로 pin1부터 pin6까지 변수로 설정합니다.

​

**이전 블로그 자바 코드 (S0602_MultiLed_1) - 단순 나열 코드**

package com.pi4j.book.ch06; import static com.pi4j.util.Pi4jUtil.delay; import com.pi4j.io.gpio.GpioController; import com.pi4j.io.gpio.GpioFactory; import com.pi4j.io.gpio.GpioPinDigitalOutput; import com.pi4j.io.gpio.PinState; import com.pi4j.io.gpio.RaspiPin; public class S0602_MultiLed_1 { GpioController gpio = GpioFactory.getInstance(); GpioPinDigitalOutput pin1; GpioPinDigitalOutput pin2; GpioPinDigitalOutput pin3; GpioPinDigitalOutput pin4; GpioPinDigitalOutput pin5; GpioPinDigitalOutput pin6; int delayTime = 500; void setup() { pin1 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_01, PinState.LOW); pin2 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_02, PinState.LOW); pin3 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_03, PinState.LOW); pin4 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_04, PinState.LOW); pin5 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_05, PinState.LOW); pin6 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_06, PinState.LOW); } void loop() { System.out.println("All Ledis On"); pin1.high(); pin2.high(); pin3.high(); pin4.high(); pin5.high(); pin6.high(); delay(delayTime); System.out.println("All Ledis Off"); pin1.low(); pin2.low(); pin3.low(); pin4.low(); pin5.low(); pin6.low(); delay(delayTime); System.out.println("Left isOn, Right is Off"); pin1.high(); pin2.high(); pin3.high(); pin4.low(); pin5.low(); pin6.low(); delay(delayTime); System.out.println("Left isOff, Right is On"); pin1.low(); pin2.low(); pin3.low(); pin4.high(); pin5.high(); pin6.high(); delay(delayTime); System.out.println("All Ledis Off"); pin1.low(); pin2.low(); pin3.low(); pin4.low(); pin5.low(); pin6.low(); delay(delayTime); } void shutdown() { gpio.shutdown(); } public static void main(String[] args) { S0602_MultiLed_1 instance = new S0602_MultiLed_1(); instance.setup(); for (int i = 0; i < 5; i++) { instance.loop(); } instance.shutdown(); } } 

​

자바 코드는 가변인자를 사용하는 메소드 형태와 배열을 사용하는 형태, 두가지로 변형해 보겠습니다. 

​

먼저 가변인자를 사용하는 메소드 형태입니다. 핀의 선언과 정의문은 그대로 두고 Led On/Off를 가변인자를 사용하는 메소드를 새롭게 만들어 봅니다. setHigh()와 setLow()의 이름으로 두개의 메소드를 만들어서 pin 변수를 한번에 던져 On/Off를 처리합니다. 

​

아래의 코드를 보면 동일한 기능을 수행하는데 코드가 역시 이전 보다 상당히 줄었습니다.

​

**개선한 자바 코드 (S0602_MultiLed_2)**

package com.pi4j.book.ch06; import static com.pi4j.util.Pi4jUtil.delay; import com.pi4j.io.gpio.GpioController; import com.pi4j.io.gpio.GpioFactory; import com.pi4j.io.gpio.GpioPinDigitalOutput; import com.pi4j.io.gpio.PinState; import com.pi4j.io.gpio.RaspiPin; public class S0602_MultiLed_2 { GpioController gpio = GpioFactory.getInstance(); GpioPinDigitalOutput pin1; GpioPinDigitalOutput pin2; GpioPinDigitalOutput pin3; GpioPinDigitalOutput pin4; GpioPinDigitalOutput pin5; GpioPinDigitalOutput pin6; int delayTime = 500; void setup() { pin1 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_01, PinState.LOW); pin2 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_02, PinState.LOW); pin3 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_03, PinState.LOW); pin4 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_04, PinState.LOW); pin5 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_05, PinState.LOW); pin6 = gpio.provisionDigitalOutputPin(RaspiPin.GPIO_06, PinState.LOW); } void loop() { System.out.println("All Ledis On"); setHigh(pin1, pin2, pin3, pin4, pin5, pin6); delay(delayTime); System.out.println("All Ledis Off"); setLow(pin1, pin2, pin3, pin4, pin5, pin6); delay(delayTime); System.out.println("Left isOn, Right is Off"); setHigh(pin1, pin2, pin3); setLow(pin4, pin5, pin6); delay(delayTime); System.out.println("Left isOff, Right is Om"); setLow(pin1, pin2, pin3); setHigh(pin4, pin5, pin6); delay(delayTime); System.out.println("All Ledis Off"); setLow(pin1, pin2, pin3, pin4, pin5, pin6); delay(delayTime); } void shutdown() { gpio.shutdown(); } void setHigh(GpioPinDigitalOutput... pin) { for (GpioPinDigitalOutput p : pin) { p.high(); } } void setLow(GpioPinDigitalOutput... pin) { for (GpioPinDigitalOutput p : pin) { p.low(); } } public static void main(String[] args) { S0602_MultiLed_2 instance = new S0602_MultiLed_2(); instance.setup(); for (int i = 0; i < 5; i++) { instance.loop(); } instance.shutdown(); } } 

하지만 배열로 선언하면 핀의 정의와 설정을 for 문으로 사용하여 편리하게 할 수 있습니다. 

​

아두이노 코드와 같이 핀을 배열로 선언하고 선언과 설정에 사용하고 LED On/Off에 for 문을 사용합니다. 

코드가 처음보다 간결해지고 라인수가 많이 줄었습니다.

​

**개선한 자바 코드 (S0602_MultiLed_3)**

package com.pi4j.book.ch06; import static com.pi4j.util.Pi4jUtil.delay; import com.pi4j.io.gpio.GpioController; import com.pi4j.io.gpio.GpioFactory; import com.pi4j.io.gpio.GpioPinDigitalOutput; import com.pi4j.io.gpio.Pin; import com.pi4j.io.gpio.PinState; import com.pi4j.io.gpio.RaspiPin; public class S0602_MultiLed_3 { private static final Pin GPIO01 = RaspiPin.GPIO_01; private static final Pin GPIO02 = RaspiPin.GPIO_02; private static final Pin GPIO03 = RaspiPin.GPIO_03; private static final Pin GPIO04 = RaspiPin.GPIO_04; private static final Pin GPIO05 = RaspiPin.GPIO_05; private static final Pin GPIO06 = RaspiPin.GPIO_06; Pin[] pin = { GPIO01, GPIO02, GPIO03, GPIO04, GPIO05, GPIO06 }; GpioController gpio = GpioFactory.getInstance(); GpioPinDigitalOutput[] pins = new GpioPinDigitalOutput[pin.length]; int delayTime = 500; void setup() { for (int i = 0; i < pin.length; i++) { pins[i] = gpio.provisionDigitalOutputPin(pin[i], PinState.LOW); } } void loop() { System.out.println("All Ledis On"); for (GpioPinDigitalOutput p : pins) { p.high(); } delay(delayTime); System.out.println("All Ledis Off"); for (GpioPinDigitalOutput p : pins) { p.low(); } delay(delayTime); System.out.println("Left isOn, Right is Off"); for (int i = 0; i < 3; i++) { pins[i].high(); } for (int i = 3; i < pins.length; i++) { pins[i].low(); } delay(delayTime); System.out.println("Left isOff, Right is Om"); for (int i = 0; i < 3; i++) { pins[i].low(); } for (int i = 3; i < pins.length; i++) { pins[i].high(); } delay(delayTime); System.out.println("All Ledis Off"); for (GpioPinDigitalOutput p : pins) { p.low(); } delay(delayTime); } void shutdown() { gpio.shutdown(); } public static void main(String[] args) { S0602_MultiLed_3 instance = new S0602_MultiLed_3(); instance.setup(); for (int i = 0; i < 5; i++) { instance.loop(); } instance.shutdown(); } }
