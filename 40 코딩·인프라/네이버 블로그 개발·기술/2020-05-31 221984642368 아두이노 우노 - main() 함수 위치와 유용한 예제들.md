**아두이노 스케치 기본 주석 제거**

아두이노 통합개발툴(IDE)를 실행하면 다음과 같이 setup 함수와 loop 함수에 친절하게도 영문의 주석이 따라붙습니다.

초기에는 나름 고마운 주석인데 어느 정도 익숙해지고 나서 코딩을 할 때마다 매번 지우기는 것이 귀찮은 일이 됩니다.

​

아두이노 폴더를 기준으로 다음의 폴더에 들어가면

**C:\Program Files (x86)\Arduino\examples\01.Basics\BareMinimum**

스케치를 시작하는 데 필요한 최소한의 코드인 BareMinimum.ino 파일이 존재합니다.

파일을 열고 setup 함수와 loop 함수에 영문 주석을 지우고 저장하면 생성되는 신규 파일에 주석이 나타나지 않습니다.

**아두이노 파일명 규칙****​**

"sketch_"에 날짜가 월은 영문으로 일은 숫자로 붙여지고 a부터 순차적으로 z까지 이름이 붙습니다.

**아두이노 소스 main() 확인**

아두이노가 설치된 폴더를 기준으로 다음의 폴더로 이동해 보면 Arduino.h 파일과 main.cpp 파일이 존재합니다.

C:\Program Files (x86)\Arduino\hardware\arduino\avr\cores\arduino

Arduino.h 파일에는 아두이노 스케치에서 많이 사용하는 내장함수의 선언을 볼 수가 있습니다. (코드의 일부분)

pinMode(), digitalRead(), digitalWrite(), analogRead(), analogWrite(), delay(), ...... setup(), loop()

void init(void); void initVariant(void); int atexit(void (*func)()) __attribute__((weak)); void pinMode(uint8_t, uint8_t); void digitalWrite(uint8_t, uint8_t); int digitalRead(uint8_t); int analogRead(uint8_t); void analogReference(uint8_t mode); void analogWrite(uint8_t, int); unsigned long millis(void); unsigned long micros(void); void delay(unsigned long); void delayMicroseconds(unsigned int us); unsigned long pulseIn(uint8_t pin, uint8_t state, unsigned long timeout); unsigned long pulseInLong(uint8_t pin, uint8_t state, unsigned long timeout); void shiftOut(uint8_t dataPin, uint8_t clockPin, uint8_t bitOrder, uint8_t val); uint8_t shiftIn(uint8_t dataPin, uint8_t clockPin, uint8_t bitOrder); void attachInterrupt(uint8_t, void (*)(void), int mode); void detachInterrupt(uint8_t); void setup(void); void loop(void);

main.cpp 파일에는 setup 함수와 loop 함수를 실행하는 코드를 볼 수가 있습니다.

main이 실행되면 먼저 초기화 함수를 실행하고 setup 함수를 한번 호출하고 for 문을 사용해서 loop 함수를 무한 반복하고 있네요.
