**1\. MySQL 개요**

지나온 프로젝트를 뒤돌아 보면 20년 전에는 MS-SQL을 많이 사용하였고 10년 전에는 Oracle을 많이 사용했다. 그리고 어느 시점부터 MySQL과 MariaDB를 실제 프로젝트에서 많이 사용하고 있다. Java와 Python으로 MySQL / MariaDB 데이터베이스를 연결하는 코드를 작성해 본다.

​

MySQL은 관계형 데이터베이스 관리 시스템(RDBMS)의 하나로, 오픈 소스 기반으로 개발된 데이터베이스 시스템이다. MySQL은 속도와 안정성, 확장성에 중점을 두고 설계되어 있으며, 다양한 플랫폼에서 사용할 수 있다. MySQL은 초기에는 스웨덴의 회사인 MySQL AB에서 개발되었으며, 현재는 Oracle Corporation이 소유하고 유지 보수를 담당하고 있다. MySQL은 많은 웹 애플리케이션 및 서비스에서 널리 사용되며, 가볍고 빠른 성능, 사용 편의성, 확장성 및 안정성으로 인기를 얻고 있다.

**3\. 참고 정보**

MySQL / MariaDB에 잘 연결되는지 코드를 구현해 보자. MariaDB는 로컬에 설치되어 있고 데이터베이스는 example이다. 

**root** 계정을 사용하여 접속하여 TB_EMPLOYEE 테이블을 조회해 본다.

**연결문자열**

  * JDBC Driver class : com.mysql.cj.jdbc.Driver

  * JDBC URL format : jdbc:mysql://[host][:port]/[database][?propertyName][=propertyValue]

  * JDBC URL example : jdbc:mysql://localhost:3306/database?useUnicode=true&characterEncoding=utf8

**4\. 데이터베이스 연결 테스트 with Java**

다운로드한 zip 파일을 압축 해제하면 mysl-connector-j-8.0.30.jar 파일이 들어있다. 

jar 파일을 라이브러리로 등록한다.

​

**파일 : TestMySql.java**

import java.sql.Connection; import java.sql.DriverManager; import java.sql.ResultSet; import java.sql.SQLException; import java.sql.Statement; public class TestMySql { public static void main(String[] args) { Connection conn = null; Statement stmt = null; ResultSet rs = null; String dbUrl = "jdbc:mysql://localhost/example"; String dbUser = "root"; String dbPassword = "1234"; try { Class.forName("com.mysql.cj.jdbc.Driver"); System.out.println("Driver Loading OK. *^^*"); } catch (ClassNotFoundException e) { System.out.println("Driver Loading Error. ^^;"); System.out.println(e.toString()); return; } try { conn = DriverManager.getConnection(dbUrl, dbUser, dbPassword); System.out.println("Driver Connection OK. *^^*"); } catch (SQLException e) { System.out.println("Driver Connection Error. ^^;"); System.out.println(e.toString()); return; } try { stmt = conn.createStatement(); rs = stmt.executeQuery("SELECT * FROM TB_EMPLOYEE"); while (rs.next()) { System.out.println(rs.getString(1) + " - " + rs.getString(2)); } } catch (SQLException e) { System.out.println("executeQuery() Error. ^^;");+ System.out.println(e.toString()); } try { if (rs != null) { rs.close(); } if (stmt != null) { stmt.close(); } if (conn != null) { conn.close(); } } catch (SQLException e) { System.out.println(e.toString()); } } }
