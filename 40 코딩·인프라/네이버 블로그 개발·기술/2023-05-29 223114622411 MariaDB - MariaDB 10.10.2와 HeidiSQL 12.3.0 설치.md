**1\. MariaDB 개요**

MariaDB는 오픈 소스 관계형 데이터베이스로 상용으로 사용하는 것도 무료이다. MySQL 핵심 개발자가 만들고 오픈 소스로 유지하고 있다. MariaDB는 MySQL의 코드를 기반으로 개발하여 모든 기능이 동일하여 호환성이 보장된다.

​

**2\. MariaDB 다운로드**

MariaDB 다운로드 페이지에서 설치 파일을 다운로드한다.

<https://mariadb.org/download>

[ ![](https://dthumb-phinf.pstatic.net/?src=%22https%3A%2F%2Fmariadb.org%2Fwp-content%2Fuploads%2F2019%2F01%2Fcropped-mariadb_org_rgb_v-2.png%22&type=ff120) ](https://mariadb.org/download) [ **Download MariaDB Server - MariaDB.org** REST API Release Schedule Reporting Bugs … Continue reading "Download MariaDB Server" mariadb.org ](https://mariadb.org/download)

MariaDB Server Version은 "MariaDB Server 10.10.2"를 선택했다. 

운영체제는 Windows, 아키텍처는 x86_64, 패키지 형태는 MSI Package를 선택하고 다운로드 버튼을 클릭한다.

**4\. HeidiSQL 설치**

HeidiSQL은 MySQL, MariaDB, Microsoft SQL Server, PostgreSQL 등 다양한 데이터베이스 시스템을 관리하기 위한 클라이언트 프로그램이다. HeidiSQL은 오픈 소스로 개발되었으며, 사용자가 데이터베이스를 쉽게 관리하고 조작할 수 있도록 다양한 기능을 제공한다. HeidiSQL은 Windows 운영체제에서 사용할 수 있으며, 직관적인 사용자 인터페이스를 통해 데이터베이스 관리 작업을 수행할 수 있다.

​

아래의 주소에서 HeidiSQL을 다운로드한다.

<https://www.heidisql.com/download.php>

![](https://postfiles.pstatic.net/MjAyMzA1MjlfMjY5/MDAxNjg1MzQxMzI2OTY0.a966fitVllTb2KVSCLxK11xWjdDzLwc16Jw8sfGYvPEg.DkfGaiAltzSRPaedbX1INrpiwK_GT0c3yefKLfwt6ecg.PNG.agapeuni/img.png?type=w80_blur)

​

다운로드한 "HeidiSQL_12.3.0.6589_Setup.exe" 파일을 실행하여 설치한다.

설치 경로는 "D:\db\HeidiSQL"로 지정했다.

![](https://postfiles.pstatic.net/MjAyMzA1MjlfMjMy/MDAxNjg1MzQxMzMxNDM1.9A6Q8d9C6D5tBH-7G0qM3R3aEgzrTQveqJ9Kd4a52eQg.OdYQvp9lopxzvDattvqt0ZMuLUaZOtZ8-Pu0PYj3K-wg.PNG.agapeuni/img.png?type=w80_blur)
