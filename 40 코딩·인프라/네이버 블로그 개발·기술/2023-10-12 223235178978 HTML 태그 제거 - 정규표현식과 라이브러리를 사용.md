​

데이터베이스에 담겨있는 정보를 화면에 표시할 때, 저장된 정보에 담겨있는 HTML 태그가 그대로 보이는 경우가 있다. 정보의 내용만을 표시하거나 제목의 일부만 보여주어야 하는 경우에 정보에 포함된 HTML 태그를 제거해 주어야 할 때가 있다. 

​

아래의 코드를 사용하면 태그를 제거한 정보만을 화면에 표시할 수가 있다.

​

1\. 정규 표현식으로 HTML 태그 제거

자바 1.4부터 정규 표현식 기능이 추가되었는데, 이를 사용하면 매우 간단하게 String에 포함된 HTML 태그를 제거할 수 있다. HTML 태그는 <로 시작해서 >로 끝나고, 종료 태그의 경우는 </로 시작하거나 또는 />로 끝난다.

​

따라서, 아래와 같은 정규 표현식은 HTML 태그를 모두 포함하게 된다.

<(/)?([a-zA-Z]*)(\s[a-zA-Z]*=[^>]*)?(\s)*(/)?>

자바 1.4부터 String.repalceAll(String regex, String replacemenet) 메서드를 제공하는데, 이 메서드는 문자열에서 regex의 정규 표현식에 일치하는 부분을 replacement로 치환해 주는 기능을 제공한다. 따라서, 특정 문자열에 HTML 태그를 제거하려면 위의 정규 표현식을 다음과 같이 적용하면 된다. 

String contents = "......"; String textWithoutTag = contents.replaceAll("<(/)?([a-zA-Z]*)(\s[a-zA-Z]*=[^>]*)?(\s)*(/)?>", "");

​

**1) Java에서 HTML 태그 제거하기**

List<Board> list = boardDao.selectList("selectBoard", condition); for (Board board : list) { String contents = board.getContents(); String removeTag = contents.replaceAll("<(/)?([a-zA-Z]*)(\\\s[a-zA-Z]*=[^>]*)?(\\\s)*(/)?>", ""); board.setContents(removeTag); }

​

**2) JavaScript에서 HTML 태그 제거하기**

function htmltagRemover (value) { return value.replace(/<(\/)?([a-zA-Z]*)(\s[a-zA-Z]*=[^>]*)?(\s)*(\/)?>/ig, ""); }

​

2\. 라이브러리로 HTML 태그 제거

정규 표현식으로 JavaScript와 Java에서 HTML 태그를 제거하는 작업을 수행할 수 있지만, 각 언어에는 서로 다른 방법과 라이브러리가 있다. 아래는 JavaScript와 Java를 사용하여 HTML 태그를 제거하는 방법이다. 

​

**1) JavaScript에서 HTML 태그 제거**

JavaScript를 사용하여 HTML 태그를 제거하려면 DOM(Document Object Model)을 사용할 수 있다. DOMParser를 사용하여 HTML 문자열을 파싱하고, 그 결과에서 본문 텍스트만 추출하여 HTML 태그를 제거한다.

​

다음은 JavaScript를 사용하여 HTML 문자열에서 태그를 제거하는 예제다.

function removeHTMLTags(input) { var doc = new DOMParser().parseFromString(input, "text/html"); return doc.body.textContent || ""; } var htmlString = "<p>This is <b>HTML</b> text.</p>"; var plainText = removeHTMLTags(htmlString); console.log(plainText); // "This is HTML text."

**​**

**2) Java에서 HTML 태그 제거**

Java에서 Jsoup 라이브러리를 사용하여 HTML 태그를 제거할 수 있다. soup 라이브러리를 사용하여 HTML 문자열을 파싱하고, `text()` 메서드를 사용하여 본문 텍스트만 추출하여 HTML 태그를 제거한다.

​

Jsoup 라이브러리를 프로젝트에 추가해야 한다. 

Maven을 사용하는 경우 다음 의존성을 추가할 수 있다.

<dependency> <groupId>org.jsoup</groupId> <artifactId>jsoup</artifactId> <version>1.14.3</version> </dependency>

​

다음은 Java를 사용하여 HTML 태그를 제거하는 예제다. 

import org.jsoup.Jsoup; import org.jsoup.nodes.Document; public class HTMLTagRemover { public static String removeHTMLTags(String html) { Document doc = Jsoup.parse(html); return doc.text(); } public static void main(String[] args) { String htmlString = "<p>This is <b>HTML</b> text.</p>"; String plainText = removeHTMLTags(htmlString); System.out.println(plainText); // "This is HTML text." } }
