**1\. JSON 예제**

JSON (JavaScript Object Notation)으로 간단한 예제를 진행해 보자. Ajax로 요청한 데이터를 리턴 받을 때 Text / JSON / XML 형식으로 받는다. JSON은 자바스크립트 객체 표기법으로 XML 형식과 동일하게 사용한다. 자바스크립트 입장에서 보면 JSON이 XML보다 쉽고 가벼워서 실무에서도 많이 사용한다. 

​

그럼 초간단 예제를 살펴보고 쉽게 적용해 보자.

{ "name1": "Kim Seung Gu", "name2": "Joo Han Gil", "name2": "Hong Gil Dong" }

​

위와 같은 데이터를 서버에서 응답으로 받을 때 다음과 같이 eval 함수를 적용하면 아래와 같이 사용할 수 있다.

var res = { "name1" : "Kim Seung Gu", "name2" : "Joo Han Gil", "name2" : "Hong Gil Dong" } // JSON 형태의 텍스트를 JavaScript 객체화 한다. eval("res = " + request.responseText); // 실제 객체를 사용한다. alert(res.name1); // "Kim Seung Gu"을 출력한다. alert(res.name2); // "Joo Han Gil"을 출력한다

​

데이터 목록을 그리드나 테이블에 표시하기 위해 배열로 담아서 보내는 것도 가능하다.

[ ["name1", "Kim Seung Gu"], ["name2", "Joo Han Gil"], ["name3", "Hong Gil Dong"] ... ]

​

배열도 생성한 데이터를 eval 함수로 적용하면 다음과 같이 배열 인덱스로 접근이 가능하다.

var res = [ [ "name1", "Kim Seung Gu" ], [ "name2", "Joo Han Gil" ], [ "name3", "Hong Gil Dong" ] ]; eval("res = " + request.responseText); alert(res[0][0]); // "name1"을 출력한다. alert(res[2][1]); // "Hong Gil Dong"를 출력한다.

​

아래 코드는 books 정보에 jsonData로 되어있고 4건의 데이터가 담겨있다. 

books의 속성은 title, author, isbn으로 되어 있다. 

​

JSON으로 되어있는 정보를 얻으려면 아래와 같이 사용하면 된다. 

파일 : books.html

<html> <head> <title>JSON Test</title> <script type="text/javascript" language="JavaScript"> function jsonTest() { var jsonData = { "books" : [ { "title" : "Hyperion", "author" : "Dan Simmons", "isbn" : "0553283685" }, { "title" : "The Stars My Destination", "author" : "Alfred Bester", "isbn" : "0679767800" }, { "title" : "Black House", "author" : [ "Stephen King", "Peter Straub" ], "isbn" : "0345441036" }, { "title" : "The Golden Compass", "author" : "Philip Pullman", "isbn" : "0679879242" }, ] }; console.log(jsonData.books[1].author); // Alfred Bester console.log(jsonData.books[3].isbn); // 0679879242 console.log(jsonData.books[2].isbn); // 0345441036 console.log(jsonData.books[0].author); // Dan Simmons console.log(jsonData.books[2].title); // Black House console.log(jsonData.books[2].author[1]); // Peter Straub } </script> </head> <body> <input type="button" value="Test" name="Test" onClick="jsonTest();" /> </body> </html>
