1\. Microsoft SQL Server

2003년 이전에 진행한 프로젝트에서는 MS-SQL을 기본적으로 사용했다. 그때는 그 이후로도 계속해서 MS SQL을 사용할 거 같아서 MCDBA(Microsoft Certified Database Administrator)도 취득했다. 하지만 2003년 eCMS 프로젝트를 마지막으로 그 이후에 진행한 프로젝트는 Oracle과 MySQL / MariaDB를 주로 사용했다.

2\. 20년 만에 다시 사용

최근에 진행한 PLM 프로젝트에서 사용했던 데이터베이스가 MS-SQL이다. 20년 만에 MS SQL Server를 다시 사용하게 되었다. 설치 화면은 예전과는 많이 달라진 거 같은데 예나 지금이나 Microsoft 제품은 설치가 어렵지 않아서 정말 편하다. Microsoft SQL Server를 먼저 설치하고 Microsoft SQL Server Management Studio(SSMS)를 바로 설치했다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMjcg/MDAxNjg3NTQ0OTQwNzEz.AXaQj827B5cYZY9RIOugyT3b2mu8YYTe5U9Nbt4IGeEg.00fntREt8V6eJylREd76_tyjjQ9_jcwDdNeOfHR4yyog.PNG.agapeuni/img.png?type=w80_blur)

​

원활한 프로젝트 수행을 위해 HRDB2 데이터베이스도 생성해 보고 간단한 쿼리를 실행해 보았다. 

처음에는 익숙하지 않아서 조금 불편했는데 UI가 직관적이 이어서 얼마간 시간이 지나고 나니 금방 적응했다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMTk1/MDAxNjg3NTQ0OTQ5MzE2.oo9aNCSyCnfy4I0_iqkvlFBwsyT9BVrKDbhv2LHkAJ8g.-e_6yDq__beBU-p86tiVs7q8g_m_r_RbHUCiIt7Ow_4g.PNG.agapeuni/img.png?type=w80_blur)

​

생성된 테이블을 기준으로 신규 다이어그램을 생성해 보았는데 키 관계를 매핑하여 ERD을 자동으로 그려준다. 

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMjk3/MDAxNjg3NTQ0OTUzMDE1.1c8zwuCoC1OKISvOVgUcqTY2JEd9FUxAK8wrMUmSsMAg.xCTXFnPhA4iBXY2ohm-RyFgBisjNwsHRxuLFTtPiyxsg.PNG.agapeuni/img.png?type=w80_blur)

​

HRDB2 디스크 사용에 대한 화면이다. 데이터베이스 내의 디스크 공간 사용량에 대한 개요 정보를 표시한다.

![](https://postfiles.pstatic.net/MjAyMzA2MjRfMjE4/MDAxNjg3NTQ0OTU2Mzg4.PzCAvJTcTrVfbVJ4eYnKi__AawBQI5BGBeof_GTy3UIg.ZMwUXH2s7TbI7qtB-xnudsMVJInjxHRE3yJ9sxgiOtQg.PNG.agapeuni/img.png?type=w80_blur)
