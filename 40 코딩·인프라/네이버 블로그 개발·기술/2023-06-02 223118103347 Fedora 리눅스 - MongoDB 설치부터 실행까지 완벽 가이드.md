**1\. 개요**

Fedora 리눅스에 MongoDB를 설치해 보자.

​

​

**2\. Yum 저장소를 구성**

Fedora 시스템에 MongdoDB를 설치하기 위해 Yum 저장소를 구성한다.

$ sudo nano /etc/yum.repos.d/mongodb.repo

​

mongodb.repo 파일에 다음의 내용을 추가한다.

[Mongodb] name=MongoDB Repository baseurl=https://repo.mongodb.org/yum/redhat/8/mongodb-org/4.4/x86_64/ gpgcheck=1 enabled=1 gpgkey=https://www.mongodb.org/static/pgp/server-4.4.asc

​

**3\. MongoDB 설치**

DNF 패키지 관리자를 사용하여 MongoDB를 설치한다.

$ sudo dnf install mongodb-org mongodb-org-server

**4\. MongoDB 서비스 시작**

MongoDB가 잘 설치되었으면 MongoDB 서비스를 활성화하고 시작한다.

$ sudo systemctl enable mongod $ sudo systemctl start mongod

서비스가 시작되면 다음의 명령어로 상태를 확인한다.
