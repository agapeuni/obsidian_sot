1\. python-barcode 개요

python-barcode 라이브러리는 Python 표준 라이브러리를 기반으로 바코드를 손쉽게 생성할 수 있도록 지원하는 도구이다. 이 라이브러리를 활용하면 복잡한 설정 없이도 간단한 코드 작성만으로 다양한 형태의 바코드를 만들 수 있다. 바코드를 생성하기 위해 필요한 것은 바코드의 형식(EAN, ISBN, UPC 등)과 해당 코드 정보뿐이며, 이를 입력하면 자동으로 바코드 이미지를 생성할 수 있다.

​

python-barcode는 별도의 복잡한 환경 설정 없이도 빠르게 결과물을 얻을 수 있어, 바코드 생성이 필요한 각종 응용 프로그램이나 데이터 관리 작업에 유용하게 활용할 수 있다.

​

라이브러리에서 제공되는 바코드 형식은 다음과 같다.

\- Code 128

\- Code 39

\- EAN-13

\- EAN-14

\- EAN-8

\- ISBN-10

\- ISBN-13

\- ISSN

\- JAN

\- PZN

\- UPC-A

​

3\. 바코드 생성

예시로 "한 권으로 이해하는 IoT 교과서" 서적의 ISBN을 입력하여 바코드를 생성해보았다. 이미지로 생성하려면 ImageWriter가 필요하다.

import barcode from barcode.writer import ImageWriter my_code = barcode.get('isbn13', '9788931461534', writer=ImageWriter()) # barcode_1.png 파일이 생성된다. my_code.save('./example/barcode/barcode_1')

4\. EAN-13 형식의 바코드를 생성

EAN13형식의 바코드를 생성한다. EAN-13은 유럽에서 가장 흔히 인식되고 있는 바코드로, 기본적인 제품 식별을 위해 사용한다.

from barcode import EAN13 from barcode.writer import ImageWriter # EAN13의 객체를 생성 my_code = EAN13('5901234123457', writer=ImageWriter()) # 바코드를 저장 my_code.save("./example/barcode/barcode_2")
