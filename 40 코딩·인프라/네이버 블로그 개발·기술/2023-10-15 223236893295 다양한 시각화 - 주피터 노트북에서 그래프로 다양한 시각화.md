1\. 막대그래프 (Bar Graph)

패키지 정의

from sklearn.datasets import load_wine import pandas as pd import matplotlib.pyplot as plt

데이터 로드

WINE = load_wine() wine = pd.DataFrame(WINE.data, columns=WINE.feature_names)

​

와인 데이터세트 타깃 변수로 막대그래프로 그려보자. wine 데이터프레임에 타깃 변수를 'type' 칼럼에 지정한다. 참고로 target 값은 0, 1, 2로 되어 있다. 그리고 type에 지정된 값을 'type 0', 'type 1', 'type 2'로 매핑한다. value_count() 함수를 사용하여 범주별로 값을 구한다.

​

wine_type 생성

wine['type'] = WINE.target wine['type'] = wine['type'].map({0:'type 0', 1:'type 1', 2:'type 2'}) wine_type = wine['type'].value_counts()

type type 1 71 type 0 59 type 2 48 Name: count, dtype: int64

plt.bar(wine_type.index, wine_type.values, width=0.7, align='center')

4\. 산점도 행렬(Scatter Matrix)

import pandas as pd import matplotlib.pyplot as plt from sklearn.datasets import load_iris from pandas.plotting import scatter_matrix

IRIS = load_iris() iris = pd.DataFrame(IRIS.data, columns=IRIS.feature_names) iris['class'] = IRIS.target iris['class'] = iris['class'].map({0:'Setosa', 1:'Versicolor', 2:'Virginica'})

scatter_matrix(iris, alpha=0.5, figsize=(8,8), diagonal='hist') plt.show()
