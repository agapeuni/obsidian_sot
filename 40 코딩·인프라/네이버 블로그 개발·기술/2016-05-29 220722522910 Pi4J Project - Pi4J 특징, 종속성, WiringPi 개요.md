1\. Pi4J 특징

Pi4J 프로젝트의 주요 특징은 다음과 같습니다.

​

① 자바 기반

Pi4J는 자바 언어로 개발되었으며, 자바 개발자들에게 친숙한 환경에서 라즈베리 파이를 제어할 수 있도록 지원합니다.

​

② 강력한 API

Pi4J는 다양한 기능을 제공하는 강력한 API를 제공합니다. 이를 통해 GPIO 핀 상태 읽기/쓰기, 상태 변화 감지, 인터럽트 처리, 액추에이터 제어, 다양한 하드웨어 인터페이스 사용 등을 수행할 수 있습니다.

​

③ 다양한 하드웨어 지원

Pi4J는 다양한 하드웨어 장치와 인터페이스를 지원합니다. 디지털 입력 및 출력, 아날로그 입력, PWM 출력, I2C, SPI, UART 등의 통신 프로토콜을 사용하여 외부 장치와 연결할 수 있습니다.

​

④ 높은 확장성

Pi4J는 라즈베리 파이 모델 A, B, A+, B+, 2B, 3B, 3B+, 4B 등 다양한 모델과 호환됩니다. 또한, 다른 Pi4J 기반 프로젝트와 통합하여 확장성을 높일 수 있습니다.

​

⑤ 오픈 소스

Pi4J는 오픈 소스 프로젝트로, GitHub를 통해 소스 코드와 문서를 제공합니다. 사용자들은 자유롭게 프로젝트에 기여하거나 수정하여 자신의 요구에 맞게 사용할 수 있습니다.

​

Pi4J는 GPIO 핀의 입출력 방향과 Edge 검출을 설정할 수 있으며 GPIO 핀 상태 제어/쓰기/읽기가 가능합니다. 폴링이 아닌 인터럽트 기반으로 GPIO 핀의 상태 변화를 수신하며 프로그램 종료(GPIO shut down)에 GPIO 상태를 설정할 수 있으며 I2C, SPI 통신이 가능합니다. 확장 보드를 통해 GPIO 용량을 추가하기 위해 GPIO Provider 인터페이스로 확장 가능합니다. 라즈베리 파이의 시스템 정보와 네트워크 정보에 어렵지 않게 접근할 수 있습니다. 자바에서 WiringPi 라이브러리에 직접 접근하기 위한 래퍼 클래스들도 준비되어 있습니다. ​

​

2\. Pi4J 지원 모델

시판 중인 대부분의 라즈베리 파이 모든 종류를 지원하고 있습니다.

  * 라즈베리 파이 - 모델 A

  * 라즈베리 파이 - 모델 B (리비전 1)

  * 라즈베리 파이 - 모델 B (리비전 2)

  * 라즈베리 파이 - 모델 A+

  * 라즈베리 파이 - 모델 B+

  * 라즈베리 파이 – 컴퓨트 모듈

  * 라즈베리 파이 2 - 모델 B

  * 라즈베리 파이 3 - 모델 B 

  * 라즈베리 파이 제로

​

3\. Pi4J 종속성

종속성이란 여러 개의 프로젝트가 있는 경우 A를 필요로 할 때 그때 B도 필요한 경우에 A는 B에 종속되었다고 말합니다. Pi4J는 고든 헨더슨에 의해 개발된 WiringPi 라이브러리의 JNI 래퍼를 구현합니다. Pi4J는 WiringPi 라이브러리에 정적으로 컴파일해서 필요한 부가적인 런타임 종속성이나 설치 전제조건이 없습니다.

4\. WiringPi 개요

WiringPi는 Raspberry Pi에서 사용되는 BCM2835를 위해 C로 만들어진 GPIO 액세스 라이브러리입니다. 아두이노 "wiring" 시스템을 사용하는 사람들에게 익숙하도록 설계되어 있으며 커맨트 유틸리티를 포함하고 있고 아날로그 읽기와 쓰기를 지원합니다.

​

WiringPi는 Pi4J와 유사한 목적을 가지는 라이브러리입니다. WiringPi는 C 및 C++ 언어를 사용하여 라즈베리 파이의 GPIO 핀을 제어하는 라이브러리입니다. WiringPi는 라즈베리 파이에서 하드웨어를 제어하기 위해 사용되는 다양한 기능과 API를 제공합니다. WiringPi 또한 오픈 소스로 개발되었으며, C와 C++ 개발자들이 라즈베리 파이를 다루는 데 도움을 주고 있습니다. WiringPi는 라즈베리 파이 커뮤니티에서 널리 사용되고 있으며, 많은 프로젝트에서 기본 GPIO 제어 라이브러리로 사용됩니다.

​

5\. 네이티브 라이브러리

Pi4J는 WiringPi 네이티브 라이브러리를 의존하고 있고 WiringPi 라이브러리 JNI 래퍼 구현하고 있습니다. WiringPi는 Pi4J 네이티브 라이브러리에 포함되어 있어서 따로 WiringPi 설치가 필요하지 않습니다. Pi4J는 WiringPi 네이티브 라이브러리를 사용하여 라즈베리 파이의 GPIO 핀을 제어합니다. WiringPi는 C와 C++로 작성된 GPIO 제어 라이브러리이며, Pi4J는 이 라이브러리를 자바에서 사용할 수 있도록 Wrapping 하고 제공합니다.

​

Pi4J는 WiringPi 라이브러리에 대한 자바 네이티브 바인딩을 제공하며, 이를 통해 자바 개발자들은 WiringPi의 기능을 자바에서 직접 사용할 수 있습니다. 이는 Pi4J가 WiringPi의 기능과 호환성을 제공하면서도 자바로 개발된 프로젝트에 더 편리한 인터페이스를 제공하는 장점을 가지고 있습니다.

​

WiringPi 네이티브 라이브러리는 라즈베리 파이의 GPIO 핀을 직접 제어할 수 있는 저수준의 기능을 제공합니다. 이 라이브러리를 사용하여 디지털 입력 및 출력, 아날로그 입력, PWM 출력, I2C, SPI, UART 등의 다양한 하드웨어 기능을 사용할 수 있습니다. WiringPi는 라즈베리 파이의 하드웨어와 밀접하게 연결되어 있으며, C나 C++로 작성된 프로젝트에서 많이 사용되고 있습니다.

​

Pi4J는 WiringPi를 자바에서 사용하기 위해 네이티브 바인딩을 제공하므로, 자바 개발자들은 WiringPi의 강력한 기능을 활용하면서도 자바 언어와 Pi4J의 편리한 API를 활용할 수 있습니다. 이를 통해 라즈베리 파이에서 자바 기반의 프로젝트를 쉽게 개발하고 관리할 수 있습니다.
