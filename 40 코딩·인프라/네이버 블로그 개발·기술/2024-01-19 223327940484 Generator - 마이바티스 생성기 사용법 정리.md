**1\. 마이바티스 생성기 개요**

마이바티스 생성기(MyBatis Generator)는 마이바티스 프레임워크를 활용한 코드 생성 도구로, 마이바티스의 모든 버전에 대한 코드를 생성하는 역할을 한다. 이 도구는 데이터베이스 테이블을 검사하고 테이블에 액세스하기 위한 자바 코드 및 구성 파일을 생성하여 개발자가 초기 설정에 들어가는 수고를 덜어준다. 

​

주로 CRUD(생성, 검색, 업데이트, 삭제)와 같은 간단한 데이터베이스 작업에 중점을 두고 있으며, 조인 쿼리나 저장 프러시저와 같은 복잡한 SQL 쿼리를 직접 코딩할 필요가 없다. 마이바티스 생성기를 통해 코드 생성의 효율을 높이고 초기 개발 작업을 간소화할 수 있다.

​

​

**2\. 마이바티스 생성기 기능**

1) 코드 생성

마이바티스 생성기는 다양한 구성 방식에 따라 다양한 스타일과 언어로 코드를 생성할 수 있다. Java 또는 Kotlin 코드를 생성할 수 있고, MyBatis3 호환 XML도 생성 가능하다. 현재는 XML이 레거시 사용으로 간주된다.

​

2) 클래스 생성

테이블 구조와 일치하는 Java 또는 Kotlin 클래스를 생성한다. 이는 테이블의 기본 키 및 일반 필드에 대한 클래스로 구성될 수 있으며, BLOB 필드가 있는 경우에도 해당 클래스를 생성한다.

​

3) SQL 생성

마이바티스 생성기는 MyBatis3 호환 SQL 맵 XML 파일을 생성할 수 있다. 이 파일에는 CRUD 작업에 필요한 다양한 SQL 문이 포함되어 있다. 예를 들면 끼워 넣기, 업데이트, 삭제, 선택 등이 있다.

​

4). 클라이언트 클래스 및 인터페이스 생성

마이바티스 생성기는 생성된 클래스를 활용하여 Java 또는 Kotlin 클라이언트 클래스, 인터페이스, Kotlin 확장 메서드 등을 생성한다. 이는 선택적으로 사용할 수 있다.

​

## 주의사항

마이바티스 생성기는 반복적인 개발 환경에서 잘 실행되도록 설계되었으며, 지속적인 빌드 환경에서 Ant 작업이나 Maven 플러그인으로 포함될 수 있다. XML 파일 이름이 기존 파일과 충돌하는 경우 MBG는 자동으로 병합하며, Java 및 Kotlin 파일에 대해서는 덮어쓰거나 새로운 파일로 저장할 수 있다.

​

Eclipse 플러그인을 사용하는 경우 Java 파일을 자동으로 병합할 수 있다. Kotlin 파일에 대해서는 MBG가 병합하지 않으므로 변경된 내용을 직접 병합해야 한다.

​
