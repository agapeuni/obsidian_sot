1\. jQuery 개요

jQuery는 JavaScript 기반의 오픈 소스 프런트엔드 라이브러리다. jQuery는 HTML 문서의 요소를 선택하고 조작하는 데 사용되며, 웹 페이지의 상호작용과 동적인 기능을 개발하는 데 사용한다. jQuery는 간결하고 직관적인 문법을 제공하여 JavaScript 코드를 더 쉽게 작성할 수 있게 해준다. 일반적으로 DOM 조작, 이벤트 처리, 애니메이션 효과, AJAX 요청 등을 간편하게 처리할 수 있다.

​

jQuery는 브라우저 간의 호환성 문제를 해결하고, 크로스 브라우징을 지원하기 위해 많은 노력을 기울였다. 이는 개발자가 다양한 웹 브라우저에서 일관된 동작을 구현할 수 있도록 도와주어 불필요한 작업을 없애준다. jQuery는 많은 웹 사이트에서 사용되고 있고, 기존 프로젝트나 레거시 코드에서 유용하게 사용하고 있다.

​

그러나 최근 몇 년간 웹 개발의 추세가 변하면서 jQuery의 인기는 상대적으로 감소했습니다. 웹 표준의 발전과 모던 브라우저의 기능 향상으로 인해 많은 기능들이 JavaScript 자체에서 제공되고 있는 것이 이유이기도 하다. 대부분의 기능을 jQuery 없이 순수 JavaScript로 구현할 수 있으며, 많은 개발자들은 jQuery를 사용하지 않고 웹 개발을 진행하고 있다. 

​

​

2\. jQuery 사용법

jQuery를 사용하기 위해 먼저 웹 페이지에 jQuery 라이브러리를 로드해야 한다. 일반적으로 다음과 같은 스크립트 태그를 HTML 문서의 `<head>` 태그나 `<body>` 태그 안에서 사용하여 로드한다. jQuery를 로드한 후에는 JavaScript 코드 내에서 `$` 기호를 사용하여 jQuery 기능을 호출할 수 있다.

<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>

jQuery는 전달된 인수를 기반으로 DOM에서 찾거나 HTML 문자열을 기준으로 일치하는 요소를 반환한다. jQuery는 다양한 기능과 메서드를 제공하며, 문서에서 자세한 정보와 예제를 찾을 수 있다. jQuery 공식 사이트에서 API 문서와 튜토리얼을 확인해 보자.

​

**2-1. jQuery( selector [, context ] )**

: expression는 String로 표현되며 특정 태그를 찾을 때 사용된다.

: context는 Element나 jQuery으로 인자 값으로 받는다.

﻿$("input:radio", document.forms[0]);﻿

**2-2. jQuery( elements )**

: DOM element(s)를 인자로 받아 jQuery 개체에 래핑한다. 

﻿$(document.body).css( "background", "black" ); $(myForm.elements).hide()

​

**2- 3. jQuery( object )**

: jQuery 개체에 래핑할 일반 개체이다.

​

​

**2-4. jQuery( html )**

: jQuery는 인자 값으로 html 태그를 받아 그 태그를 HTML 페이지에 생성한다. 

$("<div><p>Hello</p></div>").appendTo("body") $("<input/>").attr("type", "checkbox");

​

**2-5. jQuery( callback )**

: DOM이 준비되면 실행할 함수를 지정한다. 특정 이벤트가 발생할 때 그 부분을 함수로 처리하기 위해서이다. 

$(document).ready(function(){....};) $(function() { // Document is ready });
