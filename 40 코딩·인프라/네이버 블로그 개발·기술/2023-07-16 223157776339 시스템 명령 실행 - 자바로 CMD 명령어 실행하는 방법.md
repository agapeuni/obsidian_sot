# 2023-07-16 223157776339 시스템 명령 실행 - 자바로 CMD 명령어 실행하는 방법

​

자바에서 Runtime.getRuntime()을 사용하여 시스템 명령을 실행할 수 있다. Runtime 클래스의 exec() 메서드를 사용하여 원하는 명령을 실행할 수 있다. 윈도우에서 실행할 때는 명령어를 아래와 같이 command 문자열에 담아둔다. 그리고 결과값이 한글이라 InputStreamReader에 "euc-kr"로 인코딩 설정을 해두었다.

​

**SystemCommand.java**

import java.io.BufferedReader; import java.io.File; import java.io.InputStreamReader; public class SystemCommand { public static void main(String[] args) throws Exception { new SystemCommand().executeSystemCommand(); } public void executeSystemCommand() throws Exception { String command = new String("cmd.exe /C dir"); File workingDirectory = new File("C:"); // Runtime 객체를 얻는다 Runtime runtime = Runtime.getRuntime(); // 서브 프로세스인 Process 객체를 얻는다 Process process = runtime.exec(command, null, workingDirectory); // 입력 스트림을 구한다. InputStreamReader isr = new InputStreamReader(process.getInputStream(), "euc-kr"); BufferedReader br = new BufferedReader(isr); // 한 라인씩 읽어서 응용 프로그램의 표준 출력으로 보낸다 String szLine; while ((szLine = br.readLine()) != null) { System.out.println(szLine); } // 프로세스 종료 대기 int exitCode = process.waitFor(); System.out.println("\nProcess Exit Code : " + exitCode); } }

**실행 결과**

C 드라이브의 볼륨: 윈도우 볼륨 일련 번호: 1E71-F1F1 C:\ 디렉터리 2023-07-11 오전 10:45 <DIR> Program Files 2023-07-15 오후 07:39 <DIR> Program Files (x86) 2023-07-11 오전 10:45 <DIR> ProgramData 2023-07-16 오후 07:40 <DIR> Temp 2023-03-30 오후 10:17 <DIR> Users 2023-07-01 오전 03:04 <DIR> Windows 0개 파일 0 바이트 6개 디렉터리 132,097,716,224 바이트 남음 Process Exit Code : 0 

위 코드에서는 C 드라이브에서 dir 명령을 실행하는 예시를 보여준다. exec() 메서드에 실행할 명령을 전달하여 Process 객체를 생성하고 getInputStream() 메서드를 사용하여 명령 실행 결과를 읽어온다. 결과는 BufferedReader를 사용하여 한 줄씩 읽고 출력한다. 마지막으로 waitFor() 메서드를 사용하여 프로세스가 종료될 때까지 대기하고, 종료 코드를 출력한다.

​

주의할 점은 시스템 명령을 실행할 때는 보안과 안정성을 고려해야 한다. 사용자의 입력을 직접 명령에 사용하거나 외부 입력을 받아 명령으로 실행할 때는 적절한 검증과 예외 처리를 해주어야 한다. 또한, 특정 운영체제에서만 동작하는 명령을 실행할 경우 이식성에 주의해야 한다.
