# 2020-11-21 222150168974 라즈베리 파이 - ARM 6v에 Node.js 설치

## 본문

![](https://postfiles.pstatic.net/MjAyNTA5MjFfMTkz/MDAxNzU4NDQ1MjE2NDg1.pzTcmxv9LwSNTGe_PzSixrtAgwgoIqygrcfI2LrWATcg.2q6BjEexMKE6JgRtAjSr4WT-Jhrfva9rCxlqD7M81AMg.PNG/%EB%9D%BC%EC%A6%88%EB%B2%A0%EB%A6%AC-%ED%8C%8C%EC%9D%B4-001_\(5\).png?type=w80_blur)

​

라즈베리 파이 모델 B에 2020-08-20 릴리즈된 Rasberry Pi OS를 설치하고 arm6v에 구동할 수 있는 최신버전의 Node.js을 설치한다.

​

혹시 nodejs가 설치되어 있다면 아래의 명령어로 기존에 설치되어 있는 nodejs를 제거한다.

**$ sudo apt remove nodejs**

**​**

Architecture를 확인해 보니 armv6l 이다. 

**$ lscpu**

![](https://postfiles.pstatic.net/MjAyMDExMjFfMTY5/MDAxNjA1ODg2ODg2NjIy.-eH0RpcYfIu3QW7KXA1WthXETmd5Y9F3cCWnPJlCOhQg.XjoreTHzzPqQQXr-6Wqxe4hRZzNqZRIgbsMz7Ks2pUkg.PNG.agapeuni/image.png?type=w80_blur)

​

armv6l으로 설치할 수 있는 최신버전은 v11.15.0 이다.

![](https://postfiles.pstatic.net/MjAyMDExMjFfNDUg/MDAxNjA1ODg2ODU0NDkz.PDku76hAJb4h4qGab3u1fSTsZERVn1mj9y20NgZEOOAg.ca8AFfrhxC-sw59BfiDQgz6GJRApBBt0axs-5x_2tekg.PNG.agapeuni/SE-37e4d16b-57c1-469e-b072-66ca9ccebd6e.png?type=w80_blur)

​

Putty로 SSH로 접속해서 터미털 창에서 wget 명령어를 사용해 설치할 파일을 다운로드 하고 압축을 해제한다.

$ wget <https://nodejs.org/dist/v11.15.0/node-v11.15.0-linux-armv6l.tar.xz>

$ tar -xvf node-v11.15.0-linux-armv6l.tar.xz 

![](https://postfiles.pstatic.net/MjAyMDExMjFfMTY3/MDAxNjA1ODg2NjMwOTI5.851FIVYgOYX6WfjBTi2K9c3AVXkM7cXgPXE8rgk_lYog.krvlnTpPyZ6zZ7jUz4f-NtH81QKe13mdFDV_ee8TDT4g.PNG.agapeuni/image.png?type=w80_blur)

​

압축해제가 완료되면 해당 디렉토리를 /opt/nodejs 디렉토리로 옮기고 심볼릭 링크를 걸어준다.

**$ sudo mv node-v11.15.0-linux-armv6l /opt/nodejs**

**$ sudo ln -s /opt/nodejs/bin/node /usr/bin/node**

**$ sudo ln -s /opt/nodejs/bin/npm /usr/bin/npm**

**$ sudo ln -s /opt/nodejs/bin/npx /usr/bin/npx**

​

​

새롭게 설치된 node와 npm의 버전을 확인할 수 있다.

**$ node -v**

**$ npm -v**

![](https://postfiles.pstatic.net/MjAyMDExMjFfMTUz/MDAxNjA1ODg3MzI4NTIw.pBswoyx9ubeUUqwunqeaDR46zjNrzTsCl2lBaFraohkg.hrSoyvQFtoNL68cQoRIaawGForYIrbeING8oF1p_ojYg.PNG.agapeuni/image.png?type=w80_blur)

**​**

**설치한 Node.js가 정상적으로 동작하는지 테스트해 보자.**

**소스코드 : helloNode.js**

const http = require('http'); const hostname = '192.168.0.16'; const port = 3000; const server = http.createServer((req, res) => { res.statusCode = 200; res.setHeader('Content-Type', 'text/html'); res.end('<h1>Hello World</h1>'); }); server.listen(port, hostname, () => { console.log(`Server running at http://${hostname}:${port}/`); }); 

​

$ node helloNode.js
