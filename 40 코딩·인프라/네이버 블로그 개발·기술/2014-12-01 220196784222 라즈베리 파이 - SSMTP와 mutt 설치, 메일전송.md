​

이번 실험을 위해서 우선 **라즈베리 파이(Raspberry Pi)** 에 ssmtp 패키지를 설치합니다.

​

**$ sudo apt-get install ssmtp**

![](https://postfiles.pstatic.net/20150605_227/agapeuni_1433464841836xr9aW_PNG/20141201_004106.png?type=w80_blur)

아무런 문제없이 ssmtp 패키지가 성공적으로 설치되었습니다.

![](https://postfiles.pstatic.net/20150605_107/agapeuni_14334648507067MB6r_PNG/20141201_004154.png?type=w80_blur)

​

ssmtp 가 설치되고 나면 /etc/ssmtp/ssmtp.conf 파일에 아래와 같이 설정하여 둡니다. 

**$ sudo nano /etc/ssmtp/ssmtp.conf**

​

gmail을 사용하기 때문에 mailhub에 smpt.gmail.com:587 로 설정을 합니다. 

AuthUser와 AuthPass 의 값도 사용자 환경에 맞게 설정을 합니다.

# Config file for sSMTP sendmail root=postmaster mailhub=smtp.gmail.com:587 # The full hostname hostname=raspberrypi # Are users allowed to set their own From: address? # YES - Allow the user to specify their own From: address # NO - Use the system generated From: address FromLineOverride=YES # Transport Layer Security UseTLS=YES UseSTARTTLS=YES AuthUser=agapeuni7@gmail.com AuthPass=******************* AuthMethod=LOGIN﻿

![](https://postfiles.pstatic.net/20150605_266/agapeuni_1433464859110Ee5Ji_JPEG/20141201_004532.jpg?type=w80_blur)

​

그리고 나서 첨부파일 기능도 지원되고 사용하기 편리한 mutt 패키지를 설치합니다.

**$ sudo apt-get install mutt**

![](https://postfiles.pstatic.net/20150605_298/agapeuni_1433464868150CXRW5_PNG/20141201_004909.png?type=w80_blur)

​

이번에도 아무런 문제없이 성공적으로 설치가 되었습니다.

![](https://postfiles.pstatic.net/20150605_275/agapeuni_1433464877120qe6zv_PNG/20141201_005103.png?type=w80_blur)

​

사용자 디렉토리에 .muttrc 파일을 생성하고 내용을 아래와 같이 입력합니다.

**$ sudo nano .muttrc**

​

set sendmail="/usr/sbin/ssmtp"

![](https://postfiles.pstatic.net/20150605_185/agapeuni_1433464886869FayyC_PNG/20141201_005149.png?type=w80_blur)

​

다음의 명령어로 gmail과 네이버에 메일을 발송합니다. 

내용은 "Content" 로 제목은 "[Title] Hello ~" 로 하여 메일을 보냅니다.

​

형식> **echo "메일 본문" | sudo mutt -s "메일제목" <이메일>**

​

echo "Content" | sudo mutt -s "[Title] Hello 1" agapeuni7@gmail.com

echo "Content" | sudo mutt -s "[Title] Hello 2" agapeuni7@gmail.com

echo "Content" | sudo mutt -s "[Title] Hello 3" agapeuni@naver.com
