# 2025-07-29 223951385347 Ollama 설치 - Windows에 설치하는 방법

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223951385347&categoryNo=982
- 게시일: 2025. 7. 29. 17:19

## 본문

![](https://postfiles.pstatic.net/MjAyNjA1MTdfMTk2/MDAxNzc4OTkzNDIwMTA2.q6PilThw9XItAoF5oRwyRCfYYE0SLeK_zOoef7Re-z8g.68aPSH7JvIIBrwm4ttbJn9610QHlvfjBUPwnsTyuUBIg.PNG/%EA%B0%9C%EB%B0%9C%ED%99%98%EA%B2%BD-001.png?type=w80_blur)

​

최근 qwen, gemma, deepseek 등 다양한 LLM(Large Language Model)이 인기를 끌고 있다. 

이러한 모델을 손쉽게 실행할 수 있는 도구로 Ollama가 주목받고 있다. 

​

Ollama는 인터넷 연결 없이도 AI 모델을 실행할 수 있어, 

보안이 중요한 업무 환경에서도 활용도가 높다.

​

Windows 환경에서 Ollama를 설치하고 모델을 적용하는 방법을 단계별로 살펴보자.

​

1\. Ollama 다운로드

우선 Ollama 공식 웹사이트에 접속하여 설치 파일을 내려받는다. 

<https://ollama.com/>

![](https://postfiles.pstatic.net/MjAyNjAzMjhfMTg3/MDAxNzc0NjkyNjkwMjc2.L_iiKDYeoXXtiuEc30UbetI6nULzvR5Qw6wwAuNP_LUg.JmEQYN6xJknIfNE8LPpWOgDe8TiKrV5jT8cBjemrRLkg.PNG/20260328_175931.png?type=w80_blur)

[Download for Windows] 버튼을 클릭하면 설치 프로그램이 다운로드된다. 

현재 기준으로 안정화된 버전이 자동으로 제공되며, 별도의 추가 설정 없이 바로 실행 가능하다. 

​

**설치 파일 : OllamaSetup.exe**

![](https://postfiles.pstatic.net/MjAyNjAzMjhfMzMg/MDAxNzc0NjkyMjQ4NTYy.pBqpArOp67dcdX-Wa89fCmNga8cV2AWb4s3ikILLNIMg.KNYQp4YAliqBMDHbA5LNffAXJgJD_53z0-HwcUt7RCMg.PNG/20260328_170614.png?type=w80_blur)

2\. Ollama 설치

다운로드가 완료되면 설치 파일(OllamaSetup.exe)을 실행한다. 일반적인 Windows 설치 마법사 방식으로 구성되어 있으며, 별도의 복잡한 옵션 없이 다음 > 다음 > 설치 버튼을 클릭하는 것만으로 설치가 완료된다. 

![](https://postfiles.pstatic.net/MjAyNjAzMjhfMyAg/MDAxNzc0NjkyMjcwNTI1.FEiU6ttaIUI1zgfeK2IzL7mPMrPzcRNLpczA0zPuKzUg.Y5Dh1-sCSh46h8_AIbaz2LdEf9-cNkMmlm0Q1CwOrGIg.PNG/20260328_170655.png?type=w80_blur)

설치가 완료되면 Ollama를 바로 사용할 수 있다.

  * 이후 → 로컬에서 바로 실행

5\. Ollama API 

Ollama 프로그램이나 브라우저 직접 호출은 제한적이다.

Ollama는 단순 도구가 아니라 로컬 LLM API 서버로 이해해야 한다.

​

Ollama 공식 API 사이트에 가면 Endpoint 별로 내용이 잘 정리되어 있다.

하나씩 실해보면서 결과를 확인해 보면 쉽게 이해할 수 있다.

![](https://postfiles.pstatic.net/MjAyNjAzMjhfMjUw/MDAxNzc0NjkyNjc4NzMx.gz3hBMBQ3eDojWFbIdDM1jyPCKqTAnJTUJadkiFMK5Ag.JHar9qyC5yFiWlkTqRku9OJm1wRoGl52FUaBQxEAqlUg.PNG/20260328_172922.png?type=w80_blur)

6\. 자주 쓰이는 명령어

명령어 |  설명  
---|---  
ollama list |  설치된 모델 목록 확인  
ollama pull _[모델명]_ |  공식 저장소에 있는 모델을 로컬에 다운로드  
ollama run _[모델명]_ |  모델 실행 및 채팅  
ollama show _[모델명]_ |  모델에 대한 자세한 정보를 확인  
ollama ps |  실행 중인 모델 확인  
ollama stop _[모델명]_ |  실행 중인 특정 모델을 중지  
ollama rm _[모델명]__​_ |  더 이상 사용하지 않는 모델을 삭제.  
ollama create [커스텀 모델명] -f Modelfile |  사용자 정의 모델 생성

**7\. 정리**

Ollama는 아래와 같은 경우에 유용하게 사용할 수 있다.

  * 데이터 기반 AI 활용 (RAG, Agent 등)

  * 외부 API 없이 로컬에서 AI 실행

  * 보안이 중요한 환경에서의 LLM 활용

​

이상으로 Windows 환경에서 Ollama를 설치하고 기본적인 방법을 살펴보았다. 

Ollama는 로컬에서 개인화된 AI 환경을 구축하고자 할 때 아주 유용하다. 

​
