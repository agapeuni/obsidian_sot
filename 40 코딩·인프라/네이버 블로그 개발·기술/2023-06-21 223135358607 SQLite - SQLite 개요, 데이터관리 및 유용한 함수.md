**1\. SQLite 개요**

SQLite는 오픈 소스 관계형 데이터베이스 관리 시스템(RDBMS)으로서, 아이폰이나 안드로이드 같은 모바일 환경뿐 아니라 데스크톱 운영체제의 응용프로그램에서도 많이 사용된다. 

​

SQLite는 파일기반 관계형 데이터베이스이며 소형 및 중규모 애플리케이션에 적합한 경량의 데이터베이스 엔진이다. Richard Hipp가 개발한 SQLite는 퍼블릭 도메인에 배포되는 C 라이브러리로 제공되며, 모바일 애플리케이션, 임베디드 시스템, 웹 브라우저, 데이터 분석 도구 등 다양한 환경에서 사용된다.

​

​

**2\. SQLite 특징**

SQLite는 단일 사용자 및 작은 규모의 애플리케이션에 적합한 경량 데이터베이스 솔루션으로, 데이터 저장 및 관리를 위한 간단하고 효율적인 방법을 제공한다.

​

1) 경량 및 자체 포함

SQLite는 외부 종속성이 없는 단일 파일 기반의 데이터베이스로서, 라이브러리를 애플리케이션과 함께 배포하거나 설치할 필요가 없다. 이는 SQLite를 특히 모바일 및 임베디드 환경에서 사용하기에 이상적으로 만든다.

​

2) 서버 없음

SQLite는 클라이언트-서버 아키텍처가 아닌 내장형 데이터베이스 엔진으로 동작한다. 애플리케이션에서 직접 SQLite 라이브러리를 사용하여 데이터베이스 파일에 액세스하고 쿼리를 실행할 수 있다.

​

3) 크로스 플랫폼

SQLite는 모든 주요 운영 체제(Windows, macOS, Linux 등)에서 작동한다. 이는 개발자들이 다양한 환경에서 동일한 코드를 사용하여 애플리케이션을 개발할 수 있게 해준다.

​

4) SQL 호환성

SQLite는 ANSI SQL 표준을 따르며, 대부분의 SQL 기능을 지원한다. 데이터 정의, 데이터 조작, 쿼리 작성 등을 위한 SQL 문을 사용하여 SQLite 데이터베이스를 조작할 수 있다.

​

5) 트랜잭션 지원

SQLite는 ACID(원자성, 일관성, 고립성, 지속성) 특성을 지원하는 트랜잭션을 제공한다. 이를 통해 데이터의 무결성과 일관성을 유지할 수 있다.

​

참고로 SQLite 엔진의 버전이 올라가면서 아래의 기능이 제공된다.

\- SQLite에서 View는 읽기 전용이다.

\- Sqlite의 읽기/쓰기 권한은 OS 파일 시스템 권한을 사용한다.

\- 테이블 변경시 "RENAME TABLE"과 "ADD COLUMN" 명령이 가능하다.

\- "DROP COLUMN", "ALTER COLUMN", "ADD CONSTRAINT" 등은 지원하지 않는다.

\- LEFT OUTER JOIN 만 지원하며 "RIGHT OUTER JOIN"이나 "FULL OUTER JOIN"은 사용불가

**4\. System Catalog 확인**

테이블이나 인덱스 같은 DB객체의 정보 다른 말로 메타데이터를 조회하는 방법을 먼저 정리해 본다.

​

SQLITE_MASTER 테이블

시스템 카탈로그를 조회할 수 있는 테이블로 테이블, 인덱스, 트리거 등 스키마 확인과 DDL문 확인이 가능하다.

SELECT * FROM SQLITE_MASTER;

​

**PRAGMA 명령어**

  * PRAGMA table_info( table-name ); -- 테이블 정보를 조회하는 명령어다.

  * PRAGMA index_list( table-name ); -- 인덱스 리스트를 볼 수 있다.

  * PRAGMA index_info( index-name ); -- 인덱스 정보를 조회할 수 있다.

  * PRAGMA foreign_key_list( table-name ); -- fk 리스틀 볼 수 있다.

**5\. 유용한 함수**

coalesce(X,Y,Z, ...)

함수는 중에서 첫 번째로 Null 아닌 값을 리턴하는 함수.

모든 인자가 이면 Null을 리턴한다.

​

ifnull(X,Y) - 오라클의 NVL(X,Y)

첫 번째로 Not Null인 인자값을 리턴합니다.

둘 다 null 이면 null을 리턴.

​

length(X)

길이값을 리턴하는 함수

​

upper(X), lower(Y)

대/소 문자로 변환하는 함수.

​

ltrim(X)

X 값 중 왼쪽편의 공백을 제거하는 함수

​

ltrim(X,Y)

X 문자열중에서 Y에 나타난 값을 제일 좌측부터 제거하는 함수

​

max(X,Y,Z....)

인자값들 중 최댓값을 리턴.

​

min(X,Y,Z....)

인자값들 중 최솟값을 리턴합니다

​

nullif(X,Y)

두 인자가 서로 같으면 nul 다르면 X 값을 리턴

nullif('x','y') 는 ‘x’ 반환 nullif('x','x') nul 반환

​

Quote()

함수는 single quotation을 escape (‘’로 변경) 한다. Insert 나 update 시에 사용하면 유용.

select quote("girl's mouse") => 'girl''s mouse'

​

random(*)

-9223372036854775808부터 + 9223372036854775807 숫자 사이의 임의의 수를 리턴

​

replace(X, Y, Z)

X 문자열 중에서 Y문자열을 Z로 변경

select replace('1/12/2009','1','x') => "x/x2/2009"

​

round(X)

반올림 함수. Round(3.5) => 4

​

round(X, Y)

Y는 소수점 자릿수 round(2.555, 2) => 2.56

​

substr(X, Y, Z)

X문자열 중에서 Y 번째부터 시작해서 Z개수만큼 문자열을 가져오는 함수. Z 가 생략되면 Y 번째 문자열부터 문자열 끝까지 리턴한다. Y의 최소 값은 1 (자바에서는 0)

select substr("string", 1, 3) => str

select substr("string", 0, 3) => st

select substr("string", -1, 3) => g

select substr("string", -3, 3) => ing

select substr("string", 2) => tring

​

typeof(X)

X 표현식에 대한 데이터 타입 (“null”, “integer”, “real”,“text ”, “blob”)을 반환

​

​

**6\. Aggregation Function (집합 함수)**

avg(X)

Not Null 값의 평균값을 리턴한다.

X 칼럼값이 문자열이나 BLOB 이면 0으로 간주하고 처리함.

​

count(X)

X칼럼이 Not Null 값을 가지는 레코드의 개수 반환한다.

​

group_concat(X)

X가 not null인 경우 그룹 내의 모든 문자열을 콤마 (,)를 구분자로 해서 문자열을 합쳐서 반환한다.

​

group_concat(X,Y)

Y 값이 구분자로 사용하여 문자열을 합한 후 리턴한다.

​

max(X)

그룹 내의 값들 중 최댓값을 리턴.

​

min(X)

그룹 내의 값들 중 최솟값을 리턴한다.

모든 값이 Null이면 Null을 리턴.

​

sum(X), total(X)

그룹 내의 값의 합계를 리턴한다.

모든 값이 Null 인 경우 Sum()은 Null Total()은 0.0을 반환한다.

**7\. DateTime**

1) Keyword

CURRENT_DATE : 현재 날짜 (형식 :2010 -08 25) UTC 기준

SELECT CURRENT_TIME, CURRENT_DATE;

time(timestring, modifier, modifier, ...)

julianday (timestring, modifier, modifier, ...) 율리우스력 함수

strftime(format, timestring, modifier, modifier, ...) 날짜 포맷팅 함수
