Spring 프레임워크와 Apache POI 라이브러리를 사용하여 엑셀 다운로드를 구현한다. 엑셀 템플릿을 미리 만들어 놓고 데이터를 기록하여 다운로드하는 방식이다. 이를 위해 먼저 Spring 웹 애플리케이션 프로젝트를 설정해야 한다.

​

**1\. Spring 프로젝트 설정**

Spring Boot 프로젝트를 생성하거나 기존의 Spring 프로젝트에 의존성을 추가한다.

Maven을 사용한다면 pom.xml 파일에 다음 의존성을 추가한다.

<dependency> <groupId>org.springframework.boot</groupId> <artifactId>spring-boot-starter-web</artifactId> </dependency> <dependency> <groupId>org.apache.poi</groupId> <artifactId>poi</artifactId> <version>5.0.0</version> </dependency>

​

**2\. ExcelView 작성**

\- AbstractExcelView 클래스를 상속받는다.

\- buildExcelDocument를 오버라이드 한다. 

​

​

**3\. ExcelView 설정**

\- url에 엑셀 템플릿을 DI 한다. 

<bean id="codeListExcelView" class="com.interactivy.hshop.admin.views.excel.code.CodeListExcelView"> <property name="url" value="/WEB-INF/excel/codeList" /> </bean>

**4\. MultiActionController 작성**

\- Excel View를 DI 한다.

\- Excel View로 조회 결과 리스트와 검색 조건을 넘긴다.

/** * 코드 리스트 엑셀 View */ private View codeListExcelView; public void setCodeListExcelView(View codeListExcelView) { this.codeListExcelView = codeListExcelView; } /** * 공통코드 리스트를 엑셀로 다운로드합니다. */ public ModelAndView listExcelView(HttpServletRequest request, HttpServletResponse response) throws Exception { Code code = new Code(); bind(request, code); String keyfield = code.getKeyfield(); if (keyfield != null && StringUtils.hasLength(keyfield)) { createWhere(code); } List<Code> codeList = codeFacadeImpl.getCodeList(code); ModelAndView mav = new ModelAndView(codeListExcelView); mav.addObject("codeList", codeList); mav.addObject("code", code); return mav; }

​

**5\. Controller 설정**

<bean id="findCodeController" class="com.interactivy.hshop.admin.web.code.FindCodeController"> <property name="methodNameResolver" ref="ssmFindPropsResolver" /> <property name="codeFacadeImpl" ref="codeFacade" /> <property name="codeListExcelView" ref="codeListExcelView" /> </bean>

****

**6\. resolver 설정**

<!-- 멀티 액션 --> <bean id="ssmFindPropsResolver" class="org.springframework.web.servlet.mvc.multiaction.PropertiesMethodNameResolver"> <property name="mappings"> <props> <!-- code --> <prop key="/code/codeList.do">list</prop> <prop key="/code/codeListExcel.do">listExcelView</prop> </props> </property> </bean> <!-- 세션 체크 --> <bean id="ssmAuthURLMapping" class="org.springframework.web.servlet.handler.SimpleUrlHandlerMapping"> <property name="interceptors"> <list> <ref bean="authenticationInterceptor" /> </list> </property> <property name="mappings"> <props> <!-- Code --> <prop key="/code/addCode.do"> addCodeFormController </prop> <prop key="/code/editCode.do"> editCodeFormController </prop> <prop key="/code/codeList.do"> findCodeController </prop> </props> </property> </bean>
