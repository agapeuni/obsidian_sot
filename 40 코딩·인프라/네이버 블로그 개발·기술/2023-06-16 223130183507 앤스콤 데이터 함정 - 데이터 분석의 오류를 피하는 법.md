1\. 앤스콤 데이터 함정(Anscombe's Quartet)

앤스콤 데이터 함정(Anscombe's Quartet)은 데이터 시각화와 통계 분석의 중요성을 강조하기 위해 만들어진 예시 데이터 세트다. 이 데이터 세트는 1973년에 프랭크 앤스콤(Francis Anscombe)이 제시한 것으로, 네 개의 데이터 세트가 각각 다른 X와 Y 변수 사이의 관계를 가지고 있음에도 불구하고, 그래프로 표현할 때 거의 유사한 회귀선과 통계적 요약 수치를 가지고 있다는 특징을 보여준다. 이는 데이터를 분석할 때 단순한 통계량만을 보고 결론을 내리게 될 때 발생할 수 있는 오류를 보여주는 사례로 사용된다.

​

3\. 시각화

seaborn 라이브러리에서 anscombe 데이터셋을 가져온다. 

anscombe 데이터셋에서 그룹 I 에서 그룹 IV 까지 별도의 데이터셋으로 담아둔다.

import seaborn as sns anscombe = sns.load_dataset("anscombe") ds_1 = anscombe[anscombe['dataset'] == 'I'] ds_2 = anscombe[anscombe['dataset'] == 'II'] ds_3 = anscombe[anscombe['dataset'] == 'III'] ds_4 = anscombe[anscombe['dataset'] == 'IV'] 

​

matplotlib 라이브러리를 사용하여 4개의 그룹을 시각화한다. 

4개의 subplot을 만들고 그룹별로 데이터를 지정한다.

import matplotlib.pyplot as plt plt.rc('font', family='NanumGothic') fig = plt.figure() fig.tight_layout() axes1 = fig.add_subplot(2, 2, 1) axes2 = fig.add_subplot(2, 2, 2) axes3 = fig.add_subplot(2, 2, 3) axes4 = fig.add_subplot(2, 2, 4) axes1.plot(ds_1['x'], ds_1['y'], 'o') axes2.plot(ds_2['x'], ds_2['y'], 'o') axes3.plot(ds_3['x'], ds_3['y'], 'o') axes4.plot(ds_4['x'], ds_4['y'], 'o')
