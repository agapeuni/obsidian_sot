# 2023-07-21 223162083066 한글 입력 오류 - 한글 입력시 자음과 모음이 분리되는 현상

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223162083066&categoryNo=982
- 게시일: 2023. 7. 21. 5:38

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTBfMjIy/MDAxNzQ0MjI0NDY4MDE1.7h1jSP4TwjzUC87nZU8etZ-YRZF2WRIJXRoR4y_7CnYg.yQpXWOs_6HeB17e7Af-ZGp8xroH4OoXgJRAbMLycsAYg.PNG/%EC%9C%88%EB%8F%84%EC%9A%B0-001_\(1\).png?type=w80_blur)

​

1\. 문제(Problem)

윈도우에서 작업하다 보면 어느 순간 한글을 입력할 때 아래와 같이 자음과 모음이 분리되는 현상이 발생한다. 

​

> ㅇㅣㅂㄹㅕㄱㅇㅣ ㅇㅣㅅㅏㅇㅎㅏㄷㅏ. (입력이 이상하다.)

> ㅁㅜㄴㅈㅔㄱㅏ ㅂㅏㄹㅅㅐㅇ (문제가 발생)

​

2\. 원인(Cause)

위와 같은 형상이 발생되는 것은, 작업하다가 우연하지 않게 Win + H 키를 눌러서 음성 인식 기능이 작동해서 그렇다. 한국어는 지원하지 않는다고 메시지가 표시된다. 그리고 "Microsoft Text Input Application"이 실행되면서 한글 입력 시 자음과 모음이 분리되는 현상이 발생한다. 

![](https://postfiles.pstatic.net/MjAyMzA3MjFfMjI0/MDAxNjg5ODg0OTI3ODUw.lBsQ3plGKEfNtUAYgoCGd2pI8dFz7S7obCQIJuRQrFcg.bPTmN9NFH49up16yz-wmdhxwFdOEuOdme7dA8WML2Fkg.PNG.agapeuni/image.png?type=w80_blur)

​

3\. 해결(Solution)

다행히 키보드 문제가 아니라 프로그램 문제였다. 해당 프로그램을 멈추면 해결이 된다. 

​

Ctrl + Alt + Del 키를 누르고 "작업 관리자"를 선택하거나 Ctrl + Shift + Esc 키를 눌러 "작업 관리자"를 실행한다. 그리고 " Microsoft Text Input Application" 프로세스를 찾아 우측 클릭하여 "작업 끝내기"를 실행하면 문제가 해결된다.
