​

전송하는 데이터양이 증가하면 증가할수록, 통신 비용은 증가합니다. 데이터양이 계속 증가하는 IoT 시스템에 대해, 통신 비용도 증가하는 경향에 있습니다. 거기서 중요한 것이, 엣지 측에서 수집한 데이터를 어떠한 형식으로 서버의 클라우드 측에 송신하는가입니다.

​

일반적으로 자주 사용되는 데이터 형식은 이전에 설명한 바와 같이 "CSV" "XML" "JSON"으로, 각각 다음과 같은 특징이 있습니다.

​

● CSV: 값을 쉼표(,)로 구분한 데이터로, 매우 간결하게 할 수 있으므로 고속으로 데이터 처리할 수 있는 것이 특징입니다. 그러나, 값을 쉼표로 나누는 것뿐이므로, 구조화된 데이터를 취급할 수 없습니다. 단순하게, 센서 디바이스의 값만을 전송하게 됩니다.

​

● XML: XML은 마크업 언어이며, 구조화된 데이터를 표현할 수 있어서 데이터를 유연하게 처리할 수 있습니다. 그러나, 센서 디바이스의 값 데이터 이외에, 구조화를 위한 태그 데이터가 필요하게 되어, 파일 크기가 커지게 됩니다.

​

● JSON: CSV와 XML의 중간에 위치하는 데이터 형식입니다. 구조화된 데이터를 표현할 수 있지만, XML과 비교하면 단순하여서, XML 만큼 파일 크기가 커지지 않습니다. 가장 단순한 CSV 형식만큼 작게는 되지 않지만, 구조화된 데이터를 가지고 있어서, 최근 IoT 시스템에서는 JSON 형식을 채택하는 일이 늘고 있습니다.
