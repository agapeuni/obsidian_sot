# 챗GPT_이미지_프롬프트모음

## 문서 내용

챗GPT 이미지 2 활용법 16가지 — 프롬프트 모음 by 스마트대디

사용 방법

1. 각 번호의 프롬프트를 복사한다

2. ChatGPT ‘이미지’를 선택한다.

3. 필요한 항목(종목명, 상호명, 주제 등)만 본인 상황에 맞게 수정한다

4. 이미지 생성을 요청한다

5. 결과물 확인 후 수정이 필요하면 대화형으로 "여기 이 부분만 이렇게 바꿔줘"로 요청한다

6. 조사가 필요한 항목은 Thinking 모드 선택 후 진행

수정 요청 팁 (공통)

생성 결과물을 수정할 때는 다음 방식으로 요청하면 가장 정확하다.

• 위치 명시: "상단 로고 부분만", "오른쪽 카드만", "3번째 컷의 대사만"

• 변경 대상 명시: "색상", "텍스트 내용", "배치", "폰트 크기"

• 변경 후 상태 명시: "파란색으로", "가격을 69,000원으로", "세로 4컷을 2x2로"

좋은 수정 요청 예시:

• "상단 로고 색상을 파란색에서 초록색으로 바꿔줘"

• "우측 카드의 가격을 89,000원에서 69,000원으로 바꾸고, 할인률도 46%로 수정"

• "배치를 세로 4컷에서 2x2 그리드로 재배치"

Thinking 모드 활용 가이드

Thinking 모드를 쓰면 다음 기능이 추가된다.

• 실시간 자료 조사 (오늘 주가, 최신 뉴스, 실제 제품 정보)

• 작품·인물·사건 상세 조사 (드라마, 인물, 웹툰 배경)
