**Java 프로젝트 구합니다.**

​

**\-- SKILL 별 단가(단위:만 원) --**

아래의 기본사항은 필수항목이며 그 이외의 항목은 선택입니다. 

기본사항과 선택사항은 1달을 기준으로 단가를 책정하고 나머지는 책정된 단가를 기준으로 합니다.

​

업주들께서는 사전에 충분히 검토하시고 반드시 필요한 스킬만 선택하셔서 합리적인 지불 금액을 산출하시기 바랍니다.

사용한 만큼 지불하는 클라우드 환경처럼, 지불한 금액만큼의 기술을 지원해 드리고 있습니다.

​

**지급되지 않은 항목은 프로젝트 진행시 절대(!) 도와드릴 수 없음을 사전에 알려드립니다.**

**프로젝트 진행중에 추가하실 경우에는 프로젝트 착수일 기준으로 산정됨을 양해하시기 바랍니다.**

![](https://blogimgs.pstatic.net/sticker/pc/moon_high_school_memories/original/10.png)

**\- 기본사항 -**

1\. 자바 (JAVA/JSP/Servlet) : 300 만원 ※ 자바는 기본 API 사용을 전제합니다.

2\. JavaScript, jQuery 기본기능 : 60 만 원 

3\. JavaScript, jQuery 고급기능 : 120 만 원

4\. Angular, React, Vue.Js : 150 만 원

5\. 위젯이나 플러그인 추가 시 난이도에 따라 금액이 청구됩니다. (상 : 100 만원, 중 : 70 만원, 하 : 40 만원)

6\. 데이터베이스 (SQL만 작성) : 50 만 원

7\. 데이터베이스 (프러시저, 트리거, 패키지) : 70 만 원

8\. 데이터베이스 마이그레이션 : 테이블당 기본 10만원 + 데이터 건당 1,000원

​

월 단위 기본금액으로 익월 5일 전까지 입금해 주셔야 합니다. 

입금일 이후에는 12% 이자 발생. 30일 초과시 내용증명과 함께 바로 소송들어갑니다.

​

​

![](https://blogimgs.pstatic.net/sticker/pc/moon_high_school_memories/original/40.png)

**\- 선택사항 -**

1\. Struts / Spring / MyBatis / Hibernate : 100만 원

2\. Oracle / Mysql / Mssql (SQL 튜닝) : 50만 원

3\. PI (마이플랫폼 / TF / 가우스) : 50만 원

4\. Flex / Ajax / Silverlight : 80만 원

5\. 시스템 안정화 및 VOC 대응 : 50만 원

6\. 배치, 인터페이스 1건당 : 30만 원 ※ 단, ERP 인터페이스는 RFC 방식으로만 가능

선택사항의 합계가 200만 원 이상일 때는 월에 야근 2회(2시간) 정도 서비스해 드립니다. 

단, 프로젝트 기간이 4개월 이상일 경우에 해당되며 기간이 4개월 미만인 경우에는 에누리 없이 칼퇴근입니다.

​

주의, 실제 야근의 경우에는 정상근무 기준 시간당 금액에서 1.2배 적용합니다. 

그리고 식사와 교통비를 일일 1만 5천 원으로 경비처리합니다. 금요일은 2만 원입니다.

​

![](https://blogimgs.pstatic.net/sticker/pc/moon_high_school_memories/original/29.png)

**\- 단계별 산출물 -**

1\. 워드, 아래한글 페이지 단가 : 0.5만 원

2\. 파워포인트 페이지 단가 : 0.5만 원 ※ 임원 보고나 발표용 자료는 페이지 당 1만 원

3\. 엑셀 페이지 단가 : 0.5만 원

4\. 사용자/운영자 매뉴얼 페이지 단가 : 1 만 원 

5\. 데이터베이스 모델링 엔터티 단가 : 0.3 만 원

​

기작성된 문서의 현행화나 일부 수정도 같은 단가로 적용됩니다.

단계별 산출물이 감리를 받아야 하는 경우에나 야근 시간에 작업시 상기 금액에서 2배로 증가됩니다. 

![](https://blogimgs.pstatic.net/sticker/pc/moon_high_school_memories/original/20.png)

**\- 고급 서비스 -****​**

1\. 아키텍처 구성 : 사이트 규모에 따라 협의

2\. 보안/운영 컨설팅 : 사이트 규모에 따라 협의

3\. 클러스터링/이중화 : 사이트 규모에 따라 협의 

4\. 클라우드 전환 : 사이트 규모에 따라 협의 

​

고급 서비스에서 2가지 이상 선택하시면 협의한 금액에서 20% DC 가능합니다.

협의 금액을 2배로 하시면 작업기간을 절반으로 단축해드립니다. 

​

![](https://blogimgs.pstatic.net/sticker/pc/moon_high_school_memories/original/21.png)

**\- 일반 서비스 -**

1\. WAS : TOMCAT/JEUS/WEBLOGIC/JBoss 내에서 어떤 제품 사용해도 무관

이외의 WAS인 경우는 30만 원 추가. (범용적인 WAS인 경우에 한함)

​

2\. DB : Oracle/MS-SQL/MySQL/MariaDB - 2회 백업 무료 서비스

2회 초과 시 1회당 단가 : 20만 원

​

3\. Report : OZ / Report Deginer에 한해서 2본 무료 서비스

2본 초과 시 1본당 단가 : 10만 원

​

![](https://blogimgs.pstatic.net/sticker/pc/moon_high_school_memories/original/14.png)
