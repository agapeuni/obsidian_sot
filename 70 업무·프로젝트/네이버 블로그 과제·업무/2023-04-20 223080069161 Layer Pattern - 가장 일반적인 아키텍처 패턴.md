# 2023-04-20 223080069161 Layer Pattern - 가장 일반적인 아키텍처 패턴

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223080069161&categoryNo=1123
- 게시일: 2023. 4. 20. 11:52

## 본문

![](https://postfiles.pstatic.net/MjAyNTAyMTZfMTUg/MDAxNzM5NjY5NTE1MjMw.Yf2o0AwEORpEnzt7e6seJsqk4rkWg7h-aDaC7PhaTuEg.NOoUS52O3Ew9d9U6KwgMxY4N5gj_jap4lL3FMR-ZsvYg.PNG/%EC%95%84%ED%82%A4%ED%85%8D%EC%B2%98-001.png?type=w80_blur)

​

Layer로 계층화된 패턴이 가장 일반적인 아키텍처 패턴으로 소프트웨어 시스템을 계층으로 나누어 구성하는 패턴이다. 대부분의 Java 애플리케이션의 표준으로 널리 알려져 있다. 보통 Presentation Layer, Business Layer, Persistence Layer 그리고 Database로 관심사를 분리하여 나눈다. 

​

각 계층은 서로 다른 역할을 수행하며, 계층 간의 상호작용은 일반적으로 각 계층에서 다음 계층으로만 진행된다. 이 패턴은 시스템을 더욱 모듈화하고 유연하게 만들어주며, 시스템의 일부분을 수정해도 다른 부분에 영향을 미치지 않도록 보장한다. 

​

![](https://postfiles.pstatic.net/MjAyMzA0MjBfMjc4/MDAxNjgxOTU4OTY1MDQ4.PjGnch6moaL-oY01ykAm3a8xOTJrgzl2XzMd9Ex2zPwg.y6IIn1RnACGF8XKCNbZ2atqh23cw_XNQxYocnWDRBF4g.PNG.agapeuni/img.png?type=w80_blur)

**​**

**1\. Presentation Layer**

최상위 계층으로 주로 화면을 담당하는 부분이다. 응용프로그램의 프런트 엔드 부분으로 HTTP 요청을 처리하거나 인증을 수행한다. 화면을 통하여 사용자로부터 입력을 받거나, 사용자에게 정보를 보여주는 역할을 담당한다.

* 요구되는 기술 사항은 다음과 같다.

\- 화면 구성요소를 표시

\- 화면 구성요소를 배치

\- 화면으로부터 받은 명령을 처리

\- 화면 컨트롤의 이벤트를 처리

\- 다른 Layer에게 입력받은 명령이나 데이터를 전달

​

**​**

**2\. Business Logic Layer**

비즈니스 로직이 포함되며 서비스 클래스로 구성되어 있다. 사용자로부터 전달받은 입력을 주어진 로직에 따라 처리를 담당한다. 유효성 검사 및 권한 부여를 담당하는 등의 작업을 처리하는 로직을 비즈니스 로직이라 한다.

* 요구되는 기술 사항은 다음과 같다.

\- 하나의 로직 상태를 여러 화면과 공유

\- 유효성 검사 및 권한 부여를 담당 

\- Persistence Layer에 데이터를 주고받는 방법

​

**​**

**3\. Persistence Layer**

지속성 계층에는 데이터베이스 스토리지가 포함된다. 비즈니스 개체를 데이터베이스에 영구적으로 저장하거나, 저장된 장소에서 데이터를 가져오는 역할을 담당한다. 

* 요구되는 기술 사항은 다음과 같다.

\- 데이터를 파일이나 데이터베이스에 저장, 수정, 삭제

\- 데이터베이스에 연결하고 연결을 유지하는 방법

​

**​**

**4\. Database Layer**

데이터베이스 계층에는 MariaDB, MongoDB 등과 같은 모든 데이터베이스가 포함된다. CRUD - Create(생성), Read(읽기), Update(갱신), Delete(삭제) - 작업 수행을 담당한다.

* 요구되는 기술 사항은 다음과 같다.

\- DBMS, NoSQL 관리 시스템

\- 데이터 백업 및 복원

**​**

**5\. Integration Layer**

애플리케이션이 다른 부분과 연동하거나, 통신을 할 필요가 있을 경우, 이에 대한 처리를 담당하는 부분이다. 단독으로 실행하는 애플리케이션일 경우에는 해당 Layer가 있을 필요 없다.

* 요구되는 기술 사항은 다음과 같다.

\- 통신 방법과 통신 프로토콜

\- 분산 객체 호출 방법

\- 비동기로 외부 시스템에 전달
