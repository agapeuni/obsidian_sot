​

신규 프로젝트를 진행할 때 명명규칙을 확인하는 것은 좋은 습관이다. 명명규칙은 코드, 파일, 폴더, 변수, 함수, 클래스 등과 같은 요소들에 대한 이름을 일관되고 명확하게 정의하는 규칙이다. 프로젝트를 시작하기 전에 미리 확인해 두고 처음부터 잘 적용해 나가는 것이 좋다.

​

이름은 가급적 약어로 사용하지 말고 누구나 쉽게 알 수 있도록 한다.

​

*** Table 이름**

TB_W3C_ADMIN_TERM

TB_W3C_ADMIN_TERM_DETAIL

​

​

*** Query Id**

subsystem.module.pagename.function

ex) 

w3c.admin.term.list

w3c.admin.term.save

w3c.admin.term.insert

w3c.admin.term.update

w3c.admin.term.delete

​

*** SQL id**

nameSpace.selectTerm

nameSpace.selectTermById

nameSpace.countTerm

nameSpace.insertTerm

nameSpace.updateTerm

nameSpace.deleteTerm 

​

​

*** Naming Rule**

JSP 이름과 Java, Table까지 이름에 일관된 규칙을 둔다.

​

/jsp/w3c/admin/termList.jsp

/jsp/w3c/admin/termDetail.jsp

/jsp/w3c/admin/termOpenPop.jsp

w3c.admin.controller.TermController

w3c.admin.dao.TermDao

w3c.admin.dao.TermDaoImpl

w3c.admin.model.Term

w3c.admin.service.TermService

w3c.admin.service.TermServiceImpl

​

​

*** Java Package Name**

controller

dao 

model / domain / entity

service

web / ui

​

*** JavaScript**

select, insert, update, delete를 알 수 있는 메서드 이름을 사용한다.

​

listTerm() -> select

findTerm() -> select

findTermById() -> select

​

createTerm() -> insert 

modifyTerm() -> update 

removeTerm() -> delete

*** SELECT 메서드 이름**

listComment()

createComment()

*** UPDATE 메서드 이름**

modifyComment()

*** DELETE 메서드 이름**

removeComment()

​

*** Event 메서드 이름**

onCreate()

onStart()

onRestart()

onResume()

onPause()

onStop()

onDestory()

*** ETC 메서드 이름**

hitComment() 

goPage()

​

*** JavaScript Style Guide**

<http://google-styleguide.googlecode.com/svn/trunk/javascriptguide.xml>

*** 도메인 기반 파라미터**

DAO에서부터 UI 까지 객체 타입으로 전달하여 계층 간의 독립성을 보장하라.

UI, Controller, Service, Dao

​

*** MVC**

C = NameController

S = NameService / NameServiceImpl

D = NameDao / NameDaoImpl

V = NameVO

​

​

*** 연속적인 번호**

권한이나 페이지 번호를 부여할 때 간격을 충분히 준다. 

xx10, xx20으로 사용하면 나중에 xx15를 사이에 추가할 수 있다.

​

​

*** Message Id**

module.msg.fuction.name

​

ex) 

w3c.msg.admin.email.fail=메일이 오류입니다.

w3c.msg.user.course.reject=반려하시겠습니까?

*** Page Id**

module.msg.fuction.name

​

ex)

w3c.page.user.label.no=번호
