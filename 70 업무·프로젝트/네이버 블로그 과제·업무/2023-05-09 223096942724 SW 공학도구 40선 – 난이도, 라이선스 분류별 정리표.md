# 2023-05-09 223096942724 SW 공학도구 40선 – 난이도, 라이선스 분류별 정리표

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTNfMjMg/MDAxNzQ0NDc3MTM5Njcx.OhUwKgVLFasRrkcOhaEZnqi_AcIpF1V-2vg3RTLwIDAg.V7hc-GgH7w4jttRVwTEcAoBq0sVjA9ty_FYNWOYwgOog.PNG/%EC%86%8C%ED%94%84%ED%8A%B8%EC%9B%A8%EC%96%B4_%EA%B3%B5%ED%95%99-001.png?type=w80_blur)

​

SW 공학도구(Software Engineering Tools)는 소프트웨어 개발 과정에서 사용되는 도구로, 소프트웨어 개발을 보다 쉽고 효율적으로 진행할 수 있도록 지원한다. SW 공학도구는 다양한 종류가 있다. 일반적으로는 요구 분석, 설계, 코딩, 테스트, 디버깅, 관리 등의 과정을 지원하는 도구들을 말한다. 

​

SW 공학도구는 프로젝트에서 작업 중인 모든 팀의 생산성을 증가시킨다. 생산성은 중요한 요소이다. 같은 시간에 더 많은 작업을 처리할수록 비즈니스에 더 많은 이익이 발생한다. SW 공학도구와 유용한 앱을 통해 생산성이 뛰어난 프로젝트에서 함께 작업할 수 있다. 대표적인 SW 공학도구로는 Microsoft Visual Studio, Eclipse, IntelliJ IDEA, JIRA, Git 등이 있다. 

​

![](https://postfiles.pstatic.net/MjAyMzA1MDlfMjYy/MDAxNjgzNTc0MDQ2NDgx.gLE1dCAh3hDOwmopsEAba3Dw7AF1LI7XADIu_tAgvCgg.xnzrmPjcbP5s4Yz8ji_dXZw-v8Lzga0BMBZFkPQyjA4g.PNG.agapeuni/img.png?type=w80_blur)

​

1\. 요구 분석 도구

요구 분석 도구는 고객의 요구사항을 수집하고 분석하여 요구사항 명세서를 작성하는 데 사용된다. 요구사항 명세서는 개발자들이 개발에 필요한 요구사항을 정확히 이해할 수 있도록 돕는다.

​

2\. 설계 도구

설계 도구는 시스템 아키텍처를 설계하고 설계 문서를 작성하는 데 사용된다. 이러한 도구는 다양한 시스템 아키텍처와 디자인 패턴을 제공하며, 개발자들이 좀 더 구체적으로 구현할 수 있도록 돕는다.

​

3\. 코딩 도구

코딩 도구는 개발자가 소스 코드를 작성하고 편집할 수 있는 도구이다. 이러한 도구는 코드 작성에 필요한 문법 검사, 자동 완성, 디버깅 등의 기능을 제공한다.

​

4\. 테스트 도구

테스트 도구는 개발된 소프트웨어가 요구사항을 만족시키고 예상대로 작동하는지 확인하는 데 사용된다. 이러한 도구는 단위 테스트, 통합 테스트, 성능 테스트 등을 수행할 수 있다. 

​

5\. 디버깅 도구

디버깅 도구는 개발자가 소스 코드에서 발생한 오류를 찾아 수정하는 데 사용된다. 이러한 도구는 변수 값 추적, 스택 추적, 중단점 설정 등의 기능을 제공한다.

​

6\. 관리 도구

관리 도구는 개발 프로젝트를 관리하는 데 사용된다. 이러한 도구는 프로젝트 일정, 리소스 할당, 이슈 관리, 협업 도구 등의 기능을 제공한다.

​
