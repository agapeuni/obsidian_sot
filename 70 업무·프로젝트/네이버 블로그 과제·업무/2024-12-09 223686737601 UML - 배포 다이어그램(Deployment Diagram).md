# 2024-12-09 223686737601 UML - 배포 다이어그램(Deployment Diagram)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223686737601&categoryNo=1123
- 게시일: 2024. 12. 9. 7:30

## 본문

![](https://postfiles.pstatic.net/MjAyNTA0MTdfMTQw/MDAxNzQ0ODIzNTEzMjQ2.1LY6uUqF9BeInam41KugzxKW-_CuNGXRRub23lnq8j8g.CsTkLSt1sxfefvbB-0BWJx6kVcZMU_ybNE-qrheLtxkg.PNG/%EC%84%A4%EA%B3%84_%EB%AA%A8%EB%8D%B8%EB%A7%81-001_\(1\).png?type=w80_blur)

​

배포 다이어그램은 소프트웨어 시스템의 물리적 배포를 시각적으로 표현하며, 하드웨어 노드와 소프트웨어 구성 요소 간의 관계를 나타내는 데 사용된다. 소프트웨어 시스템의 물리적 배포와 실행 환경을 이해하는 데 유용하며, 시스템의 성능, 확장성, 유지 보수성을 설계하고 최적화하는 데 도움을 준다.

​

​

**1\. Node**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfNyAg/MDAxNzMzNjYzMDMzMzE2.n8Wr2PoaX_r1rHOclk2xdVKA6PzJYqukznqJ-gPdt4Eg.TmY4S0JQDi4tGICsJ6ChWImEiltkj_0mJDi-a-JZQ9sg.PNG/img.png?type=w80_blur)

  * **설명** : 물리적 장치나 실행 환경을 나타낸다. 노드는 서버, 클라이언트 컴퓨터, 모바일 장치 등과 같은 하드웨어 또는 가상 머신, 컨테이너 환경을 포함한다.

  * **예시** : "웹 서버", "데이터베이스 서버", "클라이언트 디바이스".

**​**

**​**

**2\. Component**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfMTM1/MDAxNzMzNjYzMDM2ODg2.WOxLfi8RASM2unqju4D-caSUddSQImqr33JnfUM1viMg.RsFwLJslWjb2EsSXRfsC51M2mDvhpAYzBRD8rAD7zeIg.PNG/img.png?type=w80_blur)

  * **설명** : 소프트웨어의 실행 가능한 단위를 나타낸다. 컴포넌트는 특정 노드에 배포되어 실행되며, 응용 프로그램, 서비스, 모듈 등을 포함한다.

  * **예시** : "웹 애플리케이션", "API 서비스", "데이터베이스 관리 시스템".

**​**

**​**

**3\. Link**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfMjE4/MDAxNzMzNjYzMDUzMjE1.IlzgXOjFh56RpKOaKqKU8qxxQnYViIPzsJ_Bd8WL6QIg.GtnOl9Et5fItqJqmIJWorNWs5IwCyAqGy3KiK-abaUUg.PNG/img.png?type=w80_blur)

  * **설명** : 노드 간의 연결을 나타내며, 데이터의 전송 경로나 네트워크 연결을 의미한다. 링크는 소프트웨어 구성 요소가 서로 통신할 수 있도록 지원한다.

  * **예시** : "클라이언트와 웹 서버 간의 HTTP 연결", "웹 서버와 데이터베이스 서버 간의 TCP/IP 연결".
