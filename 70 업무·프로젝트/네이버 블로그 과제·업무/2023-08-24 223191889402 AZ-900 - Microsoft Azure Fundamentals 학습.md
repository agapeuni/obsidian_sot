시험 Azure-900은 인프라 관리, 데이터베이스 관리 또는 소프트웨어 개발 등 IT 영역에서 작업한 기술과 경험을 필요로한다.

  * 클라우드 개념에 대해 설명(25~30%)

  * Azure 아키텍처 및 서비스 설명(35~40%)

  * Azure 관리 및 거버넌스 설명(30~35%)

​

**클라우드 개념에 대해 설명(25~30%)**

**1) 클라우드 컴퓨팅 설명**

  * 클라우드 컴퓨팅 정의

  * 공동 책임 모델 설명

  * 퍼블릭, 프라이빗 및 하이브리드를 포함한 클라우드 모델 정의

  * 각 클라우드 모델에 대한 적절한 사용 사례 식별

  * 사용량 기반 모델 설명

  * 클라우드 가격 책정 모델 비교

  * 서버리스 설명

​

**2) 클라우드 서비스 사용의 이점 설명**

클라우드의 고가용성 및 스케일링 성능의 이점 설명

클라우드의 안정성 및 예측 가능성의 이점 설명

클라우드의 보안 및 거버넌스의 이점 설명

클라우드에서 관리 효율성의 이점 설명

​

**3) 클라우드 서비스 유형 설명**

IaaS(서비스 제공 인프라) 설명

PaaS(Platform as a Service) 설명

SaaS(Software as a service) 설명

각 클라우드 서비스(IaaS, PaaS, SaaS)에 대한 적절한 사용 사례 식별

​

​

**Azure 아키텍처 및 서비스 설명(35~40%)**

**1) Azure의 핵심 아키텍처 구성 요소 설명**

  * Azure 지역, 지역 쌍 및 소버린 지역 설명

  * 가용성 영역 설명

  * Azure 데이터 센터 설명

  * Azure 리소스 및 리소스 그룹 설명

  * 구독 설명

  * 관리 그룹 설명

  * 리소스 그룹, 구독 및 관리 그룹의 계층 구조 설명

​

**2) Azure 컴퓨팅 및 네트워킹 서비스 설명**

  * 컨테이너, 가상 머신 및 함수를 포함한 컴퓨팅 유형 비교

  * Azure Virtual Machines 

  * Azure Virtual Machine Scale Sets 

  * Azure Virtual Desktop을 포함한 가상 머신 옵션 설명

  * 가상 머신에 필요한 리소스 설명

  * 웹앱, 컨테이너, 가상 머신을 포함하여 애플리케이션 호스팅 옵션 설명

  * Azure Virtual Networks, Azure 가상 서브넷, Azure DNS

  * VPN Gateway 및 ExpressRoute의 목적을 포함하여 가상 네트워킹 설명

  * 퍼블릭 및 프라이빗 엔드포인트 정의

​

**3) Azure Storage 서비스 설명**

  * Azure Storage 서비스 비교

  * 스토리지 계층 설명

  * 중복성 옵션 설명

  * 스토리지 계정 옵션 및 스토리지 유형 설명

  * AzCopy, Azure Storage Explorer 및 Azure 파일 동기화 포함하여 파일을 이동하기 위한 옵션 식별

  * Azure Migrate 및 Azure Data Box를 비롯한 마이그레이션 옵션 설명

​

**4) Azure ID, 액세스 및 보안 설명**

  * Microsoft Entra의 일부인 Azure AD(Azure Active Directory) 

  * Azure AD DS(Azure Active Directory Domain Services)를 포함한 Azure의 디렉터리 서비스 설명

  * SSO(Single Sign-On), MFA(다단계 인증) 및 암호 없는 인증을 비롯한 Azure의 인증 방법 설명

  * B2B(Business-to-Business) 및 B2C(Business-to-Customer)를 비롯한 Azure의 외부 ID 설명

  * Azure AD의 조건부 액세스 설명

  * Azure RBAC(역할 기반 액세스 제어) 설명

  * 제로 트러스트 개념 설명

  * 심층 방어 모델의 목적 설명

  * 클라우드용 Microsoft Defender의 목적 설명

​

​

**Azure 관리 및 거버넌스 설명(30~35%)**

**1) Azure의 비용 관리 설명**

  * Azure의 비용에 영향을 줄 수 있는 요인 설명

  * 가격 계산기와 TCO(총 소유 비용) 계산기 비교

  * Azure의 비용 관리 기능 설명

  * 태그 용도 설명

​

**2) 거버넌스 및 규정 준수를 위한 Azure의 기능 및 도구 설명**

  * Azure에서 Microsoft Purview의 목적 설명

  * Azure Policy의 목적 설명

  * 리소스 잠금의 목적 설명

​

**3) Azure 리소스 관리 및 배포용 기능과 도구 설명**

  * Azure Portal 설명

  * Azure CLI(명령줄 인터페이스) 및 Azure PowerShell을 포함하여 Azure Cloud Shell 설명

  * Azure Arc의 목적 설명

  * IaC(Infrastructure as Code) 설명

  * ARM(Azure Resource Manager) 및 ARM 템플릿 설명

​

**4) Azure의 모니터링 도구 설명**

  * Azure Advisor의 목적 설명

  * Azure Service Health 설명

  * Log Analytics, Azure Monitor 경고

  * Application Insights를 비롯한 Azure Monitor 설명
