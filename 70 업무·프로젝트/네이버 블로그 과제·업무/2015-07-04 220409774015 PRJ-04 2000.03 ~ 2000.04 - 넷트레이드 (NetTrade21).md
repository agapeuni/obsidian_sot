**어셈블리 개발자에서 웹 프로그래머로**

어셈블리와 비주얼C++로 시스템 프로그램을 개발하다가 인터넷 회사로 이직한 후, 웹 프로그래밍을 시작하다. 그 당시 닷컴 기업들이 빠르게 성장하던 시기였으며, 대부분의 기업들이 웹사이트를 구축하기 시작하였다. 인터넷 열풍의 초창기였기에, 프로그래밍이라기보다는 인터넷 자료와 서적을 참고하여 기존 코드를 확장하는 방식으로 개발을 진행하였다.

**BASIC을 배우고 ASP로 웹사이트를 만들다**

넷트레이드 프로젝트에서 사용한 ASP 언어는 마이크로소프트에서 발표한 웹 기술로, 웹사이트를 구축하는 데 매우 유용한 언어였다. 이전에 BASIC 언어를 학습했기 때문에 ASP 문법은 크게 어려운 부분이 없었으나, 데이터베이스와 연계하여 적용하는 방법은 새롭게 배워야 했다. 다행히 인터넷에는 참고할 수 있는 자료들이 많았기 때문에 기능 구현에 어려움은 없었다.

**데이터를 손수 만들어 구축한 글로벌 웹사이트**

아래는 직접 개발한 NetTrade 홈페이지의 모습이다. "View Offer" 화면에서 나라를 선택하고 "Offer to Sell"이나 "Offer to Buy"를 진행하며, 상세 입력 페이지에서 필요한 상품이나 관련 정보를 입력하면 선택한 국가별로 정보를 공유할 수 있었다. 이 사이트는 전 세계를 대상으로 했으나 일부 국가에서만 사용된 것으로 기억된다.

​

![](https://postfiles.pstatic.net/20150704_40/agapeuni_1435942600362S4BXE_PNG/20150704_015537.png?type=w966)

​

아래 화면은 대륙별 국가 정보를 제공하는 화면이다. 페이지 기능 구현보다는 나라별 코드 부여와 데이터베이스에 데이터를 생성하는 데 시간이 더 소요되었다. 당시에는 데이터가 부족했기에 필요한 정보는 직접 만들어서 사용해야 했다. 지금은 데이터를 많이 공유하고 있어 재사용 환경이 마련되었지만, 당시에는 자료나 정보가 제한적이었다.
