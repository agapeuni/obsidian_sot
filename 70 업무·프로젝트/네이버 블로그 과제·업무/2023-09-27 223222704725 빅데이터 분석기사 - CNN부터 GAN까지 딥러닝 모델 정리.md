# 2023-09-27 223222704725 빅데이터 분석기사 - CNN부터 GAN까지 딥러닝 모델 정리

## 본문

​

1\. CNN(Convolutional Neural Network)

CNN은 "Convolutional Neural Network"의 약자로, 컴퓨터 비전 작업을 위해 개발된 인공 신경망의 한 유형이다. CNN은 주로 이미지 분류, 객체 감지, 얼굴 인식 등의 비전 작업에 사용되며, 데이터의 공간적 구조를 고려하여 효과적으로 작동한다.

​

CNN은 훈련 과정에서 역전파 알고리즘을 사용하여 가중치를 조정하며 데이터로부터 패턴을 학습한다. 이러한 구조는 이미지 및 비전 작업에서 매우 효과적이며, 딥러닝 분야에서 매우 중요한 역할을 한다. CNN 아키텍처에는 다양한 변형과 최적화 기법이 있으며, 이를 조합하여 특정 작업에 맞는 최상의 모델을 개발할 수 있다.

![](https://postfiles.pstatic.net/MjAyMzA5MjJfMTUg/MDAxNjk1MzEzMTU2MTY1.M_7ZrB3_DD9akub4pu-a_s7u4pSp-3y214JdyRu5GuEg.6FehDaMqYiqi4t0mmABrhtY_fjmQrMECVqU-C5dmWZ4g.PNG.agapeuni/image.png?type=w80_blur)

[출처] <https://saturncloud.io/blog/a-comprehensive-guide-to-convolutional-neural-networks-the-eli5-way/>

​

**1) 합성곱 층 (Convolutional Layer)**

이 층은 입력 이미지와 필터(커널) 사이의 합성곱 연산을 수행한다. 이 작업은 입력 이미지의 작은 부분 영역에 필터를 슬라이딩하면서 특징 맵(Feature Map)을 생성한다. 이 특징 맵은 이미지의 다양한 시각적 특징을 담고 있다.

​

**2) 활성화 함수 (Activation Function)**

일반적으로 합성곱 층 뒤에는 비선형 활성화 함수로 ReLU (Rectified Linear Unit)를 사용한다. 이 함수는 음수 값을 0으로 만들어 네트워크가 비선형성을 학습하도록 돕는다.

​

**3) 풀링 층 (Pooling Layer)**

풀링은 특징 맵의 크기를 줄이는 역할을 한다. 일반적으로 최대 풀링(Max Pooling)이 사용되며, 특징 맵에서 최댓값을 추출하여 작은 크기의 특징 맵을 생성한다. 이로써 계산량이 감소하고 공간적 계층 구조를 유지한다.

​

**4) 완전 연결 층 (Fully Connected Layer)**

풀링 층 이후에는 하나 이상의 완전 연결 층이 온다. 이 층은 이미지의 특징을 기반으로 최종 출력을 생성한다. 주로 분류 문제를 위한 소프트맥스 활성화 함수가 사용된다.

​

**5) 출력 층 (Output Layer)**

출력 층은 모델의 최종 예측을 수행한다. 분류 문제의 경우 클래스에 대한 확률 분포를 출력하며, 회귀 문제의 경우 연속적인 값을 출력할 수 있다.

​

​

2\. RNN(Recurrent Neural Network)

RNN은 "Recurrent Neural Network"의 약자로, 순차적인 데이터를 처리하는 데 사용되는 인공 신경망의 한 종류다. RNN은 이전의 입력 데이터와 현재 입력 데이터를 함께 고려하여 순차 데이터에서 패턴을 학습하고 시퀀스 예측 및 생성과 같은 작업에 유용하다. RNN은 자연어 처리 (NLP), 음성 인식, 시계열 예측 등과 같은 분야에 사용된다.

​

하지만 RNN에는 장기 의존성 문제가 있어서 시퀀스가 길어질수록 그 성능이 감소할 수 있다. 이를 해결하기 위해 LSTM(Long Short-Term Memory) 및 GRU(Gated Recurrent Unit)와 같은 변형 RNN 아키텍처가 개발되었다. 현재는 변형된 RNN 구조가 더 효과적인 시퀀스 모델링을 위해 주로 사용되고 있다.

![](https://postfiles.pstatic.net/MjAyMzA5MjZfMTM4/MDAxNjk1NzA1NzQ0MTI2.atCnAtwiB5xaGsyiW8D0KE81kMjaIKutKQMds6EJpaQg.1sm0HWpgDIiLgxw-xJYbNg-hH5LaMDwGOUF7785-I4Qg.JPEG.agapeuni/SE-367bb73f-1823-40d2-93fc-3529a3f31c1f.jpg?type=w80_blur)

[출처] <https://www.geeksforgeeks.org/introduction-to-recurrent-neural-network/>

**1) 순환 구조**

RNN은 순환 구조를 가지고 있으며, 현재 입력 데이터뿐만 아니라 이전 타임 스텝(시간 단계)의 출력 데이터를 다음 타임 스텝의 입력으로 사용한다. 이렇게 함으로써 RNN은 이전 정보를 유지하면서 순차 데이터를 처리한다.

​

**2) 가중치 공유**

RNN의 각 타임 스텝에서 사용되는 가중치는 동일하다. 이것은 네트워크가 순차 데이터에서 발생하는 패턴을 학습하는 데 도움이 된다.

​

**3) 시퀀스 길이**

RNN은 다양한 시퀀스 길이를 처리할 수 있으며, 고정된 입력 크기가 필요하지 않는다. 이것은 자연어 처리(NLP)와 같은 다양한 응용 분야에서 유용하다.

​

​

3\. LSTM(Long Short-Term Memory)

LSTM은 "Long Short-Term Memory"의 약자로, RNN (Recurrent Neural Network)의 한 변형으로 장기 의존성 문제를 해결하기 위해 개발된 인공 신경망 아키텍처이다. LSTM은 시퀀스 데이터를 처리하고 시간에 따라 발생하는 패턴을 학습하는 데 특히 유용하다.

​

LSTM은 RNN과 달리 장기 의존성을 보다 효과적으로 처리할 수 있도록 설계되었다. RNN은 긴 시퀀스에 대한 정보를 계속해서 가지고 있지 못하거나 기울기 소실 문제로 인해 학습이 어려울 수 있다. 이에 반해 LSTM은 다음과 같은 주요 구성 요소를 통해 이러한 문제를 극복한다.

​

LSTM은 자연어 처리(NLP) 작업, 음성 처리, 시계열 예측 및 기타 시퀀스 모델링 작업에서 주로 사용된다. LSTM의 덕목 중 하나는 긴 시퀀스에 대한 정보를 효과적으로 처리할 수 있으며, 장기 의존성을 가진 시퀀스 데이터를 모델링 하기에 적합하다는 점이다. 그 외에도 LSTM의 변형 모델이 개발되어, 더 복잡한 시퀀스 모델링 문제에 대응하고 있다. 예를 들어, 양방향 LSTM (Bidirectional LSTM)은 양방향으로 시퀀스를 처리하여 문맥을 더 잘 이해하는 데 도움을 준다. 스택 된 LSTM 층을 사용하여 더 깊은 시퀀스 모델을 구축할 수도 있다.

![](https://postfiles.pstatic.net/MjAyMzA5MjJfNDAg/MDAxNjk1MzE0MDM2NTM1.qeScDgMefB8NPbPEx4UvagCDBMHkPtUoYj0yiAh-7Acg.9L79FxAxkUsfMisysNfHCHaQx3ju-0pqsciMtQN-9Ckg.JPEG.agapeuni/lstm-architecture-768x532.jpg?type=w80_blur)

[출처] <https://databasecamp.de/en/ml/lstms>

**1) 셀 상태 (Cell State)**

LSTM은 셀 상태를 사용하여 정보를 오랫동안 유지합니다. 셀 상태는 시간을 거치면서 정보가 추가되고 제거된다. 이를 통해 모델이 장기 의존성을 학습하고 오랫동안 기억할 수 있다.

​

**2) 게이트 (Gate) 메커니즘**

LSTM은 게이트를 사용하여 셀 상태의 정보를 제어합니다. 세 가지 주요 게이트가 있다.

\- Forget Gate : 어떤 정보를 삭제하고 어떤 정보를 유지할지를 결정한다.

\- Input Gate : 어떤 정보를 현재 셀 상태에 추가할지를 결정한다.

\- Output Gate : 현재 셀 상태를 기반으로 다음 타임 스텝의 출력을 계산한다.

​

**3) 활성화 함수**

LSTM 셀 내부에서 시그모이드 함수와 tanh 함수를 사용하여 게이트를 제어하고 셀 상태를 업데이트한다.

​

​

4\. GRU (Gated Recurrent Unit)

GRU (Gated Recurrent Unit)는 순환 신경망(RNN)의 한 유형으로, 장기 의존성 문제와 기울기 소실 문제를 해결하기 위해 개발된 변형 RNN 아키텍처 중 하나이다. GRU는 LSTM (Long Short-Term Memory)과 유사한 목적을 가지고 있으며, 시퀀스 데이터를 처리하고 모델이 더 장기적인 의존성을 학습할 수 있도록 돕는다.

​

GRU는 자연어 처리 (NLP)와 시계열 데이터 분석과 같은 시퀀스 모델링 작업에서 주로 사용된다. LSTM과 비슷한 역할을 하지만 모델 크기와 학습 시간 면에서 더 효율적일 수 있다. GRU와 LSTM 중 어떤 것을 선택할지는 주어진 작업과 데이터에 따라 다를 수 있으며, 두 모델을 실험적으로 비교하여 최적의 결과를 얻는 것이 일반적이다.

![](https://postfiles.pstatic.net/MjAyMzA5MjJfODcg/MDAxNjk1MzE0ODQxOTY3.0CkqWGYqoDYqhaBKUUvGPNLV7dguiVYe8IjN8H5cWJQg.usTviMa8G3kvL277IzINg0oMWQRr3DVUjkhXNxoF64Ug.PNG.agapeuni/RNN-vs-LSTM-vs-GRU-1024x308.png?type=w80_blur)

[출처] <http://dprogrammer.org/rnn-lstm-gru>

**1) 게이트 메커니즘**

GRU는 LSTM과 마찬가지로 게이트 메커니즘을 사용하여 정보의 흐름을 제어한다. GRU에는 두 가지 게이트가 있다.

\- 업데이트 게이트 (Update Gate) : 업데이트 게이트는 현재 정보를 얼마나 업데이트할지를 결정합니다. 이를 통해 모델은 이전 정보를 유지하거나 새로운 정보로 업데이트할 수 있다.

\- 리셋 게이트 (Reset Gate) : 리셋 게이트는 이전 타임 스텝의 은닉 상태와 현재 입력을 얼마나 혼합할지를 결정한다.

​

**2) 은닉 상태 (Hidden State)**

GRU는 LSTM과 달리 LSTM 셀에서 별도의 셀 상태와 은닉 상태를 유지하지 않고 단일 은닉 상태만을 사용한다. 이 은닉 상태는 현재 입력과 이전 타임 스텝의 은닉 상태를 기반으로 계산된다.

​

**3) 기울기 소실 문제 완화**

LSTM과 비교하여 GRU는 게이트 메커니즘을 더 간단하게 사용하기 때문에 기울기 소실 문제를 완화할 수 있다. 이로 인해 GRU는 더 빠르게 학습하거나 더 간단한 모델로 장기 의존성을 캡처할 수 있다.

​

​

5\. Autoencoder

딥러닝 Autoencoder는 데이터의 차원 축소와 특징 추출에 사용되는 인공 신경망 아키텍처 중 하나다. Autoencoder는 비지도 학습 방법으로, 입력 데이터를 낮은 차원의 잠재 공간으로 매핑하고 다시 원래 입력 데이터로 재구성하는 방법을 학습한다. 이렇게 하면 데이터의 주요 특징을 추출하고 노이즈를 제거하는 데 사용될 수 있다. Autoencoder는 다양한 응용 분야에서 활용될 뿐만 아니라, 다른 딥러닝 모델의 초기 가중치로 사용하여 전이 학습(Transfer Learning)에도 활용된다.

​

Autoencoder는 데이터 압축, 노이즈 제거, 차원 축소, 특징 추출 등 다양한 응용 분야에서 사용된다.

**1) 차원 축소 (Dimensionality Reduction)**

Autoencoder는 고차원 데이터를 저차원 잠재 공간으로 매핑하여 데이터의 중요한 특징을 보존하면서 데이터의 차원을 줄일 수 있다.

​

**2) 노이즈 제거 (Noise Reduction)**

Autoencoder는 입력 데이터에 노이즈가 추가된 경우 이를 제거하고 원래 데이터를 복원하는 데 사용된다.

​

**3) 이미지 생성 (Image Generation)**

Variational Autoencoders (VAEs)와 같은 Autoencoder의 변형은 이미지 생성에 사용되며, 새로운 이미지를 생성하는 데 활용된다.

​

**4) 희소 표현 (Sparse Representation)**

Autoencoder를 통해 데이터를 희소하게 표현하고 중요한 특징만을 강조할 수 있다.

​

**5) 특징 추출 (Feature Extraction)**

Autoencoder는 데이터에서 중요한 특징을 학습하고, 이러한 특징을 다른 머신 러닝 모델에 입력으로 제공하는 데 사용된다.

Autoencoder의 주요 구성 요소와 작동 방식은 다음과 같다.

​

**1) 인코더 (Encoder)**

인코더는 입력 데이터를 저차원의 잠재 공간 (latent space) 표현으로 인코딩한다. 

인코더는 주로 다층 신경망 (MLP)으로 구성되며, 입력 데이터를 저차원 벡터로 매핑하는 함수를 학습한다.

​

**2) 디코더 (Decoder)**

디코더는 인코더에서 얻은 저차원 잠재 표현을 다시 원래 입력 데이터로 디코딩 한다. 

디코더도 다층 신경망으로 구성되며, 저차원 표현을 원래 차원으로 확장하는 함수를 학습한다.

​

**3) 손실 함수 (Loss Function)**

Autoencoder는 입력 데이터와 디코더의 출력 간의 차이를 최소화하도록 훈련된다. 

일반적으로 평균 제곱 오차 (Mean Squared Error, MSE)와 같은 손실 함수를 사용하여 재구성 오차를 최소화한다.

6\. GAN은 "Generative Adversarial Network"

GAN은 "Generative Adversarial Network"의 약자로, 생성 모델링을 위한 딥러닝 아키텍처 중 하나이다. GAN은 2014년에 Ian Goodfellow와 그의 동료들에 의해 소개되었으며, 생성된 데이터가 실제 데이터와 거의 구별할 수 없도록 학습하는 데 중점을 둔다는 점에서 독특하다. GAN은 생성 모델링 작업에서 주로 사용되며, 이미지, 음성, 텍스트 등 다양한 유형의 데이터를 생성하는 데 활용된다.

​

GAN은 학습 도중 모드 붕괴와 같은 문제에 직면할 수 있으며, 학습이 불안정할 수 있다. 그러나 이러한 어려움을 극복하기 위해 다양한 GAN 아키텍처 및 학습 기술이 개발되었으며, GAN 기반의 생성 모델링은 딥러닝 분야에서 매우 중요한 연구 주제이다.

​

GAN은 다양한 응용 분야에서 사용된다.

  * 이미지 생성 : GAN은 고품질 이미지 생성에 사용된다. 얼굴 이미지 생성, 조각적인 그림 생성, 스타일 변환 등이 포함된다.

  * 스타일 변환 : 스타일 GAN (StyleGAN)과 같은 변형은 이미지의 스타일을 변경하거나 합성하는 데 사용된다.

  * 음성 합성 : GAN은 음성 합성 및 음성 변환 작업에 사용된다.

  * 데이터 증강 : GAN은 데이터 증강을 위해 사용되며, 훈련 데이터를 다양하게 확장하는 데 도움을 줍니다.

  * 의료 이미지 생성 : 의료 영상 데이터 생성 및 증강을 위해 GAN이 활용된다.

**1) 생성자 (Generator)**

생성자는 랜덤 한 잡음 벡터나 다른 형태의 입력을 받아 실제 데이터와 유사한 가짜 데이터를 생성하는 역할을 한다. 생성자는 주로 딥러닝 신경망으로 구성되며, 학습을 통해 데이터 분포를 모델링하고 실제 데이터와 유사한 출력을 생성하도록 훈련된다.

​

**2) 판별자 (Discriminator)**

판별자는 생성자가 생성한 가짜 데이터와 실제 데이터를 구별하는 역할을 한다. 판별자는 또한 딥러닝 신경망으로 구성되며, 가짜 데이터와 실제 데이터 간의 차이를 식별하도록 훈련된다.

​

**3) 적대적 학습 (Adversarial Training)**

GAN의 핵심 아이디어는 생성자와 판별자가 서로 경쟁하면서 학습하는 것이다. 생성자는 판별자를 속이도록 노력하고, 판별자는 생성자에서 생성된 가짜 데이터를 가능한 한 실제 데이터와 구별하도록 노력한다. 이 과정은 적대적인 학습으로서 두 네트워크가 서로를 개선하게 되며, 생성자는 점점 실제 데이터와 유사한 데이터를 생성하게 된다.
