# 2024-12-09 223686725145 UML - 시퀀스 다이어그램(Sequence Diagram)

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=223686725145&categoryNo=1123
- 게시일: 2024. 12. 9. 3:30

## 본문

![](https://postfiles.pstatic.net/MjAyNDEyMDhfMjAx/MDAxNzMzNjYxODg1NzMw.1bZrFmUILk9-b_2H-AF8HexhjRimE6RBJrQka8zma18g.Fq4Nj6SZIiAUACAiCdGTUaXOclaSRT98Idn5MU9iBIcg.PNG/%EC%84%A4%EA%B3%84_%EB%AA%A8%EB%8D%B8%EB%A7%81-001_\(3\).png?type=w80_blur)

**​**

시퀀스 다이어그램은 시스템 내에서 객체들 간의 상호작용을 시간의 흐름에 따라 시각적으로 표현하는 도구다. 객체들 간의 상호작용을 시간 순서대로 표현하여, 시스템의 동작을 직관적으로 이해할 수 있도록 돕는다. 이를 통해 설계 단계에서 복잡한 프로세스를 명확히 하고, 개발자와 이해관계자 간의 의사소통을 원활하게 할 수 있다.

​

​

**1\. Object**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfMjUg/MDAxNzMzNjYyMjc4NDY1.A7muabEP8SQVE4AlghXHimeBaxkKupiFwz6AACHU67sg.30c3-Op_-Jch_W6h81xdOdjpmAwb-Caj2DQPcRDPxNkg.PNG/img.png?type=w80_blur)

  * **설명** : 시퀀스 다이어그램에서 특정 역할이나 기능을 수행하는 엔터티를 나타낸다. 객체는 시스템의 구성 요소로서, 다른 객체와 메시지를 주고받는다.

  * **예시** : "사용자", "로그인 시스템", "데이터베이스"와 같은 엔터티.

**​**

**​**

**2\. Focus of Control**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfMTU1/MDAxNzMzNjYyMjgxNjQx.MHOhCYiYySrkf46xQNmo2CACRBFjXim4EpDBFTaw-8og.tUxNJjAKxlh24uye8eZEhrNmw-jbAmUyvUB8IDmwx48g.PNG/img.png?type=w80_blur)

  * **설명** : 특정 객체가 실행 중임을 나타내는 요소로, 직사각형으로 표현된다. 이는 객체가 작업을 수행하는 동안의 기간을 나타낸다.

  * **예시** : "사용자 인증" 중 로그인 시스템의 작업 기간.

**​**

**​**

**3\. Life Line**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfODgg/MDAxNzMzNjYyMjkxODM3.iI0bvvq_3EhxnL5LCucg7HmQbIC1AxsoS6zqC52Ma9Ig.BF04GtV9dNCchDAOJVju2n9g7GdZnYfW97lfO-MatBsg.PNG/img.png?type=w80_blur)

  * **설명** : 객체의 생명 주기를 나타내며, 객체가 존재하고 있는 동안의 타임라인을 수직선으로 표현한다.

  * **특징** : 객체가 메시지를 주고받거나 작업을 수행하지 않는 동안도 생명선은 유지된다.

  * **예시** : "사용자"와 "로그인 시스템" 간의 상호작용 동안 각 객체의 생명선.

**​**

**​**

**4\. Message**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfMjIx/MDAxNzMzNjYyMjk1ODcw.8Z2ueanGYHLl-6GEaGsk5qI6KL_x0SOkvIIhbnapI3Ug.6iReCkKENuhI9a4R5zuf6-5NdPbK-KoNQSEJQPz9NgQg.PNG/img.png?type=w80_blur)

  * **설명** : 객체 간의 통신을 나타내며, 요청이나 호출을 표현한다. 메시지는 화살표로 표현되고, 요청의 내용이 함께 적힌다.

  * **예시** : "로그인 시스템"이 "데이터베이스"에 데이터를 조회하는 요청 메시지.

**​**

**​**

**5\. Return**

![](https://postfiles.pstatic.net/MjAyNDEyMDhfODQg/MDAxNzMzNjYyMjk4MTUy.nxwTT2i1VoumtEqAucmCVzTg_Om-pO0w1eUZ-Qiv-Ccg.9xSwCge7Capogw4EkcHVn-X8_yYACQs0yf4ph60CwHUg.PNG/img.png?type=w80_blur)

  * **설명** : 요청에 대한 응답을 나타내며, 메시지에 대한 결과나 데이터를 반환할 때 사용된다. 반환 메시지는 점선 화살표로 표현된다.

  * **예시** : "데이터베이스"가 "로그인 시스템"에 조회 결과를 반환하는 과정.
