테이블의 Logical 명이 한글일 경우 PK생성시 명칭이 한글로 생성되므로 확인해보고 사용하자.

**1\. Database > Pre & Post Scripts > Table-Level...**

![](https://postfiles.pstatic.net/MjAyMzA3MDJfMjYg/MDAxNjg4MzA3OTAzMzkw.k_VockncmvfbgEcoSg0oTbN0Ge_tPVlcYTrkFWf9ZMIg.VSnZROIjvWyg_DlM4agEPU6i9rIugvQmCYnHK9ktRPkg.PNG.agapeuni/image.png?type=w80_blur)

**2\. New를 클릭하고 Name을 입력**

![](https://postfiles.pstatic.net/MjAyMzA3MDJfMjM5/MDAxNjg4MzA3OTQ0NTk3.9mT-chPnaJ6mJEdLecV5MyQQ7kixcOxU_wKgXm_oDHYg.SwqB8pVjKnrBf_cj9hVPWkvkDVxGuv5kNI3X-ojSWqAg.PNG.agapeuni/image.png?type=w80_blur)

**3\. code에 입력에 스크립트를 입력**

%ForEachTable() { COMMENT ON TABLE %TableName IS '%EntityName'; %ForEachColumn() { %Switch('%ColumnComment') { %Choose(''){COMMENT ON COLUMN %TableName.%ColName IS '%AttName';} %Default {COMMENT ON COLUMN %TableName.%ColName IS '%ColumnComment';} } } }

![](https://postfiles.pstatic.net/MjAyMzA3MDJfMjk3/MDAxNjg4MzA4MDEzODYx.ROtp81ejabxIiGBjfAeJpF0uqHJTVy_PKqvLPieFLtEg.bf45EbhEOMTwJumhUW4SNFP2wp1tz5tIJCUoKDvE_k0g.PNG.agapeuni/image.png?type=w80_blur)

​

**4\. Logical의 한글명이 Comment로 생성**

COMMENT ON TABLE TB_KM_ADMIN IS '관리자'; COMMENT ON COLUMN TB_KM_ADMIN.ADMIN_ID IS '관리자아이디'; COMMENT ON COLUMN TB_KM_ADMIN.ADMIN_PWD IS '비밀번호'; COMMENT ON COLUMN TB_KM_ADMIN.ADMIN_NM IS '이름_한글'; COMMENT ON COLUMN TB_KM_ADMIN.TEL_NO IS '전화번호'; COMMENT ON COLUMN TB_KM_ADMIN.EMAIL IS '이메일'; COMMENT ON COLUMN TB_KM_ADMIN.PHONE_NO IS '휴대전화번호'; COMMENT ON COLUMN TB_KM_ADMIN.STATE IS '상태'; COMMENT ON COLUMN TB_KM_ADMIN.REG_ID IS '등록자아이디'; COMMENT ON COLUMN TB_KM_ADMIN.REG_DT IS '등록일시'; COMMENT ON COLUMN TB_KM_ADMIN.MOD_ID IS '수정자아이디'; COMMENT ON COLUMN TB_KM_ADMIN.MOD_DT IS '수정일시'; 

​
