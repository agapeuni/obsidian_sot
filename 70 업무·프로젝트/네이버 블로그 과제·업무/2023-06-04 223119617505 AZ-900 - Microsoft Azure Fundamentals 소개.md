**1\. AZ-900 자격증**

Microsoft Azure Fundamentals (AZ-900) 클라우드 자격증을 취득하려고 한다. Microsoft Azure의 공식 인증 중 하나인 AZ-900은 Azure 기초를 이해하고 있는 개념을 검증하는 역할을 한다. 클라우드 서비스에 대한 기초 지식과 Microsoft Azure에서 제공되는 방법에 대한 지식을 알고 있으면 된다. AZ-900 시험을 통해 Microsoft Azure의 기본 개념과 서비스에 대한 이해를 인증받을 수 있으며, 클라우드 컴퓨팅과 Azure를 활용하여 조직의 비즈니스 요구사항을 충족시키기 위한 기반을 마련하는 데 도움이 된다. 

​

<https://learn.microsoft.com/ko-kr/certifications/resources/study-guides/az-900>

[ ![](https://dthumb-phinf.pstatic.net/?src=%22https%3A%2F%2Flearn.microsoft.com%2Fen-us%2Fmedia%2Fopen-graph-image.png%22&type=ff500_300) ](https://learn.microsoft.com/ko-kr/certifications/resources/study-guides/az-900) [ **시험 AZ-900: Microsoft 365 기본 사항 학습 가이드** 시험 AZ-900: Microsoft 365 기본 사항 학습 가이드 | Microsoft Docs learn.microsoft.com ](https://learn.microsoft.com/ko-kr/certifications/resources/study-guides/az-900)

AZ-900 시험은 다음과 같은 주요 주제를 다룬다.

1\. Azure의 기초 개념 이해: 클라우드 컴퓨팅, Azure의 이점, Azure 구독 등

2\. Azure 서비스의 주요 기능 이해: 가상 머신, 스토리지, 데이터베이스, 인공지능, 모바일 서비스 등

3\. Azure의 보안 및 규정 준수: 보안 개념, 데이터 보호, 규정 준수 등

4\. Azure 가격 및 지원 계획: 가격 책정 모델, 지원 계획 등

​

AZ-900 시험은 주로 비기술적인 전문가, 비개발자, 비관리자, 비프로그래머 등을 대상으로하며, Azure를 사용하는 결정을 내리는 데 필요한 기본 지식을 제공한다. AZ-900 시험에 합격하면 클라우드 컴퓨팅 및 Azure 서비스에 대한 기본 지식을 보유하고 있다는 것을 인증받을 수 있다. 

​

시험은 다양한 학습 자료와 유튜브 강의를 통해 준비할 수 있으며, Microsoft 웹사이트에서 관련 정보를 찾을 수 있다.
