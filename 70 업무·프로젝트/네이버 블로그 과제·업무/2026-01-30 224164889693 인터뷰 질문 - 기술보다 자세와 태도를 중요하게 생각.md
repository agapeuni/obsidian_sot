# 2026-01-30 224164889693 인터뷰 질문 - 기술보다 자세와 태도를 중요하게 생각

​

2024년 3월부터 현재까지 2년 이상 수행 중인 프로젝트에서, 2026년을 기준으로 두 명의 팀원이 순차적으로 철수하게 되었다. 한 명은 이직으로 인해 2026년 2월말에 프로젝트를 종료하고, 다른 한 명은 개인적인 사정으로 2026년 4월 중순에 철수할 예정이다. 이로 인해 공백이 발생하게 되었고, 해당 인력을 대체하기 위해 신규 인원 채용 인터뷰를 진행하고 있다.

​

인터뷰에 앞서 가장 먼저 하는 일은 지원자의 이력서를 차분히 검토하는 것이다. 나이와 출퇴근 거리가 현실적인 범위인지 확인하고, 전공과 취득한 자격증을 통해 기본적인 배경을 살핀다. 이후 이력서에 정리된 ‘SKILL INVENTORY’를 처음 참여한 프로젝트부터 현재까지 순서대로 읽어 내려가며, 어떤 기술을 어떤 맥락에서 경험해 왔는지를 살펴본다. 단순히 기술 목록을 확인하기보다는, 기술의 흐름과 사용 경험의 축적 과정을 보는 데 초점을 둔다.

​

이 과정을 거치고 나면, 인터뷰에서 직접 확인해 보고 싶은 항목들이 자연스럽게 정리된다. 기술 면접을 진행하다 보면, 대부분의 개발자는 이미 일정 수준 이상의 기술적 경험과 지식을 갖추고 있다. 그래서 인터뷰는 단순히 무엇을 알고 있는지를 확인하는 자리에 그치지 않는다. 질문에 답하는 방식, 설명하는 태도, 그리고 질문 자체에 임하는 자세를 통해 그 사람이 현장에서 어떤 방식으로 일해 왔는지를 함께 살펴보게 된다. 결국 인터뷰는 기술의 깊이뿐 아니라, 일에 대한 태도와 사고방식을 확인하는 과정에 가깝다.

​

Vue.js 3

  * Vue 2의 Options API와 Vue 3의 Composition API는 각각 어떤 장단점이 있는지 설명할 수 있나요?

  * Vue 2와 Vue 3에서 컴포넌트 간 상태를 관리하는 방식은 어떻게 달라졌나요?

  * Vue.js 3를 사용하면서 “이건 Vue 2에서는 불편했는데 확실히 좋아졌다”고 느낀 것이 있나요?

​

Linux / Bash / CI·CD

  * 리눅스 서버 환경에서 명령어를 사용하는 데 어느 정도 익숙한가요? 주로 어떤 작업에 사용했나요?

  * bash 스크립트를 작성해 본 경험이 있다면, 어떤 목적의 스크립트였는지 설명해 주세요.

  * Jenkins 및 Ansible을 사용해 본 경험이 있다면, 과제나 업무에서 어떤 방식으로 활용했는지 말씀해 주세요.
