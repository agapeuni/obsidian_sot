**아펙엔지니어링 자동차 부품 생산 기계 웹사이트 구축기**

이번 프로젝트는 아펙엔지니어링으로부터 수주 받은 자동차 부품 생산 기계 회사의 웹사이트 구축이다. 이 웹사이트는 다양한 제품 정보를 쉽게 검색하고 관련 영상을 제공하는 기능을 구현한 사이트다. 이전의 시스템 프로그래밍 경험을 바탕으로 웹 프로그래밍 분야로 전향한 후, 두 번째로 구축한 웹 사이트였다. 이전의 성공 경험에 자신을 얻어 다양한 기능을 구현해 보았다.

**[No. 05] 아펙머신****(ApecMachine)**

**Windows 98과 ASP로 완성한 웹사이트 및 관리자 툴 개발기**

이번 프로젝트는 Windows 98 운영체제에서 ASP 언어와 MS-SQL 데이터베이스를 사용하여 개발하였다. 제품 정보를 다양한 키워드로 검색할 수 있도록 하고, 웹사이트 외에도 제품 관리 기능을 구현하는 관리 툴을 개발하였다. 비주얼 베이직으로 구현한 관리자 툴은 회원 정보 관리, 제품 정보 관리, 부서/게시판 관리 등의 기능을 지원했다.

​

고객은 매우 협조적인 성격의 단아한 여성분이었고, 덕분에 프로젝트 진행은 큰 어려움 없이 순조롭게 이루어졌다. 여러 기능을 요구하였지만, 충분한 기간 덕분에 관련 기술을 학습할 수 있었고, 유사한 모듈들이 인터넷에 있어 이를 참고하여 원활히 프로젝트를 마무리할 수 있었다. ASP 웹 프로그래밍과 MS-SQL에 대한 경험을 쌓았고, 책이나 학원에서 배운 정보와 실제 업무에서 배우는 차이를 느낄 수 있는 값진 경험이었다.

**ASP·비주얼베이직으로 만든 웹사이트와 통합 관리 시스템**

웹사이트의 모든 콘텐츠는 해외 판매를 고려하여 영어로 서비스되었고, 사이트의 화면 해상도는 당시 기준인 800x600으로 작업했다. 애니메이션 효과가 적용된 플래시로 구현된 사이트맵이 기억에 남는다. 방문 카운터 기능을 구현하기 위해, ASP 코드를 사용하여 메인 화면에 방문자 수를 표시하고, 일정 수마다 카운트를 기록하는 방식으로 작업하였다.

​

회원과 제품을 관리 위한 관리자툴을 별도로 제작해야 해서 비주얼베이직으로 구현하여 제공하였다. 회원정보관리, 제품정보관리, 부서/일반게시판 게시글 관리기능을 제공한다. 이번 프로젝트는 다양한 기능 모듈을 경험하였고, 웹 프로그래밍에 대해 더욱 깊이 배울 수 있는 중요한 계기가 되었으며, 이후 프로그램 개발자로서의 역량을 더욱 넓히는 기회가 되었다.

**설비 장비 코드 관리와 ASP 방문자 카운터 개발 경험**

기계, 설비가 분류에 따라 메뉴로 구성하였으나 설비장비에 대한 코드를 부여하는 작업이 쉽지는 않았다. 검색을 위해서 제품의 동적인 정보표시를 위해서 사진명이랑 데이터베이스에 입력된 코드와 일치시키는게 일이였다.

![](https://postfiles.pstatic.net/20150704_9/agapeuni_1435946493006WJnnS_PNG/20150704_025827.png?type=w80_blur)

![](https://postfiles.pstatic.net/20150704_244/agapeuni_1435946892019bLaPy_PNG/20150704_030801.png?type=w80_blur)

아래의 코드는 위의 화면과는 상관없는 코드이지만 참고용으로 ASP 코드 일부를 넣어 보았다. 메인화면에 방문카운터를 표시하기 위해 counter.txt 파일에 값을 저장하고 화면에 표시한다. 방문자수가 10으로 딱 나누어질 때마다 파일에 카운터값을 저장한다.

​

​

**global.asa 파일**

<SCRIPT LANGUAGE=VBScript RUNAT=Server> Sub Application_OnStart Set objFile = Server.CreateObject("Scripting.FileSystemObject") Set objStream = objFile.OpenTextFile(Server.MapPath("counter.txt"), 1) Application("count") = objStream.ReadLine objStream.close() Set objStream = nothing Set objFile = nothing End Sub Sub Application_OnEnd Set objFile = Server.CreateObject("Scripting.FileSystemObject") Set objStream = objFile.OpenTextFile(Server.MapPath("counter.txt"), 2) objStream.WriteLine(Application("count")) objStream.close() Set objStream = nothing Set objFile = nothing End Sub Sub Session_OnStart Application.Lock Application("count") = Application("count") + 1 Application.UnLock if Application("count") MOD 10 = 0 Then Set objFile = Server.CreateObject("Scripting.FileSystemObject") Set objStream = objFile.OpenTextFile(Server.MapPath("counter.txt"), 2) Application.lock objStream.WriteLine(Application("count")) objStream.close() Application.Unlock End if set objStream = nothing set objFile = nothing End Sub SUB Session_OnEnd END SUB </SCRIPT>
