**SI 개요**

SI (System Integration, 시스템 통합)은 다양한 시스템이 통합되어 하나의 통합 시스템으로 작동하도록 하는 과정을 말한다. 시스템 통합은 여러 개별적인 시스템이 독립적으로 운영되는 것보다 더 효율적인 기능과 데이터 공유를 가능하게 한다. 기업이 필요로 하는 정보시스템에 관한 기획에서부터 개발과 구축, 나아가서는 운영까지의 모든 서비스를 제공하는 이다. 네트워크, 하드웨어 및 소프트웨어 등 IT와 관련된 수많은 요소들을 결합시켜, 하나의 시스템으로서 함께 운영되도록 한다.

​

과거에는 정보시스템을 구축할 때 자체적으로 시스템 구축을 기획하여 설계하고, 개별적으로 하드웨어를 조달하고 소프트웨어를 발주하는 것이 일반적인 방법이었다. 그러나 최근에는 정보기기가 다양해지고, 더욱이 필요로 하는 정보시스템이 거대하고 복잡해지고 있어 사용자는 어떤 기기를 선택해야 하고, 어떤 소프트웨어를 어떤 방법으로 만들어야 할 것인지를 알 수 없는 경우가 많다.

​

SI는 바로 그와 같은 필요성에서 생겨난 서비스로, 시스템의 설계, 최적의 하드웨어 선정에서 발주 및 조달, 사용자의 필요에 맞춘 응용 소프트웨어의 개발, 시스템의 유지 ·보수 등을 포함한다. 이와 같은 서비스를 제공하는 사업자를 시스템통합 사업자(system Integrator)라고 한다. SI 사업자에는 주로 컴퓨터 제조회사, 정보처리 서비스 회사, 소프트웨어 개발 회사, 부가가치 통신망 사업자, 컨설턴트 회사 등이 진출하고 있다. 시스템통합 사업은 무엇보다도 사용자의 요구를 정확하게 파악할 수 있는 우수한 인재의 확보와, 다양한 요소 기술을 가지고 있는 업체의 확보가 성패를 좌우한다.

**​**

**SI 기술**

1) 인터페이스 (Interface)

서로 다른 시스템 간의 상호 작용을 위한 통신 경로 또는 연결점을 나타낸다. 인터페이스는 데이터, 명령어, 제어 신호 등을 교환할 수 있다.

​

2) API (Application Programming Interface)

소프트웨어 응용 프로그램이 다른 소프트웨어와 상호 작용하기 위해 사용하는 인터페이스를 말한다. API는 함수, 프로토콜, 도구 등의 형태로 제공된다.

​

3) SOA (Service-Oriented Architecture)

서비스 지향 아키텍처는 애플리케이션의 기능을 독립적인 서비스 단위로 나누고 이들 서비스를 조합하여 시스템을 구축하는 방법론이다.

​

4) EAI (Enterprise Application Integration)

기업 내에서 다양한 애플리케이션 및 시스템을 통합하는 접근 방식을 의미한다. EAI는 데이터 공유, 프로세스 흐름 및 비즈니스 통합을 강화한다.

​

5) ESB (Enterprise Service Bus)

서비스 지향 아키텍처에서 서비스 간 통신을 중재하는 소프트웨어 인프라스트럭처를 말한다. ESB는 메시징, 라우팅, 프로토콜 변환 등을 처리하여 시스템 간 상호 작용을 용이하게 한다.

​

6) Middleware

분산 환경에서 애플리케이션, 데이터베이스, 하드웨어 등의 소프트웨어와 서비스 간 상호 작용을 지원하는 소프트웨어 계층이다. Middleware는 통합, 통신, 보안 등의 기능을 제공한다.

**​**

**SI 관련 용어**

  * ABC (Activity Based Cost) : 행위기준원가계산

  * APS (Advanced Planning & Scheduling System) : 최적 제조계획/스케쥴링 시스템

  * AQL (Acceptable Quality Level) : 허용품질수준

  * ATO (Assembly to Order) : 주문 조립 생산

  * BOM (Bill of Material) : 자재 List

  * BPR (Business Process Reengineering) : 업무 프로세스 재 설계

  * CAD (Computer Aided Design) : 설계

  * CAE (Computer Aided Engineering) : 분석

  * CALS (Commerce at Light Speed) : 빛처럼 빠른 전자상거래

  * CAM (Computer Aided Manufacturing) : 가공

  * CAPP (Computer Aided Process Planning) : 공정 설계

  * CIM (Computer Integrated Manufacturing) : 통합 생산 시스템

  * CLT (Cumulative Lead Time) : 총 소요 시간

  * COE (Customer Order Entry) : 고객주문처리

  * CRP (Capacity Requirements Planning) : 능력 소용량 계획

  * CSM (Component Supplier Management) : 부품조달관리시스템

  * DRP (Delivery Lead Time) : 납품소요기간

  * DRP (Distribution Requirement Planning) : 물류계획/스케쥴링시스템

  * DSS (Decision Support System) : 의사결정 지원 시스템

  * EC (Electronic Commerce) : 전자상거래

  * EDI (Electronic Data Interchange) : 전자데이터교환

  * EIS (Executive Information System) : 경영자 정보 시스템

  * ERP (Enterprise Resource Planning) : 전사적 자원 관리

  * ETO (Engineering to Order) : 주문설계생산

  * FAS (Final Assembly Schedule) : 최종조립일정

  * GT (Group Technology) : 군(群) 관리

  * IOC (Input Output Control) : 입출물관리

  * JIT (Just in Time) : 적시생산시스템

  * Level-PM (Level Production Method) : 레벨생산방식

  * Level-PM (Levelled Production Method) : 평준화 생산

  * M-BOM (Manufacturing BOM) : 제조 BOM

  * MES (Manufacturing Execution System) : 제조현장관리시스템

  * MIS (Management Information System) : 경영 정보 시스템

  * MPS (Master Production Planning) : 기준생산계획

  * MRP (Material Requirement Planning) : 자재소요량계획

  * MRP II (Manufacturing Resource Planning) : 생산 자원 계획

  * MTO (Make to Order) : 주문생산

  * MTS (Make to Stock) : Stock 생산

  * P/T (Pitch Time) : 제조능력시간

  * PAC (Production Activity Control) : 생산현장관리

  * PDM (Product Data Management) : 제품데이터관리

  * PFS (Process Flow Scheduling) : 흐름생산일정

  * PMS (Purchase Management System) : 구매관리시스템

  * POP (Point of Product) : 생산 시점 관리

  * RCCP (Rough-cut Capacity Planning) : 개략능력분석

  * ROI (Return on Investment) : 투자회수율

  * RP (Resource Planning) : 자원계획

  * S&BP (Strategic & Business Planning) : 전략경영계획

  * SCM (Supply Chain Management) : 공급 망 관리 시스템

  * SFA (Sales Force Automation) : 영업지원시스템

  * SFC (Shop Floor Control) : 작업 현장 관리

  * SIS (Strategic Information System) : 전략 정보 시스템

  * SOP (Standard Operation Procedure) : 표준작업절차

  * WIP (Work in Process) : 재공(在工)
