**1-1장 데이터의 이해**

**1절 데이터와 정보**

데이터의 의미는 관념적이고 추상적인 개념에서 기술적이고 사실적인 의미로 변화

데이터는 추론과 추정의 근거를 이루는 사실

​

정성적 데이터 : 비정형 언어/문자, 주관적, 분석에 비용 소모 많음

정량적 데이터 : 정형 데이터, 객관적, 분석에 비용 소모 적음

​

암묵지 : 학습과 경험, 내면화, 공통화

형식지 : 문서나 매뉴얼, 표출화, 연결화

​

데이터 - 정보 - 지식 - 지혜 

​

​

**2절 데이터베이스 정의와 특징**

정의 : 체계적이거나 조직적으로 정리된 레코드의 집합.

특징 : 통합, 저장, 공용, 변화, 기계가독성, 검색가독성, 원격조작성

​

​

**3절 데이터베이스 활용**

OLTP : 데이터를 수시로 갱신, 갱신 위주, 데이터 복잡, 트랜잭션 중심

OLAP : 정보 분석 처리를 의미, 조회 위주, 데이터 단순, 주제 중심

​

제조, 금융, 유통
