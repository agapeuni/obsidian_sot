**프로그래밍 실력으로 도전한 첫 프로젝트**

대학교에서 컴퓨터과학을 전공하였다. 전자회로를 한 학기 배우고, 두 학기 이상 어셈블리 언어와 C언어를 기본적으로 배웠다. 그동안 쌓아온 프로그래밍 기술을 바탕으로 팀을 이루어 프로젝트를 진행하였다. 처음 진행한 프로젝트라 설렘과 긴장감이 동시에 느껴졌다. 지나고 나면 그런 걱정이나 두려움은 불필요했음을 알게 되었지만, 처음이라 '잘 해낼 수 있을까?' '기능을 못 만들면 어떻게 하지?' 등의 생각이 떠오르며 긴장을 하게 되었다.

​

프로젝트 경비로 작업을 위한 컴퓨터를 제공받았는데, 개인적으로 구매하기엔 비싼 고사양 PC였다. 개인비용으로 구매하기 어려운 꽤나 고급 사양이라 컴파일 시간이 상당히 빠르게 진행되었다. 업무를 진행하면서 이미 배웠던 내용은 더 깊게 알게 되었고, 일을 진행하면서 모르는 내용이 많아 프린트물이나 IT 서적을 계속해서 읽어 나갔다. 학습으로 배우는 것과 실무에서 활용하는 것은 완전히 달랐다.

**ADC부터 DAC까지 어셈블리로 구현한 음성 신호 처리 프로젝트**

프로그래밍 언어로 사용한 어셈블리는 대학교 교과과정에서 배운 내용을 바탕으로 작성하였고, DSP 처리와 음성 신호와 관련된 내용은 인터넷 자료나 마이크로소프트웨어 잡지의 연재 칼럼을 참고하였다. 기능을 구현하는 데 필요한 로직이나 알고리즘은 프로젝트에 함께한 교수님의 지도를 받았다.

​

어셈블리 언어를 사용하여 PC 마이크에서 입력된 음성 신호를 ADC를 통해 디지털 값으로 변환하고, 디지털 신호 처리(DSP)를 이용해 고속으로 처리한 후, DAC를 거쳐 스피커로 재생하는 기능을 구현하였다. 음성 신호의 샘플링 주기를 어셈블리 언어로 조정하여 아날로그 음성 값을 디지털로 변환하고, 이를 메모리 영역에 저장한 뒤 DSP를 통해 디지털 값을 처리하여 다시 아날로그 신호로 변환하여 스피커로 출력하는 방식이었다.

​

영상/음성 보드를 제작하여 직접 고속으로 처리하기 위해서 어셈블리로 로직을 작성하였다.

​

DSP(digital signal processor) : 디지털 신호 처리 

ADC(analog-to-digital converter) : 아날로그-디지털 변환 회로

DAC(digital-to-analog converter) : 디지털-아날로그 변환 회로
