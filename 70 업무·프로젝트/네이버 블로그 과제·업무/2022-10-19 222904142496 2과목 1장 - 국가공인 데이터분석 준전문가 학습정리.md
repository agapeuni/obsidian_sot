**2-1장 데이터 분석 기획의 이해**

**1절 분석 기획 방향성 도출**

분석 기획은 분석을 수행할 과제를 정의하고 의도했던 결과를 도출할 수 있도록 관리하는 방안을 사전에 계획하는 작업이다.

​

분석의 대상(What)과 분석의 방법(How)에 따라 4가지로 나누어진다.

  * 대상도 알고 방법도 알 때 : 최적화 (Optimization)

  * 대상을 모르고 방법은 알 때 : 통찰 (Insight)

  * 대상은 알고 방법을 모를 때 : 솔루션 (Solution)

  * 대상도 모르고 방법도 모를 때 : 발견 (Discovery)

​

과제 중심적인 방식 : 문제 해결, 단기적, Speed & Test

장기적인 마스터 플랜 방식 : 문제 정의, 중장기적. Accuracy & Deploy

​

분석 기획시 고려사항

  * 가용 데이터에 대한 고려

  * 적절한 활용방안과 유즈케이스

  * 장애요소에 대한 사전계획 수립

​

​

**2절 분석 방법론**

방법론은 절차, 방법, 도구와 기법, 템플릿과 산출물로 구성되어 어느 정도 지식만 있으면 활용이 가능해야 한다.

​

합리적 의사결정을 가로막는 장애요소

  * 고정 관념

  * 편향된 생각

  * 프레이밍 효과

​

방법론 업무 특정에 따른 모델

  * 폭포수 모델

  * 프로토타입 모델

  * 나선형 모델

​

* KDD 분석 방법론

  1. 데이터셋 선택 - 비즈니스 도메인, 필요 데이터 선택

  2. 데이터 전처리 - 잡음, 이상치, 결측치 식별. 데이터셋 정제

  3. 데이터 변환 - 데이터 차원을 축소. 학습 데이터와 검증 데이터 분리

  4. 데이터 마이닝 - 적절한 알고리즘 적용. 필요에 따라 전처리와 변환 프로세스를 추가로 실행

  5. 데이터 마이닝 결과 평가 - 분석 목적과의 일치성을 확인. 발견한 지식을 업무에 활용.

​

* CRISP-DM 분석 방법론

  1. 업무 이해 - 요구사항을 이해. 프로젝트 계획 수립. 

  2. 데이터 이해 - 데이터 수집, 속성을 이해. 숨겨져 있는 인사이트 발견

  3. 데이터 준비 - 데이터를 편성하는 단계, 데이터셋 정제

  4. 모델링 - 기법 선택. 파라미터 최적화. 과적합 방지.

  5. 평가 - 분석결과 평가. 모델 적용성 평가

  6. 전개 - 모델을 실무에 적용하기 위한 계획 수립

​

빅데이터 분석 방법론 - 5단계

  1. 분석 기획 - 비즈니스 이해 및 범위 설정, 프로젝트 정의 및 계획 수립, 프로젝트 위험계획 수립

  2. 데이터 준비 - 필요 데이터 정의, 데이터 스토어 설계, 데이터 수집 및 정합성 점검

  3. 데이터 분석 - 분석 데이터 준비, 텍스트 분석, 탐색적 분석, 모델링, 모델 평가 및 검증

  4. 시스템 구현 - 설계 및 구현, 시스템 테스트 및 운영

  5. 평가 및 전개 - 모델 발전 계획 수립, 프로젝트 평가 및 보고
