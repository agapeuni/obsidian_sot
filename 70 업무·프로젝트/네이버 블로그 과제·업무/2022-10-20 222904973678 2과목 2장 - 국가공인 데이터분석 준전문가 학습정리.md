**2-2장 분석 마스터 플랜**

**1절 마스터 플랜 수립 프레임 워크**

적용 우선순위를 설정

  * 전략적 중요도

  * 비즈니스 성과/ROI

  * 실행 용이성

​

적용 범위 / 방식 고려 요소

  * 업무 내재화 적용 수준

  * 분석 데이터 적용 수준

  * 기술 적용 수준

​

분석과제 도출 → 우선순위 평가 → 우선순위 조정

시급성과 난이도로 평가 기준을 정한다.

​

​

**2절 분석 거버넌스 체계 수립**

조직 내 분석 관리체계를 수립

데이터 분석을 기업의 문화로 정착

​

분석 거버넌스 체계 구성요소

  * 분석 기획 및 관리를 수행하는 조직

  * 과제 기획 및 운영 프로세스

  * 분석 관련 시스템

  * 데이터 

  * 분석 교육 및 마인드 육성체계

​

데이터 분석 수준 진단을 위한 분석 준비도의 구성

  * 분석 인력, 조직

  * 분석 문화

  * 분석 업무

  * 분석 기법

  * 분석 데이터

  * 분석 인프라

​

데이터 분석 수준 진단을 위한 분석 성숙도의 구성

  * 비즈니스

  * 조직 및 역량

  * IT

  * 도입 - 활용 - 확산 - 최적화

​

분석 성숙도 모델

CMMI (Capability Maturity Model Integration)

​

준비도와 성숙도에 따른 사분면 분석

준비형(둘 다 낮음), 도입형(준비도 높음), 정착형(성숙도 높음), 확산형(둘 다 높음)

​

데이터 거버넌스 관리 대상

  * 마스터 데이터

  * 메타 데이터

  * 데이터 사전

​

데이터 거버넌스 구성요소

  * 원칙 - 지침과 가이드

  * 조직 - 역할과 책임

  * 프로세스 - 활동과 체계

​

데이터 거버넌스 체계

  * 데이터 표준화

  * 데이터 관리 체계

  * 데이터 저장소 관리

  * 표준화 활동

​

분석을 위한 3가지 데이터 조직 구조

  * 집중 구조

  * 기능 구조

  * 분산 구조
