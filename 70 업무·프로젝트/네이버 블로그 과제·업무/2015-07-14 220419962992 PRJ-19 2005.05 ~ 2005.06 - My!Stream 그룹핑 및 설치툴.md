**My!Stream 그룹 관리와 사용자 편의성을 더하다**

My!Stream 프로젝트를 잘 마무리하는 시점에 일본에서 추가로 요청이 들어왔다. 회사나 학교에서 사용할 수 있도록 그룹핑 기능을 추가하고 손쉽게 설치할 수 있는 인스톨러를 제작해 달라고 하였다.

​

My!Stream 프로젝트를 성공적으로 마무리해가던 시점에, 일본 측으로부터 추가 요청이 들어왔다. 기존 시스템에 회사나 학교 등 단체 사용자를 고려한 그룹핑(Grouping) 기능을 추가해 달라는 것이었다. 이를 통해 여러 사용자를 관리하는 데 있어 보다 체계적이고 효율적인 운영이 가능하도록 시스템을 확장하려는 목적이었다.

​

사용자 편의를 위해 설치 과정을 간소화할 수 있는 전용 인스톨러(Installer)를 함께 제작해 줄 것을 요청받았다. 복잡한 설정 과정을 최소화하고, 비전문가도 손쉽게 시스템을 설치할 수 있도록 하기 위한 조치였다. 추가 요청은 시스템 구조를 일부 수정하고 새로운 기능을 설계해야 하는 작업이었기 때문에, 단순한 유지보수 이상의 노력이 필요했다.

**처음 도전한 인스톨러 제작, 그리고 완성한 GUI·CLI 버전**

그룹핑 기능 개발은 비교적 명확했다. 일본 측이 요구한 기능을 충실히 반영하여 설계하고 구현하는 방식으로 진행하면 되었기에, 큰 어려움 없이 작업을 이어갈 수 있었다. 그러나 문제는 인스톨러(Installer) 제작이었다. 지금까지 솔루션 개발은 경험해왔지만, 인스톨러를 직접 제작해본 경험은 전무했던 터라 처음에는 막연한 부담감을 느꼈다.

​

그럼에도 불구하고, 솔루션을 원활하게 배포하기 위해서는 반드시 인스톨러가 필요했기에 결국 작업을 맡아 진행하게 되었다. "할 수 있다"는 마음가짐으로 하나하나 필요한 부분을 조사하고, 설치 과정을 자동화하는 방법을 익혀가며 개발을 진행했다. 

​

그 결과, 단순히 기본 기능만 구현하는 데 그치지 않고, GUI(Graphical User Interface) 버전과 CLI(Command Line Interface) 버전, 두 가지 형태의 인스톨러를 모두 완성할 수 있었다. GUI 버전은 사용자가 직관적으로 설치 과정을 따라갈 수 있도록 시각적 편의를 제공했고, CLI 버전은 서버 환경이나 터미널 기반 환경에서도 손쉽게 설치할 수 있도록 지원하였다.

**두 달간의 일본 체류, 기술 지원과 추억을 걷다**

약 두 달간 일본에 머무르며, My!Stream을 적용한 여러 사이트에 대한 기술 지원 업무를 수행하였다. 이 기간 동안, My!Stream 설치를 보다 간편하게 진행할 수 있도록 설치 툴도 직접 개발하여 배포하였다. 현지 고객사들의 요청사항을 신속히 반영하고, 시스템 안정성을 확보하는 과정에서 많은 실전 경험을 쌓을 수 있었다.

​

업무 외에도 다양한 전시회를 방문하며 최신 기술 트렌드를 체험할 기회가 있었고, 치바 공업대학(千葉工業大学)에도 들러 학술적인 분위기를 느껴보았다. 프로젝트와 학습을 병행하는 짧지만 알찬 시간이 이어졌다. 남는 시간이나 주말에는 예전에 일했던 곳들을 찾아가 보았다. 

​

과거에 근무했던 회사 주변이나 살았던 동네를 다시 걷게 되니, 문득 가슴이 저릿해졌다. 익숙하면서도 낯선 거리, 그리고 한때의 추억이 남아 있는 장소들이 마음속 깊은 곳을 건드렸다. 시간이 지나도 사라지지 않는 감정과 기억들이, 조용히 가슴 한편에 남아 있다는 사실을 새삼 느낄 수 있었던 소중한 순간이었다.

**My!Stream GUI와 CLI 버전 설치툴 개발**

일본 치바 공업대학과 교육위원회, 그리고 몇몇 초등학교(소학교)에서는 이미 My!Stream 솔루션을 도입하여 사용하고 있었다. 그러나 실제 운영 과정에서는 여러 대의 서버에 제품을 일일이 수작업으로 설치해야 하는 번거로움이 자주 발생하였다. 매뉴얼을 참고해 수동으로 설치하는 과정은 많은 시간과 노력을 필요로 했고, 이로 인해 작업 효율성에도 한계가 드러났다.

​

이러한 문제를 해결하기 위해, 보다 편리하고 신속하게 설치를 진행할 수 있는 전용 설치툴을 제작하게 되었다. 처음에는 적응 기간이 필요했지만, 반년가량 My!Stream 제품을 다루면서 솔루션에 대한 이해도와 자신감을 점차 쌓아나갈 수 있었다. 그 결과, My!Stream의 그룹핑 버전을 새롭게 개발함과 동시에, 설치 과정을 대폭 간소화할 수 있는 설치툴을 함께 완성하였다. 

​

설치툴은 사용자 편의를 고려하여 GUI(Graphical User Interface) 버전과 CLI(Command Line Interface) 버전, 두 가지 형태로 제작하였다. GUI 버전은 비전문가도 손쉽게 사용할 수 있도록 직관적인 화면 구성을 갖추었으며, CLI 버전은 서버 관리자나 고급 사용자를 위해 보다 빠르고 유연한 설치 환경을 제공하였다.

​

![](https://storep-phinf.pstatic.net/moon_special/original_9.png?type=p50_50)

My!Stream 설치툴 기능 순서는 아래와 같다.

01\. 라이센스키 인증

02\. MyStream 설치 (/opt/mystream/)

03\. config.properties 생성 (/opt/mystream/WEB-INF/classes)

04\. ePersNET.jdf.properties 생성 (/opt/mystream/conf/)

05\. ePersNET.pdf.properties 생성 (/opt/mystream/conf/)

07\. httpd.conf 설정 (/etc/httpd/conf/)

08\. workers2.properties 설정 (/etc/httpd/conf/)

09\. mod_jk2.so 복사 (/usr/lib/apache/)

10\. 압축 해제 (/opt/tomcat/)

11\. dbScript 실행 (MySQL)
