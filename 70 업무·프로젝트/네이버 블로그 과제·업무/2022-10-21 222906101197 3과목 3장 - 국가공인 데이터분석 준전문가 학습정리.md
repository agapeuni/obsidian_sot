**3-3장 데이터 마트**

**1절 데이터 변경 및 요약**

데이터 마트는 데이터 웨어하우스와 사용자 사이의 중간층에 위치하고 하나의 주제 중심의 데이터 웨어하우스라 할 수 있다.

​

요약 변수

  * 데이터 마트에서 가장 기본적인 변수

  * 데이터 분석을 위해 만들어지는 변수

  * 분석에 맞게 종합한 변수

  * 공통으로 사용될 수 있어 재활용성이 높다

​

파생 변수

  * 특정 조건이나 특정 함수에 의해 값을 만들어 의미를 부여한 변수

  * 주관적일 수 있어 논리적 타당성을 갖추어 개발해야 함

  * 세분화, 고객 행동 예측, 캠페인 반응 예측에 활용

​

reshape 패키지 활용

  * melt()와 cast() 핵심 함수

  * melt() : 쉬운 캐스팅을 위해 적당한 형태로 만들어 주는 함수

  * cast() : 데이터를 원하는 형태로 계산 또는 변형 시켜주는 함수

​

sqldf 패키지

  * sql 명령어를 사용하게 해주는 패키지

​

plyr 패키지

  * apply 함수에 기반에 데이터와 출력 변수를 동시에 배열로 치환하여 처리하는 패키지

  * a : array

  * d : data frame

  * l : list

  * r : replicate

  * m : arguments

​

data.table 패키지

  * R에서 가장 많이 사용하는 데이터 핸들링 패키지

  * 큰 데이터를 탐색, 연산, 병합하는데 아주 유용

  * data.frame 보다 빠른 속도

​

**2절 데이터 가공**

데이터 분석을 위해 구성된 데이터의 변수들의 상태를 파악

  * head()

  * tail()

  * summary()

​

변수의 중요도

  * 모형을 생성하여 변수의 중요도를 살피는 과정

  * klaR 패키지 활용

​

변수의 구간화

  * 연속형 변수를 분석에 활용하기 위해 구간화하여 모델링에 적용.

  * 보통 5개 구간으로 하고 7개를 넘지 않게 설정.

  * binning : 연속형 변수를 범주형 변수로 구간화하는데 활용

  * 의사결정나무 : 세분화 또는 예측에 활용되는 의사결정나무 모형을 사용하여 입력 변수들을 구간화

​

​

**3절 기초 분석 및 데이터 관리**

EDA(탐색적 자료 분석)

  * 데이터를 다양한 각도로 접근

  * summary()를 이용하여 데이터의 기조 통계량을 확인

​

결측값 인식

  * 결측값은 NA, 999999, '', Unknown 등으로 표현되는 값

  * 결측값을 처리하기 위해 시간을 사용하는 것은 비효율적

  * 결측값 처리는 전체 작업 속도에 영향을 준다

​

결측값 처리

  * 단순 대치법 : 레코드 삭제, 평균 대치법, 단순확률 대치법

  * 다중 대치법 : m 번의 대치를 통해 m 개의 가상적 완전 자료를 만드는 방법 ( 대치 → 분석 → 결합)

  * complete.cases()

  * is.na()

  * Amelia 패키지의 amelia()

​

이상값 인식

  * 의도하지 않게 잘못 입력한 값

  * 분석의 목적이나 종류에 따라 적절한 판단이 필요

​

이상값 처리

  * ESD(Extreme Studentized Deviation) : 평균으로부터 3 표준편차 떨어진 값

  * 극단값 절단 방법 : 기하평균을 이용한 제거, 하단/상단을 이용한 제거 

  * 극단값 조정 방법 : 상한 값과 하한 값을 벗어나는 값들을 상한, 하한으로 바꾸어 활용
