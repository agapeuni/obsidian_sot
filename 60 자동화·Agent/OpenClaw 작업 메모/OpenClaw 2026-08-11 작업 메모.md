## grep·rg 래퍼 실패 원인 규명 및 claude-code 설치 복구

- 작업 ID: `20260811-2003-server-claude-code-native-binary-repair`
- 증상: 셸에서 `grep`, `rg` 호출이 `Error: claude native binary not installed.`를 출력하며 실패했다.
- 오진 배제: `.bashrc`, `.profile`, `/etc/profile.d/*`를 전수 확인했으나 사용자 셸 프로필에는 해당 함수 정의가 없었다. `.bashrc`의 `alias grep='grep --color=auto'`는 무관하다.
- 실제 원인: Claude Code가 자체적으로 주입하는 `grep`/`rg` 래퍼 함수가 `CLAUDE_CODE_EXECPATH`의 번들 ugrep/ripgrep으로 호출을 라우팅하는데, 그 경로의 `bin/claude.exe`가 실제 바이너리가 아니라 에러만 출력하고 exit 1 하는 500 bytes 플레이스홀더 스텁이었다.
- 폴백 미작동 이유: 래퍼는 `[[ -x $_cc_bin ]]`만 검사한다. 스텁이 실행 가능 비트를 갖고 있어 `command grep` 폴백이 발동하지 않았다.
- 근본 원인: 전역 npm 패키지 `@anthropic-ai/claude-code@2.1.227`이 당일 19:59 갱신될 때 postinstall이 완료되지 않아 플랫폼 네이티브 optional dependency(`claude-code-linux-x64`)가 내려받아지지 않았다.
- 조치: 사용자 승인 후 패키지가 안내하는 공식 복구 방법인 `node install.cjs`를 해당 패키지 디렉터리에서 실행했다. 버전 고정 상태를 유지하기 위해 npm 전역 재설치나 `@latest` 업그레이드는 하지 않았다.
- 검증: `bin/claude.exe`가 500 bytes 스텁에서 304,282,632 bytes ELF 64-bit x86-64 실행파일로 교체됨. `grep -c`/`grep -n`/`rg -n` 정상 동작, `rg --version`은 ripgrep 14.1.1(+PCRE2), 래퍼 결과와 `command grep` 결과가 4로 일치. `claude --version` 2.1.227 정상, `openclaw --version` 2026.7.1-2 정상.
- 영향: 전역 npm 패키지 `@anthropic-ai/claude-code`의 `bin/` 디렉터리만 변경했다. 버전은 2.1.227로 유지되며 다른 전역 패키지와 OpenClaw 설정은 변경하지 않았다.
- 재발 가능성: 이 패키지의 자동 업데이트 시 postinstall이 다시 실패하면 같은 증상이 재현된다. 증상이 보이면 같은 `node install.cjs`로 복구한다.
- 상태: 완료.
