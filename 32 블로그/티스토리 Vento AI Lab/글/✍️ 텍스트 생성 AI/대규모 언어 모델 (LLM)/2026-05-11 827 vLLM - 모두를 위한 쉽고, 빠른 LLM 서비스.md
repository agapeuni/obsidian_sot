## vLLM 개요

vLLM(versatile Large Language Model)은 LLM 추론과 서빙을 위한 빠르고 사용하기 쉬운 라이브러리로, UC Berkeley의 스카이 컴퓨팅 랩에서 개발되었으며, 현재는 학계와 산업계의 협력으로 발전하고 있는 커뮤니티 기반 프로젝트이다. vLLM은 고성능 LLM 추론 시스템으로, 대규모 언어 모델(LLM)을 효율적으로 실행하기 위해 설계되었다. 주된 목표는 모델 추론 속도를 향상시키고, 하드웨어 자원을 효율적으로 사용하는 것이다. vLLM은 대규모 언어 모델을 효율적으로 실행할 수 있는 훌륭한 도구로, 특히 배포 환경에서 유용하다.

> Easy, fast, and cheap LLM serving for everyone
>
>
>
>
> 누구에게나 쉽고 빠르며 저렴한 LLM 서비스 제공

vLLM은 페이징 메커니즘(paging mechanism)과 효율적인 캐싱 시스템을 통해 메모리 사용량을 줄이면서도 높은 처리량을 유지한다. 이를 통해 대규모 모델도 상대적으로 적은 자원으로 실행할 수 있다. vLLM은 Attention Key와 Value를 효율적으로 관리하는 새로운 Attention 알고리즘인 PagedAttention을 활용하여 높은 처리량을 제공한다. PagedAttention은 메모리 사용량을 최적화하면서도 성능을 유지하도록 설계되어, LLM 서비스의 처리량과 응답 속도를 혁신적으로 개선한다.

## vLLM 특징

### 1) 속도와 효율성

- 최첨단 서빙 처리량: 고성능 추론 지원.

- 페이지드 에텐션(PagedAttention): Attention key와 value 메모리를 효율적으로 관리.

- 지속적 배치(Continuous batching): 들어오는 요청을 동적으로 묶어 처리.

- 빠른 모델 실행: CUDA/HIP 그래프 활용.

- 양자화 지원: GPTQ, AWQ, INT4, INT8, FP8.

- 최적화된 CUDA 커널: FlashAttention 및 FlashInfer 통합.

- 추측 디코딩: 추론 속도를 더욱 향상.

- 청크 자동 채우기: 초기화 단계에서의 효율성을 강화.

### 2) 유연성과 사용 편의성

- Hugging Face 모델과의 원활한 통합: 간편한 모델 로드와 실행.

- 다양한 디코딩 알고리즘 지원: 병렬 샘플링(parallel sampling), 빔 서치(beam search) 등

- 분산 추론을 위한 텐서 병렬화(Tensor Parallelism)와 파이프라인 병렬화(Pipeline Parallelism) 지원.

- 스트리밍 출력: 실시간 결과 출력 가능.

- OpenAI 호환 API 서버 제공.

- Prefix Caching 및 Multi-LoRA 지원.

## vLLM 설치

NVIDIA GPU(CUDA 11.7 이상 권장)를 사용하는 경우 pip를 직접 사용하여 vLLM을 설치할 수 있다. vLLM은 Python 환경(Python 3.8 이상)에서 동작하며, 최신 버전의 PyTorch 및 CUDA가 설치되어야 한다.

```
pip install vllm
```

**예제 코드**

아래는 vLLM을 사용하여 Hugging Face의 LLM 모델을 로드하고 간단한 텍스트 생성 작업을 수행하는 코드이다. LLM 클래스는 별도의 모델 추론 서버를 사용하지 않고 모델과 상호 작용하여 오프라인 추론을 수행하기 위한 Python 인터페이스를 제공한다.

```
from vllm import LLM, SamplingParams

# vLLM을 사용하여 모델 로드
llm = LLM(model="facebook/opt-125m")  # 필요에 따라 변경 가능

# 생성 파라미터 설정
sampling_params = SamplingParams(
    temperature=0.7,  # 생성의 다양성 제어
    top_p=0.9,  # 확률 분포의 상위 90% 선택
    max_tokens=50,  # 생성할 최대 토큰 수
)

# 입력 프롬프트
prompts = [
    "The president of the United States is",
    "The president of the South Korea is",
]

# 텍스트 생성
outputs = llm.generate(prompts, sampling_params)

for output in outputs:
    prompt = output.prompt
    generated_text = output.outputs[0].text
    print(f"Prompt: {prompt!r}")
    print(f"Output: {generated_text!r}")
```
