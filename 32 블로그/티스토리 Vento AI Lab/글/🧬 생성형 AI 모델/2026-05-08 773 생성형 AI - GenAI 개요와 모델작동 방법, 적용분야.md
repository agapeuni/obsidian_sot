## 생성형 AI 개요

생성형 AI는 원시 또는 훈련 데이터를 기반으로 텍스트, 비디오, 오디오 또는 이미지 등의 새로운 콘텐츠를 생성하는 인공지능 기술을 의미한다. 생성형 AI는 딥러닝 기술을 사용하여 학습하며, 방대한 양의 데이터를 기반으로 패턴을 파악하고 이를 토대로 새로운 데이터를 생성한다. 간단한 입력만으로 새롭고 독창적인 결과를 생성한다.

많이 알려진 대화형 생성형 AI로는 챗GPT, 코파일럿(Copliot), 클로바X(Clova X) 등이 있고 이미지 생성형 AI로는 달리(DALL-E), 미드저니(Midjourney), 스테이블 디퓨전(Stable Diffusion) 등이 있다.

## 생성형 AI 모델

생성형 AI는 복잡한 신경망과 대규모 데이터 분석을 통해 새로운 콘텐츠를 생성하는 강력한 도구다. 데이터의 패턴을 학습하여 이를 기반으로 독창적인 결과물을 만들어내는 능력은 다양한 응용 분야에서 혁신적인 가능성을 제공한다. GANs와 트랜스포머와 같은 모델은 이러한 원리를 바탕으로 다양한 생성 작업에서 높은 성능을 발휘하고 있다.

### 1) GANs (Generative Adversarial Networks)

적대적 생성 신경망 또는 생성적 적대 신경망은 가장 인기 있는 생성적 AI 모델 중 하나다. GAN은 주로 생성자(Generator)와 판별자(Discriminator)라는 두 가지 유형의 신경망을 활용한다. 이 두 네트워크는 훈련 세트에서 실제 데이터를 연구하여 자체 감독 훈련을 거치고, 서로를 보완하며 함께 작동하여 고품질의 현실적인 출력을 생성한다.

![[03 Attachments/티스토리 Vento AI Lab/773/773-002-img1.daumcdn.jpg]]

[출처]   https://www.aitimes.kr/news/articleView.html?idxno=15368

GAN에서 생성자 (Generator)는 새로운 데이터를 생성하는 역할을 한다. 입력 프롬프트나 무작위 노이즈 신호를 사용하여 훈련 세트의 실제 데이터를 기반으로 오디오나 이미지와 같은 새로운 데이터를 생성한다. 판별자를 속여서 생성된 데이터가 실제 데이터처럼 보이도록 만드는 것이다. 그리고 판별자 (Discriminator)는 입력된 데이터가 실제 데이터인지 생성된 데이터인지 구별하는 역할을 한다. 생성된 데이터와 실제 데이터를 일치시켜 구별하도록 훈련된다. 생성자가 만든 데이터를 실제 데이터와 구별한다.

### 2) 트랜스포머 (Transformers)

트랜스포머 모델은 주로 텍스트 데이터를 처리하며, 입력 시퀀스를 토큰 단위로 처리하여 각 토큰의 관계를 학습한다. 트랜스포머 모델은 컨텍스트가 중요한 애플리케이션, 예를 들어 텍스트 번역이나 생성에 가장 적합하다. 트랜스포머는 개별 데이터 포인트를 사용하는 대신 순차적 데이터를 사용하고 내부 관계를 추적하여 컨텍스트와 의미를 학습한다.

트랜스포머는 어텐션 메커니즘을 사용하여 데이터 내의 관계를 학습하고, 이를 통해 컨텍스트와 의미를 이해한다. 이를 통해 순차적 데이터를 처리할 때 뛰어난 성능을 발휘한다. 이러한 모델은 Large Language Models (LLM)에 의해 더욱 지원되고 향상된다. LLM을 활용하여 대규모 데이터를 처리하고, 이를 바탕으로 고성능의 자연어 처리 작업을 수행한다.

## 생성형 AI 작동 방법

생성형 AI는 머신 러닝 프레임워크이다. 그 핵심은 대규모 데이터를 처리하는 신경망을 활용하는 데 있다. 이러한 모델은 데이터를 분석하여 패턴을 식별하고, 이를 기반으로 새로운 콘텐츠를 생성할 수 있다.

### 1) 데이터 수집 및 전처리

- 수집: 텍스트, 이미지, 코드 등 다양한 유형의 대규모 데이터를 수집한다.

- 전처리: 데이터를 정제하고 구조화하여 모델 학습에 적합한 형태로 변환한다.

### 2) 모델 학습

- 신경망 구조: 인간의 뇌를 모방한 신경망을 사용하여 데이터를 처리한다.

- 학습 과정: 대규모 데이터를 통해 패턴과 특징을 학습한다. 이를 통해 모델은 입력 데이터의 구조와 의미를 이해하게 된다.

### 3) 패턴 인식 및 생성

- 패턴 인식: 모델은 학습한 데이터를 통해 패턴을 식별하고 이를 바탕으로 새로운 데이터를 생성할 준비를 한다.

- 데이터 생성: 학습한 패턴을 바탕으로 새로운 텍스트, 이미지, 코드 등을 생성한다.

## 생성형 AI 적용 분야

### 1) 자연어 처리 (NLP)

- 텍스트 생성: 소설, 기사, 시 등 다양한 글을 자동으로 작성.

- 번역: 자동 번역 시스템에서 자연스러운 번역문 생성.

- 챗봇: 사용자와 자연스럽게 대화하는 대화형 AI 시스템.

### 2) 이미지 생성

- 예술 작품 생성: 새로운 그림이나 디자인 생성.

- 사진 보정 및 편집: 낮은 해상도의 사진을 고해상도로 변환하거나 특정 스타일로 변환.

### 3) 비디오 생성

- 애니메이션: 짧은 애니메이션 클립 생성.

- 비디오 편집: 비디오 콘텐츠의 자동 생성 및 편집.

### 4) 음악 및 오디오 생성

- 작곡: 새로운 음악 생성.

- 음성 합성: 자연스러운 음성 생성, 텍스트를 음성으로 변환하는 시스템.

## 인기 있는 생성형 AI

생성형 AI는 텍스트, 이미지, 음악 등 다양한 형태의 데이터를 생성하는 인공지능 기술을 의미한다. 생성형 AI는 각각의 특화된 분야에서 혁신적인 콘텐츠를 생성하는 데 활용되며, 다양한 산업과 응용 분야에서 그 활용도가 계속해서 확장되고 있다. 대표적인 생성형 AI를 정리해보면 다음과 같다.

![[03 Attachments/티스토리 Vento AI Lab/773/773-004-img1.daumcdn.png]]

### 1) 텍스트 생성형 AI

- GPT-4 (OpenAI): 자연어 처리와 생성에서 가장 널리 사용되는 모델 중 하나로, 다양한 질문에 대한 답변, 에세이 작성, 창의적인 글쓰기 등 다양한 작업을 수행한다.

- BERT (Google): 텍스트 이해 및 생성에 강력한 성능을 보이는 모델로, 주로 문장 및 문서의 의미를 이해하고 생성하는 데 사용된다.

- T5 (Google): 텍스트를 다양한 형식으로 변환하는 데 특화된 모델로, 번역, 요약, 질문 생성 등 여러 자연어 처리 작업을 수행할 수 있다.

### 2) 이미지 생성형 AI

- DALL-E (OpenAI): 텍스트 설명을 기반으로 이미지를 생성하는 모델로, 창의적이고 독특한 이미지를 만들어낼 수 있다.

- MidJourney: 고해상도의 예술적 이미지 생성에 특화된 모델로, 사용자의 텍스트 설명을 기반으로 예술적인 이미지를 생성한다.

- Stable Diffusion: 텍스트 설명을 바탕으로 현실적이고 세부적인 이미지를 생성하는 모델로, 다양한 응용 분야에서 사용된다.

### 3) 음악 생성형 AI

- Jukedeck (Bytedance): 사용자가 원하는 스타일과 분위기에 맞춰 음악을 생성해주는 서비스로, 주로 배경 음악 제작에 활용된다.

- OpenAI's MuseNet: 다양한 장르와 스타일의 음악을 생성할 수 있는 모델로, 여러 악기와 복잡한 음악 패턴을 생성할 수 있다.

- Amper Music: 사용자가 선택한 매개변수에 따라 맞춤형 음악을 생성하는 플랫폼으로 광고, 비디오 및 게임 배경음악 제작에 사용된다.

### 4) 동영상 생성형 AI

- Synthesia: 텍스트를 입력하면 가상 인물의 동영상을 생성해주는 플랫폼으로, 주로 교육 및 마케팅 콘텐츠 제작에 활용된다.

- DeepArt: 이미지를 입력하면 그 이미지의 스타일을 적용한 동영상을 생성하는 AI로, 예술적 비디오 콘텐츠 제작에 사용된다.

### 5) 코드 생성형 AI

- GitHub Copilot (OpenAI): 프로그래밍 코드 작성 지원 도구로, 개발자가 코드를 작성할 때 자동 완성 및 코드 제안을 제공한다.

- TabNine: 다양한 프로그래밍 언어를 지원하는 코드 완성 AI로, 개발자 생산성을 높이는 데 도움을 준다.
