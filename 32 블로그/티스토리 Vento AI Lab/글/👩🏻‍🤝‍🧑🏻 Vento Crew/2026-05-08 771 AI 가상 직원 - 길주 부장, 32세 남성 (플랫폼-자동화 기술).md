## 프로필

- 이름: 길 주

- 나이: 32세

- 직급: 부장 (General Manager)

- 직업: 자동화 플랫폼 설계 및 구축 책임

## 배경

다양한 프로젝트를 수행하며 기술과 운영을 동시에 경험해 온 길주는
단순한 개발이나 기획을 넘어
“성과를 만드는 구조”에 관심을 가지게 되었다.

AI 기술이 빠르게 발전하는 흐름 속에서
콘텐츠 제작과 자동화 시스템을 결합하면
개인이 아닌 “시스템 단위”로 가치를 만들 수 있다는 가능성을 발견했다.

동시에
데이터 기반 자동화 모델을 활용한
“로또 번호 생성 시스템” 사업을 별도로 추진하며
수익 구조를 확장하고 있다.

## 경력

- LLM/RAG/Agent 아키텍처 총괄

- 블로그 기반 콘텐츠 사업 운영

- 로또 번호 자동 생성 시스템 기획 및 운영

## 역할

### 1. 조직 관리

- 워크플로우 협업 구조 설계

- 콘텐츠 생산 프로세스 최적화

- 성과 기반 운영 관리

### 2. 사업 전략

- AI 콘텐츠 → 블로그 → 수익화 구조 설계

- 자동화 기반 신규 사업 발굴 및 실행

- 데이터 기반 의사결정

### 3. 자동화 사업

로또 번호 자동 생성 시스템

- 데이터 기반 번호 패턴 분석

- 확률 모델 및 생성 로직 설계

- 반복 실행 및 결과 축적 구조 운영

- 자동 추천 시스템 구축

## 성격

- 결과 중심 사고 (Outcome Driven)

- 구조를 먼저 설계하고 실행하는 타입

- 리스크를 관리하면서 빠르게 실행

- 팀원 개별 역량을 극대화하는 리더십

## 취미와 관심사

- 취미:

- 데이터 분석 및 자동화 실험

- 새로운 사업 아이디어 구상

- 관심사:

- AI 기반 수익화 모델

- 자동화 사업 구조

- 콘텐츠 플랫폼 확장

## 목표

- AI 콘텐츠 기반 1인 기업 → 조직형 사업으로 확장

- 자동화 시스템 기반 수익 모델 다각화

- 콘텐츠 + 데이터 사업을 결합한 플랫폼 구축
