## 1. 텐서플로 개요

요즘 주변에서 인공지능(AI), 기계학습(ML)에 관한 이야기가 자주 들린다. 실제 업무에 인공지능을 사용하는 곳도 점점 늘고 있다. 기술의 트렌드를 따라가기 위해 구글의 딥러닝 "텐서플로(Tensorflow)"를 입문해 본다. 추후에는 로컬PC 나 구글 코랩을 이용할 텐데, 지금은 친숙한 라즈베리 파이에 텐서플로를 설치하고 간단한 예제를 실행해 보자.

## 2. 파이썬 패키지 설치

파이썬과 관련된 패키지를 설치한다. 상황에 따라 이미 패키지가 설치되어 있을 수 있다.

$ sudo apt-get install python3-pip

$ sudo apt-get install python3-dev

$ sudo apt-get install python-virtualenv

![[03 Attachments/티스토리 Vento AI Lab/831/831-002-SE-91f1b7f1-e9c4-40be-92a8-27c88b256a02.png]]

![[03 Attachments/티스토리 Vento AI Lab/831/831-003-SE-f0a7ed03-07bb-4325-b0b4-3f744fb49c5b.png]]

## 3. 텐서플로 가상환경

다음의 명령어로 Tensorflow를 위한 가상환경을 만들고 활성화한다.

$ virtualenv --system-site-packages -p python3 tensorflow

$ source ~/tensorflow/bin/activate

![[03 Attachments/티스토리 Vento AI Lab/831/831-004-image.png]]

## 4. 텐서플로 설치

### 1) 텐서플로 설치 실패

라즈베리 파이에 텐서플로를 설치하는데 디스크 용량 부족으로 인해 실패하였다.

micro SD 카드를 8GB에서 64G으로 변경하여 재설치하였다.

![[03 Attachments/티스토리 Vento AI Lab/831/831-005-SE-80c76ca2-f046-4a52-90b9-7044d6d6b982.png]]

### 2) whl 파일 URL

아래의 사이트에 설치하고자 하는 대상의 URL을 링크 복사한다.

라즈베리 파이의 버전에 따라 설치할 수 있는 whl아 나와있다.

[https://github.com/lhelontra/tensorflow-on-arm/releases](https://github.com/lhelontra/tensorflow-on-arm/releases)

![[03 Attachments/티스토리 Vento AI Lab/831/831-006-image.png]]

### 3) whl 파일 URL 복사

설치하려는 디바이스가 라즈베리 파이 3이라 [**tensorflow-2.4.0-cp37-none-linux_armv7l.whl에**](https://github.com/lhelontra/tensorflow-on-arm/releases/download/v2.2.0/tensorflow-2.2.0-cp37-none-linux_armv7l.whl) 대한 링크를 복사해 두었다.

![[03 Attachments/티스토리 Vento AI Lab/831/831-007-image.png]]

****

### 4) whl 파일로 텐서플로설치

복사한 URL를 사용하여 아래의 명령을 실행한다. 그러면 가상환경에 텐서플로를 설치한다.

pip install [https://github.com/lhelontra/tensorflow-on-arm/releases/download/v2.4.0/tensorflow-2.4.0-cp37-none-linux_armv7l.whl](https://github.com/lhelontra/tensorflow-on-arm/releases/download/v2.4.0/tensorflow-2.4.0-cp37-none-linux_armv7l.whl)

![[03 Attachments/티스토리 Vento AI Lab/831/831-008-image.png]]

## 6. 오류 발생

pip install tensorflow로 설치하면 1.14.0-cp37 버전이 설치되는데, 뭔가 문제가 있는지 간단한 예제를 실행해도 오류가 난다.

[https://www.piwheels.org/simple/tensorflow/tensorflow-1.14.0-cp37-none-linux_armv7l.whl](https://www.piwheels.org/simple/tensorflow/tensorflow-1.14.0-cp37-none-linux_armv7l.whl)

## 7. CUDA Toolkit 설치

CUDA Toolkit 버전을 10.1로 맞추라고 한다.

[https://developer.nvidia.com/cuda-toolkit-archive](https://developer.nvidia.com/cuda-toolkit-archive)

![[03 Attachments/티스토리 Vento AI Lab/831/831-013-image.png]]

서적에는 아래와 같이 설치하라고 했는데 잘 안된다.

$ pip install tensorflow

구글링해서 찾은 자료에는 아래와 같이 설치하라고 한다.

$ pip install tensorflow-cpu

이미 설치가 되어 있어서 아래와 같이 실행했다.

아래의 명령어로 설치하고 나니 다행히 실행된다.

$ pip install --upgrade tensorflow-cpu
