이 책은 파이썬에 관한 개념을 설명하기 위한 부분과 기술을 소개하는 부분으로 되어있다. 파이썬을 관습적으로 사용하는 방법과 그 방법에 따라 코드를 작성하는 것에 관한 방법을 다룬다. 예제와 설명을 보면 기술 서적이라기보다는 기본서에 가깝다. 개념과 원리를 상세히 다루고 있어 학습에는 도움이 되는데 실무에 활용하기에는 코드가 그리 실용적이지 않아 아쉽다.

> 파이썬의 기본적인 내용이 절반이고
> 
> 동시성, 병렬성, 비동기의 내용이 절반이다.

First-Class, Higher-Order Function, Closure, Decorator, Iterator, Generator, Comprehension & Expression, Equality vs Identity 와 같은 개념에 대해 설명하고 있다. Lock, Mutex, Semaphore는 20년 전에 배운 내용인데 그동안 프로젝트 진행하면서 한번도 사용한 적이 없었다. 그런데 이책에서 다시 Lock, Mutex, Semaphore를 다루고 있었다. 마지막으로 파이썬 학습 서적에서 잘 다루지 않는 '동시성'과 '비동기'를 다루고 있는데 읽으면서도 이런 기술을 언제 사용을 할까? 하고 의문이 든다. 

​

저자에게는 미안한 이야기지만 서적에 담긴 내용을 어느 정도 파악을 한 상태였으면 이 책을 구매하지 않고 그냥 도서관에서 빌려보았을 것이다.

소스코드와 실행 결과 그리고 개념 설명이 잘 구분되어 있어 읽기는 편하다. 개념과 원리에 관한 내용이 많아 관심이 없다면 다소 지루하거나 따분할 수 있다. 유익한 내용들도 곳곳에 있어 잘 알아두면 나중에 도움이 될 수도 있다. 

def args_test(*args): print ("=== args list ===") for arg in args: print ("Argument : %s" % arg) def kwargs_test(**kwargs): print ("=== kwargs list ===") for keyword, arg in kwargs.items(): print ("Argument keyword : %s, arg : %s" % (keyword, arg)) def main(): args = ["red", "blue", "first", "second"] kwargs = {"red":"color", "blue":"color", "first":"number", "second":"number"} args_test(*args) kwargs_test(**kwargs) if __name__ == "__main__": main()
