# 2019-03-13 221487275698 독서-402 디비로 누리는 특별한 세상 SQL Server 운영편

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221487275698&categoryNo=1213
- 게시일: 2019. 3. 13. 15:27

## 본문

![](https://postfiles.pstatic.net/MjAyMzA2MDdfOTEg/MDAxNjg2MTQ4NTMwMTMx.dUdMnvkFaa9FAjxBesLxrtqn68iuxIyWXDY8aqDvFa8g.hF4sfX6Tqckcbd77VjxYnrmxZFShXi6TkZ7pucG280og.PNG.agapeuni/SE-9baeea76-1362-4102-bc80-a56b1e6aa518.png?type=w80_blur)

현재 진행하는 프로젝트에서 MS-SQL Server를 사용한다. 턴키로 프로젝트 계약을 진행하게 되었다. 운영서버 데이터베이스 구축 작업을 하게 되어 해당 서적을 참고하여 원활하게 진행을 하였습니다. 운영과 개발을 위한 데이터베이스 구축에 잘 활용하여서 책값은 충분히 하였다.

​

아주 오래전에 MS SQL을 사용하고 많은 시간이 지났는데 다시 단계별로 진행해 보니 화면이 조금 변경되었을 뿐 사용방법은 크게 달라지진 않았다. SSMS는 SQL Server Management Studio로 가장 핵심적인 도구로 개발과 운영에 사용하는 통합 도구이다. 운영서버를 설치하고 추가로 해야할 작업은 백업과 복원 그리고 권한 관리였는데 책의 내용을 가이드 삼아 잘 마무리 되었다. ㅎㅎ

![](https://postfiles.pstatic.net/MjAyMjEyMTJfMTY4/MDAxNjcwNzgxMzYzNjkx.xP7MB7qIUMw3cdz_HWFPYVI098JAxZDzXwADuRhCtzgg.U0KOSxqToOQOmwbtlAhhdBBGaRlg2_8UKFGGBVHCvtYg.JPEG.agapeuni/SE-f8a06212-7978-11ed-aed4-116299a5a835.jpg?type=w80_blur)

​

자동화(Automations)를 잘 해두면 DBA 업무 부담을 줄일 수 있다. 나중에 Daily로 전체백업을 작업을 할 때 아래의 내용을 참고해야겠다. 설치 과정에서 파일들이 위치할 폴더(Data, Log, Backup)를 지정해야 하는데 미리 만들로 진행하는 것이 편리하다. 

  * D:\SQLData

  * E:\SQLLog

  * F:\SQLBackup

​

![](https://postfiles.pstatic.net/MjAxOTAzMTNfODYg/MDAxNTUyNDU3NDYzMDcy.E4Jh7lki03NfQlDI-k6vafjHjJqO7RVQl9MW0KBXzPYg.MkFwsETnx9Bfyhye8lzb9fv-ZdAMg-p925uPoUXMz-Ag.JPEG.agapeuni/KakaoTalk_20190313_140301334.jpg?type=w966)

​

이 책의 특징은 내용의 깊이는 입문자 수준이라 설명을 읽어보면 쉽게 이해할 수 있다. 그리고 큼지막한 화면과 이해를 돕는 일러스트 그림이 적절히 있어서 페이지는 손쉽게 넘어간다. 개인적인 생각인데 설명과 내용을 보다 보강하고 전체적으로 그림의 크기를 조금 줄이는 것도 좋을거 같다.

![](https://postfiles.pstatic.net/MjAyMjEyMTJfMjQx/MDAxNjcwNzgxMzY0Nzkx.h9sK2HmghK842tBq_6vGoSMhjotSvLNbl66wSQmW83Ug.d8HGz2zc0Q2J2TGii-yZkmY-6BxCeW5JPw35kf9V1eEg.JPEG.agapeuni/SE-f8a0883a-7978-11ed-aed4-d77853e18996.jpg?type=w80_blur)

​

저자가 MS SQL Server에 오련 경험을 갖고 있어서 그런지 입문자의 눈높이로 설명을 잘 해주고 있고 그림도 적절히 잘 보여주고 있다. 아래의 그림을 보시면 알겠지만 잘 그려진 한장의 그림이 페이지를 차지하는 부분도 있지만 많은 설명을 대신한다.

![](https://postfiles.pstatic.net/MjAyMjEyMTJfMTkx/MDAxNjcwNzgxMzY1NjE5.D2GU5lSXpgQ96SR3A4Bm5CooQERp1wo9E1mX5aDg_WAg.e2kGdIcPA99naQEtIEpBcjqiWjtYRv_uccOPsKjwCKsg.JPEG.agapeuni/SE-f8a0884a-7978-11ed-aed4-11a3277905a4.jpg?type=w80_blur)

​

데이터베이스를 백업/복원하고 나서 로그인 계정과 데이터베이스 사용자 계정을 만들어 주고나서 적절한 권한을 부여하고 작업을 마무리하였다.
