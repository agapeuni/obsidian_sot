​

자바 웹 애플리케이션에 관한 개념과 이론 설명이 참 잘 정리되어 있다. 필요한 정보만 정리해 놓은 교과서처럼 것처럼 내용이 깔끔하다. 아쉬운 것은 편집이나 구성이 너무 밋밋하여 페이지를 읽어 나가는게 지루한 면이 있다. 서블릿을 처음 배우거나 서블릿의 기능을 제대로 배우기 원하는 사람에게 추천한다.

​

**1장 서블릿**

​

**2장 세션 관리**

URL rewriting, Hidden Field, Cookie, HttpSession

​

**3장 JSP**

Implicit Objects - request, response, out, session, application, config, pageContext, page, exception

directive - page, include

​

**4장 EL(Expression Language)**

​

c - core, x - xml, fmt - fmt, sql - sql, fn - function

if, choose, when, otherwise, forEach, forTokens

​

**6장 커스텀 태그**

SimpleTag, EL function

​

**7장 태그 파일**

Tag File - .tag

​

**8장 리스너**

​

**9장 필터**

Filter, FilterConfig, FilterChain

​

Model 1
