# 2017-05-23 221011941278 독서-253 마이바티스 프로그래밍 - 데이터베이스 프레임워크

- 게시일: 2017. 5. 23. 1:32

## 본문

![](https://postfiles.pstatic.net/MjAyMzA1MzFfMjM1/MDAxNjg1NTI4NDI2NDk3.E2tC9svnvZCe_nDRbvY6OvtRiVpnpDWeqUuVA5LC3rsg.w08lraFXuzYXKI06uPOdVqR9qWRY5P9W9EdO-q5taawg.PNG.agapeuni/image.png?type=w80_blur)

이 책은 아이바티스에서 마이바티스로 전환하는 경우와 마이바티스를 새롭게 적용하는 경우에 많은 도움이 됩니다. 이제 마이바티스는 프로젝트를 진행할 때 거의 표준과 가까운 퍼시스턴스 프레임워크가 되었습니다. 아이바티스가 기존에 갖고 있는 장점위에 다양한 기능들과 편리함을 업그레이드한 뒤 마이바티스로 변경되어 나타났습니다. 

![](https://postfiles.pstatic.net/MjAxNzA1MjNfMTM1/MDAxNDk1NDcwNTM4NDA1.4oMKOyb2Xkd6ECA-4mRPQtr-chsW3Un-T3ZePpmupOUg.78PUYGFswKMnDHD4EZ_7SjtDdxVUcoK4ZPLydA4c4SMg.JPEG.agapeuni/20170523_010629.jpg?type=w80_blur)

마이바티스(MyBatis)는 Java 언어를 위한 오픈 소스 데이터 매핑 프레임워크입니다. 마이바티스는 기존의 iBATIS 프레임워크에서 파생되었으며, 데이터베이스와의 상호작용을 쉽게 처리할 수 있도록 도와줍니다. 마이바티스는 SQL 매핑을 통해 Java 객체와 SQL 문 사이의 매핑을 제공합니다. 개발자는 XML 또는 애노테이션을 사용하여 객체와 데이터베이스 테이블, SQL 문을 연결할 수 있습니다. 이를 통해 SQL 문을 명시적으로 작성하고 데이터베이스와 상호작용할 수 있습니다.

​

마이바티스의 핵심 컴포넌트는 SqlSession이라는 이름의 객체입니다. SqlSession은 데이터베이스와의 연결을 관리하고 SQL 문을 실행하는 데 사용됩니다. SqlSession은 개발자가 정의한 SQL 문을 실행하고 결과를 객체로 변환하여 반환하는 데 필요한 모든 로직을 처리합니다. ​

![](https://postfiles.pstatic.net/MjAxNzA1MjNfMjYg/MDAxNDk1NDcwNTM4NzMw.S-cNLj6y1I_gWfSOqr7mUGPfUtRdYCn-sDNF8fEzpvQg.yaJgiGdMO_tHVzCwiqQN4o-3qGapprIuFbVB5DKTdZMg.JPEG.agapeuni/20170523_010928.jpg?type=w80_blur)

마이바티스는 다음과 같은 주요 특징을 가지고 있습니다.

​

1\. SQL 매핑: 마이바티스는 SQL 매핑을 사용하여 자바 객체와 SQL 쿼리 간의 매핑을 정의합니다. 개발자는 XML 또는 어노테이션을 사용하여 SQL 매핑을 작성하고, 데이터베이스 연산에 필요한 SQL 문과 자바 객체 간의 매핑을 지정할 수 있습니다.

​

2\. 유연한 쿼리 작성: 마이바티스는 동적 SQL을 지원하여 복잡한 쿼리를 작성하는 데 유용합니다. 개발자는 조건문, 반복문 등을 사용하여 동적으로 쿼리를 생성할 수 있습니다.

​

3\. 자동 매핑: 마이바티스는 결과셋을 자동으로 자바 객체에 매핑할 수 있습니다. 개발자는 SQL 매핑을 통해 결과셋의 열과 자바 객체의 프로퍼티를 매핑하거나, 커스텀 매핑 규칙을 정의할 수 있습니다.

​

4\. 다양한 데이터베이스 지원: 마이바티스는 다양한 데이터베이스를 지원합니다. 데이터베이스에 종속되지 않는 범용적인 SQL 쿼리 작성이 가능하며, 데이터베이스 간의 이식성을 제공합니다.

​

5\. 성능 최적화: 마이바티스는 SQL 성능 최적화를 위한 다양한 기능을 제공합니다. 캐시 기능을 활용하여 반복적인 쿼리 실행을 피하고, 지연 로딩을 통해 필요한 시점에 데이터를 로드할 수 있습니다.

​

6\. 간결한 코드: 마이바티스는 간결하고 직관적인 코드를 작성할 수 있도록 도와줍니다. SQL 문을 XML이나 어노테이션으로 분리하고, 데이터베이스 연산을 간단한 메서드로 호출할 수 있습니다.
