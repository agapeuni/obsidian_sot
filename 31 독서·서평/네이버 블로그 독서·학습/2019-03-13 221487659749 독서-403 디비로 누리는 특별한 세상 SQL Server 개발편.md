학습을 목적으로 SQL Server를 설치하려고 하면 Developer Edition을 설치하면 된다.

​

운영편에서는 DBA 및 서버운영자를 위한 운영 및 활용에 대한 방법을 다루었다면 이 책에서는 개발자를 위한 간단한 쿼리부터 고급쿼리까지 다루고 있다. 간단한 예제들을 기반으로 구성되어 있어서 학습하기에는 좋지만 단순하고 평이한 내용으로 되어 있어서 중급자에겐 다소 아쉬움이 남을 수 있다.

![](https://postfiles.pstatic.net/MjAxOTAzMTNfMTg1/MDAxNTUyNDg3MzQyMDY3.KF_Xzjiurxa5U0AbweSWSptKYACz0M1K5Rmtau4QTekg.LceP2gVLbmhn2UZZvwMJGXZzdfGvqJ7UNgfJkgCG-08g.JPEG.agapeuni/KakaoTalk_20190313_223303920.jpg?type=w80_blur)

SQL Server 2005까지는 날짜와 시간 데이터 형식은 datetime과 smalldatetime이 었는데 SQL Server 2008부터 date, time, datetime2, datetimeoffset이 추가되었다. 

​

임시 테이블을 만들 수 있는데 테이블 이름앞에 '#'을 붙이면 된다. 지역 임시 테이블로 세션에서만 사용가능하다. 전역 임시 테이블은 테이블 이름앞에 '#'을 두개 붙이면 되는데 다른 세션에서도 조회가 가능하다.

​

데이터 파일이 있고 트랜젝션 로그 파일이 있고 데이터 파일은 페이지와 익스텐트로 구성되어 있는 데이버베이스 구조를 아래의 한장의 그림이 말해주고 있습니다. 데이터베이스를 생성하면 기본적으로 만들어지는 파일들입니다.

![](https://postfiles.pstatic.net/MjAxOTAzMTNfMjA4/MDAxNTUyNDg3MzM5NjAx._Jh94_ht8JX2stq8sGZeUJqLIHdJc4MoD_GEwnSQeDsg.dkM-Xhry2lnJTDO7ZNaaB2u1Fn33lMoy3Gjx_sUHdtkg.JPEG.agapeuni/KakaoTalk_20190313_221224566.jpg?type=w80_blur)

​

집계를 위한 쿼리문을 작성하다 보면 순위를 구하거나 번호를 표시해야 하는 경우가 있다. SQL Server에서는 순위와 관련된 다양한 함수를 제공한다. 순위를 가져오는 RANK, DENSE_RANK, ROW_NUMBER 는 매번 사용해도 기억에 남지 않아서 번번히 다시 보게 된다.

![](https://postfiles.pstatic.net/MjAxOTAzMTNfMjcw/MDAxNTUyNDg3MzM5OTYz.iba47SD1cmUY_IOC87UMErO455EcB9U1kOBfqtgvE-0g.eYQV6f9VwxG96DDcuvsLxR7m9qbaMSUl8pUdeSXf_w0g.JPEG.agapeuni/KakaoTalk_20190313_221224765.jpg?type=w80_blur)
