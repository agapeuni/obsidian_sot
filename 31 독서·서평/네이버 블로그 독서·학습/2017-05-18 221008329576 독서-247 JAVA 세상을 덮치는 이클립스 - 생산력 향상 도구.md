# 2017-05-18 221008329576 독서-247 JAVA 세상을 덮치는 이클립스 - 생산력 향상 도구

## 본문

![](https://postfiles.pstatic.net/MjAyMzA1MzFfNzIg/MDAxNjg1NTI3NjkwMjE5.g5JJOvI45VDHWDtMy81oO067MXyxFARRVgvT0rnCPlEg.JWIlqhx260O46-w4kpadHNWR8e2-xJe86fkDukI8KYog.PNG.agapeuni/image.png?type=w80_blur)

​

Java 기반의 프로그램을 개발하는데 있어서 이클립스는 최선의 IDE이다. 상용툴 못지않은 막강한 기능을 갖고 있음에도 무료로 제공하고 있으며 지속적인 업그레이드를 하고 있다. 자바 프로젝트를 진행할 때 이클립스가 없다는 것은 생각할 수도 없다. 이클립스에서 Working Set를 사용하여 자신의 작업을 정의해 두면 작업하고자 하는 대상 코드만 뷰에 표시할 수 있어서 업무 효율을 높일 수 있다. 

![](https://postfiles.pstatic.net/MjAxNzA1MThfMTYz/MDAxNDk1MDU5Nzg1NjM0.34LCqkewOpWu50YlEG3iK_5cIrnUTMlS-hRaSeGZmgAg.NE3ecB5coSz3rHbuTwQKx9JCAIKNromLzWYDwESHe3kg.JPEG.agapeuni/20170518_002518.jpg?type=w80_blur)

​

Package Explorer에 Java 파일의 Outline 정보도 표시되는데 경험상 에디트 화면에서 단축키를 사용해서 개요를 보는 것이 편하고 Package Explorer에서는 개요 정보가 표시되지 않는 것이 하위 트리를 자동으로 펼칠 때 효율적이다.

![](https://postfiles.pstatic.net/MjAxNzA1MThfMjUw/MDAxNDk1MDU5Nzg1ODUy.PR3YCjXen4yH16KOOfll8nwUKLnak6HtfdBtU4hAWyEg.vhH0SsUCSl60StcBAza3AVxM-u32juGQjMhab-X_FMcg.JPEG.agapeuni/20170518_003149.jpg?type=w80_blur)

​

Ant build.xml 파일 하나 잘 만들어 두면 프로젝트 진행하는데 두고두고 편리함을 느끼게 해준다.

![](https://postfiles.pstatic.net/MjAxNzA1MThfMjQy/MDAxNDk1MDU5Nzg2MDY5.Sq0TlgvHjfiv8VwuT-xgd49HsxgtugDe19_N6SxjLf0g.OULsxXcngT5tawqcoOLPSfoDyOR9C8Gk_eKP1xxOoxcg.JPEG.agapeuni/20170518_004020.jpg?type=w80_blur)
