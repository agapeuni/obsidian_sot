# 2017-05-20 221009957708 독서-249 iBATIS 인 액션 - 강력한 SQL 매핑 프레임워크

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221009957708&categoryNo=1213

## 본문

![](https://postfiles.pstatic.net/MjAyMzA1MzFfMTUg/MDAxNjg1NTI4MDM3ODUx.DZVp7OA3BQDIUG1AcgSA1QWOCtspUj-m0KU6mHstgb8g.arEHaTD38q2S30W_PBA5MVPT7Zh6pWHpaNBSHc6DW-Ug.PNG.agapeuni/image.png?type=w80_blur)

번역서이긴 하지만 현재 국내에 한글로 되어 있는 유일한 iBATIS 서적입니다. 그리고 저자가 iBATIS 프레임워크를 만든 사람입니다. 지금은 현장에서 아이바티스 대신 마이바티스를 많이 사용하고 있지만 이전에 구축되어 있는 시스템에는 아직도 iBATIS로 되어 있습니다. 이 프레임워크 덕분에 보다 편리하고 효율적인 시스템을 손쉽게 만들 수 있게 되었습니다.

​

iBATIS는 Java 언어를 위한 데이터 매핑 프레임워크로, 데이터베이스와의 상호작용을 간소화하는 데 사용됩니다. iBATIS는 객체 지향 프로그래밍 모델과 관계형 데이터베이스 사이의 간극을 줄여줍니다. iBATIS는 SQL 매핑을 통해 Java 객체와 SQL 문 사이의 매핑을 지원합니다. 개발자는 XML 또는 애노테이션을 사용하여 객체와 데이터베이스 테이블, SQL 문을 연결할 수 있습니다. 이를 통해 SQL 문을 명시적으로 작성하고 데이터베이스와 상호작용할 수 있습니다.

​

iBATIS의 핵심 컴포넌트는 SqlMap이라는 이름의 객체입니다. SqlMap은 데이터베이스와의 연결을 관리하고 SQL 문을 실행하는 데 사용됩니다. SqlMap은 SQL 문을 실행하고 결과를 객체로 변환하여 반환하는 데 필요한 모든 로직을 포함합니다. iBATIS는 오픈 소스로 개발되었으며, Apache Software Foundation의 Apache iBATIS 프로젝트로 유지되었습니다.

​

​

iBATIS는 다음과 같은 주요 구성 요소로 구성됩니다.

​

1\. SQL Maps: SQL Maps는 SQL 쿼리와 자바 객체 간의 매핑을 정의하는 XML 파일입니다. 개발자는 SQL Maps를 사용하여 데이터베이스 연산을 수행하는 SQL 문을 작성하고, 입력 및 출력 매개변수와 결과 객체를 매핑할 수 있습니다.

​

2\. SqlMapClient: SqlMapClient는 iBATIS에서 SQL Maps를 실행하는 인터페이스입니다. 개발자는 SqlMapClient를 사용하여 데이터베이스에 대한 CRUD(Create, Read, Update, Delete) 작업을 수행할 수 있습니다.

​

3\. Data Access Objects (DAOs): DAO는 데이터베이스와 상호 작용하는 메서드를 제공하는 인터페이스 또는 클래스입니다. iBATIS는 DAO 패턴을 지원하며, 개발자는 DAO를 사용하여 SQL Maps와 SqlMapClient를 조합하여 데이터베이스 연산을 수행할 수 있습니다.

​

​

iBATIS의 주요 특징

  * 간단한 설정: XML 파일을 사용하여 SQL 쿼리와 자바 객체 간의 매핑을 정의하므로 간단한 설정이 가능합니다.

  * 직접적인 SQL 제어: 개발자가 직접 SQL 쿼리를 작성하고 매핑하는 방식으로, 세밀한 제어와 최적화가 가능합니다.

  * 재사용 가능한 SQL 매핑: SQL Maps는 재사용 가능한 구성 요소로 분리하여 코드의 중복을 방지하고 유지보수성을 향상시킵니다.

  * 다양한 데이터베이스 지원: iBATIS는 다양한 데이터베이스를 지원하며, 데이터베이스 간 이식성을 제공합니다.

​

iBATIS의 개념도입니다.
