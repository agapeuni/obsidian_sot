![](https://postfiles.pstatic.net/MjAyMzA1MzFfMjUy/MDAxNjg1NTM2OTAxMDk0.nLuJ6J_2rDcBSQQtlr8jma4vvaY5ZCpr1R4hDgwlI8kg.xqVa6sjtrOCdgNomt8bnLRSQbXRfFkFdIpH0JQ-JuI8g.PNG.agapeuni/image.png?type=w80_blur)

발행한지 10년이 지난 서적이지만 자바스크립트에 대하여 기본적인 기술을 소개하고 있습니다.

참고로 이 책은 EMCA-262와 JavaScript 1.5/1.6을 기초로 하고 있습니다.

![](https://postfiles.pstatic.net/MjAxNzA0MjVfMTM4/MDAxNDkzMTA1ODIwMjY0.phvqH7qS43bqF6f53fbhQ_JqGsRWogZTUsYkQnWk_mEg.caW5_pHCeejhmyi6OWaTuclLxu4mDJaeQi8Tkbe0POsg.JPEG.agapeuni/20160403_112945.jpg?type=w80_blur)

아래에 클로저에 대한 내용은 설명이나 예제가 충분하지는 않습니다.

해당 기술에 대한 실용적인 예제가 많이 없어서 아쉽긴 한데 기본적인 내용과 객체에 대한 설명은 잘 되어 있습니다.

![](https://postfiles.pstatic.net/MjAxNzA0MjVfMTky/MDAxNDkzMTEwNjQwODg3.H_8qUFeafa4dSzVV8qfh76yACY5Sp40Wd1CRKaV-3NAg.lkfZATdEQXIBAfgTLe4CM3MO6pky1eyMp19qi5uZEP8g.JPEG.agapeuni/20160403_113022.jpg?type=w80_blur)

부록에 개발환경과 디버깅 툴에 대한 설명도 되어 있고 Prototype, Rico, Dojo, MochiKit과 같은 JavaScript 라이브러리를 소개하고 있습니다.

![](https://postfiles.pstatic.net/MjAxNzA0MjVfMjk0/MDAxNDkzMTEwNDk0ODIw.LmnHYWovz17s5VdYT4laBm5oXqvB64d3UsbETUTgS8Ug.eoRliZj2dpaNjveO7Fww7gw__VIDKBTNLofHyjffYO0g.JPEG.agapeuni/20160403_113108.jpg?type=w80_blur)

0, "", NaN, null, undefined 는 false 이다.
