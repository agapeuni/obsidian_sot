# 2020-11-28 222156637051 독서-531 자바로 시작하는 라즈베리 파이 - BlueJ와 함께

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=222156637051&categoryNo=1213

## 본문

![](https://postfiles.pstatic.net/MjAyMzAzMTZfNzYg/MDAxNjc4OTU2OTUxMjAz._xW0t0_l_lFc8KnDnOFHY8uQqomJTb9SpeCFxqNDgsQg.BOk5H8updtFxIHX6zoL4icCH6U8b6Zx9-K8Qel7E7K8g.PNG.agapeuni/image.png?type=w80_blur)

작년 초에 직접 번역하였던 책인데 기억을 더듬어 다시 한번 읽어보았다. 다른 분야와 달리 IT 기술의 변화는 너무 빠르다. 예전에는 IT 기술서적이 평균적으로 2년이나 3년 이상을 커버했었다. 이 책은 아직 1년 반을 조금 넘었는데 벌써 많은 변화가 생겨 페이지의 내용이 옛 기술이 되어 버렸다. 

​

![](https://postfiles.pstatic.net/MjAyMDExMjdfMjAz/MDAxNjA2NDg1NDMyODIw.kwKaFhW4XYg-_F7QVlheas2SqJ96nGttfKQkeCGdxw0g.AAkthl1GAIsw_yzU5Ha91XEX8lsugoC2ksZ89KcoFH8g.PNG.agapeuni/image.png?type=w80_blur)

​

이 책을 번역할 시점에서는 일본어 서적의 내용도 이미 옛 기술이 되어버려 많은 부분을 변경된 내용을 반영하여 최신으로 업데이트해주었다. 하지만 그 노력마저 무의미해질 정도가 기술의 변화가 너무 빠르다. 본의 아니게 출판사에 미안한 마음이 든다.

![](https://postfiles.pstatic.net/MjAyMDExMjdfMjQy/MDAxNjA2NDg1NDMyOTgy.Ix299GL0-oOJiOyAgTa1dmFKPkq8Ah_-a2OPSW_3KWMg.h26up46zfrLv8fPOa5oIXe3VismGuyC3iogE3tpS8X8g.PNG.agapeuni/image.png?type=w80_blur)

많은 사람들이 익숙해져 있는 Java 언어로 라즈베리 파이에 접근하려는 의도는 좋았다고 본다. 하지만 이미 대중적인 언어가 되어버린 Python 언어가 라즈베리 파이의 기본 언어라는 점이 Pi4J의 활용과 확산에 제제를 받는다.

![](https://postfiles.pstatic.net/MjAyMDExMjdfOTQg/MDAxNjA2NDg1NDM0MjQ2.zu4MrKF_Phf79UXjYX7zlwUhy8qQOUhYDqmhRGAOOdEg.FWOvnE5ZGOh1cs3uJ9A_IH9T5_L-PPJenpBUqDc7f3wg.PNG.agapeuni/image.png?type=w80_blur)

​

BlueJ는 전세계 수백만 명이 사용하고 있는 초보자를 위한 무료 Java 개발 환경이다. Java 프로그램을 빠르고 쉽게 개발할 수 있다. Java의 창시자인 제임스 고슬링도 가장 좋아하는 개발환경 중 하나가 BlueJ라고 했다. 윈도우와 맥뿐만 아니라 우분투 등 다양한 운영체제를 지원하고 있다.

​

단순한 인터페이스를 가지고 있고 교육을 염두해 두고 설계되었다. 이 책에서 소개하고 있는 BlueJ는 교육현장에서 활용하면 좋을거 같다. 프로그래밍을 배우는데 있어 클래스를 시각적으로 나타낼 수 있어서 교육생의 이해를 돕는데 효과적으로 보인다.

![](https://postfiles.pstatic.net/MjAyMDExMjdfMzkg/MDAxNjA2NDg1NDM0Mzkz.KZuykmYNJHxqt_FchJuAhp5mbSXLQYX8rkOSciOq8P0g.lytm_Z7UAPn0v8iwMykDGHAkIRuFgSTMFEppoV9VAKMg.PNG.agapeuni/image.png?type=w80_blur)
