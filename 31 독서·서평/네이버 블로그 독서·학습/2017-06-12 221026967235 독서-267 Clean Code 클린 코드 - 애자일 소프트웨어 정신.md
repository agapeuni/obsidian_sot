# 2017-06-12 221026967235 독서-267 Clean Code 클린 코드 - 애자일 소프트웨어 정신

## 본문

![](https://postfiles.pstatic.net/MjAyMzA1MjhfNTcg/MDAxNjg1MjA0ODAxODkx.i6wgBHvRhXK5O4dkTnZ4llXCMkOrJoHpnFsVMCO_ECAg.qcDyKSljrHUyaNz14ErIARgFOxT9Xx_lEviRcRuhx1Yg.PNG.agapeuni/image.png?type=w80_blur)

각 장마다 저자의 경험과 노하우가 담겨 있어서 무언가 배울 것과 익힐 것이 많이 있습니다. 설명을 진행하면서 적절한 코드를 예제로 보여주고 있고 공감할 만한 사례들이 적절하여 보다 쉽게 이해할 수 있습니다. 하지만 부록에 80페이지 분량의 소스와 테스크 코드를 그대로 옮긴것은 페이지 낭비인 것 같다. 차라리 소스코드 직접 다운을 받게 하고 책을 좀더 얇게 만들 수 있었을 것을 하는 아쉬움이 있습니다.

![](https://postfiles.pstatic.net/MjAxNzA2MTJfMTIw/MDAxNDk3MTk5NDcyNDA4.fIQWyr-Dp-lWPLR9JMAn-aGKu_n0CVxa-ZQNB2d50LIg.h7V3hq9mGr-2CiuF9RYvh2neXneygL8Nha4Cmoqk86Qg.JPEG.agapeuni/IMG_20170611_233719.jpg?type=w80_blur)

![](https://postfiles.pstatic.net/MjAxNzA2MTJfMjg4/MDAxNDk3MTk5NDcyNTkz.R4IlYrqb3e9ajNbF49bjbil6W76fz5NaCxA56oorQ-Mg.7JCgXg-fy6yeTkIuboL3HRisM0HccP5Q7phmyrNaWZ8g.JPEG.agapeuni/IMG_20170611_233755.jpg?type=w80_blur)

이번에 프로그래밍 할 때는 기능 구현도 중요하지만 무엇보다 깨끗한 코드 작성에 집중해보려고 합니다. 변수명이나 함수명을 의미를 잘 전달할 수 있도록 서술적으로 기재하여 주석을 불필요하게 하고 한눈에 알 수 있게 최대한 응집도를 높이면서 단순화 할 계획입니다. 이 책에서 말하고 있는 내용들을 적극 참고하여 클린 코드를 작성을 해보려고 합니다.
