# 2021-12-04 222586384884 독서-626 파이썬아 반가워! - 20일 안에 끝내는 코딩

## 본문

회사 업무를 진행하는데 있어 파이썬의 활용이 점점 많아지고 있다. 사업부마다 파이썬을 업무에 적용하고 있다. 미래를 준비하기 위해 주말마다 아이들에게 코딩을 알려주고 있는데 이 책을 교재로 사용하려고 한다. 

![](https://postfiles.pstatic.net/MjAyMTEyMDRfMTM0/MDAxNjM4NTU3NzE4MjUy.9DGusErcCwNdkIlXLLF57WDxsLszsN0myITB0tJtE-4g.yXblwDpp6wWoZxvUbX2EOJFCnAj5kNEdd4qYoGW5HLMg.JPEG.agapeuni/SE-e7360f10-e4fd-416e-bf19-3b94376f9cae.jpg?type=w80_blur)

주말 강좌를 2장 엔트리와 엔트리파이썬은 건너뛰고 3장부터 진행했다. 이전에 스크래치를 가리켜 보았다. 아이들이 스크래치로 코딩을 학습하기보다는 간단한 게임을 만들거나 고양이로 장난을 하는데 시간을 보내 깊이있는 코딩을 경험하지 못했다. 이번에는 그런 상황을 피하기 싶었고 개인적으로 생각하기에도 스크래치나 엔트리가 아이들에게 진정한 프로그래밍을 접하지 못하게 하는 것처럼 보였다.

![](https://postfiles.pstatic.net/MjAyMTEyMDRfMTQ1/MDAxNjM4NTU3NzE1NDYy.RrrkhFSZLamjYX70GOcGQjJbNFB1spS9aZygnGV8m6gg.tPxNxKVO7i2eZzv8BnT1mp79yYtOuYJvs-hk0qoJ0Hwg.JPEG.agapeuni/SE-2c86731c-54ee-44e3-9633-7aa44b1f4edf.jpg?type=w80_blur)

지난주에는 변수와 연산자 그리고 데이터 타입에 대해 배웠다. 파이썬으로 진행하니 확실하게 아이들이 자바를 배울때 보다 힘들어 하지 않았다. 코딩은 별로의 프로그램 설치 없이 진행이 가능한 Jupyter notebook을 사용했다. turtle 모듈을 사용하여 원격에 위치한 노트북에서 각자의 거북이가 움직이는 것을 신기해 했다.

import random from turtle import Turtle t = Turtle() def up(): if (t.heading() == 90): t.forward(100) else: t.setheading(90) t.forward(100) def down(): if (t.heading() == 270): t.forward(100) else: t.setheading(270) t.forward(100) def right(): if (t.heading() == 0): t.forward(100) else: t.setheading(0) t.forward(100) def left(): if (t.heading() == 180): t.forward(100) else: t.setheading(180) t.forward(100) def undo(): t.undo() def key_event(): t.shape('turtle') t.screen.onkey(up, 'Up') t.screen.onkey(down, 'Down') t.screen.onkey(right, 'Right') t.screen.onkey(left, 'Left') t.screen.onkey(undo, 'Escape') t.screen.listen() t.screen.title('Turtle v1.0') key_event() t.screen.mainloop()
