## 본문

![](https://postfiles.pstatic.net/MjAyMzAzMTFfMTgy/MDAxNjc4NTM0MjU5MTMx.lsqFClpVB0B2etc7o6Gyp8wUchT0ja_6KyVKzi1YQREg.f_8PcffeSvbb9uRNKC6ys9XpB5F0f_tqDRy5AamN0YEg.PNG.agapeuni/image.png?type=w80_blur)

​

프로젝트 진행시 10년 가까이 SVN을 주로 사용하였다. 하지만 최근에 진행하는 프로젝트들은 Git을 사용하고 있다. 그동안 익숙한 SVN 과는 개념이나 사용법이 다른 Git을 처음 접할 때는 개념과 문맥을 이해하지 못해 어려운 부분도 있었지만 인터넷이나 서적을 통해 어느 정도 익숙해졌다. 

​

하지만 뭔가 제대로 숙지하지 못하고 있어 뭔가 부족한 감이 있어 항상 아쉬움이 있었는데 이 책으로 어느 정도 해결했다. 고양이 개발자와 문어 개발자가 등장하여 단계별로 내용을 전달하고 있어서 그냥 따라가는 것으로도 충분한 이해가 되었다.

​

로컬 저장소를 생성하면 오른쪽에 "master" 가 표시된다. 'master'라는 브랜치가 기본 이름이다. 브랜치는 단순하게 커밋을 가리키는 포인터이다.

**$ git init**

![](https://postfiles.pstatic.net/MjAyMTA0MjhfMTcw/MDAxNjE5NTQwMDk0MDM1.t7k0xT2Dgu-S7qW_SLxg5fDCyieKQf5Cjn6Hg02ltN0g.s2lRkJal9vg2Qa125z1-SFC3BZnuX8MGn2YV5F5NpnYg.PNG.agapeuni/image.png?type=w80_blur)

​

Git의 옵션에는 local, global, system 환경이 있다.

local은 Git 저장소에서만 유효하고 global은 현재 사용자 그리고 system은 PC 전체 사용자에 적용된다.

​

다음의 명령어는 모든 옵션을 출력한다.

**$ git config --list**

**$ git config --global core.editor "nano"**

![](https://postfiles.pstatic.net/MjAyMTA0MjhfMTI0/MDAxNjE5NTQwMzAyNjk1.tjHpEt7zw-o9tuJoz9nHIRnFKskqgEcC3ny1NauUY80g.BJ55qkiZbaAhqx4alkg8Tlkr4VTI-1UCW4w1H2S7IGgg.PNG.agapeuni/image.png?type=w80_blur)

​

file1.txt 이름의 새로운 파일을 하나 만든다.

![](https://postfiles.pstatic.net/MjAyMTA0MjhfMTUy/MDAxNjE5NTQwODMyMTA2.K9YZ2FDnhmnFvBPOQ4pWI21yw6VAL7LfDjoFaqAcALwg.u2SCC9yjXAVlcELodBeV-ShYajnwNmgaisMogCJ_Drsg.PNG.agapeuni/image.png?type=w80_blur)

​

git add 명령을 사용하여 스테이지 영역에 추가한다. 취소하려면 git reset file1.txt를 입력한다.

![](https://postfiles.pstatic.net/MjAyMTA0MjhfMTAg/MDAxNjE5NTQwODY0MTY3.eyo0G8q5wxes9VueuVGCwJb_knxeemHkte7suXK2FNog.H5RNagynG7xPZY6RBVDADDuDVd1UZU70rkuibawMLYIg.PNG.agapeuni/image.png?type=w80_blur)

​

아래의 명령어는 origin이라는 이름으로 원격 저장소를 추가한다. 그리고 원격 저장소의 목록을 확인한다.

**$ git remote add origin**[**https://github.com/agapeuni/test-git.git**](https://github.com/agapeuni/name.git)

**$ git remote -v**
