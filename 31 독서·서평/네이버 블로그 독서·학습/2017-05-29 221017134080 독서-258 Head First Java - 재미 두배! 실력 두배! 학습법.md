이 책은 두뇌 친화적인 학습이론을 바탕으로 자바를 재미있고 즐겁게 배울 수 있다. 프로그래밍 서적도 이렇게 재미있게 집필 할 수 있다는 것을 보여주는 대표적인 서적으로 생각된다. 아래의 그림만 보아도 소스 코드를 컴파일하여 바이트코드를 생성하고 가상머신에서 실행하는 과정이 한눈에 들어온다.

​

*** 나중에 참고할 만한 내용**

\- 간단히 정리해본 자바의 역사

\- 상속과 다형성에 관한 설명

\- 추상클래스와 인터페이스에 관한 설명

\- JAR 만들고 실행하는 방법

\- 자바 웹 스타트 (JWS, Java Web Start)

"소스 -> 컴파일러 -> 결과물 -> 가상머신" 까지의 과정을 잘 표현하여 그림만 보아도 이해가 잘 된다.
