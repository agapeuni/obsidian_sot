# 2023-06-14 223128260428 독서-782 그림으로 이해하는 AWS 구조와 기술 - 클라우드

## 본문

![](https://postfiles.pstatic.net/MjAyMzA2MTNfMjMz/MDAxNjg2NjYzNDQ1NjA3.TpUWlhXGcdxWoSyGvSBjseVrC7iXPntJ2ijZFpq1Wywg.-jrolmx_STBRWrdsIvagfsLljkgZX8lbSXklpceW_9Ag.PNG.agapeuni/image.png?type=w80_blur)

AWS(Amazon Web Services)는 아마존에서 제공하는 포괄적인 클라우드 컴퓨팅 플랫폼이다. 개인, 기업 및 조직이 확장 가능하고 유연하게 다양한 응용 프로그램과 서비스를 구축하고 배포할 수 있는 다양한 서비스를 제공한다. 이 플랫폼은 계속해서 발전하며 사용자의 변화하는 요구에 맞춰 새로운 기능과 서비스를 제공하고 있다.

​

아마존 웹 서비스에 관한 기초 지식을 그림과 함께 쉽게 이해할 수 있다. 그리고 AWS의 대표적인 서비스인 Amazon EC2(서버 서비스), Amazon S3(스토리지 서비스), Amazon VPC(가상 네트워크 서비스), Amazon RDS(데이터베이스 서비스)에 대해 개요와 기능 그리고 과금에 대해 잘 설명해 주고 있다.

![](https://postfiles.pstatic.net/MjAyMzA2MTNfODQg/MDAxNjg2NjYzMzIzNDEz.wDQeJc801-d8WUFkaF5_MD49lJkaamLvCPAE6STbwOgg.Ly8uMQSG7lcdKrr16ER8E1HW1p_oA3Oz7TUthqq5cEog.JPEG.agapeuni/SE-3ca8e643-cf2f-4f8b-a617-c2228853320d.jpg?type=w80_blur)

1) EC 인스턴스 (서버) : 웹 서버로 사용. 

2) RDS 인스턴스 (DB 서버) : DB 서버로 사용.

​

![](https://postfiles.pstatic.net/MjAyMzA2MTNfMjgg/MDAxNjg2NjYzMzI1Njcy.WXF1wIlsUnrjc2B8DmKn2qZcKMzu9BHPnzhrPVKA26cg.BhwNVLYfkQ9RtqhwSoGTJyKxrzhj8hmYwdfY8c-fmDUg.JPEG.agapeuni/SE-ab334ef4-e3c3-4a1e-88e7-558e952c7190.jpg?type=w80_blur)

1) EC 인스턴스 (서버) : 웹 서버 2대와 상품 등록 서버 1대.

2) RDS 인스턴스 (DB 서버) : DB 서버로 사용.

3) S3 패킷 (DB 서버) : 이미지·동영상 서버.

4) ELB (로드 밸런서) : 웹 서버 앞에 둠.

​

![](https://postfiles.pstatic.net/MjAyMzA2MTNfMjU0/MDAxNjg2NjYzMzI3ODgx.alq8gozxpRsh9f2X37CXbWp3alWEoxdKN7QazGccdwMg.f0LEKGThYb3UdQBnZ3fEHGdmYQFas3IhDfzM40X3zwgg.JPEG.agapeuni/SE-d7f07e07-1baa-407e-a01a-5efc6ab04077.jpg?type=w80_blur)

1) EC 인스턴스 (서버) : 업무 시스템 서버와 인증 서버.

2) RDS 인스턴스 (DB 서버) : DB 서버로 사용.

3) S3 패킷 (DB 서버) : 파일서버. 연결은 게이트웨이 엔드포인트를 사용.

4) Direct Connect : 사내에서 접속 회선으로 사용.

​

![](https://postfiles.pstatic.net/MjAyMzA2MTNfMjkg/MDAxNjg2NjYzMzI5ODg5.PZtd4nepCbZy3LLFqv1NZK2-trM3iimuu4l_B92I8X4g.kKIIoTB_nyWYQNL-3-yz5vS-VFKs90PQ1c8WIo1kV44g.JPEG.agapeuni/SE-1e610fce-5aaf-44f4-b513-f96d59b0cc47.jpg?type=w80_blur)

1) EC 인스턴스 (서버) : EC 사이트.

2) Redshift (데이터 웨어하우스) : 집계 및 분석 서버로 사용.

3) S3 패킷 (DB 서버) : 로그 및 매출 데이터 저장. 결과 취합.
