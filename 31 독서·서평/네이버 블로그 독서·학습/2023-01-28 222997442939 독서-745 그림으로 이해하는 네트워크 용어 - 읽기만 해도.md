블루투스 : 네트워크를 구축하기 위한 규격이 아니라 기기 상호 간을 무선으로 연결하기 위한 통신방식.

인프라 모드 : 엑세스 포인트라는 기지국을 중심으로 통신.

애드훅 모드 : 무선 LAN 어댑터끼리 직접 통신하는 방식.

노드 : 접속점, 마디라는 의미. 네트워크에 연결된 기기.

VPN : 네트워크에 가상적인 전용 공간을 만들어 거점 사이를 안전하게 연결하는 기술.

UPnP : 유니버설 플러그 앤 플레이의 약어로 PnP의 개념을 네트워크까지 확장.

NAT : 사설 IP 주소와 공인 IP 주소를 상호 변환하는 기술.

패킷 필터링 : 미리 지정된 규칙에 따라 통과시킬지 여부를 제어하는 기능. 프로토콜과 포트로 구별 가능.

프록시 서버 : 내부 네트워크의 컴퓨터를 대신해 외부 네트워크에 엑세스 하는 서비스. 일반적으로 프록시 서버는 방화벽에서 실행.
