Java 6을 기준으로 새롭게 등장한 기술 소개와 프로페셔널한 Java 활용 기술을 설명하고 있다. IT 영어는 그렇게 어렵지 않아서 원서로 보아도 어느 정도 읽혔는데 다시 읽으려니 이해가 잘 안된다. 한참을 들여다보면 내용이 조금 와닿기는 하는데 이제는 거의 해독하는 분위기다. ㅠㅠ

​

30대에는 영문서적도 어느 정도 읽혔는데 40대가 되니 이제 영어가 버겁다는 생각이 든다.
