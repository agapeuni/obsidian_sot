# 2017-08-05 221067180412 독서-274 이펙티브 자바(Effective Java) 제2판 - 자바 SE6

- 원문: https://blog.naver.com/PostView.naver?blogId=agapeuni&logNo=221067180412&categoryNo=1213
- 게시일: 2017. 8. 5. 1:09

## 본문

![](https://postfiles.pstatic.net/MjAyMzA1MjVfNzIg/MDAxNjg0OTYwNTkyNDc4.4xaJj7TxaPuiHGyuk3UF2Oh1iI8C5-foGT6w-nzWsoYg.2caNgIV1SefzoZPrdL_a_CJUZjgCbvc7lJ8n2UmhBXgg.PNG.agapeuni/image.png?type=w80_blur)

5월 중순부터 시작한 프로젝트의 작업 일정이 그다지 여유롭지 못해서 평일에는 일하는데 에너지를 소비하여 독서의 진도가 떨어졌다. 앞으로는 하루의 일정이 바쁘더라도 버려지는 시간을 잘 관리하고 시간 배분을 잘해서 독서의 시간을 의지적으로 만들려고 한다. 자바의 깊이를 더하고 기술을 보다 향상시키고 싶어 여러 사람들의 평판이 괜찮은 이 책을 읽게 되었다. 여타 기본서나 입문서와 달리 내용은 심도 있고 많은 요소 기술을 담고 있다. 하지만 그림이나 도표 없이 대부분 난해한 설명 위주로 되어있어서 전달력이 약해서 이해하기도 쉽지 않았고 번역서가 갖고 있는 원천적인 한계도 있어 보였다.

![](https://postfiles.pstatic.net/MjAxNzA4MDRfMjc2/MDAxNTAxODU4NDY4MjYw.iNUdRex0S5Bumj7sw7AKWRbtMN-awBr3BY0KkTbLtHkg.pHNQNoYX_RK7K5M3Df_1fs4TSjmhWdYRG5yUz-Fj7jsg.JPEG.agapeuni/IMG_20170804_234115.jpg?type=w80_blur)

​

읽고 있는 과정에서는 자바에 이런 내용도 있구나 하며 새로운 것을 배우는 면도 있었다. 하지만 대학교 전공서적처럼 장황한 내용을 텍스트 기반으로 죽 나열되어 있어서 책 속에 내용이 잘 전달이 되지 않아 이해가 힘들었다. 예제 코드도 실무에서 접하지 못하는 것들도 있어서 실용적인 면에서는 아쉬운 부분도 있다.

![](https://postfiles.pstatic.net/MjAxNzA4MDRfOTgg/MDAxNTAxODU4NDY4NTAx.8Ch-PIbfsvQvS5tmYGh2JLxglx2iIk8YW1nL6ygRgbog.STsdmhxSO7WSGTRIncQSLJGXgvD8IAhNh6anYNvd960g.JPEG.agapeuni/IMG_20170804_234200.jpg?type=w80_blur)

​

대부분의 페이지가 사진처럼 설명 위주로 되어 있고 번역된 설명도 그렇게 쉽게 전달되지 않아서 끝까지 보는 것이 상당한 인내와 자제력이 필요하다. 곳곳에 유용한 내용들이 있지만 개인적으로는 잘 요리된 스테이크를 먹는 것이 아니라 덩어리 고기를 거칠게 익혀서 먹는 것 같다.
